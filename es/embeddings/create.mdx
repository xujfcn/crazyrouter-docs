## Descripción de la interfaz

Convierte el texto de entrada en un vector de alta dimensión, utilizado para búsqueda semántica, agrupamiento, recomendaciones y otros escenarios. Totalmente compatible con el formato OpenAI Embeddings API.

## Modelos compatibles

| Modelo | Dimensiones | Descripción |
|------|------|------|
| `text-embedding-3-large` | 3072 | Alta precisión, recomendado para entornos de producción |
| `text-embedding-3-small` | 1536 | Gran relación calidad/precio |
| `text-embedding-ada-002` | 1536 | Modelo clásico |

## Parámetros de solicitud

<ParamField body="model" type="string" required>
  Nombre del modelo de embedding, por ejemplo `text-embedding-3-large`
</ParamField>

<ParamField body="input" type="string | string[]" required>
  Texto a embeddar, se admite una sola cadena o un arreglo de cadenas
</ParamField>

<ParamField body="encoding_format" type="string" default="float">
  Formato de retorno: `float` o `base64`
</ParamField>

<ParamField body="dimensions" type="integer">
  Dimensión del vector de salida (soportado solo por `text-embedding-3-*`)
</ParamField>

## Formato de la respuesta

```json
{
  "object": "list",
  "data": [
    {
      "object": "embedding",
      "index": 0,
      "embedding": [0.0023064255, -0.009327292, ...]
    }
  ],
  "model": "text-embedding-3-large",
  "usage": {
    "prompt_tokens": 8,
    "total_tokens": 8
  }
}
```

## Ejemplo de código

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.embeddings.create(
    model="text-embedding-3-large",
    input="Crazyrouter 是一个 AI 模型网关"
)

embedding = response.data[0].embedding
print(f"向量维度: {len(embedding)}")
print(f"前5个值: {embedding[:5]}")
```

```python Python (批量)
response = client.embeddings.create(
    model="text-embedding-3-large",
    input=[
        "第一段文本",
        "第二段文本",
        "第三段文本"
    ]
)

for item in response.data:
    print(f"索引 {item.index}: 维度 {len(item.embedding)}")
```

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/embeddings \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-large",
    "input": "Crazyrouter 是一个 AI 模型网关"
  }'
```

</CodeGroup>

<Note>
  En solicitudes por lotes, se admite un máximo de 2048 textos por vez. Se recomienda no superar los 8191 tokens por texto.
</Note>
