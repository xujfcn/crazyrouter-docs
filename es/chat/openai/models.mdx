# Listar modelos

```
GET /v1/models
```

Devuelve la lista de modelos disponibles para la API Key actual.

Esta página sólo registra acciones `2026-04-14` que ya han sido verificadas en el entorno de producción de Crazyrouter.

## Autenticación

```text
Authorization: Bearer YOUR_API_KEY
```

## Ejemplo de solicitud

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

models = client.models.list()

for model in models.data:
    print(model.id)
```

```javascript Node.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.crazyrouter.com/v1",
});

const models = await client.models.list();

for (const model of models.data) {
  console.log(model.id);
}
```

</CodeGroup>

## Campos comunes

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `success` | boolean | Indica si la solicitud fue exitosa |
| `id` | string | Identificador del modelo que se pasa al llamar la API |
| `object` | string | Fijo como `model` |
| `created` | integer | Marca de tiempo |
| `owned_by` | string | Identificador de la organización o fuente del modelo |

## Información de precios

Si necesitas información pública sobre precios, consulta la [página de precios](https://crazyrouter.com/es/pricing). Para la confirmación de modelos visibles por el Token actual desde el lado de la programación, sigue usando `GET /v1/models` de esta página.

<Note>
  `GET /v1/models` devuelto por `supported_endpoint_types` solo indica el estilo de interfaz admitido por el modelo actual. `openai` corresponde a `POST /v1/chat/completions`, `anthropic` corresponde a `POST /v1/messages`, solo `openai-response` corresponde a `POST /v1/responses`. Actualmente, Claude admite públicamente `openai` + `anthropic`, no admite `openai-response`.
</Note>
