# Compatibilidad con Claude PDF

```
POST /v1/messages
```

Hasta el 23 de marzo de 2026, el entorno de producción de Crazyrouter ha verificado que `claude-opus-4-8` puede leer archivos PDF en Base64 mediante la API nativa de Messages y devolver un resumen de texto.

---

## Solicitud mínima verificada

```bash
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 512,
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "document",
            "source": {
              "type": "base64",
              "media_type": "application/pdf",
              "data": "JVBERi0xLjQK..."
            }
          },
          {
            "type": "text",
            "text": "Summarize the document in one sentence."
          }
        ]
      }
    ]
  }'
```

Forma clave devuelta realmente en producción:

```json
{
  "model": "claude-opus-4-8",
  "content": [
    {
      "type": "text",
      "text": "The document is a simple Crazyrouter PDF test document..."
    }
  ]
}
```

<Note>
  Actualmente, esta página solo mantiene la ruta de entrada de PDF en Base64 que ya ha sido probada con éxito. En esta ronda no se volvieron a testear escenarios más complejos como URL remotos, comparación de múltiples PDF o salida de PDF en streaming.
</Note>
