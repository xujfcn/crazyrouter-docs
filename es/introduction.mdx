<Note>
  Ruta de acceso a la API: la entrada internacional predeterminada es `https://api.crazyrouter.com`, se recomienda priorizar `https://cn.crazyrouter.com` en el este de Asia. Los clientes compatibles con OpenAI suelen añadir `/v1` tras el dominio principal; los clientes nativos de Claude Code / Anthropic usan solo el dominio principal, sin añadir `/v1`. Consulta [Puntos finales de la API](/es/api-endpoint) para más detalles.
</Note>

Crazyrouter es una pasarela API unificada para modelos de IA. Puedes usar una sola clave API para invocar capacidades de modelos para texto, imagen, video, audio, embedding, rerank y la integración de herramientas de terceros.
