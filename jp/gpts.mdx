## 概要

Crazyrouterは標準のChat Completions APIを介してOpenAI GPTs（カスタムGPTアプリケーション）を呼び出すことをサポートしています。モデル名をGPTs特有の形式に設定するだけで利用できます。

## モデル名の形式

```
gpt-4-gizmo-{gizmo_id}
```

ここで、`gizmo_id`はGPTsの一意の識別子であり、GPTsのURLから取得できます。

## Gizmo IDの取得方法

1. [ChatGPT GPTsストア](https://chatgpt.com/gpts)にアクセス
2. 対象となるGPTアプリを開く
3. URLからIDを抽出: `https://chatgpt.com/g/g-B3hgivKK9-xxx` → IDは`g-B3hgivKK9`

## コード例

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

# 使用 GPTs 对话
response = client.chat.completions.create(
    model="gpt-4-gizmo-g-B3hgivKK9",
    messages=[
        {"role": "user", "content": "你好，请介绍一下你自己"}
    ]
)

print(response.choices[0].message.content)
```

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4-gizmo-g-B3hgivKK9",
    "messages": [
      {"role": "user", "content": "你好，请介绍一下你自己"}
    ]
  }'
```

</CodeGroup>

<Warning>
  GPTsの呼び出しには上流チャネルのサポートが必要です。すべてのGPTsが利用できるわけではなく、チャネル設定によって異なります。
</Warning>

<Note>
  GPTs会話はストリーミング出力に対応しており、`stream: true`を設定するだけです。料金はGPT-4モデル価格に準じます。
</Note>
