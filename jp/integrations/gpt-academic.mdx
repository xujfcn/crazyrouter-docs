## 概要

GPT Academic（学術版 GPT）は、論文の校正、翻訳、コード解説などの場面に対応しています。Crazyrouter に接続する場合は、引き続き OpenAI の URL リダイレクト方式を利用することを推奨しますが、デフォルトモデルは現在運用環境で検証済みの最新利用可能モデルへ切り替える必要があります。

## 設定方法

### 設定ファイルを編集

`config.py` または `config_private.py` を編集してください：

```python
API_KEY = "sk-xxx"
API_URL_REDIRECT = {
    "https://api.openai.com/v1/chat/completions": "https://api.crazyrouter.com/v1/chat/completions"
}

# 或者直接设置
LLM_MODEL = "gpt-5.5"
AVAIL_LLM_MODELS = [
    "gpt-5.5",
    "claude-opus-4-8",
    "gemini-3.1-pro"
]
```

### 環境変数による方法

```bash
export API_KEY=sk-xxx
export API_URL_REDIRECT='{"https://api.openai.com/v1/chat/completions": "https://api.crazyrouter.com/v1/chat/completions"}'
export LLM_MODEL=gpt-5.5
```

### Docker によるデプロイ

```yaml
services:
  gpt-academic:
    image: ghcr.io/binary-husky/gpt_academic
    ports:
      - "22303:22303"
    environment:
      - API_KEY=sk-xxx
      - LLM_MODEL=gpt-5.5
      - API_URL_REDIRECT={"https://api.openai.com/v1/chat/completions": "https://api.crazyrouter.com/v1/chat/completions"}
```

## 推奨モデル

| シナリオ | モデル | 説明 |
|------|------|------|
| 最初の学術アシスタント検証 | `gpt-5.5` | 2026年3月23日に運用環境で実地テスト済み、OpenAI 互換ベースラインとして最適 |
| 高品質な長文要約 | `claude-opus-4-8` | 複雑な解説や長文リライト・要約により適しています |
| Gemini バックアップ枠 | `gemini-3.1-pro` | 2番目のサプライヤ互換性検証パス補完に適しています |

<Note>
  GPT Academic の URL リダイレクト機能により、OpenAI へのリクエストを Crazyrouter へ直接転送できます。まずは `gpt-5.5` だけを使って最低限のセッションをテストし、その後モデルリストや高度なプラグイン機能を段階的に追加していくのがおすすめです。
</Note>
