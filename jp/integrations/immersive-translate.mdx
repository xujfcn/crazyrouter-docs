没入型翻訳は、日常的なウェブページ翻訳、バイリンガル読書、選択翻訳、ドキュメント翻訳に非常に適したブラウザ拡張機能です。Crazyrouter を連携する場合、最も確実な方法は公式がサポートする `OpenAI` サービス設定を利用し、`その他の設定` でカスタム API アドレスを記入してください。

## 概要

没入型翻訳の OpenAI サービス設定を通じて、リクエストを Crazyrouter へ送信できます：

- 推奨プロトコル：`OpenAI-compatible API`
- サービスタイプ：`OpenAI`
- API Key：あなたの `sk-...`
- カスタム API アドレス：`https://api.crazyrouter.com/v1/chat/completions`
- 推奨初回検証モデル：`gpt-5.5`

<Tip>
没入型翻訳と ChatBox 最大の違いは、通常ここでは完全なエンドポイントパスを入力する必要があり、ルートドメインだけではいけません。
</Tip>

## なぜ完全なパス入力が必要？

没入型翻訳公式 OpenAI サービスドキュメントによると、`その他の設定` で OpenAI API アドレスのカスタマイズが可能です。そのため、Crazyrouter 側では通常完全なアドレスを書く方がより安全です：

```text
https://api.crazyrouter.com/v1/chat/completions
```

<Warning>
ここにルートドメイン `https://api.crazyrouter.com` や `/v1` のみを入力しないでください。没入型翻訳のような連携方法では、まずは完全な `/v1/chat/completions` パスを用いて検証してください。
</Warning>

## 対象ユーザー

- ウェブ上で高品質な AI 翻訳を行いたい方
- Crazyrouter の自身のトークンで翻訳コストを管理したい方
- 複数のブラウザやデバイスごとにクォータ管理をしたい方
- OpenAI 互換方式でブラウザ拡張翻訳を利用したい方

## システム要件と前提条件

| 項目 | 説明 |
|------|------|
| Crazyrouter アカウント | まず [crazyrouter.com](https://crazyrouter.com) で登録 |
| Crazyrouter トークン | 没入型翻訳用にトークンを新規で作成を推奨 |
| ブラウザ | Chrome、Edge、Firefox など、この拡張が対応するブラウザ |
| 没入型翻訳拡張 | 最新で安定しているバージョンを推奨 |
| 利用可能モデル | 最低1つの翻訳モデルを許可しておくこと |

初期ホワイトリストおすすめ：

- `gpt-5.5`
- `claude-opus-4-8`

## インストールと設定手順

### Chrome / Edge 手順

1. 拡張ストアから没入型翻訳をインストール
2. 拡張設定を開く
3. `翻訳サービス` に進む
4. `OpenAI` を選択
5. `その他の設定` を開く
6. Crazyrouter キーと完全なカスタムアドレスを入力

### Firefox 手順

1. Firefox アドオンから没入型翻訳をインストール
2. 設定ページを開く
3. `翻訳サービス` に進む
4. `OpenAI` を選択
5. `その他の設定` に進む
6. Crazyrouter のパラメータを入力

## ゼロからの完全設定

<Steps>
  <Step title="ステップ1：拡張機能のインストール">
    公式拡張ストアから「没入型翻訳」をインストール。
  </Step>

  <Step title="ステップ2：Crazyrouterで専用トークンを作成する">
    初回は以下のみ許可を推奨：

    - `gpt-5.5`
    - `claude-opus-4-8`

    いきなり大量のモデルを翻訳環境に追加しないでください。
  </Step>

  <Step title="ステップ3：OpenAIサービス設定を開く">
    拡張アイコンをクリックして下記に進む：

    - `設定`
    - `翻訳サービス`
    - `OpenAI` を選択
  </Step>

  <Step title="ステップ4：APIキーとカスタムアドレスを入力する">
    記入内容：

    - `API Key`：あなたの `sk-...`
    - `カスタムAPIエンドポイントアドレス`：`https://api.crazyrouter.com/v1/chat/completions`
    - `モデル`：まず `gpt-5.5` を入力

    もし一部のパラメータが画面で折りたたまれている場合は、`その他の設定` を展開して全フィールドを表示してください。
  </Step>

  <Step title="ステップ5：最初にリクエスト頻度を低く設定する">
    没入型翻訳公式ドキュメントは OpenAI 経由での頻度制限の注意を明記しています。Crazyrouter 連携初回は、リクエスト頻度を低めに設定することを推奨します。特に長文や電子書籍の場合。

    初回は次のように保守的に：

    - 1 秒あたりのリクエスト数を高くしすぎない
    - 小ページや選択テキストで先に検証
    - うまく行ったら徐々に引き上げ
  </Step>

  <Step title="ステップ6：初回の最小検証を完了する">
    推奨ステップ：

    1. まず短い選択テキストを翻訳
    2. 次に短いウェブページを翻訳
    3. 最後に全ページや長いドキュメントをテスト

    これなら、「API 設定ミス」か「リクエスト量が多すぎる不安定」かを一番簡単に切り分けられます。
  </Step>
</Steps>

## 推奨モデル設定

| 利用シーン | 推奨モデル | 理由 |
|----------|----------|------|
| 最小初回検証 | `gpt-5.5` | 2026年3月23日に本番環境で実証済み。OpenAI 互換翻訳パイプラインの動作確認に最適 |
| 高品質翻訳 | `claude-opus-4-8` | 長文解説、文章のブラッシュアップ、品質要件が高い場合に最適 |
| Gemini バックアップ | `gemini-3.1-pro` | 2本目の互換検証経路として適するが、まずは主経路を正常化してから試すことを推奨 |

## Token 設定ベストプラクティス

| 設定 | 推奨 | 説明 |
|------|------|------|
| 専用トークン | 必須 | ブラウザ翻訳拡張と IDE／CLI ツールのトークンは分離してください |
| モデルホワイトリスト | 強く推奨 | 最初は1～2モデルのみ許可で始めてください |
| クォータ上限 | 強く推奨 | 全ページ翻訳・電子書籍翻訳は通常の会話より消費が速いです |
| デバイス隔離 | 推奨 | ブラウザやデバイスごとにトークンを分けると便利 |
| 流出対策 | 即時ローテーション | 録画・スクショ・ブラウザ同期などで流出時はすぐ Key を変更 |

## よくあるエラーと修正

| 現象 | 主な原因 | 解決方法 |
|------|----------|----------|
| 404 | API アドレスが `/chat/completions` 欠落、またはルートドメインだけ記入 | 完全なアドレス `https://api.crazyrouter.com/v1/chat/completions` に修正 |
| 401 unauthorized | API Key の誤り・期限切れ・不完全コピー | Token を再発行し再入力 |
| 403 / モデル許可なし | トークンでモデル許可していない | Crazyrouter のトークン設定でモデルを許可 |
| 429 / 不安定 | リクエスト頻度過多 | 頻度を下げ、小テキストから検証開始 |
| 長文翻訳失敗多 | 同時/高頻度翻訳が原因 | まず範囲を小さくして、徐々に増加 |
| コスト上昇が早い | 全ページ・全サイト・電子書籍の一括翻訳 | まず `gpt-5.5` で小範囲検証・範囲制御 |

## 節約アドバイス

- デフォルトは `gpt-5.5` を利用
- まずは選択範囲のみ翻訳を推奨、いきなり全ページ翻訳は避ける
- 長文書は先にサンプル検証して、全訳が必要か判断
- 複数ブラウザで拡張利用ならトークン分離でコスト分析

## FAQ

### 没入型翻訳で API アドレスは何を入れる？

完全なパス：`https://api.crazyrouter.com/v1/chat/completions` を入力してください。

### なぜ ChatBox と違い、ルートドメインだけを推奨しない？

没入型翻訳公式の OpenAI カスタムアドレスエントリは、直接エンドポイントパスを入力する方がより安定して初回検証できます。

### 推奨最初のモデルは？

まず `gpt-5.5` を使用してください。

### なぜ初回から全ページや電子書籍翻訳を推奨しない？

設定ミス・頻度制限・コスト問題が一気に顕在化しやすくなるためです。まずは短文から翻訳し、トラブル原因の特定を優先しましょう。

<Note>
あなたのゴールが「Crazyrouter でウェブ AI 翻訳コストを管理すること」であれば、没入型翻訳は詳細説明を補足する価値の高いブラウザ拡張です。
</Note>
