LangChain は最も利用されている LLM アプリ開発フレームワークの一つで、チャットインターフェースのラッピング、プロンプトチェーン、ツール呼び出し、RAG、プロキシ型ワークフローやアプリケーションレベルのオーケストレーションに適しています。Crazyrouter を接続する場合、LangChain の公式がサポートする OpenAI 互換コンポーネントを使うのが最も確実です。

## 概要

LangChain の OpenAI コンポーネントを通じて、リクエストを Crazyrouter に送信できます：

- 推奨プロトコル：`OpenAI-compatible API`
- Base URL：`https://api.crazyrouter.com/v1`
- 認証変数：`OPENAI_API_KEY`
- Python メインパッケージ：`langchain-openai`
- JavaScript / TypeScript メインパッケージ：`@langchain/openai`

<Tip>
もし Crazyrouter を自身のアプリケーションコードに接続したい場合（デスクトップクライアントのみのチャットでなく）、LangChain は最も自然なエンジニアリング統合パスとなります。
</Tip>

## 想定されるユーザー

- Python や Node.js プロジェクトで Crazyrouter を本格導入したい開発者
- プロンプトチェーン、RAG、ツール呼び出し、ワークフローオーケストレーションを行いたい方
- モデル呼び出しロジックを統一的に抽象化したく、直接生の HTTP リクエストを書きたくない方
- 後でモデルや上流の切り替え柔軟性を残しておきたい方

## 利用プロトコル

推奨プロトコル：`OpenAI-compatible API`

Crazyrouter の対応する主要設定：

```text
OPENAI_API_KEY=sk-xxx
BASE_URL=https://api.crazyrouter.com/v1
```

LangChain 内での記述例は通常次の通り：

- Python：`api_key` + `base_url`
- JavaScript / TypeScript：`apiKey` + `configuration.baseURL`

## システム要件と前提条件

| 項目 | 説明 |
|------|------|
| Crazyrouter アカウント | [crazyrouter.com](https://crazyrouter.com) で事前登録 |

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

## Python サンプル

### 最小チャット例

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-5.5",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1",
    temperature=0.7,
)

response = llm.invoke("什么是 LangChain？")
print(response.content)
```

### Embeddings サンプル

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-large",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1",
)

vectors = embeddings.embed_documents(["文本一", "文本二"])
print(len(vectors), len(vectors[0]))
```

### Prompt チェーン例

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

llm = ChatOpenAI(
    model="gpt-5.5",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1",
)

prompt = ChatPromptTemplate.from_template("用简单的语言解释 {topic}")
chain = prompt | llm | StrOutputParser()

result = chain.invoke({"topic": "量子计算"})
print(result)
```

### RAG 最小サンプル

```python
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough

llm = ChatOpenAI(
    model="gpt-5.5",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1",
)

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-large",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1",
)

texts = [
    "Crazyrouter 支持多种 AI 模型协议",
    "Crazyrouter 支持 OpenAI 兼容调用方式",
]

vectorstore = FAISS.from_texts(texts, embeddings)
retriever = vectorstore.as_retriever()

prompt = ChatPromptTemplate.from_template(
    "根据以下上下文回答问题：\n{context}\n\n问题：{question}"
)

chain = {"context": retriever, "question": RunnablePassthrough()} | prompt | llm

result = chain.invoke("Crazyrouter 适合用什么协议接 LangChain？")
print(result.content)
```

## 推奨モデル設定

| 利用シーン | 推奨モデル | 理由 |
|----------|----------|------|
| 初回チェーン検証 | `gpt-5.5` | 2026年3月23日に本番環境で実動作済、LangChain と Crazyrouter の接続確認に最適 |
| 高品質長文・複雑チェーン | `claude-opus-4-8` | 複雑な説明、要約、重めの推論タスクに最適 |
| Gemini 代替 | `gemini-3.1-pro` | 互換性検証の2本目として活用可能 |
| ベクトル検索 | `text-embedding-3-large` | embedding のベースライン検証に最適 |

## トークン設定ベストプラクティス

| 設定 | 推奨 | 補足 |
|------|------|------|
| 専用トークン | 必須 | LangChain プロジェクトとデスクトップクライアントでトークン共用しないこと |
| モデルホワイトリスト | 強く推奨 | チャットモデル＋embedding モデルのみ許可推奨 |
| クォータ上限 | 強く推奨 | チェーン呼び出し、RAG、Agent は消費量アップ |
| 環境分離 | 推奨 | dev / staging / production でトークン分離推奨 |
| 漏洩対応 | 速やかにローテーション | key を Git に上げない・漏洩したら即交換 |

## よくあるエラーと修正方法

| 現象 | 主な原因 | 修正方法 |
|------|----------|----------|
| 401 unauthorized | `OPENAI_API_KEY` のミス・期限切れ・コピーミス | 新しいトークン発行＋再セット |
| 404 | `base_url` / `baseURL` ミスまたは `/v1` 抜け | `https://api.crazyrouter.com/v1` へ修正 |
| `model not found` | モデル名ミス or トークン未許可 | 確認済みモデル `gpt-5.5` 等に戻し、ホワイトリスト要確認 |
| embeddings エラー | embedding モデルに許可を忘れた | トークンに `text-embedding-3-large` を追加 |
| RAG 動かない | 初回からコンポーネントが多すぎ | 単純なチャットから段階的に増強を |
| 消費過多 | チェーン呼び出し・検索・多段 Agent の重複 | チェーンを単純化し、トークンクォータ個別に管理 |

## FAQ

### LangChain で Crazyrouter 接続時はどのプロトコルを利用すべき？

OpenAI 互換プロトコルを最優先で使用してください。

### Base URL には何を指定すべき？

`https://api.crazyrouter.com/v1` を指定してください。

### Python で利用すべきパッケージは？

優先して `langchain-openai` をご利用ください。

### JavaScript / TypeScript で利用すべきパッケージは？

優先して `@langchain/openai` をご利用ください。

### 初回から Agent や大規模 RAG を非推奨な理由は？

LangChain のチェーンが複雑になるとトラブルシュートの難易度が急増するためです。まずは最小構成でチャット動作確認し、徐々にコンポーネントを追加する方が確実です。

<Note>
Crazyrouter を本格的に自身のアプリケーションに導入する予定なら、LangChain ドキュメントは最優先で揃えておくべき開発フレームワークの一つです。
</Note>
