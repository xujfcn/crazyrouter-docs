> 内容更新日: 2026-06-09

LobeChat は、チームチャットの入り口、個人で複数モデルを扱う作業用デスク、自社運用用AIチャットフロントエンドに最適です。Crazyrouter との連携時には、LobeChat の `OpenAI` パスを使用し、プロキシアドレスを Crazyrouter の OpenAI 互換ベースURLに向けるのが最も安定します。

## 概要

LobeChat の OpenAI 設定項目から対話リクエストを Crazyrouter に転送できます：

- 推奨プロトコル：`OpenAI-compatible API`
- 推奨接続方法：LobeChat `OpenAI` provider
- Base URL：`https://api.crazyrouter.com/v1`
- 認証方法：`sk-...` token
- 推奨初回検証モデル：`gpt-5.5`

自社運用する場合は、環境変数経由で OpenAI のデフォルトパスを Crazyrouter にプリセットすることも可能です。

## 対象者

- 安定したチャットフロントエンドを自分で運用したい方
- Crazyrouter を個人またはチームのチャットワークベンチとして利用したい方
- 複数モデル一括管理＆会話履歴保持したい方
- 社内メンバーに固定モデルやデフォルト設定を展開したい方

## 利用プロトコル

推奨プロトコル：`OpenAI-compatible API`

LobeChat で Crazyrouter 連携時には OpenAI 互換ベースURLを使用します：

```text
https://api.crazyrouter.com/v1
```

以下のようにしてはいけません：

- `https://api.crazyrouter.com`
- `https://api.crazyrouter.com/v1/chat/completions`

<Note>
LobeChat ドキュメントの `OPENAI_PROXY_URL` の説明は「OpenAI API リクエストアドレス」で、標準のデフォルト例・サンプルも `/v1` 形式です。またローカル `http://127.0.0.1:4000/api/status` の公式サンプルリンクも `{address}/v1` になっています。したがって Crazyrouter 連携時はまず `https://api.crazyrouter.com/v1` を入力してください。独自のリバースプロキシが追加で `/v1` を付加している場合は個別で調整し、サフィックスの重複を避けましょう。
</Note>

## 前提条件

| 項目 | 説明 |
|------|------|
| Crazyrouter アカウント | まず [crazyrouter.com](https://crazyrouter.com) で登録 |
| Crazyrouter token | LobeChat 用に新規 `sk-...` token を作成推奨 |
| LobeChat | オンライン版・自社運用版どちらも可、安定最新版推奨 |
| 利用可能モデル | 当日動作確認済みの OpenAI 互換チャットモデルを最低1つ許可：例 `gpt-5.5` |

推奨初期ホワイトリスト：

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

<Tip>
Cursor・Codex・Claude Code も Crazyrouter に接続予定なら、LobeChat は別tokenで管理したほうがエンド側消費量を把握しやすくなります。
</Tip>

## 5分クイックスタート

<Steps>
  <Step title="LobeChat専用トークンを作成する">
    Crazyrouter 管理画面で `lobechat` という token を新規作成し、最初は `gpt-5.5`、`claude-opus-4-8` のような当日確認済みモデルだけ許可します。
  </Step>
  <Step title="言語モデル設定を開く">
    LobeChat に入り左下のアイコンもしくは設定から `設定` → `言語モデル` を開きます。
  </Step>
  <Step title="OpenAI パスを設定する">
    `OpenAI` 関連設定で以下を記入：
    - `API Key`: あなたの `sk-...`
    - `API プロキシ アドレス / API Proxy URL`: `https://api.crazyrouter.com/v1`

    また `カスタム API プロキシ アドレスを使用する` または同等の項目を ON にします。
  </Step>
  <Step title="ベースラインモデルを選択する">
    保存後、まず `gpt-5.5` をデフォルトモデルにし、初めから複数モデルは投入しないでください。
  </Step>
  <Step title="初回認証を行う">
    新規チャットを作成し「`Reply only OK`」を送信。正常応答があり、Crazyrouter 管理画面で該当ログ確認できれば接続成功です。
  </Step>
</Steps>

## 自社運用クイック設定

Docker 自社運用の場合は、OpenAI のデフォルト設定を環境変数に書き込めます：

```yaml
services:
  lobechat:
    image: lobehub/lobe-chat
    ports:
      - "3210:3210"
    environment:
      - OPENAI_API_KEY=sk-xxx
      - OPENAI_PROXY_URL=https://api.crazyrouter.com/v1
      - OPENAI_MODEL_LIST=gpt-5.5,claude-opus-4-8,gemini-3.1-pro
```

フロントエンドユーザーが自由に Key を変えられないようにしたい場合は、現在のバージョンの隠し／管理項目も活用し、デフォルトKeyをサーバー側の環境変数で固定しましょう。

## 推奨モデル設定

| 利用シーン | 推奨モデル | 理由 |
|----------|----------|------|
| デフォルトメインチャットモデル | `gpt-5.5` | 当日動作確認済み、LobeChat のメイン基準に適合 |
| 高品質 文章/コード | `claude-opus-4-8` | 長文・ライティングやコーディング支援に最適 |
| Gemini 予備確認 | `gemini-3.1-pro` | 2つ目の互換性検証ルートに最適 |

推奨手順：まず `gpt-5.5` で動作を確かめ、次に `claude-opus-4-8` と `gemini-3.1-pro` に拡張します。

## Token 設定ベストプラクティス

| 設定 | 推奨 | 説明 |
|------|------|------|
| 専用token | 必須 | LobeChat用tokenは IDE／CLI用と共用しないこと |
| モデルホワイトリスト | 強く推奨 | 利用端末から必要なモデルのみ解放 |
| IP 制限 | 固定出口で自社運用なら有効化推薦 | 公開網や頻繁に変動する家ネット環境では慎重に使う |
| クォータ上限 | 強く推奨 | チームチャット用フロントは1トークンを複数人で利用しやすい |
| 環境分離 | 推奨 | テスト/本番環境でtokenを分ける |
| デフォルトモデル管理 | 推奨 | まず高コストモデルをデフォルトから除外し、必要時に開放 |

## 検証チェックリスト

- [ ] `API Key` 正常保存済み
- [ ] `API プロキシ アドレス / API Proxy URL` を `https://api.crazyrouter.com/v1` に設定
- [ ] 独自プロキシアドレス項目を有効化済み
- [ ] 最初のモデルが正しく選択済み
- [ ] 1件目の対話リクエストが正常応答
- [ ] ストリーム出力が正常
- [ ] Crazyrouter 管理画面に該当リクエストが記録
- [ ] token のクォータおよびモデルホワイトリストが期待通り

## 主なエラーと修正

| 症状 | 主な原因 | 修正方法 |
|------|----------|----------|
| 保存不可または検証失敗 | API Keyミスまたはプロキシアドレスの記入誤り | `sk-...` や `https://api.crazyrouter.com/v1` を再確認 |
| 401 unauthorized | token 無効・期限切れ・誤消去 | tokenを再発行し差し替え |
| 403 / 該当モデル利用不可 | 現在モデルがtokenホワイトリスト未登録 | Crazyrouter 管理画面でモデル許可 |
| 404 | プロキシアドレスがルートドメイン、または具体エンドポイント記入 | `https://api.crazyrouter.com/v1` に修正 |
| 設定一見正しいが404 | 独自ゲートウェイや逆プロキシ、配備層で自動的に`/v1` を追加している | サフィックス重複が無いか確認、上流路で `/v1` 自動追加時は再度追加しない |
| モデル選択可だが実エラー | LobeChatフロントキャッシュが旧モデル or デフォルトモデル不在 | `gpt-5.5` に戻し、ページ更新後再選択 |
| 会話送信できるがストリーム異常 | クライアントバージョンやモデル互換性問題 | まず `gpt-5.5` で基本動作検証し、LobeChat更新 |
| 共同利用で消費が速い | 単一tokenを複数人共有かつクォータ設定なし | チームフロントで個別クォータ設定、必要ならtoken分割 |
| 自社運用でもユーザーが上流変更可 | デフォルト値設定のみでフロントのカスタム項目制限せず | 配備層で管理設定追加、カスタマイズ権限を制限 |

## パフォーマンス・コスト対策

- 初期段階では `gpt-5.5` のみ許可
- チーム用途のデフォルトモデルは低コスト優先、高コストモデルは上級者や特定目的時のみ解放
- 知識ベースやプラグイン、長い文脈での会話機能を使う場合、LobeChat 側でクォータを明示的に設定
- 自社運用時は本番用tokenとテスト用tokenを分け、社内検証が本番予算に影響しないよう配慮
- 異常な高コスト時は、Crazyrouterログで多人数長会話が発生していないか確認

## FAQ

### LobeChat の Base URL には何を記入すべきですか？

`https://api.crazyrouter.com/v1` を入力してください。

### ここでルートドメインだけを入力してはいけない理由は？

LobeChat の OpenAI プロキシ設定は、OpenAI 互換ベースURLを直接記載した方が適しているため、ルートドメインでは不十分です。

### 独自のリバースプロキシで自動的に `/v1` を加えている場合は？

LobeChat の最終アドレスには`/v1`を重ねて書かないでください。代理チェーン全体でサフィックス重複が無いか事前に確認しましょう。

### 最初に推奨されるモデルは？

まず `gpt-5.5` を利用します。

### LobeChatは複数モデルを同時利用できますか？

はい、ただし最初は1モデルで検証し徐々に拡張推奨です。

### 運用時、tokenは環境変数に固定すべきですか？

上流/コストを集中管理したい場合は推奨します。各利用者ごとにKeyを持ちたいときはフロントカスタムを解放しましょう。

<Note>
安定したチャットフロントやチーム共用作業台を求めるならLobeChatが最適です。コード用プロキシや自動実行ユースには Cursor・Claude Code・Codex・Cline 等の優先検討が無難です。
</Note>
