Cursor は Crazyrouter を普段のコーディングワークフローへ組み込むのに最適です。チャット、コード解釈、リファクタ提案、通常の編集補助として利用できます。

## 概要

Cursor の BYOK（Bring Your Own Key）機能を利用することで、一部のチャットモデルリクエストを Crazyrouter にルーティングし、自分の token で料金を支払うことができます。

- 推奨接続方法：OpenAI 互換モード
- Crazyrouter Base URL：`https://api.crazyrouter.com/v1`
- 認証方式：`sk-...` token
- 最初に連携推奨する機能：Chat、Ask、一般的な編集用対話

<Warning>
Cursor 公式ドキュメントによれば、`Custom API keys only work with standard chat models` のような Tab Completion など専用モデルを使う機能は、引き続き Cursor 内蔵モデルを使用します。これは Crazyrouter 由来の制限ではなく、Cursor 側の仕様です。
</Warning>

## 対象ユーザー

- Cursor 上で Crazyrouter token を統合的に使いたい開発者
- モデル選択・コスト・利用枠を管理したい人
- Cursor のチャット機能を Crazyrouter に繋げたいチーム
- 複数 IDE や CLI で利用料金・枠を分けたい方

## 利用プロトコル

推奨プロトコル：`OpenAI-compatible API`

Cursor で Crazyrouter を連携する場合、OpenAI 互換のベース URL を利用します：

```text
https://api.crazyrouter.com/v1
```

下記のようには入力しないでください：

- `https://api.crazyrouter.com`
- `https://api.crazyrouter.com/v1/chat/completions`

## 前提条件

| 項目 | 説明 |
|------|------|
| Crazyrouter アカウント | [crazyrouter.com](https://crazyrouter.com) で事前登録 |
| Crazyrouter token | Cursor 用に専用 `sk-...` token を作成推奨 |
| Cursor デスクトップ版 | 最新安定版にアップデートしてから設定推奨 |
| 利用可能モデル | 少なくとも token で OpenAI 互換チャットモデル 1～2 個が利用可能な状態 |

以下いずれかのモデルを最初に許可することを推奨：

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

<Tip>
今後 Claude Code・Codex・Cline も設定する場合、Cursor とは別の token を使ってください。token を分離すると、トラブルシュートやコスト管理が簡単です。
</Tip>

## 5分間クイックスタート

<Steps>
  <Step title="Cursor 専用トークンを作成する">
    Crazyrouter 管理画面で新しい token を作成します。名前は `cursor` がおすすめ。少数モデルの whitelist を最初にオン、例えば `gpt-5.5` と `claude-opus-4-8`。
  </Step>
  <Step title="Cursor 設定を開く">
    Cursor を開いて `Cursor Settings` → `Models` に進みます。
  </Step>
  <Step title="OpenAI 接続情報を入力する">
    OpenAI 関連設定に以下を入力：
    - `OpenAI API Key`: あなたの `sk-...`
    - `Override OpenAI Base URL`: `https://api.crazyrouter.com/v1`

    Cursor のバージョンで `Override OpenAI Base URL` が見当たらない場合は、OpenAI 互換エンドポイントのカスタム対応が未完成です。Cursor をアップデートするか、対応完了をお待ちください。
  </Step>
  <Step title="キーを検証し、モデルを選択する">
    `Verify` をクリックします。認証できたら、まず 1 つのモデルで検証しましょう。`gpt-5.5` を推奨。
  </Step>
  <Step title="初回テストを完了する">
    Cursor のチャットパネルを開き、テストリクエスト（例：`Reply with only OK`）を送信してください。正常にレスポンスが返れば Crazyrouter との連携成功です。
  </Step>
</Steps>

## 推奨モデル設定

| 利用シーン | 推奨モデル | 理由 |
|----------|----------|------|
| デフォルト主軸 | `gpt-5.5` | 2026年3月23日実運用実績あり。Cursor の OpenAI 互換ベースラインとして最適です |
| 高品質コード・長文 | `claude-opus-4-8` | 複雑な解説・要約・コード補助向け |
| Gemini 予備 | `gemini-3.1-pro` | 2 番目の互換性検証パスとして有用 |

推奨は、まず `gpt-5.5` で動作を確認後、順に `claude-opus-4-8`・`gemini-3.1-pro` を追加調整。

## Token 設定のベストプラクティス

| 項目 | 推奨 | 説明 |
|------|------|------|
| 専用 token | 必須 | Cursor 用に専用 token；他のツールと混在させない |
| モデル whitelist | 推奨オン | Cursor で用いるモデルだけ許可 |
| IP 制限 | ケースバイケース | 個人PC（可変IP）は推奨せず。固定社内LANならオン検討可 |
| 枠上限 | 強く推奨 | Cursor 用に予算枠を別設置。全体利用量過剰を防止 |
| 開発/本番分離 | 推奨 | 個人PC・チーム端末・CI で異なる token を割当 |
| ローテ頻度 | 定期推奨 | スクショ・録画・同期設定で token 流出懸念時は速やかに再発行 |

## よくあるエラーと対処法

| 症状 | 原因 | 解決策 |
|------|----------|----------|
| `Verify` 失敗 | API Key 誤り、もしくは Base URL 入力ミス | `sk-...`・`https://api.crazyrouter.com/v1` を再確認 |
| 401 unauthorized | token 無効/期限切れ/コピペ時に空白混入 | 再発行し、クリーンな値をペースト |
| 403 / model not allowed | モデルが token whitelist に無い | Crazyrouter token 設定で対象モデル許可 |
| 404 | Base URL にドメインや API パスを直接記入 | `https://api.crazyrouter.com/v1` へ統一修正 |
| モデル一覧や表示異常 | Cursor BYOK 更新失敗・バージョン非対応 | Cursor を再起動し Verify、新版アップデートも検討 |
| チャットは動くが Tab 補完が Crazyrouter 経由しない | Cursor 公式仕様：専用能力は内蔵モデル経由 | 期待動作であり Crazyrouter 不調ではありません |
| カスタムモデル利用できず | Cursor の OpenAI 互換カスタム対応が不安定 | まず `gpt-5.5` で動作確認。次に他モデルで検証 |
| コスト上昇 | 複数利用機能で token 共有/whitelist 範囲過大 | モデル範囲を絞り Cursor 用に別枠予算設定 |

## 性能・コスト最適化アドバイス

- 初期段階は `gpt-5.5` のみ許可
- 複雑なコード解説・要約・リファクタは `gpt-5.5` を優先利用
- 複数ベンダー検証には `claude-opus-4-8`・`gemini-3.1-pro` を追加
- Claude Code / Codex も併用時は token を分割しコスト管理
- 高負荷時は Crazyrouter ログから Cursor の複数ラウンドコンテキストを確認

## FAQ

### Cursor ではどの Base URL を入力する？

`https://api.crazyrouter.com/v1` を入力してください。

### Key を入力しても一部機能が Crazyrouter に流れないのはなぜ？

Cursor 公式案内により、API key 指定は標準チャットモデルのみ反映されます。Tab Completion など専用機能は Cursor 内蔵モデルを引き続き使います。

### 最初にどのモデルを推奨？

まず `gpt-5.5` を推奨。現在動作検証済みの最新 OpenAI 互換ベースラインです。

### Claude など他モデルは直接使える？

利用自体は可能ですが、はじめに OpenAI 互換ルートの基本動作を必ずご確認ください。カスタムモデルの Cursor 対応状況はバージョン依存です。

### チャットは正常だがモデル選択が乱れる場合？

Cursor を再起動し、再度 Verify。問題が解消しない場合はまず `gpt-5.5` などの検証済みモデルに戻して様子見。

<Note>
安定したコーディング用途で Crazyrouter をメイン利用する場合、Claude Code、Codex、Cline の各公式接続方法が Cursor のカスタムエンドポイントよりもコントロールしやすいケースが多いです。Cursor にはまずチャットや通常編集補助から導入をおすすめします。
</Note>
