## 概要

ChatGPT on WeChat は一般的な微信（WeChat）ロボットプロジェクトであり、Crazyrouter のモデル機能を個人チャットやグループチャットに接続できます。接続時には、デフォルトの OpenAI 互換設定方式を継続使用し、まずは実地で検証済みのモデルで最小限の応答ルートを通すことを推奨します。

## 推奨ファーストラウンド設定

- `open_ai_api_base`: `https://api.crazyrouter.com/v1`
- 最初の検証モデル：`gpt-5.5`
- 初回はモデル数を絞り、トラブルシューティングの範囲を限定する

## 設定方法

### 設定ファイルの編集

`config.json` を編集してください：

```json
{
  "open_ai_api_key": "sk-xxx",
  "open_ai_api_base": "https://api.crazyrouter.com/v1",
  "model": "gpt-5.5",
  "proxy": "",
  "single_chat_prefix": [""],
  "single_chat_reply_prefix": "",
  "group_chat_prefix": ["@bot"],
  "group_name_white_list": ["AI交流群"]
}
```

### 環境変数による設定

```bash
export OPEN_AI_API_KEY=sk-xxx
export OPEN_AI_API_BASE=https://api.crazyrouter.com/v1
export MODEL=gpt-5.5
```

### Docker 配備

```yaml
services:
  chatgpt-on-wechat:
    image: zhayujie/chatgpt-on-wechat
    environment:
      - OPEN_AI_API_KEY=sk-xxx
      - OPEN_AI_API_BASE=https://api.crazyrouter.com/v1
      - MODEL=gpt-5.5
    volumes:
      - ./config.json:/app/config.json
```

## 推奨モデル

| シーン        | モデル             | 説明                                                                                   |
|---------------|--------------------|----------------------------------------------------------------------------------------|
| 初回ルート検証| `gpt-5.5`    | 2026 年 3 月 23 日に実稼働環境で検証済みで、OpenAI 互換ルートの初期確認に最適です        |
| 高品質長文応答| `claude-opus-4-8`    | 複雑な解説・要約・長文テキストにより適しています                                    |
| Gemini 予備枠 | `gemini-3.1-pro`    | 2番目のサプライヤー互換性検証ルートの補完に適しています                             |

## 推奨検証手順

1. まずは1つの token のみ設定
2. 1つのモデル `gpt-5.5` のみ設定
3. 個人チャットで `Reply only OK` を送信
4. Crazyrouter 管理画面のログに該当リクエストが記録されたことを確認
5. その後グループチャット、さらに多くのプレフィクスルールや他モデルを段階的に開放

<Warning>
  微信（WeChat）ロボットプロジェクトは微信の利用規則を遵守し、頻繁なメッセージ送信によるアカウント制限を避けてください。
</Warning>
