## 概要

Gemini CLIはGoogleのコマンドラインAIアシスタントです。CrazyrouterのGeminiネイティブエントリを設定することで、コマンドラインから直接、当サイトの本番環境で実際のリクエスト検証が完了したGeminiモデルを利用できます。

## 設定方法

### 環境変数

Gemini CLIの現在バージョンはAPI Key方式において、最低限明示的に`GEMINI_API_KEY`を提供する必要があります。CrazyrouterのGeminiネイティブエントリを利用する場合は、この3つの環境変数を同時に設定することを推奨します：

```bash
export GEMINI_API_KEY=sk-xxx
export GEMINI_MODEL=gemini-3.1-pro
export GOOGLE_GEMINI_BASE_URL=https://api.crazyrouter.com
```

Windows PowerShell:

```powershell
$env:GEMINI_API_KEY="sk-xxx"
$env:GEMINI_MODEL="gemini-3.1-pro"
$env:GOOGLE_GEMINI_BASE_URL="https://api.crazyrouter.com"
```

開くたびに自動的に有効にしたい場合、`~/.gemini/.env`やPowerShellプロファイルに記述できます。

### 設定ファイル

`~/.gemini/settings.json`を編集します：

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  },
  "apiKey": "sk-xxx",
  "baseUrl": "https://api.crazyrouter.com",
  "model": {
    "name": "gemini-3.1-pro"
  }
}
```

注意：

- 認証方式を`oauth-personal`のままにしないでください。そうするとCLIはGoogleログインを継続します。
- `model`を文字列として記述しないでください。現在バージョンでは`model.name`を使用してください。
- `settings.json`だけでは一部の場面で不十分です。コマンドライン方式では`GEMINI_API_KEY`環境変数が引き続き必要な場合があります。

### `.gemini/.env`の例

`~/.gemini/.env`に直接記述することもできます：

```bash
GEMINI_API_KEY=sk-xxx
GEMINI_MODEL=gemini-3.1-pro
GOOGLE_GEMINI_BASE_URL=https://api.crazyrouter.com
```

### 起動

```bash
gemini
```

## 推奨モデル

| モデル | 説明 |
|------|------|
| `gemini-3.1-pro` | 2026年4月8日にCrazyrouter本番環境でGemini CLIによる実際のリクエストで検証済み、現時点の主基準として最適 |

<Note>
  CrazyrouterはGeminiネイティブAPI形式とOpenAI互換形式を両方サポートしています。Gemini CLIはGeminiネイティブ形式を使用します。本ドキュメントに記載されている`gemini-3.1-pro`、`gemini-api-key`の認証方法と、`GOOGLE_GEMINI_BASE_URL=https://api.crazyrouter.com`は実際のCLIリクエストによる検証が完了しています。
</Note>
