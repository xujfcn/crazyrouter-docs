> 内容更新日: 2026-06-09

Zotero 自体は文献管理ツールであり、Crazyrouter の設定画面は直接組み込まれていません。実際の接続方法は、まず AI 呼び出し機能を持つ Zotero プラグインを導入し、そのプラグイン内に Crazyrouter の OpenAI 互換エンドポイント、API Key、モデル名を入力する流れとなります。

このページで最も重要な原則は「適当な Zotero AI プラグインなら何でも接続できる」ではなく、まずプラグインの種類を分けることです：

- 直接接続可能：プラグインが `Base API URL` / `API URL` / `Endpoint` のカスタム設定に対応している
- 直接接続不可または公開手順に不向き：公式 OpenAI Key 入力のみで、上流アドレスをカスタムできない

## まず結論から

Crazyrouter を Zotero で推奨する一般的な接続方法は：

- OpenAI 互換アドレスのカスタマイズに対応した Zotero AI プラグインを選ぶ
- ベースアドレスを `https://api.crazyrouter.com/v1` に設定
- API Key を `sk-xxx` に設定
- 検証モデルはまず `gpt-5.5` を利用

<Warning>
すべての Zotero AI プラグインがカスタム上流アドレスに対応しているわけではありません。もし「OpenAI API Key 入力のみ」で、`Base URL` や `API URL` の設定欄がないプラグインだと、大抵そのままでは Crazyrouter にリダイレクトできません。こうしたプラグインは一般向け手順とすべきではありません。
</Warning>

## なぜこの手順なのか

現時点で Zotero の AI プラグインは多様性が大きいため：

- Zotero 公式ドキュメントによれば、プラグインはコミュニティ主導で、導入方法は共通ですが、機能は統一されていません
- カスタム `base API URL` に対応していると明記しているものもあります
- 逆に公開ドキュメントには `OpenAI API Key` 設定のみ記載されたものもあります

このため Crazyrouter の公式説明文は「OpenAI 互換カスタムアドレス可」なプラグインを優先案内し、「全部のプラグインがすぐ接続できる」前提にしないことが肝心です。

## 対象ユーザー

- Zotero で論文要約、翻訳、QA をしたい人
- 文献管理と Crazyrouter モデル利用を一つのワークフローにまとめたい人
- 文献、PDF 読解やノート整理に AI 機能を導入したい人
- スクリプトは書かず Zotero の GUI だけで構成したい人

## 前提条件

| 項目 | 説明 |
|------|------|
| Crazyrouter アカウント | まず [crazyrouter.com](https://crazyrouter.com) で登録 |
| Crazyrouter token | Zotero 専用の token 発行を推奨 |
| Zotero デスクトップ | プラグインは主にデスクトップ用 |
| AI プラグイン | OpenAI 互換アドレスをカスタム可能なものが必要 |
| 文献・PDF | テスト用に最低一つのエントリを用意 |

最初は以下のみ許可推奨：

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

## Zotero のインストール

1. [Zotero 公式ダウンロードページ](https://www.zotero.org/download/)を開く
2. Windows 用インストーラをダウンロード
3. インストーラを実行
4. Zotero を起動

2. macOS パッケージをダウンロード
3. Zotero を `Applications` へドラッグ＆ドロップ

### Linux

1. [Zotero 公式ダウンロードページ](https://www.zotero.org/download/)を開く
2. 公式 Linux パッケージをダウンロード

4. Zotero が正常に開くか確認

<Note>
Zotero 公式ドキュメントによれば、プラグインは主にデスクトップ版に導入します。AI 系プラグインはモバイル初回設定にはあまり向きません。
</Note>

## Zotero AI プラグインの選び方

以下を満たすプラグインが公開ドキュメント上で特に推奨されます：

- `Base API URL`、`API URL`、`Endpoint` いずれか入力欄がある
- `API Key` の入力対応
- モデル名の手動入力ができる
- Zotero の設定画面からパラメータ変更が可能だとなお良い

### 公開ドキュメントでのおすすめ判断基準

下記機能の記載が明確なプラグインは Crazyrouter 接続により適しています：

- `Customize base API URL`
- `API URL`
- `Custom endpoint`
- `Model preferences`

例として、`zotero-chatgpt` の公開 README は `base API URL` カスタマイズに対応と明記。一方 `Aria` の公開 README には `OpenAI API Key`、モデルプリファレンス入力記述がメインで、「上流カスタム」は主軸で扱われていません。このため Crazyrouter のナレッジでは「OpenAI 互換アドレスのカスタマイズ対応プラグインを選ぶ」が推奨主線となります。

## 推奨設定形式

プラグインごとに項目名称は異なりますが初期設定は下記方針が手堅いです：

| プラグイン項目 | 推奨値 |
|----------|--------|
| Base API URL / API URL | `https://api.crazyrouter.com/v1` |
| Full Endpoint | `https://api.crazyrouter.com/v1/chat/completions` |
| API Key | `sk-xxx` |
| Model | `gpt-5.5` |

<Tip>
「基礎アドレス」入力なら `https://api.crazyrouter.com/v1` を優先入力。プラグイン側が「フルエンドポイント」明示の場合のみ `https://api.crazyrouter.com/v1/chat/completions` を使ってください。
</Tip>

## 設定手順

<Steps>
  <Step title="ステップ1：Zotero専用Crazyrouterトークンを作成する">
    初回は以下のみ許可：

    - `gpt-5.5`
    - `claude-opus-4-8`

    モデルを一気に大量開放せず、まずは件数を絞りデバッグしやすく。
  </Step>

  <Step title="ステップ2：Zoteroデスクトップ版をインストールする">
    OS に応じて Zotero をセットアップ。論文エントリが取り込めるか確認。
  </Step>

  <Step title="ステップ3：AIプラグインをダウンロードしてインストールする">
    Zotero 公式プラグイン導入ガイドに基づき、まずプラグインの `.xpi` ファイルを入手し Zotero で：

    - `Tools` を開く
    - `Plugins` に移動
    - `.xpi` ファイルをプラグインウィンドウへドラッグ

    完了したら Zotero を再起動。
  </Step>

  <Step title="ステップ4：プラグイン設定画面に入る">
    典型的な設定箇所：

    - `Edit` → `Preferences`
    - プラグインの設定画面
    - サイドバーやツールバーのエントリ

    プラグインごとに場所は違いますが、API とモデル設定欄を探すのがコツです。
  </Step>

  <Step title="ステップ5：Crazyrouterのアドレス、キー、およびモデルを入力する">
    基礎アドレス型の場合は以下推奨：

    - `Base API URL`: `https://api.crazyrouter.com/v1`
    - `API Key`: `sk-xxx`
    - `Model`: `gpt-5.5`

    フルエンドポイント指定型は以下：

    - `Endpoint`: `https://api.crazyrouter.com/v1/chat/completions`
  </Step>

  <Step title="ステップ6：プラグインの指示に従い、Zoteroを再起動する">
    一部プラグインは API Key やモデル、設定変更後に Zotero 再起動が必要です。初回設定後は一度再起動推奨。
  </Step>

  <Step title="ステップ7：最も基本的な学術シナリオで初回検証を行う">
    いきなり複雑な依頼はせず、まず：

    - 要約付き文献を選択
    - あるいは軽い PDF 開く
    - 要約／翻訳／簡単 QA を一度実行

    テスト用プロンプト例：

    ```text
    Summarize this paper in 3 bullet points.
    ```
  </Step>
</Steps>

## 推奨検証プロセス

下記順で進めてください：

1. Zotero 本体およびプラグインの起動確認
2. `gpt-5.5` の接続確認
3. 単独文献の要約
4. 翻訳実行
5. 複数文献比較や長文解析・バッチ実行

## 推奨モデル

| シーン | モデル | 理由 |
|------|----------|------|
| チェーン初回検証 | `gpt-5.5` | 2026年3月23日、商用稼働成功済み、Crazyrouter への疎通確認に最適 |
| 詳細分析や解説 | `claude-opus-4-8` | 複雑な要約、手法比較、長文解説に適合 |
| Gemini 予備 | `gemini-3.1-pro` | 二次的な互換性検証経路に |

## Zotero で想定する利用形態

### 単一論文の要約

初期検証に最適。文脈がシンプルで結果判断しやすい。

### PDF 翻訳

まずは1ページまたは短い範囲でテスト推奨、徐々に拡大。

### 複数文献比較

初回に実施は避けてください。単一要約・翻訳の安定確認後、比較・要旨・研究ギャップ抽出など複雑処理へ進めます。

### ノート整理

結果を Zotero ノートに書き戻せるプラグインなら、まず短い要約から試し、最初から大量ノート自動生成は避けてください。

## Token 運用のベストプラクティス

| 設定 | 推奨 | 説明 |
|------|------|------|
| 専用 token | 必須 | IDE や自動化プロセスと使い回さない |
| モデル許可リスト | 強く推奨 | まず 1～2 モデルのみ許可 |
| クオータ制限 | 強く推奨 | 長文 PDF や多段要約は消費増大につながる |
| 用途別 token | 推奨 | 個人利用とチーム共有は分離 |
| 漏洩時対応 | すぐローテーション | デモ・画面共有・設定露出後は即時入れ替え |

## よくあるエラーと対処法

| 現象 | 主な原因 | 修復方法 |
|------|----------|----------|
| プラグインに OpenAI Key 入力欄しかない | 上流カスタム非対応 | `Base API URL` または `Endpoint` カスタム可能なプラグインに差替え |
| 401 unauthorized | token ミス・コピペ不完全・期限切れなど | token 再生成し再設定 |
| 404 | ベースまたはフルアドレスの入力ミス | ベースは `https://api.crazyrouter.com/v1`／フルは `https://api.crazyrouter.com/v1/chat/completions` へ戻す |
| 403 / model not allowed | token で該当モデル非許可 | Crazyrouter token 設定で該当モデル許可 |
| `model not found` | モデル名のタイプミス | 最小要件確認は `gpt-5.5` で実施 |
| プラグイン無反応／設定反映されない | プラグイン側で Zotero 再起動必要 | 再起動後リトライ |
| 要約失敗だがエラー応答なし | 選択文献に要約無し・PDF未添付・プラグインが文脈取得できない | 要約or PDF付きで再確認 |
| 長文処理が遅い | PDF 多頁・依頼内容が重すぎる | 最初は1段落、1頁、1ファイル要約に縮小 |

## FAQ

### Zotero 自体から Crazyrouter 設定できる？

通常は Zotero 本体間接でなく、OpenAI 互換インターフェース対応 AI プラグイン経由になります。

### どのプラグインが Crazyrouter 向き？

`Base API URL`、`API URL`、`Endpoint` のカスタム可能なものを最優先で選んでください。

### OpenAI API Key のみしか入力できないプラグインは？

このタイプは Crazyrouter 上流変更に未対応。公開の標準手順としない方針です。カスタムアドレス入力可能なプラグインに切替推奨。

### ベースアドレスは何を入れれば？

`https://api.crazyrouter.com/v1` を推奨します。

### 一つ目のモデルは？

`gpt-5.5` から入力。

### 複数分析や総合要約はいつから？

最初に単一要約や単一翻訳安定確認後、段階的に複雑化。

<Note>
目標が「とりあえず Zotero で Crazyrouter を通す」場合、必要なのは強力なプラグインを追い求めるより、「本当にカスタム OpenAI 互換アドレスに対応するプラグインか」と、`gpt-5.5` で単独要約が動くかの確認です。
</Note>
