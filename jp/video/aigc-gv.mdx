# AIGC GV VOD の呼び出し方法

`aigc-video-gv-*` は、Crazyrouter が Tencent VOD 回線を通じて接続する GV / Google Veo ビデオモデルです。呼び出し方法は AIGC Kling VOD と同じで、OpenAI スタイルのビデオ非同期 API を使用します：

```http
POST /v1/video/generations
GET /v1/video/generations/{task_id}
```

<Note>
  `aigc-video-gv-*` は `/v1/video/generations` と一致するクエリルートのみを使用します。これらのモデルを `/v1/video/create` に送信しないでください。ルートが一致しない場合は `model_not_found` または同様の上流エラーが発生します。
</Note>

## 利用可能なモデル

| モデル | 上流バージョン | 説明 |
|------|------|------|
| `aigc-video-gv-3.1` | GV 3.1 | 高品質バージョン、音声付き動画対応 |
| `aigc-video-gv-3.1-fast` | GV 3.1 Fast | より高速なバージョン、音声付き動画対応 |
| `aigc-video-gv-3.1-lite` | GV 3.1 Lite | 軽量バージョン、音声付き動画対応 |

<Note>
  Tencent VOD の GV 3.1 は Google Veo 回線となっており、Kling ではありません。`aigc-video-kling-3.1` などのモデル名は使用しないでください。
</Note>

## タスクの作成

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-gv-3.1-fast",
    "prompt": "a cinematic product shot with natural camera movement",
    "seconds": "5",
    "metadata": {
      "resolution": "1080P",
      "sound": true
    }
  }'
```

## 画像生成および複数画像参照

1枚画像の場合は `image` を使用可能です。複数画像参照には `metadata.image_list` の利用を推奨します：

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-gv-3.1",
    "prompt": "combine the visual style of the references into one smooth shot",
    "seconds": "5",
    "metadata": {
      "resolution": "1080P",
      "image_list": [
        {
          "url": "https://example.com/ref-1.png",
          "reference_type": "asset"
        },
        {
          "url": "https://example.com/ref-2.png",
          "reference_type": "style"
        }
      ]
    }
  }'
```

<Warning>
  GV の複数画像入力は必ず `FileInfos` で渡す必要があります。当サイトでは `image_list` を `FileInfos` に変換し、また GV 複数画像リクエストに `LastFrameUrl` は使用しません。
</Warning>

## よく使う metadata フィールド

| フィールド | 説明 |
|------|------|
| `resolution` | `720P`、`1080P`、`2K`、`4K`。利用可能な仕様は Pricing ページでご確認ください |
| `sound` | 音声の生成有無を設定。`true` / `false`、`on` / `off` に対応 |
| `audio_generation` | `Enabled` / `Disabled` を直接指定 |
| `image_list` | 複数画像参照配列 |
| `reference_type` / `ReferenceType` | GV 参照タイプ。主に `asset` または `style` を利用 |

価格、割引、利用可能な仕様は [Pricing ページ](https://crazyrouter.com/ja/pricing) をご参照ください。
