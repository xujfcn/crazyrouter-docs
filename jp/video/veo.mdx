# Veo 3.1

現在、Crazyrouterが顧客向けに公開している Veo 3.1 モデルは以下の通りです：

- `veo-3.1-fast`
- `veo-3.1-quality`

これらの名称は顧客向けのパブリックエイリアスです。内部のカノニカルプロバイダー名称は、直接顧客に公開されません。

<Note>
  `veo-3.1` は顧客が直接提出できる `model` 値ではありません。顧客のリクエストでは常に `veo-3.1-fast` または `veo-3.1-quality` をご利用ください。
</Note>

## 統一動画 API での呼び出し

```
POST /v1/video/create
```

このページでは、すでに顧客向けに提供されている機能のみを扱っています：

- テキストから動画生成
- 画像から動画生成

Google公式ドキュメントに記載されている `referenceImages`、style reference、及びさらに詳細なプロバイダー固有モードは、現時点の公開契約には含まれていません。

### 現在利用可能なモデル

| モデル | 説明 |
|------|------|
| `veo-3.1-fast` | より低遅延、最初の利用可能な結果を素早く取得したい場合に適しています |
| `veo-3.1-quality` | より高品質重視、デフォルトの主要表示に適しています |

### 機能状況

| 機能 / 仕様 | 状態 | 説明 |
|------|------|------|
| テキスト動画生成 `720P / 1080P` | `Verified` | 現在公開契約で対応済み |
| 画像から動画生成 `720P / 1080P` | `Verified` | 現在公開契約で対応済み |
| 音声対応行 | `Beta` | 公式機能は存在するが、現在公開アーティファクトはまだ追加予定 |
| `start_end` | `Beta` | 現在公開ページでは未保証 |
| `referenceImages` / reference assets | `Beta` | 現在公開ページでは未保証 |
| `4K` | `Beta` | 現在公開ページでは未保証 |

<Note>
  プライシングページとこのドキュメントは同一のステータス基準を使用しています：`Verified` は現時点で最小のライブ閉ループがあることを示し、`Beta` は公式機能は存在するが現在公開検証または制約が追加されていることを示しています。
</Note>

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | `veo-3.1-fast` または `veo-3.1-quality` |
| `prompt` | string | はい | 動画説明プロンプト |
| `aspect_ratio` | string | いいえ | 現在公開の推奨値は `16:9` または `9:16` |
| `size` | string | いいえ | 現在公開の推奨値は `720P` または `1080P` |
| `images` | array | いいえ | 画像から動画生成時は `1` 枚の画像URLを指定します |
| `duration` | integer | いいえ | 一般的な値は `8` |

### リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-quality",
    "prompt": "A cinematic shot of a spaceship landing on Mars, dust clouds rising, golden hour lighting",
    "aspect_ratio": "16:9"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/video/create",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "veo-3.1-quality",
        "prompt": "A cinematic shot of a spaceship landing on Mars",
        "aspect_ratio": "16:9"
    }
)

task_id = response.json()["task_id"]
print(f"任务 ID: {task_id}")
```

</CodeGroup>

## 画像から動画生成例

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-fast",
    "prompt": "The person in the image slowly turns their head and smiles",
    "images": ["https://example.com/portrait.jpg"],
    "aspect_ratio": "9:16",
    "size": "720P"
  }'
```

## タスクの照会

```
GET /v1/video/query?id={task_id}
```

```bash cURL
curl "https://api.crazyrouter.com/v1/video/query?id=veo_task_abc123" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### レスポンス例（完了済み）

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "veo_task_abc123",
    "status": "SUCCESS",
    "url": "https://media.crazyrouter.com/task-artifacts/example.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/example.mp4"
  }
}
```

<Note>
  Google公式ドキュメントでは Veo 3.1 の `reference asset images`、及びより詳細なプロバイダー固有の機能境界について説明されています。現時点でCrazyrouterの公開ページでは `veo-3.1-fast` / `veo-3.1-quality` 下のテキスト動画生成および画像から動画生成のみ対応保証しています。今後さらにVeoの第一級機能を公開する場合、別途ドキュメント及び検証記録を追加します。
</Note>
