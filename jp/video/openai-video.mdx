# OpenAI ビデオフォーマット

Crazyrouter は OpenAI 公式のビデオ API フォーマットをサポートしており、OpenAI SDK と互換性があります。

## ビデオの作成

```
POST /v1/videos
```

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | モデル名。例: `veo-3.1-fast`、`veo-3.1-quality` |
| `prompt` | string | はい | ビデオ説明プロンプト |
| `size` | string | いいえ | ビデオサイズ：`1920x1080`、`1080x1920`、`1080x1080` |
| `duration` | integer | いいえ | ビデオ長さ（秒単位） |
| `image_url` | string | いいえ | 参照画像URL |
| `storyboard` | array | いいえ | ストーリーボードスクリプト |
| `private` | boolean | いいえ | プライベートモードかどうか |

### リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/videos \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-fast",
    "prompt": "A timelapse of a city skyline from day to night, clouds moving quickly",
    "size": "1920x1080",
    "duration": 10
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/videos",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "veo-3.1-fast",
        "prompt": "A timelapse of a city skyline from day to night",
        "size": "1920x1080",
        "duration": 10
    }
)

print(response.json())
```

</CodeGroup>

## ビデオの照会

```
GET /v1/videos/{id}
```

```bash cURL
curl https://api.crazyrouter.com/v1/videos/video_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### レスポンス例（完了時）

```json
{
  "code": "success",
  "message": "",
  "data": {
    "id": "video_abc123",
    "task_id": "video_abc123",
    "status": "SUCCESS",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/example.mp4",
    "result_url": "https://media.crazyrouter.com/task-artifacts/example.mp4"
  }
}
```

---

## ビデオのダウンロード

```
GET /v1/videos/{id}/content
```

ビデオファイルを直接ダウンロードします。

```bash cURL
curl -o output.mp4 https://api.crazyrouter.com/v1/videos/video_abc123/content \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## ビデオを編集

`image_url` を作成リクエスト内で指定すると画像からビデオ生成が可能です：

```json
{
  "model": "veo-3.1-fast",
  "prompt": "The scene comes to life with gentle movement",
  "image_url": "https://example.com/scene.jpg",
  "size": "1920x1080",
  "duration": 5
}
```

---

## Storyboard ストーリーボード

```json
{
  "model": "veo-3.1-fast",
  "storyboard": [
    {"prompt": "Wide shot of a forest at dawn", "duration": 3},
    {"prompt": "A deer walks into frame", "duration": 4},
    {"prompt": "Close-up of the deer looking at camera", "duration": 3}
  ],
  "size": "1920x1080"
}
```

---

## プライベートモード

`private: true` を設定すると、生成されたビデオが公開ギャラリーに表示されなくなります：

```json
{
  "model": "veo-3.1-fast",
  "prompt": "A confidential product demo video",
  "size": "1920x1080",
  "private": true
}
```

### タスクステータス

| ステータス | 説明 |
|------|------|
| `processing` | 処理中 |
| `SUCCESS` | 完了 |
| `failed` | 失敗 |
