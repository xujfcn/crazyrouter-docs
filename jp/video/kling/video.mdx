# Kling 動画生成

Crazyrouter は現在、一般公開中の Kling 動画ファミリーを公式プロトコルに基づいて2つのモデルファミリーに分割しています：

| ルーティングファミリー | 提出パス | クエリパス | 現在公開中のモデル |
|------|------|------|------|
| 標準 Kling 動画 | `POST /kling/v1/videos/text2video` `POST /kling/v1/videos/image2video` `POST /kling/v1/videos/multi-image2video` | `GET /kling/v1/videos/text2video/{task_id}` `GET /kling/v1/videos/image2video/{task_id}` `GET /kling/v1/videos/multi-image2video/{task_id}` | `kling-v2-5-turbo` `kling-v2-6` `kling-v3` |
| Kling Omni 動画 | `POST /kling/v1/videos/omni-video` | `GET /kling/v1/videos/omni-video/{task_id}` | `kling-v3` `kling-v3` |

すべてのタスクは非同期で処理されます。結果のクエリ時は Crazyrouter のアーカイブアドレス（例: `https://media.crazyrouter.com/...`）が優先して返されます。

## 最初の5モデルとその機能

| モデル | ルーティングファミリー | 現在の提供機能 | 検証ステータス | 課金概要 |
|------|------|------|------|------|
| `kling-v2-5-turbo` | 標準 Kling 動画 | テキストから動画生成、画像から動画生成、最初/最終フレーム、リファレンス画像から動画 | `Beta` | `mode + duration` |
| `kling-v2-6` | 標準 Kling 動画 | テキストから動画生成、画像から動画生成、最初/最終フレーム、リファレンス画像から動画、音声、ボイスコントロール、動作制御 | `Beta` | `mode + duration + sound + voice control` |
| `kling-v3` | 標準 Kling 動画 | テキストから動画生成、画像から動画生成、最初/最終フレーム、リファレンス画像から動画、動作制御、標準ルーティング要素参照 | `Beta` | `mode + duration + sound`；動作制御は個別課金バケット |
| `kling-v3` | Kling Omni 動画 | Omni 動画、画像/要素/動画/音声参照 | `Beta` | `mode + duration + sound + video input` |

<Note>
  提供機能やフィールドは公式 Kling プロトコルを基準とし、Crazyrouter は外部チャネルを内部プロバイダーとしてのみ扱い、外部プロトコルを顧客に公開しません。価格はリアルタイムの Pricing ページに準拠します。
</Note>

<Note>
  現在 Kling 最初の5モデルは公式項目や価格マトリクスに整合済みですが、機能ステータスはすべて当面 `Beta` で統一しています。リリースからしばらく経った後、スクリプト統計や生産ログをもとに各項目を正式化していきます。
</Note>

## 標準 Kling 動画

```
POST /kling/v1/videos/text2video
POST /kling/v1/videos/image2video
POST /kling/v1/videos/multi-image2video
```

### 現在のおすすめモデル

- `kling-v2-5-turbo`
- `kling-v2-6`
- `kling-v3`

### テキストから動画生成のパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model_name` | string | はい | 標準 Kling 動画モデル |
| `prompt` | string | はい | 動画の説明プロンプト |
| `image_urls` | array[string] | いいえ | 公式の最初/最終フレーム入力。`@element_name` 参照時は明示入力を推奨 |
| `negative_prompt` | string | いいえ | ネガティブプロンプト |
| `duration` | string/integer | いいえ | よく使われる `5` または `10` |
| `aspect_ratio` | string | いいえ | 例: `16:9`、`9:16`、`1:1` |
| `mode` | string | いいえ | 生成モード。例: `std`、`pro` |
| `sound` | string / boolean | いいえ | 公式値 `on` / `off` の利用を推奨 |
| `multi_shots` | boolean | いいえ | 公式のマルチカメラスイッチ。エイリアス `multi_shot` も対応 |
| `multi_prompt` | array | 条件付き必須 | マルチカメラ説明。最大5シーンまで |
| `kling_elements` | array | いいえ | `kling-v3` 標準ルーティング要素の参照。プロンプト内の `@element_name` と併用 |
| `cfg_scale` | number | いいえ | ガイド強度 |
| `camera_control` | object | いいえ | カメラ制御パラメータ |
| `callback_url` | string | いいえ | コールバックURL |
| `external_task_id` | string | いいえ | ビジネス側カスタムタスクID |

### 画像から動画生成例

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/videos/image2video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kling-v3",
    "prompt": "图片中的人物开始微笑并缓缓转头",
    "image": "https://example.com/portrait.jpg",
    "duration": "5",
    "mode": "std"
  }'
```

公式の優先フィールドは `image_urls` です。`image + image_tail` も引き続き利用可能で、最初/最後フレーム互換エイリアスとして扱われます。動画タスクは非同期であり、[タスククエリ](/jp/video/kling/query) で最終結果を取得してください。

### ローカルリファレンス画像をアップロードして動画生成

リファレンス画像がローカルにある場合は、まず一時イメージホスティングサービスで公開URLを取得し、それをKlingに渡してください。一時画像はデフォルトで72時間保存され、保存期間内は日ごとの課金はありません。

```bash cURL
UPLOAD_RESPONSE=$(curl -sS -X POST https://api.crazyrouter.com/v1/files/uploads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@./portrait.png" \
  -F "purpose=model_input")

IMAGE_URL=$(python -c "import json,sys; print(json.load(sys.stdin)['url'])" <<< "$UPLOAD_RESPONSE")

curl -X POST https://api.crazyrouter.com/kling/v1/videos/image2video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d "{
    \"model_name\": \"kling-v3\",
    \"prompt\": \"图片中的人物缓缓转头并微笑，镜头轻微推进，电影级光影\",
    \"image_urls\": [\"$IMAGE_URL\"],
    \"duration\": \"5\",
    \"mode\": \"std\"
  }"
```

### リファレンス画像から動画生成のパラメータ

```
POST /kling/v1/videos/multi-image2video
```

このパスは標準 Kling 公式 `Reference` 機能に対応します。それは `image2video` とは異なり、`image`/`image_tail` を使わず、公式の `image_list` をリファレンス素材入力として利用します。

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model_name` | string | はい | 標準 Kling 動画モデル |
| `prompt` | string | はい | リファレンス画像の一貫性および動作説明 |
| `image_list` | array | はい | 公式リファレンス画像リスト |
| `negative_prompt` | string | いいえ | ネガティブプロンプト |
| `duration` | string/integer | いいえ | よく使われる `5` または `10` |
| `aspect_ratio` | string | いいえ | 出力比率 |
| `mode` | string | いいえ | 生成モード |
| `sound` | string / boolean | いいえ | 公式値 `on` / `off` の利用を推奨 |
| `multi_shots` | boolean | いいえ | 公式のマルチカメラスイッチ。エイリアス `multi_shot` も対応 |
| `multi_prompt` | array | 条件付き必須 | マルチカメラ説明 |
| `cfg_scale` | number | いいえ | ガイド強度 |
| `camera_control` | object | いいえ | カメラ制御パラメータ |
| `callback_url` | string | いいえ | コールバックURL |
| `external_task_id` | string | いいえ | ビジネス側カスタムタスクID |

### リファレンス画像から動画生成例

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/videos/multi-image2video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kling-v3",
    "prompt": "保持同一只柴犬的形象，在草地上向前奔跑",
    "duration": "5",
    "aspect_ratio": "16:9",
    "mode": "pro",
    "image_list": [
      {
        "image_id": 1,
        "image_url": "https://example.com/reference-1.png"
      },
      {
        "image_id": 2,
        "image_url": "https://example.com/reference-2.png"
      }
    ]
  }'
```

<Note>
  `multi-image2video` は標準 Kling ファミリーのリファレンス画像機能の入口です。入力が最初/最終フレームの場合は `image2video` をご利用ください。このタスクのクエリには `GET /kling/v1/videos/multi-image2video/{task_id}` を使用してください。
</Note>

## Kling Omni 動画

```
POST /kling/v1/videos/omni-video
```

### 現在公開中のモデル

- `kling-v3`

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model_name` | string | はい | `kling-v3` のみサポート |
| `prompt` | string | はい | 公式 Omni プロンプト。`image_list`、`element_list`、`video_list`、`voice_list` のオブジェクト参照可 |
| `sound` | string | いいえ | 公式値は `on` / `off` 使用 |
| `duration` | string/integer | いいえ | よく使われる `5`、上限は該当モデルの公式ドキュメントに従う |
| `aspect_ratio` | string | いいえ | 例: `16:9`、`9:16`、`1:1` |
| `mode` | string | いいえ | 生成モード。例: `std`、`pro` |
| `multi_shots` | boolean | いいえ | 公式のマルチカメラスイッチ。エイリアス `multi_shot` も対応 |
| `multi_prompt` | array | 条件付き必須 | マルチカメラ説明 |
| `image_list` | array | いいえ | 公式画像リファレンスリスト |
| `element_list` | array | いいえ | 公式要素リファレンスリスト |
| `video_list` | array | いいえ | 公式動画リファレンスリスト |
| `voice_list` | array | いいえ | 公式音声リファレンスリスト |
| `callback_url` | string | いいえ | コールバックURL |
| `external_task_id` | string | いいえ | ビジネス側カスタムタスクID |

### Omni リクエスト例

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/videos/omni-video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kling-v3",
    "prompt": "<<<image_1>>> 在雨夜巷子里向镜头走来",
    "sound": "on",
    "duration": "5",
    "aspect_ratio": "16:9",
    "mode": "pro",
    "image_list": [
      {
        "image_id": 1,
        "image_url": "https://example.com/reference.png"
      }
    ]
  }'
```

<Note>
  Omni ルーティングは公式 `element_list` の使用を推奨しますが、`kling_elements` エイリアスにも対応しています。タスクをクエリする際は提出パスと同じファミリーの `GET /kling/v1/videos/omni-video/{task_id}` を使ってください。
</Note>
