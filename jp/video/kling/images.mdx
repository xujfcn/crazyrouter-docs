# Kling 画像生成

```
POST /kling/v1/images/generations
```

現在公開されているドキュメントは、Kling 画像生成のメインパスのみを保証しています。まだ公開されていない image-side の拡張フィールドを、安定した対外契約と誤認して記述しないでください。

## 現時点で検証済みの範囲

- `kling-v2-5-turbo` 画像生成は、bounded 検証が完了しています
- 成功時のレスポンスは優先的に Crazyrouter アーカイブアドレス（例：`https://media.crazyrouter.com/...png`）を返します

## リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | いいえ | 現在よく使われている例は `kling-v2-5-turbo` |
| `prompt` | string | はい | 画像の説明プロンプト |
| `negative_prompt` | string | いいえ | ネガティブプロンプト |
| `aspect_ratio` | string | いいえ | `1:1`、`16:9`、`9:16` など |
| `n` | integer | いいえ | 生成数、デフォルトは `1` |
| `callback_url` | string | いいえ | コールバックアドレス |
| `external_task_id` | string | いいえ | ビジネス側のカスタムタスク ID |

## リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "kling-v2-5-turbo",
    "prompt": "一只戴着墨镜的柴犬，写实摄影风格",
    "negative_prompt": "blurry, low quality",
    "aspect_ratio": "1:1",
    "n": 1
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/kling/v1/images/generations",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "kling-v2-5-turbo",
        "prompt": "一只戴着墨镜的柴犬，写实摄影风格",
        "negative_prompt": "blurry, low quality",
        "aspect_ratio": "1:1",
        "n": 1
    }
)

print(response.json())
```

</CodeGroup>

## 画像タスクの照会

```
GET /kling/v1/images/generations/{task_id}
```

```bash cURL
curl https://api.crazyrouter.com/kling/v1/images/generations/2037177945839673344 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### レスポンス例（完了時）

```json
{
  "code": "success",
  "message": "",
  "data": {
    "error": null,
    "format": "png",
    "metadata": null,
    "status": "succeeded",
    "task_id": "2037177945839673344",
    "url": "https://media.crazyrouter.com/task-artifacts/2026/03/26/50/imageGenerate/2037177945839673344.png"
  }
}
```

<Note>
 Kling 画像生成は非同期タスクです。送信後は照会インターフェースで最終結果を取得してください。本ページでは画像から画像へ、`image_fidelity`などのimage-side拡張パラメータを公開されたハードな契約とはみなしていません。
</Note>
