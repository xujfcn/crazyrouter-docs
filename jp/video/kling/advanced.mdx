# Kling 高度な機能

## バーチャル試着

```
POST /kling/v1/images/kolors-virtual-try-on
```

現在公開されている Kling の高度な機能は、バーチャル試着のみです。この機能パスは bounded の成功検証が完了しており、`タスク成功 -> R2 アーカイブ -> media.crazyrouter.com` ループもすでに連携済みです。

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model_name` | string | いいえ | よくあるモデル例：`kolors-virtual-try-on-v1`、`kolors-virtual-try-on-v1-5` |
| `human_image` | string | はい | 人物画像。URL または Base64 に対応 |
| `cloth_image` | string | はい | 服装画像。URL または Base64 に対応 |
| `callback_url` | string | いいえ | コールバック URL |
| `external_task_id` | string | いいえ | ビジネス側のカスタムタスク ID |

### リクエスト例

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/images/kolors-virtual-try-on \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kolors-virtual-try-on-v1",
    "human_image": "https://example.com/person.jpg",
    "cloth_image": "https://example.com/jacket.jpg"
  }'
```

### 送信成功時のレスポンス例

```json
{
  "created_at": 1774585120,
  "id": "866361099762425934",
  "model": "kolors-virtual-try-on-v1",
  "object": "video",
  "progress": 0,
  "status": "",
  "task_id": "866361099762425934"
}
```

## 試着タスクのクエリ

```
GET /kling/v1/images/kolors-virtual-try-on/{task_id}
```

```bash cURL
curl https://api.crazyrouter.com/kling/v1/images/kolors-virtual-try-on/866361099762425934 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### レスポンス例（完了時）

```json
{
  "code": "success",
  "message": "",
  "data": {
    "status": "succeeded",
    "task_id": "866361099762425934",
    "url": "https://media.crazyrouter.com/task-artifacts/2026/03/27/50/tryOnGenerate/866361099762425934.png"
  }
}
```

<Note>
  現時点では、口の動きの同期、動画の延長、動画エフェクトなど、その他の Kling 高度な機能は公開 API として記載しないでください。これらはまだ Crazyrouter の公開 contract には含まれていません。
</Note>
