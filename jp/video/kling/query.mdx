# Kling タスク検索

## 検索可能なタスクパス

| パス | 用途 |
|------|------|
| `GET /kling/v1/videos/text2video/{task_id}` | テキストから動画生成タスクの検索 |
| `GET /kling/v1/videos/image2video/{task_id}` | 画像から動画生成タスクの検索 |
| `GET /kling/v1/videos/multi-image2video/{task_id}` | 参考画像から動画生成タスクの検索 |
| `GET /kling/v1/videos/omni-video/{task_id}` | Omni 動画タスクの検索 |
| `GET /kling/v1/images/generations/{task_id}` | 画像生成タスクの検索 |
| `GET /kling/v1/images/kolors-virtual-try-on/{task_id}` | バーチャル試着タスクの検索 |

## レスポンスフォーマット

すべての Kling 検索APIは同一形式のタスク構造を返します：

```json
{
  "code": "success",
  "message": "",
  "data": {
    "error": null,
    "format": "mp4",
    "metadata": null,
    "status": "SUCCESS",
    "task_id": "866168216002236456",
    "result_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/kling/866168216002236456.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/kling/866168216002236456.mp4"
  }
}
```

### キューイング中

```json
{
  "code": "success",
  "message": "",
  "data": {

```

### 処理中

```json
{
  "code": "success",
  "message": "",
  "data": {
    "error": null,
    "format": "mp4",
    "metadata": null,
    "status": "processing",
    "task_id": "task_abc123",
    "result_url": "",
    "artifact_url": ""
  }
}
```

### 完了

```json
{
  "code": "success",
  "message": "",
  "data": {
    "error": null,
    "format": "mp4",
```

### 失敗

```json
{
  "code": "success",
  "message": "",
  "data": {
    "error": {
      "message": "content moderation failed",
      "code": "task_failed"
    },
    "format": "mp4",
    "metadata": null,
    "status": "failed",
    "task_id": "task_abc123",
    "result_url": "",
    "artifact_url": ""
  }
}
```

## タスク状態

| 状態 | 説明 |
|------|------|
| `queued` | 提出済みまたはキューイング中 |
| `processing` | 生成中 |
| `SUCCESS` | 完了、`result_url` または `artifact_url` で直接アクセス可能 |
| `failed` | 終了型の失敗 |

## 完全なフロー例

```python Python
import requests
import time

API_KEY = "YOUR_API_KEY"
BASE_URL = "https://api.crazyrouter.com"
headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {API_KEY}"
}

# 1. 提交文生视频任务
resp = requests.post(
    f"{BASE_URL}/kling/v1/videos/text2video",
    headers=headers,
    json={
        "model_name": "kling-v2-5-turbo",
        "prompt": "一只猫咪在花园里追蝴蝶",
        "duration": "5",
        "aspect_ratio": "16:9"
    }
)
task_id = resp.json()["data"]["task_id"]

# 2. 轮询查询
while True:
    resp = requests.get(
        f"{BASE_URL}/kling/v1/videos/text2video/{task_id}",
        headers=headers
    )
    data = resp.json()["data"]

    if data["status"] == "SUCCESS":
        print(f"视频地址: {data.get('artifact_url') or data.get('result_url')}")
        break
    if data["status"] == "failed":
        print(f"失败: {data['error']}")
        break

    time.sleep(10)
```

<Note>
  Kling 標準動画、Omni 動画、画像、バーチャル試着タスクの結果では、サイト内保存先 `media.crazyrouter.com/...` が返される可能性があります。クライアント側では、まず `artifact_url` または `result_url` を利用すれば十分で、上流の元CDNを解析する必要はありません。
</Note>
