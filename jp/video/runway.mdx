# Runway

```
POST /runwayml/v1/image_to_video
```

Runway Gen-3 モデルを利用して画像を動画へ変換します。

## リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | いいえ | モデル名（例: `gen3a_turbo`） |
| `promptImage` | string | はい | 入力画像のURL |
| `promptText` | string | いいえ | 動画の説明用プロンプト |
| `duration` | integer | いいえ | 動画の長さ（秒）、デフォルトは5 |
| `ratio` | string | いいえ | アスペクト比：`16:9`、`9:16` |
| `watermark` | boolean | いいえ | 透かし（ウォーターマーク）を追加するかどうか |

## リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/runwayml/v1/image_to_video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gen3a_turbo",
    "promptImage": "https://example.com/landscape.jpg",
    "promptText": "Camera slowly pans across the landscape, clouds moving in the sky",
    "duration": 5,
    "ratio": "16:9",
    "watermark": false
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/runwayml/v1/image_to_video",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "gen3a_turbo",
        "promptImage": "https://example.com/landscape.jpg",
        "promptText": "Camera slowly pans across the landscape",
        "duration": 5,
        "ratio": "16:9"
    }
)

print(response.json())
```

## タスクの照会

```
GET /runwayml/v1/tasks/{task_id}
```

```bash cURL
curl https://api.crazyrouter.com/runwayml/v1/tasks/runway_task_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### レスポンス例（完了）

```json
{
  "id": "runway_task_abc123",
  "status": "SUCCEEDED",
  "output": [
    "https://runway-output.s3.amazonaws.com/..."
  ]
}
```

### タスクステータス

| ステータス | 説明 |
|------|------|
| `PENDING` | 処理待ち |
| `RUNNING` | 生成中 |
| `SUCCEEDED` | 成功 |
| `FAILED` | 失敗 |
