# MiniMax ビデオ

MiniMax（海螺）は高品質なビデオ生成機能を提供します。

## ビデオを作成する

```
POST /minimax/v1/video_generation
```

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | モデル名（例：`video-01`、`video-01-live2d`） |
| `prompt` | string | はい | ビデオ説明のプロンプトワード |
| `first_frame_image` | string | いいえ | 最初のフレーム画像のURL |

### リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/minimax/v1/video_generation \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "video-01",
    "prompt": "一只小猫在阳光下打盹，微风吹动它的毛发"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/minimax/v1/video_generation",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "video-01",
        "prompt": "一只小猫在阳光下打盹，微风吹动它的毛发"
    }
)

print(response.json())
```

</CodeGroup>

## タスクの照会

```
GET /minimax/v1/query/video_generation?task_id={task_id}
```

```bash cURL
curl "https://api.crazyrouter.com/minimax/v1/query/video_generation?task_id=minimax_video_abc123" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### レスポンス例（完了時）

```json
{
  "task_id": "minimax_video_abc123",
  "status": "Success",
  "file_id": "file_abc123",
  "base_resp": {
    "status_code": 0,
    "status_msg": "success"
  }
}
```

### タスクステータス

| ステータス | 説明 |
|------|------|
| `Queueing` | キュー待ち |
| `Processing` | 処理中 |
| `Success` | 成功 |
| `Fail` | 失敗 |
