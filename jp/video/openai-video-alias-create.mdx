# 動画生成エイリアス

```
POST /v1/video/generations
```

これはCrazyrouterが提供する互換性エイリアスルートで、`/v1/video/generations`パスに固定利用する動画クライアントやミドルウェアに適しています。

## 認証

```http
Authorization: Bearer YOUR_API_KEY
```

## いつ使用するべきか

- クライアントが既に`/v1/video/generations`に書き込まれている
- 履歴動画ワークフローを移行中で、呼び出しパスを変更したくない
- サードパーティで既に公開されたリクエストフォーマットとの互換が必要
- Wan文生動画を提出したい場合、例：`wan2.5-t2v-preview`や`wan2.2-t2v-plus`

新規接続開発では、以下を優先してください：

- Wan文生動画：本ページの`POST /v1/video/generations`を使用
- Veo／統一動画ワークフロー：`POST /v1/video/create`を使用し、`veo-3.1-fast`または`veo-3.1-quality`を提出
- OpenAI公式互換動画ワークフロー：`POST /v1/videos`を使用

## 最小リクエスト例

### Wan 2.2 T2V Plus

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "wan2.2-t2v-plus",
    "prompt": "一段平静的电影感山间云海镜头",
    "seconds": "5",
    "size": "480P"
  }'
```

### 一般的な最小例

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations   -H "Content-Type: application/json"   -H "Authorization: Bearer YOUR_API_KEY"   -d '{
    "model": "wan2.5-t2v-preview",
    "prompt": "A cinematic shot of waves hitting a cliff at sunset"
  }'
```

## 典型的成功レスポンス

```json
{
  "id": "video_task_abc123",
  "task_id": "video_task_abc123",
  "status": "processing",
  "status_update_time": 1709123456
}
```

## ローカル検証済みエラー応答

ローカル`http://127.0.0.1:4000`環境でこのルートは既に存在が検証されています。モデルが一時的に利用できない場合は、`404`ではなく業務エラーが返されます：

```json
{
  "code": "get_channel_failed",
  "message": "model wan2.2-t2v-plus is temporarily unavailable, please try again later",
  "data": null
}
```

## 注意事項

- リクエストボディの項目は、具体的な動画モデルや上流機能によって変わります
- `model`の可用性は現在のトークンホワイトリストと上流チャネルの状態に依存します
- Wan文生動画は`model`、`prompt`、`seconds`、`size`を使用します。`wan2.2-t2v-plus`の検証済み組み合わせは`seconds: "5"`、`size: "480P"`、または`"1080P"`です。
- `wan2.2-t2v-plus`は`/alibailian/api/v1/services/aigc/video-generation/video-synthesis`に提出しないでください。
- タスク作成が成功したら、引き続き`GET /v1/video/generations/{task_id}`を呼び出して状態を確認できます

<Note>
このルートは互換エイリアスであり、すべての動画モデルが完全に同じリクエスト項目を共有しているわけではありません。Wan文生動画は現在、本ページのルート利用を推奨します。Veoや統一動画ワークフローの場合は`/v1/video/create`を利用し、`veo-3.1-fast`または`veo-3.1-quality`を提出してください。
</Note>
