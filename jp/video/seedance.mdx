# Seedance

Seedance はバイトダンス / 豆包の動画生成モデル群です。Crazyrouter は現在、対顧客向けには火山ネイティブ `/volc/v1/*` プロトコルのみを提供しており、旧統一動画インターフェース内の `doubao-seedance-2-0-fast` は公開される主プロトコルとしては利用されなくなりました。

**Seedance 2.0 / 2.0 Fast の Crazyrouter における本当の決済ロジック**（「なぜタスク完了後に token での追加決済か」「token と秒数は固定換算できるか」等）を知りたい場合は、特集ページをご覧ください：[Seedance 2.0 料金説明](/jp/video/seedance-2-billing)。

## 現在公開されているモデル

| モデル | 現在の公開用途 |
|------|------|
| `doubao-seedance-1-0-lite-t2v` | テキストから動画生成 |
| `doubao-seedance-1-0-lite-i2v` | 単一画像から動画生成 |
| `doubao-seedance-1-0-pro` | 汎用高品質動画生成 |
| `doubao-seedance-1-0-pro-fast` | 汎用高速動画生成 |
| `doubao-seedance-1-5-pro` | より高次のバージョンで、今後も公式機能パラメータの拡張が可能です |
| `doubao-seedance-2-0` | Seedance 2.0 公式マルチモーダル動画生成 |
| `doubao-seedance-2-0-fast` | Seedance 2.0 Fast 公式マルチモーダル動画生成 |

## 動画タスクの提出

```
POST /volc/v1/contents/generations/tasks
```

### 現在公開されているリクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | 顧客向けモデル名、上の表の canonical モデル名を使用してください |
| `content` | array | はい | 入力内容の配列 |
| `content[].type` | string | はい | 現在 `text`、`image_url`、`video_url`、`audio_url`、`draft_task` をサポートしています |
| `content[].text` | string | 条件付き必須 | `type=text` の場合はプロンプトを入力してください |
| `content[].image_url.url` | string | 条件付き必須 | `type=image_url` の場合は画像 URL を入力してください |
| `content[].video_url.url` | string | 条件付き必須 | `type=video_url` の場合は参照動画 URL を入力してください |
| `content[].audio_url.url` | string | 条件付き必須 | `type=audio_url` の場合は参照音声 URL を入力してください |
| `content[].role` | string | 任意 | Seedance 2.0 では `first_frame`、`last_frame`、`reference_image`、`reference_video`、`reference_audio` をサポートしています |
| `generate_audio` | boolean | 任意 | Seedance 2.0 で音声を生成するかどうかを指定します |
| `ratio` | string | 任意 | 出力アスペクト比 例: `16:9` |
| `resolution` | string | 任意 | Seedance 2.0 / 2.0 fast では現在 `480p`、`720p` のみをサポートしています |
| `duration` | integer | 任意 | Seedance 2.0 / 2.0 fast では `4-15` か `-1` をサポートしています |
| `watermark` | boolean | 任意 | 透かしを追加するかどうか |
| `seed` | integer | 任意 | ランダムシード |

### Seedance 2.0 公式機能の制約

- 4 モーダル入力に対応：テキスト、画像、動画、音声。
- マルチモーダル参照に対応：画像最大 `9` 枚、動画最大 `3` 個、音声最大 `3` 個、混在ファイルの合計上限 `12`。
- 画像フォーマット：`jpeg`、`png`、`webp`、`bmp`、`tiff`、`gif`；1画像あたり最大サイズ `< 30MB`。
- 動画フォーマット：`mp4`、`mov`；動画参照最大 `3` 個、合計再生時間は推奨 `[2, 15]s`、最大ファイルサイズ `< 50MB`。
- 音声フォーマット：`mp3`、`wav`；音声参照は最大 `3` 個、合計再生時間 `<= 15s`、最大ファイルサイズ `< 15MB`。
- 音声のみの入力はできません。少なくとも `1` 枚の画像または動画参照が必要です。
- 生成可能時間は `4-15s` をサポートし、また `-1` で上位システムのデフォルト時間を使うこともできます。
- `480p`、`720p` をサポートしますが、`1080p` は Seedance 2.0 / 2.0 fast には現在対応していません。
- `frames` は現在 Seedance 2.0 / 2.0 fast には対応していません。
- `camera_fixed` は現在 Seedance 2.0 / 2.0 fast には対応していません。
- 製品の形式として、Seedance 2.0 は現在「最初と最後のフレーム」と「万能参照」の2つの入口に主に分かれます。API ではこれは `content[].role` および `content[].type` で統一的に反映されます。
- 上位システムは現時点で、現実の顔写真素材のアップロードにコンプライアンス制限を設けています。高解像度かつ現実的な顔が含まれる画像や動画参照は、上位システムで即時ブロックされる可能性があります。

### Seedance 2.0 公式料金の実態

| モデル | 公式課金方式 | 公式単価 |
|------|------|------|
| `doubao-seedance-2-0` | 出力 tokens ベースの課金 | 動画入力あり `出力トークン100万個につき28元`；動画入力なし `出力トークン100万個につき46元` |
| `doubao-seedance-2-0-fast` | 出力 tokens ベースの課金 | 動画入力あり `出力トークン100万個につき22元`；動画入力なし `出力トークン100万個につき37元` |

<Note>
  リモート URL 素材の MIME、再生時間、サイズは最終的に上位システムで検証されます。Crazyrouter は、提出前に数・再生時間パラメータ・音声のみでの入力禁止・480p/720p / `frames` / `camera_fixed` などの明示的制約について検証します。
</Note>

### テキストから動画生成例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/volc/v1/contents/generations/tasks \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "doubao-seedance-1-0-lite-t2v",
    "content": [
      {
        "type": "text",
        "text": "镜头缓慢推进，一只白色海鸥从海面掠过，日落金光反射在海浪上"
      }
    ]
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/volc/v1/contents/generations/tasks",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "doubao-seedance-1-0-lite-t2v",
        "content": [
            {
                "type": "text",
                "text": "镜头缓慢推进，一只白色海鸥从海面掠过，日落金光反射在海浪上"
            }
        ]
    }
)

print(response.json())
```

curl -X POST https://api.crazyrouter.com/volc/v1/contents/generations/tasks \

## タスクの照会

```
GET /volc/v1/contents/generations/tasks/{task_id}
```

```bash cURL
curl https://api.crazyrouter.com/volc/v1/contents/generations/tasks/cgt_task_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### レスポンス例（完了状態）

```json
{
  "code": "success",
  "message": "",
  "data": {
    "id": "cgt_task_abc123",
    "task_id": "cgt_task_abc123",
    "model": "doubao-seedance-2-0-fast",
    "status": "SUCCESS",
    "result_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/seedance/cgt_task_abc123.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/seedance/cgt_task_abc123.mp4",
    "content": {
      "video_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/seedance/cgt_task_abc123.mp4"
    }
  }
}
```

### タスク状況

| 状態 | 説明 |
|------|------|
| `NOT_START` | 提出済み、上位処理待ち |
| `IN_PROGRESS` | 生成中 |
| `SUCCESS` | 完了、`result_url`、`artifact_url` または `content.video_url` から結果を取得可能 |
| `FAILURE` | 最終失敗 |

<Note>
  現在公開しているドキュメントは、ネイティブ `/volc/v1/*` 経路と canonical モデル名のみを保証します。古い `doubao-seedance-2-0-fast` は歴史的参照のためだけに残されており、新たな顧客向け主プロトコルではありません。
</Note>

<Note>
  Seedance 公式の料金情報は現在 `per_output_token` で管理されており、秒単位ではありません。もし将来的に pricing ページでプラットフォーム統一表示される場合、その表示はあくまでプラットフォームの販売基準であり、公式のネイティブ単位ではないことを明記してください。
</Note>
