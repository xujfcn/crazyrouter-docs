# 統一動画 API

Crazyrouter は、統一された動画生成インターフェースを提供し、複数の動画モデルを同じ API フォーマットで呼び出すことができます。

<Note>
  `Seedance` 現在、統一された `/v1/video/*` プロトコルの利用は推奨していません。ネイティブの `/volc/v1/contents/generations/tasks` をご利用ください。詳細は [Seedance](/jp/video/seedance) を参照してください。
</Note>

## 対応モデル

| モデル | 説明 |
|------|------|
| `veo-3.1-fast` | Google Veo 3.1 Fast |
| `veo-3.1-quality` | Google Veo 3.1 Quality |
| `wan2.2-t2v-plus` | Wan テキストから動画生成 |
| `wan2.5-t2v-preview` | Wan テキストから動画生成 |

---

## 動画生成

```
POST /v1/video/create
```

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | モデル名 |
| `prompt` | string | はい | 動画説明のプロンプト |
| `aspect_ratio` | string | いいえ | アスペクト比：`16:9`、`9:16`、`1:1` |
| `size` | string | いいえ | 動画サイズ。例：`1280x720` |
| `images` | array | いいえ | 現在公開されている画像から動画生成の場合、通常は `1` 枚の画像URLを指定します |
| `duration` | integer | いいえ | 動画の長さ（秒） |

### リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-quality",
    "prompt": "一只金毛犬在海滩上奔跑，慢动作，电影级画质",
    "aspect_ratio": "16:9"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/video/create",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "veo-3.1-quality",
        "prompt": "一只金毛犬在海滩上奔跑，慢动作，电影级画质",
        "aspect_ratio": "16:9"
    }
)

data = response.json()
task_id = data["task_id"]
print(f"任务 ID: {task_id}")
```

</CodeGroup>

### 生成レスポンス

```json
{
  "task_id": "video_task_abc123",
  "status": "processing"
}
```

## 画像から動画生成

`images` パラメータで参考画像を指定します：

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "wan-ai/wan2.1-i2v-14b-720p",
    "prompt": "图片中的人物开始微笑并挥手",
    "images": ["https://example.com/portrait.jpg"],
    "aspect_ratio": "16:9"
  }'
```

## タスクの確認

```
GET /v1/video/query?id={task_id}
```

### リクエスト例

```bash cURL
curl "https://api.crazyrouter.com/v1/video/query?id=video_task_abc123" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### 確認レスポンス（処理中）

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "video_task_abc123",
    "status": "processing",
    "url": ""
  }
}
```

### 確認レスポンス（完了）

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "video_task_abc123",
    "status": "SUCCESS",
    "url": "https://media.crazyrouter.com/task-artifacts/example.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/example.mp4"
  }
}
```

### タスク状態

| 状態 | 説明 |
|------|------|
| `queued` | キュー待ち |
| `processing` | 処理中 |
| `SUCCESS` | 完了 |
| `failed` | 失敗 |

## 完全なフロー例

```python Python
import requests
import time

API_KEY = "YOUR_API_KEY"
BASE_URL = "https://api.crazyrouter.com"
headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {API_KEY}"
}

# 1. 创建视频任务
resp = requests.post(f"{BASE_URL}/v1/video/create", headers=headers, json={
    "model": "veo-3.1-quality",
    "prompt": "一只金毛犬在海滩上奔跑，慢动作",
    "aspect_ratio": "16:9"
})
task_id = resp.json()["task_id"]
print(f"任务已创建: {task_id}")

# 2. 轮询查询状态
while True:
    resp = requests.get(f"{BASE_URL}/v1/video/query?id={task_id}", headers=headers)
    result = resp.json().get("data", resp.json())
    status = result["status"]
    print(f"状态: {status}")

    if status == "SUCCESS":
        print(f"视频地址: {result.get('artifact_url') or result.get('url')}")
        break
    elif status == "failed":
        print("视频生成失败")
        break

    time.sleep(10)
```

<Note>
  動画生成には通常 1〜5分かかります。ポーリング間隔は10秒を推奨します。
</Note>
