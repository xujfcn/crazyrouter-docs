# AIGC Kling VOD 利用方法

`aigc-video-kling-*` は Crazyrouter が Tencent VOD 経由で提供する Kling 動画モデルです。これはネイティブ Kling ドキュメントの `/kling/v1/videos/*` パスとは異なり、OpenAI スタイルの動画非同期インターフェースで利用します：

```http
POST /v1/video/generations
GET /v1/video/generations/{task_id}
```

<Note>
  VOD 経由の場合、必ず `aigc-video-kling-*` モデル名を利用してください。`kling-v2-5-turbo`、`kling-v2-6`、`kling-v3` をこのページのインターフェースへ直接送信しないでください。そうするとネイティブ Kling 回線で処理されることがあります。
</Note>

<Note>
  画像モデル `aigc-image-kling-3.0` を使いたい場合は、[AIGC Kling 3.0 画像生成](/jp/images/aigc-kling) をご参照ください。このモデルは `POST /v1/images/generations` を利用し、本ページの動画インターフェースは使用しません。
</Note>

## 利用可能なモデル

| モデル | 上流バージョン | 対応機能 |
|------|------|------|
| `aigc-video-kling-1.6` | Kling 1.6 | テキスト生成、画像生成、始終フレーム、参照画像 |
| `aigc-video-kling-2.0` | Kling 2.0 | テキスト生成、画像生成、始終フレーム、参照画像 |
| `aigc-video-kling-2.1` | Kling 2.1 | テキスト生成、画像生成、始終フレーム、参照画像 |
| `aigc-video-kling-2.5-turbo` | Kling 2.5 Turbo | テキスト生成、画像生成、始終フレーム、参照画像 |
| `aigc-video-kling-2.6` | Kling 2.6 | テキスト生成、画像生成、始終フレーム、参照画像、動画入力 |
| `aigc-video-kling-2.6-motion-control` | Kling 2.6 Motion Control | 動作制御 |
| `aigc-video-kling-3.0` | Kling 3.0 | テキスト生成、画像生成、始終フレーム、参照画像 |
| `aigc-video-kling-3.0-turbo` | Kling 3.0 Turbo | テキスト生成、画像生成、参照画像 |
| `aigc-video-kling-3.0-motion-control` | Kling 3.0 Motion Control | 動作制御 |
| `aigc-video-kling-o1` | Kling O1 | テキスト生成、画像生成、参照画像、動画入力 |
| `aigc-video-kling-avatar` | Kling Avatar | デジタルヒューマン / Avatar |

<Note>
  Tencent VOD ドキュメント中の `GV 3.1`、`3.1-fast`、`3.1-lite` は Google Veo 回線であり、Kling 3.1 ではありません。必ず専用の `aigc-video-gv-*` モデルをご利用ください。
</Note>

## タスク作成

```http
POST https://api.crazyrouter.com/v1/video/generations
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

### 共通パラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | 必須 | 本ページの `aigc-video-kling-*` モデル名を入力 |
| `prompt` | string | 条件付き必須 | テキスト生成は必須。マルチショットや一部画像生成ケースは拡張パラメータで代用可能 |
| `seconds` / `duration` | string / number | 任意 | 動画長。よく使われるのは `5` または `10`。デフォルトは `5` 秒 |
| `size` | string | 任意 | `1280x720`、`720x1280` などを元に出力比率を推論 |
| `image` | string | 任意 | 単一画像生成動画の初フレーム URL |
| `images` | array[string] | 任意 | 最初の画像は初フレーム、2枚目は終フレームまたは参照画像として利用可能 |
| `metadata` | object | 任意 | VOD Kling 拡張パラメータ。下記のフィールド表を参照 |

### よく使う metadata フィールド

| フィールド | 説明 |
|------|------|
| `resolution` | 出力仕様（例：`720P`、`1080P`、`2K`、`4K`） |
| `aspect_ratio` | 出力比率（例：`16:9`、`9:16`、`1:1`） |
| `sound` | 音声生成の有無。`true` / `false`、`on` / `off` をサポート |
| `image_urls` | 始終フレーム配列。最大2枚まで |
| `image_tail` / `last_frame_url` | 終了フレーム URL。`image_urls[1]` より優先されます |
| `image_list` | 参照画像リスト。最大9枚まで対応 |
| `multi_shots` / `multi_shot` | マルチショット切替 |
| `shot_type` | ショット分割タイプ |
| `multi_prompt` | マルチショット用プロンプト配列 |
| `kling_elements` / `element_list` | Kling 要素制御 |
| `camera_control` | カメラワーク制御 |
| `motion_brush` / `dynamic_masks` | 動作制御パラメータ |
| `video_list` | 動画参照入力。O1や動画インプット系の能力で活用 |
| `voice_list` | 音声参照入力 |
| `session_id` / `face_choose` | リップシンク関連パラメータ |

## テキスト生成動画

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-2.6",
    "prompt": "a red square logo slowly rotating on a clean white background",
    "size": "1280x720",
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "sound": false
    }
  }'
```

## 画像生成動画

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-2.5-turbo",
    "prompt": "make the picture gently move with a slow camera push in",
    "image": "https://example.com/input.png",
    "size": "1280x720",
    "seconds": "5",
    "metadata": {
      "resolution": "720P"
    }
  }'
```

## 始終フレーム動画

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-2.6",
    "prompt": "transition naturally from the first frame to the last frame",
    "images": [
      "https://example.com/first.png",
      "https://example.com/last.png"
    ],
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "sound": false
    }
  }'
```

<Note>
  Kling 2.6 の始終フレームでは `metadata.sound=false` を明示的に入力することを推奨します。
</Note>

## 複数参照画像

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-3.0",
    "prompt": "keep the same character identity and create a cinematic walking shot",
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "image_list": [
        "https://example.com/ref-1.png",
        "https://example.com/ref-2.png"
      ]
    }
  }'
```

## 動作制御

動作制御機能は専用モデル名（例：`aigc-video-kling-2.6-motion-control`、`aigc-video-kling-3.0-motion-control`）を使用します。

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-3.0-motion-control",
    "prompt": "animate the selected subject moving from left to right",
    "image": "https://example.com/input.png",
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "dynamic_masks": [
        {
          "mask_url": "https://example.com/mask.png",
          "trajectories": [
            { "x": 220, "y": 380 },
            { "x": 620, "y": 380 }
          ]
        }
      ]
    }
  }'
```

## O1 動画入力

`aigc-video-kling-o1` で `metadata.video_list` 経由の動画参考を受け付けます。動画入力の有無で課金仕様が異なります。

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-o1",
    "prompt": "use the reference video motion style and generate a new cinematic shot",
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "video_list": [
        { "url": "https://example.com/reference.mp4" }
      ]
    }
  }'
```

## Avatar およびリップシンク

Avatar は `aigc-video-kling-avatar` で利用：

```json
{
  "model": "aigc-video-kling-avatar",
  "prompt": "a presenter speaks naturally to the camera",
  "image": "https://example.com/avatar.png",
  "seconds": "5",
  "metadata": {
    "resolution": "720P",
    "voice_list": [
      { "url": "https://example.com/voice.wav" }
    ]
  }
}
```

リップシンクは `aigc-video-kling-identifyface` を利用します。上流から `session_id` と `face_choose` を取得している場合は `metadata` に格納可能：

```json
{
  "model": "aigc-video-kling-identifyface",
  "prompt": "lip sync the face with the provided voice",
  "image": "https://example.com/face.png",
  "seconds": "5",
  "metadata": {
    "resolution": "720P",
    "session_id": "SESSION_ID",
    "face_choose": "FACE_ID",
    "voice_list": [
      { "url": "https://example.com/voice.wav" }
    ]
  }
}
```

<Note>
  リップシンクの完全な流れでは、まず顔認識を行いそれから動画生成タスクを送信します。`session_id` / `face_choose` が無い場合は、上流でパラメータエラーになることがあります。
</Note>

## タスク照会

タスク作成で `id` または `task_id` が返されたら、同じ一連の互換パスで照会：

```bash cURL
curl https://api.crazyrouter.com/v1/video/generations/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

完了後はアーカイブされた動画の URL を取得できます：

```json
{
  "code": "success",
  "data": {
    "status": "SUCCESS",
    "task_id": "vod_task_abc123",
    "result_url": "https://media.crazyrouter.com/task-artifacts/example.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/example.mp4"
  }
}
```

## ネイティブKlingとの違い

| 項目 | AIGC Kling VOD | ネイティブ Kling |
|------|------|------|
| モデル名 | `aigc-video-kling-*` | `kling-v2-5-turbo`、`kling-v2-6`、`kling-v3` |
| 作成パス | `POST /v1/video/generations` | `POST /kling/v1/videos/text2video` 等 |
| 照会パス | `GET /v1/video/generations/{task_id}` | `GET /kling/v1/videos/{type}/{task_id}` |
| 主なフィールド | `model`、`prompt`、`seconds`、`image`、`images`、`metadata` | `model_name`、`prompt`、`image_urls`、`duration` 等 |
| 対応シーン | Tencent VOD 設定でのルート、VOD の料金・機能を利用 | ネイティブ Kling プロトコル利用 |

価格、割引、利用可能な仕様は [Pricing ページ](https://crazyrouter.com/ja/pricing) を必ず確認してください。
