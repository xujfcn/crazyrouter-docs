# Wan ビデオ

Wan シリーズは現在、能力ごとに異なる対ユーザー用プロトコルを採用しています：

- テキストから動画生成（`wan2.5-t2v-preview`、`wan2.2-t2v-plus`）：`POST /v1/video/generations` を使用し、`GET /v1/video/generations/{task_id}` にて検索します。
- 画像から動画生成、始終フレーム生成、主体参照動画生成：Alibaba百炼互換パス `POST /alibailian/api/v1/services/aigc/video-generation/video-synthesis` を使用し、`GET /alibailian/api/v1/tasks/{task_id}` にて検索します。

<Warning>
  `wan2.2-t2v-plus` を `/alibailian/api/v1/services/aigc/video-generation/video-synthesis` に送信しないでください。プロダクション環境では `invalid_request`が返され、`/v1/video/generations`を使うよう案内されます。
</Warning>

Alibabaフォーマットワークフローの完全なリクエスト体、およびタスク検索フォーマットについては [Alibaba百炼動画API](/jp/video/alibailian) をご覧ください。本ページは現時点で外部公開されている最初の `Wan` モデル・能力・課金体系・推奨プロトコルをまとめています。

## プロトコル規定

### 1. テキストから動画生成

- 推奨提出パス：`POST /v1/video/generations`
- 推奨検索パス：`GET /v1/video/generations/{task_id}`
- 主要フィールド：`model`、`prompt`、`seconds`、`size`
- 主なモデル：`wan2.5-t2v-preview`、`wan2.2-t2v-plus`

### 2. 画像から動画生成

- 主要フィールド：`input.img_url`
- 主なモデル：`wan2.5-i2v-preview`、`wan2.2-i2v-plus`、`wan2.2-i2v-flash`

### 3. 始終フレーム生成

- 主要フィールド：`input.first_frame_url`、`input.last_frame_url`
- 主なモデル：`wan2.2-kf2v-flash`

### 4. 主体参照動画生成

- 主要フィールド：`input.image_url`
- 主なモデル：`wan2.2-s2v`

## リクエスト例

### テキストから動画生成：Wan 2.2 T2V Plus

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "wan2.2-t2v-plus",
    "prompt": "一段平静的电影感山间云海镜头",
    "seconds": "5",
    "size": "480P"
  }'
```

### 画像から動画生成

```bash cURL
curl -X POST https://api.crazyrouter.com/alibailian/api/v1/services/aigc/video-generation/video-synthesis \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "wan2.5-i2v-preview",
    "input": {
      "prompt": "让画面中的人物转头看向镜头",
      "img_url": "https://example.com/first-frame.png"
    },
    "parameters": {
      "resolution": "720P",
      "duration": 5,
      "prompt_extend": true,
      "audio": true
    }
  }'
```

### 始終フレーム生成

```json
{
  "model": "wan2.2-kf2v-flash",
  "input": {
    "prompt": "镜头从白天平滑过渡到夜晚",
    "first_frame_url": "https://example.com/frame-start.png",
    "last_frame_url": "https://example.com/frame-end.png"
  },
  "parameters": {
    "resolution": "720P",
    "duration": 5
  }
}
```

### 主体参照動画生成

```json
{
  "model": "wan2.2-s2v",
  "input": {
    "prompt": "让参考人物自然说话并有轻微头部动作",
    "image_url": "https://example.com/portrait.png",
    "audio_url": "https://example.com/voice.mp3"
  },
  "parameters": {
    "resolution": "720P",
    "duration": 5
  }
}
```

## タスク取得

Wanは現状では非同期タスクモデルを採用しています。顧客がタスクを作成後、提出プロトコルに従って検索します：

テキストから動画生成：

```http
GET /v1/video/generations/{task_id}
```

Alibaba互換の画像生成、始終フレーム、主体参照ワークフロー：

```http
GET /alibailian/api/v1/tasks/{task_id}
```

検索結果が `status = SUCCESS` の場合は、`result_url` または `artifact_url` から最終動画結果を取得してください。

## 境界説明

- Wan テキストから動画生成の推奨顧客プロトコルは `/v1/video/generations`であり、Alibaba百炼互換の提出パスではありません。
- Alibaba百炼互換パスは主に画像生成、始終フレーム生成、主体参照動画生成などのAlibabaフォーマット移行シナリオで利用されます。
- Crazyrouter内部では公式、ApiPass、Kie、その他サードパーティーをプロバイダーとして利用できますが、これらのプロバイダーは顧客プロトコルを独自に定義しません。
- 現在のBeta項目は顧客向けに暫定公開できます。ローンチ後はプロダクションタスクログとライブエビデンスを統合して検証し、成功後Betaラベルを除去します。
