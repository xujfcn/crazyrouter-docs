# 即梦

即梦（Jimeng）は字节跳动の動画生成サービスです。Crazyrouterは現在、対顧客推奨ルートとして`/jimeng/*`のみを利用しており、上流の`Action + Version`を直接主要プロトコルとして公開していません。

## 現在検証済みの範囲

- `POST /jimeng/submit/videos`は`jimeng-video-3.0`のテキストから動画生成の投稿が検証済みです
- 単一画像入力と単一画像`recamera`は検証済みで利用可能です
- 現在安定している正サンプルの主チェーンは`1080P`に集中しています
- `720P / recamera`は引き続き`ch119`の、carrierレベルのフォローアップとなっており、現在公開されているハード契約拡張範囲には含まれません
- 検索結果はまずCrazyrouterで保存されているメディアアドレス（例：`https://media.crazyrouter.com/...`）を優先的に返します
- `expired`の候補タスク再取得ルートはクローズドループ化済みですが、自然期限切れサンプルはバックグラウンドでより長い保持期間を待っており、主チェーン接続には影響しません

## 動画タスクの投稿

```
POST /jimeng/submit/videos
```

### 現在の推奨モデル

- `jimeng-video-3.0`：現在、主に対顧客推奨されているモデルです

### リクエストパラメータ

| パラメータ | タイプ | 必須 | 説明 |
|------|------|------|------|
| `model` | string | 必須 | 顧客向けモデル名。現在の推奨は`jimeng-video-3.0`です |
| `prompt` | string | 条件付き必須 | テキスト動画生成の場合は必須推奨；`recamera`も動作説明を補足することを推奨します |
| `duration` | integer | 任意 | `5`または`10`の利用推奨 |
| `aspect_ratio` | string | 任意 | 比例（例：`16:9`、`9:16`） |
| `image_url` | string | 任意 | 単一画像URL入力 |
| `binary_data_base64` | string[] | 任意 | 単一画像Base64入力 |
| `image_urls` | string[] | 任意 | 配列書き方に対応；現状、複数参照画像用公開保証として扱わないでください |
| `template_id` | string | 任意 | 単一画像`recamera`テンプレート（例：`handheld`） |
| `camera_strength` | string | 任意 | 単一画像`recamera`強度（例：`weak`、`medium`、`strong`） |
| `req_key` | string | 任意 | デバッグや互換シーンでの利用のみ。通常の接続では明示的な送信は推奨されません |

### テキスト動画生成例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/jimeng/submit/videos \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "jimeng-video-3.0",
    "prompt": "镜头缓慢推进，一只橘猫在窗边打哈欠，晨光柔和",
    "duration": 5,
    "aspect_ratio": "9:16"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/jimeng/submit/videos",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "jimeng-video-3.0",
        "prompt": "镜头缓慢推进，一只橘猫在窗边打哈欠，晨光柔和",
        "duration": 5,
        "aspect_ratio": "9:16"
    }
)

print(response.json())
```

</CodeGroup>

## タスクの検索

```
GET /jimeng/fetch/{task_id}
```

```bash cURL
curl https://api.crazyrouter.com/jimeng/fetch/2526913314163451526 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```json

  "code": "success",
  "message": "",
  "data": {
    "error": null,
    "format": "mp4",
    "metadata": null,
    "status": "succeeded",
    "task_id": "2526913314163451526",
    "url": "https://media.crazyrouter.com/task-artifacts/2026/03/27/51/generate/2526913314163451526.mp4"
  }

```

### タスクの状態

| 状態 | 説明 |
|------|------|
| `queued` | 投稿済みまたはキュー中 |
| `processing` | 動画生成中 |
| `succeeded` | 完了。`url`から直接取得可能 |
| `failed` | 永続的な失敗 |

<Note>
  現在公開中のドキュメントでは、単一画像入力と単一画像`recamera`のみ保証しています。`image_urls`をJimengの複数参照画像ハード契約として誤記しないでください。また、`frames`を推奨公開パラメータとして扱わないでください；サポート外の`frames`値は、上流アルゴリズム段階で遅延的に失敗する可能性があります。
</Note>

<Note>
  現在公開中のドキュメントは、検証済み安定範囲（`jimeng-video-3.0 + テキストからビデオ生成 / 単一画像入力 / 単一画像 recamera`）に収束しています。`720P / recamera`の更なる公開可否は、今後のcarrierサンプル再検証により決まります。倉庫コードの透過送信可否では判断されません。
</Note>
