# 火山引擎

火山引擎（Volcengine）はByteDanceグループ傘下のビデオ生成機能を提供します。

## ビデオタスクの作成

```
POST /volc/v1/contents/generations/tasks
```

### リクエストパラメーター

| パラメーター | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | モデル名 |
| `content` | object | はい | コンテンツ設定 |
| `content.prompt` | string | はい | ビデオ生成用の説明キーワード |
| `content.image_url` | string | いいえ | 参考画像URL |
| `content.aspect_ratio` | string | いいえ | アスペクト比 |

### リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/volc/v1/contents/generations/tasks \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "doubao-video",
    "content": {
      "prompt": "一只蝴蝶在花丛中飞舞，微距镜头",
      "aspect_ratio": "16:9"
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/volc/v1/contents/generations/tasks",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "doubao-video",
        "content": {
            "prompt": "一只蝴蝶在花丛中飞舞，微距镜头",
            "aspect_ratio": "16:9"
        }
    }
)

print(response.json())
```

</CodeGroup>

## タスクの照会

```
GET /volc/v1/contents/generations/tasks/{task_id}
```

```bash cURL
curl https://api.crazyrouter.com/volc/v1/contents/generations/tasks/volc_task_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### レスポンス例（完了時）

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "volc_task_abc123",
    "status": "SUCCESS",
    "content": {
      "video_url": "https://cdn.volcengine.com/videos/...",
      "duration": 5
    }
  }
}
```

### タスクステータス

| ステータス | 説明 |
|------|------|
| `SUBMITTED` | 提出済み |
| `PROCESSING` | 処理中 |
| `SUCCESS` | 成功 |
| `FAILED` | 失敗 |
