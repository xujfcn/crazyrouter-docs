# 阿里百炼動画API

Crazyrouter は、阿里百炼互換の動画パスを提供します。DashScope / 阿里百炼動画フォーマットを導入済みのアプリケーションが、そのまま移行可能です。

## このページで扱う内容

- 本ページでは、Crazyrouter が外部に公開する阿里互換エイリアスについて説明します。DashScope / 阿里百炼動画フォーマット統合済みのワークフローで、そのまま `/alibailian/api/v1/*` を利用できます。
- Crazyrouter 内部で接続している公式上流は DashScope `/api/v1/*` パスに統一されています。
- Crazyrouter の統一動画APIを利用したい場合は、阿里互換移行パスではなく、`/v1/video/generations` を選択してください。
- Wan 生成動画は現在 `/v1/video/generations` を使用しています。特に `wan2.2-t2v-plus` は本ページの `/alibailian/...video-synthesis` 提出パスをサポートしていません。
- 現在のモデルが利用可能かどうかは、あなたのトークンホワイトリスト、モデル料金設定、現在の運用状態によります。阿里上流の全モデルが無条件で開放されているわけではありません。

## 対応エンドポイント

- `POST /alibailian/api/v1/services/aigc/video-generation/video-synthesis`
- `GET /alibailian/api/v1/tasks/{task_id}`

## 内部上流パス説明

- 外部互換提出パス：`POST /alibailian/api/v1/services/aigc/video-generation/video-synthesis`
- 外部互換参照パス：`GET /alibailian/api/v1/tasks/{task_id}`
- Crazyrouter 内部提出上流：`POST /api/v1/services/aigc/video-generation/video-synthesis`
- Crazyrouter 内部参照上流：`GET /api/v1/tasks/{task_id}`

## 認証

```http
Authorization: Bearer YOUR_API_KEY
```

## POST 動画生成

```
POST /alibailian/api/v1/services/aigc/video-generation/video-synthesis
```

### リクエストボディ構造

| フィールド | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | モデル名（例：`wan2.5-i2v-preview`） |
| `input` | object | はい | 基本入力パラメータ |
| `input.prompt` | string | いいえ | 正方向プロンプト |
| `input.negative_prompt` | string | いいえ | 逆方向プロンプト |
| `input.img_url` | string | いいえ | 先頭フレーム画像 URL または Base64 |
| `input.audio_url` | string | いいえ | 音声ファイル URL |
| `input.template` | string | いいえ | ビデオエフェクトテンプレート |
| `parameters` | object | いいえ | 高度な処理パラメータ |
| `parameters.resolution` | string | いいえ | 解像度ランク（例：`480P`） |
| `parameters.duration` | integer | いいえ | 動画の長さ（秒） |
| `parameters.prompt_extend` | boolean | いいえ | スマートリライティングを有効にするか |
| `parameters.watermark` | boolean | いいえ | AIウォーターマークを追加するか |
| `parameters.audio` | boolean | いいえ | オーディオを自動追加するか |
| `parameters.seed` | integer | いいえ | ランダムシード |

<Warning>
  `wan2.2-t2v-plus` を本ページパスに提出すると `invalid_request` が返されます。プロダクションのプロンプトは `/v1/video/generations` を使用してください。Wan 生成動画については [Wan 動画](/jp/video/wan) または [動画生成エイリアス](/jp/video/openai-video-alias-create) を参照してください。
</Warning>

### リクエストの例

```bash cURL
curl -X POST https://api.crazyrouter.com/alibailian/api/v1/services/aigc/video-generation/video-synthesis \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "wan2.5-i2v-preview",
    "input": {
      "prompt": "改变一下光线",
      "img_url": "https://example.com/first-frame.png"
    },
    "parameters": {
      "resolution": "480P",
      "prompt_extend": true,
      "audio": true
    }
  }'
```

### レスポンス例

```json
{
  "request_id": "ccffb21f-c21e-4eba-861a-6c80e6db6e4d",
  "output": {
    "task_id": "a55bfe14-6e78-4b9d-b97d-128420399ed1",
    "task_status": "PENDING"
  }
}
```

## ローカルで確認されたエラー応答

- ローカルでルート作成が存在確認済み。モデルが利用不可の場合、`model_not_found` のような業務エラーが返されます。`404` ではありません。
- ローカルでルート参照が存在確認済み。存在しないタスクの場合は下記が返ります：

```json
{
  "code": "task_not_exist",
  "message": "task_not_exist",
  "data": null
}
```

<Note>
阿里百炼このパス群は「プロトコル互換移行」に最適です。リクエスト・レスポンスはオリジナル DashScope / 百炼のスタイルに近く、Crazyrouter の統一動画フォーマットとは異なります。また「Crazyrouter が阿里動画モデルを全て外部公開している」ことを意味するわけではありません。公開状況は現行料金表、モデルホワイトリスト、実際の運用状況に従います。
</Note>
