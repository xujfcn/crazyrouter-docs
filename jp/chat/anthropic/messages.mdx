# Claude ネイティブ形式

```
POST /v1/messages
```

本ページには、`2026-03-22` が Crazyrouter の本番環境でレビュー済みの Claude Messages の使用例のみを記載します。

現在の主な例示モデル：

- `claude-opus-4-8`
- `claude-opus-4-8`

## 認証

今回のレビューでは、以下の2つの記法がどちらも利用可能であることを確認しました：

```text
x-api-key: YOUR_API_KEY
```

```text
Authorization: Bearer YOUR_API_KEY
```

両方とも保持します：

```text
anthropic-version: 2023-06-01
```

---

## 基本的な会話

```bash cURL
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 128,
    "messages": [
      {
        "role": "user",
        "content": "Explain quantum computing in one sentence."
      }
    ]
  }'
```

現在、本番環境で返される主要な構造体は次のとおりです：

```json
{
  "type": "message",
  "content": [
    {
      "type": "text",
      "text": "..."
    }
  ]
}
```

## Function Calling

現在の本番環境では、Claude のツール呼び出しは `/v1/messages` を介して安定して `tool_use` を返します。

初回の連携テストでの推奨事項：

- 明示的に `tool_choice` を送信する
- プロンプト内で「必ずツールを呼び出すこと、直接回答しないこと」を明確に記載する

```bash cURL
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 256,
    "tools": [
      {
        "name": "get_time",
        "description": "Get the current time for a timezone",
        "input_schema": {
          "type": "object",
          "properties": {
            "timezone": {
              "type": "string"
            }
          },
          "required": ["timezone"]
        }
      }
    ],
    "tool_choice": {
      "type": "any"
    },
    "messages": [
      {
        "role": "user",
        "content": "Use the get_time tool for Asia/Shanghai. Do not answer directly."
      }
    ]
  }'
```

現在、本番検証で返される主要なフィールド：

```json
{
  "stop_reason": "tool_use",
  "content": [
    {
      "type": "tool_use",
      "name": "get_time",
      "input": {
        "timezone": "Asia/Shanghai"
      }
    }
  ]
}
```

## Extended Thinking

今回の本番レビューでは、`thinking` ブロックが返される組み合わせは明確に次のとおりです：

- `claude-opus-4-8`

ベーシック版 `claude-opus-4-8` では今回同等に明確な thinking ブロックが得られなかったため、ここではthinking能力を優先して記載します。

```bash cURL
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 320,
    "thinking": {
      "type": "enabled",
      "budget_tokens": 128
    },
    "messages": [
      {
        "role": "user",
        "content": "Which is larger, 9.11 or 9.9? Explain briefly."
      }
    ]
  }'
```

現在、実際の検証で返される主要なフィールド：

```json
{
  "content": [
    {
      "type": "thinking",
      "thinking": "..."
    },
    {
      "type": "text",
      "text": "..."
    }
  ]
}
```

<Warning>
  `thinking` を使用する場合は、`max_tokens` は必ず `budget_tokens` より大きくなければなりません。thinking トークンもコストに含まれます。
</Warning>

## 現時点の推奨事項

- 通常のテキスト会話：優先的に `claude-opus-4-8` を使用
- ツール呼び出し：優先的に `claude-opus-4-8` を使用し、初回の検証で `tool_choice` を追加
- thinking ブロックが必要な場合：優先的に `claude-opus-4-8` を使用
