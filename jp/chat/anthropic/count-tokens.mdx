# Claude トークン数の計測

```
POST /v1/messages/count_tokens
```

実際に `POST /v1/messages` を呼び出す前に、入力部分で消費されるトークン数をあらかじめ推定するためのものです。Claude CLI、Claude Code、予算管理やコンテキストのトリミングロジックに適しています。

## 認証

Anthropicスタイルのリクエストヘッダーを推奨します：

```http
x-api-key: YOUR_API_KEY
anthropic-version: 2023-06-01
```

また、標準的なBearer認証も使えますが、Anthropicエコシステムのクライアントは通常上記のヘッダーを使用します。

## リクエスト本文

リクエスト本文はClaude Messagesスタイルに準じます。通常、最小限必要なフィールドは以下の通りです：

- `model`
- `messages`

リクエスト内に`system`、`tools`、ツールの結果やテキストが含まれる場合も、推定に含まれます。

## リクエスト例

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/v1/messages/count_tokens   -H "Content-Type: application/json"   -H "x-api-key: YOUR_API_KEY"   -H "anthropic-version: 2023-06-01"   -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {"role": "user", "content": "hello"}
    ]
  }'
```

```python Python
import requests

resp = requests.post(
    "https://api.crazyrouter.com/v1/messages/count_tokens",
    headers={
        "x-api-key": "YOUR_API_KEY",
        "anthropic-version": "2023-06-01",
        "Content-Type": "application/json",
    },
    json={
        "model": "claude-opus-4-8",
        "messages": [
            {"role": "user", "content": "hello"}
        ],
    },
)

print(resp.json())
```

</CodeGroup>

## レスポンス例

```json
{
  "input_tokens": 4
}
```

## レスポンスフィールド

| フィールド | 型 | 説明 |
|------|------|------|
| `input_tokens` | integer | 現在のリクエストテキスト部分の推定入力トークン数 |
| `warning` | string | オプションの警告；リクエストに画像やファイルが含まれる場合、それらが推定に含まれていない旨を通知する場合があります |

## 制限事項

現在の実装で推定される主な項目：

- `system`
- `messages` のテキスト部分
- ツール定義およびツール結果に含まれるテキスト/JSON

<Warning>
リクエスト内に画像やファイルが含まれている場合、このAPIはそれらの画像／ファイルのトークンを`input_tokens`に含めません。その場合はレスポンスに`warning`が現れることがあり、実際の課金は推定値より高くなる可能性があります。
</Warning>

<Note>
このAPIが返すのはあくまでも推定値であり、最終的な決済値ではありません。実際の利用量は、モデルの呼び出し結果に基づいて決定されます。
</Note>
