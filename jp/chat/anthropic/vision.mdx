# Claude 画像理解

2026年3月23日までに、Crazyrouter本番環境ではClaudeの画像入力経路が2種類検証されています：

- ネイティブ `POST /v1/messages` + `type: "image"` + Base64 PNG
- OpenAI互換 `POST /v1/chat/completions` + `type: "image_url"` + data URL

---

## ネイティブ形式：`/v1/messages`

```bash
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 128,
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "image",
            "source": {
              "type": "base64",
              "media_type": "image/png",
              "data": "iVBORw0KGgoAAA..."
            }
          },
          {
            "type": "text",
            "text": "What color is this image?"
          }
        ]
      }
    ]
  }'
```

今回の本番環境チェックで返却されたもの：

- `model: "claude-opus-4-8"`
- `content[0].type = "text"`

---

## OpenAI互換形式：`/v1/chat/completions`

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {
        "role": "user",
        "content": [
          {"type": "text", "text": "What color is this image?"},
          {
            "type": "image_url",
            "image_url": {
              "url": "data:image/png;base64,iVBORw0KGgoAAA..."
            }
          }
        ]
      }
    ],
    "max_tokens": 128
  }'
```

2026年3月23日の本番環境実測では、モデルから返された`message.content`は通常の文字列で、画像色のテキスト説明が内容になっています。

<Note>
  現在ページではBase64 PNGとdata URLの2つの検証済み画像入力方式のみ記載しております。リモートURLや他の画像形式、複数画像入力の複雑なシーンについては今回再検証しておりません。
</Note>
