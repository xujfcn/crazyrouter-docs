# Claude PDF サポート

```
POST /v1/messages
```

2026年3月23日現在、Crazyrouter 本番環境で `claude-opus-4-8` は Messages API によって Base64 PDF を読み込み、テキスト要約を返すことが確認されています。

---

## 検証済みの最小リクエスト

```bash
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 512,
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "document",
            "source": {
              "type": "base64",
              "media_type": "application/pdf",
              "data": "JVBERi0xLjQK..."
            }
          },
          {
            "type": "text",
            "text": "Summarize the document in one sentence."
          }
        ]
      }
    ]
  }'
```

本番環境から実際に返却された主要な形式：

```json
{
  "model": "claude-opus-4-8",
  "content": [
    {
      "type": "text",
      "text": "The document is a simple Crazyrouter PDF test document..."
    }
  ]
}
```

<Note>
  このページでは、Base64 PDF の入力経路のみ再テスト済みとして保持しています。リモート URL、複数 PDF の比較、ストリーミング PDF 出力などの複雑なシナリオは、今回個別の再テストは行っていません。
</Note>
