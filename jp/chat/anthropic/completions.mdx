# Claude OpenAI 互換フォーマット

```
POST /v1/chat/completions
```

2026年3月23日時点、Crazyrouter 本番環境にて検証済み：

- `claude-opus-4-8` 非ストリーミングリクエストは `object: "chat.completion"` を返します
- `message` 現行の安定版には `role`、`content` を含みます
- ストリーミングリクエストは `chat.completion.chunk` を返します
- SSE は引き続き `data: [DONE]` で終了します

<Warning>
本ページは Claude が OpenAI Chat Completions 互換フォーマットでの一般的な対話パスについて説明しています。Claude のネイティブ `tool_use`、Claude Code、ならびにツール呼び出しを伴うエージェントプログラミングシナリオにおいては、[Claude ネイティブフォーマット](/jp/chat/anthropic/messages) の `POST /v1/messages` を優先的にご利用ください。OpenAI 互換フォーマットでは Claude ネイティブのツールブロックを同等にサポートする保証はありません。
</Warning>

---

## 非ストリーミングリクエスト

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {"role": "system", "content": "You are a concise assistant."},
      {"role": "user", "content": "Compare PostgreSQL and MySQL in one paragraph."}
    ],
    "max_tokens": 256,
    "temperature": 0.2
  }'
```

主なレスポンス形式：

```json
{
  "object": "chat.completion",
  "model": "claude-opus-4-8",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "PostgreSQL and MySQL are both popular..."
      }
    }
  ]
}
```

## ストリーミングリクエスト

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {"role": "user", "content": "Say hello in one sentence."}
    ],
    "max_tokens": 128,
    "stream": true
  }'
```

2026-03-23 の本番環境におけるストリーミングプローブの冒頭部分は以下の通りです：

```text
data: {"object":"chat.completion.chunk","model":"claude-opus-4-8","choices":[{"delta":{"role":"assistant"}}]}
data: {"object":"chat.completion.chunk","model":"claude-opus-4-8","choices":[{"delta":{"content":"Hello! ..."}}]}
data: [DONE]
```

<Note>
  Claude のネイティブ `thinking`、ネイティブツールブロックまたはドキュメント入力が必要な場合は、[Claude Messages](/jp/chat/anthropic/messages) のご利用を優先してください。
</Note>
