# Gemini ツール呼び出し

```
POST /v1beta/models/{model}:generateContent
```

2026年3月23日時点で、Crazyrouter 本番環境は `gemini-3.1-pro` を用いて以下の Gemini ネイティブツール機能を安定してトリガーできることを確認しています：

- `codeExecution`
- `googleSearch`
- `urlContext`
- `functionDeclarations`

<Note>
  本ページには本番環境で実際に成功したリクエスト形式とレスポンス識別のみを残しています。
</Note>

---

## コード実行

以下のリクエストは本番環境で `executableCode` と `codeExecutionResult` の2つの主要レスポンスブロックを返しました：

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "Use code execution. Compute the sum of the first 20 prime numbers and state the result."}
        ]
      }
    ],
    "tools": [
      {
        "codeExecution": {}
      }
    ]
  }'
```

本番環境で観測された主要レスポンス形式：

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "executableCode": {
              "language": "PYTHON",
              "code": "..."
            }
          },
          {
            "codeExecutionResult": {
              "outcome": "OUTCOME_OK",
              "output": "639\n"
            }
          },
          {
            "text": "The sum is 639."
          }
        ]
      }
    }
  ]
}
```

## Google検索

以下のリクエストは本番環境で `groundingMetadata` を返し、モデルが確かに Google Search をトリガーしたことを示しています：

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "Use Google Search. What are two AI news items from March 2026?"}
        ]
      }
    ],
    "tools": [
      {
        "googleSearch": {}
      }
    ]
  }'
```

現在これに基づいて確認可能：

- `candidates[0].groundingMetadata`
- 通常のテキスト回答は引き続き `candidates[0].content.parts[*].text` にあります

## URLコンテキスト

以下のリクエストは本番環境で `urlContextMetadata` を返し、かつ `groundingMetadata` も含まれています：

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "Use URL context to summarize https://example.com/ in one sentence."}
        ]
      }
    ],
    "tools": [
      {
        "urlContext": {}
      }
    ]
  }'
```

現在これに基づいて確認可能：

- `candidates[0].urlContextMetadata`
- `candidates[0].groundingMetadata`

## カスタム関数呼び出し

以下のリクエストは本番環境で `functionCall` を返しました：

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "What is the weather in Beijing? Use the provided function."}
        ]
      }
    ],
    "tools": [
      {
        "functionDeclarations": [
          {
            "name": "get_weather",
            "description": "Get weather info for a city",
            "parameters": {
              "type": "object",
              "properties": {
                "city": {
                  "type": "string"
                }
              },
              "required": ["city"]
            }
          }
        ]
      }
    ]
  }'
```

主要レスポンス形式：

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "functionCall": {
              "name": "get_weather",
              "args": {
                "city": "Beijing"
              }
            }
          }
        ]
      }
    }
  ]
}
```

関数結果の返却時は、引き続き Gemini ネイティブの `functionResponse` 構造体を利用できます。
