# Imagen 4

Google Imagen 4 はプロフェッショナル向けの画像生成モデルであり、Gemini API エンドポイントを通じて呼び出すことができます。

<Warning>
  Imagen 4 は現在開発中であり、機能や利用可能性は変更される可能性があります。
</Warning>

```
POST /v1beta/models/imagen-4:generateContent
```

---

## 基本的な使い方

<CodeGroup>

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/imagen-4:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "一只金色的拉布拉多犬在阳光明媚的草地上奔跑，摄影级画质，浅景深"}
        ]
      }
    ],
    "generationConfig": {
      "responseModalities": ["IMAGE"],
      "imageGenerationConfig": {
        "numberOfImages": 1,
        "aspectRatio": "16:9"
      }
    }
  }'
```

```python Python
import google.generativeai as genai
import base64

genai.configure(
    api_key="YOUR_API_KEY",
    transport="rest",
    client_options={"api_endpoint": "https://api.crazyrouter.com"}
)

model = genai.GenerativeModel("imagen-4")

response = model.generate_content(
    "一只金色的拉布拉多犬在阳光明媚的草地上奔跑，摄影级画质",
    generation_config=genai.GenerationConfig(
        response_modalities=["IMAGE"],
        image_generation_config={
            "number_of_images": 1,
            "aspect_ratio": "16:9"
        }
    )
)

for part in response.candidates[0].content.parts:
    if hasattr(part, "inline_data"):
        with open("imagen_output.png", "wb") as f:
            f.write(base64.b64decode(part.inline_data.data))
        print("图片已保存")
```

</CodeGroup>

### レスポンス形式

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "inlineData": {
              "mimeType": "image/png",
              "data": "iVBORw0KGgoAAAANSUhEUg..."
            }
          }
        ],
        "role": "model"
      },
      "finishReason": "STOP"
    }
  ]
}
```

---

## パラメータ説明

### imageGenerationConfig

| パラメータ | 型 | 説明 |
|------|------|------|
| `numberOfImages` | integer | 画像生成数、1-4 |
| `aspectRatio` | string | アスペクト比: `1:1`、`16:9`、`9:16`、`4:3`、`3:4` |

---

## 一括生成

```json
{
  "generationConfig": {
    "responseModalities": ["IMAGE"],
    "imageGenerationConfig": {
      "numberOfImages": 4,
      "aspectRatio": "1:1"
    }
  }
}
```

<Note>
  Imagen 4 は純粋な画像生成モデルであり、`responseModalities` を `["IMAGE"]` に設定してください。文字説明も同時に返したい場合は、Gemini 画像生成モデルをご利用ください。
</Note>

<Note>
  Imagen 4 のプロンプトは、より良い生成結果を得るため、スタイル・ライティング・構図など詳細な記述言語を使用することを推奨します。
</Note>
