# Gemini 画像編集

```
POST /v1/images/generations
```

Gemini / Nano Banana の画像編集は Crazyrouter で OpenAI Images 互換エンドポイントを通じて一元的に利用されます。デフォルトでは `image_input` の URL を使用します。特定のグレースケールアカウントでは dataURL、raw Base64、および `/v1/images/edits` マルチパート三画像編集もサポートされています。

<Warning>
  画像編集や複数参考画像を利用するリクエストは、通常処理に時間がかかります。商用環境ではメインラインの `https://api.crazyrouter.com/v1` を最優先で利用してください。完全なエンドポイントは `https://api.crazyrouter.com/v1/images/generations` です。
</Warning>

---

## 現在の推奨

1. 新規導入では `nano-banana-2` または `nano-banana-pro` を優先的に使用してください
2. 画像入力は `image_input` を利用し、URL または URL 配列で指定してください
3. Gemini 固有のフィールド（`generationConfig`、`imageConfig`、`imageOutputOptions` など）は送信しないでください
4. クライアント側のタイムアウトは 180 秒以上に設定することを推奨します

---

## リクエストテンプレート

以下は統一 Images API 経由で参考画像編集を行う最小限のリクエスト例です：

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-2",
    "prompt": "把参考图背景改成蓝色，保留主体结构和边缘细节",
    "image_input": [
      "https://example.com/reference.png"
    ],
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "png"
  }'
```
