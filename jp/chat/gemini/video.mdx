# Gemini ビデオ理解

```text
POST /v1beta/models/{model}:generateContent
```

`2026-04-08`時点で、Crazyrouter 本サイトとローカルの`4000`ポートで再検証した結果：

- `gemini-3.1-pro` は`video/mp4`を読み取ることができます
- 現在安定して稼働している主なルートは`fileData.fileUri`です
- 動画ファイルは、Geminiのアップストリームからアクセス可能なパブリックURLである必要があります

---

## 検証済みの最小リクエスト

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "fileData": {
              "mimeType": "video/mp4",
              "fileUri": "https://example.com/demo.mp4"
            }
          },
          {
            "text": "请用一句中文回答：视频里的主体是什么，如何运动，镜头是否固定。"
          }
        ]
      }
    ],
    "generationConfig": {
      "maxOutputTokens": 512
    }
  }'
```

本番環境で成功した同タイプの主要なレスポンス形式：

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "视频里的主体是一个红色小球，它从左向右滚动，镜头是固定的。"
          }
        ]
      }
    }
  ]
}
```

## リクエストの要点

- ビデオ理解の現在主推奨記述例は`fileData.fileUri`です
- `mimeType`は実際のファイルに沿って記入してください（例：`video/mp4`）
- `fileUri`はGeminiのアップストリームからアクセス可能でなければなりません
- ファイルがプライベートネットワーク内にある場合、認証が必要な場合、またはURLが直接接続できないと失敗しやすいです

<Note>
  画像理解は優先的に`inlineData`を使用し、画像の成功例をそのまま動画に転用しないでください。画像の詳細は [Gemini 画像理解](/jp/chat/gemini/vision) をご覧ください。
</Note>
