# Gemini ネイティブ形式

このページには、`2026-03-22` が Crazyrouter 本番環境で検証済みの Gemini ネイティブ利用方法のみを書いています。

現在の主なサンプルモデル：

- `gemini-3.1-pro`

成功リクエストの経験に基づき、マルチモーダルページを個別に整理しています：

- [Gemini 画像理解](/jp/chat/gemini/vision)
- [Gemini 映像理解](/jp/chat/gemini/video)
- [Gemini 音声理解](/jp/chat/gemini/audio)

## エンドポイント

```text
POST /v1beta/models/{model}:generateContent
POST /v1beta/models/{model}:streamGenerateContent
```

## 認証

URL パラメータとして API Key を渡します：

```text
?key=YOUR_API_KEY
```

---

## 基本文本生成

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Explain machine learning in one sentence."
          }
        ]
      }
    ],
    "generationConfig": {
      "maxOutputTokens": 128
    }
  }'
```

現在、本番環境で返される主要な構造：

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "...",
            "thoughtSignature": "..."
          }
        ]
      }
    }
  ]
}
```

## ストリーム生成

今回の検証で `streamGenerateContent` が SSE による増分コンテンツ返却が可能であることを確認しました。

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:streamGenerateContent?key=YOUR_API_KEY&alt=sse" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Write one short sentence about AI."
          }
        ]
      }
    ]
  }'
```

本番環境で受信された SSE フラグメントの形は以下のようになります：

```text
data: {"candidates":[{"content":{"parts":[{"text":"...","thoughtSignature":"..."}]}}]}
```

## 構造化出力

現在、本番環境で `responseMimeType + responseSchema` の利用が確認されています：

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Return a JSON object with keys city and country for Tokyo."
          }
        ]
      }
    ],
    "generationConfig": {
      "responseMimeType": "application/json",
      "responseSchema": {
        "type": "object",
        "properties": {
          "city": {"type": "string"},
          "country": {"type": "string"}
        },
        "required": ["city", "country"]
      }
    }
  }'
```

本番環境で検証済みの返却例：

```json
{"city":"Tokyo","country":"Japan"}
```

curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \

      {
        "googleSearch": {}

- `groundingMetadata.webSearchQueries`
- `groundingMetadata.groundingChunks`
- `groundingMetadata.groundingSupports`

## Thinking

現在、本番環境で `thinkingConfig` の利用が確認されています：

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Which is larger, 9.11 or 9.9? Explain briefly."
          }
        ]
      }
    ],
    "generationConfig": {
      "thinkingConfig": {
        "thinkingBudget": 256
      },
      "maxOutputTokens": 512
    }
  }'
```

本番環境で検証済みの主要な指標：

```json
{
  "usageMetadata": {
    "thoughtsTokenCount": 120
  }
}
```

## generationConfig よく使われるフィールド

| フィールド | 型 | 説明 |
|------|------|------|
| `maxOutputTokens` | integer | 出力トークン最大数 |
| `temperature` | number | サンプリング温度 |
| `responseMimeType` | string | 構造化出力時の MIME タイプ |
| `responseSchema` | object | 構造化出力制約 |
| `thinkingConfig` | object | 思考モード設定 |

<Note>
  Gemini ネイティブは `contents[].parts[]` 構造を採用しており、OpenAI の `messages` 構造ではありません。OpenAI 風に利用したい場合は、[Gemini OpenAI 互換形式](/jp/chat/gemini/openai-compat)をお使いください。
</Note>
