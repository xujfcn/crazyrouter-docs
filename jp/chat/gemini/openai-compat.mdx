# Gemini OpenAI 互換フォーマット

OpenAI Chat Completions 互換フォーマットを使用して Gemini を呼び出すことができます。

```
POST /v1/chat/completions
```

このページには、`2026-03-22` が Crazyrouter の本番環境で再検証された互換レイヤーの挙動のみが記載されています。

現在の主なサンプルモデル：

- `gemini-3.1-pro`

## 現時点での主な結論

今回の本番再検証で確認できた内容：

- `gemini-3.1-pro` は `/v1/chat/completions` との正常な会話が可能です
- ストリーミング応答は `chat.completion.chunk` の SSE 構造に対応しています
- Gemini の構造化出力、Google Search、thinking 等の機能が必要な場合は、引き続き [Gemini ネイティブフォーマット](/jp/chat/gemini/native) を優先して参照してください

---

## 基本的な会話

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gemini-3.1-pro",
    "messages": [
      {
        "role": "system",
        "content": "You are a concise assistant."
      },
      {
        "role": "user",
        "content": "Explain quantum entanglement in one sentence."
      }
    ],
    "max_tokens": 128
  }'
```

現在本番で検証された返却の重要な構造：

```json
{
  "object": "chat.completion",
  "model": "gemini-3.1-pro",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "..."
      }
    }
  ]
}
```

---

## Python サンプル

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="gemini-3.1-pro",
    messages=[
        {"role": "system", "content": "You are a concise assistant."},
        {"role": "user", "content": "Explain quantum entanglement in one sentence."}
    ],
    max_tokens=128
)

print(response.choices[0].message.content)
```

## ストリーミング出力

今回本番でもストリーミング互換応答を再検証しました：

```python Python
stream = client.chat.completions.create(
    model="gemini-3.1-pro",
    messages=[
        {"role": "user", "content": "Write one short sentence about AI."}
    ],
    max_tokens=64,
    stream=True
)

for chunk in stream:
    delta = chunk.choices[0].delta
    if delta.content is not None:
        print(delta.content, end="")
```

本番で受信したSSEフラグメントの形態例：

```text
data: {"object":"chat.completion.chunk","model":"gemini-3.1-pro",...}
data: {"choices":[{"delta":{"content":"..."}}],...}
data: [DONE]
```

## 互換フォーマットとネイティブフォーマット、どちらを使うべきか

- すでにOpenAI SDKの実装があり、標準的な会話機能だけが必要な場合：互換フォーマットを優先的に使用してください
- Geminiの構造化出力、Google Search、thinking、ネイティブフィールドなどが必要な場合：[Gemini ネイティブフォーマット](/jp/chat/gemini/native) を優先してください
