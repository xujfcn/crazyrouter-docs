# Gemini 画像生成

```
POST /v1/images/generations
```

Crazyrouter は、Gemini 画像モデル用に OpenAI Images 互換の統一エンドポイントを提供しています。ユーザー側は Gemini のネイティブ `generateContent` を直接呼び出す必要はなく、また Gemini のネイティブ `generationConfig.imageConfig` を送信する必要もありません。

| 推奨公開モデル名 | 互換ベースモデル名 |
|------|------|
| `nano-banana` | `nano-banana` |
| `nano-banana-pro` | `nano-banana-pro` |
| `nano-banana-2` | `nano-banana-2` |

<Warning>
  Gemini 画像生成は長時間処理が必要なリクエストです。商用接続の場合は主に推奨される経路 `https://api.crazyrouter.com/v1` をご利用ください。完全な生成エンドポイントは `https://api.crazyrouter.com/v1/images/generations` です。
</Warning>

<Note>
  クライアントコードでは `nano-banana`、`nano-banana-pro`、`nano-banana-2` の使用を推奨します。もしお使いのシステムで `nano-banana`、`nano-banana-pro`、`nano-banana-2` を既に直接ご利用中でも、同じ Images API エンドポイントで引き続きリクエスト可能です。
</Note>

## リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | `nano-banana`、`nano-banana-pro`、`nano-banana-2`、または対応する Gemini canonical 名 |
| `prompt` | string | はい | 生成または編集指示 |
| `image_input` | string または string[] | いいえ | 参照画像URL；未指定の場合はテキストから画像を生成します |
| `resolution` | string | いいえ | `1K`、`2K`、`4K` |
| `aspect_ratio` | string | いいえ | 例：`1:1`、`16:9`、`9:16`、`21:9`、`auto` |
| `output_format` | string | いいえ | `png`、`jpeg` / `jpg` |
| `output_compression` | integer | いいえ | `0-100`、JPEG 圧縮品質用 |
| `n` | integer | いいえ | 生成枚数、デフォルトは `1` |

これら上位供給元のプライベートフィールドは送信しないでください：`generationConfig`、`imageConfig`、`imageOutputOptions`、`image_output_options`。

## リクエスト例

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-2",
    "prompt": "A simple red square on a white background, clean vector style",
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "png"
  }'
```

レスポンスは OpenAI Images スタイルを維持します：

```json
{
  "created": 1778990000,
  "data": [
    {
      "url": "https://media.crazyrouter.com/task-artifacts/2026/05/17/sync-image/request-id-1.png"
    }
  ]
}
```

## 参照画像編集

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-pro",
    "prompt": "把参考图改成高级电商海报，保留主体，背景更简洁",
    "image_input": [
      "https://example.com/reference.png"
    ],
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "jpeg",
    "output_compression": 85
  }'
```

<Note>
  もし Gemini のネイティブ API 方式が必要な場合は、[Gemini ネイティブフォーマット](/jp/chat/gemini/native)をご参照ください。ただし画像生成および編集には、本ページの Images API をご利用いただくことを推奨します。
</Note>
