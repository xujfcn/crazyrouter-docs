# Gemini ドキュメント理解

```
POST /v1beta/models/{model}:generateContent
```

2026年3月23日現在、Crazyrouterの本番環境では `gemini-3.1-pro` に対応していることが確認されています：

- `inlineData` でPDFを読み込み
- `responseMimeType` + `responseSchema` の組み合わせで解析可能なJSONを出力

---

## PDF 要約

以下のリクエストでは、本番環境でPDFの読み取りと要約テキストの返却に成功しています：

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "Summarize the attached PDF in one sentence."},
          {
            "inlineData": {
              "mimeType": "application/pdf",
              "data": "JVBERi0xLjQK..."
            }
          }
        ]
      }
    ]
  }'
```

本番でのテストでは、モデルがPDFの内容について一文要約を正常に返しました。

---

## PDF + 構造化出力

以下のリクエストでは、本番環境で`json.loads()`できるJSONテキストが直接返されます：

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "Extract the key topic and whether the document mentions gamma."},
          {
            "inlineData": {
              "mimeType": "application/pdf",
              "data": "JVBERi0xLjQK..."
            }
          }
        ]
      }
    ],
    "generationConfig": {
      "responseMimeType": "application/json",
      "responseSchema": {
        "type": "object",
        "properties": {
          "topic": {"type": "string"},
          "mentions_gamma": {"type": "boolean"}
        },
        "required": ["topic", "mentions_gamma"]
      }
    }
  }'
```

本番環境で実際に返された例：

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "{\n  \"topic\": \"Crazyrouter PDF test document\",\n  \"mentions_gamma\": false\n}"
          }
        ]
      }
    }
  ]
}
```

対応するコードではそのまま解析可能です：

```python
import json

text = response["candidates"][0]["content"]["parts"][0]["text"]
data = json.loads(text)
```

<Note>
  このページでは、PDF入力とJSON構造化出力の2つの流れのみを確認しています。より複雑な表抽出や長文比較などの用途については、ご自身の実サンプルで本番検証されることをお勧めします。
</Note>

<Warning>
  大きなPDFは入力Token数が大幅に増加します。本格導入の前に、小さなドキュメントで項目やプロンプトを検証し、徐々に入力規模を拡大することを推奨します。
</Warning>
