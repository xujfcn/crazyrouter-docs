# Gemini 画像理解

```
POST /v1beta/models/{model}:generateContent
```

`2026-04-08` 時点で、Crazyrouter 当サイトとローカル `4000` ポート再検証の結果：

- `gemini-3.1-pro` は `inlineData` を通じて画像を安定して読み込んでテキスト説明を返すことができます
- リモート画像URL型の `fileData.fileUri` は複数の経路で取得失敗や上流のレスポンス異常などの問題が頻発しています
- そのため、画像理解では現時点で `inlineData` を推奨方式としています

---

## 検証済みの最小リクエスト

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "inlineData": {
              "mimeType": "image/png",
              "data": "BASE64_PNG_DATA"
            }
          },
          {
            "text": "请用一句中文描述这张图片里有什么。"
          }
        ]
      }
    ]
  }'
```

本番環境で実際に返される主要な形式：

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "这张图片展示了多种鲜艳色彩平滑过渡的渐变效果。"
          }
        ]
      }
    }
  ]
}
```

## リクエスト要点

- 画像理解には `inlineData` を優先して用いてください
- `mimeType` は実際の画像フォーマットに合わせて、例えば `image/png` や `image/jpeg` のように設定しましょう
- `data` にはBase64の内容のみ入力し、`data:image/...;base64,` プレフィックスは含めないでください
- 手元にリモート画像URLしかない場合、現在はそれをGemini画像理解のメイン方式として選ばないでください

<Note>
  動画理解をしたい方は [Gemini 動画理解](/jp/chat/gemini/video) へ。音声理解をしたい方は [Gemini 音声理解](/jp/chat/gemini/audio) をご覧ください。
</Note>
