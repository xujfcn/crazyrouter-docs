# 作成完了 (レガシー)

```
POST /v1/completions
```

<Warning>
  これは互換性のためのエンドポイントであり、現在の主要な推奨ルートではありません。新規利用の場合は、優先して `/v1/chat/completions` または `/v1/responses` をご利用ください。
</Warning>

## 現在の運用状況

2026年3月23日現在、Crazyrouter の本番環境では次のことが確認されています：

- ルートは依然として利用可能です
- クラシックサンプルモデル `gpt-5-mini` でリクエストを送信すると、`503` が返されます
- エラーコードは `model_not_found` です
- エラーメッセージは「temporarily unavailable」です

つまり、このエンドポイントは「旧クライアントとの互換性テスト用途」に限定し、標準の新規導入策としては推奨されません。

---

## 現時点での推奨

1. 新しいプロジェクトでは [`Chat Completions`](/jp/chat/openai/completions) を直接ご利用ください
2. GPT-5 推論や Web Search など新機能が必要な場合は、優先して [`Responses`](/jp/chat/responses/overview) をご利用ください
3. 既存の旧版クライアントがあり、かつご自身が所有するレガシーモデルが現環境で利用可能と確認できている場合のみ、`/v1/completions` の検証を続けてください

---

## Retest テンプレート

古いモデルがこのエンドポイントで動作するか検証が必要な場合は、まず [`/v1/models`](/jp/chat/openai/models) でモデルIDを確認し、最小限のリクエストを実施してください：

```bash
curl https://api.crazyrouter.com/v1/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "YOUR_LEGACY_MODEL",
    "prompt": "Say hello in three words.",
    "max_tokens": 16
  }'
```

本番環境で実際に発生したエラー例：

```json
{
  "error": {
    "code": "model_not_found",
    "message": "Model gpt-5-mini is temporarily unavailable",
    "type": "new_api_error"
  }
}
```
