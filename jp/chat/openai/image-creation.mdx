# チャット画像生成

```
POST /v1/chat/completions
```

2026年3月23日現在、Crazyrouter本番環境での検証結果は以下の通りです：

- `gpt-4o`は`200`を返しますが、`message.content`は標準のマルチパート画像コンテンツではなく、プレーンテキストです
- `gpt-image-2`も`200`を返しますが、現状のレスポンス形式はまだ標準OpenAI `image_url`マルチパート構造ではなく、テキストやパラメータブロック・ID・プレビューリンクを含むMarkdownです
- 機械読み取り可能な安定した画像出力が必要な場合、現在推奨されるパスは[`/v1/images/generations`](/jp/images/gpt-image)の`gpt-image-2`です。Grok画像モデルの場合は、[`Grok Image Models`](/jp/images/grok)をご参照ください
- 参照画像編集や複数画像入力が必要な場合は、Nano Bananaファミリーの`/v1/images/generations`エントリポイントを安定ルートとして使い続けないでください。まずは[`Nano Banana 2`](/jp/images/nano-banana-2)に記載されたGeminiネイティブパスをお試しください。[`Nano Banana`](/jp/images/nano-banana)は現在コントロールテスト中です

<Warning>
  現在のCrazyrouterのchat-imageレスポンスを標準OpenAI `content: [{type: "image_url", ...}]`としてパースしないでください。
</Warning>

## 現在再現可能なチャット挙動

以下のリクエストが本番環境の`gpt-image-2`を通り、`200`を返しました：

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "messages": [
      {
        "role": "user",
        "content": "Generate an image of a red square on a white background."
      }
    ],
    "max_tokens": 512
  }'
```

観察された`message.content`は、以下のようなおおよその形の文字列でした：

```text
{
  "prompt": "Generate an image of a red square on a white background.",
  "ratio": "1:1",
  "n": 1
}

ID: ...
Data Preview: https://...
```

つまり、現行のチャットパスは標準化されたマルチパート画像メッセージオブジェクトというよりも、テキストにラップされた画像タスク出力のように振る舞っています。

## 安定ルート: Images API

プログラム経由で画像取得が必要な場合には、次を利用してください：

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A red square on a white background",
    "size": "1024x1024",
    "quality": "low",
    "output_format": "png"
  }'
```

現在の`gpt-image-2`の安定ルートは、主要な画像ルート`https://api.crazyrouter.com/v1`を使用しています。レスポンスには通常以下が含まれます：

- `data[0].url`

`gpt-image-2`は、`response_format="url"`および`response_format="b64_json"`をレガシー互換フィールドとして受け付けますが、新規統合では`output_format="png"`、`"jpeg"`、または`"webp"`で画像ファイル形式を選択してください。

したがって、安定した自動化ルートは引き続きImages APIであり、chat-image互換パスではありません。

<Note>
  手動テストのみ行う場合は`gpt-image-2`チャットパスも観察用として有効です。バックエンド自動化や保存、後処理が必要な場合は、[`GPT Image docs`](/jp/images/gpt-image)または[`Grok Image Models`](/jp/images/grok)をご利用ください。参照画像編集または複数画像入力依存のワークロードの場合は、まず[`Nano Banana 2`](/jp/images/nano-banana-2)に記載されたGeminiネイティブルートをご参照ください。Nano Bananaファミリーの`/v1/images/generations`を安定推奨ルートとして使い続けないでください。
</Note>
