# チャット画像認識

```
POST /v1/chat/completions
```

Crazyrouter本番環境では、OpenAIスタイルの`image_url`入力を用いた以下の主要モデルが検証済みです：

- `gpt-4o`、`gpt-4o-mini`、`gpt-5.5`、`gpt-5.5` などのOpenAIビジョンモデル
- 入力は`data:image/...;base64,...` data URLと公開`https://` URLの2つの形式をサポート
- 返却される`message.content`は現状、普通の文字列です

> 推奨手順：ローカル画像はまず[画像アップロードAPI](/jp/upload)で`media.crazyrouter.com`の一時URLに変換してから`image_url`へ渡してください。または直接base64 data URLを送信することも可能です。リモートの公開URLも利用できますが、以下の「リモートURL制限」を満たす必要があります。

---

## base64 data URLを使う（最も安定）

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": [
          {"type": "text", "text": "What color is this image?"},
          {
            "type": "image_url",
            "image_url": {
              "url": "data:image/png;base64,iVBORw0KGgoAAA..."
            }
          }
        ]
      }
    ],
    "max_tokens": 100
  }'
```

返却例：

```json
{
  "model": "gpt-4o-mini",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "Red."
      }
    }
  ]
}
```

---

## リモートhttps URLを使う

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": [
          {"type": "text", "text": "Describe in 5 words."},
          {
            "type": "image_url",
            "image_url": {
              "url": "https://www.gstatic.com/webp/gallery/1.jpg"
            }
          }
        ]
      }
    ],
    "max_tokens": 40
  }'
```

### リモートURL制限

URLは**Crazyrouterサーバーがアクセスできる**画像アドレスである必要があり、「ブラウザで開ける」だけでは十分ではありません。よくある失敗パターンは以下の通りです：

| 失敗パターン | 原因 | 解決方法 |
|--------------|-------|-----------|
| ドメイン解決不可 | プライベートネットワークアドレス、綴り間違い | 公開https URLに変更 |
| 403 Forbidden | 一部CDN（例：wikimedia、プライベートS3）がサーバーのUA/Refererを制限 | [画像アップロードAPI](/jp/upload)かbase64利用 |
| Content-Typeが`image/*`ではない | URLがHTMLページやログインページへのリダイレクト | 直リンクでダウンロード可能なURLを確認 |
| ファイルサイズ20MB超 | 単体ファイルサイズ上限 | 圧縮またはトリミングして再アップロード |

もし`Unable to process the image you provided. Please verify the image URL is publicly accessible, or upload it as base64.`というエラーが表示された場合は、URLがサーバー側で到達不能な状態です。上記表を参照してご確認ください。

---

## 推奨運用

- 内部素材・非公開画像・到達性が不明な画像：まず[`POST /v1/files/uploads`](/jp/upload)を呼び出して`media.crazyrouter.com/...`の72時間限定URLを取得し、それを`image_url`に渡してください
- 小さい画像（< 1MB）や一時利用画像：直接base64 data URLを使い、追加のアップロードリクエストを省略
- 複数画像や`detail`パラメータなど上級用途：現在、OpenAI公式でも対応しているため、OpenAIの公式プロトコルに従って送信してください
