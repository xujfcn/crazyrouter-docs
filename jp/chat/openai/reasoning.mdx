# 推論モデル

このページでは、`2026-03-22` 上の Crazyrouter 本番環境で再検証された推論挙動のみを記載しています。

OpenAI 互換統合の場合、現在のガイダンスは以下の通りです：

- より強力な推論だけを求め、最終的な回答だけが必要な場合は、`reasoning_effort` で Chat Completions を使用してください。
- 安定した検証可能な推論出力が必要な場合は、Responses API を推奨し、[GPT-5 思考モード](/jp/chat/responses/gpt5-thinking)を参照してください。

## 検証済みの組み合わせ

| ルート | モデル | リクエストパラメータ | 現在の本番挙動 |
|-------|-------|-------------------|-----------------------------|
| Chat Completions | `gpt-5.5` | `reasoning_effort` | リクエストが成功し、最終回答が返されます |
| Responses | `gpt-5.5` | `reasoning.effort` / `reasoning.summary` | `output` に `reasoning` および `message` が含まれます |

---

## Chat Completions: `reasoning_effort`

現在本番環境で動作するリクエスト形式：

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Which is larger, 9.11 or 9.9? Explain briefly."
      }
    ],
    "reasoning_effort": "high",
    "max_tokens": 120
  }'
```

利用可能な `reasoning_effort` の値：

| 値 | 意味 |
|-------|---------|
| `low` | 単純なタスク向けに素早い応答 |
| `medium` | バランスのとれたデフォルト設定 |
| `high` | 難しいタスク向けに推論を強化 |

### 現在の応答挙動

`2026-03-22` 本番再検証では：

- リクエストが成功しました
- 最終回答が `message.content` に返されました
- `message.reasoning_content` には有用な内容が確実に含まれていませんでした

そのため、より強力な推論だけを求める場合は、`reasoning_effort` の Chat Completions でも利用可能です。推論サマリーフィールドが必要な場合は、Chat Completions を主な方法として使わないでください。

---

## 検証可能な推論出力が必要な場合

より信頼性の高い本番経路は Responses API です：

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Which is larger, 9.11 or 9.9? Explain briefly.",
    "reasoning": {
      "effort": "high",
      "summary": "detailed"
    }
  }'
```

検証済み `output.type` 値：

```json
["reasoning", "message"]
```

具体的な応答形式、サマリーフィールド、ストリーミングイベント名については、以下を参照してください：

- [GPT-5 思考モード](/jp/chat/responses/gpt5-thinking)
- [AI 思考フィールド](/jp/reference/thinking)

---

## 現在の推奨

- 推論サマリーの記録や表示が必要な新しいビルドには、Responses API から始めてください
- 最終回答だけが必要な既存 Chat Completions 統合には、`reasoning_effort` も依然として有効な経路です
- すべての OpenAI 互換推論モデルが必ずしも `reasoning_content` を確実に出力するとは限らないことに注意してください

<Warning>
  推論リクエストは通常、レイテンシーとトークン使用量の両方が増加します。高い `reasoning_effort` は通常コストも高くなります。
</Warning>
