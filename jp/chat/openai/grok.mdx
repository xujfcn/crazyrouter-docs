# Grok モデル

```
POST /v1/chat/completions
```

Grok テキストモデルは OpenAI Chat Completions 互換フォーマットで呼び出します。`base_url` を Crazyrouter に設定し、`model` に Grok モデル ID を入力するだけで利用できます。

<Note>
  モデルの利用可能性は、チャネル、トークン権限、および pricing ページの設定によって変動します。正式リリース前には、まず `GET /v1/models` で現在の API Key がご希望のモデルを参照できるか確認することをおすすめします。
</Note>

## よく使われるモデル

現在主流の Grok テキストモデル書式は以下の通りです：

| モデル | 説明 |
|------|------|
| `grok-4` | Grok 4 メインモデル |
| `grok-4-fast` | Grok 4 fast バリアント |
| `grok-4-fast-non-reasoning` | Grok 4 fast 非推論バリアント |
| `grok-4-fast-reasoning` | Grok 4 fast 推論バリアント |
| `grok-4.1` | Grok 4.1 |
| `grok-4.1-fast` | Grok 4.1 fast |
| `grok-4.1-fast` | Grok 4.1 thinking |
| `grok-4.1-fast` | Grok 4.2 |
| `grok-4-0709` | Grok 4 日付バージョン |

<Warning>
  古い `grok-4` / `grok-4.1` 系列は、歴史的な呼び出しまたは下位互換の設定で参照されることがありますが、現在公開されている pricing では主に `grok-4*` 系列が維持されています。新規接続の場合は `grok-4`、`grok-4.1`、`grok-4.1-fast` や fast/reasoning バリアントを優先してください。
</Warning>

## 最小リクエスト

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "grok-4",
    "messages": [
      {
        "role": "user",
        "content": "Reply with one short sentence: what is Grok?"
      }
    ],
    "temperature": 0.7,
    "max_tokens": 120
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.chat.completions.create(
    model="grok-4",
    messages=[
        {"role": "user", "content": "Reply with one short sentence: what is Grok?"}
    ],
    temperature=0.7,
    max_tokens=120,
)

print(response.choices[0].message.content)
```

```javascript Node.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.crazyrouter.com/v1",
});

const response = await client.chat.completions.create({
  model: "grok-4",
  messages: [
    { role: "user", content: "Reply with one short sentence: what is Grok?" },
  ],
  temperature: 0.7,
  max_tokens: 120,
});

console.log(response.choices[0].message.content);
```

</CodeGroup>

## ストリーミング出力

`stream: true` をセットすることで SSE ストリーミング出力が利用できます。

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "grok-4-fast",
    "stream": true,
    "messages": [
      {
        "role": "user",
        "content": "Write a concise API migration checklist."
      }
    ]
  }'
```

## 推論バリアント

モデル名に `reasoning` または `thinking` を含む Grok モデルには、なるべくシンプルなリクエストパラメータを使用することを推奨します：

```json
{
  "model": "grok-4-fast-reasoning",
  "messages": [
    {
      "role": "user",
      "content": "Compare two implementation options and explain the tradeoffs."
    }
  ],
  "max_tokens": 800
}
```

<Note>
  上流のチャネルによっては、推論フィールド・検索フィールド・実験的なパラメータのサポート状況が異なる場合があります。複数チャネルで安定的な利用を目指す際は、標準的な OpenAI Chat フィールド（`model`、`messages`、`temperature`、`top_p`、`max_tokens`、`stream`）の優先利用を推奨します。
</Note>
