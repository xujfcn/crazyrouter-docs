# モデル一覧

```
GET /v1/models
```

現在の API Key で利用可能なモデルの一覧を返します。

このページには `2026-04-14` が Crazyrouter 本番環境でレビュー済みの動作のみを記載しています。

## 認証

```text
Authorization: Bearer YOUR_API_KEY
```

## リクエスト例

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

models = client.models.list()

for model in models.data:
    print(model.id)
```

```javascript Node.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.crazyrouter.com/v1",
});

const models = await client.models.list();

for (const model of models.data) {
  console.log(model.id);
}
```

</CodeGroup>

## よく見るフィールド

| フィールド | 型 | 説明 |
|------|------|------|
| `success` | boolean | リクエストが成功したかどうか |
| `id` | string | API 呼び出し時に渡されたモデル識別子 |
| `object` | string | `model` で固定 |
| `created` | integer | タイムスタンプ |
| `owned_by` | string | モデルの所属組織または出所識別子 |

## 価格情報

公共の価格情報については、[Pricing ページ](https://crazyrouter.com/ja/pricing) をご参照ください。プログラム側で現在のトークンで表示可能なモデルを確認する場合は、本ページの `GET /v1/models` を引き続きご利用ください。

<Note>
  `GET /v1/models` の返す `supported_endpoint_types` は、現在のモデルがサポートするインターフェース様式を示すだけです。このうち `openai` が `POST /v1/chat/completions` に、`anthropic` が `POST /v1/messages` に対応し、`openai-response` のみが `POST /v1/responses` に対応します。Claude は現在公開されているものとしては `openai` + `anthropic` をサポートし、`openai-response` はサポートしていません。
</Note>
