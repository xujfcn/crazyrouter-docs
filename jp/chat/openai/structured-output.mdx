# 構造化出力

```
POST /v1/chat/completions
```

2026年3月23日現在、Crazyrouter本番環境では、`gpt-5.5`が`response_format.type = "json_schema"`と共に、直接パース可能なJSONを返すことが確認されています。

---

## 推奨パス: `json_schema`

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Return the people and roles from: Alice is CTO. Bob is PM."
      }
    ],
    "response_format": {
      "type": "json_schema",
      "json_schema": {
        "name": "people_roles",
        "strict": true,
        "schema": {
          "type": "object",
          "properties": {
            "people": {
              "type": "array",
              "items": {
                "type": "object",
                "properties": {
                  "name": {"type": "string"},
                  "role": {"type": "string"}
                },
                "required": ["name", "role"],
                "additionalProperties": false
              }
            }
          },
          "required": ["people"],
          "additionalProperties": false
        }
      }
    }
  }'
```

実際の本番`message.content`は、次のように直接パースされました:

```json
{
  "people": [
    {
      "name": "Alice",
      "role": "CTO"
    },
    {
      "name": "Bob",
      "role": "PM"
    }
  ]
}
```

---

## コンシューマー側での処理

```python
import json

content = response["choices"][0]["message"]["content"]
data = json.loads(content)
```

<Note>
  この本番更新では厳密な`json_schema`パスのみが再検証されています。従来の`json_object`モードは個別には再チェックされていないため、ここではもはや主要な例としては掲載していません。
</Note>
