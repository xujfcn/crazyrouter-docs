# チャット補完の作成

```
POST /v1/chat/completions
```

入力されたメッセージリストに基づいてモデルの返信を生成し、非ストリーミング応答およびストリーミング応答の両方をサポートします。

このページでは `2026-03-23` が Crazyrouter のプロダクション環境でレビューされた汎用動作のみを記載しています。

## 認証

```text
Authorization: Bearer YOUR_API_KEY
```

## コアパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | モデル名。例：`gpt-5.5`、`claude-opus-4-8`、`gemini-3.1-pro` |
| `messages` | array | はい | メッセージリスト |
| `stream` | boolean | いいえ | ストリーム出力を有効にするかどうか |
| `max_tokens` | integer | いいえ | 最大出力トークン数 |
| `temperature` | number | いいえ | サンプリング温度 |
| `response_format` | object | いいえ | 構造化出力フォーマット制約 |
| `tools` | array | いいえ | ツールリスト |
| `tool_choice` | string\|object | いいえ | ツール選択戦略 |
| `stream_options` | object | いいえ | ストリーミング追加オプション。例：`include_usage` |

<Note>
  モデルによってオプションパラメータのサポート状況は異なります。クライアント実装時は汎用フィールドを優先して利用し、全てのモデルが同じ上位パラメータ群を完全にサポートしていると仮定しないでください。
</Note>

## 非ストリーミングリクエスト

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "system",
        "content": "You are a helpful assistant."
      },
      {
        "role": "user",
        "content": "Explain artificial intelligence in one sentence."
      }
    ],
    "max_tokens": 64
  }'
```

現在のプロダクションで返却される典型的な構造：

```json
{
  "object": "chat.completion",
  "model": "gpt-5.5",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "...",
        "reasoning_content": null,
        "tool_calls": null
      },
      "finish_reason": "stop"
    }
  ]
}
```

### 特にご注意ください

- `message.content` が最も安定した最終テキストフィールドです
- `message.tool_calls` はツール呼び出し時のみ出現します
- `message.reasoning_content` はキーが存在することがありますが、現時点では安定して必ず内容があるとは限りません

## ストリーミングリクエスト

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Explain AI in one short sentence."
      }
    ],
    "stream": true,
    "stream_options": {
      "include_usage": true
    },
    "max_tokens": 64
  }'
```

今回のプロダクションレビューで確認された事項：

- ストリーミングは `chat.completion.chunk` を返します
- SSE は `data: ...` の形式で一塊ずつ送信されます
- ストリーム終了時も引き続き `data: [DONE]` です

現在受信される SSE フラグメントは以下のような形です：

```text
data: {"object":"chat.completion.chunk","model":"gpt-5.5","choices":[{"delta":{"role":"assistant","content":"AI","reasoning_content":null,"tool_calls":null}}]}
```

```text
data: [DONE]
```

## Python サンプル

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

stream = client.chat.completions.create(
    model="gpt-5.5",
    messages=[
        {"role": "user", "content": "Explain AI in one short sentence."}
    ],
    stream=True,
    stream_options={"include_usage": True},
    max_tokens=64
)

for chunk in stream:
    delta = chunk.choices[0].delta
    if delta.content is not None:
        print(delta.content, end="")
```

## 現時点での推奨

- 通常のテキスト会話：`/v1/chat/completions`
- reasoning 要約や OpenAI スタイルの web 検索が必要な場合：優先的に `/v1/responses` を使用
- より高度な能力判断が必要な場合は、必ず対応する能力ページを参照し、このページのみを参考にしないでください
