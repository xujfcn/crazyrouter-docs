# レスポンスWeb検索

```
POST /v1/responses
```

2026年3月23日現在、Crazyrouter本番環境にて、`gpt-5.5`は以下を用いてResponses APIで検証されています:

- `tools: [{ "type": "web_search_preview" }]`
- `output`のシーケンスと、その後に`web_search_call`、`message`

<Note>
  Claudeは現在、`POST /v1/responses`をサポートしていません。ClaudeのWeb検索を利用する場合は、`POST /v1/chat/completions`またはネイティブなClaudeパスをご利用ください。
</Note>

---

## 最小リクエスト

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Find one AI news item from March 2026.",
    "tools": [
      {
        "type": "web_search_preview"
      }
    ]
  }'
```

本番環境で観測されたレスポンスの形状:

```json
{
  "output": [
    {
      "type": "web_search_call"
    },
    {
      "type": "message"
    }
  ]
}
```

---

## 現行の検証ルール

モデルが実際にWeb検索を行ったかどうかを確認したい場合、現時点で最も安全なチェック方法は次の通りです:

- `web_search_call`が`output`に現れるかどうか
- 最終回答が依然として`message`として到着するかどうか

  このページでは、古くなった過去の例は保存しておらず、再検証されていない検索パラメータについても現行の主要パスとしては記載していません。
</Warning>
