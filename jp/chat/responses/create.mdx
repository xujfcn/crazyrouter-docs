# レスポンスの作成

```
POST /v1/responses
```

2026年3月23日現在、Crazyrouter本番環境による検証結果:

- `gpt-5.5`は`object: "response"`を返します
- 基本的なテキストリクエストは、現在`message`型の`output`アイテムを返します
- ストリーミングリクエストは、一貫して`response.created`、`response.in_progress`、`response.output_item.added`、`response.content_part.added`、および`response.output_text.delta`を公開します

<Note>
  Claudeは現在`POST /v1/responses`をサポートしていません。Claudeを使用する場合は、`POST /v1/messages`または`POST /v1/chat/completions`をご利用ください。
</Note>

---

## 基本リクエスト

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Explain what an API is in one sentence."
  }'
```

本番環境で観測されたレスポンス構造:

```json
{
  "object": "response",
  "model": "gpt-5.5",
  "output": [
    {
      "type": "message"
    }
  ]
}
```

## ストリーミングリクエスト

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Say hello in one sentence.",
    "stream": true
  }'
```

2026年3月23日に本番環境ストリーミングプローブで観測されたオープニングイベントの順序:

```text
event: response.created
event: response.in_progress
event: response.output_item.added
event: response.content_part.added
event: response.output_text.delta
```

そのため、現在最も安全なコンシューマ戦略は以下の通りです:

1. `response.output_text.delta`からテキストを蓄積する
2. `response.completed`またはストリームの終了を完了シグナルとみなす

## 現在の推奨事項

- 新しいGPTテキスト連携は`/v1/responses`上の`gpt-5.5`で始めてください
- ツールの利用には、[Responses Function Calling](/jp/chat/responses/function-calling)を継続してください
- ライブウェブアクセスには、[Responses Web Search](/jp/chat/responses/web-search)を継続してください
- 可視化された推論マーカーには、[GPT-5 Thinking](/jp/chat/responses/gpt5-thinking)を継続してください
