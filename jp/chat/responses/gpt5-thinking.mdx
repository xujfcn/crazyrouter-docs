# GPT-5 推論モード

このページでは、`2026-03-22` 上で Crazyrouter 本番環境にて再検証された GPT 推論動作のみを記載しています。

現在の主要な例は以下を使用しています:

- `gpt-5.5`
- `POST /v1/responses`

<Note>
  Claudeは現在、`POST /v1/responses` をサポートしていません。Claude を統合する場合は、本ページのリクエスト形状の代わりに `POST /v1/messages` または `POST /v1/chat/completions` をご利用ください。
</Note>

```
POST /v1/responses
```

## 基本的な使い方

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Which is larger, 9.11 or 9.9? Explain briefly.",
    "reasoning": {
      "effort": "high",
      "summary": "detailed"
    }
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.responses.create(
    model="gpt-5.5",
    input="Which is larger, 9.11 or 9.9? Explain briefly.",
    reasoning={
        "effort": "high",
        "summary": "detailed"
    }
)

print(response.output_text)
```

```javascript Node.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.crazyrouter.com/v1",
});

const response = await client.responses.create({
  model: "gpt-5.5",
  input: "Which is larger, 9.11 or 9.9? Explain briefly.",
  reasoning: {
    effort: "high",
    summary: "detailed",
  },
});

console.log(response.output_text);
```

## 検証済みレスポンス形式

検証済み `output.type` の値:

```json
["reasoning", "message"]
```

一般的な `reasoning` アイテムの形:

```json
{
  "id": "rs_xxx",
  "type": "reasoning",
  "encrypted_content": "...",
  "summary": [
    {
      "type": "summary_text",
      "text": "..."
    }
  ]
}
```

最終的な回答は `message` アイテムを通じて返されます:

```json
{
  "type": "message",
  "content": [
    {
      "type": "output_text",
      "text": "..."
    }
  ]
}
```

---

## `reasoning` パラメータ

| フィールド | 型 | 説明 |
|-------|------|-------------|
| `effort` | string | 推論強度。検証済み値は `low`、`medium`、`high` など |
| `summary` | string | 要約粒度。`concise` と `detailed` が再検証されました |

### 実践的なルール

- より強い推論のみが必要な場合は、`effort` を送信してください
- 検証可能な推論要約が必要な場合は、`effort` と `summary` の両方を送信してください

現在の再確認では:

- `effort` のみの場合、`reasoning` アイテムは存在しますが `summary` は空配列となることもあります
- `summary: "detailed"` の場合、`summary_text` が安定して返されました

## 推論要約の抽出

```python Python
response = client.responses.create(
    model="gpt-5.5",
    input="Design a high-concurrency message queue architecture.",
    reasoning={
        "effort": "high",
        "summary": "detailed"
    }
)

for item in response.output:
    if item.type == "reasoning":
        for part in item.summary:
            if part.type == "summary_text":
                print("Thinking summary:", part.text)
    elif item.type == "message":
        for content in item.content:
            if content.type == "output_text":
                print("Final answer:", content.text)
```

## 推論のストリーミング

以下の Responses SSE イベント名が本番環境で再検証されました:

- `response.reasoning_summary_part.added`
- `response.reasoning_summary_text.delta`
- `response.reasoning_summary_text.done`
- `response.output_text.delta`
- `response.output_text.done`
- `response.completed`

例:

```python Python
stream = client.responses.create(
    model="gpt-5.5",
    input="Explain briefly why 9.9 is larger than 9.11.",
    reasoning={
        "effort": "high",
        "summary": "detailed"
    },
    stream=True
)

for event in stream:
    if event.type == "response.reasoning_summary_text.delta":
        print(f"[Thinking summary] {event.delta}", end="")
    elif event.type == "response.output_text.delta":
        print(event.delta, end="")
```

## 現時点での推奨

- 推論フィールドを表示したい場合は Responses API で `gpt-5.5` を推奨します
- `gpt-5.5` Chat Completions `reasoning_content` を現在の主要な契約として扱わないでください
- 最終回答のみが必要な場合は、`reasoning_effort` を用いた Chat Completions で問題ありません

<Warning>
  推論モードは遅延とトークンの使用量がともに増加します。高い `effort` ほど、一般にコストも高くなります。
</Warning>
