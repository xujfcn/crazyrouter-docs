# レスポンス API 概要

レスポンス API は、現在 Crazyrouter上の最新GPT機能の主なルートの一つです。

このページは、`2026-03-22`で運用環境にて再検証された結論のみを記載しています。

<Note>
  現在運用環境で確認された範囲では、Claudeは`POST /v1/messages`と`POST /v1/chat/completions`のみ対応しており、`POST /v1/responses`には対応していません。レスポンスページはGPT優先のガイダンスとして扱ってください。
</Note>

## 現在の位置付け

- 検証可能な推論出力が必要な場合、`/v1/responses`を推奨します
- OpenAIスタイルのウェブ検索が必要な場合、`/v1/responses`を推奨します
- 通常のチャットのみ必要、または既存の連携を維持したい場合は`/v1/chat/completions`も問題ありません

## レスポンス APIとChat Completions APIの比較

| 次元 | レスポンス API | Chat Completions API |
|-----------|---------------|----------------------|
| エンドポイント | `/v1/responses` | `/v1/chat/completions` |
| 入力形式 | `input` | `messages` |
| 出力形式 | `output[]` アイテムリスト | `choices[].message` |
| GPT推論 | 検証済み`reasoning`アイテム | `reasoning_effort`は動作するが`reasoning_content`は安定しません |
| OpenAIスタイルのウェブ検索 | 検証済み`web_search_preview`パス | 旧型`web_search`形式では安定した検証可能なトリガーはこのラウンドでは得られませんでした |
| ストリーミング | より多様なイベントタイプ | 従来のデルタSSE |

## 最小限の有用な例

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.responses.create(
    model="gpt-5.5",
    input="Explain what a REST API is in one sentence."
)

print(response.output_text)
```

現在の運用環境で再確認した際、この最小限のリクエストは以下を返しました：

```json
{
  "object": "response",
  "output": [
    {
      "type": "message"
    }
  ]
}
```

## レスポンスを選ぶべきケース

- `gpt-5.5`の推論要約が必要な場合
- モデルが実際に`web_search_call`をトリガーしたか検証したい場合
- より多様なSSEイベントが欲しい場合

## Chat Completionsを維持すべきケース

- 既に安定したChat Completions連携がある場合
- 最終回答だけ気にしており、`reasoning`アイテムは不要な場合
- Claude、Gemini、その他OpenAI互換モデルを統合している場合

<Note>
  両APIは同一プロジェクト内で共存可能です。実際には、最良のパターンは完全な移行ではなく、新機能が必要なリクエストのみを`/v1/responses`へ移行するのが一般的です。
</Note>
