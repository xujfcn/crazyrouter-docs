## ステップ1：API Key を取得する

1. [Crazyrouter](https://crazyrouter.com) にアクセスしてアカウントを登録してください。
2. ログイン後、[トークン管理](https://crazyrouter.com/console/token) ページへ進みます。
3. 「新規トークン作成」をクリックしてAPI Keyを作成します。

## ステップ2：リクエストを送信する

<Note>
国際接続の標準エンドポイントには優先的に`https://api.crazyrouter.com/v1`をご記入ください。東アジア地域では`https://cn.crazyrouter.com/v1`を優先的にご利用ください。クライアントがルートドメインか`/v1`のどちらを指定すべきか不明な場合は、まず[API Endpoint 説明](https://docs.crazyrouter.com/jp/api-endpoint)をご参照ください。
</Note>

<CodeGroup>
```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {"role": "user", "content": "你好"}
    ]
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "你好"}]
)
print(response.choices[0].message.content)
```

```javascript Node.js
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'YOUR_API_KEY',
  baseURL: 'https://api.crazyrouter.com/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-5.5',
  messages: [{ role: 'user', content: '你好' }]
});
console.log(response.choices[0].message.content);
```
</CodeGroup>

```json
  }],
  "usage": {
    "prompt_tokens": 9,
    "completion_tokens": 12,
    "total_tokens": 21
  }
}
```

<Note>
このクイックスタートページの`gpt-5.5`のサンプルは2026-06-06のドキュメント基準に合わせて更新されています。
</Note>

<Note>
OpenAI互換の全クライアントやフレームワーク（LangChain、LlamaIndex、Cursorなど）は、`base_url`と`api_key`を変更するだけで接続可能です。
</Note>
