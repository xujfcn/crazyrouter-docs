<Note>
  API 接続パス：デフォルトの国際エントリーは `https://api.crazyrouter.com`、東アジア地域では `https://cn.crazyrouter.com` を優先して使用してください。OpenAI 互換クライアントは通常、ルートドメインの後に `/v1` を追加します；Claude Code / Anthropic ネイティブクライアントはルートドメインのみ使用し、`/v1` を付けないでください。詳細は[API エンドポイント](/jp/api-endpoint)をご覧ください。
</Note>

Crazyrouter は統合型 AI モデル API ゲートウェイです。1つの API Key で、テキスト・画像・動画・音声・埋め込み・リランクやサードパーティツール統合など多様なモデル機能を利用できます。
