# ツール呼び出し

本ドキュメントでは **Crazyrouter生産環境で実際にリクエストが成功した** ツール呼び出しの使用方法のみを収録しています。

検証日時：

- `2026-03-22`

検証済みモデル：

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

---

## 検証済み機能マトリックス

| モデル | プロトコル | エンドポイント | 成功の判定 |
|------|------|------|----------|
| `gpt-5.5` | OpenAI Chat Completions | `POST /v1/chat/completions` | `tool_calls`が返される |
| `claude-opus-4-8` | Anthropic Messages | `POST /v1/messages` | `tool_use` blockが返される |
| `gemini-3.1-pro` | Gemini Native | `POST /v1beta/models/{model}:generateContent` | `functionCall`が返される |

<Warning>
Claudeツール呼び出しは現在Anthropic Messagesプロトコルで検証されており、つまり`POST /v1/messages`が返され、`tool_use` blockとなります。この結論をClaudeのOpenAI互換`/v1/chat/completions`パスへ安易に適用しないでください。Copilot、Continue、VS Code Agentの一部やその他ツール呼び出し依存のプログラミング環境では、OpenAI互換エンドポイントでClaudeネイティブのツール呼び出しが動作しない場合があります。ClaudeのプログラミングAgent能力が必要な場合は、Claude CodeやAnthropicネイティブクライアント設定の利用を優先してください。
</Warning>

## GPT-5.4

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Use the get_time tool for Asia/Shanghai. Do not answer without calling the tool."
      }
    ],
    "tools": [
      {
        "type": "function",
        "function": {
          "name": "get_time",
          "description": "Get the current time for a timezone",
          "parameters": {
            "type": "object",
            "properties": {
              "timezone": {
                "type": "string"
              }
            },
            "required": ["timezone"],
            "additionalProperties": false
          }
        }
      }
    ],
    "tool_choice": "required"
  }'
```

生産環境の検証で返される重要なフィールド：

```json
{
  "tool_calls": [
    {
      "type": "function",
      "function": {
        "name": "get_time",
        "arguments": "{\"timezone\":\"Asia/Shanghai\"}"
      }
    }
  ]
}
```

## Claude Sonnet 4.6

```bash cURL
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 256,
    "tools": [
      {
        "name": "get_time",
        "description": "Get the current time for a timezone",
        "input_schema": {
          "type": "object",
          "properties": {
            "timezone": {
              "type": "string"
            }
          },
          "required": ["timezone"]
        }
      }
    ],
    "tool_choice": {
      "type": "any"
    },
    "messages": [
      {
        "role": "user",
        "content": "Use the get_time tool for Asia/Shanghai. Do not answer directly."
      }
    ]
  }'
```

生産環境の検証で返される重要なフィールド：

```json
{
  "stop_reason": "tool_use",
  "content": [
    {
      "type": "tool_use",
      "name": "get_time",
      "input": {
        "timezone": "Asia/Shanghai"
      }
    }
  ]
}
```

初回連携テストのおすすめ：

- Claudeネイティブ`/v1/messages`には、優先して明示的に`tool_choice`を追加してください
- プロンプト内で「必ずツールを呼び出し、直接回答しない」と明記する
- これにより`tool_use`を安定して再現しやすくなります

## Gemini 3 Pro

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Use the get_time function for Asia/Shanghai."
          }
        ]
      }
    ],
    "tools": [
      {
        "functionDeclarations": [
          {
            "name": "get_time",
            "description": "Get the current time for a timezone",
            "parameters": {
              "type": "object",
              "properties": {
                "timezone": {
                  "type": "string"
                }
              },
              "required": ["timezone"]
            }
          }
        ]
      }
    ]
  }'
```

生産環境の検証で返される重要なフィールド：

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "functionCall": {
              "name": "get_time",
              "args": {
                "timezone": "Asia/Shanghai"
              }
            }
          }
        ]
      }
    }
  ]
}
```

## どのプロトコルを使うべきか

- すでにOpenAI SDKを使っているプロジェクトでは、まず`gpt-5.5`のOpenAI互換方式を推奨します
- Claudeネイティブ導入の場合、まず`/v1/messages`を使い、初回検証時には`tool_choice`を追加してください
- Geminiネイティブ導入の場合は、Gemini Native APIの利用を優先してください
