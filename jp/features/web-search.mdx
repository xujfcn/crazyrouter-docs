# ウェブ検索

本ドキュメントには、**Crazyrouter 本番環境で実際にリクエスト検証が成功した**ウェブ検索の使い方のみを収録しています。

検証時刻：

- `2026-03-22`

検証済みモデル：

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

---

## 検証済み機能マトリックス

| モデル | プロトコル | エンドポイント | 成功の指標 |
|--------|------------|----------------|-------------|
| `gpt-5.5` | OpenAI Responses | `POST /v1/responses` | `output` 内に `web_search_call` が出現 |
| `claude-opus-4-8` | OpenAI互換チャット | `POST /v1/chat/completions` | `remote_web_search` ツール呼び出しが返る |
| `gemini-3.1-pro` | Gemini ネイティブ | `POST /v1beta/models/{model}:generateContent` | `groundingMetadata` が返る |

---

## GPT-5.4

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Use web search to find one current headline from a major technology news site published recently.",
    "tools": [
      {
        "type": "web_search_preview"
      }
    ]
  }'
```

本番検証で返る主な`output.type`：

```json
["web_search_call", "web_search_call", "message"]
```

## Claude Sonnet 4.6

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {
        "role": "user",
        "content": "Find one recent technology headline. Use web search and do not answer from memory."
      }
    ],
    "web_search_options": {
      "search_context_size": "medium",
      "user_location": {
        "approximate": {
          "timezone": "Asia/Shanghai",
          "country": "CN"
        }
      }
    },
    "max_tokens": 200
  }'
```

本番検証で返る主なフィールド：

```json
{
  "tool_calls": [
    {
      "type": "function",
      "function": {
        "name": "remote_web_search"
      }
    }
  ],
  "finish_reason": "tool_calls"
}
```

これは Crazyrouter の OpenAI互換ルート下では、Claude 4.6 のネット検索がツール呼び出しとして露出することを示しています。

初回連携テストの推奨事項：

- プロンプト内で`Use web search` を明記する
- 併せて `do not answer from memory` も一文追加してください
- プロンプトが弱い場合、モデルが直接テキスト回答して明示的に`remote_web_search`を発火しない可能性があります

## Gemini 3 Pro

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Use Google Search to find one recent headline from a major technology news site."
          }
        ]
      }
    ],
    "tools": [
      {
        "googleSearch": {}
      }
    ]
  }'
```

本番検証では以下の主なフィールドが返りました：

- `groundingMetadata.webSearchQueries`
- `groundingMetadata.groundingChunks`
- `groundingMetadata.groundingSupports`
