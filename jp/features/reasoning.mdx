# 推論

本ドキュメントでは、**Crazyrouter 本番環境で実際にリクエスト検証が成功した**推論／思考用途のみを収録しています。

検証日時：

- `2026-03-22`

検証済みモデル：

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

---

## 検証済み能力マトリクス

| モデル | プロトコル | エンドポイント | 成功の目印 |
|------|------|------|----------|
| `gpt-5.5` | OpenAI Responses | `POST /v1/responses` | `output` 内に `reasoning` item が出現 |
| `claude-opus-4-8` | Anthropic Messages | `POST /v1/messages` | `thinking` block を返す |
| `gemini-3.1-pro` | Gemini Native | `POST /v1beta/models/{model}:generateContent` | `usageMetadata` 内に `thoughtsTokenCount` が出現 |

---

## GPT-5.4

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Which is larger, 9.11 or 9.9? Explain briefly.",
    "reasoning": {
      "effort": "high",
      "summary": "detailed"
    }
  }'
```

本番環境検証で返却された主要な `output.type`：

```json
["reasoning", "message"]
```

その中で `reasoning` item の重要フィールドには以下が含まれる：

```json
{
  "type": "reasoning",
  "summary": [
    {
      "type": "summary_text",
      "text": "..."
    }
  ]
}
```

これは Crazyrouter 現行本番環境において、`gpt-5.5` の推論能力は Responses API の `reasoning` item を基準とし、Chat Completions の `reasoning_content` には依存しないことを示しています。

## Claude Opus 4.7 推論

```bash cURL
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 320,
    "thinking": {
      "type": "enabled",
      "budget_tokens": 128
    },
    "messages": [
      {
        "role": "user",
        "content": "Which is larger, 9.11 or 9.9? Explain briefly."
      }
    ]
  }'
```

本番検証で返却された重要なフィールド：

```json
{
  "content": [
    {
      "type": "thinking",
      "thinking": "..."
    },
    {
      "type": "text",
      "text": "..."
    }
  ]
}
```

注意：

- `claude-opus-4-8` の基本モデルは同日にテストした際、通常の `text` のみ返されました
- `claude-opus-4-8` でのみ明確な thinking block を確認できました

したがって、本ドキュメントでは Claude 4.7 推論サンプルとして `claude-opus-4-8` の使用を優先します。

## Gemini 3 Pro

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Which is larger, 9.11 or 9.9? Explain briefly."
          }
        ]
      }
    ],
    "generationConfig": {
      "thinkingConfig": {
        "thinkingBudget": 256
      },
      "maxOutputTokens": 512
    }
  }'
```

本番検証で返却された重要なフィールド：

- `usageMetadata.thoughtsTokenCount`

これにより現行本番環境において `gemini-3.1-pro` の thinking モードが実際に有効であることが確認されます。

## 現時点で主結論に記載しない組み合わせ

- `gpt-5.5` の Chat Completions ルートは本検証サイクル中に `reasoning_content` を安定して返さなかったため、本ページで GPT 主サンプルから除外します
- `claude-opus-4-8` のベースモデルでは本検証サイクル中に thinking block が返却されませんでした
- `claude-opus-4-8` では同等の明確な thinking 能力を持つモデルは確認できませんでした
