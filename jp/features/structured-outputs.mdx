# 構造化出力

本ドキュメントには、**Crazyrouter 本番環境で実際のリクエストによる動作確認が取れた** 構造化出力の使い方のみ収録しています。

検証日時：

- `2026-03-22`

厳格な検証に成功したモデル：

- `gpt-5.5`
- `gemini-3.1-pro`

現時点で厳格な成功例には含めていないモデル：

- `claude-opus-4-8`

理由：

- 本番環境での再チェックにて、`claude-opus-4-8` は現行 OpenAI 互換 `response_format=json_schema` 要求形式では安定して「完全な純粋 JSON」にならない挙動を確認
- 過去のテストでは fenced code block の出現も確認
- `2026-03-22` の再チェック時には空の `content` の発生も見られた
- このため現状「厳格な構造化出力が検証された」とは記載しない

---

## 検証済み能力マトリクス

| モデル | プロトコル | エンドポイント | 成功指標 |
|------|------|------|----------|
| `gpt-5.5` | OpenAI Chat Completions | `POST /v1/chat/completions` | 返却内容がそのまま `JSON.parse` 可能 |
| `gemini-3.1-pro` | Gemini Native | `POST /v1beta/models/{model}:generateContent` | 返却される `application/json` 形式テキストはそのまま解析できる |

---

## GPT-5.4

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Return a JSON object with keys city and country for Tokyo."
      }
    ],
    "response_format": {
      "type": "json_schema",
      "json_schema": {
        "name": "city_country",
        "strict": true,
        "schema": {
          "type": "object",
          "properties": {
            "city": {"type": "string"},
            "country": {"type": "string"}
          },
          "required": ["city", "country"],
          "additionalProperties": false
        }
      }
    }
  }'
```

本番検証時の返却：

```json
{"city":"Tokyo","country":"Japan"}
```

## Gemini 3 Pro

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Return a JSON object with keys city and country for Tokyo."
          }
        ]
      }
    ],
    "generationConfig": {
      "responseMimeType": "application/json",
      "responseSchema": {
        "type": "object",
        "properties": {
          "city": {"type": "string"},
          "country": {"type": "string"}
        },
        "required": ["city", "country"]
      }
    }
  }'
```

本番検証時の返却：

```json
{"city":"Tokyo","country":"Japan"}
```

## Claude 4.6 現時点での結論

`2026-03-22` の本番テストでは：

- `claude-opus-4-8` は当該リクエスト形式では安定的かつ再現可能な厳格 JSON 出力をしませんでした
- テストの度に fenced code block または空の `content` が散見
- そのため現行 Claude 4.6 は「厳格スキーマ出力確認済み」とはしません

後日 Claude 4.6 をこの一覧に加える場合は、追加の細かい本番検証を行い、以下を必ず確認してください：

- より適切なネイティブプロトコル記法があるか
- 追加の system prompt が必要か
- code fence を安定して排除できるか
