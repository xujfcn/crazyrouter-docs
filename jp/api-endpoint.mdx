## APIベースURL

```
https://api.crazyrouter.com
```

`https://api.crazyrouter.com` はデフォルトの国際API接続入口として利用されています。アカウントのログイン、チャージ、およびコンソールには以下を引き続き使用してください：

```
https://crazyrouter.com
```

<Warning>
アカウントおよび管理APIは主ドメイン`https://crazyrouter.com`で使用する必要があります。例：`/api/user/self`、`/api/token/*`、`/api/log/*`。これらのパスを`https://api.crazyrouter.com`や`https://cn.crazyrouter.com`へ送らないでください。これらはモデルやメディアAPI専用ドメインであり、誤って利用すると`404 api_only_endpoint`が返されます。モデル推論API（例えば`/v1/chat/completions`、`/v1/messages`、`/v1/models`）はAPI専用ドメインを引き続き使用します。
</Warning>

東アジア地域では以下のAPIアドレスを優先してご利用ください：

```
https://cn.crazyrouter.com
```

サードパーティのクライアント、SDK、IDE、Agentを構成する場合は、まずそのツールで入力すべきドメインがルートドメインか`/v1`かを確認しましょう：

<Card title="接続アドレスの説明を確認する" icon="book" href="https://docs.crazyrouter.com/jp/api-endpoint">
  まずこのセクションでルートドメインか`/v1`を入力すべきかを確認し、各ツールのドキュメントに戻って具体的な設定を行ってください。
</Card>

## 推奨接続アドレス

デフォルトは国際API入口`https://api.crazyrouter.com`を優先利用してください。東アジア地域のユーザーは`https://cn.crazyrouter.com`を優先してください。これら2つのアドレスはAPIリクエスト専用です。Webアカウント、チャージ、コンソール、価格ページは引き続き`https://crazyrouter.com`をご使用ください。

## クライアント毎に入力すべきアドレス

| 利用方法 | デフォルト国際入口 | 東アジア優先入口 | 説明 |
|----------|----------------|----------------|------|
| OpenAI互換SDK／クライアント | `https://api.crazyrouter.com/v1` | `https://cn.crazyrouter.com/v1` | クライアントはこのアドレスの後に`/chat/completions`、`/models`等のパスを連結します |
| Claude Code／Anthropicネイティブクライアント | `https://api.crazyrouter.com` | `https://cn.crazyrouter.com` | クライアント側で`/v1/messages`を連結します。`/v1`を手動で追加しないでください |
| curl／手書きHTTPリクエスト | 完全なエンドポイント（例：`https://api.crazyrouter.com/v1/chat/completions`） | 完全なエンドポイント（例：`https://cn.crazyrouter.com/v1/chat/completions`） | 手書きリクエストの場合は完全なAPIパスを記述する必要があります |
| アカウント、残高、Token、ログ管理API | `https://crazyrouter.com` | `https://crazyrouter.com` | `/api/user/self`、`/api/token/*`、`/api/log/*`に使用。API専用ドメインは使用不可 |

<Warning>
ログに`/v1/v1/models`、`/v1/v1/messages`、`/v1/messages/v1/messages`が出現した場合、APIパスをクライアント設定で二重連結している可能性があります。Claude Code／Anthropicネイティブクライアントはルートドメインに戻しましょう。OpenAI互換クライアントは`/v1`までにしてください。
</Warning>

<Warning>
Claudeのネイティブ`tool_use`、Claude Codeプログラミング機能や一部IDE Agentツールによる呼び出しは、Anthropic Messages経路`POST /v1/messages`を優先的に使用してください。OpenAI互換`/v1/chat/completions`は一般的なチャットや基本的な互換接続に適しており、ClaudeネイティブMessagesAPIとは同等ではありません。ClaudeモデルをOpenAI互換エンドポイントでツール呼び出しすると、安定してツールを起動できない場合があります。
</Warning>
