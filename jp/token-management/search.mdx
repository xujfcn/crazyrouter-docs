## インターフェース説明

キーワードによりトークンを検索し、名前の部分一致やトークンの一部によるフィルタもサポートしています。

<Note>
  この `/api/token/*` インターフェース群は、主に Crazyrouter コンソールにおける API Key 管理の自動化に使われます。ユーザー `access token` および `New-Api-User` ヘッダーが必要であり、一般的な `sk-xxx` モデルの呼び出しフローに直接利用するためのものではありません。リクエストのベース URL には必ず `https://crazyrouter.com` を使用してください。`https://api.crazyrouter.com` はモデル API 専用エントリーポイントであり、管理パスを呼び出すと `404 api_only_endpoint` が返されます。
</Note>

## 認証方式

ユーザー側認証を使用し、リクエストヘッダーに以下を含めてください：

```text
Authorization: Bearer your_access_token
New-Api-User: 1
```

## リクエストパラメータ

<ParamField query="keyword" type="string" required>
  検索キーワード（トークン名に一致）
</ParamField>

<ParamField query="token" type="string">
  オプション。トークン文字列の一部で絞り込み
</ParamField>

## コード例

<CodeGroup>

```python Python
import requests

headers = {
    "Authorization": "Bearer your_access_token",
    "New-Api-User": "1",
    "User-Agent": "Mozilla/5.0"
}

response = requests.get(
    "https://crazyrouter.com/api/token/search?keyword=生产&token=sk-",
    headers=headers
)

tokens = response.json()["data"]
for token in tokens:
    print(f"[{token['id']}] {token['name']} - 剩余额度: {token['remain_quota']}")
```

```bash cURL
curl "https://crazyrouter.com/api/token/search?keyword=生产&token=sk-" \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 1"
```
