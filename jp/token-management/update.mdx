## インターフェイス説明

既存のトークンの名前、クォータ、期限、モデル権限などの設定を編集します。

<Note>
  この `/api/token/*` のインターフェイス群は主に Crazyrouter コンソールにおける API Key 管理自動化のためのものです。これらの利用にはユーザー `access token` および `New-Api-User` リクエストヘッダーが必要であり、一般的な `sk-xxx` モデル呼び出しフローで直接利用するためのAPIではありません。リクエストのベースアドレスには必ず `https://crazyrouter.com` を使用してください。`https://api.crazyrouter.com` はモデルAPI専用エンドポイントであり、管理用パスを呼び出すと `404 api_only_endpoint` が返されます。
</Note>

## 認証方式

ユーザー側認証を使用します。リクエストヘッダに以下を含めてください:

```text
Authorization: Bearer your_access_token
New-Api-User: 1
```

## リクエストパラメータ

<ParamField body="id" type="integer" required>
  トークンID
</ParamField>

<ParamField body="name" type="string">
  トークン名
</ParamField>

<ParamField body="remain_quota" type="integer">
  残りクォータ
</ParamField>

<ParamField body="unlimited_quota" type="boolean">
  無制限クォータか
</ParamField>

<ParamField body="expired_time" type="integer">
  期限のタイムスタンプ、`-1` は無期限を意味します
</ParamField>

<ParamField body="model_limits_enabled" type="boolean">
  モデルホワイトリストを有効化するか
</ParamField>

<ParamField body="model_limits" type="string">
  モデル制限設定文字列、例：`["gpt-5.5","claude-opus-4-8"]`
</ParamField>

<ParamField body="status" type="integer">
  ステータス：1=有効、2=無効
</ParamField>

<ParamField body="allow_ips" type="string">
  IPホワイトリスト文字列
</ParamField>

<ParamField body="group" type="string">
  グループ
</ParamField>

## レスポンス形式

本APIは更新後のtokenオブジェクトを返します：

```json
{
  "success": true,
  "message": "",
  "data": {
    "id": 10,
    "name": "生产环境-已更新",
    "status": 1,
    "remain_quota": 200000,
    "unlimited_quota": false,
    "model_limits_enabled": true,
    "model_limits": "[\"gpt-5.5\",\"claude-opus-4-8\"]",
    "allow_ips": "203.0.113.10",
    "group": "default"
  }
}
```

## コード例

<CodeGroup>

```python Python
import json
import requests

headers = {
    "Authorization": "Bearer your_access_token",
    "New-Api-User": "1",
    "Content-Type": "application/json",
    "User-Agent": "Mozilla/5.0"
}

response = requests.put(
    "https://crazyrouter.com/api/token/",
    headers=headers,
    json={
        "id": 10,
        "name": "生产环境-已更新",
        "remain_quota": 200000,
        "model_limits_enabled": True,
        "model_limits": json.dumps(["gpt-5.5", "claude-opus-4-8"])
    }
)

print(response.json())
```

```bash cURL
curl -X PUT https://crazyrouter.com/api/token/ \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 1" \
  -H "Content-Type: application/json" \
  -d '{
    "id": 10,
    "name": "生产环境-已更新",
    "remain_quota": 200000,
    "model_limits_enabled": true,
    "model_limits": "[\"gpt-5.5\"]"
  }'
```

</CodeGroup>

<Warning>
  トークンを編集してもAPI Keyは再発行されません。Keyを変更したい場合は、削除後に新規作成してください。
</Warning>
