---
title: "トークンの削除"
description: "指定された API トークンを削除します"
api: 'DELETE /api/token/{id}'
---
> 内容更新日: 2026-07-20

## インターフェース説明

指定した API トークンを永久に削除します。削除後、そのトークンの API キーは直ちに無効になります。

<Note>
  この `/api/token/*` の一連のインターフェースは、Crazyrouter コンソールにおける API キー管理の自動化を主目的としています。利用には、ユーザー `access token` と `New-Api-User` リクエストヘッダーが必要で、一般的な `sk-xxx` モデル呼び出しフロー向けのインターフェースではありません。リクエストの基盤となるURLには `https://crazyrouter.com` を必ず使用してください。`https://api.crazyrouter.com` はモデルAPI専用の入り口であり、管理パスを呼び出すと `404 api_only_endpoint` が返されます。
</Note>

## 認証方式

ユーザー側認証を使用します。リクエストヘッダーに以下を含めてください：

```text
Authorization: Bearer your_access_token
New-Api-User: 1
```

## パスパラメータ

<ParamField path="id" type="integer" required>
  削除したいトークンID
</ParamField>

## レスポンス形式

```json
{
  "success": true,
  "message": "令牌删除成功"
}
```

## コード例

<CodeGroup>

```python Python
import requests

headers = {
    "Authorization": "Bearer your_access_token",
    "New-Api-User": "1",
    "User-Agent": "Mozilla/5.0"
}

token_id = 10
response = requests.delete(
    f"https://crazyrouter.com/api/token/{token_id}",
    headers=headers
)

print(response.json())
```

```bash cURL
curl -X DELETE https://crazyrouter.com/api/token/10 \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 1"
```

</CodeGroup>

<Warning>
  削除操作は復元できません。削除後、このキーを使用する全てのアプリケーションは直ちにAPIを呼び出せなくなります。
</Warning>
