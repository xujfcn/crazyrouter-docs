## インターフェース概要

新しい API トークン（Token）を作成し、AI モデル API の呼び出しに使用します。

<Note>
  この `/api/token/*` 一連のインターフェースは Crazyrouter コンソールの API Key 管理自動化のために主に用意されています。これらのご利用にはユーザー `access token` および `New-Api-User` リクエストヘッダーが必要で、通常の `sk-xxx` モデル呼び出しプロセスでは直接は使われません。リクエストのベースURLには必ず `https://crazyrouter.com` をご利用ください；`https://api.crazyrouter.com` はモデル API 専用の入口で、管理系パスを呼び出すと `404 api_only_endpoint` が返されます。
</Note>

## 認証方式

このインターフェースを利用するにはユーザー側で認証を行う必要があります：

```text
Authorization: Bearer your_access_token
New-Api-User: 1
```

## リクエストパラメータ

<ParamField body="name" type="string" required>
  トークン名。目的を識別しやすくするための名前です。
</ParamField>

<ParamField body="remain_quota" type="integer" default="0">
  初期クレジット（単位：内部クレジット値）。0 に設定した場合は `unlimited_quota` と合わせてご利用ください。
</ParamField>

<ParamField body="unlimited_quota" type="boolean" default="false">
  無制限クレジットに設定するかどうか
</ParamField>

<ParamField body="expired_time" type="integer" default="-1">
  有効期限（UNIX タイムスタンプ）。`-1` は無期限を意味します。
</ParamField>

<ParamField body="model_limits_enabled" type="boolean" default="false">
  モデルホワイトリスト制限を有効にするかどうか
</ParamField>

<ParamField body="model_limits" type="string">
  モデル制限の設定。現時点ではこの項目は文字列になっており、通常は JSON 形式の文字列（例：`["gpt-5.5","claude-opus-4-8"]`）で保存します。
</ParamField>

<ParamField body="allow_ips" type="string">
  IP ホワイトリスト文字列。1件の IP または改行で複数の IP を指定できます。
</ParamField>

<ParamField body="group" type="string">
  トークンが属するグループ。現在のユーザーが権限を持つグループのみ設定可能です。
</ParamField>

## レスポンスフォーマット

このインターフェースでの作成に成功した場合は、成功ステータスのみを返します：

```json
{
  "success": true,
  "message": ""
}
```

## コード例

<CodeGroup>

```python Python
import json
import requests

headers = {
    "Authorization": "Bearer your_access_token",
    "New-Api-User": "1",
    "Content-Type": "application/json",
    "User-Agent": "Mozilla/5.0"
}

response = requests.post(
    "https://crazyrouter.com/api/token/",
    headers=headers,
    json={
        "name": "生产环境",
        "remain_quota": 100000,
        "unlimited_quota": False,
        "expired_time": -1,
        "model_limits_enabled": True,
        "model_limits": json.dumps(["gpt-5.5", "claude-opus-4-8"]),
        "allow_ips": "203.0.113.10"
    }
)

print(response.json())
```

```bash cURL
curl -X POST https://crazyrouter.com/api/token/ \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 1" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "生产环境",
    "remain_quota": 100000,
    "expired_time": -1,
    "model_limits_enabled": true,
    "model_limits": "[\"gpt-5.5\"]"
  }'
```

</CodeGroup>

<Warning>
  この作成インターフェースは作成した新規 `key` の完全な内容をレスポンスとして返しません。その場で完全なキーをコピーする必要がある場合は、コンソール画面からの作成＆保存を優先的にご利用ください。
</Warning>
