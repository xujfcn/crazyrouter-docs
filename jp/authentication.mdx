## Bearer Token 認証

すべての API リクエストでは、Header に API Key を含める必要があります：

```
Authorization: Bearer YOUR_API_KEY
```

## API Key の取得方法

1. [Crazyrouter](https://crazyrouter.com) にログインする
2. ログイン後、[Token 管理](https://crazyrouter.com/console/token) ページに移動する
3. 「新規トークン」をクリックする
4. トークン名、利用制限、利用可能モデルなどを設定する
5. 生成された `sk-` で始まるキーをコピーする

<Warning>
API Keyは作成時にのみ表示されますので、大切に保管してください。紛失した場合は新たに作成が必要です。
</Warning>

## 利用例

<Note>
OpenAI 互換接続時のデフォルト国際アドレスには `https://api.crazyrouter.com/v1` をご利用ください。東アジア地域では `https://cn.crazyrouter.com/v1` を優先的にご利用ください。Claude Code、Hermes、OpenClaw など他ツールにアドレス設定を行う場合は、事前に [API Endpoint 説明](https://docs.crazyrouter.com/jp/api-endpoint) をご参照ください。
</Note>

<CodeGroup>
```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-5.5", "messages": [{"role": "user", "content": "Hi"}]}'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",
    base_url="https://api.crazyrouter.com/v1"
)
```

```javascript Node.js
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-xxxxxxxx',
  baseURL: 'https://api.crazyrouter.com/v1'
});
```
</CodeGroup>

## Token 権限管理

トークン作成時に以下を設定できます：

- **名称**：用途の識別に便利
- **利用制限**：使用できる最大限度を設定
- **有効期限**：有効期間を設定
- **利用可能モデル**：利用を許可するモデルの範囲を制限
- **IP ホワイトリスト**：呼び出し元 IP を制限
