# AI思考フィールド

このページでは、`2026-03-22` がCrazyrouter本番環境で再検証済みのthinking / reasoning公開方法のみをリストします。

重要な前提条件として：異なるプロトコルは「思考」公開方法が異なります。

- OpenAIのレスポンスは、独立した`reasoning`項目の返却傾向が強い
- ClaudeのネイティブMessagesは`thinking`ブロックとして返却します
- Gemini Nativeは現状`usageMetadata.thoughtsTokenCount`によって思考動作の有無が最も判断しやすいです

## 現時点で検証済みのフィールド

| モデル | プロトコル | 検証済みフィールドまたはフラグ | 説明 |
|------|------|------------------|------|
| `gpt-5.5` | Responses | `output[].type = "reasoning"` | `summary`と組み合わせて、表示可能な要約を取得可能 |
| `claude-opus-4-8` | Anthropic Messages | `content[].type = "thinking"` | `text`ブロックと並立で返却される |
| `gemini-3.1-pro` | Gemini Native | `usageMetadata.thoughtsTokenCount` | thinking budgetが実際に消費されたことを示す |

<Note>
  今回の再検証では、`gpt-5.5` Chat Completionsの`message.reasoning_content`は安定して信頼できる内容を返していないため、主要な観測フィールドとしてここでは取り上げません。
</Note>

## GPT: Responses `reasoning`項目

```json
{
  "output": [
    {
      "id": "rs_xxx",
      "type": "reasoning",
      "encrypted_content": "...",
      "summary": [
        {
          "type": "summary_text",
          "text": "..."
        }
      ]
    },
    {
      "type": "message",
      "content": [
        {
          "type": "output_text",
          "text": "最终回答"
        }
      ]
    }
  ]
}
```

抽出方法：

```python
response = client.responses.create(
    model="gpt-5.5",
    input="Which is larger, 9.11 or 9.9?",
    reasoning={"effort": "high", "summary": "detailed"}
)

for item in response.output:
    if item.type == "reasoning":
        for part in item.summary:
            if part.type == "summary_text":
                print("思考摘要:", part.text)
```

## Claude: `thinking`ブロック

```json
{
  "content": [
    {
      "type": "thinking",
      "thinking": "..."
    },
    {
      "type": "text",
      "text": "最终回答"
    }
  ]
}
```

抽出方法：

```python
message = client.messages.create(
    model="claude-opus-4-8",
    max_tokens=320,
    thinking={
        "type": "enabled",
        "budget_tokens": 128
    },
    messages=[
        {"role": "user", "content": "Which is larger, 9.11 or 9.9?"}
    ]
)

for block in message.content:
    if block.type == "thinking":
        print("思考内容:", block.thinking)
    elif block.type == "text":
        print("回答:", block.text)
```

## Gemini: `thoughtsTokenCount`

Gemini Nativeにおける現状最も安定した観測ポイントは、本文中の見えやすい思考テキスト自体ではなく、利用量フィールドです：

```json
{
  "usageMetadata": {
    "thoughtsTokenCount": 120
  }
}
```

これは次のことを意味しています：

- thinking budgetが実際に生成へ利用された
- 現在のリクエストで思考用Token消費が確かに発生した

抽出方法：

```python
data = response.json()
thoughts = data.get("usageMetadata", {}).get("thoughtsTokenCount", 0)
print("思考 Token:", thoughts)
```

---

## 使用時の注意点

- すべてのモデルが思考過程を明示的に返すとは限りません
- 異なるプロトコルのthinkingフィールドを混同しないでください
- 監査・ログ・フロントエンド表示をする場合、必ずプロトコルごとに`reasoning`・`thinking`・`thoughtsTokenCount`のどれを読むべきか判断してください
