# 接入チュートリアル

このページには`2026-03-23`がCrazyrouter本番環境で審査済みの導入パスのみを記載しています。

最速で始めるには、まず3種類の接続方法を区別してください：

- OpenAI互換：`https://api.crazyrouter.com/v1`
- Anthropicネイティブ：`https://api.crazyrouter.com`
- Geminiネイティブ：`https://api.crazyrouter.com/v1beta/models/...`

## 最小限の移行原則

OpenAI互換クライアントからCrazyrouterへの移行では、通常2箇所だけ変更すれば済みます：

1. `base_url`を`https://api.crazyrouter.com/v1`に変更
2. `api_key`をCrazyrouterの`sk-xxx`に変更

---

## OpenAIからの移行

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "Hello"}],
    max_tokens=64
)
```

この審査期間での確認内容：

- `gpt-5.5`が`/v1/chat/completions`を通じて正常に返却されます
- reasoningの要約やOpenAIスタイルのウェブ検索が必要な場合は、まず`/v1/responses`への切替を優先してください

関連ページ：

- [Responses API概要](/jp/chat/responses/overview)
- [GPT-5思考モード](/jp/chat/responses/gpt5-thinking)

## Anthropicからの移行

### パターンA：OpenAI互換レイヤーの継続利用

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="claude-opus-4-8",
    messages=[{"role": "user", "content": "Hello"}],
    max_tokens=64
)
```

### パターンB：AnthropicネイティブMessages

```python
import anthropic

client = anthropic.Anthropic(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com"
)

response = client.messages.create(
    model="claude-opus-4-8",
    max_tokens=128,
    messages=[{"role": "user", "content": "Hello"}]
)
```

次のケースでは：

- 通常のClaude対話：まず`claude-opus-4-8`を推奨
- thinking blockが必要な場合：`claude-opus-4-8`を推奨

関連ページ：

- [Claudeネイティブフォーマット](/jp/chat/anthropic/messages)

## Geminiからの移行

### パターンA：OpenAI互換レイヤー

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="gemini-3.1-pro",
    messages=[{"role": "user", "content": "Hello"}],
    max_tokens=64
)
```

### パターンB：Geminiネイティブ

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "Hello"}
        ]
      }
    ]
  }'
```

次のケースでは：

- 既存のOpenAI SDKコードだけを使いたい場合：まず互換レイヤー経由で
- 構造化出力・Google Search・thinkingが必要な場合：Geminiネイティブを優先

- [Gemini OpenAI互換フォーマット](/jp/chat/gemini/openai-compat)

## 環境変数方式

OpenAI互換レイヤーを使う場合、先に次を設定するのがおすすめです：

<Tabs>
  <Tab title="Linux / macOS">
    ```bash
    export OPENAI_API_KEY=sk-xxx
    export OPENAI_BASE_URL=https://api.crazyrouter.com/v1
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    $env:OPENAI_API_KEY = "sk-xxx"
    $env:OPENAI_BASE_URL = "https://api.crazyrouter.com/v1"
    ```
  </Tab>
</Tabs>

その後、コード内で直接：

```python
from openai import OpenAI
client = OpenAI()
```

## 導入のアドバイス

| 目的 | 推奨開始方法 |
|------|--------------|
| GPT最速導入 | OpenAI互換 ＋ `gpt-5.5` |
| Claude最速導入 | Anthropicネイティブ ＋ `claude-opus-4-8` |
| Gemini最速導入 | OpenAI互換 または Geminiネイティブ ＋ `gemini-3.1-pro` |
| reasoning要約が必要 | Responses API |
| Claude thinking blockが必要 | `claude-opus-4-8` |
| Gemini Google Search / thinking / responseSchemaが必要 | Geminiネイティブ |

<Note>
  CrazyrouterはOpenAI、Anthropic、Geminiの三種プロトコルに同時対応しています。より安定して利用するには“全モデルを同じプロトコルに無理に統一する”のではなく、機能に合わせて最適なエンドポイントを選択するのが一般的です。
</Note>
