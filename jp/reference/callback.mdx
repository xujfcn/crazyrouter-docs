## 概要

非同期タスク（Midjourney 描画、動画生成など）に関して、Crazyrouter は Webhook コールバックによるタスク状態の変更通知をサポートしています。

## コールバック URL の設定

タスク送信時に、`notifyHook` パラメータを使ってコールバック先アドレスを指定します：

```json
{
  "prompt": "a beautiful sunset",
  "notifyHook": "https://your-server.com/api/callback"
}
```

## コールバックリクエスト形式

Crazyrouter はあなたのコールバック URL へ POST リクエストを送信します：

```
POST https://your-server.com/api/callback
Content-Type: application/json
```

### Midjourney コールバック

```json
{
  "id": "task_abc123",
  "action": "IMAGINE",
  "status": "SUCCESS",
  "prompt": "a beautiful sunset",
  "imageUrl": "https://cdn.example.com/image.png",
  "progress": "100%",
  "failReason": "",
  "submitTime": 1706000000000,
  "startTime": 1706000010000,
  "finishTime": 1706000060000
}
```

### 動画生成コールバック（Kling/Luma/Runway）

```json
{
  "id": "task_xyz789",
  "status": "succeed",
  "type": "video",
  "output": {
    "video_url": "https://cdn.example.com/video.mp4",
    "cover_url": "https://cdn.example.com/cover.jpg",
    "duration": 5.0
  },
  "created_at": 1706000000,
  "updated_at": 1706000120
}
```

## コールバック状態遷移

```
提交 → NOT_START → IN_PROGRESS → SUCCESS / FAILURE
```

状態が更新されるたびにコールバックが一度発生します。

## コールバックサーバーサンプル

<CodeGroup>

```python Python (Flask)
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route("/api/callback", methods=["POST"])
def callback():
    data = request.json
    task_id = data["id"]
    status = data["status"]

    print(f"任务 {task_id} 状态更新: {status}")

    if status == "SUCCESS":
        image_url = data.get("imageUrl")
        print(f"图片地址: {image_url}")

    return jsonify({"success": True})

app.run(port=8080)
```

```javascript Node.js (Express)
const express = require('express');
const app = express();
app.use(express.json());

app.post('/api/callback', (req, res) => {
  const { id, status, imageUrl } = req.body;
  console.log(`任务 ${id} 状态: ${status}`);

  if (status === 'SUCCESS') {
    console.log(`图片: ${imageUrl}`);
  }

  res.json({ success: true });
});

app.listen(8080);
```

</CodeGroup>

<Warning>
  コールバック URL はインターネット上からアクセス可能である必要があります。サーバーが POST リクエストを受信でき、5秒以内に200ステータスコードで応答できることを確認してください。
</Warning>

<Note>
  コールバックに失敗した場合、システムは最大3回までリトライを行い、間隔はそれぞれ10秒、30秒、60秒となります。
</Note>
