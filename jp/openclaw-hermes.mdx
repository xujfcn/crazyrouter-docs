> 内容更新日: 2026-10-12

[crazyrouter-hermes](https://github.com/xujfcn/crazyrouter-hermes)を使って[Hermes Agent](https://github.com/NousResearch/Hermes-Agent)のモデルプロバイダーをCrazyrouterに切り替えることができます。設定後、Hermesは`https://api.crazyrouter.com/v1`をOpenAI互換エンドポイントとして利用し、Claude、GPT、DeepSeek、Gemini、Qwen、627以上のモデルを1つのCrazyrouter API Keyで呼び出せます。

## 対象者

- Hermes Agentの利用者で、Crazyrouterをモデルプロバイダーとして使いたい方
- モデルやクオータをCrazyrouterで管理したいローカルagentシナリオ
- `OPENAI_API_KEY`、`OPENAI_BASE_URL`、及びデフォルトモデルを一括設定したい方

## 必要条件

| 項目 | 説明 |
|------|----------|
| Hermes Agent | Hermesをローカルにインストールし、正常に起動することを確認してください |
| Crazyrouterアカウント | [crazyrouter.com](https://crazyrouter.com)でアカウントを作成してください |
| Crazyrouter API Key | Hermes用に個別の`sk-...`トークン作成を推奨します |
| モデルアクセス | 使用予定のモデルをトークンに許可してください |

<Tip>
HermesはOpenAI互換設定を通じてCrazyrouterと接続します。Base URLには`https://api.crazyrouter.com/v1`を入力してください。
</Tip>

<Warning>

</Warning>

## 手動による設定

スクリプトを実行したくない場合は、Hermesの設定を手動で行ってください。

### 環境変数

`~/.hermes/.env`を編集してください:

```bash
OPENAI_API_KEY=sk-your-crazyrouter-key
OPENAI_BASE_URL=https://api.crazyrouter.com/v1
```

### デフォルトモデル

`~/.hermes/config.yaml`を編集してください:

```yaml
model:
  provider: "custom"
  default: "claude-opus-4-8"
  base_url: "https://api.crazyrouter.com/v1"
```

`default`は、Crazyrouterトークンで許可された任意のモデルに置き換えてください。

## モデルの切り替え

設定後はHermes内で`/model`を使ってモデルを切り替えられます:

```text
/model claude-opus-4-8
/model gpt-5.5
/model claude-sonnet-4-6
/model gemini-3.1-pro
/model deepseek-v4-pro
/model qwen-max
/model gpt-4o
```

切り替え時に`model not allowed`や`403`が表示された場合、選択したモデルが現在のCrazyrouterトークンで許可されていない事が多いです。

## チェックリスト

- [ ] `OPENAI_API_KEY` in `~/.hermes/.env`は有効なCrazyrouterトークンである
- [ ] `OPENAI_BASE_URL`が`https://api.crazyrouter.com/v1`と一致している
- [ ] `provider` in `~/.hermes/config.yaml`が`custom`と一致している
- [ ] デフォルトモデルがCrazyrouterトークンで許可されている
- [ ] Hermesがテストメッセージに応答する
- [ ] `/model gpt-5.5`または他の許可されたモデルが正しく切り替えられる

## よくある問題

| 症状 | 推定原因 | 対処方法 |
|---------|-------------------|---------|
| `401 unauthorized` | API Keyが無効・期限切れ・上書きされた | 新しいCrazyrouterトークンを作成し、`~/.hermes/.env`を更新してください |
| `403` または `model not allowed` | トークンが選択モデルを許可していない | Crazyrouterトークン設定でモデルを許可してください |
| Hermesが以前のプロバイダーを使用している | 設定ファイルの再読込不足・別ファイルの変更 | Hermesを再起動し、`~/.hermes/.env`と`~/.hermes/config.yaml`の状態を確認してください |
| 接続タイムアウト | ローカルネットワークがCrazyrouterに接続できない | proxy、firewall、DNSを確認してください |
