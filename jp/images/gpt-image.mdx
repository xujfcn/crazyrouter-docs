# GPT Image

`gpt-image-2` は OpenAI Images API の互換パスで呼び出せます：

```text
POST /v1/images/generations
POST /v1/images/edits
```

<Warning>
  `gpt-image-2` 画像生成リクエストは、主経路`https://api.crazyrouter.com/v1` を優先してご利用ください。完全な生成エンドポイントは `https://api.crazyrouter.com/v1/images/generations` です。アカウントのログイン・チャージ・コンソールは引き続き `https://crazyrouter.com` をご利用ください。
</Warning>

## 画像生成

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | 必須 | 固定値 `gpt-image-2` |
| `prompt` | string | 必須 | 画像の説明プロンプト |
| `n` | integer | 任意 | 生成する枚数、デフォルトは `1`、範囲は `1-10` |
| `size` | string | 任意 | `auto` または `幅×高さ`。幅と高さは16の倍数で、1辺3840以下、総ピクセル数は 655360 から 8294400 の間、縦横比は最大3:1まで。よく使う値：`1024x1024`、`1536x1024`、`1024x1536` |
| `quality` | string | 任意 | `auto`、`low`、`medium`、`high`。`hd` にも対応、サーバー側で`high`に正規化されます。`standard` も同様で、サーバー側で `auto`に正規化されます |
| `background` | string | 任意 | `auto` または `opaque`。`gpt-image-2`は`transparent`をサポートしません |
| `output_format` | string | 任意 | `png`、`jpeg`、`webp` |
| `output_compression` | integer | 任意 | `0-100`、`output_format`が`jpeg`または`webp`の場合のみ有効 |
| `moderation` | string | 任意 | `auto`または`low` |
| `stream` | boolean | 任意 | SSEストリームレスポンスを使用するかどうか |
| `partial_images` | integer | 任意 | `0-3`、`stream=true`の場合のみ使用可能 |
| `user` | string | 任意 | エンドユーザー識別子 |

レガシーDALL-E / OpenAI Imagesクライアントと互換性を持たせるため、`gpt-image-2`は`response_format=url`、`response_format=b64_json`、`quality=standard`、`style=vivid/natural`を受け付けます。そのうち`response_format`と`style`は上流へは転送されず、`quality=standard`は`auto`へ正規化されます。

<Warning>
  `response_format`はCrazyrouterが旧クライアント用に残した互換フィールドで、`gpt-image-2`上流パラメータではありません。新しい接続時は`output_format="png"`、`"jpeg"`、`"webp"`で画像ファイル形式を制御し、レスポンスの`data[0].url`をデフォルトで読み取ってください。旧クライアントが`response_format="b64_json"`を送信した場合、サーバー側はbase64レスポンスの意味をできるだけ保ちます。
</Warning>

引き続き拒否されるパラメータの組み合わせ例：`input_fidelity`、`background=transparent`、`output_format=png` と `output_compression` の併用。

### リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只穿着宇航服的猫咪在月球上行走，背景是地球",
    "n": 1,
    "size": "1024x1024",
    "quality": "low",
    "output_format": "png"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.generate(
    model="gpt-image-2",
    prompt="一只穿着宇航服的猫咪在月球上行走，背景是地球",
    n=1,
    size="1024x1024",
    quality="low",
    output_format="png",
)

print(response.data[0].url)
```

</CodeGroup>

### ストリーム生成

`gpt-image-2`は`stream=true`に対応しています。リクエストに`partial_images`が含まれる場合、同時に`stream`を有効にし、値の範囲は`0-3`としてください。

```bash cURL
curl -N -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一个蓝色极简验证图标，白色背景",
    "size": "1024x1024",
    "quality": "high",
    "stream": true,
    "partial_images": 2
  }'
```

<Note>
  `quality=high`や互換書式`quality=hd`の同期リクエストは処理に時間がかかる場合があります。画像生成系は`https://api.crazyrouter.com/v1`を優先利用してください。高品質なリクエストには`stream=true`を使うか、クライアント側タイムアウトを180秒以上に設定してください。
</Note>

## 画像編集

```
POST /v1/images/edits
```

既存の画像に基づき編集を行います。マスク領域編集に対応し、複数の参考画像を使用した合成、スタイル転送、部分的な合成にも対応します。

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | 必須 | 固定値 `gpt-image-2` |
| `image` / `image[]` | file または file[] | 必須 | 元画像または参考画像ファイル（multipart）；`gpt-image-2`は最大`16`枚まで参考画像をサポート |
| `prompt` | string | 必須 | 編集内容説明 |
| `mask` | file | 任意 | マスク画像、透明部分が編集対象範囲となります |
| `n` | integer | 任意 | 生成数、デフォルトは`1`、範囲は`1-10` |
| `size` | string | 任意 | 画像生成エンドポイントと同様 |
| `quality` | string | 任意 | `auto`、`low`、`medium`、`high`；`hd`は`high`へ正規化されます |
| `background` | string | 任意 | `auto`または`opaque` |
| `output_format` | string | 任意 | `png`、`jpeg`、`webp` |
| `output_compression` | integer | 任意 | `0-100`。`output_format`が`jpeg`または`webp`のとき有効 |
| `stream` | boolean | 任意 | SSEストリームレスポンスを使用するかどうか |
| `partial_images` | integer | 任意 | `0-3`、`stream=true`のとき使用 |

### 単一画像編集例

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.edit(
    model="gpt-image-2",
    image=open("original.png", "rb"),
    mask=open("mask.png", "rb"),
    prompt="在天空中添加一道彩虹",
    n=1,
    size="1024x1024",
    quality="low",
)

print(response.data[0].url)
```

### 複数画像リファレンス編集例

複数画像編集リクエストは`multipart/form-data`の使用が必須です。複数の`image[]`フィールドで参考画像を送るのが推奨です。サーバー側は`image`フィールドの繰り返しにも対応します。

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/edits \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=gpt-image-2" \
  -F "prompt=把第一张图的人物与第二张图的背景融合成一张自然的宣传图" \
  -F "size=1024x1024" \
  -F "quality=low" \
  -F "n=1" \
  -F "image[]=@person.png" \
  -F "image[]=@background.png"
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/images/edits",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    data={
        "model": "gpt-image-2",
        "prompt": "把第一张图的人物与第二张图的背景融合成一张自然的宣传图",
        "size": "1024x1024",
        "quality": "low",
        "n": "1",
    },
    files=[
        ("image[]", ("person.png", open("person.png", "rb"), "image/png")),
        ("image[]", ("background.png", open("background.png", "rb"), "image/png")),
    ],
    timeout=240,
)

response.raise_for_status()
print(response.json()["data"][0]["url"])
```

</CodeGroup>

<Note>
  `gpt-image-2`の複数参考画像は最大16枚まで対応します。複数画像リクエストは、公式OpenAI多画像対応チャネルに優先的にルーティングされます。
</Note>
