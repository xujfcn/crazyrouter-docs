# Flux

<Warning>
  現在の Crazyrouter 料金ページでは、直接呼び出し可能な Flux `model_name` は公開されていません。このページではもはや Flux のリクエスト例は提供しておらず、古い `flux-*` モデル ID は本番環境の設定に使用しないでください。
</Warning>

## 現在の代替案

画像生成や編集には、料金ページで現在公開中のモデルを推奨します:

| 利用ケース | 推奨モデル |
|----------|------------------|
| OpenAI Images | `gpt-image-2` |
| Gemini Images | `nano-banana`, `nano-banana-2`, `nano-banana-pro` |
| Grok Images | `grok-4-image` |
| Qwen Images | `qwen-image-2.0`, `qwen-image-plus`, `qwen-image-max` |
| Doubao Images | `doubao-seedream-4-5`, `doubao-seedream-5-0` |

## 確認方法

`https://crazyrouter.com/pricing` と `GET /v1/models` で返される現在のモデルリストを信頼できる情報源として利用してください。公開されていて正常にリクエストを送信できるモデルのみを、ドキュメント例や顧客向けのデフォルトとして使用してください。
