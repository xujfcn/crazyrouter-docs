# Nano Banana Pro

```
POST /v1/images/generations
```

`nano-banana-pro` を使用して画像生成およびリファレンス画像編集を行い、`OpenAI Images API` スタイルの公開プロトコルに統一されています。

<Warning>
  画像生成、画像編集、多参考画像などのリクエストは一般的に処理時間が長くなります。プロダクション利用時はメインの受け入れライン `https://api.crazyrouter.com/v1` を最優先してご利用ください。完全な生成エンドポイントは `https://api.crazyrouter.com/v1/images/generations` です。アカウントのログイン、チャージ、コンソールは引き続き `https://crazyrouter.com` をご利用ください。
</Warning>

## このページの対象範囲

- 本ページは `nano-banana-pro` / `nano-banana-pro` のみが対象です。
- クライアントからのリクエスト入口は統一して `POST /v1/images/generations` です。
- 入力画像フィールドは統一して `image_input` です。
- デフォルトの公開プロトコルは `image_input` URL の使用を推奨します。指定グレースケールアカウントのみ追加で dataURL、raw Base64、三画像 multipart による画像編集に対応しています。
- `data:` / Base64 / multipart はCrazyrouterの拡張互換機能であり、すべての上流 carrier がネイティブにサポートするわけではありません。
- バックエンドには Gemini / Vertex などの provider が利用されることがありますが、これら provider の詳細はクライアントプロトコルの一部ではありません。
- ユーザー側から `generationConfig`、`imageConfig`、`imageOutputOptions`、`image_output_options` を送信しないでください。これらフィールドは Crazyrouter が統一パラメータから自動変換します。

## 機能ステータス

| 機能 / スペック | ステータス | 説明 |
|------|------|------|
| `T2I` | `Beta` | 過去にカバーされていますが、現在公開されている artifact セットは編集／リファレンス画像パスが主軸です |
| `I2I + 1K` | `Verified` | 単一画像編集の live はクローズドループ済み |
| `I2I + 4K` | `Verified` | `4K + 21:9 + png/jpeg/jpg` の live はクローズドループ済み |
| `Reference + 1..2 refs` | `Verified` | `2` 画像の live はクローズドループ済み |
| `11257` グレースケール：dataURL / raw Base64 | `Verified` | プロダクションチャンネル304で単一画像および三画像の `image_input` 検証済み |
| `11257` グレースケール：三画像 multipart | `Verified` | `/v1/images/edits`、`image`、`image[]`、`image[n]` サポート |
| `2K` | `Beta` | 現在公開されている artifact は今後補足予定 |
| より高い多画像上限／精確な `30 MiB` 境界 | `Beta` | 公開されている contract では現在保証していません |

<Note>
  Pricing ページと本ドキュメントは同じステータス基準を使用します：`Verified` が現在存在する最小 live クローズドループを表し、`Beta` は公式機能があるものの公開検証や境界条件の補足が続いていることを意味します。
</Note>

## 現在検証済みの機能

以下の結論は、過去の live 検証および `2026-08-18` のプロダクショングレースケール検証に基づきます：

- 公式 Vertex `channel 318 (vertexsophie)` 直結で検証済み：
  - `2` 枚のリファレンス画像が利用可能
- ローカル `4000` ポート、固定 `channel 318` で検証済み：
  - 単一 `WEBP` URL リファレンス画像利用可能
  - 単一 `JPEG` URL リファレンス画像利用可能
  - `2` 枚の `PNG` URL リファレンス画像利用可能
  - `resolution: "1K"` 利用可能
  - `resolution: "4K"` 利用可能
  - `aspect_ratio: "1:1"` 利用可能
  - `aspect_ratio: "21:9"` 利用可能
  - `output_format: "png"` 利用可能
  - `output_format: "jpg"` 利用可能
- 応答で `data[].url` を直接返すことが可能

指定グレースケールアカウント `11257` はプロダクションチャネル `304` で検証済み：

- `/v1/images/generations` の `image_input` は dataURL、raw Base64、複数画像入力に対応
- `/v1/images/edits` の multipart 対応 `image`、`image[]`、`image[n]`
- オリジナル・アノテーション画像・リファレンス画像をアップロード順で三画像編集リクエストとして構成可能

下記の機能については、現時点ではお客様向けに完全に保証されているわけではありません：

- 精確な複数画像上限が `8` またはそれ以上かどうか
- `2K`
- 精確な大ファイル URL 上限
- 精確な `30 MiB` 境界
- その他 `aspect_ratio` 組み合わせ
- `output_compression` の精確な意味的境界

<Note>
  デフォルトアカウントは引き続き URL のみの公開基準で取り扱われます。Base64、dataURL、multipart 画像編集は現時点では特定グレースケールアカウントのみ対応です。ご利用を希望される場合は、あらかじめアカウントがグレースケールリストへ追加されていることをご確認ください。
</Note>

## リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | 必須 | `nano-banana-pro` を推奨。`nano-banana-pro` もサポートしています |
| `prompt` | string | 必須 | 生成または編集の指示 |
| `image_input` | string または string[] | 任意 | デフォルトはリファレンス画像URL。グレースケールアカウントなら dataURL/raw Base64 も使用可。現在三画像検証済み |
| `resolution` | string | 任意 | 現在公開されている `1K` および `4K` を保証 |
| `aspect_ratio` | string | 任意 | 現在公開されている `1:1` および `21:9` を保証 |
| `output_format` | string | 任意 | 現在公開されている `png`、`jpeg`/`jpg` を保証 |
| `output_compression` | integer | 任意 | `0-100`、JPEG 圧縮品質用 |
| `n` | integer | 任意 | 生成枚数。デフォルトは `1` |

### 複数画像の現況

- `2` 枚：検証済み
- `11257` グレースケール三画像：検証済み
- さらに多い枚数：上流の厳密な最大値は未検証のため現時点では保証しません

### ルーティングの説明

- 単一画像リクエストは一般的なバックエンドに命中可能
- デフォルトでは複数画像リクエストは公式 `Gemini / Vertex` carrier のみをルートします。指定グレースケールアカウントなら検証済みのグレーキャリア利用可
- これはサーバ側の内部ルーティング戦略であり、クライアントプロトコルには変更ありません

### グレースケール三画像 multipart

`11257` グレースケールアカウントは `/v1/images/edits` を利用可能：

```bash
curl -X POST https://api.crazyrouter.com/v1/images/edits \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=nano-banana-pro" \
  -F "prompt=以第一张为原图，第二张为批注图，第三张为参考图，仅修改批注区域" \
  -F "image[]=@original.png" \
  -F "image[]=@annotation.png" \
  -F "image[]=@reference.png"
```

画像の順序はクライアントの送信順に従います。アノテーション画像は現状、視覚的参考としてのみ利用され、GPTマスクのようなピクセル単位の領域ロックは保証していません。

## 現在判明している制限事項

- 非グレースケールアカウントは `image`、`data:` / Base64 または multipart 画像入力は受け付けません
- グレースケールアカウントは現在3画像まで検証済みで、さらに多い枚数上限は保証しません
- 本ドキュメントは`30 MiB` URL境界を厳密に保証するものではありません
- 本ページに掲載の全ての比率とパラメータが完全クローズドで運用中であると保証するものではありません
