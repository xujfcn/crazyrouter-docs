# AIGC Kling 3.0 画像生成

`aigc-image-kling-3.0` は、Crazyrouter が Tencent VOD 回線を通じて提供する Kling 3.0 テキストから画像生成モデルです。クライアントは OpenAI Images 互換インターフェースを利用してください：

```http
POST /v1/images/generations
```

<Warning>
  完全なエンドポイントは `https://api.crazyrouter.com/v1/images/generations` です。本モデルを `/kling/v1/images/generations` に送信しないでください。また、モデル名を動画モデル `aigc-video-kling-3.0` としないでください。
</Warning>

## リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | 固定値：`aigc-image-kling-3.0` |
| `prompt` | string | はい | 画像生成のプロンプト |
| `aspect_ratio` | string | いいえ | 出力比率。よく使われる値：`1:1`、`16:9`、`9:16`、`4:3`、`3:4`。デフォルトは `1:1` |
| `size` | string | いいえ | 互換サイズ記法を入力できます。サーバーはこれを出力比率に変換します。下表参照 |

現在公開されている機能はテキストから画像生成です。本モデルのリクエストで参考画像の送信や `/v1/images/edits` の利用はしないでください。

### サイズと比率

通常は `aspect_ratio` を直接指定するのを推奨します。もし `size` を使用した場合の現行換算ルールは下記の通りです：

| `size` | 実際の出力比率 |
|------|------|
| `1024x1024` | `1:1` |
| `1792x1024`、`1536x1024` | `16:9` |
| `1024x1792`、`1024x1536` | `9:16` |
| `1024x768` | `4:3` |
| `768x1024` | `3:4` |

<Note>
  `aspect_ratio` と `size` の両方を指定した場合は `aspect_ratio` が優先されます。その他の未記載 `size` は現時点で `1:1` として扱われます。
</Note>

## リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-image-kling-3.0",
    "prompt": "一张电影感的未来城市夜景，雨后的街道反射霓虹灯光，画面细节丰富",
    "aspect_ratio": "16:9"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/images/generations",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json",
    },
    json={
        "model": "aigc-image-kling-3.0",
        "prompt": "一张电影感的未来城市夜景，雨后的街道反射霓虹灯光，画面细节丰富",
        "aspect_ratio": "16:9",
    },
    timeout=240,
)

response.raise_for_status()
result = response.json()
print(result["data"][0]["url"])
```

</CodeGroup>

## 処理時間について

Tencent VOD 側は非同期タスクとして処理していますが、Crazyrouter サーバー側ではタスクが完了するまで待機し、最終的な OpenAI Images 形式の結果を同じ HTTP リクエストで返します。クライアントによるタスクの追加問い合わせは不要です。

<Note>
  画像生成には数十秒かかる場合があります。クライアントのタイムアウトは最低 `240` 秒以上に設定し、リクエスト完了までお待ちください。一時的に応答がないからといってすぐに再送しないでください。そうすると重複タスクや二重請求が発生する可能性があります。
</Note>

## 他の Kling モデルとの違い

| モデル | 用途 | リクエストパス |
|------|------|------|
| `aigc-image-kling-3.0` | Tencent VOD Kling 3.0 テキストから画像生成 | `POST /v1/images/generations` |
| `aigc-video-kling-3.0` | Tencent VOD Kling 3.0 動画生成 | `POST /v1/video/generations` |
| ネイティブKling 画像モデル | ネイティブ Kling 画像プロトコル | `POST /kling/v1/images/generations` |

本モデルは画像が正常に生成された場合のみ料金が発生します。リアルタイム料金、割引、利用可能状況は [料金ページ](https://crazyrouter.com/ja/pricing) およびAPIキーで取得できる現在の `GET /v1/models` を参照してください。
