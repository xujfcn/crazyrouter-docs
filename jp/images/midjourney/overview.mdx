# Midjourney 概要

Crazyrouter は Midjourney API の完全なプロキシを提供し、Imagine、Blend、Describe、Upscale、Variation などすべての操作をサポートしています。すべてのリクエストは非同期タスクとして処理されます。

## 基本パス

```
https://api.crazyrouter.com/mj
```

## 認証

リクエストヘッダーに API Key を含めてください：

```
Authorization: Bearer YOUR_API_KEY
```

---

## タスクオブジェクト

Midjourney リクエストを送信すると、システムはタスクオブジェクトを返します。タスクオブジェクトは以下のフィールドを含みます：

| フィールド | 型 | 説明 |
|------|------|------|
| `id` | string | タスクのユニーク識別子 |
| `action` | string | タスクタイプ：`IMAGINE`、`UPSCALE`、`VARIATION`、`BLEND`、`DESCRIBE` など |
| `status` | string | タスクステータス |
| `prompt` | string | 提供されたプロンプト |
| `promptEn` | string | 翻訳された英語プロンプト |
| `description` | string | タスク説明 |
| `submitTime` | number | 提出時刻（ミリ秒タイムスタンプ） |
| `startTime` | number | 処理開始時刻 |
| `finishTime` | number | 完了時刻 |
| `progress` | string | 進捗率、例：`"100%"` |
| `imageUrl` | string | 生成された画像 URL |
| `failReason` | string | 失敗理由（失敗時のみ値が入る） |
| `properties` | object | 追加属性 |
| `buttons` | array | 実行可能な操作ボタン一覧 |

---

## タスクステータス

| ステータス | 説明 |
|------|------|
| `NOT_START` | タスクが提出され、処理待ち |
| `SUBMITTED` | タスクが Midjourney に提出済み |
| `IN_PROGRESS` | タスク処理中 |
| `SUCCESS` | タスク完了 |
| `FAILURE` | タスク失敗 |

---

## 操作ボタン

タスク完了後、`buttons` フィールドに後続操作が含まれます：

```json
{
  "buttons": [
    {"customId": "MJ::JOB::upsample::1::hash", "emoji": "U1", "label": "U1", "style": 2},
    {"customId": "MJ::JOB::upsample::2::hash", "emoji": "U2", "label": "U2", "style": 2},
    {"customId": "MJ::JOB::upsample::3::hash", "emoji": "U3", "label": "U3", "style": 2},
    {"customId": "MJ::JOB::upsample::4::hash", "emoji": "U4", "label": "U4", "style": 2},
    {"customId": "MJ::JOB::variation::1::hash", "emoji": "V1", "label": "V1", "style": 2},
    {"customId": "MJ::JOB::variation::2::hash", "emoji": "V2", "label": "V2", "style": 2},
    {"customId": "MJ::JOB::variation::3::hash", "emoji": "V3", "label": "V3", "style": 2},
    {"customId": "MJ::JOB::variation::4::hash", "emoji": "V4", "label": "V4", "style": 2}
  ]
}
```

`customId` を利用し、Action インターフェースから対応する操作（アップスケール、バリエーション等）を実行できます。

## API エンドポイント一覧

| メソッド | エンドポイント | 説明 |
|------|------|------|
| POST | `/mj/submit/imagine` | Imagine タスクを提出 |
| POST | `/mj/submit/action` | 操作実行（アップスケール、バリエーションなど） |
| POST | `/mj/submit/blend` | 画像のブレンド |
| POST | `/mj/submit/describe` | 画像の説明 |
| POST | `/mj/submit/modal` | ポップアップ確認を提出 |
| POST | `/mj/submit/shorten` | プロンプトを短縮 |
| GET | `/mj/task/{id}/fetch` | 単一タスクの照会 |
| POST | `/mj/task/list-by-condition` | タスクを一括照会 |
| GET | `/mj/task/{id}/image-seed` | 画像の Seed を取得 |

<Note>
  Midjourney タスクは非同期で処理されるため、送信後はタスクステータスをポーリングチェックする必要があります。3～5秒ごとにステータスを照会し、状態が `SUCCESS` または `FAILURE` になるまで繰り返してください。
</Note>
