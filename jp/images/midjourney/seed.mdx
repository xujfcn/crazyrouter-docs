# シード値の取得

```
GET /mj/task/{id}/image-seed
```

完了したタスクの画像シード値を取得します。シード値は、類似した生成結果を再現するために利用できます。

## リクエスト例

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/mj/task/task_1234567890/image-seed \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.crazyrouter.com/mj/task/task_1234567890/image-seed",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)

print(response.json())
```

</CodeGroup>

## レスポンス例

```json
{
  "code": 1,
  "description": "成功",
  "result": "1234567890"
}
```

| フィールド | 説明 |
|------|------|
| `result` | シード値。Imagineのプロンプトで`--seed 1234567890`を使うことで再現が可能 |

---

## Seedの利用方法

Imagineリクエストのプロンプトに`--seed`パラメータを追加します：

```json
{
  "prompt": "a beautiful sunset over the ocean --ar 16:9 --v 6 --seed 1234567890"
}
```

<Note>
  シード値はタスクが正常に完了した後のみ取得可能です。同じシード値＋同じプロンプトで、非常に似ている（しかし完全に同じではない）画像を生成できます。
</Note>
