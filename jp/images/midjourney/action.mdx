# 実行操作

## Action - アップスケール / バリエーション

```
POST /mj/submit/action
```

完了した Imagine タスクに対して、アップスケール（Upscale）、バリエーション（Variation）などの後続操作を実行します。

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `taskId` | string | はい | 元のタスクID |
| `customId` | string | はい | 操作ボタンの `customId`、タスクの `buttons` フィールドから取得 |
| `notifyHook` | string | いいえ | コールバックURL |
| `state` | string | いいえ | カスタムステータス |

### リクエスト例

```bash cURL
curl -X POST https://api.crazyrouter.com/mj/submit/action \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "taskId": "task_1234567890",
    "customId": "MJ::JOB::upsample::1::abc123"
  }'
```

### レスポンス例

```json
{
  "code": 1,
  "description": "提交成功",
  "result": "task_action_001",
  "properties": {}
}
```

## Blend - 画像合成

```
POST /mj/submit/blend
```

複数の画像を合成して新しい画像を生成します。

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `botType` | string | いいえ | `MID_JOURNEY`（デフォルト）または `NIJI_JOURNEY` |
| `base64Array` | array | はい | Base64 エンコードされた画像の配列（2～5枚） |
| `dimensions` | string | いいえ | 出力サイズ：`PORTRAIT`、`SQUARE`、`LANDSCAPE` |
| `notifyHook` | string | いいえ | コールバックURL |
| `state` | string | いいえ | カスタムステータス |

### リクエスト例

```bash cURL
curl -X POST https://api.crazyrouter.com/mj/submit/blend \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "base64Array": [
      "data:image/png;base64,iVBORw0KGgo...",
      "data:image/png;base64,iVBORw0KGgo..."
    ],
    "dimensions": "SQUARE"
  }'
```

### レスポンス例

```json
{
  "code": 1,
  "description": "提交成功",
  "result": "task_blend_001"
}
```

## Describe - 画像説明


画像をアップロードして、Midjourney に対応したプロンプト説明文を生成してもらいます。

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `botType` | string | いいえ | `MID_JOURNEY`（デフォルト）または `NIJI_JOURNEY` |
| `base64` | string | はい | Base64 エンコードされた画像 |
| `notifyHook` | string | いいえ | コールバックURL |
| `state` | string | いいえ | カスタムステータス |

### リクエスト例

```bash cURL
curl -X POST https://api.crazyrouter.com/mj/submit/describe \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "base64": "data:image/png;base64,iVBORw0KGgo..."
  }'
```

## Modal - ポップアップ確認

```
POST /mj/submit/modal
```

Midjourney のポップアップ確認操作（Region Vary など再確認が必要な操作）を送信します。

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `taskId` | string | はい | 元のタスクID |
| `prompt` | string | いいえ | ポップアップのプロンプト文 |
| `maskBase64` | string | いいえ | マスク画像のBase64エンコード |

### リクエスト例

```bash cURL
curl -X POST https://api.crazyrouter.com/mj/submit/modal \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "taskId": "task_1234567890",
    "prompt": "add a rainbow in the sky"
  }'
```

<Note>
  すべての操作は送信後、新しいタスクIDが返されます。結果は[タスクステータス確認](/jp/images/midjourney/query)APIで取得してください。
</Note>
