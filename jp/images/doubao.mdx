# 豆包 Seedream

```
POST /v1/images/generations
```

Crazyrouterは現在外部に対してOpenAI Images互換プロトコルで`Seedream`シリーズ画像モデルを公開しています。クライアントは引き続き統一された`/v1/images/generations`を使用します。ByteDance公式およびその他のサードパーティチャンネルは内部プロバイダーとしてのみ扱い、クライアントプロトコルを個別に公開しません。

## 現在公開中のモデル

| モデル | 公式対応 | 現在のクライアント機能 | ドキュメント状態 |
|------|----------|--------------|----------|
| `doubao-seedream-4-0` | Seedream 4.0 | テキストから画像生成、画像から画像生成、複数参照画像、グループ画像出力 | Beta |
| `doubao-seedream-4-5` | Seedream 4.5 | テキストから画像生成、画像から画像生成、複数参照画像、グループ画像出力 | Beta |
| `doubao-seedream-5-0` | Seedream 5.0 lite | テキストから画像生成、画像から画像生成、複数参照画像、グループ画像出力 | Beta |
| `doubao-seedream-3-0` | Seedream 3.0 | 互換性維持 | Legacy |

<Note>
 ここでの「Beta」の意味は：クライアントプロトコルと公式機能定義はすでに整合しているが、現在の運用負荷と実地artifactが引き続き補完中です。公式機能は先に完全な形で記載し、未完成部分はBetaのラベルを残しています。
</Note>

## クライアントプロトコル

### リクエストパラメータ

| パラメータ | タイプ | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | `doubao-seedream-4-0`、`doubao-seedream-4-5`、`doubao-seedream-5-0` |
| `prompt` | string | はい | 生成プロンプト |
| `image_input` | string または string[] | いいえ | 参照画像URL。公式4.0/4.5/5.0 liteの現時点の上限は`14`枚 |
| `size` | string | いいえ | 出力サイズ。`Seedream 4.5`公式は`2K`、`4K`、および範囲内の明示的な幅と高さをサポート；`Seedream 5.0 lite`は現在幅×高さの総ピクセル数が最低`3,686,400`必要 |
| `n` | integer | いいえ | 出力枚数。デフォルトは`1` |
| `response_format` | string | いいえ | `url`または`b64_json` |
| `watermark` | boolean | いいえ | ウォーターマーク付与の有無 |
| `sequential_image_generation` | string | いいえ | `auto`または`disabled`；グループ画像出力や連続生成のセマンティクス用 |
| `optimize_prompt_options` | object | いいえ | 公式プロンプト最適化オプション；現在`Seedream 4.5`と`5.0 lite`は`mode: "standard"`のみ確認済み |

### Seedream 5.0 サイズ要件

`doubao-seedream-5-0`の明示的な`幅×高さ`サイズは以下を満たす必要があります：

```text
宽 × 高 >= 3,686,400
```

| サイズ | 総ピクセル数 | 最低基準を満たすか |
|------|--------|------------------|
| `2688x1152` | `3,096,576` | いいえ；上流で`InvalidParameter`が返されます |
| `2048x2048` | `4,194,304` | はい；ただしモデル対応の幅・高さ・比率範囲も満たす必要 |

<Warning>
  同じ不正なサイズに対して繰り返し試行したり、モデルの利用不可と判断しないで下さい。エラーログに「Service temporarily unavailable」や「The requested model is temporarily unavailable」と表示された場合はまず`size`を確認してください。現時点の一般的なエラーログは上流の詳細なサイズエラーが隠れている場合があります。
</Warning>

### 参照画像の制約

- `Seedream 4.0`、`4.5`、`5.0 lite`公式は最大`14`枚の参照画像をサポート
- 1枚あたり参照画像の最大は`10MB`
- 公式サポート入力フォーマットは`jpeg`、`png`、`webp`、`bmp`、`tiff`、`gif`まで拡張
- 公式サポート入力画像の縦横比範囲は`1/16`～`16`

### リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "doubao-seedream-4-5",
    "prompt": "一张高级感产品海报，主体是一只透明玻璃香水瓶，晨雾光线，简洁中文标题",
    "size": "2K",
    "n": 1,
    "response_format": "url",
    "watermark": false,
    "optimize_prompt_options": {
      "mode": "standard"
    }
  }'
```

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "doubao-seedream-4-5",
    "prompt": "基于这些参考图生成同一角色的一组商品海报，保持主体一致但镜头和布局不同",
    "image_input": [
      "https://example.com/ref-1.png",
      "https://example.com/ref-2.png"
    ],
    "size": "2K",
    "sequential_image_generation": "auto",
    "response_format": "url",
    "optimize_prompt_options": {
      "mode": "standard"
    }
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.images.generate(
    model="doubao-seedream-4-5",
    prompt="一张高级感产品海报，主体是一只透明玻璃香水瓶，晨雾光线，简洁中文标题",
    size="2K",
    n=1
)

print(response.data[0].url)
```

## 公式課金基準

現時点で確定している公式基準は「成功した画像生成枚数で課金する」ことで、入力/出力トークン課金表示ではありません。

| モデル | 公式課金基準 | 公式単価 | 現在のドキュメント状態 |
|------|----------|----------|--------------|
| `doubao-seedream-4-0` | 画像枚数単位 | `1枚あたり$0.03` | 公式と一致済み |
| `doubao-seedream-4-5` | 画像枚数単位 | `1枚あたり$0.04` | 公式と一致済み |
| `doubao-seedream-5-0` | 画像枚数単位 | 公式価格未決定 | Beta |

## 整合説明

- クライアントプロトコルは統一された`/v1/images/generations`に収束済み
- `Seedream 4.5`公式サイズ能力は現在`2K`、`4K`が主で、デフォルトは`2048x2048`
- `Seedream 4.5`と`5.0 lite`の`optimize_prompt_options.mode`は現時点では`standard`でのみ整合；`fast`は現時点でクライアントへの約束対象外
- `Seedream 3.0`は引き続き互換名を維持しますが、本ページの公式整合重点は既に`4.0 / 4.5 / 5.0 lite`に移行済み
