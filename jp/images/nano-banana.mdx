# ナノバナナ

```
POST /v1/images/generations
```

`nano-banana` は `nano-banana` の公開エイリアスです。ユーザー側は OpenAI Images 互換のプロトコルを一括して使います。Gemini / Vertex のネイティブ処理、フィールド変換とルーティング選択は全てサービス側のCrazyrouterで自動的に行われます。

<Warning>
  画像生成・編集・マルチリファレンス画像のリクエストは一般的に処理が長時間かかります。商用導入の場合は優先してメインのエンドポイント `https://api.crazyrouter.com/v1` のご利用を推奨します。完全な生成エンドポイントは `https://api.crazyrouter.com/v1/images/generations` です。アカウントのログイン、チャージや管理コンソールは引き続き `https://crazyrouter.com` をご利用ください。
</Warning>

## モデル名

| 推奨モデル名 | 等価な基盤モデル |
|------|------|
| `nano-banana` | `nano-banana` |

クライアントコードでは `nano-banana` の利用を推奨します。もし既にシステムで `nano-banana` を直接指定されている場合でも、そのまま同じ `/v1/images/generations` エンドポイントからご利用いただけます。

## リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | 推奨：`nano-banana`。`nano-banana` も互換あり |
| `prompt` | string | はい | 生成・編集指示 |
| `image_input` | string または string[] | いいえ | 参照画像URL。未指定の場合はテキストから画像生成 |
| `resolution` | string | いいえ | `1K`、`2K`、`4K` |
| `aspect_ratio` | string | いいえ | `1:1`、`16:9`、`9:16`、`21:9`、`auto` など |
| `output_format` | string | いいえ | `png`、`jpeg` または `jpg` |
| `output_compression` | integer | いいえ | `0-100`。JPEG圧縮クオリティ用 |
| `n` | integer | いいえ | 生成数。デフォルトは `1` |

<Note>
  クライアントリクエスト内では Gemini のネイティブフィールド例：`generationConfig`、`imageConfig`、`imageOutputOptions`、`image_output_options` を直接渡さないでください。これらは上流プロバイダー仕様の詳細であり、Crazyrouter 側で統一パラメータから自動変換されます。
</Note>

## テキストから画像生成例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana",
    "prompt": "A clean banana icon on a white background, minimal product style",
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "png"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.generate(
    model="nano-banana",
    prompt="A clean banana icon on a white background, minimal product style",
    n=1,
    extra_body={
        "resolution": "1K",
        "aspect_ratio": "1:1",
        "output_format": "png",
    },
)

print(response.data[0].url or response.data[0].b64_json)
```

</CodeGroup>

## 参照画像編集例

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana",
    "prompt": "保持主体不变，把背景改成白色电商棚拍风格",
    "image_input": [
      "https://example.com/product.png"
    ],
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "jpeg",
    "output_compression": 85
  }'
```

## レスポンス

レスポンスは OpenAI Images スタイルを維持しています。デフォルトで `data[0].url` を優先取得します。一部の互換プロバイダーでは `data[0].b64_json` を返す場合もあります。

```json
{
  "created": 1778990000,
  "data": [
    {
      "url": "https://media.crazyrouter.com/task-artifacts/2026/05/17/sync-image/request-id-1.png"
    }
  ]
}
```

## よくある間違い

| 誤り例 | 正しい例 |
|------|------|
| 直接 `/v1beta/models/nano-banana:generateContent` を呼ぶ | `POST /v1/images/generations` を利用 |
| リクエストに `image_output_options` を送信 | 統一パラメータ `output_format`、`output_compression` を使用 |
| base URL に `https://api.crazyrouter.com` のみ設定し、SDKにOpenAIパスを結合させる | OpenAI SDKは `https://api.crazyrouter.com/v1` を使用 |
