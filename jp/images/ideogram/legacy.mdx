# Ideogram 旧版

Ideogram 旧版 API は基本的な画像生成機能を提供します。

<Note>
  より良い生成結果を得るために [Ideogram V3](/jp/images/ideogram/v3) のご利用をおすすめします。
</Note>

## 画像生成

```
POST /ideogram/generate
```

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `image_request` | object | はい | 画像リクエストオブジェクト |
| `image_request.prompt` | string | はい | プロンプト（お題文） |
| `image_request.model` | string | いいえ | モデルバージョン：`V_2`、`V_2_TURBO` |
| `image_request.aspect_ratio` | string | いいえ | アスペクト比 |
| `image_request.magic_prompt_option` | string | いいえ | プロンプト強化 |
| `image_request.style_type` | string | いいえ | スタイルタイプ |
| `image_request.negative_prompt` | string | いいえ | ネガティブプロンプト（否定的ワード） |

### リクエスト例

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "image_request": {
      "prompt": "A futuristic cityscape at night with neon lights",
      "model": "V_2",
      "aspect_ratio": "ASPECT_16_9",
      "magic_prompt_option": "AUTO"
    }
  }'
```

### レスポンス例

```json
{
  "created": 1709123456,
  "data": [
    {
      "url": "https://ideogram.ai/assets/image/...",
      "prompt": "A futuristic cityscape at night with neon lights",
      "resolution": "1344x768",
      "seed": 67890
    }
  ]
}
```

## Remix 合成

```
POST /ideogram/remix
```

参照画像をもとにバリエーションを生成します。

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/remix \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "image_request": {
      "prompt": "Same scene in anime style",
      "model": "V_2"
    },
    "image_file": "https://example.com/photo.jpg"
  }'
```

## 画像アップスケール

```
POST /ideogram/upscale
```

画像を高解像度へ拡大します。

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/upscale \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "image_request": {
      "prompt": "high quality detailed image"
    },
    "image_file": "https://example.com/photo.jpg"
  }'
```

## 画像説明

```
POST /ideogram/describe
```

モデルが画像の内容を説明し、対応するプロンプトを生成します。

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/describe \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "image_file": "https://example.com/photo.jpg"
  }'
```

### レスポンス例

```json
{
  "descriptions": [
    {
      "text": "A futuristic cityscape at night with vibrant neon lights reflecting off wet streets, tall skyscrapers with holographic advertisements"
    }
  ]
}
```
