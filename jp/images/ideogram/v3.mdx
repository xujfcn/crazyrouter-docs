# Ideogram V3

Ideogram V3 は最新世代のテキストから画像へのモデルであり、文字描画や画像品質が大幅に向上しています。

## 画像生成

```
POST /ideogram/v1/ideogram-v3/generate
```

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `prompt` | string | はい | 画像の説明用プロンプト |
| `aspect_ratio` | string | いいえ | アスペクト比（例：`ASPECT_1_1`、`ASPECT_16_9`、`ASPECT_9_16`） |
| `model` | string | いいえ | モデルバージョン（デフォルトは `V_3`） |
| `magic_prompt_option` | string | いいえ | プロンプト強化：`AUTO`、`ON`、`OFF` |
| `rendering_speed` | string | いいえ | レンダリング速度：`DEFAULT`、`TURBO`、`QUALITY` |
| `style_type` | string | いいえ | スタイルタイプ：`AUTO`、`GENERAL`、`REALISTIC`、`DESIGN` |
| `negative_prompt` | string | いいえ | ネガティブプロンプト |

### リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/v1/ideogram-v3/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "A serene Japanese garden with cherry blossoms, text saying \"Hello World\" on a wooden sign",
    "aspect_ratio": "ASPECT_16_9",
    "rendering_speed": "DEFAULT",
    "style_type": "REALISTIC"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/ideogram/v1/ideogram-v3/generate",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "prompt": "A serene Japanese garden with cherry blossoms",
        "aspect_ratio": "ASPECT_16_9",
        "style_type": "REALISTIC"
    }
)

print(response.json())
```

</CodeGroup>

## 画像編集

```
POST /ideogram/v1/ideogram-v3/edit
```

既存画像に対して編集・修正を行います。

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `prompt` | string | はい | 編集内容の説明 |
| `image` | string | はい | 元画像URLまたはBase64 |
| `mask` | string | いいえ | マスク画像（編集する領域を指定） |
| `style_type` | string | いいえ | スタイルタイプ |

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/v1/ideogram-v3/edit \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "Replace the sky with a starry night",
    "image": "https://example.com/photo.jpg",
    "mask": "https://example.com/mask.png"
  }'
```

## Remix画像

```
POST /ideogram/v1/ideogram-v3/remix
```

参考画像と新しいプロンプトに基づきバリエーション画像を生成します。

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `prompt` | string | はい | 新しいプロンプト |
| `image` | string | はい | 参考画像 |
| `image_weight` | number | いいえ | 参考画像の重み（0～100） |

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/v1/ideogram-v3/remix \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "Same scene but in watercolor painting style",
    "image": "https://example.com/photo.jpg",
    "image_weight": 50
  }'
```

## Reframe再構成

```
POST /ideogram/v1/ideogram-v3/reframe
```

画像キャンバスを拡張し、元画像の枠を超えた内容を生成します。

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `image` | string | はい | 元画像 |
| `resolution` | string | いいえ | 目標解像度 |

## 背景置換

```
POST /ideogram/v1/ideogram-v3/replace-background
```

被写体を自動認識し、背景を置き換えます。

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `prompt` | string | はい | 新しい背景の説明 |
| `image` | string | はい | 元画像 |

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/v1/ideogram-v3/replace-background \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "A tropical beach at sunset",
    "image": "https://example.com/portrait.jpg"
  }'
```

<Note>
  Ideogram V3 は文字描画性能が優れており、画像内に文字を含めたい用途に最適です。
</Note>
