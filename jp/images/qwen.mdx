# Qwen Image

```
POST /v1/images/generations
```

Crazyrouterは現在、OpenAI Images 互換プロトコルで`Qwen Image`の初期生成モデルを外部に提供しています。顧客は引き続き統一された`/v1/images/generations`を使用し、Alibaba公式とサードパーティの提供は内部プロバイダーとしてのみ機能し、顧客プロトコルとしては別途公開しません。

## 現在公開されているモデル

| モデル | 上流の実行形式 | 顧客向け機能 | 検証状況 |
|------|--------------|--------------|----------|
| `qwen-image-plus` | 非同期生成 | テキストから画像生成 | 検証済み |
| `qwen-image-max` | 同期生成 | テキストから画像生成 | 検証済み |
| `qwen-image-2.0` | 同期生成 | テキストから画像生成 | 検証済み |
| `qwen-image-2.0` | 同期生成 | テキストから画像生成 | Beta |

<Note>
  `qwen-image-2.0`はプロトコルとコードの整合が完了していますが、商用運用の証明がまだ補完中のため、まずBetaと記載しています。
</Note>

## 顧客プロトコル

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `model` | string | はい | `qwen-image-plus`、`qwen-image-max`、`qwen-image-2.0`、`qwen-image-2.0` |
| `prompt` | string | はい | テキストから画像生成用のプロンプト |
| `size` | string | いいえ | 出力サイズ。現行モデルページやplaygroundで対応しているサイズの利用を推奨します |
| `n` | integer | いいえ | 生成枚数。デフォルトは`1`です |
| `response_format` | string | いいえ | `url`または`b64_json` |

### リクエスト例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "qwen-image-max",
    "prompt": "一张具有高级感的产品海报，主体是一瓶玻璃香水，柔和棚拍光线，中文标题“晨雾”",
    "size": "1024x1024",
    "n": 1,
    "response_format": "url"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.images.generate(
    model="qwen-image-max",
    prompt="一张具有高级感的产品海报，主体是一瓶玻璃香水，柔和棚拍光线，中文标题“晨雾”",
    size="1024x1024",
    n=1
)

print(response.data[0].url)
```

</CodeGroup>

## 公式料金基準

Qwen Image の公式料金は、画像が生成された枚数に基づきます。入力/出力トークンでの表示はありません。

| モデル | 公式基準 | 公式単価 | 現在のドキュメント状況 |
|------|----------|----------|--------------|
| `qwen-image-plus` | 画像ごと | `¥0.20 / 画像` | 検証済み |
| `qwen-image-max` | 画像ごと | `¥0.50 / 画像` | 検証済み |
| `qwen-image-2.0` | 画像ごと | `¥0.20 / 画像` | 検証済み |
| `qwen-image-2.0` | 画像ごと | `¥0.50 / 画像` | Beta |

## 想定される範囲

- このページの初期公開分は`テキストから画像生成`の顧客向け機能のみを保証し、上流の多モーダル機能を直接顧客プロトコルとして開示することはありません。
- `Qwen Image`のプロバイダー側は非同期や同期の違いがあるかもしれませんが、顧客側は引き続き統一されたOpenAI Imagesリクエスト/レスポンス形式を使用します。
- 画像編集モデル `qwen-image-plus`は本ページの「生成モデル公開範囲」には含まれません。編集機能が必要な場合は、編集モデルの現行公開状況に従って個別評価してください。
