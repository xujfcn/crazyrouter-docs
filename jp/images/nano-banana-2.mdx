# Nano Banana 2

```
POST /v1/images/generations
```

`nano-banana-2` は `nano-banana-2` の公開別名です。ユーザー側ではOpenAI Images互換プロトコルを統一して使用します；サーバ側は`output_format`、`output_compression`、`resolution`、`aspect_ratio` などの共通パラメーターをGemini／Vertexネイティブリクエストへ自動変換します。

<Warning>
  `nano-banana-2` は長時間処理が必要な画像モデルです。商用接続では主線経`https://api.crazyrouter.com/v1`を優先的に利用し、完全な生成エンドポイントは`https://api.crazyrouter.com/v1/images/generations`です。アカウントログイン、チャージ、コンソール操作は引き続き`https://crazyrouter.com`を使用します。
</Warning>

## モデル名

| 推奨モデル名 | 同等の基礎モデル |
|------|------|
| `nano-banana-2` | `nano-banana-2` |

クライアントコードでは`nano-banana-2`を推奨します。もし既存システムで`nano-banana-2`を直接記述している場合も、同じ`/v1/images/generations`エントリから引き続き呼び出すことができます。

## リクエストパラメーター

| パラメーター | タイプ | 必須 | 説明 |
|------|------|------|------|
| `model` | string | 是 | 推奨は`nano-banana-2`；`nano-banana-2`も対応 |
| `prompt` | string | 是 | 生成または編集指示 |
| `image_input` | string または string[] | 否 | 参考画像URL；指定しない場合はテキスト画像生成 |
| `resolution` | string | 否 | `1K`、`2K`、`4K` |
| `aspect_ratio` | string | 否 | `1:1`、`16:9`、`9:16`、`21:9`、`auto`のように |
| `output_format` | string | 否 | `png`、`jpeg` ／ `jpg` |
| `output_compression` | integer | 否 | `0-100`、JPEG圧縮品質指定 |
| `n` | integer | 否 | 生成数、デフォルトは`1` |

<Note>
  Geminiネイティブフィールド（`generationConfig`、`imageConfig`、`imageOutputOptions`、`image_output_options`など）はクライアントリクエストで送信しないでください。これらのフィールドはCrazyrouterがサーバで現在の上流プロトコルに従って自動生成します。
</Note>

## テキスト画像生成例

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-2",
    "prompt": "A clean ecommerce hero shot of a red apple on a white background",
    "resolution": "1K",
    "aspect_ratio": "16:9",
    "output_format": "jpeg",
    "output_compression": 85
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.generate(
    model="nano-banana-2",
    prompt="A clean ecommerce hero shot of a red apple on a white background",
    n=1,
    extra_body={
        "resolution": "1K",
        "aspect_ratio": "16:9",
        "output_format": "jpeg",
        "output_compression": 85,
    },
)

print(response.data[0].url or response.data[0].b64_json)
```

</CodeGroup>

## 参考画像編集例

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-2",
    "prompt": "把参考图改成横幅广告图，保留主体，背景更干净",
    "image_input": [
      "https://example.com/reference.png"
    ],
    "resolution": "1K",
    "aspect_ratio": "16:9",
    "output_format": "png"
  }'
```

## レスポンス

レスポンスはOpenAI Imagesスタイルを維持します。デフォルトで`data[0].url`を優先的に読み込みます；一部互換チャネルでは`data[0].b64_json`が返される場合もあります。

```json
{
  "created": 1778990000,
  "data": [
    {
      "url": "https://media.crazyrouter.com/task-artifacts/2026/05/17/sync-image/request-id-1.png"
    }
  ]
}
```

## 移行について

既存コードが直接以下を呼び出している場合：

```text
POST /v1beta/models/nano-banana-2:generateContent
```

次への移行を推奨します：

```text
POST https://api.crazyrouter.com/v1/images/generations
```

なお、Geminiネイティブパラメーターは統一パラメーターに置き換えてください：

| Gemini ネイティブ概念 | Crazyrouter 統一パラメーター |
|------|------|
| `imageConfig.aspectRatio` | `aspect_ratio` |
| `imageConfig.imageSize` | `resolution` |
| `imageOutputOptions.mimeType` | `output_format` |
| `imageOutputOptions.compressionQuality` | `output_compression` |
