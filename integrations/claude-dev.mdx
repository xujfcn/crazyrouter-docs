## 概述

Claude Dev 是一款针对 Claude 风格代码讲解、重构建议以及通过 Crazyrouter 进行多轮协作的 VS Code AI 编码扩展。对于公开文档，优先推荐使用 OpenAI 兼容路线，因为它与 Crazyrouter 其他集成组件更加一致，且更易于排查问题。

<Warning>
本页中的 `https://api.crazyrouter.com/v1` URL 仅适用于 Claude Dev 的 `OpenAI Compatible` 服务商。请勿将其复制到 Claude Code 的 `ANTHROPIC_BASE_URL` 中；Claude Code 应当使用根域名 `https://api.crazyrouter.com`。
</Warning>

## 推荐配置

<Steps>
  <Step title="安装扩展">
    在 VS Code 扩展市场中搜索 `Claude Dev` 并安装。
  </Step>
  <Step title="打开设置">
    点击侧边栏的 Claude Dev 图标进入设置界面。
  </Step>
  <Step title="选择提供方">
    优先选择 `OpenAI Compatible` 作为 API 服务商。
  </Step>
  <Step title="输入配置">
    - **基础 URL**：`https://api.crazyrouter.com/v1`
    - **API 密钥**：`sk-xxx`
    - **模型**：`claude-opus-4-8`
  </Step>
</Steps>

对于默认的国际 API 入口，请将 Claude Dev 的 `OpenAI Compatible` 基础 URL 设置为 `https://api.crazyrouter.com/v1`。

## 推荐模型

| 场景 | 模型 |
|------|------|
| 日常编码 | `claude-opus-4-8` |
| 高强度推理与规划 | `claude-opus-4-8` |

<Note>
  `claude-opus-4-8` 和 `claude-opus-4-8` 与本说明集中的最新 Claude 模型指引保持一致。对于最小的 VS Code 首步验证，建议从 `claude-opus-4-8` 开始。
</Note>
