# Claude OpenAI Compatible Format

```
POST /v1/chat/completions
```

As of March 23, 2026, the following have been validated in the Crazyrouter production environment:

- `claude-opus-4-8` Non-streaming requests return `object: "chat.completion"`
- `message` Current stable includes `role` and `content`
- Streaming requests return `chat.completion.chunk`
- SSE still ends with `data: [DONE]`

<Warning>
This page describes the standard dialog path for Claude using the OpenAI Chat Completions compatible format. For Claude native `tool_use`, Claude Code, or Agent programming scenarios that rely on tool invocation, please give priority to the `POST /v1/messages` from [Claude Native Format](/en/chat/anthropic/messages). The OpenAI compatible format does not guarantee equivalent support for Claude native tool blocks.
</Warning>

---

## Non-Streaming Requests

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {"role": "system", "content": "You are a concise assistant."},
      {"role": "user", "content": "Compare PostgreSQL and MySQL in one paragraph."}
    ],
    "max_tokens": 256,
    "temperature": 0.2
  }'
```

Key response formats:

```json
{
  "object": "chat.completion",
  "model": "claude-opus-4-8",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "PostgreSQL and MySQL are both popular..."
      }
    }
  ]
}
```

---

## Streaming Requests

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {"role": "user", "content": "Say hello in one sentence."}
    ],
    "max_tokens": 128,
    "stream": true
  }'
```

In the production streaming probe as of 2026-03-23, the opening segments are as follows:

```text
data: {"object":"chat.completion.chunk","model":"claude-opus-4-8","choices":[{"delta":{"role":"assistant"}}]}
data: {"object":"chat.completion.chunk","model":"claude-opus-4-8","choices":[{"delta":{"content":"Hello! ..."}}]}
data: [DONE]
```

<Note>
  If you need Claude native `thinking`, native tool blocks, or document input, prioritize [Claude Messages](/en/chat/anthropic/messages).
</Note>
