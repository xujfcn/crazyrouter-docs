# Gemini Image Generation

```
POST /v1/images/generations
```

Crazyrouter provides a unified OpenAI Images-compatible entry point for the Gemini image models. Users do not need to call the native Gemini `generateContent` directly, nor do they need to provide the native Gemini `generationConfig.imageConfig`.

| Recommended Public Model Name | Compatible Backend Model Name |
|------|------|
| `nano-banana` | `nano-banana` |
| `nano-banana-pro` | `nano-banana-pro` |
| `nano-banana-2` | `nano-banana-2` |

<Warning>
  Gemini image generation is a long-running request. For production integration, please prioritize using the primary routing line `https://api.crazyrouter.com/v1`, with the complete generation endpoint being `https://api.crazyrouter.com/v1/images/generations`.
</Warning>

<Note>
  It is recommended to use `nano-banana`, `nano-banana-pro`, and `nano-banana-2` in your client code. If your system already directly uses `nano-banana`, `nano-banana-pro`, or `nano-banana-2`, you can also continue calling through the same Images API entry.
</Note>

---

## Request Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `model` | string | Yes | `nano-banana`, `nano-banana-pro`, `nano-banana-2`, or the corresponding Gemini canonical name |
| `prompt` | string | Yes | Generation or editing instruction |
| `image_input` | string or string[] | No | Reference image URL; if omitted, generates from text |
| `resolution` | string | No | `1K`, `2K`, or `4K` |
| `aspect_ratio` | string | No | Such as `1:1`, `16:9`, `9:16`, `21:9`, `auto` |
| `output_format` | string | No | `png`, `jpeg` / `jpg` |
| `output_compression` | integer | No | `0-100`, used for JPEG compression quality |
| `n` | integer | No | Number to generate, default is `1` |

Do not send these upstream private fields: `generationConfig`, `imageConfig`, `imageOutputOptions`, `image_output_options`.

## Request Example

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-2",
    "prompt": "A simple red square on a white background, clean vector style",
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "png"
  }'
```

The response maintains the OpenAI Images style:

```json
{
  "created": 1778990000,
  "data": [
    {
      "url": "https://media.crazyrouter.com/task-artifacts/2026/05/17/sync-image/request-id-1.png"
    }
  ]
}
```

## Reference Image Editing

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-pro",
    "prompt": "把参考图改成高级电商海报，保留主体，背景更简洁",
    "image_input": [
      "https://example.com/reference.png"
    ],
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "jpeg",
    "output_compression": 85
  }'
```

<Note>
  If you do need the native Gemini API format, please refer to [Gemini Native Format](/en/chat/gemini/native). But for image generation and editing, we recommend clients consistently use the Images API described on this page.
</Note>
