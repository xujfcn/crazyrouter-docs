# Gemini Image Editing

```
POST /v1/images/generations
```

Gemini / Nano Banana image editing is standardized on Crazyrouter via the OpenAI Images compatible entry. The `image_input` URL is used by default; accounts specified for grayscale also support dataURL, raw Base64, and `/v1/images/edits` multipart three-image editing.

<Warning>
  Requests such as image editing and multiple reference images usually take longer. For production integration, please use the primary supported routing, `https://api.crazyrouter.com/v1`, with the complete endpoint being `https://api.crazyrouter.com/v1/images/generations`.
</Warning>

---

## Current Recommendations

1. New integrations should preferably use `nano-banana-2` or `nano-banana-pro`
2. For image input, use `image_input`, submitting a URL or an array of URLs
3. Do not submit native Gemini fields, such as `generationConfig`, `imageConfig`, `imageOutputOptions`
4. It is recommended to set client timeout to 180 seconds or more

---

## Request Template

Below is the minimal request for editing a reference image via the unified Images API:

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-2",
    "prompt": "把参考图背景改成蓝色，保留主体结构和边缘细节",
    "image_input": [
      "https://example.com/reference.png"
    ],
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "png"
  }'
```
