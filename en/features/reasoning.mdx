# Reasoning

This documentation only includes Reasoning / Thinking usages that have been **successfully validated by actual requests in the Crazyrouter production environment**.

Validation time:

- `2026-03-22`

Models validated:

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

---

## Validated Capability Matrix

| Model | Protocol | Endpoint | Success Indicator |
|------|------|------|----------|
| `gpt-5.5` | OpenAI Responses | `POST /v1/responses` | Appearance of `reasoning` item in `output` |
| `claude-opus-4-8` | Anthropic Messages | `POST /v1/messages` | Returns `thinking` block |
| `gemini-3.1-pro` | Gemini Native | `POST /v1beta/models/{model}:generateContent` | Appearance of `thoughtsTokenCount` in `usageMetadata` |

## GPT-5.4

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Which is larger, 9.11 or 9.9? Explain briefly.",
    "reasoning": {
      "effort": "high",
      "summary": "detailed"
    }
  }'
```

Key `output.type` returned from production validation:

```json
["reasoning", "message"]
```

Key fields of `reasoning` item include:

```json
{
  "type": "reasoning",
  "summary": [
    {
      "type": "summary_text",
      "text": "..."
    }
  ]
}
```

This indicates that in the current Crazyrouter production environment, the reasoning capability of `gpt-5.5` should be judged based on the `reasoning` item from the Responses API, rather than relying on the `reasoning_content` from Chat Completions.

## Claude Opus 4.7 Thinking

```bash cURL
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 320,
    "thinking": {
      "type": "enabled",
      "budget_tokens": 128
    },
    "messages": [
      {
        "role": "user",
        "content": "Which is larger, 9.11 or 9.9? Explain briefly."
      }
    ]
  }'
```

Key fields returned from production validation:

```json
{
  "content": [
    {
      "type": "thinking",
      "thinking": "..."
    },
    {
      "type": "text",
      "text": "..."
    }
  ]
}
```

Note:

- The `claude-opus-4-8` base model only returned standard `text` during tests on the same day
- The `claude-opus-4-8` validation confirmed the presence of a clear thinking block

Therefore, this documentation should prioritize using `claude-opus-4-8` as the Claude 4.7 reasoning example.

## Gemini 3 Pro

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Which is larger, 9.11 or 9.9? Explain briefly."
          }
        ]
      }
    ],
    "generationConfig": {
      "thinkingConfig": {
        "thinkingBudget": 256
      },
      "maxOutputTokens": 512
    }
  }'
```

Key fields returned from production validation:

- `usageMetadata.thoughtsTokenCount`

This shows that in the current production environment, the thinking mode of `gemini-3.1-pro` has actually taken effect.

## Combinations Not Included in the Main Conclusion

- The Chat Completions routing for `gpt-5.5` did not stably return `reasoning_content` during this round of review, so it is no longer the main GPT example on this page
- The `claude-opus-4-8` base model did not return a thinking block in this round of validation
- `claude-opus-4-8` did not possess a comparably clear thinking capability model
