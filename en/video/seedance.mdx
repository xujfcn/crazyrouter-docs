# Seedance

Seedance is a video generation model family from ByteDance / Doubao. Crazyrouter currently retains the native Volcano `/volc/v1/*` protocol for end users and no longer uses `doubao-seedance-2-0-fast` from the legacy unified video interface as the main public protocol.

If you want to see the **actual settlement logic for Seedance 2.0 / 2.0 Fast in Crazyrouter**, including "why tokens are deducted after task completion" and "whether tokens can be directly converted from seconds", just visit the dedicated page: [Seedance 2.0 Billing Instructions](/en/video/seedance-2-billing).

## Currently Public Models

| Model | Current Public Position |
|------|------|
| `doubao-seedance-1-0-lite-t2v` | Text-to-video |
| `doubao-seedance-1-0-lite-i2v` | Single-image-to-video |
| `doubao-seedance-1-0-pro` | General high-quality video generation |
| `doubao-seedance-1-0-pro-fast` | General fast video generation |
| `doubao-seedance-1-5-pro` | More advanced versions, will continue to expand official capability parameters in the future |
| `doubao-seedance-2-0` | Seedance 2.0 Official Multimodal Video Generation |
| `doubao-seedance-2-0-fast` | Seedance 2.0 Fast Official Multimodal Video Generation |

## Submit Video Tasks

```
POST /volc/v1/contents/generations/tasks
```

### Currently Public Request Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `model` | string | Yes | Model name for end users; use canonical model names from the table above |
| `content` | array | Yes | Array of input content |
| `content[].type` | string | Yes | Currently supports `text`, `image_url`, `video_url`, `audio_url`, `draft_task` |
| `content[].text` | string | Condition Required | Enter prompt when using `type=text` |
| `content[].image_url.url` | string | Condition Required | Enter image URL when using `type=image_url` |
| `content[].video_url.url` | string | Condition Required | Enter reference video URL when using `type=video_url` |
| `content[].audio_url.url` | string | Condition Required | Enter reference audio URL when using `type=audio_url` |
| `content[].role` | string | Optional | Seedance 2.0 supports `first_frame`, `last_frame`, `reference_image`, `reference_video`, `reference_audio` |
| `generate_audio` | boolean | Optional | Seedance 2.0 supports whether to generate audio |
| `ratio` | string | Optional | Output aspect ratio, such as `16:9` |
| `resolution` | string | Optional | Seedance 2.0 / 2.0 fast currently only support `480p`, `720p` |
| `duration` | integer | Optional | Seedance 2.0 / 2.0 fast support `4-15` or `-1` |
| `watermark` | boolean | Optional | Whether to add watermark |
| `seed` | integer | Optional | Random seed |

### Official Capability Limits for Seedance 2.0

- Supports four input modalities: text, image, video, audio.
- Supports multimodal references: a maximum of `9` images, `3` videos, `3` audios, and total number of mixed files up to `12`.
- Image formats: `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`; single image size `< 30MB`.
- Video formats: `mp4`, `mov`; up to `3` video references, total duration is recommended within `[2, 15]s`, total file size `< 50MB`.
- Audio formats: `mp3`, `wav`; up to `3` audio references, total duration `<= 15s`, total file size `< 15MB`.
- Audio cannot be input alone; at least `1` image or video references must be provided at the same time.
- Supported generation duration `4-15s`, and supports letting upstream set default duration with `-1`.
- Supports `480p`, `720p`; `1080p` is currently not applicable to Seedance 2.0 / 2.0 fast.
- `frames` is currently not applicable to Seedance 2.0 / 2.0 fast.
- `camera_fixed` is currently not applicable to Seedance 2.0 / 2.0 fast.
- In terms of product forms, Seedance 2.0 is mainly divided into "first and last frame" and "all-purpose reference" entry points; for API, this is unified as `content[].role` and `content[].type`.
- Upstream currently has compliance restrictions for uploading realistic human face materials. Images or video references containing clear realistic faces may be intercepted by upstream directly.

### Official Billing Values for Seedance 2.0

| Model | Official Billing Method | Official Price |
|------|------|------|
| `doubao-seedance-2-0` | Charged by output tokens | Includes video input `28 yuan / million output Tokens`; excludes video input `46 yuan / million output Tokens` |
| `doubao-seedance-2-0-fast` | Charged by output tokens | Includes video input `22 yuan / million output Tokens`; excludes video input `37 yuan / million output Tokens` |

<Note>
  MIME, duration, and file size of remote URL materials are finally checked by the upstream; Crazyrouter currently checks count, duration parameters, audio must not be input alone, and explicit boundaries such as 480p/720p / `frames` / `camera_fixed` before submission.
</Note>

### Text-to-Video Example

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/volc/v1/contents/generations/tasks \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "doubao-seedance-1-0-lite-t2v",
    "content": [
      {
        "type": "text",
        "text": "镜头缓慢推进，一只白色海鸥从海面掠过，日落金光反射在海浪上"
      }
    ]
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/volc/v1/contents/generations/tasks",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "doubao-seedance-1-0-lite-t2v",
        "content": [
            {
                "type": "text",
                "text": "镜头缓慢推进，一只白色海鸥从海面掠过，日落金光反射在海浪上"
            }
        ]
    }
)

print(response.json())
```

## Query Task

```
GET /volc/v1/contents/generations/tasks/{task_id}
```

```bash cURL
curl https://api.crazyrouter.com/volc/v1/contents/generations/tasks/cgt_task_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response Example (Completed)

```json
{
  "code": "success",
  "message": "",
  "data": {
    "id": "cgt_task_abc123",
    "task_id": "cgt_task_abc123",
    "model": "doubao-seedance-2-0-fast",
    "status": "SUCCESS",
    "result_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/seedance/cgt_task_abc123.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/seedance/cgt_task_abc123.mp4",
    "content": {
      "video_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/seedance/cgt_task_abc123.mp4"
    }
  }
}
```

### Task Status

| Status | Description |
|------|------|
| `NOT_START` | Submitted, waiting for upstream processing |
| `IN_PROGRESS` | Generating |
| `SUCCESS` | Completed, results can be retrieved from `result_url`, `artifact_url`, or `content.video_url` |
| `FAILURE` | Final failure |

<Note>
  The currently public documentation only guarantees the native `/volc/v1/*` path and canonical model names. The old `doubao-seedance-2-0-fast` is only retained for historical reference and is no longer used as the new main public protocol.
</Note>

<Note>
  The official Seedance price value is currently maintained according to `per_output_token`, not by seconds; if the pricing page later does platform normalization display, it should be clarified that this is the platform's selling reference, not the official native unit.
</Note>
