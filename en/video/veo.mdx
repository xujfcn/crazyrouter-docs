# Veo 3.1

Currently, the Veo 3.1 models publicly available to customers via Crazyrouter are:

- `veo-3.1-fast`
- `veo-3.1-quality`

These two names are public aliases for customers. The internal canonical provider names will not be directly exposed to customers.

<Note>
  `veo-3.1` is not a `model` value that can be directly submitted by customers. For customer requests, please always use `veo-3.1-fast` or `veo-3.1-quality`.
</Note>

## Calling through the unified video API

```
POST /v1/video/create
```

This page only covers features that have already been made available to customers:

- Text-to-video generation
- Single-image-to-video generation

The `referenceImages`, style reference, and more granular provider-native modes in Google's official documentation are not covered by the current public contract.

### Currently Available Models

| Model | Description |
|------|------|
| `veo-3.1-fast` | Lower latency, suitable for getting the first available result faster |
| `veo-3.1-quality` | More quality-focused, suitable as the main default display |

### Feature Status

| Feature / Specification | Status | Description |
|------|------|------|
| Text-to-video `720P / 1080P` | `Verified` | The current public contract is finalized |
| Single-image-to-video `720P / 1080P` | `Verified` | The current public contract is finalized |
| Audio activation line | `Beta` | The official capability exists, but the current public artifact still needs to be supplemented |
| `start_end` | `Beta` | No commitment yet on the current public page |
| `referenceImages` / reference assets | `Beta` | No commitment yet on the current public page |
| `4K` | `Beta` | No commitment yet on the current public page |

<Note>
  The Pricing page and this documentation use the same status definitions: `Verified` indicates that the minimal live feedback loop is already available, `Beta` means the official capability exists but public verification or boundary conditions are still being supplemented.
</Note>

### Request Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `model` | string | Yes | `veo-3.1-fast` or `veo-3.1-quality` |
| `prompt` | string | Yes | Video description prompt |
| `aspect_ratio` | string | No | It is currently recommended to use `16:9` or `9:16` |
| `size` | string | No | It is currently recommended to use `720P` or `1080P` |
| `images` | array | No | Submit `1` image URLs for single-image-to-video generation |
| `duration` | integer | No | Common value is `8` |

### Request Example

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-quality",
    "prompt": "A cinematic shot of a spaceship landing on Mars, dust clouds rising, golden hour lighting",
    "aspect_ratio": "16:9"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/video/create",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "veo-3.1-quality",
        "prompt": "A cinematic shot of a spaceship landing on Mars",
        "aspect_ratio": "16:9"
    }
)

task_id = response.json()["task_id"]
print(f"任务 ID: {task_id}")
```

</CodeGroup>

### Response Example

```json
{
  "task_id": "veo_task_abc123",
  "status": "processing"
}
```

## Single-Image-to-Video Example

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-fast",
    "prompt": "The person in the image slowly turns their head and smiles",
    "images": ["https://example.com/portrait.jpg"],
    "aspect_ratio": "9:16",
    "size": "720P"
  }'
```
