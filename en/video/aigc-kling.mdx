# AIGC Kling VOD Usage Method

`aigc-video-kling-*` is the Kling video model accessed by Crazyrouter through the Tencent VOD route. Its path is different from `/kling/v1/videos/*` in the native Kling documentation, and for external users, an OpenAI-style asynchronous video interface is used:

```http
POST /v1/video/generations
GET /v1/video/generations/{task_id}
```

<Note>
  When using the VOD route, you must use the `aigc-video-kling-*` model name. Do not submit `kling-v2-5-turbo`, `kling-v2-6`, or `kling-v3` directly to this interface, or you may hit the native Kling route.
</Note>

<Note>
  If you need to use the image model `aigc-image-kling-3.0`, please see [AIGC Kling 3.0 Image Generation](/en/images/aigc-kling). This model uses `POST /v1/images/generations` and does not use this page's video interface.
</Note>

| `aigc-video-kling-2.0` | Kling 2.0 | Text-to-video, image-to-video, first and last frame, reference image |
| `aigc-video-kling-2.1` | Kling 2.1 | Text-to-video, image-to-video, first and last frame, reference image |
| `aigc-video-kling-2.5-turbo` | Kling 2.5 Turbo | Text-to-video, image-to-video, first and last frame, reference image |
| `aigc-video-kling-2.6` | Kling 2.6 | Text-to-video, image-to-video, first and last frame, reference image, video input |
| `aigc-video-kling-2.6-motion-control` | Kling 2.6 Motion Control | Motion Control |
| `aigc-video-kling-3.0` | Kling 3.0 | Text-to-video, image-to-video, first and last frame, reference image |
| `aigc-video-kling-3.0-turbo` | Kling 3.0 Turbo | Text-to-video, image-to-video, reference image |
| `aigc-video-kling-3.0-motion-control` | Kling 3.0 Motion Control | Motion Control |
| `aigc-video-kling-o1` | Kling O1 | Text-to-video, image-to-video, reference image, video input |
| `aigc-video-kling-avatar` | Kling Avatar | Digital Human / Avatar |
| `aigc-video-kling-identifyface` | Kling Identifyface | Lip Sync |

<Note>
  `GV 3.1`, `3.1-fast`, and `3.1-lite` in the Tencent VOD documentation refer to the Google Veo route, not Kling 3.1. Please use the dedicated `aigc-video-gv-*` model.
</Note>

## Creating a Task

```http
POST https://api.crazyrouter.com/v1/video/generations
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

### General Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `model` | string | Yes | Use this page's `aigc-video-kling-*` model name |
| `prompt` | string | Conditionally Required | Required for text-to-video; in multi-shot or certain image-to-video scenes, can be placed in extended parameters |
| `seconds` / `duration` | string / number | No | Video duration, commonly `5` or `10`, default processing as `5` seconds |
| `size` | string | No | e.g., `1280x720`, `720x1280`, will infer the output ratio |
| `image` | string | No | Single image-to-video first frame URL |
| `images` | array[string] | No | First image as the first frame; second can be the last frame or reference image |
| `metadata` | object | No | VOD Kling extended parameters, see field table below |

### Common metadata Fields

| Field | Description |
|------|------|
| `resolution` | Output specs, e.g., `720P`, `1080P`, `2K`, `4K` |
| `aspect_ratio` | Output aspect ratio, e.g., `16:9`, `9:16`, `1:1` |
| `sound` | Whether to generate audio, supports `true` / `false`, `on` / `off` |
| `image_urls` | Array of first/last frames, up to 2 images |
| `image_tail` / `last_frame_url` | Last frame URL, higher priority than `image_urls[1]` |
| `image_list` | List of multiple reference images, up to 9 images |
| `multi_shots` / `multi_shot` | Multi-shot toggle |
| `shot_type` | Storyboard type |
| `multi_prompt` | Array of multi-shot prompts |
| `kling_elements` / `element_list` | Kling element control |
| `camera_control` | Camera movement control |
| `motion_brush` / `dynamic_masks` | Motion control parameters |
| `video_list` | Video reference input, commonly for O1 or video input capabilities |
| `voice_list` | Audio reference input |
| `session_id` / `face_choose` | Lip sync related parameters |

## Text to Video

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-2.6",
    "prompt": "a red square logo slowly rotating on a clean white background",
    "size": "1280x720",
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "sound": false
    }
  }'
```

```bash cURL
      "resolution": "720P"
    }
  }'
```

## First and Last Frame Video

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-2.6",
    "prompt": "transition naturally from the first frame to the last frame",
    "images": [
      "https://example.com/first.png",
      "https://example.com/last.png"
    ],
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "sound": false
    }
  }'
```

<Note>
  For Kling 2.6 first and last frame, it’s recommended to explicitly pass `metadata.sound=false`.
</Note>

## Motion Control

Motion control capability uses a dedicated model name, such as `aigc-video-kling-2.6-motion-control` or `aigc-video-kling-3.0-motion-control`.

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-3.0-motion-control",
    "prompt": "animate the selected subject moving from left to right",
    "image": "https://example.com/input.png",
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "dynamic_masks": [
        {
          "mask_url": "https://example.com/mask.png",
          "trajectories": [
            { "x": 220, "y": 380 },
            { "x": 620, "y": 380 }
          ]
        }
      ]
    }
  }'
```

## O1 Video Input

`aigc-video-kling-o1` can input video reference through `metadata.video_list`. Including video input will impact billing specifications.

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-o1",
    "prompt": "use the reference video motion style and generate a new cinematic shot",
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "video_list": [
        { "url": "https://example.com/reference.mp4" }
      ]
    }
  }'
```

## Avatar and Lip Sync

Avatar uses `aigc-video-kling-avatar`:

```json
{
  "model": "aigc-video-kling-avatar",
  "prompt": "a presenter speaks naturally to the camera",
  "image": "https://example.com/avatar.png",
  "seconds": "5",
  "metadata": {
    "resolution": "720P",
    "voice_list": [
      { "url": "https://example.com/voice.wav" }
    ]
  }
}
```

Lip sync uses `aigc-video-kling-identifyface`. If the business side already has upstream-recognized `session_id` and `face_choose`, they can be put into `metadata`:

```json
{
  "model": "aigc-video-kling-identifyface",
  "prompt": "lip sync the face with the provided voice",
  "image": "https://example.com/face.png",
  "seconds": "5",
  "metadata": {
    "resolution": "720P",
    "session_id": "SESSION_ID",
    "face_choose": "FACE_ID",
    "voice_list": [
      { "url": "https://example.com/voice.wav" }
    ]
  }
}
```

<Note>
  The complete lip sync process usually requires facial recognition first and then submission of the video generation task. If `session_id` / `face_choose` is missing, the upstream may return a parameter error.
</Note>

## Query Task

After creating a task and getting `id` or `task_id`, use the same compatible path for querying:

```bash cURL
curl https://api.crazyrouter.com/v1/video/generations/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

After completion, usually an archived video URL will be returned:

```json
{
  "code": "success",
  "data": {
    "status": "SUCCESS",
    "task_id": "vod_task_abc123",
    "result_url": "https://media.crazyrouter.com/task-artifacts/example.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/example.mp4"
  }
}
```

## Differences from Native Kling

| Item | AIGC Kling VOD | Native Kling |
|------|------|------|
| Model Name | `aigc-video-kling-*` | `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3` |
| Creation Path | `POST /v1/video/generations` | `POST /kling/v1/videos/text2video` etc. |
| Query Path | `GET /v1/video/generations/{task_id}` | `GET /kling/v1/videos/{type}/{task_id}` |
| Main Fields | `model`, `prompt`, `seconds`, `image`, `images`, `metadata` | `model_name`, `prompt`, `image_urls`, `duration`, etc. |
| Suitable Scenarios | Use Tencent VOD route, with VOD pricing and capabilities | Use native Kling protocol |

Prices, discounts, and available specs are as shown on the [Pricing page](https://crazyrouter.com/en/pricing).
