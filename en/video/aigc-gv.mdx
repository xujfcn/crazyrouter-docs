# AIGC GV VOD Usage Guide

`aigc-video-gv-*` is the GV / Google Veo video model connected by Crazyrouter through the Tencent VOD route. The calling method is the same as AIGC Kling VOD, using the OpenAI-style asynchronous video API:

```http
POST /v1/video/generations
GET /v1/video/generations/{task_id}
```

<Note>
  `aigc-video-gv-*` only uses `/v1/video/generations` and the corresponding query route. Do not send these models to `/v1/video/create`; a route mismatch will result in `model_not_found` or a similar upstream error.
</Note>

## Available Models

| Model | Upstream Version | Description |
|------|------|------|
| `aigc-video-gv-3.1` | GV 3.1 | High-quality version, supports videos with audio |
| `aigc-video-gv-3.1-fast` | GV 3.1 Fast | Faster version, supports videos with audio |
| `aigc-video-gv-3.1-lite` | GV 3.1 Lite | Lightweight version, supports videos with audio |

<Note>
  Tencent VOD's GV 3.1 is the Google Veo route, not Kling. Do not use model names like `aigc-video-kling-3.1`.
</Note>

## Creating a Task

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-gv-3.1-fast",
    "prompt": "a cinematic product shot with natural camera movement",
    "seconds": "5",
    "metadata": {
      "resolution": "1080P",
      "sound": true
    }
  }'
```

## Image-to-Video and Multi-Image Reference

For single image input, use `image`; for multi-image reference, use `metadata.image_list`:

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-gv-3.1",
    "prompt": "combine the visual style of the references into one smooth shot",
    "seconds": "5",
    "metadata": {
      "resolution": "1080P",
      "image_list": [
        {
          "url": "https://example.com/ref-1.png",
          "reference_type": "asset"
        },
        {
          "url": "https://example.com/ref-2.png",
          "reference_type": "style"
        }
      ]
    }
  }'
```

<Warning>
  GV multi-image input must be provided through `FileInfos`. The site will convert `image_list` to `FileInfos`, and will not use `LastFrameUrl` for GV multi-image requests.
</Warning>

## Common Metadata Fields

| Field | Description |
|------|------|
| `resolution` | `720P`, `1080P`, `2K`, `4K`. The actual available specifications are subject to the Pricing page |
| `sound` | Whether to generate sound, supports `true` / `false`, `on` / `off` |
| `audio_generation` | Directly pass `Enabled` / `Disabled` |
| `image_list` | Multi-image reference array |
| `reference_type` / `ReferenceType` | GV reference types, typically `asset` or `style` |

Pricing, discounts, and available specifications are subject to the [Pricing Page](https://crazyrouter.com/en/pricing).
