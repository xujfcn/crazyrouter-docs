> Content updated: 2026-10-12

With [crazyrouter-hermes](https://github.com/xujfcn/crazyrouter-hermes), you can switch [Hermes Agent](https://github.com/NousResearch/Hermes-Agent) to Crazyrouter as the model provider. Once configured, Hermes uses `https://api.crazyrouter.com/v1` as the OpenAI-compatible endpoint and calls Claude, GPT, DeepSeek, Gemini, Qwen, and 627+ other models with a single Crazyrouter API Key.

## Who is this for

- for users of Hermes Agent who want to use Crazyrouter as their model provider
- for local agent scenarios where models and quotas must be managed through Crazyrouter
- for those who want to set up `OPENAI_API_KEY`, `OPENAI_BASE_URL`, and the default model with a single command

## Requirements

| Item | Description |
|------|------------|
| Hermes Agent | Install Hermes locally and make sure it runs |
| Crazyrouter account | Create an account at [crazyrouter.com](https://crazyrouter.com) |
| Crazyrouter API Key | It's recommended to create a separate `sk-...` token for Hermes |
| Access to models | Allow in the token the models you plan to use |

<Tip>
Hermes connects to Crazyrouter using OpenAI-compatible settings. The Base URL must be `https://api.crazyrouter.com/v1`.
</Tip>

## Setup with one command

<Tabs>
  <Tab title="Linux / macOS / WSL2">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/xujfcn/crazyrouter-hermes/main/setup.sh | bash
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    irm https://raw.githubusercontent.com/xujfcn/crazyrouter-hermes/main/setup.ps1 | iex
    ```
  </Tab>
  <Tab title="Windows CMD">
    ```bat
    curl -o setup.bat https://raw.githubusercontent.com/xujfcn/crazyrouter-hermes/main/setup.bat
    setup.bat
    ```
  </Tab>
</Tabs>

The script will prompt you to enter the Crazyrouter API Key, choose a default model, and optionally verify the connection.

<Warning>
The script writes the local Hermes configuration. If you already have your own settings, make a backup of `~/.hermes/.env` and `~/.hermes/config.yaml` first.
</Warning>

## Manual setup

If you don't want to run the script, configure Hermes manually.

### Environment Variables

Edit `~/.hermes/.env`:

```bash
OPENAI_API_KEY=sk-your-crazyrouter-key
OPENAI_BASE_URL=https://api.crazyrouter.com/v1
```

### Default Model

Edit `~/.hermes/config.yaml`:

```yaml
model:
  provider: "custom"
  default: "claude-opus-4-8"
  base_url: "https://api.crazyrouter.com/v1"
```

Replace `default` with any model allowed in your Crazyrouter token.

## Switching Models

After setup, switch models inside Hermes using `/model`:

```text
/model claude-opus-4-8
/model gpt-5.5
/model claude-sonnet-4-6
/model gemini-3.1-pro
/model deepseek-v4-pro
/model qwen-max
/model gpt-4o
```

If you see `model not allowed` or `403` when switching, usually the selected model isn't allowed in the current Crazyrouter token.

## Checklist

- [ ] `OPENAI_API_KEY` in `~/.hermes/.env` is a valid Crazyrouter token
- [ ] `OPENAI_BASE_URL` equals `https://api.crazyrouter.com/v1`
- [ ] `provider` in `~/.hermes/config.yaml` equals `custom`
- [ ] the default model is allowed in the Crazyrouter token
- [ ] Hermes responds to a test message
- [ ] `/model gpt-5.5` or another allowed model switches successfully

## Common Issues

| Symptom | Likely Cause | Solution |
|---------|-------------|----------|
| `401 unauthorized` | API Key is incorrect, expired, or has been replaced | create a new Crazyrouter token and update `~/.hermes/.env` |
| `403` or `model not allowed` | token does not allow the selected model | allow the model in the Crazyrouter token settings |
| Hermes still uses the old provider | Hermes hasn't reread the config or the wrong file was changed | restart Hermes and check `~/.hermes/.env` and `~/.hermes/config.yaml` |
| Connection timeout | your local network can't connect to Crazyrouter | check proxy, firewall, and DNS |
