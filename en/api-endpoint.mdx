## API Base URL

```
https://api.crazyrouter.com
```

`https://api.crazyrouter.com` has already been enabled as the default international API access point. Account login, recharging, and the console still use:

```
https://crazyrouter.com
```

<Warning>
Account and management interfaces must use the main domain `https://crazyrouter.com`, including `/api/user/self`, `/api/token/*`, and `/api/log/*`. Do not send these paths to `https://api.crazyrouter.com` or `https://cn.crazyrouter.com`; these domains are only for model and media APIs, and using them incorrectly will return `404 api_only_endpoint`. Model inference endpoints (such as `/v1/chat/completions`, `/v1/messages`, `/v1/models`) still use the dedicated API domain.
</Warning>

East Asia region should preferentially use the following API access address:

```
https://cn.crazyrouter.com
```

If you are setting up a third-party client, SDK, IDE, or Agent, first confirm whether the tool should use the root domain or `/v1`:

<Card title="View Access Address Instructions" icon="book" href="https://docs.crazyrouter.com/en/api-endpoint">
  Follow this section to confirm whether to use the root domain or `/v1`, then return to the specific tool’s documentation to configure it.
</Card>

## Recommended Access Addresses

Default priority is the international API endpoint `https://api.crazyrouter.com`. Users in East Asia should prioritize `https://cn.crazyrouter.com`. These two addresses are for API requests only; web-based accounts, recharging, console, and pricing pages continue to use `https://crazyrouter.com`.

## Addresses to Use for Different Clients

| Usage     | Default International Entry | East Asia Preferred Entry | Note |
|-----------|----------------------------|--------------------------|------|
| OpenAI-compatible SDK / Client | `https://api.crazyrouter.com/v1` | `https://cn.crazyrouter.com/v1` | The client will append `/chat/completions`, `/models`, etc., after this address |
| Claude Code / Anthropic Native Client | `https://api.crazyrouter.com` | `https://cn.crazyrouter.com` | The client will concatenate `/v1/messages` itself; do not manually add `/v1` |
| curl / manual HTTP request            | Use complete endpoint, e.g. `https://api.crazyrouter.com/v1/chat/completions` | Use complete endpoint, e.g. `https://cn.crazyrouter.com/v1/chat/completions` | For manual requests, the full API path needs to be written |
| Account, Balance, Token, and Log Management Interfaces | `https://crazyrouter.com` | `https://crazyrouter.com` | Used for `/api/user/self`, `/api/token/*`, `/api/log/*`; do not use API-only domains |

<Warning>
If you see `/v1/v1/models`, `/v1/v1/messages`, or `/v1/messages/v1/messages` in the logs, this means the client configuration is concatenating the API path redundantly. For Claude Code / Anthropic native clients, switch back to the root domain; for OpenAI compatible clients, only keep up to `/v1`.
</Warning>

<Warning>
For Claude's native `tool_use`, Claude Code coding capabilities, and some IDE Agent tool invocation scenarios, Anthropic Messages route should be preferred, that is `POST /v1/messages`. The OpenAI-compatible `/v1/chat/completions` is better suited for simple conversations and basic compatibility access, but is not equivalent to Claude's native Messages API. If Claude models are accessed via OpenAI-compatible endpoints with tool invocation, tools may not launch reliably.
</Warning>

## Main Endpoints

### Chat API

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/v1/chat/completions` | POST | OpenAI Chat format |
| `/v1/messages` | POST | Anthropic Claude format |
| `/v1/responses` | POST | OpenAI Responses API |
| `/v1/completions` | POST | Legacy Completions |

### Gemini Native Format

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/v1beta/models/{model}:generateContent` | POST | Text Generation |
| `/v1beta/models/{model}:streamGenerateContent` | POST | Streaming Generation |
