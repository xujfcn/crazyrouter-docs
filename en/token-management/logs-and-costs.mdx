## Applicable Scenarios

When customers need to monitor each API Key, using Crazyrouter's set of management interfaces is recommended, instead of querying business-side `sk-xxx` directly:

- Obtain the list of API Keys under the current account
- Query call logs by time range, Key name, model name
- Summarize the total consumption quota of a specific Key
- Convert USD expenses based on system exchange rate parameters

<Note>
  Management interfaces use user authentication, not the business Token used in model calls.
</Note>

<Warning>
  All accounts and management interfaces on this page (including `/api/token/*`, `/api/log/*`, and `/api/user/self`) must request `https://crazyrouter.com`. `https://api.crazyrouter.com` only carries Model/Media APIs, and misuse will return `404 api_only_endpoint`.
</Warning>

## Authentication Method

The management interfaces must carry the following two request headers:

```text
Authorization: Bearer {access_token}
New-Api-User: {user_id}
```

- `access_token`: Access token generated after user login, used for console/management interface authentication
- `New-Api-User`: Current user ID, which must be consistent with the user corresponding to `access_token`
- `sk-xxx`: Business call Token, only used for model calls, not for management interfaces like `/api/token/*` and `/api/log/*`

## Recommended Access Process

It is recommended to access in the following order:

1. Call `/api/token/` to get the list of Keys under the current account
2. Use `token_name` to call `/api/log/self` to fetch detailed logs for a certain Key
3. Call `/api/log/self/stat` to get a summary quota under the same condition
4. Call `/api/status` to get `quota_per_unit`
5. Use `quota / quota_per_unit` to convert to USD expenses

## 1. Get API Key List

```bash cURL
curl "https://crazyrouter.com/api/token/?p=1&page_size=100" \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 485"
```

Response Example:

```json
{
  "success": true,
  "message": "",
  "data": {
    "page": 1,
    "page_size": 100,
    "total": 1,
    "items": [
      {
        "id": 409,
        "name": "gptai",
        "key": "sk-xxxxxxxxxxxxxxxx",
        "status": 2,
        "used_quota": 16605808,
        "model_limits_enabled": true,
        "model_limits": "kimi-k2.5"
      }
    ]
  }
}
```

It is recommended that customers save the following fields for subsequent monitoring:

- `id`
- `name`
- `status`
- `used_quota`
- `model_limits_enabled`
- `model_limits`

## 2. Query Call Logs for a Specific Key

Use `/api/log/self` to retrieve the consumption logs for the current user. It is recommended to include at least:

- `type`
- `token_name`
- `start_timestamp`
- `end_timestamp`
- `p`
- `page_size`

Example:

```bash cURL
curl "https://crazyrouter.com/api/log/self?type=2&token_name=gptai&start_timestamp=1771334901&end_timestamp=1772309095&p=1&page_size=5" \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 485"
```

Response Example:

```json
{
  "success": true,
  "message": "",
  "data": {
    "page": 1,
    "page_size": 5,
    "total": 4988,
    "items": [
      {
        "created_at": 1772308747,
        "token_name": "gptai",
        "model_name": "deepseek-chat",
        "quota": 3188,
        "cost_usd": 0.006376,
        "prompt_tokens": 884,
        "completion_tokens": 397,
        "use_time": 16.48,
        "is_stream": true,
        "ip": "203.0.113.10",
        "other": {
          "client": "openai-python",
          "request_id": "req_xxx",
          "request_method": "POST",
          "request_path": "/v1/chat/completions",
          "http_status": 200,
          "discount": 0
        }
      }
    ]
  }
}
```

### Explanation of Key Fields

| Field | Explanation |
|------|------|
| `token_name` | Which business Key is hit |
| `model_name` | Actual billing model |
| `quota` | System quota deducted for this request |
| `cost_usd` | USD expense converted for this request |
| `prompt_tokens` | Input token |
| `completion_tokens` | Output token |
| `use_time` | Request duration, in seconds |
| `other.request_id` | Request ID, suitable for link tracking |
| `other.client` | Client identifier for the call |
| `other.request_path` | The exact interface path hit |
| `other.http_status` | Upstream response status code |

<Note>
  `cost_usd` returns the USD expense calculated by the system's conversion. The calculation method is `quota / quota_per_unit`. If your production environment hasn't upgraded to the version containing this field, you can temporarily convert it yourself using the summary quota.
</Note>

<Warning>
Single failed requests will not incur charges; `quota` / `cost_usd` in the logs should be 0. However, in Agent mode, workflows, chain calls, or IDE auto-programming, a single user operation may break into multiple model requests: if previous requests have succeeded and only a subsequent step fails, the previously successful requests will still be charged according to actual token consumption. When investigating abnormal consumption, please check each request in the log one by one instead of only reviewing if the final task failed.
</Warning>

## 3. Query Summary Consumption

If you do not need detailed logs and only want a monitoring dashboard or daily report, it is recommended to call the summary interface:

```bash cURL
curl "https://crazyrouter.com/api/log/self/stat?type=2&token_name=gptai&start_timestamp=1771334901&end_timestamp=1772309095" \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 485"
```

Response Example:

```json
{
  "success": true,
  "message": "",
  "data": {
    "quota": 16605808,
    "rpm": 0,
    "tpm": 0
  }
}
```

Among them:

- `quota`: total consumption quota under these filter conditions
- `rpm`, `tpm`: reserved fields for the current interface, can be used for extended monitoring

## 4. Query Current Account Balance

If customers not only want to monitor by business Key, but also want to display the current Crazyrouter account balance directly on their own backend, they can call `/api/user/self`.

Request headers are consistent with other management interfaces:

```bash cURL
curl "https://crazyrouter.com/api/user/self" \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 4004"
```

Response Example:

```json
{
  "success": true,
  "message": "",
  "data": {
    "id": 4004,
    "username": "google_4004",
    "quota": 11000000,
    "used_quota": 0,
    "request_count": 0,
    "group": "default"
  }
}
```

Key Fields:

| Field | Explanation |
|------|------|
| `quota` | Current remaining quota, in the system's internal quota unit |
| `used_quota` | Quota used historically, in the system's internal quota unit |
| `request_count` | Number of historical requests |
| `group` | Current account group |

Conversion Method:

```text
balance_usd = quota / quota_per_unit
used_usd = used_quota / quota_per_unit
```

Example:

```text
quota = 11000000
quota_per_unit = 500000

balance_usd = 11000000 / 500000 = 22
```

That is, the above sample balance is:

```text
$22.00
```

<Note>
  `/api/user/self` is more suitable for "displaying the current account total balance"; `/api/log/self` and `/api/log/self/stat` are more suitable for "consumption analysis by time range, Key, and model."
</Note>

## 5. Convert USD Expenses

System conversion parameters can be obtained through the public interface `/api/status`:

```bash cURL
curl "https://api.crazyrouter.com/api/status"
```

Focus on in the response:

```json
{
  "success": true,
  "message": "",
  "data": {
    "quota_per_unit": 500000,
    "quota_display_type": "USD",
    "usd_exchange_rate": 7.3
  }
}
```

Conversion Formula:

```text
cost_usd = quota / quota_per_unit
```

Example:

```text
16605808 / 500000 = 33.211616 USD
```

## Python Integration Example

```python
import requests

BASE_URL = "https://crazyrouter.com"
ACCESS_TOKEN = "your_access_token"
USER_ID = "485"
TOKEN_NAME = "gptai"

headers = {
    "Authorization": f"Bearer {ACCESS_TOKEN}",
    "New-Api-User": USER_ID,
    "User-Agent": "Mozilla/5.0",
}

token_resp = requests.get(
    f"{BASE_URL}/api/token/",
    params={"p": 1, "page_size": 100},
    headers=headers,
    timeout=30,
)
token_resp.raise_for_status()
tokens = token_resp.json()["data"]["items"]

log_resp = requests.get(
    f"{BASE_URL}/api/log/self/stat",
    params={
        "type": 2,
        "token_name": TOKEN_NAME,
        "start_timestamp": 1771334901,
        "end_timestamp": 1772309095,
    },
    headers=headers,
    timeout=30,
)
log_resp.raise_for_status()
quota = log_resp.json()["data"]["quota"]

status_resp = requests.get(f"{BASE_URL}/api/status", timeout=30)
status_resp.raise_for_status()
quota_per_unit = status_resp.json()["data"]["quota_per_unit"]

cost_usd = quota / quota_per_unit

print("tokens:", [item["name"] for item in tokens])
print("quota:", quota)
print("cost_usd:", round(cost_usd, 6))
```

## Monitoring Suggestions

For customer-side monitoring, it is recommended to include at least the following dimensions:

- Count the number of calls, total quota, and total expenses by `token_name`
- Count model consumption distribution by `model_name`
- Distinguish `/v1/chat/completions`, `/v1/responses`, and other interfaces by `other.request_path`
- Calculate success and failure rates by `other.http_status`
- Keep issue tracking links by `other.request_id`

## Frequently Asked Questions

### Why can't the management interface use `sk-xxx` directly?

Because `sk-xxx` is a business call credential, verified by `TokenAuth` middleware; whereas management interfaces like `/api/token/*` and `/api/log/self*` use user authentication, which requires `access_token` and `New-Api-User`.

### Can you query your logs by a specific Key?

Yes. It is recommended to filter `/api/log/self` and `/api/log/self/stat` through `token_name`.

### Can you get the expense amount directly through the API?

If the server version already supports the `cost_usd` field, you can obtain the USD expense for a single request directly from the log details. For the summary, it is recommended to use `quota / quota_per_unit` for conversion, which matches the console display.
