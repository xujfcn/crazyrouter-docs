## Overview

Gemini CLI is Google's command-line AI assistant. By configuring Crazyrouter's native Gemini endpoint, you can directly use Gemini models (already validated in our production environment with real requests) from the command line.

## Configuration Method

### Environment Variables

In its current version, Gemini CLI in API Key mode requires at least `GEMINI_API_KEY` to be set explicitly. If you want to connect to Crazyrouter's native Gemini endpoint, it is recommended to set these 3 environment variables:

```bash
export GEMINI_API_KEY=sk-xxx
export GEMINI_MODEL=gemini-3.1-pro
export GOOGLE_GEMINI_BASE_URL=https://api.crazyrouter.com
```

Windows PowerShell:

```powershell
$env:GEMINI_API_KEY="sk-xxx"
$env:GEMINI_MODEL="gemini-3.1-pro"
$env:GOOGLE_GEMINI_BASE_URL="https://api.crazyrouter.com"
```

If you would like this to take effect automatically each time you open the terminal, write it into `~/.gemini/.env` or the PowerShell profile.

### Configuration File

Edit `~/.gemini/settings.json`:

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  },
  "apiKey": "sk-xxx",
  "baseUrl": "https://api.crazyrouter.com",
  "model": {
    "name": "gemini-3.1-pro"
  }
}
```

Note:

- Do not keep the authentication method as `oauth-personal`, or the CLI will continue to use Google login.
- Do not write `model` as a string; in the current version, `model.name` should be used.
- Only specifying `settings.json` is sometimes insufficient—CLI mode may still require the `GEMINI_API_KEY` environment variable.

### `.gemini/.env` Example

You can also write directly to `~/.gemini/.env`:

```bash
GEMINI_API_KEY=sk-xxx
GEMINI_MODEL=gemini-3.1-pro
GOOGLE_GEMINI_BASE_URL=https://api.crazyrouter.com
```

### Launch

```bash
gemini
```

## Recommended Models

| Model | Description |
|------|------|
| `gemini-3.1-pro` | Successfully validated in the Crazyrouter production environment using real requests via Gemini CLI on April 8, 2026. Suitable as the main current baseline. |

<Note>
  Crazyrouter supports both Gemini native API format and OpenAI-compatible format. Gemini CLI uses the Gemini native format. The `gemini-3.1-pro` and `gemini-api-key` authentication methods, as well as `GOOGLE_GEMINI_BASE_URL=https://api.crazyrouter.com` documented here, have all been verified through real CLI requests.
</Note>
