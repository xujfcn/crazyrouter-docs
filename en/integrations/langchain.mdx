LangChain is one of the most commonly used frameworks for developing LLM applications. It is suitable for wrapping chat interfaces, prompt chains, tool calling, RAG, agent workflows, and application-level orchestration. The most reliable way to connect Crazyrouter is by using the OpenAI-compatible components officially supported by LangChain.

## Overview

With LangChain's OpenAI component, you can send requests to Crazyrouter:

- Recommended protocol: `OpenAI-compatible API`
- Base URL: `https://api.crazyrouter.com/v1`
- Authentication variable: `OPENAI_API_KEY`
- Main Python package: `langchain-openai`
- Main JavaScript / TypeScript package: `@langchain/openai`

<Tip>
If you plan to integrate Crazyrouter into your own application code rather than just chatting in a desktop client, LangChain is usually the most natural engineering integration path.
</Tip>

## Who Is It For

- Developers looking to properly integrate Crazyrouter into Python or Node.js projects
- People wanting to build prompt chains, RAG, tool calling, or workflow orchestration
- Those wanting to abstract model calling logic uniformly instead of writing low-level HTTP requests directly
- Those wanting flexibility to switch models or upstream providers in the future

## Usage Protocol

Recommended protocol: `OpenAI-compatible API`

Corresponding core configuration for Crazyrouter:

```text
OPENAI_API_KEY=sk-xxx
BASE_URL=https://api.crazyrouter.com/v1
```

Typical syntax in LangChain:

- Python: `api_key` + `base_url`
- JavaScript / TypeScript: `apiKey` + `configuration.baseURL`

## System Requirements and Prerequisites

| Project | Description |
|------|------|
| Crazyrouter account | Register first at [crazyrouter.com](https://crazyrouter.com) |
| Crazyrouter token | Recommended to create a separate token for your LangChain project |
| Python | Recommended `Python 3.10+` |
| Node.js | Recommended `Node.js 18+` |
| LangChain package | Use `langchain-openai` for Python; `@langchain/openai` for JS / TS |
| Available models | At least enable one chat model; to use vector search, also enable embedding models |

Recommended initial whitelist:

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`
- `text-embedding-3-large`

## Complete Integration Path for Python Projects

### Recommended Path for Windows

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -U langchain-openai langchain-community
python --version

```

## Complete Setup From Scratch

<Steps>
  <Step title="Step 1: Create a dedicated LangChain token in Crazyrouter">
    For the first time, it's recommended to only enable:

    - `gpt-5.5`
    - `claude-opus-4-8`
    - `text-embedding-3-large`

    If you later need more models, expand as needed, but stick to a minimum whitelist at first.
  </Step>

  <Step title="Step 2: Set up environment variables first">
    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        export OPENAI_API_KEY=sk-xxx
        echo $OPENAI_API_KEY
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        $env:OPENAI_API_KEY = "sk-xxx"
        echo $env:OPENAI_API_KEY
        ```
      </Tab>
    </Tabs>

    If you plan to develop long-term, persist the configuration:

    <Tabs>
      <Tab title="Linux Bash">
        ```bash
        echo 'export OPENAI_API_KEY=sk-xxx' >> ~/.bashrc
        source ~/.bashrc
        ```
      </Tab>
      <Tab title="macOS / Zsh">
        ```bash
        echo 'export OPENAI_API_KEY=sk-xxx' >> ~/.zshrc
        source ~/.zshrc
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        [System.Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-xxx", "User")
        $env:OPENAI_API_KEY = "sk-xxx"
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Step 3: Complete the minimal Python chat validation">
    Create a new `test_langchain_chat.py`:

    ```python
    from langchain_openai import ChatOpenAI

    llm = ChatOpenAI(
        model="gpt-5.5",
        api_key="sk-xxx",
        base_url="https://api.crazyrouter.com/v1",
        temperature=0,
    )

    response = llm.invoke("Reply only OK")
    print(response.content)
    ```

    Run:

    ```bash
    python test_langchain_chat.py
    ```
  </Step>

  <Step title="Step 4: Change to the environment variable version">
    After running successfully, it's recommended not to hardcode your key in the code:

    ```python
    import os
    from langchain_openai import ChatOpenAI

    llm = ChatOpenAI(
        model="gpt-5.5",
        api_key=os.environ["OPENAI_API_KEY"],
        base_url="https://api.crazyrouter.com/v1",
        temperature=0,
    )
    ```
  </Step>

  <Step title="Step 5: Complete the minimal JavaScript / TypeScript chat validation">
    Create `test-langchain-chat.mjs`:

    ```javascript
    import { ChatOpenAI } from "@langchain/openai";

    const llm = new ChatOpenAI({
      model: "gpt-5.5",
      apiKey: process.env.OPENAI_API_KEY,
      configuration: {
        baseURL: "https://api.crazyrouter.com/v1",
      },
      temperature: 0,
    });

    const response = await llm.invoke("Reply only OK");
    console.log(response.content);
    ```

    Run:

    ```bash
    node test-langchain-chat.mjs
    ```
  </Step>

  <Step title="Step 6: Gradually add Embeddings, Prompt, RAG">
    It's not recommended to start with complex pipelines. Suggested order:

    1. Run basic single-round chat first
    2. Next, run Prompt + Output Parser
    3. Then, connect Embeddings
    4. Finally, do RAG or Agent
  </Step>
</Steps>

## Python Examples

### Minimal Chat Example

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-5.5",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1",
    temperature=0.7,
)

response = llm.invoke("什么是 LangChain？")
print(response.content)
```

### Embeddings Example

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-large",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1",
)

vectors = embeddings.embed_documents(["文本一", "文本二"])
print(len(vectors), len(vectors[0]))
```

### Prompt Chain Example

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

llm = ChatOpenAI(
    model="gpt-5.5",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1",
)

prompt = ChatPromptTemplate.from_template("用简单的语言解释 {topic}")
chain = prompt | llm | StrOutputParser()

result = chain.invoke({"topic": "量子计算"})
print(result)
```

### Minimal RAG Example

```python
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough

llm = ChatOpenAI(
    model="gpt-5.5",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1",
)

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-large",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1",
)

texts = [
    "Crazyrouter 支持多种 AI 模型协议",
    "Crazyrouter 支持 OpenAI 兼容调用方式",
]

vectorstore = FAISS.from_texts(texts, embeddings)
retriever = vectorstore.as_retriever()

prompt = ChatPromptTemplate.from_template(
    "根据以下上下文回答问题：\n{context}\n\n问题：{question}"
)

chain = {"context": retriever, "question": RunnablePassthrough()} | prompt | llm

result = chain.invoke("Crazyrouter 适合用什么协议接 LangChain？")
print(result.content)
```

## Recommended Model Configuration

| Scenario | Recommended Model | Reason |
|----------|----------|------|
| Initial Pipeline Verification | `gpt-5.5` | Successfully tested in production on March 23, 2026; best for verifying LangChain and Crazyrouter are connected |
| High-quality long text & complex pipelines | `claude-opus-4-8` | Suitable for complex explanation, summarization, and heavier reasoning tasks |
| Gemini backup | `gemini-3.1-pro` | Suitable as a secondary compatibility verification path |
| Vector search | `text-embedding-3-large` | Good for validating embedding baseline first |

## Best Practices for Token Settings

| Setting | Recommendation | Description |
|------|------|------|
| Dedicated token | Mandatory | Do not use the same token for LangChain project and desktop client |
| Model whitelist | Strongly recommended | Initially only enable chat models + embedding models |
| Quota limit | Strongly recommended | Chain calls, RAG, and Agent increase consumption |
| Environment isolation | Recommended | Use separate tokens for dev / staging / production |
| Leak handling | Rotate immediately | Do not submit keys to Git; immediately change keys if leaked |

## Verification Checklist

- [ ] Python or Node.js runtime environment is ready
- [ ] `OPENAI_API_KEY` is properly set
- [ ] `langchain-openai` or `@langchain/openai` is installed
- [ ] Chat model is set `base_url` / `baseURL` to `https://api.crazyrouter.com/v1`
- [ ] The first `Reply only OK` request returns successfully
- [ ] Corresponding request visible in Crazyrouter backend logs
- [ ] If using embeddings, embedding model is enabled
- [ ] If using RAG, first verify with minimal text set

## Common Errors and Fixes

| Phenomenon | Common Cause | Fix |
|------|----------|----------|
| 401 unauthorized | `OPENAI_API_KEY` is incorrect, expired, or copied wrong | Regenerate token and reset environment variable |
| 404 | `base_url` / `baseURL` written incorrectly or `/v1` missing | Change to `https://api.crazyrouter.com/v1` |
| `model not found` | Model name incorrect or token not whitelisted | Switch back to confirmed models like `gpt-5.5` and check whitelist |
| Embeddings error | Forgot to enable embedding model | Add `text-embedding-3-large` to token |
| RAG not running | Too many components connected initially | Roll back to basic chat, then add components step by step |
| Consumption too fast | Chain calls, retrieval, multi-round Agent superimposed | Minimize pipeline and separately control token quota |

## FAQ

### What protocol should LangChain use to connect to Crazyrouter?

Prefer OpenAI-compatible protocol.

### What should be entered for Base URL?

Enter `https://api.crazyrouter.com/v1`.

### Which package should be used in Python?

Prefer `langchain-openai`.

### Which package should be used in JavaScript / TypeScript?

Prefer `@langchain/openai`.

### Why is it not recommended to start with Agent or large-scale RAG the first time?

Because LangChain pipelines become significantly harder to troubleshoot as complexity increases. Start with minimal chat and add components step by step for stability.
