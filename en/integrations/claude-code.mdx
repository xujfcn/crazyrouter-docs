Claude Code is currently one of the terminal coding tools most recommended for priority integration with Crazyrouter. It directly uses the Anthropic Messages API, making it suitable for reading code, modifying, refactoring, executing commands, tool invocation, and long-context repository analysis.

## Overview

By using environment variables, Claude Code can send Anthropic requests directly to Crazyrouter:

- Recommended protocol: `Anthropic Messages API`
- Base URL: `https://api.crazyrouter.com`
- Default international API Base URL: `https://api.crazyrouter.com`
- Authentication variable: `ANTHROPIC_API_KEY`
- Recommended default model: `claude-opus-4-8`

<Tip>
Claude Code will complete the Anthropic request path on its own, so you must write only the root domain for the Base URL, either `https://api.crazyrouter.com` or `https://api.crazyrouter.com`, and do not manually append `/v1` or `/v1/messages`.
</Tip>

## Who is this for

- Developers who want to use Crazyrouter as the backend for Claude Code
- People who want stable tool invocation, long context support, and terminal coding workflows
- Users who want to separately bill Claude Code and Cursor / Codex / Aider
- Teams who want unified CLI configuration across Linux, macOS, and Windows

## Usage protocol

Recommended protocol: `Anthropic Messages API`

When integrating Claude Code with Crazyrouter, use:

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

For the default international API endpoint, also use only the root address:

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

Do not write it as:

- `https://api.crazyrouter.com/v1`
- `https://api.crazyrouter.com/v1/messages`
- `https://api.crazyrouter.com/v1/complete`
- `https://api.crazyrouter.com/v1`
- `https://api.crazyrouter.com/v1/messages`

## Full installation paths by operating system

### Recommended path for Windows

The most reliable path for Claude Code on Windows is: `Git` + `Node.js` + `Global installation of Claude Code using npm` + `PowerShell` written into the environment variables.

Recommended steps:

1. Install Git
2. Install Node.js LTS
3. Use npm to install Claude Code
4. Use PowerShell for writing temporary variables
5. Use PowerShell for writing user-level persistent variables

Recommended verification command:

```powershell
git --version
node -v
npm -v
claude --version
where.exe git
where.exe node
where.exe claude
```

If `claude --version` cannot find the command, close and reopen PowerShell before trying again.

### Recommended path for macOS

For macOS, the smoothest path for Claude Code is usually: `Xcode Command Line Tools` + `Homebrew` + `Git` + `Node.js` + `Global installation of Claude Code using npm` + `~/.zshrc` for persistent environment variables.

Recommended steps:

1. Install Xcode Command Line Tools
2. Install Homebrew (if you don't have it yet)
3. Install Git and Node.js
4. Use npm to install Claude Code
5. Write `~/.zshrc`
6. Open a new terminal to verify the command path

Recommended verification command:

```bash
git --version
node -v
npm -v
claude --version
which git
which node
which claude
```

### Why manual API path entry is not recommended here

Claude Code uses the native Anthropic protocol. You only need to provide the root site address:

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

For the default international API endpoint, also only fill in the root address:

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

Do not build `/v1`, `/v1/messages`, or other specific API paths as you would for an OpenAI-compatible client.

If you want to script Claude Code installation and write related Crazyrouter environment variables automatically, you can check [crazyrouter-claude-code](https://github.com/xujfcn/crazyrouter-claude-code). This repository provides one-click setup scripts for Windows, macOS, and Linux; this document still includes a full manual setup for you to review each configuration item.

## Complete installation from scratch

<Steps>
  <Step title="Step 1: Install Git">
    If your machine doesn't have Git yet, install Git before continuing with Claude Code setup.

    <Tabs>
      <Tab title="Windows PowerShell">
        ```powershell
        winget install --id Git.Git -e --source winget
        git --version
        ```
      </Tab>
      <Tab title="macOS">
        ```bash
        xcode-select --install
        git --version
        ```
        If you are already using Homebrew, you can also:
        ```bash
        brew install git
        git --version
        ```
      </Tab>
      <Tab title="Ubuntu / Debian">
        ```bash
        sudo apt update
        sudo apt install -y git
        git --version
        ```
      </Tab>
    </Tabs>

    After installation, it's recommended to add global identity information:

    ```bash
    git config --global user.name "Your Name"
    git config --global user.email "you@example.com"
    git config --global init.defaultBranch main
    ```
  </Step>

  <Step title="Step 2: Install Node.js 18 or above">
    Claude Code depends on Node.js. Confirm the version before continuing to install Claude Code.

    <Tabs>
      <Tab title="Windows PowerShell">
        ```powershell
        winget install OpenJS.NodeJS.LTS
        node -v
        npm -v
        ```
      </Tab>
      <Tab title="macOS">
        ```bash
        brew install node
        node -v
        npm -v
        ```
      </Tab>
      <Tab title="Ubuntu / Debian">
        ```bash
        sudo apt update
        sudo apt install -y nodejs npm
        node -v
        npm -v
        ```
      </Tab>
    </Tabs>

    If after installation `node -v` is still below 18, it is recommended to upgrade using `nvm` or the official Node installer before continuing.
  </Step>

  <Step title="Step 3: Install Claude Code">
    <Tabs>
      <Tab title="Windows PowerShell">
        ```powershell
        npm install -g @anthropic-ai/claude-code
        claude --version
        where.exe claude
        ```
      </Tab>
      <Tab title="macOS">
        ```bash
        npm install -g @anthropic-ai/claude-code
        claude --version
        which claude
        ```
      </Tab>
    </Tabs>

    <Warning>
    Do not use `sudo npm install -g @anthropic-ai/claude-code`. If you encounter permission issues during global installation, fix the npm/Node environment before proceeding.
    </Warning>
  </Step>

  <Step title="Step 4: Create a dedicated token for Claude Code in Crazyrouter">
    After logging into the Crazyrouter dashboard, create a dedicated token, and it's recommended to name it `claude-code`.

    Initially, it's only recommended to allow:

    - `claude-opus-4-8`
    - `claude-opus-4-8`

    It's also recommended to set a separate quota for it to avoid sharing budget with Cursor, Codex, or OpenClaw.
  </Step>

  <Step title="Step 5: First set temporary environment variables in the current terminal">
    First set up a temporary configuration; after confirming it works, then write the persistent configuration.

    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        export ANTHROPIC_BASE_URL=https://api.crazyrouter.com
        export ANTHROPIC_API_KEY=sk-xxx
        echo $ANTHROPIC_BASE_URL
        echo $ANTHROPIC_API_KEY
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        $env:ANTHROPIC_BASE_URL = "https://api.crazyrouter.com"
        $env:ANTHROPIC_API_KEY = "sk-xxx"
        echo $env:ANTHROPIC_BASE_URL
        echo $env:ANTHROPIC_API_KEY
        ```
      </Tab>
    </Tabs>

    Write `ANTHROPIC_BASE_URL` as the root domain `https://api.crazyrouter.com`, do not write it as `https://api.crazyrouter.com/v1`.
  </Step>

  <Step title="Step 6: Write environment variables into the persistent configuration">
    Temporary variables are only valid for the current terminal. For daily use, write them into your shell configuration file.

    <Tabs>
      <Tab title="Linux Bash">
        ```bash
        echo 'export ANTHROPIC_BASE_URL=https://api.crazyrouter.com' >> ~/.bashrc
        echo 'export ANTHROPIC_API_KEY=sk-xxx' >> ~/.bashrc
        source ~/.bashrc
        ```
      </Tab>
      <Tab title="macOS / Zsh">
        ```bash
        echo 'export ANTHROPIC_BASE_URL=https://api.crazyrouter.com' >> ~/.zshrc
        echo 'export ANTHROPIC_API_KEY=sk-xxx' >> ~/.zshrc
        source ~/.zshrc
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        [System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.crazyrouter.com", "User")
        [System.Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-xxx", "User")

        $env:ANTHROPIC_BASE_URL = "https://api.crazyrouter.com"
        $env:ANTHROPIC_API_KEY = "sk-xxx"
        ```
      </Tab>
    </Tabs>

    The `ANTHROPIC_BASE_URL` in the persistent variables should also be written as `https://api.crazyrouter.com`.

    After finishing, it's recommended to open a new terminal, then run:

    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        claude --version
        echo $ANTHROPIC_BASE_URL
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        claude --version
        echo $env:ANTHROPIC_BASE_URL
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Step 7: Prepare your Git repository">
    Claude Code will read and write files and execute commands. For first integration, it's recommended to test in a small, familiar repository.

    If the current directory is not a Git repository:

    ```bash
    git init
    git add .
    git commit -m "chore: initial snapshot before Claude Code"
    ```

    If it is already an existing repository, at least make sure the working tree is in a state you can accept:

    ```bash
    git status
    ```
  </Step>

  <Step title="Step 8: Launch Claude Code and complete the first verification">
    After entering the project directory, run:

    ```bash
    cd /path/to/your/project
    claude
    ```

    For first-time verification, it's recommended to follow these steps in order:

    1. First send: `Please reply with OK only`
    2. Then send: `Only read the current repository structure, do not modify any files`
    3. Finally, perform a low-risk task, such as: `Please identify obvious typos in the README before directly editing the file`

    If all three return normally, and request logs appear in the Crazyrouter dashboard, it means the link is now working end-to-end.
  </Step>
</Steps>

### How to Switch Models

Claude Code selects models using either the `ANTHROPIC_MODEL` environment variable or the `/model` command within a session. Just replace the model name with any from the table above.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    export ANTHROPIC_BASE_URL=https://api.crazyrouter.com
    export ANTHROPIC_API_KEY=sk-xxx

    # 临时切到 Kimi K2.5
    export ANTHROPIC_MODEL=kimi-k2.5
    claude

    # 或临时切到 MiniMax
    ANTHROPIC_MODEL=MiniMax-M2.7 claude
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    $env:ANTHROPIC_BASE_URL = "https://api.crazyrouter.com"
    $env:ANTHROPIC_API_KEY  = "sk-xxx"

    $env:ANTHROPIC_MODEL = "kimi-k2.5"
    claude

    # 或临时切换
    $env:ANTHROPIC_MODEL = "MiniMax-M2.7"; claude
    ```
  </Tab>
</Tabs>

You can also switch via session command after Claude Code starts:

```text
/model kimi-k2.5
/model MiniMax-M2.7
```

### Recommendations and Known Differences

- **Preferred Order**: If you wish to prioritize domestic models in Claude Code, currently recommended to start with `kimi-k2.5`, `kimi-k2.6`, then consider `deepseek-v4-pro`. For the Qwen series, please confirm available model IDs via `/v1/models` first, then verify individually.
- **MiniMax Known Differences**: `MiniMax-M2.7`, although protocol is available, outputs its thinking process as plain text with `<think>...</think>` tags at start and end. For strict tasks like "output only one sentence", it's not recommended to pick this first.
- **DeepSeek / GLM Boundaries**: `deepseek-v4-pro` and `glm-5.1` are available in Claude Code, but this does not mean they are also suitable for native Codex Responses configuration. These two are separate protocols—do not mix compatibility conclusions.
- **Token Whitelist**: If your Claude Code-specific token enables a model whitelist, be sure to add the domestic models you want to use; otherwise, `403 model not allowed` will be returned.
- **Recommend Real Client Validation First**: Run a round of `Reply only OK` first, then perform the "read a file and only return the title" task, as this is closer to the real usage scenario of Claude Code than just testing the bare API.

### One Command to Quickly Check If a Model is Available

```bash
curl -sS https://api.crazyrouter.com/v1/messages \
  -H "Authorization: Bearer $ANTHROPIC_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k2.5",
    "max_tokens": 32,
    "messages": [{"role":"user","content":"reply OK"}]
  }'
```

A 200 response and a non-empty `content[].text` mean Claude Code can use the model normally.

## Best Practices for Token Settings

| Setting | Recommendation | Description |
|---------|----------------|-------------|
| Dedicated token | Required | Do not share Claude Code token with Cursor, Codex, OpenClaw |
| Model whitelist | Highly recommended | Only permit the actual Claude or domestic models needed to simplify troubleshooting and control costs |
| IP restriction | Recommend for fixed exit environments | Use with caution if your laptop IP changes frequently |
| Quota limit | Highly recommended | Claude Code long sessions + tool use can keep consuming quota |
| Dev / team isolation | Recommended | Each developer and each shared host should use a separate token |
| Rotate if leaked | Required | Immediately rotate token if exposed through shell history, screen recording, or shared terminal |

## Common Errors and Fixes

| Phenomenon | Common Reason | Fix |
|------------|--------------|-----|
| `claude: command not found` | Claude Code not installed, or npm global path not in PATH | Reinstall, confirm `npm bin -g` directory is in PATH |
| `node` version too low | Local Node version is below requirements | Upgrade to Node.js 18+ and reinstall Claude Code |
| 401 unauthorized | `ANTHROPIC_API_KEY` invalid, expired or copy error | Regenerate token and reset environment variable |
| 403 / model not allowed | Token does not permit current Claude model | Permit needed model via Crazyrouter token settings |
| 404 | Base URL incorrectly set to `/v1`, `/v1/messages` or other wrong path | Change to `https://api.crazyrouter.com` or `https://api.crazyrouter.com` |
| Log paths showing `/v1/v1/messages`, `/v1/v1/models` or `/v1/messages/v1/messages` | Claude Code Base URL has `/v1` or full endpoint, client auto-appends path again | Change `ANTHROPIC_BASE_URL` to root domain, do not include any path |
| Claude Code still uses old config after starting | New environment variable not reloaded | Start new terminal or `source ~/.bashrc` / `source ~/.zshrc` again |
| Git changes too messy | No repo snapshot taken before letting AI edit code | Commit initial snapshot first, then modify in stages |
| Unexpected cost | Long context + multiple tool calls + long session | Shorten sessions, split tasks, set dedicated budget for Claude Code |

## FAQ

### What should the Base URL be in Claude Code?

Just use root domain: `https://api.crazyrouter.com`

Default international API entry: use root domain `https://api.crazyrouter.com`

### Why can't `/v1` be used here?

Because Claude Code will itself append the Anthropic Messages API path. Just provide the site root address.

### What's recommended for Windows?

If you mainly develop in command line, prioritize PowerShell or WSL2. Make sure Git, Node.js, and Claude Code are properly installed, whichever method you choose.

### PowerShell or Git Bash for Windows?

For initial setup, use PowerShell: environment variable writing, `where.exe` validation, and user-level variable persistence are more straightforward.

### Why take a Git snapshot first?

Because Claude Code will change files and run commands. Snapshots make review and rollback easier if issues occur.

### Which model is recommended first?

Start with `claude-opus-4-8`, which is usually the most stable baseline model.

If you prioritize Claude series models + terminal coding experience, Claude Code should be at the top of the integration order in Crazyrouter code tools.
