## Overview

RikkaHub is an AI model aggregation client, supporting unified management for various model providers.

## Configuration Steps

<Steps>
  <Step title="Open Settings">
    Go to the RikkaHub settings page and find the `Model Service` or `API Configuration` option.
  </Step>
  <Step title="Add Provider">
    Click to add a new provider:
    - **Type**: OpenAI Compatible
    - **Name**: Crazyrouter
    - **API Base URL**: `https://api.crazyrouter.com/v1`
    - **API Key**: `sk-xxx`
  </Step>
  <Step title="Select Model">
    After completing the configuration, select the desired model from the model list.
  </Step>
</Steps>

## Available Models

Once configured, it is recommended to first add the currently validated main models:

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

First use `gpt-5.5` to complete the initial connectivity test; then add Claude, Gemini, or any other model already enabled in the site's model list as needed.

<Note>
  RikkaHub supports configuring multiple providers at the same time and allows flexible switching in conversations.
</Note>
