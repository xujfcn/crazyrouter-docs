Immersive Translation is a browser extension ideal for everyday web page translation, bilingual reading, selected text translation, and document translation. When integrating with Crazyrouter, the most reliable way is to use the officially-supported `OpenAI` service configuration, and fill in your custom API address in `More settings`.

## Overview

By configuring Immersive Translation's OpenAI service, you can send requests to Crazyrouter:

- Recommended protocol: `OpenAI-compatible API`
- Service type: `OpenAI`
- API Key: your `sk-...`
- Custom API address: `https://api.crazyrouter.com/v1/chat/completions`
- Recommended initial verification model: `gpt-5.5`

<Tip>
The biggest difference between Immersive Translation and ChatBox is that you usually need to fill in the complete API path here, not just the root domain name.
</Tip>

## Why the complete path should be filled in here

According to the Immersive Translation official OpenAI service documentation, it supports customizing the OpenAI API address in `More settings`. So, for Crazyrouter, it's generally more reliable to write the full address:

```text
https://api.crazyrouter.com/v1/chat/completions
```

<Warning>
Don't enter just the root domain `https://api.crazyrouter.com` here, and don't only write up to `/v1`. For this kind of connection, it's best to use the full `/v1/chat/completions` path for the first round of verification.
</Warning>

## Installation and Configuration Path

### Chrome / Edge Path

1. Install Immersive Translation from the extension store
2. Open extension settings
3. Go to `Translation service`
4. Choose `OpenAI`
5. Open `More settings`
6. Enter Crazyrouter key and the full custom address

### Firefox Path

1. Install Immersive Translation from Firefox Add-ons
2. Open the settings page
3. Go to `Translation service`
4. Choose `OpenAI`
5. Enter `More settings`
6. Fill in Crazyrouter parameters

## Complete configuration from scratch

<Steps>
  <Step title="Step 1: Install the extension">
    Install "Immersive Translation" from the official extension store.
  </Step>

  <Step title="Step 2: Create a dedicated token in Crazyrouter">
    For your first setup, only allow:

    - `gpt-5.5`
    - `claude-opus-4-8`

    Don't add too many models to the translation scenario right away.
  </Step>

  <Step title="Step 3: Open the OpenAI service configuration">
    After clicking the extension icon, go to:

    - `Settings`
    - `Translation service`
    - Choose `OpenAI`
  </Step>

  <Step title="Step 4: Enter the API Key and custom address">
    Fill in:

    - `API Key`: your `sk-...`
    - `Custom API endpoint address`: `https://api.crazyrouter.com/v1/chat/completions`
    - `Model`: start with `gpt-5.5`

    If some parameters are collapsed by default in the interface, remember to expand `More settings` to view all fields.
  </Step>

  <Step title="Step 5: First, reduce the request frequency">
    The Immersive Translation official documentation has a special note about frequency limits for OpenAI connections. When connecting to Crazyrouter for the first time, it's recommended to lower the request frequency, especially for long texts or eBooks.

    A conservative initial approach is recommended, such as:

    - Don't set too high a request rate per second
    - Test with smaller pages or selected text first
    - Gradually increase after successful connection
  </Step>

  <Step title="Step 6: Complete the first minimal verification">
    Recommended order:

    1. First translate a small selected text
    2. Then translate a short web page
    3. Finally, test a full page or longer document

    This makes it easier to distinguish "API configuration error" from "unstable due to too much request volume."
  </Step>
</Steps>

## Best Practices for Token Settings

| Setting | Recommendation | Description |
|------|------|------|
| Dedicated token | Mandatory | Don't share tokens between browser translation extensions and IDE/CLI tools |
| Model whitelist | Highly recommended | Start by only allowing 1-2 translation models |
| Quota cap | Highly recommended | Whole-page or eBook translation consumes quota much faster than ordinary conversations |
| Device isolation | Recommended | Use different tokens for different browsers or devices |
| Leak handling | Rotate immediately | Replace the key immediately after leaks via screen recording, screenshots, or browser sync |

## Common Errors & Fixes

| Issue | Common Cause | Solution |
|------|----------|----------|
| 404 | Missing `/chat/completions` in API address, or only the root domain entered | Change to full address `https://api.crazyrouter.com/v1/chat/completions` |
| 401 unauthorized | API Key incorrect, expired, or incomplete copy | Regenerate token and refill |
| 403/model not allowed | Token not allowed for current model | Allow model in Crazyrouter token settings |
| 429/unstable | Request frequency too high | Lower request frequency, start with small texts |
| Higher failure rate for long texts | Too many concurrent or overly frequent requests | Reduce translation range first, then gradually increase |
| Costs rising too fast | Directly translating whole pages, sites, or eBooks | Use `gpt-5.5` for small-scale validation first and control translation range |

## Money-saving Tips

- Use `gpt-5.5` by default
- Prefer translating selected areas instead of whole pages
- Sample quality on long documents before deciding on full translation
- If you have the extension on multiple browsers, use separate tokens for cost accounting

## FAQ

### What API address should be entered in Immersive Translation?

Enter the full path: `https://api.crazyrouter.com/v1/chat/completions`.

### Why is this different from ChatBox, and root domain only entry not recommended?

Because Immersive Translation's official OpenAI custom address entry is more suitable for the full interface path, first validation is more reliable.

### What's the first recommended model?

Start with `gpt-5.5`.

### Why is it not recommended to directly translate whole pages or eBooks at first?

Because it magnifies configuration, frequency limit, and cost issues all at once. Translating small segments first helps troubleshoot faster.
