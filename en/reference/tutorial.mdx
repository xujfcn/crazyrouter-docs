# Access Tutorial

This page only records the getting started paths `2026-03-23` that have already been reviewed in the production environment of Crazyrouter.

If you want to get started the fastest, first distinguish three access types:

- OpenAI Compatible: `https://api.crazyrouter.com/v1`
- Anthropic Native: `https://api.crazyrouter.com`
- Gemini Native: `https://api.crazyrouter.com/v1beta/models/...`

## Shortest Migration Principle

To migrate from an OpenAI compatible client to Crazyrouter, usually only two changes are needed:

1. Change `base_url` to `https://api.crazyrouter.com/v1`
2. Change `api_key` to Crazyrouter's `sk-xxx`

---

## Migrating from OpenAI

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "Hello"}],
    max_tokens=64
)
```

Production review in this round confirms:

- `gpt-5.5` can return normally through `/v1/chat/completions`
- If you need reasoning summaries or OpenAI-style web search, it is preferred to switch to `/v1/responses`

Related pages:

- [Responses API Overview](/en/chat/responses/overview)
- [GPT-5 Thinking Mode](/en/chat/responses/gpt5-thinking)

## Migrating from Anthropic

### Option A: Continue Using the OpenAI Compatible Layer

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="claude-opus-4-8",
    messages=[{"role": "user", "content": "Hello"}],
    max_tokens=64
)
```

### Option B: Use Anthropic Native Messages

```python
import anthropic

client = anthropic.Anthropic(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com"
)

response = client.messages.create(
    model="claude-opus-4-8",
    max_tokens=128,
    messages=[{"role": "user", "content": "Hello"}]
)
```

If you want to:

- Standard Claude conversations: Prefer `claude-opus-4-8`
- Explicitly need thinking block: Prefer `claude-opus-4-8`

Related pages:

- [Claude Native Format](/en/chat/anthropic/messages)

## Migrating from Gemini

### Option A: OpenAI Compatible Layer

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="gemini-3.1-pro",
    messages=[{"role": "user", "content": "Hello"}],
    max_tokens=64
)
```

### Option B: Gemini Native

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "Hello"}
        ]
      }
    ]
  }'
```

If you want to:

- Only reuse existing OpenAI SDK code: Start with the compatible layer
- Need structured output, Google Search, thinking: Prefer Gemini native

Related pages:

- [Gemini OpenAI Compatible Format](/en/chat/gemini/openai-compat)
- [Gemini Native Format](/en/chat/gemini/native)

## Environment Variable Method

If you use the OpenAI compatible layer, it is recommended to first configure:

<Tabs>
  <Tab title="Linux / macOS">
    ```bash
    export OPENAI_API_KEY=sk-xxx
    export OPENAI_BASE_URL=https://api.crazyrouter.com/v1
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    $env:OPENAI_API_KEY = "sk-xxx"
    $env:OPENAI_BASE_URL = "https://api.crazyrouter.com/v1"
    ```
  </Tab>
</Tabs>

Then in your code, you can directly:

```python
from openai import OpenAI
client = OpenAI()
```

## Getting Started Recommendations

| Target | Recommended Start Method |
|--------|--------------------------|
| Fastest access to GPT | OpenAI Compatible + `gpt-5.5` |
| Fastest access to Claude | Anthropic Native + `claude-opus-4-8` |
| Fastest access to Gemini | OpenAI Compatible or Gemini Native + `gemini-3.1-pro` |
| Need reasoning summary | Responses API |
| Need Claude thinking block | `claude-opus-4-8` |
| Need Gemini Google Search / thinking / responseSchema | Gemini Native |

<Note>
  Crazyrouter supports OpenAI, Anthropic, and Gemini protocols simultaneously. A more robust approach is usually not "forcing all models to use the same protocol," but to choose the most suitable entry based on capabilities.
</Note>
