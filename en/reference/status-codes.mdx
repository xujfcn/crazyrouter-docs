## HTTP Status Codes

| Status Code | Description | Handling Suggestion |
|--------|------|----------|
| 200 | Request successful | - |
| 400 | Request parameter error | Check request body format and parameters |
| 401 | Authentication failed | Check if the API Key is correct |
| 403 | Insufficient permissions | Check if the token has permission to access the model |
| 404 | Resource does not exist | Check the URL path |
| 429 | Request frequency exceeded | Lower request frequency or contact administrator |
| 500 | Server-side 5xx error | Can retry; may be internal site error or upstream 5xx returned through the site |
| 502 | Failed to obtain gateway or upstream result | Usually means upstream call phase has been entered, but failed to obtain valid upstream response or result, can retry |
| 503 | Service unavailable | System under maintenance |

## Difference Between 500 and 502

- `500` is a broader server-side error. In CrazyRouter, it may indicate an internal site error or upstream directly returning `5xx`, which is relayed to the client by the site.
- `502` is more specific, usually indicating that the request has reached CrazyRouter's gateway or upstream call phase, but CrazyRouter failed to obtain a valid upstream response or result (such as upstream unreachable, invalid gateway-level response returned, or failure to retrieve task result address).
- If similar issues persist:
  - Lots of `502` usually require checking upstream channel availability, network connectivity, and whether the result URL is accessible first.
  - Many `500` need to be further distinguished based on error type and logs; only those clearly marked as on-site `site_internal` or panic situations should be directly considered CrazyRouter's own problem.

## General Error Handling Suggestions

<Warning>
  When encountering 429 errors, do not retry immediately. It is recommended to use an exponential backoff strategy, starting with a wait of 1 second and doubling each time.
</Warning>

```python
import time
import requests

def request_with_retry(url, headers, json_data, max_retries=3):
    for i in range(max_retries):
        response = requests.post(url, headers=headers, json=json_data)
        if response.status_code == 429:
            wait = 2 ** i
            print(f"频率限制，等待 {wait} 秒后重试...")
            time.sleep(wait)
            continue
        return response
    return response
```
