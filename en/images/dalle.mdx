# DALL-E legacy API reference

The old DALL-E examples and duplicated size table have been retired. The public catalogue checked on 2026-10-12 does not list `dall-e-3`; historical examples are not a current availability guarantee. Catalogue absence does not prove every compatibility alias is unavailable. Check models visible to your key and the applicable endpoint before calling.

For synchronous images, select a model documented for the Images API, such as `gpt-image-2`. Verify its size, count and billing rules. Do not automatically carry DALL-E quality/style parameters into other image models.
