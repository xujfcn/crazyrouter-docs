# Doubao Seedream

```
POST /v1/images/generations
```

Crazyrouter currently publicly offers the `Seedream` image model series through an OpenAI Images compatible protocol. Clients continue to use the unified `/v1/images/generations`; the Byte official team and other third-party channels only serve as internal providers and do not separately expose the client protocol.

## Currently Available Models

| Model | Official Correspondence | Current Client Capabilities | Documentation Status |
|------|----------|--------------|----------|
| `doubao-seedream-4-0` | Seedream 4.0 | Text-to-image, image-to-image, multiple reference images, group image output | Beta |
| `doubao-seedream-4-5` | Seedream 4.5 | Text-to-image, image-to-image, multiple reference images, group image output | Beta |
| `doubao-seedream-5-0` | Seedream 5.0 lite | Text-to-image, image-to-image, multiple reference images, group image output | Beta |
| `doubao-seedream-3-0` | Seedream 3.0 | Compatibility reserved | Legacy |

<Note>
  The meaning of “Beta” here is: The client protocol and official capability definitions have been aligned, but current production support and tested artifacts are still being completed. The official capabilities are stated in their full form, and unfinished parts retain the Beta mark.
</Note>

## Client Protocol

### Request Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `model` | string | Yes | `doubao-seedream-4-0`, `doubao-seedream-4-5`, `doubao-seedream-5-0` |
| `prompt` | string | Yes | Generation prompt |
| `image_input` | string or string[] | No | Reference image URL. The current capability limit for official 4.0 / 4.5 / 5.0 lite is `14` images |
| `size` | string | No | Output dimensions. `Seedream 4.5` official support for `2K`, `4K`, as well as explicit width and height within range; `Seedream 5.0 lite` currently requires width × height to be at least `3,686,400` total pixels |
| `n` | integer | No | Number of output images, default is `1` |
| `response_format` | string | No | `url` or `b64_json` |
| `watermark` | boolean | No | Whether to add a watermark |
| `sequential_image_generation` | string | No | `auto` or `disabled`; used for group image output and sequential generation semantics |
| `optimize_prompt_options` | object | No | Official prompt optimization options; currently, only `mode: "standard"` is confirmed for `Seedream 4.5` and `5.0 lite` |

### Seedream 5.0 Dimension Requirements

Explicit `width x height` dimensions for `doubao-seedream-5-0` must meet the following:

```text
宽 × 高 >= 3,686,400
```

| Size | Total Pixels | Meets Minimum Threshold? |
|------|--------|------------------|
| `2688x1152` | `3,096,576` | No; upstream returns `InvalidParameter` |
| `2048x2048` | `4,194,304` | Yes; also needs to comply with the model-supported width, height, and aspect ratio range |

<Warning>
  Do not repeatedly retry or judge the model as unavailable for the same invalid dimensions. If error logs show “Service temporarily unavailable” or “The requested model is temporarily unavailable”, please check `size` first; current general error logs may mask more specific upstream dimension errors.
</Warning>

### Reference Image Boundaries

- `Seedream 4.0`, `4.5`, `5.0 lite` officially support a maximum of `14` reference images
- The maximum size for a single reference image is `10MB`
- Supported input formats officially extended to `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`
- Supported input image aspect ratio ranges from `1/16` to `16`

### Request Example

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "doubao-seedream-4-5",
    "prompt": "一张高级感产品海报，主体是一只透明玻璃香水瓶，晨雾光线，简洁中文标题",
    "size": "2K",
    "n": 1,
    "response_format": "url",
    "watermark": false,
    "optimize_prompt_options": {
      "mode": "standard"
    }
  }'
```

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "doubao-seedream-4-5",
    "prompt": "基于这些参考图生成同一角色的一组商品海报，保持主体一致但镜头和布局不同",
    "image_input": [
      "https://example.com/ref-1.png",
      "https://example.com/ref-2.png"
    ],
    "size": "2K",
    "sequential_image_generation": "auto",
    "response_format": "url",
    "optimize_prompt_options": {
      "mode": "standard"
    }
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.images.generate(
    model="doubao-seedream-4-5",
    prompt="一张高级感产品海报，主体是一只透明玻璃香水瓶，晨雾光线，简洁中文标题",
    size="2K",
    n=1
)

print(response.data[0].url)
```

## Official Billing Method

The currently confirmed official benchmark is “billed by the number of successfully generated images,” not based on input/output token metrics.

| Model | Official Benchmark | Official Unit Price | Current Documentation Status |
|------|----------|----------|--------------|
| `doubao-seedream-4-0` | Per image | `$0.03 / image` | Aligned with official |
| `doubao-seedream-4-5` | Per image | `$0.04 / image` | Aligned with official |
| `doubao-seedream-5-0` | Per image | Official price pending release | Beta |

## Alignment Description

- The client protocol has already settled to the unified `/v1/images/generations`
- `Seedream 4.5` official dimension capability currently focuses on `2K`, `4K`, with `2048x2048` as default
- `Seedream 4.5` and `5.0 lite`’s `optimize_prompt_options.mode` are currently only aligned according to `standard`; `fast` is not a current client commitment
- `Seedream 3.0` continues to reserve compatibility aliases, but the official alignment focus on this page has shifted to `4.0 / 4.5 / 5.0 lite`
