# Nano Banana Pro

```
POST /v1/images/generations
```

Use `nano-banana-pro` to generate images or edit based on references, all using the unified, `OpenAI Images API`-style open protocol.

<Warning>
  Requests for image generation, image editing, and multiple reference images are usually time-consuming. For production access, it's recommended to use the primary route `https://api.crazyrouter.com/v1`; the full generation endpoint is `https://api.crazyrouter.com/v1/images/generations`. Account login, recharge, and the dashboard still use `https://crazyrouter.com`.
</Warning>

## What this page covers

- This page only covers `nano-banana-pro` / `nano-banana-pro`
- The client entrypoint for requests is unified as `POST /v1/images/generations`
- The input image field is unified as `image_input`
- The default open protocol is still recommended to use `image_input` URL; for designated graylist accounts, dataURL, raw Base64, and three-image multipart editing are also supported
- `data:` / Base64 / multipart are Crazyrouter compatibility extensions, not guaranteed to be natively supported by all upstream carriers
- Backend can be providers like Gemini / Vertex, but those details are not part of the client protocol
- Users should not send `generationConfig`, `imageConfig`, `imageOutputOptions`, or `image_output_options`; these are auto-converted from unified parameters by Crazyrouter

## Request Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `model` | string | Yes | Recommended `nano-banana-pro`; also compatible with `nano-banana-pro` |
| `prompt` | string | Yes | Generation or editing instruction |
| `image_input` | string or string[] | No | Usually pass reference image URL; graylist accounts can also pass dataURL / raw Base64; three images already verified |
| `resolution` | string | No | Currently officially supports `1K`, `4K` |
| `aspect_ratio` | string | No | Currently officially supports `1:1`, `21:9` |
| `output_format` | string | No | Currently officially supports `png`, `jpeg` / `jpg` |
| `output_compression` | integer | No | `0-100`, used for JPEG compression quality |
| `n` | integer | No | Quantity to generate, default `1` |

### Current Multi-Image Status

- `2` images: verified
- `11257` graylist three-image: verified
- Higher count: upstream exact max still to be tested, not committed yet

### Routing Explanation

- Single image requests can be served by general available providers
- By default, multi-image requests are only routed to official `Gemini / Vertex` carrier; specified graylist accounts can use verified graylist carriers
- This is an internal server routing policy; client protocol remains unchanged

### Graylist Three-Image Multipart

`11257` graylist accounts can use `/v1/images/edits`:

```bash
curl -X POST https://api.crazyrouter.com/v1/images/edits \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=nano-banana-pro" \
  -F "prompt=以第一张为原图，第二张为批注图，第三张为参考图，仅修改批注区域" \
  -F "image[]=@original.png" \
  -F "image[]=@annotation.png" \
  -F "image[]=@reference.png"
```

The order of images is determined by the client’s submission order. The annotation image is currently used as a visual reference input; GPT-mask-style pixel-level region locking is not guaranteed.

## Request Example

### Single Image Editing

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-pro",
    "prompt": "把这张商品图改成超宽横幅 KV，背景更简洁，保留主体结构",
    "image_input": [
      "https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20250925/fpakfo/image36.webp"
    ],
    "resolution": "4K",
    "aspect_ratio": "21:9",
    "output_format": "png"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/images/generations",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "nano-banana-pro",
        "prompt": "把这张商品图改成超宽横幅 KV，背景更简洁，保留主体结构",
        "image_input": [
            "https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20250925/fpakfo/image36.webp"
        ],
        "resolution": "4K",
        "aspect_ratio": "21:9",
        "output_format": "png"
    }
)

data = response.json()
print(data["data"][0]["url"])
```

</CodeGroup>

## Response Example

It is recommended to directly consume `data[].url`:

```json
{
  "created": 1774846705,
  "data": [
    {
      "url": "https://media.crazyrouter.com/task-artifacts/2026/03/30/sync-image/20260331073825672515332JyP6hAcs-1.png"
    }
  ]
}
```

If you need to get the final generated image result, just read `data[0].url`. Currently, Crazyrouter will archive upstream inline images as accessible URLs, then return them to the client.
