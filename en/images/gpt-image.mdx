# GPT Image

`gpt-image-2` can be called with a compatible path via the OpenAI Images API:

```text
POST /v1/images/generations
POST /v1/images/edits
```

<Warning>
  For image generation requests `gpt-image-2`, please primarily use the main relay line `https://api.crazyrouter.com/v1`. The full generation endpoint is `https://api.crazyrouter.com/v1/images/generations`. Account login, recharge, and console still use `https://crazyrouter.com`.
</Warning>

## Generate Image

### Request Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `model` | string | Yes | Fixed to `gpt-image-2` |
| `prompt` | string | Yes | Image description prompt |
| `n` | integer | No | Number to generate, default is `1`, range is `1-10` |
| `size` | string | No | `auto` or `Width x Height`. Width and height must be multiples of 16, each side no more than 3840, total pixels between 655360 and 8294400, and the long to short side ratio does not exceed 3:1. Common values: `1024x1024`, `1536x1024`, `1024x1536` |
| `quality` | string | No | `auto`, `low`, `medium`, `high`. Compatible with `hd`, the server will normalize to `high`; compatible with `standard`, the server will normalize to `auto` |
| `background` | string | No | `auto` or `opaque`. `gpt-image-2` does not support `transparent` |
| `output_format` | string | No | `png`, `jpeg`, `webp` |
| `output_compression` | integer | No | `0-100`, only available when `output_format` is `jpeg` or `webp` |
| `moderation` | string | No | `auto` or `low` |
| `stream` | boolean | No | Whether to use SSE streaming response |
| `partial_images` | integer | No | `0-3`, only available when `stream=true` is present |
| `user` | string | No | End-user identifier |

For compatibility with legacy DALL-E / OpenAI Images clients, `gpt-image-2` will also accept `response_format=url`, `response_format=b64_json`, `quality=standard`, and `style=vivid/natural`. Of these, `response_format` and `style` will not be forwarded to the upstream, `quality=standard` will be normalized to `auto`.

<Warning>
  `response_format` is just a compatibility field reserved by Crazyrouter for old clients, not an upstream parameter of `gpt-image-2`. For new integrations, please use `output_format="png"`, `"jpeg"`, or `"webp"` to control the image file format and, by default, read the `data[0].url` in the response. If a legacy client sends `response_format="b64_json"`, the server will try its best to retain the base64 response semantics.
</Warning>

Parameter combinations that will still be rejected include: `input_fidelity`, `background=transparent`, `output_format=png` combined with `output_compression`.

### Request Example

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只穿着宇航服的猫咪在月球上行走，背景是地球",
    "n": 1,
    "size": "1024x1024",
    "quality": "low",
    "output_format": "png"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.generate(
    model="gpt-image-2",
    prompt="一只穿着宇航服的猫咪在月球上行走，背景是地球",
    n=1,
    size="1024x1024",
    quality="low",
    output_format="png",
)

print(response.data[0].url)
```

</CodeGroup>

### Streaming Generation

`gpt-image-2` supports `stream=true`. If `partial_images` is included in the request, you must also enable `stream`, and its value range is `0-3`.

```bash cURL
curl -N -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一个蓝色极简验证图标，白色背景",
    "size": "1024x1024",
    "quality": "high",
    "stream": true,
    "partial_images": 2
  }'
```

<Note>
  Synchronous requests with `quality=high` or the compatible format `quality=hd` may take a long time. For image generation business, please prioritize `https://api.crazyrouter.com/v1`. For high-quality requests, it is recommended to use `stream=true`, or ensure that your client timeout exceeds 180 seconds.
</Note>

## Edit Image

```
POST /v1/images/edits
```

Edit based on existing images, supporting masked area editing, and also supports submitting multiple reference images for fusion, style transfer, or local composition.

### Request Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `model` | string | Yes | Fixed as `gpt-image-2` |
| `image` / `image[]` | file or file[] | Yes | Original image or reference image files (multipart); `gpt-image-2` supports up to `16` reference images |
| `prompt` | string | Yes | Edit description |
| `mask` | file | No | Mask image, with transparent area being the part to edit |
| `n` | integer | No | Number to generate, default is `1`, range is `1-10` |
| `size` | string | No | Same as generate interface |
| `quality` | string | No | `auto`, `low`, `medium`, `high`; `hd` will be normalized to `high` |
| `background` | string | No | `auto` or `opaque` |
| `output_format` | string | No | `png`, `jpeg`, `webp` |
| `output_compression` | integer | No | `0-100`, only available when `output_format` is `jpeg` or `webp` |
| `stream` | boolean | No | Whether to use SSE streaming response |
| `partial_images` | integer | No | `0-3`, only available when `stream=true` is present |

### Single Image Editing Example

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.edit(
    model="gpt-image-2",
    image=open("original.png", "rb"),
    mask=open("mask.png", "rb"),
    prompt="在天空中添加一道彩虹",
    n=1,
    size="1024x1024",
    quality="low",
)

print(response.data[0].url)
```

### Multi-Image Reference Editing Example

Multi-image editing requests must use `multipart/form-data`. It is recommended to use multiple `image[]` fields to send reference images; the server is also compatible with repeating the `image` field.

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/edits \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=gpt-image-2" \
  -F "prompt=把第一张图的人物与第二张图的背景融合成一张自然的宣传图" \
  -F "size=1024x1024" \
  -F "quality=low" \
  -F "n=1" \
  -F "image[]=@person.png" \
  -F "image[]=@background.png"
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/images/edits",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    data={
        "model": "gpt-image-2",
        "prompt": "把第一张图的人物与第二张图的背景融合成一张自然的宣传图",
        "size": "1024x1024",
        "quality": "low",
        "n": "1",
    },
    files=[
        ("image[]", ("person.png", open("person.png", "rb"), "image/png")),
        ("image[]", ("background.png", open("background.png", "rb"), "image/png")),
    ],
    timeout=240,
)

response.raise_for_status()
print(response.json()["data"][0]["url"])
```

</CodeGroup>

<Note>
  `gpt-image-2` multi-image reference supports up to 16 images. Multi-image requests will be preferentially routed to the official OpenAI carrying channel that supports multi-image references.
</Note>
