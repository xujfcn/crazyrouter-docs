# Nano Banana

```
POST /v1/images/generations
```

`nano-banana` is the public alias of `nano-banana`. On the client side, the OpenAI Images compatible protocol is used uniformly; Gemini / Vertex native handling, field conversion, and routing selection are all managed by Crazyrouter on the server side.

<Warning>
  Requests such as image generation, image editing, and multi-reference image tasks typically take longer. For production access, please give priority to the main hosting route `https://api.crazyrouter.com/v1`. The complete generation endpoint is `https://api.crazyrouter.com/v1/images/generations`. Account login, recharge, and the console still use `https://crazyrouter.com`.
</Warning>

## Model Names

| Recommended Model Name | Equivalent Underlying Model |
|------|------|
| `nano-banana` | `nano-banana` |

It is recommended to use `nano-banana` in client code. If your system is already directly coded with `nano-banana`, you can continue to call through the same `/v1/images/generations` entry point.

## Request Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `model` | string | yes | Recommend `nano-banana`; also compatible with `nano-banana` |
| `prompt` | string | yes | Generation or editing instruction |
| `image_input` | string or string[] | no | Reference image URL; if omitted, generates from text |
| `resolution` | string | no | `1K`, `2K`, `4K` |
| `aspect_ratio` | string | no | Such as `1:1`, `16:9`, `9:16`, `21:9`, `auto` |
| `output_format` | string | no | `png`, `jpeg` / `jpg` |
| `output_compression` | integer | no | `0-100`, used for JPEG compression quality |
| `n` | integer | no | Number to generate, default is `1` |

<Note>
  Do not pass Gemini native fields, such as `generationConfig`, `imageConfig`, `imageOutputOptions`, `image_output_options`, in client requests. These are upstream provider details; Crazyrouter will automatically convert from unified parameters.
</Note>

## Text-to-Image Example

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana",
    "prompt": "A clean banana icon on a white background, minimal product style",
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "png"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.generate(
    model="nano-banana",
    prompt="A clean banana icon on a white background, minimal product style",
    n=1,
    extra_body={
        "resolution": "1K",
        "aspect_ratio": "1:1",
        "output_format": "png",
    },
)

print(response.data[0].url or response.data[0].b64_json)
```

</CodeGroup>

## Reference Image Editing Example

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana",
    "prompt": "保持主体不变，把背景改成白色电商棚拍风格",
    "image_input": [
      "https://example.com/product.png"
    ],
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "jpeg",
    "output_compression": 85
  }'
```

## Response

Responses retain the OpenAI Images style. By default, `data[0].url` is prioritized; a few compatible channels may return `data[0].b64_json`.

```json
{
  "created": 1778990000,
  "data": [
    {
      "url": "https://media.crazyrouter.com/task-artifacts/2026/05/17/sync-image/request-id-1.png"
    }
  ]
}
```

## Common Errors

| Incorrect Usage | Correct Usage |
|------|------|
| Directly call `/v1beta/models/nano-banana:generateContent` | Switch to `POST /v1/images/generations` |
| Pass `image_output_options` in request | Use unified parameter `output_format`, `output_compression` |
| Only set base URL as `https://api.crazyrouter.com` and let the SDK assemble the OpenAI path | Use OpenAI SDK with `https://api.crazyrouter.com/v1` |
