# Nano Banana 2

```
POST /v1/images/generations
```

`nano-banana-2` is the public alias for `nano-banana-2`. On the user side, the OpenAI Images compatible protocol is used uniformly; on the server side, unified parameters such as `output_format`, `output_compression`, `resolution`, `aspect_ratio` are converted to native Gemini / Vertex requests.

<Warning>
  `nano-banana-2` belongs to a long-running image model. For production integration, please prioritize using the main receiving line `https://api.crazyrouter.com/v1`, and the full generation endpoint is `https://api.crazyrouter.com/v1/images/generations`. Account login, recharge, and control panel still use `https://crazyrouter.com`.
</Warning>

## Model Names

| Recommended Name | Equivalent Base Model |
|------|------|
| `nano-banana-2` | `nano-banana-2` |

It is recommended to use `nano-banana-2` in your client code. If your system has already directly written `nano-banana-2`, you can continue to use the same `/v1/images/generations` entry.

## Request Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `model` | string | yes | Recommend `nano-banana-2`; also compatible with `nano-banana-2` |
| `prompt` | string | yes | Generation or editing instructions |
| `image_input` | string or string[] | no | Reference image URL; omit for text-to-image |
| `resolution` | string | no | `1K`, `2K`, `4K` |
| `aspect_ratio` | string | no | Like `1:1`, `16:9`, `9:16`, `21:9`, `auto` |
| `output_format` | string | no | `png`, `jpeg` / `jpg` |
| `output_compression` | integer | no | `0-100`, used for JPEG compression quality |
| `n` | integer | no | Number of generations, default `1` |

<Note>
  Do not pass Gemini native fields in client requests, such as `generationConfig`, `imageConfig`, `imageOutputOptions`, `image_output_options`. These fields are automatically generated by Crazyrouter on the server side according to the current upstream protocol.
</Note>

## Text-to-Image Example

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-2",
    "prompt": "A clean ecommerce hero shot of a red apple on a white background",
    "resolution": "1K",
    "aspect_ratio": "16:9",
    "output_format": "jpeg",
    "output_compression": 85
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.generate(
    model="nano-banana-2",
    prompt="A clean ecommerce hero shot of a red apple on a white background",
    n=1,
    extra_body={
        "resolution": "1K",
        "aspect_ratio": "16:9",
        "output_format": "jpeg",
        "output_compression": 85,
    },
)

print(response.data[0].url or response.data[0].b64_json)
```

</CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \

    "output_format": "png"
  }'
```

## Response

The response maintains the OpenAI Images style. By default, `data[0].url` is preferred for reading; certain compatible channels may return `data[0].b64_json`.

```json
{
  "created": 1778990000,
  "data": [
    {
      "url": "https://media.crazyrouter.com/task-artifacts/2026/05/17/sync-image/request-id-1.png"
    }
  ]
}
```

## Migration Instructions

If old code directly calls:

```text
POST /v1beta/models/nano-banana-2:generateContent
```

It is recommended to migrate to:

```text
POST https://api.crazyrouter.com/v1/images/generations
```

And change Gemini native parameters to unified parameters:

| Gemini Native Concept | Crazyrouter Unified Parameter |
|------|------|
| `imageConfig.aspectRatio` | `aspect_ratio` |
| `imageConfig.imageSize` | `resolution` |
| `imageOutputOptions.mimeType` | `output_format` |
| `imageOutputOptions.compressionQuality` | `output_compression` |
