# 모델 공식 요금 방식

본 문서는 상위 제조사 공식 과금 기준만을 설명하며, Crazyrouter의 실제 판매가와는 다릅니다.

- 상위 공식 기준: 제조사 자체의 `input`, `output`, `cached input`, `tool call`, `search grounding`, `prompt caching` 등 요금 체계
- Crazyrouter 기준: 사이트 자체의 판매가, 배율, 할인, 채널 차이 및 결제 방식

<Note>
  본 페이지는 `2026-04-27`로 조회한 제조사 공식 문서에서 정리하였습니다. 제조사는 가격을 수정할 수 있으며, 미리보기 모델, 긴 컨텍스트, 검색 툴 및 캐시 규칙을 변경할 수 있습니다. 서비스 이용 전 반드시 공식 링크에서 한 번 더 확인해 주세요.
</Note>

## 공식 단가 샘플 표

아래 예시는 각 제조사에서 가장 일반적이고, 사업 예산과 직접적으로 연결되는 한 등급만을 기재합니다.

- Anthropic: 표준 API 가격, `Fast mode`, `US-only inference` 배수 및 Batch 할인 미포함
- OpenAI: `Standard` 가격, Batch, Priority, Regional Processing 추가요금 미포함
- Gemini: `Standard` 가격, 기본적으로 텍스트 / 이미지 / 비디오 입력 기준, `Gemini 3*`에는 `<= 200K prompt` 등급 적용
- xAI: 사이트 내 라우트명에 공개된 단독 고정 단가가 없을 경우 "별도 단가 없음"으로 명시
- Z.AI: 공식 `Text Models` 가격 적용
- MiniMax: 메인표는 `Pay as You Go` 기준, 구독제는 `Token Plan` 별도 표기

<Note>
  특별 표기가 없는 한, 아래 표 금액 단위는 기본적으로 `USD / 1M tokens` 입니다.
</Note>

## Anthropic

Anthropic 계열 모델의 공식 과금 방식은 단순한 `input / output` 두 칸이 아니라 다음과 같이 분리됩니다:

- `Base Input Tokens`
- `5m Cache Writes`
- `1h Cache Writes`
- `Cache Hits & Refreshes`
- `Output Tokens`

또한 공통 규칙 두 가지:

- `Batch API` 입력과 출력은 보통 표준가 `50% 할인` 적용
- Prompt caching의 공개 배수 규칙: `5분간 캐싱 쓰기 = 입력의 1.25배`, `1시간 캐싱 쓰기 = 입력의 2배`, `캐싱 읽기 = 입력의 0.1배`

| 사이트 모델명 | 공식 대응 | 공식 과금 방식 | 특이사항 |
| --- | --- | --- | --- |
| `claude-opus-4-8` | Anthropic `claude-opus-4-8` | `base input / 5m cache write / 1h cache write / cache hit / output` 기준 요금 | Anthropic 공식적으로 `Sonnet 4.6`이 `1M context`을 지원한다고 명확히 밝혔으며, 해당 긴 컨텍스트는 표준 단가로 부과, 추가요금 없음 |
| `claude-opus-4-8` | Anthropic `claude-opus-4-8` | `base input / 5m cache write / 1h cache write / cache hit / output` 기준 요금 | `Opus 4.6`도 `1M context` 표준 요금 지원; 또한 공식적으로 `Fast mode` 별도 제공, 가격은 표준가 `6x` |
| `claude-opus-4-8` | Anthropic `claude-opus-4-8` | `base input / 5m cache write / 1h cache write / cache hit / output` 기준 요금 | `Opus 4.7`이 현재 Anthropic 공식 가격표의 독립 모델; `US-only inference` 활성화 시, 공식 문서에 `1.1x` 배수 기재 |

## OpenAI

OpenAI 이 텍스트 모델 그룹의 공식 공개 기준은 가장 통일되어 있으며, 핵심 내용은 다음과 같습니다:

- `Input`
- `Cached input`
- `Output`

추가 규칙은 대체로 다음과 같습니다:

- `Responses API` 자체는 별도의 추가 요금 없이, 선택한 모델의 토큰 단가로 요금이 부과됩니다.
- `Web search`, 컨테이너/코드 실행, Computer Use 등 도구는 도구별 요금제로, 순수 토큰 단가에 포함되지 않습니다.
- `Batch API` 입력과 출력은 일반적으로 표준가 `50% 할인`를 따릅니다.

## Google Gemini

Gemini의 공식 과금 방식은 앞의 두 회사와 가장 큰 차별점을 보입니다. 보통 표준가 하나가 아니라 동시에 여러 가격을 제시합니다:

- `Standard`
- `Batch`
- `Flex`
- `Priority`

그리고 다음 항목을 별도로 명시합니다:

- `Input`
- `Output (including thinking tokens)`
- `Context caching price`
- `Context caching storage`
- `Grounding with Google Search`
- `Grounding with Google Maps`

## xAI Grok

xAI의 공식 규정의 핵심은 “thinking 모델 별도 가격표 유무”가 아니라, 토큰과 도구 사용을 분리합니다:

- `Prompt tokens`
- `Cached prompt tokens`
- `Completion tokens`
- `Reasoning tokens`

xAI 공식 설명 추가:

- `Reasoning tokens`는 `completion token price`에 따라 요금이 부과됩니다.
- `Web Search`, `X Search`, `Code Execution`, `Collections Search` 등의 서버측 도구들은 `1000회 호출마다`로 별도 과금됩니다.
- `Batch API`에 대해 토큰 관련 요금은 일반적으로 `50% 할인`입니다.

| 사이트내 모델명 | 공식 대응 | 공식 과금 방식 | 특별 설명 |
| --- | --- | --- | --- |
| `grok-4.1-fast` | 사이트내 reasoning 라우트, 공식적으로는 Grok 4.1의 `Thinking` 구성과 대응 | 공식 기준은 `prompt / cached prompt / completion / reasoning` 4종 토큰과 필요 시 발생하는 도구 호출 요금 | 현재 xAI 공개 API 가격 표시는 `grok-4-1-fast-reasoning`와 같은 SKU에 집중하고 있습니다. 따라서 여기서 보다 정확한 이해는 “xAI reasoning 모델의 공식 요금 구조로 정산”이지, 사이트내 명칭을 별도 공식 SKU로 간주하는 것이 아닙니다. |
| `grok-4.1` | 사이트내 Grok 4.1 메인 라우트, 공식적으로는 Grok 4.1의 비사고 구성에 더 가깝습니다 | 공식 기준 역시 `prompt / cached prompt / completion`이며, 검색·코드 실행·첨부 검색 등 도구 사용 시 tool fee는 별도 | xAI의 현재 공개 API 페이지는 이미 `grok-4.1-fast` 및 `grok-4-1-fast-*`를 더 강조합니다. 따라서 예산 산정 시 xAI의 현재 공개된 토큰 및 도구 요금 규정을 우선적으로 확인해야 합니다. |

## Z.AI / GLM

Z.AI의 `GLM-5` 공식 기준은 OpenAI와 유사하지만, 캐시 스토리지 요금 항목이 추가로 있습니다:

- `Input`
- `Cached Input`
- `Cached Input Storage`
- `Output`

또한 내장 도구(예: `Web Search`)는 사용 횟수에 따라 별도 과금됩니다.

| 사이트내 모델명 | 공식 대응 | 공식 과금 방식 | 특별 설명 |
| --- | --- | --- | --- |
| `glm-5` | Z.AI `GLM-5` | `input / cached input / cached input storage / output`로 과금 | 공식 내장 `Web Search`을(를) 활성화하면 `per use`에 추가 요금이 부과됩니다. 이는 토큰 단가만 보는 것과 다릅니다. |

공식 링크:

- Z.AI 가격 정책: [docs.z.ai/guides/overview/pricing](https://docs.z.ai/guides/overview/pricing)
- GLM-5 개요: [docs.z.ai/guides/llm/glm-5](https://docs.z.ai/guides/llm/glm-5)

## MiniMax

MiniMax 모델은 공식적으로 두 가지 판매 방식을 먼저 구분해야 합니다:

- `Pay as You Go`
- `Token Plan`

그 중:

- `Pay as You Go`는 표준 API 종량제 과금
- `Token Plan`는 구독제이며, `M2.7`가 `5시간 롤링 윈도우의 요청 할당량`로 산정되어 토큰 단가만으로 결제하지 않습니다.

| 사이트내 모델명 | 공식 대응 | 공식 과금 방식 | 특별 설명 |
| --- | --- | --- | --- |
| `MiniMax-M2.7` | 사이트내 `MiniMax-M2.7`에 대응 | `Pay as You Go`를 선택하면 `input / output / prompt caching read / prompt caching write`로 과금, `Token Plan`를 선택하면 `requests / 5hrs` 구독 한도로 이용 | 이 페이지 중 가장 특이한 업체입니다. 생산 예산 책정시 `Pay as You Go`를 우선 확인하고, 개발자가 대규모 코드 작업을 할 때는 `Token Plan`가 더 경제적인지 추가로 확인하십시오. |

공식 링크:

- MiniMax 가격 총괄: [platform.minimax.io/docs/pricing/overview](https://platform.minimax.io/docs/pricing/overview)
- MiniMax 종량제: [platform.minimax.io/docs/guides/pricing-paygo](https://platform.minimax.io/docs/guides/pricing-paygo)

## 결론

빠르게 “공식적으로 실제 어떤 기준으로 요금을 매기는가”만 판단하고 싶다면 다음과 같이 정리될 수 있습니다:

- Anthropic: `base input + cache write/read + output`
- OpenAI: `input + cached input + output`, 도구 따로 계산
- Gemini: `다중 처리 모드 + 입력/출력 + 캐싱 + 검색/지도 연동`
- xAI: `prompt/cached/completion/reasoning`, 서버측 도구 따로 계산
- Z.AI: `input + cached input + cached storage + output`
- MiniMax: `사용량 기준 토큰` 또는 `구독 할당량` 두 체계 동시 운영

<Warning>
  본 페이지는 “상위 공식 가격 책정 방식”을 설명합니다. Crazyrouter의 실제 판매 가격이 아닙니다. 실제 충전, 요금 차감, 배수, 할인을 포함한 구체 요금은 Crazyrouter 사이트 내 가격 안내, 콘솔, 그리고 `/api/pricing`의 반환값을 참고하십시오.
</Warning>
