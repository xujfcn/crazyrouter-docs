# Gemini 이미지 이해

```
POST /v1beta/models/{model}:generateContent
```

`2026-04-08` 기준, Crazyrouter 자체 및 로컬 `4000` 포트 재테스트 결과:

- `gemini-3.1-pro`는 `inlineData`를 통해 안정적으로 이미지를 읽고 텍스트 설명을 반환할 수 있습니다
- 원격 이미지 URL 형태인 `fileData.fileUri`는 여러 채널에서 가져오기 실패, 업스트림 응답 이상 등의 문제가 발생한 바 있습니다
- 따라서 이미지 이해는 현재 문서에서 `inlineData`를 메인 권장 방식으로 사용합니다

---

## 검증된 최소 요청

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "inlineData": {
              "mimeType": "image/png",
              "data": "BASE64_PNG_DATA"
            }
          },
          {
            "text": "이 이미지에 무엇이 있는지 한국어로 한 문장으로 설명해 주세요."
          }
        ]
      }
    ]
  }'
```

프로덕션 환경의 실제 반환 핵심 형태:

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "이 이미지는 다양한 선명한 색상이 부드럽게 전환되는 그라데이션 효과를 보여줍니다."
          }
        ]
      }
    }
  ]
}
```

## 요청 요점

- 이미지 이해에는 `inlineData` 사용을 우선합니다
- `mimeType`은 실제 이미지 형식과 일치해야 합니다. 예: `image/png`, `image/jpeg`
- `data`에는 Base64 내용만 넣고, `data:image/...;base64,` 접두사는 포함하지 마세요
- 원격 이미지 URL만 있는 경우, 현재는 이를 Gemini 이미지 이해의 메인 경로로 사용하지 마세요
