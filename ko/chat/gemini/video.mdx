# Gemini 비디오 이해

```text
POST /v1beta/models/{model}:generateContent
```

`2026-04-08` 기준, Crazyrouter 자체 사이트 및 로컬 `4000` 포트 재테스트 결과에 따르면:

- `gemini-3.1-pro`는 `video/mp4`를 읽을 수 있습니다
- 현재 안정적으로 동작하는 주요 경로는 `fileData.fileUri`입니다
- 비디오 파일은 Gemini 업스트림에서 접근 가능한 공용 URL이어야 합니다

---

## 검증된 최소 요청

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "fileData": {
              "mimeType": "video/mp4",
              "fileUri": "https://example.com/demo.mp4"
            }
          },
          {
            "text": "한 문장으로 한국어로 답변해 주세요: 영상 속 주체는 무엇이고, 어떻게 움직이며, 카메라는 고정되어 있는지."
          }
        ]
      }
    ],
    "generationConfig": {
      "maxOutputTokens": 512
    }
  }'
```

프로덕션 환경에서 동일한 유형의 성공 응답이 갖는 주요 형태:

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "영상 속 주체는 빨간 공이며, 왼쪽에서 오른쪽으로 굴러가고 카메라는 고정되어 있습니다."
          }
        ]
      }
    }
  ]
}
```

## 요청 요점

- 비디오 이해의 현재 주요 권장 작성법은 `fileData.fileUri`입니다
- `mimeType`은 실제 파일에 맞게 작성합니다. 예: `video/mp4`
- `fileUri`는 반드시 Gemini 업스트림에서 접근 가능해야 합니다
- 파일이 사설 네트워크에 있거나, 인증이 필요하거나, URL에 직접 연결할 수 없는 경우 현재 실패하기 쉽습니다

<Note>
  이미지 이해는 `inlineData`를 우선 사용하십시오. 이미지의 성공 작성법을 그대로 비디오에 적용하지 마십시오. 이미지에 대해서는 [Gemini 이미지 이해](/ko/chat/gemini/vision)를 참고하십시오.
</Note>
