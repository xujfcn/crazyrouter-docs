# 모델 목록 조회

```
GET /v1/models
```

현재 API Key에서 사용 가능한 모델 목록을 반환합니다.

이 문서 페이지에는 `2026-04-14`에 Crazyrouter 프로덕션 환경에서 재검증된 동작만 기재되어 있습니다.

## 인증

```text
Authorization: Bearer YOUR_API_KEY
```

## 요청 예시

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

models = client.models.list()

for model in models.data:
    print(model.id)
```

```javascript Node.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.crazyrouter.com/v1",
});

const models = await client.models.list();

for (const model of models.data) {
  console.log(model.id);
}
```

</CodeGroup>

## 현재 프로덕션 검증 결론

`2026-04-14`의 프로덕션 재검증에서:

- 엔드포인트는 `200`을 반환
- 최상위 `success`는 `true`
- 최상위 `object`는 `list`
- 현재 반환되는 모델 수는 `605`개
- 다음 모델들이 반환 목록에 포함된 것으로 확인됨:
  - `gpt-5.5`
  - `claude-opus-4-8`
  - `claude-opus-4-8`
  - `gemini-3.1-pro`

<Note>
  모델 총 수와 구체적인 목록은 채널 구성, 토큰 권한, 플랫폼 업데이트에 따라 변동될 수 있으므로, 문서의 예시를 고정된 전체 목록으로 간주해서는 안 됩니다.
</Note>

## 주요 확인 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `success` | boolean | 요청 성공 여부 |
| `id` | string | API 호출 시 전달하는 모델 식별자 |
| `object` | string | 고정값 `model` |
| `created` | integer | 타임스탬프 |
| `owned_by` | string | 모델이 속한 조직 또는 출처 식별자 |

## 가격 정보

공개 가격 정보가 추가로 필요하다면 [Pricing 페이지](/pricing)를 기준으로 하십시오. 프로그램 측에서 현재 토큰에 노출되는 모델을 확인할 때는 계속 이 페이지의 `GET /v1/models`를 사용하십시오.

<Note>
  `GET /v1/models`가 반환하는 `supported_endpoint_types`는 현재 모델이 지원하는 인터페이스 스타일만을 나타냅니다. 그중 `openai`는 `POST /v1/chat/completions`에, `anthropic`은 `POST /v1/messages`에 대응하며, `openai-response`만이 `POST /v1/responses`에 대응합니다. Claude는 현재 `openai` + `anthropic`을 공개 지원하며 `openai-response`는 지원하지 않습니다.
</Note>
