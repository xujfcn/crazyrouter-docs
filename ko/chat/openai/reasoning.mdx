# 추론 모델

이 페이지는 `2026-03-22`에서 Crazyrouter 프로덕션에 대해 재검증된 추론 동작만 문서화합니다.

OpenAI 호환 통합을 위한 현재 안내는 다음과 같습니다:

- 더 강력한 추론만 필요하고 최종 답변만 원하는 경우, `reasoning_effort`와 함께 Chat Completions를 사용하세요
- 안정적이고 검사 가능한 추론 출력을 원한다면 Responses API를 선호하고 [GPT-5 사고 모드](/ko/chat/responses/gpt5-thinking)를 확인하세요

## 검증된 조합

| 루트 | 모델 | 요청 매개변수 | 현재 프로덕션 동작 |
|-------|-------|-------------------|-----------------------------|
| Chat Completions | `gpt-5.5` | `reasoning_effort` | 요청이 성공해서 최종 답변을 반환합니다 |
| Responses | `gpt-5.5` | `reasoning.effort` / `reasoning.summary` | `output`은 `reasoning`과 `message` 항목을 포함합니다 |

## Chat Completions: `reasoning_effort`

다음 요청 형태가 현재 프로덕션에서 동작합니다:

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Which is larger, 9.11 or 9.9? Explain briefly."
      }
    ],
    "reasoning_effort": "high",
    "max_tokens": 120
  }'
```

사용 가능한 `reasoning_effort` 값:

| 값 | 의미 |
|-------|---------|
| `low` | 단순한 작업에서 더 빠른 응답 |
| `medium` | 균형 잡힌 기본 스타일 설정 |
| `high` | 복잡한 작업에서 더 많은 추론 |

### 현재 응답 동작

`2026-03-22` 프로덕션 재검증에서:

- 요청이 성공했습니다
- `message.content`에서 최종 답변이 반환되었습니다
- `message.reasoning_content`은 신뢰할 수 있는 사용 가능한 내용을 항상 포함하지는 않았습니다

따라서 더 강력한 추론만 원하는 경우, `reasoning_effort`와 함께 Chat Completions는 여전히 사용할 수 있습니다. 검사 가능한 추론 요약 필드가 필요하다면, Chat Completions를 기본 경로로 사용하지 마세요.

## 검사 가능한 추론 출력이 필요한 경우

더 신뢰할 수 있는 프로덕션 경로는 Responses API입니다:

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Which is larger, 9.11 or 9.9? Explain briefly.",
    "reasoning": {
      "effort": "high",
      "summary": "detailed"
    }
  }'
```

검증된 `output.type` 값:

```json
["reasoning", "message"]
```

구체적인 응답 구조, 요약 필드, 스트리밍 이벤트 이름은 다음을 참조하세요:

- [GPT-5 사고 모드](/ko/chat/responses/gpt5-thinking)
- [AI 사고 필드](/ko/reference/thinking)

## 현재 추천

- 추론 요약을 기록하거나 표시해야 하는 신규 빌드는 Responses API를 사용하세요
- 최종 답변만 중요하게 생각하는 기존 Chat Completions 통합에는 `reasoning_effort`가 여전히 유효한 경로입니다
- 모든 OpenAI 호환 추론 모델이 `reasoning_content`을 신뢰성 있게 노출한다고 가정하지 마세요

<Warning>
  추론 요청은 보통 지연 시간과 토큰 사용량을 모두 증가시킵니다. 높은 `reasoning_effort`는 일반적으로 더 높은 비용을 초래합니다.
</Warning>
