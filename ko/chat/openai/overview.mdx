# 챗 컴플리션 오브젝트

`/v1/chat/completions`는 비스트리밍 요청에 대해 `chat.completion`를, 스트리밍 요청에 대해서는 `chat.completion.chunk`를 반환합니다.

이 페이지는 오늘날 Crazyrouter에서 가장 안정적이고 널리 사용 가능한 OpenAI 호환 응답 구조에 초점을 맞춥니다.

## 비스트리밍 오브젝트

최소 프로덕션 요청:

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Explain what a REST API is in one sentence."
      }
    ],
    "max_tokens": 64
  }'
```

일반적인 프로덕션 응답 골격:

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "created": 1774177466,
  "model": "gpt-5.5",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "...",
        "reasoning_content": null,
        "tool_calls": null
      },
      "finish_reason": "stop"
    }
  ]
}
```

### 읽는 방법

- `message.content`는 최종 텍스트 답변입니다
- `message.tool_calls`는 모델이 도구 실행을 요청할 때만 나타납니다
- `message.reasoning_content`는 일부 모델이나 경로에서 나타날 수 있지만, 현재 보장된 필드로 간주해서는 안 됩니다

---

## 스트리밍 오브젝트

스트리밍 요청의 경우, 서버는 `chat.completion.chunk` SSE 이벤트를 반환합니다:

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion.chunk",
  "created": 1774177466,
  "model": "gpt-5.5",
  "choices": [
    {
      "index": 0,
      "delta": {
        "role": "assistant",
        "content": "..."
      },
      "finish_reason": null
    }
  ]
}
```

일반적인 SSE 형태:

```text
data: {"object":"chat.completion.chunk",...}
data: {"choices":[{"delta":{"content":"..."}}],...}
data: [DONE]
```

---

## 주로 신경 쓸 필드

| 필드 | 의미 |
|-------|---------|
| `object` | 비스트리밍의 경우 `chat.completion`, 스트리밍의 경우 `chat.completion.chunk` |
| `model` | 응답에 사용된 실제 모델 |
| `choices[].message.content` | 최종 비스트리밍 텍스트 |
| `choices[].message.tool_calls` | 비스트리밍 도구 요청 |
| `choices[].delta.content` | 스트리밍 텍스트 델타 |
| `choices[].finish_reason` | `stop`, `length`, `tool_calls` 같은 중단 사유 |

<Note>
  상류(Upstream) 모델에서 추가 필드를 전달할 수 있습니다. 클라이언트 코드는 모든 모델이 동일한 확장 필드를 제공한다고 가정하기보다는, 우선 안정적인 공통 필드에 의존하는 것이 좋습니다.
</Note>
