# 채팅 이미지 생성

```
POST /v1/chat/completions
```

2026년 3월 23일 기준, Crazyrouter 프로덕션 체크 결과:

- `gpt-4o`은 `200`를 반환하지만, `message.content`는 표준 멀티파트 이미지 콘텐츠가 아니라 일반 텍스트임
- `gpt-image-2` 역시 `200`를 반환하지만, 현재 응답 형식은 여전히 파라미터 블록, ID, 미리보기 링크가 포함된 텍스트 또는 마크다운으로, 표준 OpenAI `image_url` 멀티파트 구조와 다름
- 안정적이고 기계 판독 가능한 이미지 출력이 필요하다면 현재 권장 경로는 [`/v1/images/generations`](/ko/images/gpt-image) 및 `gpt-image-2`임. Grok 이미지 모델의 경우 [`Grok Image Models`](/ko/images/grok) 참조
- 기준 이미지 편집 및 다중 이미지 입력이 필요하다면 Nano Banana 계열을 안정적인 `/v1/images/generations` 시작점으로 계속 사용하지 마세요. [`Nano Banana 2`](/ko/images/nano-banana-2)에 문서화된 Gemini 네이티브 경로로 시작하시고, [`Nano Banana`](/ko/images/nano-banana)는 현재 제한 테스트 중임

<Warning>
  현재 Crazyrouter 채팅 이미지 응답을 표준 OpenAI `content: [{type: "image_url", ...}]` 형태로 파싱하지 마세요.
</Warning>

---

## 현재 재현 가능한 채팅 동작

아래 요청이 프로덕션의 `gpt-image-2`에 전달되어 `200`를 반환함:

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "messages": [
      {
        "role": "user",
        "content": "Generate an image of a red square on a white background."
      }
    ],
    "max_tokens": 512
  }'
```

관찰된 `message.content`는 대략 다음과 같은 형태의 문자열이었음:

```text
{
  "prompt": "Generate an image of a red square on a white background.",
  "ratio": "1:1",
  "n": 1
}

ID: ...
Data Preview: https://...
```

즉, 현재 채팅 경로는 표준화된 멀티파트 이미지 메시지 객체라기보다 텍스트로 래핑된 이미지 태스크 출력처럼 동작함

## 안정 경로: Images API

프로그래밍 방식 이미지 가져오기에는 다음을 사용하세요:

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A red square on a white background",
    "size": "1024x1024",
    "quality": "low",
    "output_format": "png"
  }'
```

현재 `gpt-image-2` 안정 경로는 기본 이미지 라우트인 `https://api.crazyrouter.com/v1`를 사용함. 응답에는 일반적으로 다음이 포함됨:

- `data[0].url`

`gpt-image-2`는 하위 호환성 필드로 `response_format="url"`와 `response_format="b64_json"`를 허용하지만, 새로운 연동은 이미지 파일 포맷을 선택하기 위해 `output_format="png"`, `"jpeg"` 또는 `"webp"`를 사용해야 함

즉, 안정적인 자동화 경로는 여전히 이미지 API이며, 채팅-이미지 호환 경로가 아님

<Note>
  수동 테스트만 필요하다면, `gpt-image-2` 채팅 경로로 관찰 용도로는 유효함. 백엔드 자동화, 저장, 후처리가 필요하면 [`GPT Image docs`](/ko/images/gpt-image) 또는 [`Grok Image Models`](/ko/images/grok)를 사용하세요. 작업이 기준 이미지 편집이나 다중 이미지 입력에 의존한다면 [`Nano Banana 2`](/ko/images/nano-banana-2)에 설명된 Gemini 네이티브 경로를 시작점으로 삼으세요. Nano Banana 계열 `/v1/images/generations`를 안정적 권장 경로로 계속 이용하지 마세요.
</Note>
