# 웹 검색

이 페이지는 Crazyrouter 프로덕션에서 `2026-03-22`에 대해 재검증된 OpenAI 스타일 웹 검색 동작만 문서화합니다.

현재 주요 경로는 다음과 같습니다:

- `gpt-5.5`
- `POST /v1/responses`
- `tools: [{ "type": "web_search_preview" }]`

## 현재 결론

오늘의 프로덕션 재확인에서:

- Responses API를 통한 `gpt-5.5`가 안정적으로 `web_search_call`를 반환했습니다.
- 이전의 Chat Completions 프로브에서 `tools: [{ "type": "web_search" }]`는 `200`를 반환했지만, 안정적이고 검증 가능한 검색 트리거 신호를 제공하지 않아, 주로 문서화된 패턴으로 사용되지 않습니다.

---

## 검증된 요청

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Use web search to find one current technology headline published recently.",
    "tools": [
      {
        "type": "web_search_preview"
      }
    ]
  }'
```

검증된 `output.type` 값:

```json
["web_search_call", "message"]
```

이는 검색 단계와 최종 답변이 따로 반환됨을 보여줍니다.

---

## Python 예제

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.responses.create(
    model="gpt-5.5",
    input="Use web search to find one current technology headline published recently.",
    tools=[
        {"type": "web_search_preview"}
    ]
)

print(response.output_text)
```

---

## 실제로 검색이 실행되었는지 확인하는 방법

`response.output`를 직접 검사하세요:

```python Python
for item in response.output:
    print(item.type)
```

만약 다음을 본다면:

```text
web_search_call
message
```

모델이 먼저 검색하고 두 번째로 답변한 것입니다.

---

## 주요 방식으로 권장되지 않는 이전 패턴

이번 프로덕션 재확인에서는 이전 Chat Completions 형태도 테스트되었습니다:

```json
{
  "tools": [
    {
      "type": "web_search"
    }
  ]
}
```

결과:

- 요청이 `200`를 반환함
- 그러나 안정적이고 검증 가능한 검색 트리거 마커는 확인되지 않았음

따라서 Crazyrouter 문서에서는 현재 OpenAI 스타일 웹 검색이 Responses API를 통해 우선적으로 문서화되어야 합니다.
