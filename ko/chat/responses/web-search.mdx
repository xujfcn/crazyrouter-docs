# 응답 웹 검색

```
POST /v1/responses
```

2026년 3월 23일 기준, Crazyrouter 프로덕션은 아래 항목을 활용하여 `gpt-5.5`를 Responses API에서 검증하였습니다:

- `tools: [{ "type": "web_search_preview" }]`
- `output` 시퀀스에서 `web_search_call` 다음에 `message`

<Note>
  Claude는 현재 `POST /v1/responses`를 지원하지 않습니다. Claude 웹 검색을 사용하려면 `POST /v1/chat/completions` 또는 네이티브 Claude 경로를 이용하세요.
</Note>

---

## 최소 요청

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Find one AI news item from March 2026.",
    "tools": [
      {
        "type": "web_search_preview"
      }
    ]
  }'
```

프로덕션에서 관찰된 응답 형태:

```json
{
  "output": [
    {
      "type": "web_search_call"
    },
    {
      "type": "message"
    }
  ]
}
```

---

## 현재 검증 규칙

모델이 실제로 웹 검색을 실행했는지 확인해야 한다면, 현재 가장 안전한 점검 방법은 다음과 같습니다:

- `web_search_call`가 `output`에 나타나는지 여부
- 최종 답변이 여전히 `message`인지 여부

<Warning>
  이 페이지는 더 이상 오래된 예시를 보관하지 않으며, 현재의 주요 경로가 아닌 재검증되지 않은 검색 파라미터는 문서화하지 않습니다.
</Warning>
