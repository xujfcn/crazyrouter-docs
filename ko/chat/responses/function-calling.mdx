# 응답 함수 호출

```
POST /v1/responses
```

2026년 3월 23일 기준으로 Crazyrouter 프로덕션에서 `gpt-5.5`가 Responses API에서 신뢰성 있게 `function_call`를 반환함이 확인되었습니다.

<Note>
  Claude는 현재 `POST /v1/responses`를 지원하지 않습니다. Claude의 도구 호출이 필요하다면 `POST /v1/messages` 또는 `POST /v1/chat/completions`를 사용하세요.
</Note>

---

## 1단계: 모델이 함수 호출을 생성하도록 하십시오

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "What is the weather in Beijing? Use the tool.",
    "tools": [
      {
        "type": "function",
        "name": "get_weather",
        "description": "Get weather info for a city",
        "parameters": {
          "type": "object",
          "properties": {
            "city": {"type": "string"}
          },
          "required": ["city"],
          "additionalProperties": false
        }
      }
    ]
  }'
```

프로덕션에서 관찰된 응답 형태:

```json
{
  "output": [
    {
      "type": "function_call",
      "name": "get_weather",
      "arguments": "{\"city\":\"Beijing\"}"
    }
  ]
}
```

---

## 2단계: 도구 결과 반환하기

`function_call`을(를) 받으면, 실제 도구 결과를 `function_call_output`로 다시 전송하십시오:

```json
{
  "model": "gpt-5.5",
  "input": [
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Beijing\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "{\"temperature\":22,\"condition\":\"sunny\"}"
    }
  ],
  "tools": [
    {
      "type": "function",
      "name": "get_weather",
      "description": "Get weather info for a city",
      "parameters": {
        "type": "object",
        "properties": {
          "city": {"type": "string"}
        },
        "required": ["city"],
        "additionalProperties": false
      }
    }
  ]
}
```

<Note>
  이 페이지에서는 프로덕션에서 재현된 `function_call` 경로만 유지합니다. 더 복잡한 다중 도구 체인 또는 스트리밍 인자 델타의 경우, 의존하기 전에 같은 날에 다시 검증하시기 바랍니다.
</Note>
