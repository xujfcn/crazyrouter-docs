# Responses API 개요

Responses API는 현재 Crazyrouter에서 최신 GPT 기능을 사용할 수 있는 주요 경로 중 하나입니다.

이 페이지는 `2026-03-22`에서 프로덕션과 재검증된 결론만을 문서화합니다.

<Note>
  현재 프로덕션에서 검증된 범위에서는 Claude가 `POST /v1/messages`와 `POST /v1/chat/completions`만 지원하며, `POST /v1/responses`는 지원하지 않습니다. Responses 페이지는 GPT 우선 가이드로 취급하세요.
</Note>

## 현재 프레이밍

- 검토 가능한 추론 결과가 필요하다면 `/v1/responses`를 선호하세요
- OpenAI 스타일의 웹 검색이 필요하다면 `/v1/responses`를 선호하세요
- 일반적인 채팅만 필요하거나 기존 통합을 유지하고 싶다면 `/v1/chat/completions`도 괜찮습니다

## Responses API vs Chat Completions API

| 차원 | Responses API | Chat Completions API |
|-----------|---------------|----------------------|
| 엔드포인트 | `/v1/responses` | `/v1/chat/completions` |
| 입력 형태 | `input` | `messages` |
| 출력 형태 | `output[]` 아이템 목록 | `choices[].message` |
| GPT 추론 | 검증된 `reasoning` 아이템 | `reasoning_effort` 작동하지만 `reasoning_content`는 안정적이지 않음 |
| OpenAI 스타일 웹 검색 | 검증된 `web_search_preview` 경로 | 이전 `web_search` 형태가 이번 라운드에서 안정적으로 검증된 트리거를 생성하지 않음 |
| 스트리밍 | 더 다양한 이벤트 타입 | 전통적인 델타 SSE |

## 최소한의 유용한 예시

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.responses.create(
    model="gpt-5.5",
    input="Explain what a REST API is in one sentence."
)

print(response.output_text)
```

현재 프로덕션 재검증에서 이러한 최소 요청이 반환한 결과:

```json
{
  "object": "response",
  "output": [
    {
      "type": "message"
    }
  ]
}
```

## Responses를 선호해야 할 때

- `gpt-5.5` 추론 요약이 필요할 때
- 모델이 실제로 `web_search_call`를 트리거했는지 검증해야 할 때
- 더 풍부한 SSE 이벤트가 필요할 때

## Chat Completions를 유지해야 할 때

- 이미 안정적인 Chat Completions 통합이 있을 때
- 최종 답변만 중요하고 `reasoning` 아이템은 신경 쓰지 않을 때
- Claude, Gemini 또는 기타 OpenAI 호환 모델을 통합할 때

<Note>
  두 API를 같은 프로젝트에서 동시에 사용할 수 있습니다. 실제로는 전체를 마이그레이션 하기보다는 최신 기능이 필요한 요청만 `/v1/responses`로 옮기는 패턴이 더 나은 경우가 많습니다.
</Note>
