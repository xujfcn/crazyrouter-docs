# GPT-5 사고 모드

이 페이지는 `2026-03-22`에서 Crazyrouter 프로덕션과 재검증된 GPT 추론 동작만 문서화합니다.

현재 주요 예시는 다음을 사용합니다:

- `gpt-5.5`
- `POST /v1/responses`

<Note>
  Claude는 현재 `POST /v1/responses`를 지원하지 않습니다. Claude를 통합하신다면, 이 페이지의 요청 형태 대신 `POST /v1/messages` 또는 `POST /v1/chat/completions`를 사용하세요.
</Note>

```

```

## 검증된 응답 형태

검증된 `output.type` 값:

```json
["reasoning", "message"]
```

일반적인 `reasoning` 항목 형태:

```json
{
  "id": "rs_xxx",
  "type": "reasoning",
  "encrypted_content": "...",
  "summary": [
    {
      "type": "summary_text",
      "text": "..."
    }
  ]
}
```

최종 답변은 `message` 항목을 통해 반환됩니다:

```json
{
  "type": "message",
  "content": [
    {
      "type": "output_text",
      "text": "..."
    }
  ]
}
```

---

## `reasoning` 파라미터

| 필드 | 타입 | 설명 |
|-------|------|-------------|
| `effort` | string | 추론 강도. 검증된 값은 `low`, `medium`, 그리고 `high` 포함 |
| `summary` | string | 요약 세분성. `concise` 및 `detailed`이 재검증됨 |

### 실용 규칙

- 더 강한 추론만 원한다면 `effort`을 보내세요
- 검사 가능한 추론 요약이 필요하다면 `effort`와 `summary` 모두를 보내세요

현재 재검증에서는:

- `effort`만 사용하면 `reasoning` 항목이 존재하지만 `summary`는 빈 배열일 수 있습니다
- `summary: "detailed"` 사용 시, `summary_text`가 신뢰성 있게 반환됨

## 사고 요약 추출

```python Python
response = client.responses.create(
    model="gpt-5.5",
    input="Design a high-concurrency message queue architecture.",
    reasoning={
        "effort": "high",
        "summary": "detailed"
    }
)

for item in response.output:
    if item.type == "reasoning":
        for part in item.summary:
            if part.type == "summary_text":
                print("Thinking summary:", part.text)
    elif item.type == "message":
        for content in item.content:
            if content.type == "output_text":
                print("Final answer:", content.text)
```

## 사고 스트리밍

다음 Responses SSE 이벤트 명칭이 프로덕션에서 재검증되었습니다:

- `response.reasoning_summary_part.added`
- `response.reasoning_summary_text.delta`
- `response.reasoning_summary_text.done`
- `response.output_text.delta`
- `response.output_text.done`
- `response.completed`

예시:

```python Python
stream = client.responses.create(
    model="gpt-5.5",
    input="Explain briefly why 9.9 is larger than 9.11.",
    reasoning={
        "effort": "high",
        "summary": "detailed"
    },
    stream=True
)

for event in stream:
    if event.type == "response.reasoning_summary_text.delta":
        print(f"[Thinking summary] {event.delta}", end="")
    elif event.type == "response.output_text.delta":
        print(event.delta, end="")
```

## 현재 권장 사항

- 표시 가능한 추론 필드가 필요하다면 Responses API에서 `gpt-5.5`를 선호하세요
- `gpt-5.5` Chat Completions `reasoning_content`를 현재 기본 계약으로 간주하지 마세요
- 결과 답변만 중요하다면, `reasoning_effort`와 함께하는 Chat Completions도 여전히 괜찮습니다

<Warning>
  추론 모드는 지연 시간과 토큰 사용량을 모두 증가시킵니다. 더 높은 `effort`는 일반적으로 비용이 더 듭니다.
</Warning>
