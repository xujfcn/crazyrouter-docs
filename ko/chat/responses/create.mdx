# 응답 생성

```
POST /v1/responses
```

2026년 3월 23일 기준으로 Crazyrouter 프로덕션에서 다음이 검증되었습니다:

- `gpt-5.5`는 `object: "response"`를 반환합니다
- 기본 텍스트 요청은 현재 `output` 타입의 `message` 항목을 반환합니다
- 스트리밍 요청은 지속적으로 `response.created`, `response.in_progress`, `response.output_item.added`, `response.content_part.added`, 그리고 `response.output_text.delta`를 노출합니다

<Note>
  Claude는 현재 `POST /v1/responses`를 지원하지 않습니다. 대신 Claude에는 `POST /v1/messages` 또는 `POST /v1/chat/completions`를 사용하세요.
</Note>

---

## 기본 요청

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Explain what an API is in one sentence."
  }'
```

프로덕션에서 관찰된 응답 형태:

```json
{
  "object": "response",
  "model": "gpt-5.5",
  "output": [
    {
      "type": "message"
    }
  ]
}
```

## 스트리밍 요청

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Say hello in one sentence.",
    "stream": true
  }'
```

2026-03-23에 실시한 프로덕션 스트리밍 프로브에서 다음 오프닝 이벤트 시퀀스를 관찰했습니다:

```text
event: response.created
event: response.in_progress
event: response.output_item.added
event: response.content_part.added
event: response.output_text.delta
```

따라서 가장 안전한 현 소비자 전략은 다음과 같습니다:

1. `response.output_text.delta`에서 텍스트를 누적합니다
2. `response.completed` 또는 스트림 종료를 완료 신호로 처리합니다
