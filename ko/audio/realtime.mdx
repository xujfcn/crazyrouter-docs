# GPT Realtime

GPT Realtime은 현재 Crazyrouter의 공개 권장 사례로 제공되지 않습니다. 이미 중단되었거나 공개적으로 지원되지 않는 모델 예시를 사용자가 복사하는 것을 방지하기 위해, 이 페이지는 중국어 내비게이션에서 숨겨졌으며 WebSocket 요청 예시도 제거되었습니다.

현재 공개된 오디오 사용 사례는 다음을 사용하세요.

- [음성을 텍스트로 변환](/ko/audio/stt): `whisper-1`
- [텍스트를 음성으로 변환](/ko/audio/tts): `tts-1`

<Warning>
  Realtime 관련 모델이 다시 공개되는지 여부는 사이트 내 `GET /v1/models`, 콘솔에서 선택 가능한 모델, 그리고 프로덕션 인터페이스의 실제 반환 결과를 기준으로 판단해 주세요.
</Warning>
