## AI 도구용 프롬프트

```text
먼저 https://docs.crazyrouter.com/llms.txt 를 읽고 관련 페이지를 판단하세요.
전체 컨텍스트가 필요하면 https://docs.crazyrouter.com/llms-full.txt 를 읽으세요.
모델 이름, 가격, 과금 방식은 https://crazyrouter.com/pricing 을 기준으로 해야 합니다.
현재 API Key로 실제 사용 가능한 모델을 확인해야 한다면 GET https://api.crazyrouter.com/v1/models 를 호출하세요.
OpenAI 호환 클라이언트를 연동할 때는 base_url로 https://api.crazyrouter.com/v1 을 사용하세요.
Claude Code / Anthropic 네이티브 클라이언트를 연동할 때는 루트 도메인 https://api.crazyrouter.com 을 사용하고 /v1 을 추가하지 마세요.
동아시아 지역은 https://cn.crazyrouter.com 을 우선 사용하며, OpenAI 호환 클라이언트는 https://cn.crazyrouter.com/v1 을 사용합니다.
계정 및 관리 인터페이스(예: `/api/user/self`, `/api/token/*`, `/api/log/*`)는 반드시 https://crazyrouter.com 을 사용해야 하며, API 전용 도메인으로 보내면 404 api_only_endpoint가 반환됩니다.
```

## 기준 원칙

- `llms.txt`는 전체 모델 목록이 아닙니다.
- 모델, 가격, 과금 방식은 [Pricing 페이지](https://crazyrouter.com/pricing)를 기준으로 합니다.
- 현재 Token으로 호출할 수 있는 모델은 `GET https://api.crazyrouter.com/v1/models`의 반환 결과를 기준으로 합니다.
- 동아시아 지역은 `https://cn.crazyrouter.com`을 우선 사용하며, OpenAI 호환 클라이언트는 `https://cn.crazyrouter.com/v1`을 사용합니다.
- 호출 코드를 생성할 때는 구체적인 모델 문서에서 이미 검증된 엔드포인트 예시를 우선 사용하세요.
