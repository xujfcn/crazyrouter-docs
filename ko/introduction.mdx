> 업데이트: 2026-06-16

<Note>
  API 연동 경로: 기본 국제 진입점은 `https://api.crazyrouter.com`이며, 동아시아 지역은 `https://cn.crazyrouter.com`을 우선 사용하는 것을 권장합니다. OpenAI 호환 클라이언트는 일반적으로 루트 도메인 뒤에 `/v1`을 붙이며, Claude Code / Anthropic 네이티브 클라이언트는 루트 도메인을 사용하고 `/v1`을 붙이지 않습니다. 자세한 내용은 [API 엔드포인트](/ko/api-endpoint)를 참고하세요.
</Note>

Crazyrouter는 통합 AI 모델 API 게이트웨이입니다. API Key 하나로 텍스트, 이미지, 비디오, 오디오, 임베딩, Rerank 및 서드파티 도구 통합에 필요한 모델 기능을 호출할 수 있습니다.
