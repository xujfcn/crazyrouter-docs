## 개요

Claude Dev는 Claude 스타일의 코드 해설, 리팩터링 제안, 그리고 Crazyrouter를 통한 다중 턴 협업에 적합한 VS Code AI 코딩 확장입니다. 공개 문서를 위해서는, Crazyrouter 통합 스택 전체와 보다 일관적이고 문제 해결이 쉬운 OpenAI 호환 경로를 우선적으로 사용하는 것이 좋습니다.

<Warning>
이 페이지의 `https://api.crazyrouter.com/v1` URL은 Claude Dev의 `OpenAI Compatible` 공급자에만 적용됩니다. Claude Code의 `ANTHROPIC_BASE_URL`에는 복사해 넣지 마세요. Claude Code는 루트 도메인인 `https://api.crazyrouter.com`을(를) 사용해야 합니다.
</Warning>

## 권장 설정

<Steps>
  <Step title="확장 프로그램 설치">
    VS Code 확장 마켓플레이스에서 `Claude Dev`을(를) 검색해 설치하세요.
  </Step>
  <Step title="설정 열기">
    설정에 들어가려면 사이드바에서 Claude Dev 아이콘을 클릭하세요.
  </Step>
  <Step title="제공자 선택">
    API 공급자는 `OpenAI Compatible`을(를) 권장합니다.
  </Step>
  <Step title="구성 입력">
    - **Base URL**: `https://api.crazyrouter.com/v1`
    - **API Key**: `sk-xxx`
    - **Model**: `claude-opus-4-8`
  </Step>
</Steps>

기본 국제 API 엔트리의 경우 Claude Dev의 `OpenAI Compatible` Base URL을 `https://api.crazyrouter.com/v1`으로 설정하세요.

## 권장 모델

| 사용 시나리오 | 모델 |
|----------|-------|
| 일상적인 코딩 | `claude-opus-4-8` |
| 복잡한 추론 및 기획 | `claude-opus-4-8` |

<Note>
  `claude-opus-4-8` 및 `claude-opus-4-8`은(는) 이 문서 세트의 최신 검증된 Claude 모델 안내와 일치합니다. VS Code의 가장 최소 1차 검증을 위해서는 `claude-opus-4-8`에서 시작하세요.
</Note>
