> 업데이트: 2026-06-06

Claude Code는 현재 Crazyrouter에 우선적으로 연동할 가치가 있는 터미널 코딩 도구 중 하나입니다. Anthropic Messages API를 직접 사용하며, 코드 읽기, 수정, 리팩터링, 명령 실행, 툴 호출, 긴 컨텍스트 리포지토리 분석에 적합합니다.

## 개요

환경 변수를 통해 Claude Code는 Anthropic 요청을 Crazyrouter로 직접 전송할 수 있습니다.

- 권장 프로토콜: `Anthropic Messages API`
- Base URL: `https://api.crazyrouter.com`
- 기본 국제 API Base URL: `https://api.crazyrouter.com`
- 인증 변수: `ANTHROPIC_API_KEY`
- 권장 기본 모델: `claude-opus-4-8`

<Tip>
Claude Code는 Anthropic 요청 경로를 자체적으로 완성하므로, Base URL은 루트 도메인인 `https://api.crazyrouter.com` 또는 `https://api.crazyrouter.com`으로 작성해야 합니다. `/v1`이나 `/v1/messages`를 직접 붙이지 마세요.
</Tip>

- 툴 호출, 긴 컨텍스트, 터미널 코딩 워크플로를 안정적으로 사용하려는 분

## 사용 프로토콜

권장 프로토콜: `Anthropic Messages API`

Claude Code가 Crazyrouter와 연동할 때는 다음을 사용하세요.

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

기본 국제 API 엔드포인트도 마찬가지로 루트 주소만 입력합니다.

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

다음과 같이 작성하지 마세요.

- `https://api.crazyrouter.com/v1`
- `https://api.crazyrouter.com/v1/messages`
- `https://api.crazyrouter.com/v1/complete`
- `https://api.crazyrouter.com/v1`
- `https://api.crazyrouter.com/v1/messages`

## 운영체제별 전체 설치 경로

### Windows 권장 경로

Windows에서 Claude Code의 가장 안정적인 경로는 `Git` + `Node.js` + `npm 전역 설치 Claude Code` + `PowerShell`로 환경 변수를 기록하는 것입니다.

권장 순서:

1. Git 설치
2. Node.js LTS 설치
3. npm으로 Claude Code 설치
4. PowerShell로 임시 변수 작성
5. PowerShell로 사용자 수준 영구 변수 작성

권장 검증 명령:

```powershell
git --version
node -v
npm -v
claude --version
where.exe git
where.exe node
where.exe claude
```

`claude --version`에서 명령을 찾을 수 없다면 PowerShell을 닫고 다시 열어 재시도하세요.

### macOS 권장 경로

macOS에서 Claude Code를 가장 편하게 다루는 경로는 보통 `Xcode Command Line Tools` + `Homebrew` + `Git` + `Node.js` + `npm 전역 설치 Claude Code` + `~/.zshrc`로 환경 변수를 영구화하는 방식입니다.

권장 순서:

1. Xcode Command Line Tools 설치
2. Homebrew 설치 (아직 없다면)
3. Git, Node.js 설치
4. npm으로 Claude Code 설치
5. `~/.zshrc`에 기록
6. 새 터미널을 열어 명령 경로 검증

권장 검증 명령:

```bash
git --version
node -v
npm -v
claude --version
which git
which node
which claude
```

### 여기서 API 경로를 직접 작성하지 않는 이유

Claude Code는 Anthropic 네이티브 프로토콜을 사용합니다. 사이트 루트 주소만 알려주면 됩니다.

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

기본 국제 API 엔드포인트도 마찬가지로 루트 주소만 입력합니다.

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

OpenAI 호환 클라이언트처럼 `/v1`, `/v1/messages` 또는 구체적인 API 경로를 직접 붙이지 마세요.

스크립트로 Claude Code를 자동 설치하고 Crazyrouter 관련 환경 변수를 기록하고 싶다면 [crazyrouter-claude-code](https://github.com/xujfcn/crazyrouter-claude-code)를 확인하세요. 이 리포지토리는 Windows, macOS, Linux용 원클릭 설정 스크립트를 제공합니다. 이 문서는 각 설정 항목을 검토할 수 있도록 전체 수동 설정 절차를 계속 제공합니다.

  </Step>

## Claude Code에서 비-Claude 모델 사용하기

네이티브 Claude 계열 외에도 Crazyrouter는 일부 국산 모델의 Anthropic Messages 네이티브 연동을 제공합니다. 아래 목록에는 **2026-05-15 실제 프로덕션 클라이언트 재검증**을 통과한 모델만 남겨두었으며, 재검증되지 않은 과거 모델은 섞어 넣지 않았습니다.

### 실측 사용 가능 모델 목록

| 모델 ID | 제공사 | `Reply only OK` | `agent.md` 읽기 | 현재 결론 | 비고 |
|---------|--------|------------------|------------------|----------|------|
| `deepseek-v4-pro` | DeepSeek | 통과 | 통과 | Claude Code P0 사용 가능 | 범용 코딩에 적합; Codex 쪽에서는 현재도 Responses 사용을 권장하지 않음 |
| `MiniMax-M2.7` | MiniMax | 통과, 단 `<think>` 포함 | 통과, 단 `<think>` 포함 | 프로토콜 사용 가능 | 엄격한 출력 작업에서는 경험이 떨어짐 |
| `kimi-k2.5` | Moonshot Kimi | 통과 | 통과 | Claude Code P0 사용 가능 | 현재 가장 안정적인 국산 모델 후보 중 하나 |
| `kimi-k2.6` | Moonshot Kimi | 통과 | 통과 | Claude Code P0 사용 가능 | `kimi-k2.5`와 동급 |
| `glm-5.1` | GLM | 통과 | 통과 | Claude Code P0 사용 가능 | Claude Code에서만; Codex 네이티브 Responses는 현재 통과하지 못함 |

> 위 테스트는 Claude Code 실제 클라이언트를 기반으로, `https://api.crazyrouter.com` 루트 도메인을 통해 네이티브 `POST /v1/messages` 링크로 검증했습니다.

<Note>
이 표의 기준은 "현재 재검증되어 사용 가능"이며, "이론상 Anthropic 프로토콜로 전환 가능한 모든 서드파티 모델 전체 목록"이 아닙니다. 특정 모델이 여기에 없다면, 현재 중국어 문서에서 해당 모델을 Claude Code의 검증된 추천 항목으로 등록하지 않았다는 의미입니다.
</Note>

### 모델 전환 방법

Claude Code는 `ANTHROPIC_MODEL` 환경 변수 또는 세션 내 `/model` 명령으로 모델을 선택합니다. 모델명을 위 표의 아무 값으로나 교체하면 됩니다.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    export ANTHROPIC_BASE_URL=https://api.crazyrouter.com
    export ANTHROPIC_API_KEY=sk-xxx

    # 임시로 Kimi K2.5로 전환
    export ANTHROPIC_MODEL=kimi-k2.5
    claude

    # 또는 임시로 MiniMax로 전환
    ANTHROPIC_MODEL=MiniMax-M2.7 claude
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    $env:ANTHROPIC_BASE_URL = "https://api.crazyrouter.com"
    $env:ANTHROPIC_API_KEY  = "sk-xxx"

    $env:ANTHROPIC_MODEL = "kimi-k2.5"
    claude

    # 또는 임시로 전환
    $env:ANTHROPIC_MODEL = "MiniMax-M2.7"; claude
    ```
  </Tab>
</Tabs>

Claude Code 실행 후 세션 명령으로도 전환할 수 있습니다.

```text
/model kimi-k2.5
/model MiniMax-M2.7
```

### 사용 권장사항 및 알려진 차이점

- **우선 순서**: Claude Code에서 국산 모델을 우선 사용하고 싶다면, 현재는 `kimi-k2.5`, `kimi-k2.6`부터 시작한 후 `deepseek-v4-pro`를 고려하는 것을 권장합니다. Qwen 계열은 먼저 `/v1/models`로 사용 가능한 모델 ID를 확인한 후 별도로 검증하세요.
- **MiniMax의 알려진 차이점**: `MiniMax-M2.7`은 프로토콜상 사용 가능하지만, 사고 과정을 일반 텍스트로 그대로 출력하며 앞뒤에 `<think>...</think>` 태그가 붙습니다. "한 문장만 출력"과 같은 엄격한 작업에는 우선 선택을 권장하지 않습니다.
- **DeepSeek / GLM의 경계**: `deepseek-v4-pro`와 `glm-5.1`은 Claude Code에서 사용 가능하지만, 이것이 Codex의 네이티브 Responses 설정에도 그대로 적합하다는 의미는 아닙니다. 이 두 링크는 서로 다른 프로토콜이므로 호환성 결론을 혼용하지 마세요.
- **토큰 화이트리스트**: Claude Code 전용 토큰에 모델 화이트리스트가 설정되어 있다면, 사용하려는 국산 모델도 함께 추가해야 합니다. 그렇지 않으면 `403 model not allowed`가 반환됩니다.
- **실제 클라이언트 검증 권장**: `Reply only OK`를 한 차례 실행한 후, "파일 하나를 읽고 제목만 반환"하는 작업을 실행하는 것이 단순 API 테스트보다 Claude Code의 실제 사용 시나리오에 더 가깝습니다.

### 명령 한 줄로 특정 모델의 사용 가능 여부 빠르게 확인

```bash
curl -sS https://api.crazyrouter.com/v1/messages \
  -H "Authorization: Bearer $ANTHROPIC_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k2.5",
    "max_tokens": 32,
    "messages": [{"role":"user","content":"reply OK"}]
  }'
```

200이 반환되고 `content[].text`가 비어 있지 않다면 Claude Code에서 해당 모델을 정상적으로 사용할 수 있음을 의미합니다.

## 자주 발생하는 오류와 해결 방법

| 현상 | 일반적인 원인 | 해결 방법 |
|------|----------|----------|
| `claude: command not found` | Claude Code 설치가 실패했거나 npm 전역 경로가 PATH에 없음 | 재설치 후 `npm bin -g` 디렉터리가 PATH에 있는지 확인 |
| `node` 버전이 너무 낮음 | 로컬 Node 버전이 요구사항보다 낮음 | Node.js 18+로 업그레이드 후 Claude Code 재설치 |
| 401 unauthorized | `ANTHROPIC_API_KEY`가 유효하지 않거나 만료되었거나 잘못 복사됨 | 토큰을 재발급하고 환경 변수를 다시 설정 |
| 403 / model not allowed | 토큰이 현재 Claude 모델을 허용하지 않음 | Crazyrouter 토큰 설정에서 필요한 모델을 허용 |
| 404 | Base URL이 `/v1`, `/v1/messages` 등 잘못된 경로로 작성됨 | `https://api.crazyrouter.com` 또는 `https://api.crazyrouter.com`으로 수정 |
| 로그 경로에 `/v1/v1/messages`, `/v1/v1/models` 또는 `/v1/messages/v1/messages`가 나타남 | Claude Code의 Base URL에 `/v1`이나 전체 엔드포인트가 잘못 포함되어, 클라이언트가 경로를 한 번 더 추가함 | `ANTHROPIC_BASE_URL`을 루트 도메인으로 변경하고 어떤 경로도 붙이지 마세요 |
| Claude Code 실행 후에도 여전히 이전 설정을 사용함 | 새 환경 변수가 다시 로드되지 않음 | 새 터미널을 열거나 `source ~/.bashrc` / `source ~/.zshrc`를 다시 실행 |
| Git 변경 사항이 너무 지저분함 | 리포지토리 스냅샷을 먼저 만들지 않고 AI로 코드를 수정하기 시작함 | 초기 스냅샷을 먼저 커밋한 후 라운드별로 수정 |
| 비용이 예상을 초과함 | 긴 컨텍스트 + 다회차 툴 호출 + 장시간 세션 | 세션을 줄이고 작업을 분할하며 Claude Code에 별도 예산을 설정 |

## FAQ

### Claude Code에서 Base URL은 무엇으로 작성해야 하나요?

루트 도메인으로 작성: `https://api.crazyrouter.com`

기본 국제 API 엔드포인트도 루트 도메인으로 작성: `https://api.crazyrouter.com`

### 왜 여기서는 `/v1`을 작성할 수 없나요?

Claude Code가 Anthropic Messages API 경로를 자체적으로 추가하기 때문입니다. 사이트 루트 주소만 제공하면 됩니다.

### Windows에서는 어떤 방식을 사용해야 하나요?

주로 명령줄로 개발한다면 PowerShell이나 WSL2를 우선 사용하세요. 어느 방식이든 Git, Node.js, Claude Code 자체가 모두 올바르게 설치되어 있는지 먼저 확인하세요.

### Windows에서는 PowerShell과 Git Bash 중 무엇을 권장하나요?

처음 설정할 때는 PowerShell을 우선 사용하세요. 환경 변수 작성, `where.exe` 검증, 사용자 수준 변수 영구화가 모두 더 직관적입니다.

### 처음에 왜 Git 스냅샷을 먼저 만들어야 하나요?

Claude Code가 파일을 수정하고 명령을 실행하기 때문입니다. 먼저 스냅샷을 만들어두면 문제가 생겼을 때 더 쉽게 검토하고 되돌릴 수 있습니다.

### 처음 권장하는 모델은 무엇인가요?

먼저 `claude-opus-4-8`을 사용하세요. 대체로 가장 안정적인 기준 모델입니다.
