## 개요

ChatGPT on WeChat은 흔히 사용되는 WeChat 봇 프로젝트로, Crazyrouter의 모델 능력을 개인 채팅과 그룹 채팅 시나리오에 연동할 수 있습니다. 연동 시에는 기본 OpenAI 호환 설정 방식을 계속 사용하는 것을 권장하며, 먼저 실제로 테스트된 모델로 최소 응답 흐름을 완주하세요.

## 권장 초기 설정

- `open_ai_api_base`: `https://api.crazyrouter.com/v1`
- 첫 검증 모델: `gpt-5.5`
- 초기에는 소수의 모델만 열어 트러블슈팅 범위를 좁게 유지

## 설정 방법

### 설정 파일 수정

`config.json` 편집:

```json
{
  "open_ai_api_key": "sk-xxx",
  "open_ai_api_base": "https://api.crazyrouter.com/v1",
  "model": "gpt-5.5",
  "proxy": "",
  "single_chat_prefix": [""],
  "single_chat_reply_prefix": "",
  "group_chat_prefix": ["@bot"],
  "group_name_white_list": ["AI 대화방"]
}
```

### 환경 변수 방식

```bash
export OPEN_AI_API_KEY=sk-xxx
export OPEN_AI_API_BASE=https://api.crazyrouter.com/v1
export MODEL=gpt-5.5
```

### Docker 배포

```yaml
services:
  chatgpt-on-wechat:
    image: zhayujie/chatgpt-on-wechat
    environment:
      - OPEN_AI_API_KEY=sk-xxx
      - OPEN_AI_API_BASE=https://api.crazyrouter.com/v1
      - MODEL=gpt-5.5
    volumes:
      - ./config.json:/app/config.json
```

## 권장 모델

| 시나리오 | 모델 | 설명 |
|------|------|------|
| 초기 흐름 검증 | `gpt-5.5` | 2026년 3월 23일 프로덕션 환경에서 실측으로 성공이 확인되어, OpenAI 호환 흐름을 먼저 확인하기에 가장 적합 |
| 고품질 장문 응답 | `claude-opus-4-8` | 복잡한 설명, 요약과 장문에 더 적합 |
| Gemini 보조 옵션 | `gemini-3.1-pro` | 두 번째 공급사 호환성 검증 경로를 보완하는 데 적합 |

## 권장 검증 순서

1. 먼저 토큰 하나만 설정
2. 먼저 모델 하나 `gpt-5.5`만 설정
3. 먼저 개인 채팅에서 `Reply only OK` 전송
4. Crazyrouter 백엔드 로그에 해당 요청이 있는지 확인
5. 이후 그룹 채팅, 더 많은 접두사 규칙과 기타 모델을 점차 개방

<Warning>
  WeChat 봇 프로젝트는 WeChat 사용 규범을 준수해야 하며, 메시지를 지나치게 자주 보내 계정이 제한되는 것을 피해야 합니다.
</Warning>
