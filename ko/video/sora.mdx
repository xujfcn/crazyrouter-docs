# Sora (임시 숨김)

Sora 관련 공개 사용 예시는 현재 Crazyrouter의 신규 연동 권장 경로로 더 이상 표시되지 않습니다. 사용자가 이미 종료되었거나 공개되지 않은 모델을 그대로 복사하는 것을 방지하기 위해, 이 페이지는 내비게이션에서 제거되었으며 더 이상 요청 예시를 유지하지 않습니다.

신규 비디오 생성 연동은 다음을 우선 참고하세요.

- [Veo 3.1](/ko/video/veo): `veo-3.1-fast` 또는 `veo-3.1-quality` 사용
- [통합 비디오 API](/ko/video/unified): `POST /v1/video/create` 사용
- [OpenAI 비디오 호환 형식](/ko/video/openai-video): `POST /v1/videos` 사용

<Note>
  이후 Sora가 공개 모델 목록에 다시 포함되면, 모델 ID, 요청 예시, 검증 기록을 다시 보완할 예정입니다.
</Note>
