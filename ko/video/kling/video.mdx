# Kling 비디오 생성

Crazyrouter가 현재 고객에게 공개한 Kling 비디오 계열은 공식 프로토콜에 따라 두 개의 모델 계열로 나뉩니다.

| 라우팅 계열 | 제출 경로 | 조회 경로 | 현재 공개 모델 |
|------|------|------|------|
| 표준 Kling 비디오 | `POST /kling/v1/videos/text2video` `POST /kling/v1/videos/image2video` `POST /kling/v1/videos/multi-image2video` | `GET /kling/v1/videos/text2video/{task_id}` `GET /kling/v1/videos/image2video/{task_id}` `GET /kling/v1/videos/multi-image2video/{task_id}` | `kling-v2-5-turbo` `kling-v2-6` `kling-v3` |
| Kling Omni 비디오 | `POST /kling/v1/videos/omni-video` | `GET /kling/v1/videos/omni-video/{task_id}` | `kling-v3` `kling-v3` |

모든 작업은 비동기입니다. 조회 결과는 우선적으로 Crazyrouter 아카이브 주소(예: `https://media.crazyrouter.com/...`)를 반환합니다.

## 첫 5개 모델과 기능

| 모델 | 라우팅 계열 | 현재 고객 대상 기능 | 검증 상태 | 과금 기준 요약 |
|------|------|------|------|------|
| `kling-v2-5-turbo` | 표준 Kling 비디오 | 텍스트-투-비디오, 이미지-투-비디오, 첫/끝 프레임, 참조 이미지-투-비디오 | `Beta` | `mode + duration` |
| `kling-v2-6` | 표준 Kling 비디오 | 텍스트-투-비디오, 이미지-투-비디오, 첫/끝 프레임, 참조 이미지-투-비디오, 사운드, voice control, 동작 제어 | `Beta` | `mode + duration + sound + voice control` |
| `kling-v3` | 표준 Kling 비디오 | 텍스트-투-비디오, 이미지-투-비디오, 첫/끝 프레임, 참조 이미지-투-비디오, 동작 제어, 표준 라우팅 요소 참조 | `Beta` | `mode + duration + sound`; 동작 제어는 별도 과금 버킷 |
| `kling-v3` | Kling Omni 비디오 | Omni 비디오, 이미지/요소/비디오/사운드 참조 | `Beta` | `mode + duration + sound + video input` |

<Note>
  고객 대상 기능과 필드 기준은 공식 Kling 프로토콜을 우선으로 합니다. Crazyrouter는 서드파티 채널을 내부 provider로만 취급하며 서드파티 프로토콜을 고객에게 노출하지 않습니다. 가격은 실시간 Pricing 페이지를 기준으로 합니다.
</Note>

<Note>
  현재 Kling 첫 5개 모델은 공식 필드 및 pricing 매트릭스와 정렬이 완료되었지만, 기능 상태는 일괄적으로 `Beta`로 표시되어 있습니다. 출시 후 일정 기간이 지나면 스크립트 통계와 프로덕션 로그를 결합해 항목별로 정식 전환할 예정입니다.
</Note>

## 표준 Kling 비디오

```
POST /kling/v1/videos/text2video
POST /kling/v1/videos/image2video
POST /kling/v1/videos/multi-image2video
```

### 현재 권장 모델

- `kling-v2-5-turbo`
- `kling-v2-6`
- `kling-v3`

### 텍스트-투-비디오 파라미터

| 파라미터 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `model_name` | string | 예 | 표준 Kling 비디오 모델 |
| `prompt` | string | 예 | 비디오 설명 프롬프트 |
| `image_urls` | array[string] | 아니오 | 공식 첫 프레임 / 첫·끝 프레임 입력. `@element_name`을 참조할 때는 명시적으로 전달하는 것을 권장 |
| `negative_prompt` | string | 아니오 | 네거티브 프롬프트 |
| `duration` | string/integer | 아니오 | 일반적으로 `5` 또는 `10` |
| `aspect_ratio` | string | 아니오 | 예: `16:9`, `9:16`, `1:1` |
| `mode` | string | 아니오 | 생성 모드, 예: `std`, `pro` |
| `sound` | string / boolean | 아니오 | 공식 값 `on` / `off` 사용을 권장 |
| `multi_shots` | boolean | 아니오 | 공식 멀티샷 스위치; 별칭 `multi_shot`과 호환 |
| `multi_prompt` | array | 조건부 필수 | 멀티샷 설명, 작업당 최대 5개 세그먼트 |
| `kling_elements` | array | 아니오 | `kling-v3` 표준 라우팅 요소 참조, 프롬프트 내 `@element_name`과 함께 사용 |
| `cfg_scale` | number | 아니오 | 가이드 강도 |
| `camera_control` | object | 아니오 | 카메라 제어 파라미터 |
| `callback_url` | string | 아니오 | 콜백 주소 |
| `external_task_id` | string | 아니오 | 비즈니스 측 커스텀 작업 ID |

### 이미지-투-비디오 예시

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/videos/image2video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kling-v3",
    "prompt": "사진 속 인물이 미소를 지으며 천천히 고개를 돌립니다",
    "image": "https://example.com/portrait.jpg",
    "duration": "5",
    "mode": "std"
  }'
```

공식 우선 필드는 `image_urls`입니다. `image + image_tail`도 계속 사용할 수 있으며, 첫 프레임 / 끝 프레임 호환 별칭으로 처리됩니다. 비디오 작업은 비동기이므로 [작업 조회](/ko/video/kling/query)를 통해 최종 결과를 가져오시기 바랍니다.

### 로컬 참조 이미지 업로드 후 비디오 생성

참조 이미지가 로컬에 있는 경우, 먼저 임시 이미지 호스팅을 사용하여 공용 URL을 가져온 다음 Kling에 전달하십시오. 임시 이미지는 기본적으로 72시간 동안 저장되며, 보관 기간 내에는 별도로 일별 과금되지 않습니다.

```bash cURL
UPLOAD_RESPONSE=$(curl -sS -X POST https://api.crazyrouter.com/v1/files/uploads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@./portrait.png" \
  -F "purpose=model_input")

IMAGE_URL=$(python -c "import json,sys; print(json.load(sys.stdin)['url'])" <<< "$UPLOAD_RESPONSE")

curl -X POST https://api.crazyrouter.com/kling/v1/videos/image2video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d "{
    \"model_name\": \"kling-v3\",
    \"prompt\": \"사진 속 인물이 천천히 고개를 돌리며 미소 짓고, 카메라가 살짝 줌인하며, 영화 같은 조명\",
    \"image_urls\": [\"$IMAGE_URL\"],
    \"duration\": \"5\",
    \"mode\": \"std\"
  }"
```

### 참조 이미지-투-비디오 파라미터

```
POST /kling/v1/videos/multi-image2video
```

이 경로는 표준 Kling 공식 `Reference` 기능에 대응합니다. `image2video`와 다르게 `image` / `image_tail`을 사용하지 않고 공식 `image_list`를 참조 소재 입력으로 사용합니다.

| 파라미터 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `model_name` | string | 예 | 표준 Kling 비디오 모델 |
| `prompt` | string | 예 | 참조 이미지 일관성 및 동작 설명 |
| `image_list` | array | 예 | 공식 참조 이미지 목록 |
| `negative_prompt` | string | 아니오 | 네거티브 프롬프트 |
| `duration` | string/integer | 아니오 | 일반적으로 `5` 또는 `10` |
| `aspect_ratio` | string | 아니오 | 출력 비율 |
| `mode` | string | 아니오 | 생성 모드 |
| `sound` | string / boolean | 아니오 | 공식 값 `on` / `off` 사용을 권장 |
| `multi_shots` | boolean | 아니오 | 공식 멀티샷 스위치; 별칭 `multi_shot`과 호환 |
| `multi_prompt` | array | 조건부 필수 | 멀티샷 설명 |
| `cfg_scale` | number | 아니오 | 가이드 강도 |
| `camera_control` | object | 아니오 | 카메라 제어 파라미터 |
| `callback_url` | string | 아니오 | 콜백 주소 |
| `external_task_id` | string | 아니오 | 비즈니스 측 커스텀 작업 ID |

### 참조 이미지-투-비디오 예시

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/videos/multi-image2video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kling-v3",
    "prompt": "동일한 시바견의 모습을 유지하며 잔디밭에서 앞으로 달려가는 모습",
    "duration": "5",
    "aspect_ratio": "16:9",
    "mode": "pro",
    "image_list": [
      {
        "image_id": 1,
        "image_url": "https://example.com/reference-1.png"
      },
      {
        "image_id": 2,
        "image_url": "https://example.com/reference-2.png"
      }
    ]
  }'
```

<Note>
  `multi-image2video`는 표준 Kling 계열의 참조 이미지 기능 진입점입니다. 입력이 첫 프레임 또는 첫·끝 프레임인 경우 계속 `image2video`를 사용하십시오. 해당 작업을 조회할 때는 `GET /kling/v1/videos/multi-image2video/{task_id}`를 사용하십시오.
</Note>

## Kling Omni 비디오

```
POST /kling/v1/videos/omni-video
```

### 현재 공개 모델

- `kling-v3`

### 요청 파라미터

| 파라미터 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `model_name` | string | 예 | `kling-v3`만 지원 |
| `prompt` | string | 예 | 공식 Omni 프롬프트, `image_list`, `element_list`, `video_list`, `voice_list` 내 객체를 참조 가능 |
| `sound` | string | 아니오 | 공식 값 `on` / `off` 사용 |
| `duration` | string/integer | 아니오 | 일반적으로 `5`; 구체적인 상한은 해당 모델의 공식 문서를 기준으로 함 |
| `aspect_ratio` | string | 아니오 | 예: `16:9`, `9:16`, `1:1` |
| `mode` | string | 아니오 | 생성 모드, 예: `std`, `pro` |
| `multi_shots` | boolean | 아니오 | 공식 멀티샷 스위치; 별칭 `multi_shot`과 호환 |
| `multi_prompt` | array | 조건부 필수 | 멀티샷 설명 |
| `image_list` | array | 아니오 | 공식 이미지 참조 목록 |
| `element_list` | array | 아니오 | 공식 요소 참조 목록 |
| `video_list` | array | 아니오 | 공식 비디오 참조 목록 |
| `voice_list` | array | 아니오 | 공식 사운드 참조 목록 |
| `callback_url` | string | 아니오 | 콜백 주소 |
| `external_task_id` | string | 아니오 | 비즈니스 측 커스텀 작업 ID |

### Omni 요청 예시

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/videos/omni-video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kling-v3",
    "prompt": "<<<image_1>>> 비 내리는 밤 골목에서 카메라를 향해 걸어옵니다",
    "sound": "on",
    "duration": "5",
    "aspect_ratio": "16:9",
    "mode": "pro",
    "image_list": [
      {
        "image_id": 1,
        "image_url": "https://example.com/reference.png"
      }
    ]
  }'
```

<Note>
  Omni 라우팅은 공식 `element_list` 사용을 권장하며, `kling_elements` 별칭과도 호환됩니다. 작업을 조회하려면 제출 경로와 같은 계열의 `GET /kling/v1/videos/omni-video/{task_id}`를 사용하십시오.
</Note>
