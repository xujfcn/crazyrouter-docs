# 비디오 생성 별칭

```
POST /v1/video/generations
```

이는 Crazyrouter가 제공하는 호환 별칭 라우트로, `/v1/video/generations` 경로를 고정적으로 사용하는 비디오 클라이언트나 미들웨어에 적합합니다.

## 인증

```http
Authorization: Bearer YOUR_API_KEY
```

## 언제 사용하는가

- 클라이언트에 이미 `/v1/video/generations`가 하드코딩되어 있는 경우
- 기존 비디오 워크플로를 마이그레이션하며 호출 경로를 바꾸고 싶지 않은 경우
- 이미 배포된 서드파티 요청 형식과 호환해야 하는 경우
- Wan 텍스트-투-비디오를 제출해야 하는 경우, 예: `wan2.5-t2v-preview` 또는 `wan2.2-t2v-plus`

새로운 연동을 개발 중이라면 다음을 우선 고려하세요.

- Wan 텍스트-투-비디오: 이 페이지의 `POST /v1/video/generations` 사용
- Veo / 통합 비디오 워크플로: `POST /v1/video/create`를 사용하고 `veo-3.1-fast` 또는 `veo-3.1-quality`를 제출
- OpenAI 공식 호환 비디오 워크플로: `POST /v1/videos` 사용

## 최소 요청 예시

### Wan 2.2 T2V Plus

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "wan2.2-t2v-plus",
    "prompt": "고요한 영화적 느낌의 산속 구름바다 영상",
    "seconds": "5",
    "size": "480P"
  }'
```

### 범용 최소 예시

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations   -H "Content-Type: application/json"   -H "Authorization: Bearer YOUR_API_KEY"   -d '{
    "model": "wan2.5-t2v-preview",
    "prompt": "A cinematic shot of waves hitting a cliff at sunset"
  }'
```

## 전형적인 성공 응답

```json
{
  "id": "video_task_abc123",
  "task_id": "video_task_abc123",
  "status": "processing",
  "status_update_time": 1709123456
}
```

## 로컬에서 확인된 오류 응답

로컬 `http://127.0.0.1:4000` 환경에서 이 라우트는 이미 존재함이 검증되었습니다. 모델이 일시적으로 사용 불가할 때는 `404`가 아니라 비즈니스 오류가 반환됩니다.

```json
{
  "code": "get_channel_failed",
  "message": "model wan2.2-t2v-plus is temporarily unavailable, please try again later",
  "data": null
}
```

## 유의사항

- 요청 본문 필드는 구체적인 비디오 모델과 업스트림 능력에 따라 달라집니다
- `model`의 사용 가능 여부는 현재 Token 화이트리스트와 업스트림 채널 상태에 따라 결정됩니다
- Wan 텍스트-투-비디오는 `model`, `prompt`, `seconds`, `size`를 사용합니다. `wan2.2-t2v-plus`의 검증된 조합은 `seconds: "5"`, `size: "480P"` 또는 `"1080P"`입니다.
- `wan2.2-t2v-plus`는 `/alibailian/api/v1/services/aigc/video-generation/video-synthesis`로 제출해서는 안 됩니다.
- 작업 생성이 성공하면 이어서 `GET /v1/video/generations/{task_id}`를 호출해 상태를 조회할 수 있습니다

<Note>
이 라우트는 호환 별칭이며, 모든 비디오 모델이 완전히 동일한 요청 필드를 공유한다는 뜻은 아닙니다. Wan 텍스트-투-비디오는 현재 이 페이지의 라우트 사용을 권장하며, Veo 또는 통합 비디오 워크플로는 `/v1/video/create`를 사용해 `veo-3.1-fast` 또는 `veo-3.1-quality`를 제출해야 합니다.
</Note>
