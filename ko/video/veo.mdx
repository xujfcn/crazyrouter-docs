# Veo 3.1

현재 Crazyrouter가 대외 공개하는 Veo 3.1 모델은 다음과 같습니다:

- `veo-3.1-fast`
- `veo-3.1-quality`

이 두 명칭은 대외 public alias입니다. 내부 canonical provider 이름은 고객에게 직접 공개되지 않습니다.

<Note>
  `veo-3.1`는 고객이 직접 제출할 수 있는 `model` 값이 아닙니다. 고객 요청 시 항상 `veo-3.1-fast` 또는 `veo-3.1-quality`를 사용해 주시기 바랍니다.
</Note>

## 통합 영상 API를 통한 호출

```
POST /v1/video/create
```

현재 이 페이지는 이미 대외로 정리된 기능만 다룹니다:

- 텍스트 기반 영상 생성
- 단일 이미지 영상 생성

Google 공식 문서 내 `referenceImages`, style reference, 더 세부적인 provider-native 모드는 현재 공개 contract에 포함되지 않습니다.

### 현재 사용 가능한 모델

| 모델 | 설명 |
|------|------|
| `veo-3.1-fast` | 더 낮은 지연에 중점을 두어, 더 빠르게 첫 사용 가능한 결과를 얻을 수 있습니다 |
| `veo-3.1-quality` | 품질 우선에 중점을 두어, 기본 메인 노출에 적합합니다 |

### 기능 현황

| 기능 / 사양 | 상태 | 설명 |
|------|------|------|
| 텍스트 기반 영상 `720P / 1080P` | `Verified` | 현재 공개 contract가 정리되어 있습니다 |
| 단일 이미지 기반 영상 `720P / 1080P` | `Verified` | 현재 공개 contract가 정리되어 있습니다 |
| 오디오 활성화 행 | `Beta` | 공식 기능은 있으나, 현재 공개 artifact는 보완이 필요합니다 |
| `start_end` | `Beta` | 현재 공개 페이지에서는 약속하지 않습니다 |
| `referenceImages` / reference assets | `Beta` | 현재 공개 페이지에서는 약속하지 않습니다 |
| `4K` | `Beta` | 현재 공개 페이지에서는 약속하지 않습니다 |

<Note>
  요금 페이지와 본 문서는 동일한 상태 구분을 사용합니다: `Verified`는 현존하는 최소 live 완성 루프를 의미하며, `Beta`는 공식 기능은 있으나 현재 검증 또는 경계가 보완 중임을 의미합니다.
</Note>

### 요청 파라미터

| 파라미터 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `model` | string | 예 | `veo-3.1-fast` 또는 `veo-3.1-quality` |
| `prompt` | string | 예 | 영상 설명 프롬프트 |
| `aspect_ratio` | string | 아니오 | 현재는 `16:9` 또는 `9:16` 사용 권장 |
| `size` | string | 아니오 | 현재는 `720P` 또는 `1080P` 사용 권장 |
| `images` | array | 아니오 | 단일 이미지 기반 영상일 경우 `1`장의 이미지 URL 입력 |
| `duration` | integer | 아니오 | 일반적인 값은 `8` |

### 요청 예시

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-quality",
    "prompt": "A cinematic shot of a spaceship landing on Mars, dust clouds rising, golden hour lighting",
    "aspect_ratio": "16:9"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/video/create",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "veo-3.1-quality",
        "prompt": "A cinematic shot of a spaceship landing on Mars",
        "aspect_ratio": "16:9"
    }
)

task_id = response.json()["task_id"]
print(f"任务 ID: {task_id}")
```

</CodeGroup>

## 단일 이미지 영상 예시

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-fast",
    "prompt": "The person in the image slowly turns their head and smiles",
    "images": ["https://example.com/portrait.jpg"],
    "aspect_ratio": "9:16",
    "size": "720P"
  }'
```

## 작업 조회

```
GET /v1/video/query?id={task_id}
```

```bash cURL
curl "https://api.crazyrouter.com/v1/video/query?id=veo_task_abc123" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### 응답 예시 (완료)

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "veo_task_abc123",
    "status": "SUCCESS",
    "url": "https://media.crazyrouter.com/task-artifacts/example.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/example.mp4"
  }
}
```

<Note>
  Google 공식 문서에서는 Veo 3.1의 `reference asset images` 및 더 세부적인 provider-native 기능 범위도 설명합니다. 현재 Crazyrouter의 대외 공개 페이지는 `veo-3.1-fast` / `veo-3.1-quality` 하의 텍스트 기반 영상 및 단일 이미지 기반 영상만을 보장합니다. 향후 더 많은 Veo 1차적 기능이 공개되면 별도 문서와 검증 기록을 추가할 예정입니다.
</Note>
