# AIGC GV VOD 호출 방법

`aigc-video-gv-*`는 Crazyrouter가 Tencent VOD 경로를 통해 연결한 GV / Google Veo 비디오 모델입니다. 호출 방식은 AIGC Kling VOD와 동일하며, OpenAI 스타일의 비디오 비동기 인터페이스를 사용합니다.

```http
POST /v1/video/generations
GET /v1/video/generations/{task_id}
```

<Note>
  `aigc-video-gv-*` only uses `/v1/video/generations` and the matching query route. Do not send these models to `/v1/video/create`; a route mismatch will surface as `model_not_found` or a similar upstream error.
</Note>

## 사용 가능한 모델

| 모델 | 상류 버전 | 설명 |
|------|------|------|
| `aigc-video-gv-3.1` | GV 3.1 | 고품질 버전, 음성 포함 비디오 지원 |
| `aigc-video-gv-3.1-fast` | GV 3.1 Fast | 더 빠른 버전, 음성 포함 비디오 지원 |
| `aigc-video-gv-3.1-lite` | GV 3.1 Lite | 경량 버전, 음성 포함 비디오 지원 |

<Note>
  Tencent VOD의 GV 3.1은 Google Veo 경로이며 Kling이 아닙니다. `aigc-video-kling-3.1`과 같은 모델명을 사용하지 마세요.
</Note>

## 작업 생성

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-gv-3.1-fast",
    "prompt": "a cinematic product shot with natural camera movement",
    "seconds": "5",
    "metadata": {
      "resolution": "1080P",
      "sound": true
    }
  }'
```

## 이미지 기반 생성 및 다중 이미지 참조

단일 이미지는 `image`를 사용할 수 있으며, 다중 이미지 참조는 `metadata.image_list`를 사용하는 것을 권장합니다.

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-gv-3.1",
    "prompt": "combine the visual style of the references into one smooth shot",
    "seconds": "5",
    "metadata": {
      "resolution": "1080P",
      "image_list": [
        {
          "url": "https://example.com/ref-1.png",
          "reference_type": "asset"
        },
        {
          "url": "https://example.com/ref-2.png",
          "reference_type": "style"
        }
      ]
    }
  }'
```

<Warning>
  GV 다중 이미지 입력은 반드시 `FileInfos`를 통해 전달해야 합니다. 본 사이트는 `image_list`를 `FileInfos`로 변환하며, GV 다중 이미지 요청에는 `LastFrameUrl`을 사용하지 않습니다.
</Warning>

## 자주 사용하는 metadata 필드

| 필드 | 설명 |
|------|------|
| `resolution` | `720P`, `1080P`, `2K`, `4K`. 실제 사용 가능한 규격은 Pricing 페이지를 기준으로 합니다 |
| `sound` | 소리 생성 여부, `true` / `false`, `on` / `off` 지원 |
| `audio_generation` | `Enabled` / `Disabled`를 직접 전달 |
| `image_list` | 다중 이미지 참조 배열 |
| `reference_type` / `ReferenceType` | GV 참조 유형, 일반적으로 `asset` 또는 `style` 사용 |

가격, 할인, 사용 가능한 규격은 [Pricing 페이지](/pricing)를 기준으로 합니다.
