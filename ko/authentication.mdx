## Bearer Token 인증

모든 API 요청은 Header에 API Key를 포함해야 합니다.

```
Authorization: Bearer YOUR_API_KEY
```

## API Key 발급받기

1. [Crazyrouter](https://crazyrouter.com)에 로그인
2. 로그인 후 [토큰 관리](https://crazyrouter.com/console/token) 페이지로 이동
3. 「새 토큰 만들기」 클릭
4. 토큰 이름, 크레딧 제한, 사용 가능 모델 등을 설정
5. 생성된 `sk-`로 시작하는 키를 복사

<Warning>
API Key는 생성 시 단 한 번만 표시되므로 반드시 잘 보관하세요. 분실한 경우 다시 생성해야 합니다.
</Warning>

## 사용 예시

<Note>
OpenAI 호환 연동은 기본적으로 국제 주소 `https://api.crazyrouter.com/v1`을 사용합니다. 동아시아 지역은 `https://cn.crazyrouter.com/v1`을 우선 사용하세요. Claude Code, Hermes, OpenClaw 또는 기타 도구에 주소를 설정해야 한다면, 먼저 [API Endpoint 설명](https://docs.crazyrouter.com/ko/api-endpoint)을 참고하세요.
</Note>

<CodeGroup>
```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-5.5", "messages": [{"role": "user", "content": "Hi"}]}'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",
    base_url="https://api.crazyrouter.com/v1"
)
```

```javascript Node.js
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-xxxxxxxx',
  baseURL: 'https://api.crazyrouter.com/v1'
});
```
</CodeGroup>

## 토큰 권한 제어

토큰 생성 시 다음을 설정할 수 있습니다.

- **이름**: 용도를 식별하기 쉽도록
- **크레딧 제한**: 최대 사용 가능 크레딧 설정
- **만료 시간**: 유효 기간 설정
- **사용 가능 모델**: 호출 가능한 모델 범위 제한
- **IP 화이트리스트**: 호출 출처 IP 제한
