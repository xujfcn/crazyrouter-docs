# 작업 상태 조회

## 단일 작업 조회

```
GET /mj/task/{id}/fetch
```

작업 ID로 작업 상세 정보와 상태를 조회합니다.

### 요청 예시

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/mj/task/task_1234567890/fetch \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.crazyrouter.com/mj/task/task_1234567890/fetch",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)

print(response.json())
```

</CodeGroup>

## 일괄 작업 조회

```
POST /mj/task/list-by-condition
```

조건에 따라 작업 목록을 일괄 조회합니다.

### 요청 파라미터

| 파라미터 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `ids` | array | 아니오 | 작업 ID 목록 |

### 요청 예시

```bash cURL
curl -X POST https://api.crazyrouter.com/mj/task/list-by-condition \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "ids": ["task_1234567890", "task_0987654321"]
  }'
```

### 응답 예시

```json
[
  {
    "id": "task_1234567890",
    "action": "IMAGINE",
    "status": "SUCCESS",
    "progress": "100%",
    "imageUrl": "https://cdn.discordapp.com/attachments/.../image1.png"
  },
  {
    "id": "task_0987654321",
    "action": "IMAGINE",
    "status": "IN_PROGRESS",
    "progress": "40%",
    "imageUrl": ""
  }
]
```

<Note>
  폴링 간격은 3~5초를 권장합니다. 작업은 일반적으로 30~120초 내에 완료되며, 구체적인 시간은 Midjourney 서비스 부하에 따라 달라집니다.
</Note>
