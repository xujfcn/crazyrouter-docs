# Qwen Image

```
POST /v1/images/generations
```

Crazyrouter는 현재 OpenAI Images 호환 프로토콜로 `Qwen Image` 1차 생성 모델을 외부에 개방합니다. 고객은 계속 통합된 `/v1/images/generations`를 사용하며, 알리바바 공식 및 서드파티 서비스는 내부 provider로만 작동하고 별도의 고객 프로토콜을 노출하지 않습니다.

## 현재 개방된 모델

| 모델 | 상류 실행 형태 | 현재 고객 대상 기능 | 검증 상태 |
|------|--------------|--------------|----------|
| `qwen-image-plus` | 비동기 생성 | 텍스트-투-이미지 | 검증 완료 |
| `qwen-image-max` | 동기 생성 | 텍스트-투-이미지 | 검증 완료 |
| `qwen-image-2.0` | 동기 생성 | 텍스트-투-이미지 | 검증 완료 |
| `qwen-image-2.0` | 동기 생성 | 텍스트-투-이미지 | Beta |

<Note>
  `qwen-image-2.0`은 현재 프로토콜과 코드 정합이 완료되었지만, 프로덕션 운영 증빙이 아직 보완 중이라 우선 Beta로 표시합니다.
</Note>

## 고객 프로토콜

### 요청 파라미터

| 파라미터 | 유형 | 필수 | 설명 |
|------|------|------|------|
| `model` | string | 예 | `qwen-image-plus`, `qwen-image-max`, `qwen-image-2.0`, `qwen-image-2.0` |
| `prompt` | string | 예 | 텍스트-투-이미지 프롬프트 |
| `size` | string | 아니오 | 출력 크기. 현재 모델 페이지 또는 playground에서 제시하는 지원 크기를 사용하는 것을 권장 |
| `n` | integer | 아니오 | 생성 장수, 기본값 `1` |
| `response_format` | string | 아니오 | `url` 또는 `b64_json` |

### 요청 예시

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "qwen-image-max",
    "prompt": "고급스러운 느낌의 제품 포스터, 주제는 유리 향수병 한 병, 부드러운 스튜디오 조명, 중국어 제목 \"晨雾\"",
    "size": "1024x1024",
    "n": 1,
    "response_format": "url"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.images.generate(
    model="qwen-image-max",
    prompt="고급스러운 느낌의 제품 포스터, 주제는 유리 향수병 한 병, 부드러운 스튜디오 조명, 중국어 제목 \"晨雾\"",
    size="1024x1024",
    n=1
)

print(response.data[0].url)
```

</CodeGroup>

## 공식 과금 기준

Qwen Image는 현재 공식 실제 기준으로 성공적으로 생성된 이미지 장수에 따라 과금하며, 입력/출력 토큰 기준으로 표시하지 않습니다.

| 모델 | 공식 기준 | 공식 단가 | 현재 문서 상태 |
|------|----------|----------|--------------|
| `qwen-image-plus` | 장 단위 | `¥0.20 / 장` | 검증 완료 |
| `qwen-image-max` | 장 단위 | `¥0.50 / 장` | 검증 완료 |
| `qwen-image-2.0` | 장 단위 | `¥0.20 / 장` | 검증 완료 |
| `qwen-image-2.0` | 장 단위 | `¥0.50 / 장` | Beta |

## 범위 설명

- 본 페이지는 1차 개방으로 `텍스트-투-이미지` 고객 대상 기능만 보장하며, 상류의 더 많은 멀티모달 기능을 고객 프로토콜로 직접 노출하지 않습니다.
- `Qwen Image`의 provider 측에는 비동기 또는 동기 방식의 차이가 있을 수 있지만, 고객 측은 계속 통합된 OpenAI Images 요청/응답 형식을 사용합니다.
- 이미지 편집 모델 `qwen-image-plus`는 본 페이지의 "생성 모델" 범위에 포함되지 않습니다. 편집 기능이 필요하다면 편집 모델의 현재 개방 상태를 별도로 평가해야 합니다.
