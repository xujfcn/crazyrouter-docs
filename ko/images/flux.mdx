# 플럭스

<Warning>
  현재 Crazyrouter 가격 페이지에는 직접 호출 가능한 플럭스 `model_name`가 노출되어 있지 않습니다. 이 페이지에서는 더 이상 플럭스 요청 예시를 제공하지 않으며, 이전의 `flux-*` 모델 ID를 프로덕션 설정에 사용해서는 안 됩니다.
</Warning>

## 현재 대안

이미지 생성 또는 편집의 경우, 가격 페이지에 현재 노출된 모델을 우선적으로 사용하십시오:

| 사용 사례 | 권장 모델 |
|----------|------------------|
| OpenAI 이미지 | `gpt-image-2` |
| Gemini 이미지 | `nano-banana`, `nano-banana-2`, `nano-banana-pro` |
| Grok 이미지 | `grok-4-image` |
| Qwen 이미지 | `qwen-image-2.0`, `qwen-image-plus`, `qwen-image-max` |
| Doubao 이미지 | `doubao-seedream-4-5`, `doubao-seedream-5-0` |

## 확인 방법

`https://crazyrouter.com/pricing`와 `GET /v1/models`가 반환하는 현재 모델 리스트를 신뢰할 수 있는 정보로 사용하세요. 제출이 성공적으로 가능한 공개적으로 확인 가능한 모델만이 문서 예시나 고객 안내 기본값으로 사용되어야 합니다.
