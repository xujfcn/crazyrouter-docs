> 내용 업데이트: 2026-10-12

[crazyrouter-hermes](https://github.com/xujfcn/crazyrouter-hermes)를 사용하면 [Hermes Agent](https://github.com/NousResearch/Hermes-Agent)를 Crazyrouter를 모델 공급자로 변경할 수 있습니다. 설정이 완료되면 Hermes는 `https://api.crazyrouter.com/v1`를 OpenAI 호환 endpoint로 이용하고, 한 개의 Crazyrouter API Key로 Claude, GPT, DeepSeek, Gemini, Qwen 등 627개가 넘는 모델에 요청할 수 있습니다.

## 누구에게 적합한가요

- Hermes Agent 사용자 중 Crazyrouter를 모델 공급자로 사용하고 싶은 분
- 모델과 쿼터를 Crazyrouter로 통합 관리해야 하는 로컬 agent 사용 시나리오
- `OPENAI_API_KEY`, `OPENAI_BASE_URL`, 기본 모델을 한 번에 설정하고 싶은 분

## 요구 사항

| 항목 | 설명 |
|------|----------|
| Hermes Agent | Hermes를 로컬에 설치하고 실행되는지 확인하세요. |
| Crazyrouter 계정 | [crazyrouter.com](https://crazyrouter.com)에 계정을 만드세요. |
| Crazyrouter API Key | Hermes 전용 `sk-...` 토큰을 별도로 생성하는 것을 권장합니다. |
| 모델 접근 권한 | 사용 예정인 모델을 토큰에 허용하세요. |

<Tip>
Hermes는 OpenAI 호환 설정을 통해 Crazyrouter에 연결됩니다. Base URL은 `https://api.crazyrouter.com/v1`여야 합니다.
</Tip>

</Warning>

## 수동 설정하기

스크립트를 실행하지 않으려면 Hermes를 수동으로 설정할 수 있습니다.

### 환경 변수

`~/.hermes/.env`를 수정하세요:

```bash
OPENAI_API_KEY=sk-your-crazyrouter-key
OPENAI_BASE_URL=https://api.crazyrouter.com/v1
```

### 기본 모델

`~/.hermes/config.yaml`를 편집하세요:

```yaml
model:
  provider: "custom"
  default: "claude-opus-4-8"
  base_url: "https://api.crazyrouter.com/v1"
```

`default`를 Crazyrouter 토큰에 허용된 모델명으로 교체하세요.

## 모델 전환

설정이 완료되면 Hermes 내에서 `/model`를 통해 모델을 전환할 수 있습니다:

```text
/model claude-opus-4-8
/model gpt-5.5
/model claude-sonnet-4-6
/model gemini-3.1-pro
/model deepseek-v4-pro
/model qwen-max
/model gpt-4o
```

전환 시 `model not allowed` 또는 `403` 메시지가 나오면, 선택한 모델이 현재 Crazyrouter 토큰에서 허용되지 않은 경우가 많습니다.

## 체크리스트

- [ ] `OPENAI_API_KEY`가 `~/.hermes/.env`에 있는지, 유효한 Crazyrouter token인지 확인하세요.
- [ ] `OPENAI_BASE_URL`가 `https://api.crazyrouter.com/v1`와 동일한지 확인하세요.
- [ ] `provider`가 `~/.hermes/config.yaml` 내의 `custom`와 동일한지 확인하세요.
- [ ] 기본 모델이 Crazyrouter token에 허용되어 있는지 확인하세요.
- [ ] Hermes가 테스트 메시지에 응답하는지 확인하세요.
- [ ] `/model gpt-5.5` 또는 허용된 다른 모델이 정상적으로 전환되는지 확인하세요.

## 자주 발생하는 문제

| 증상 | 추정 원인 | 해결 방법 |
|------|-------------------|---------|
| `401 unauthorized` | API Key가 잘못되었거나 만료, 교체됨 | Crazyrouter 토큰을 새로 만들고 `~/.hermes/.env`를 갱신하세요. |
| `403` 또는 `model not allowed` | 토큰이 선택한 모델을 허용하지 않음 | Crazyrouter 토큰 설정에서 모델을 허용하세요. |
| Hermes가 여전히 이전 공급자를 사용함 | 설정 파일을 다시 불러오지 않았거나 잘못된 파일 편집 | Hermes를 재시작하고 `~/.hermes/.env` 및 `~/.hermes/config.yaml`을 확인하세요. |
| 연결 타임아웃 | 로컬 네트워크에서 Crazyrouter에 연결되지 않음 | proxy, firewall, DNS를 확인하세요. |
