# 创建响应

```
POST /v1/responses
```

截至2026年3月23日，Crazyrouter生产环境已验证：

- `gpt-5.5` 返回 `object: "response"`
- 基本文本请求当前返回类型为`message`的`output`项目
- 流式请求一致地暴露`response.created`、`response.in_progress`、`response.output_item.added`、`response.content_part.added`和`response.output_text.delta`

<Note>
  Claude目前不支持`POST /v1/responses`。请改用`POST /v1/messages`或`POST /v1/chat/completions`来使用Claude。
</Note>

---

## 基础请求

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Explain what an API is in one sentence."
  }'
```

观察到的生产环境响应结构：

```json
{
  "object": "response",
  "model": "gpt-5.5",
  "output": [
    {
      "type": "message"
    }
  ]
}
```

---

## 流式请求

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Say hello in one sentence.",
    "stream": true
  }'
```

2026年3月23日生产环境流式探测观察到以下开场事件序列：

```text
event: response.created
event: response.in_progress
event: response.output_item.added
event: response.content_part.added
event: response.output_text.delta
```

因此当前最安全的使用策略是：

1. 从`response.output_text.delta`中积累文本
2. 将`response.completed`或流终止视为完成信号
