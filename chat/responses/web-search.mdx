# 响应 Web 搜索

```
POST /v1/responses
```

截至 2026 年 3 月 23 日，Crazyrouter 生产环境已验证 `gpt-5.5` 在响应 API 上使用：

- `tools: [{ "type": "web_search_preview" }]`
- `output` 序列，先是 `web_search_call`，然后是 `message`

<Note>
  Claude 目前不支持 `POST /v1/responses`。对于 Claude 的 Web 搜索，请使用 `POST /v1/chat/completions` 或本地 Claude 路径。
</Note>

---

## 最简请求

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Find one AI news item from March 2026.",
    "tools": [
      {
        "type": "web_search_preview"
      }
    ]
  }'
```

已观察到的生产响应格式：

```json
{
  "output": [
    {
      "type": "web_search_call"
    },
    {
      "type": "message"
    }
  ]
}
```

---

## 当前验证规则

如果你需要确认模型是否真的进行了网页搜索，目前最安全的检查方式是：

- `web_search_call` 是否出现在 `output` 中
- 最终答案是否仍然以 `message` 的形式到达
