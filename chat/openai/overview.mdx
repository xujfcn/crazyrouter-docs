# 聊天完成对象

`/v1/chat/completions` 对非流式请求返回 `chat.completion`，对流式请求返回 `chat.completion.chunk`。

本页侧重于 Crazyrouter 当前最稳定、最广泛适用的兼容 OpenAI 的响应结构。

## 非流式对象

最精简的生产请求：

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Explain what a REST API is in one sentence."
      }
    ],
    "max_tokens": 64
  }'
```

典型生产响应骨架：

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "created": 1774177466,
  "model": "gpt-5.5",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "...",
        "reasoning_content": null,
        "tool_calls": null
      },
      "finish_reason": "stop"
    }
  ]
}
```

### 如何读取

- `message.content` 是最终文本答案
- `message.tool_calls` 仅在模型请求工具执行时出现
- `message.reasoning_content` 可能会出现在某些模型或路由中，但目前不应将其视为保证字段

## 流式对象

对于流式请求，服务器返回 `chat.completion.chunk` SSE 事件：

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion.chunk",
  "created": 1774177466,
  "model": "gpt-5.5",
  "choices": [
    {
      "index": 0,
      "delta": {
        "role": "assistant",
        "content": "..."
      },
      "finish_reason": null
    }
  ]
}
```

常见 SSE 结构：

```text
data: {"object":"chat.completion.chunk",...}
data: {"choices":[{"delta":{"content":"..."}}],...}
data: [DONE]
```

---

## 通常关注的字段

| 字段 | 含义 |
|-------|---------|
| `object` | 非流式为 `chat.completion`，流式为 `chat.completion.chunk` |
| `model` | 用于响应的实际模型 |
| `choices[].message.content` | 最终非流式文本 |
| `choices[].message.tool_calls` | 非流式工具请求 |
| `choices[].delta.content` | 流式文本增量 |
| `choices[].finish_reason` | 停止原因，例如 `stop`、`length` 或 `tool_calls` |

<Note>
  上游模型可能会传递额外字段。客户端代码应优先依赖稳定的通用字段，切勿假设每个模型都提供相同扩展。
</Note>
