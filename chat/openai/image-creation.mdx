# 聊天图片生成

```
POST /v1/chat/completions
```

截至2026年3月23日，生产环境在Crazyrouter上的检测结果如下：

- `gpt-4o`返回`200`，但`message.content`是纯文本，不是标准的多部分图片内容
- `gpt-image-2`也会返回`200`，但目前响应结构依然是包含参数块、ID和预览链接的文本或Markdown，而不是标准OpenAI `image_url`的多部分结构
- 如果你需要稳定、机器可读的图片输出，当前推荐方案是[`/v1/images/generations`](/images/gpt-image)，并搭配`gpt-image-2`；对于Grok图片模型，请参见[`Grok Image Models`](/images/grok)
- 如果你需要参考图片编辑或多图输入，请不要继续将Nano Banana系列作为稳定`/v1/images/generations`入口。请直接参考[`Nano Banana 2`](/images/nano-banana-2)文档里的Gemini原生路径；[`Nano Banana`](/images/nano-banana)目前仅限于受控测试

<Warning>
  请不要把当前Crazyrouter聊天图片响应当作标准OpenAI `content: [{type: "image_url", ...}]`解析。
</Warning>

## 当前可复现的聊天行为

以下请求在生产环境命中了`gpt-image-2`，并返回了`200`：

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "messages": [
      {
        "role": "user",
        "content": "Generate an image of a red square on a white background."
      }
    ],
    "max_tokens": 512
  }'
```

观察到的`message.content`大致是如下形状的字符串：

```text
{
  "prompt": "Generate an image of a red square on a white background.",
  "ratio": "1:1",
  "n": 1
}

ID: ...
Data Preview: https://...
```

这意味着当前聊天路径更像是文本包裹的图片任务输出，而不是标准化的多部分图片消息对象。

## 稳定路径：Images API

如果你需要程序化图片检索，请使用：

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A red square on a white background",
    "size": "1024x1024",
    "quality": "low",
    "output_format": "png"
  }'
```

当前`gpt-image-2`稳定路径采用主图片路由`https://api.crazyrouter.com/v1`。响应通常包含：

- `data[0].url`

`gpt-image-2`接受`response_format="url"`和`response_format="b64_json"`作为兼容字段，但新集成应使用`output_format="png"`、`"jpeg"`或`"webp"`选择图片文件格式。

所以稳定的自动化路径依然是Images API，而不是聊天图片兼容路径。

<Note>
  如果你只是手动测试，`gpt-image-2`聊天路径依然适用于观察。如果需要后端自动化、存储或后处理，请使用[`GPT Image docs`](/images/gpt-image)或[`Grok Image Models`](/images/grok)。如果你的工作负载依赖于参考图片编辑或多图输入，请直接参考[`Nano Banana 2`](/images/nano-banana-2)文档里的Gemini原生路径。不要继续将Nano Banana系列`/v1/images/generations`作为稳定推荐。
</Note>
