# 推理模型

本页仅记录在 `2026-03-22` 上通过 Crazyrouter 生产环境复验的推理行为。

针对兼容 OpenAI 的集成，当前指南如下：

- 如果你只需要更强的推理能力且只关心最终答案，请使用带有 `reasoning_effort` 的 Chat Completions
- 如需稳定且可检视的推理输出，请优先选择 Responses API，并参见 [GPT-5 思维模式](/chat/responses/gpt5-thinking)

## 已验证组合

| 路由 | 模型 | 请求参数 | 当前生产环境行为 |
|-------|-------|-------------------|-----------------------------|
| Chat Completions | `gpt-5.5` | `reasoning_effort` | 请求成功并返回最终答案 |
| Responses | `gpt-5.5` | `reasoning.effort` / `reasoning.summary` | `output` 包含 `reasoning` 和 `message` 条目 |

---

## Chat Completions: `reasoning_effort`

以下请求格式当前可在生产环境使用：

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Which is larger, 9.11 or 9.9? Explain briefly."
      }
    ],
    "reasoning_effort": "high",
    "max_tokens": 120
  }'
```

可用的 `reasoning_effort` 值：

| 值 | 含义 |
|-------|---------|
| `low` | 适用于简单任务的快速响应 |
| `medium` | 平衡的默认风格设置 |
| `high` | 用于复杂任务的更强推理 |

### 当前响应行为

在 `2026-03-22` 生产环境复检中：

- 请求成功
- 最终答案返回于 `message.content`
- `message.reasoning_content` 未能稳定地包含可用内容

因此，如果你只需更强的推理，搭配 `reasoning_effort` 的 Chat Completions 仍可用。如果你需要可见的推理摘要字段，则不建议把 Chat Completions 作为主要路径。

---

## 需要可查看的推理输出时

更可靠的生产路径是 Responses API：

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Which is larger, 9.11 or 9.9? Explain briefly.",
    "reasoning": {
      "effort": "high",
      "summary": "detailed"
    }
  }'
```

经验证的 `output.type` 值：

```json
["reasoning", "message"]
```

具体的响应结构、摘要字段和流式事件名详见：

- [GPT-5 思维模式](/chat/responses/gpt5-thinking)
- [AI 思维字段](/reference/thinking)

---

## 当前建议

- 对于需要记录或展示推理摘要的新开发项目，建议首选 Responses API
- 对于只关心最终答案的现有 Chat Completions 集成，`reasoning_effort` 依然是有效路径
- 不要假定所有 OpenAI 兼容推理模型都能稳定暴露 `reasoning_content`

<Warning>
  推理请求通常会增加延迟和 Token 用量。较高的 `reasoning_effort` 通常意味着更高的成本。
</Warning>
