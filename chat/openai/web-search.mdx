# 网页搜索

本页仅记录了在`2026-03-22`上针对Crazyrouter生产环境重新验证过的OpenAI风格网页搜索行为。

当前主要路径为：

- `gpt-5.5`
- `POST /v1/responses`
- `tools: [{ "type": "web_search_preview" }]`

## 当前结论

在今天对生产环境的复查中：

- `gpt-5.5` 通过 Responses API 稳定地返回了 `web_search_call`
- 老版本的 Chat Completions 探针使用 `tools: [{ "type": "web_search" }]` 返回了 `200`，但未能提供一个稳定、可验证的搜索触发信号，因此未作为主要文档记录的模式使用

---

## 已验证请求

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Use web search to find one current technology headline published recently.",
    "tools": [
      {
        "type": "web_search_preview"
      }
    ]
  }'
```

已验证 `output.type` 的值：

```json
["web_search_call", "message"]
```

这表明，搜索步骤和最终答案是分别返回的。

---

## Python 示例

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.responses.create(
    model="gpt-5.5",
    input="Use web search to find one current technology headline published recently.",
    tools=[
        {"type": "web_search_preview"}
    ]
)

print(response.output_text)
```

---

## 如何确认实际执行了搜索

请直接检查 `response.output`：

```python Python
for item in response.output:
    print(item.type)
```

如果你看到：

```text
web_search_call
message
```

那么模型先进行了搜索，然后给出了答案。

---

## 不推荐作为主要方案的旧模式

这次生产复查还测试了旧版 Chat Completions 结构：

```json
{
  "tools": [
    {
      "type": "web_search"
    }
  ]
}
```

结果：

- 请求返回了 `200`
- 但未能观测到稳定、可验证的搜索触发标记

因此，在 Crazyrouter 文档中，OpenAI 风格的网页搜索目前应首先通过 Responses API 记录。
