## HTTP статус-коды

| Статус-код | Описание |
|-----------|----------|
| 200 | Запрос успешно выполнен |
| 400 | Ошибка параметров запроса |
| 401 | Ошибка аутентификации, API Key недействителен или отсутствует |
| 403 | Недостаточно прав, токен не имеет доступа к данной модели |
| 429 | Частота запросов превышена |
| 500 | Внутренняя ошибка сервера |
| 502 | Вышестоящий сервис недоступен |
| 503 | Сервис временно недоступен |

## Формат ответа об ошибке

```json
{
  "error": {
    "message": "错误描述信息",
    "type": "error_type",
    "code": "error_code"
  }
}
```

## Частые ошибки

### 401 – Ошибка аутентификации

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "authentication_error",
    "code": "invalid_api_key"
  }
}
```

**Решение**: Проверьте правильность API Key, убедитесь, что он начинается с `sk-`.

### 429 – Ограничение по частоте

```json
{
  "error": {
    "message": "Rate limit exceeded",
    "type": "rate_limit_error",
    "code": "rate_limit_exceeded"
  }
}
```

**Решение**: Уменьшите частоту запросов или обратитесь в службу поддержки для увеличения лимита.

### 403 – Недостаточно баланса

```json
{
  "error": {
    "message": "Insufficient quota",
    "type": "insufficient_quota",
    "code": "insufficient_quota"
  }
}
```

**Решение**: Перейдите на [страницу пополнения](https://crazyrouter.com/console/topup) для внесения оплаты.

## Рекомендации по повторному запросу

- Для ошибки 429 рекомендуется использовать экспоненциальное отступление при повторных попытках
- Для ошибок 500/502/503 рекомендуется подождать несколько секунд и повторить запрос
- Для ошибок 400/401/403 проверьте параметры запроса и данные для аутентификации
