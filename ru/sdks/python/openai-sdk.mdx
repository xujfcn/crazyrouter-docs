## Официальный SDK OpenAI

```bash
pip install openai
```

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

# 同步调用
response = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "你好"}],
    temperature=0.7,
    max_tokens=1000
)
print(response.choices[0].message.content)
```

### Асинхронный вызов

```python
from openai import AsyncOpenAI
import asyncio

client = AsyncOpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

async def main():
    response = await client.chat.completions.create(
        model="gpt-5.5",
        messages=[{"role": "user", "content": "你好"}]
    )
    print(response.choices[0].message.content)

asyncio.run(main())
```

## Интеграция с LangChain

```bash
pip install langchain-openai
```

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-5.5",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1",
    temperature=0.7
)

# 简单调用
response = llm.invoke("用 Python 写一个快速排序")
print(response.content)
```

### Цепочный вызов LangChain

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

llm = ChatOpenAI(
    model="gpt-5.5",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个{role}。"),
    ("user", "{input}")
])

chain = prompt | llm
response = chain.invoke({"role": "Python 专家", "input": "解释装饰器"})
print(response.content)
```

### Встраивания LangChain

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-large",
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

vectors = embeddings.embed_documents(["文本一", "文本二"])
print(f"向量维度: {len(vectors[0])}")
```

## Интеграция с LlamaIndex

```bash
pip install llama-index-llms-openai llama-index-embeddings-openai
```

```python
from llama_index.llms.openai import OpenAI
from llama_index.embeddings.openai import OpenAIEmbedding

# LLM 配置
llm = OpenAI(
    model="gpt-5.5",
    api_key="sk-xxx",
    api_base="https://api.crazyrouter.com/v1"
)

response = llm.complete("什么是 RAG？")
print(response.text)

# Embedding 配置
embed_model = OpenAIEmbedding(
    model="text-embedding-3-large",
    api_key="sk-xxx",
    api_base="https://api.crazyrouter.com/v1"
)

vector = embed_model.get_text_embedding("测试文本")
print(f"维度: {len(vector)}")
```

<Note>
  Все приведённые выше примеры чата по умолчанию используют `gpt-5.5`, проверенный в рабочей среде 23 марта 2026 года. Если вы хотите заменить модель, сначала выберите также проверенную `claude-opus-4-8`; для примера Embedding используйте `text-embedding-3-large`.
</Note>
