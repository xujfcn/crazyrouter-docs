## Преобразование текста в речь (TTS)

```python
from openai import OpenAI

client = OpenAI(api_key="sk-xxx", base_url="https://api.crazyrouter.com/v1")

# 生成语音
response = client.audio.speech.create(
    model="tts-1",
    voice="alloy",
    input="你好，欢迎使用 Crazyrouter API 服务。"
)

# 保存为 MP3 文件
response.stream_to_file("output.mp3")
print("语音已保存到 output.mp3")
```

### Доступные голоса

| Голос | Особенности |
|------|------|
| `alloy` | Нейтральный, сбалансированный |
| `echo` | Мужской, солидный |
| `fable` | Мужской, тёплый |
| `onyx` | Мужской, глубокий |
| `nova` | Женский, живой |
| `shimmer` | Женский, мягкий |

### Высококачественный TTS

```python
# 使用 tts-1-hd 获得更高音质
response = client.audio.speech.create(
    model="tts-1-hd-1106",
    voice="nova",
    input="高质量语音合成示例",
    response_format="opus",  # 支持 mp3, opus, aac, flac
    speed=1.0  # 0.25 到 4.0
)

response.stream_to_file("output_hd.opus")
```

## Преобразование речи в текст (STT)

```python
# Whisper 语音识别
audio_file = open("recording.mp3", "rb")

transcript = client.audio.transcriptions.create(
    model="whisper-1",
    file=audio_file,
    language="zh"  # 可选，指定语言提高准确率
)

print(transcript.text)
```

### Расшифровка с временными метками

```python
transcript = client.audio.transcriptions.create(
    model="whisper-1",
    file=open("recording.mp3", "rb"),
    response_format="verbose_json",
    timestamp_granularities=["segment"]
)

for segment in transcript.segments:
    print(f"[{segment['start']:.1f}s - {segment['end']:.1f}s] {segment['text']}")
```

## Перевод речи

Перевод неанглийской речи в английский текст:

```python
audio_file = open("chinese_audio.mp3", "rb")

translation = client.audio.translations.create(
    model="whisper-1",
    file=audio_file
)

print(translation.text)  # 英文输出
```

<Note>
  Поддерживаемые TTS модели включают `tts-1`, `tts-1-hd-1106` и `tts-1`. Для STT используется модель `whisper-1`.
</Note>
