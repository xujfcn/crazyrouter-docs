## Установка

```bash
npm install openai
```

## Базовый диалог

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-xxx',
  baseURL: 'https://api.crazyrouter.com/v1',
});

async function main() {
  const response = await client.chat.completions.create({
    model: 'gpt-5.5',
    messages: [
      { role: 'system', content: '你是一个有帮助的助手。' },
      { role: 'user', content: '用一句话解释什么是 Node.js' },
    ],
  });

  console.log(response.choices[0].message.content);
}

main();
```

## Потоковый вывод

```javascript
async function streamChat() {
  const stream = await client.chat.completions.create({
    model: 'gpt-5.5',
    messages: [{ role: 'user', content: '写一首关于编程的诗' }],
    stream: true,
  });

  for await (const chunk of stream) {
    const content = chunk.choices[0]?.delta?.content || '';
    process.stdout.write(content);
  }
  console.log();
}

streamChat();
```

## Непрерывный диалог

```javascript
const messages = [
  { role: 'system', content: '你是一个 JavaScript 专家。' },
];

async function chat(userInput) {
  messages.push({ role: 'user', content: userInput });

  const response = await client.chat.completions.create({
    model: 'gpt-5.5',
    messages,
  });

  const reply = response.choices[0].message.content;
  messages.push({ role: 'assistant', content: reply });
  return reply;
}

async function main() {
  console.log(await chat('什么是 Promise？'));
  console.log(await chat('和 async/await 有什么区别？'));
}

main();
```

## Использование CommonJS

```javascript
const OpenAI = require('openai');

const client = new OpenAI({
  apiKey: 'sk-xxx',
  baseURL: 'https://api.crazyrouter.com/v1',
});

client.chat.completions
  .create({
    model: 'gpt-5.5',
    messages: [{ role: 'user', content: '你好' }],
  })
  .then((res) => console.log(res.choices[0].message.content));
```

<Note>
  В приведённых выше примерах по умолчанию используется `gpt-5.5`, успешно проверенный в рабочей среде 23 марта 2026 года. Если потребуется сменить модель, рекомендуется сначала выбрать также проверенные `claude-opus-4-8` или `gemini-3.1-pro`, затем при необходимости расширить для вашего сценария.
</Note>
