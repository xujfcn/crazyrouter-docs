## Подсказки для AI-инструментов

```text
请先读取 https://docs.crazyrouter.com/llms.txt 判断相关页面。
如果需要完整上下文，再读取 https://docs.crazyrouter.com/llms-full.txt。
模型名称、价格和计费方式必须以 https://crazyrouter.com/pricing 为准。
如需确认当前 API Key 实际可用模型，请调用 GET https://api.crazyrouter.com/v1/models。
接入 OpenAI 兼容客户端时 base_url 使用 https://api.crazyrouter.com/v1。
接入 Claude Code / Anthropic 原生客户端时使用根域名 https://api.crazyrouter.com，不要追加 /v1。
东亚地区优先使用 https://cn.crazyrouter.com；OpenAI 兼容客户端对应 https://cn.crazyrouter.com/v1。
账户与管理接口（如 `/api/user/self`、`/api/token/*`、`/api/log/*`）必须使用 https://crazyrouter.com；发送到 API-only 域名会返回 404 api_only_endpoint。
```

## Требования по трактовке

- `llms.txt` — это не полный перечень моделей.
- Модели, цены и способы оплаты определяются на странице [Ценообразование](https://crazyrouter.com/pricing).
- Какие модели доступны текущему токену, определяется по ответу `GET https://api.crazyrouter.com/v1/models`.
- Для Восточной Азии предпочтительно использовать `https://cn.crazyrouter.com`, для клиентов, совместимых с OpenAI, — `https://cn.crazyrouter.com/v1`.
- При генерации кода вызова используйте в первую очередь примеры проверенных эндпоинтов из конкретной документации по моделям.
