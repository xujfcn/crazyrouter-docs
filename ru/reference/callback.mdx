## Обзор

Для асинхронных задач (создание изображений в Midjourney, генерация видео и др.) Crazyrouter поддерживает уведомление об изменении статуса задачи через Webhook callback.

## Настройка URL для callback

При отправке задачи укажите адрес callback через параметр `notifyHook`:

```json
{
  "prompt": "a beautiful sunset",
  "notifyHook": "https://your-server.com/api/callback"
}
```

## Формат callback-запроса

Crazyrouter будет отправлять POST-запросы на ваш callback URL:

```
POST https://your-server.com/api/callback
Content-Type: application/json
```

### Callback для Midjourney

```json
{
  "id": "task_abc123",
  "action": "IMAGINE",
  "status": "SUCCESS",
  "prompt": "a beautiful sunset",
  "imageUrl": "https://cdn.example.com/image.png",
  "progress": "100%",
  "failReason": "",
  "submitTime": 1706000000000,
  "startTime": 1706000010000,
  "finishTime": 1706000060000
}
```

### Callback для генерации видео (Kling/Luma/Runway)

```json
{
  "id": "task_xyz789",
  "status": "succeed",
  "type": "video",
  "output": {
    "video_url": "https://cdn.example.com/video.mp4",
    "cover_url": "https://cdn.example.com/cover.jpg",
    "duration": 5.0
  },
  "created_at": 1706000000,
  "updated_at": 1706000120
}
```

## Смена статуса callback

```
提交 → NOT_START → IN_PROGRESS → SUCCESS / FAILURE
```

Каждое изменение статуса вызывает отдельный callback.

## Пример сервера для callback

<CodeGroup>

```python Python (Flask)
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route("/api/callback", methods=["POST"])
def callback():
    data = request.json
    task_id = data["id"]
    status = data["status"]

    print(f"任务 {task_id} 状态更新: {status}")

    if status == "SUCCESS":
        image_url = data.get("imageUrl")
        print(f"图片地址: {image_url}")

    return jsonify({"success": True})

app.run(port=8080)
```

```javascript Node.js (Express)
const express = require('express');
const app = express();
app.use(express.json());

app.post('/api/callback', (req, res) => {
  const { id, status, imageUrl } = req.body;
  console.log(`任务 ${id} 状态: ${status}`);

  if (status === 'SUCCESS') {
    console.log(`图片: ${imageUrl}`);
  }

  res.json({ success: true });
});

app.listen(8080);
```

</CodeGroup>

<Warning>
  Callback URL должен быть доступен из интернета. Убедитесь, что ваш сервер может принимать POST-запросы и возвращает статус-код 200 в течение 5 секунд.
</Warning>

<Note>
  В случае неудачи система повторит попытку до 3 раз, с интервалами 10 секунд, 30 секунд и 60 секунд соответственно.
</Note>
