# Руководство по подключению

На этой странице описаны только проверенные в рабочей среде Crazyrouter начальные пути `2026-03-23`.

Если вы хотите начать как можно быстрее, сначала выделите три способа подключения:

- Совместимость с OpenAI: `https://api.crazyrouter.com/v1`
- Нативный Anthropic: `https://api.crazyrouter.com`
- Нативный Gemini: `https://api.crazyrouter.com/v1beta/models/...`

## Принцип минимальной миграции

Для перехода с клиента совместимого с OpenAI на Crazyrouter, обычно нужно изменить только две вещи:

1. `base_url` заменить на `https://api.crazyrouter.com/v1`
2. `api_key` заменить на `sk-xxx` Crazyrouter

---

## Миграция с OpenAI

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "Hello"}],
    max_tokens=64
)
```

Подтверждено текущей проверкой в рабочей среде:

- `gpt-5.5` возвращает корректно через `/v1/chat/completions`
- Если вам нужно получить сводку reasoning или веб-поиск в стиле OpenAI, рекомендуется использовать `/v1/responses`

Связанные страницы:

- [Обзор Responses API](/ru/chat/responses/overview)
- [Режим мышления GPT-5](/ru/chat/responses/gpt5-thinking)

## Миграция с Anthropic

### Вариант A: Продолжать использовать слой совместимости с OpenAI

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="claude-opus-4-8",
    messages=[{"role": "user", "content": "Hello"}],
    max_tokens=64
)
```

### Вариант B: Использовать нативные Anthropic Messages

```python
import anthropic

client = anthropic.Anthropic(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com"
)

response = client.messages.create(
    model="claude-opus-4-8",
    max_tokens=128,
    messages=[{"role": "user", "content": "Hello"}]
)
```

Если вам нужно:

- Обычные диалоги Claude: рекомендуется `claude-opus-4-8`
- Явно требуется thinking block: рекомендуется `claude-opus-4-8`

Связанные страницы:

- [Нативный формат Claude](/ru/chat/anthropic/messages)

## Миграция с Gemini

### Вариант A: Слой совместимости с OpenAI

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="gemini-3.1-pro",
    messages=[{"role": "user", "content": "Hello"}],
    max_tokens=64
)
```

### Вариант B: Нативный Gemini

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "Hello"}
        ]
      }
    ]
  }'
```

Если вам нужно:

- Просто повторно использовать существующий SDK-код OpenAI: сначала используйте совместимый слой
- Необходим структурированный вывод, Google Search, thinking: рекомендуется использовать нативный Gemini

Связанные страницы:

- [Формат Gemini, совместимый с OpenAI](/ru/chat/gemini/openai-compat)

## Использование переменных среды

Если вы используете слой совместимости с OpenAI, рекомендуется сначала настроить:

<Tabs>
  <Tab title="Linux / macOS">
    ```bash
    export OPENAI_API_KEY=sk-xxx
    export OPENAI_BASE_URL=https://api.crazyrouter.com/v1
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    $env:OPENAI_API_KEY = "sk-xxx"
    $env:OPENAI_BASE_URL = "https://api.crazyrouter.com/v1"
    ```
  </Tab>
</Tabs>

Затем в коде можно напрямую использовать:

```python
from openai import OpenAI
client = OpenAI()
```

## Рекомендации для старта

| Цель | Рекомендуемый способ начала |
|------|--------------------|
| Самый быстрый доступ к GPT | Совместимость с OpenAI + `gpt-5.5` |
| Самый быстрый доступ к Claude | Нативный Anthropic + `claude-opus-4-8` |
| Самый быстрый доступ к Gemini | Совместимость с OpenAI или нативный Gemini + `gemini-3.1-pro` |
| Необходимы reasoning-сводки | Responses API |
| Нужен Claude thinking block | `claude-opus-4-8` |
| Нужен Gemini Google Search / thinking / responseSchema | Нативный Gemini |

<Note>
  Crazyrouter поддерживает три протокола: OpenAI, Anthropic и Gemini. Обычно более надёжно не "насильно использовать единый протокол для всех моделей", а выбирать наиболее подходящий вход в зависимости от возможностей.
</Note>
