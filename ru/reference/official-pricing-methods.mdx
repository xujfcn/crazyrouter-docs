# Официальные методы ценообразования моделей

В этой статье объясняются только официальные методы тарификации от производителей, что не эквивалентно реальным ценам продажи на Crazyrouter.

- Официальная тарификация: собственные методы тарификации производителя, такие как `input`, `output`, `cached input`, `tool call`, `search grounding`, `prompt caching` и другие
- Тарификация Crazyrouter: наши собственные цены, коэффициенты, скидки, различия по каналам и методы расчетов

<Note>
  На этой странице представлены сведения на основе официальной документации производителей, найденной по `2026-04-27`. Производители могут менять цены, а также корректировать правила предпросмотра моделей, длинного контекста, инструментов поиска и кэширования; перед запуском обязательно еще раз проверить по официальной ссылке.
</Note>

## Примеры официальных единичных цен

В приведенных примерах приведена только самая распространенная и легко сопоставимая с бюджетом бизнеса тарифная ступень для каждого производителя:

- Anthropic: стандартный тариф API, не включает множители `Fast mode`, `US-only inference` и скидки Batch
- OpenAI: тариф `Standard`, не включает надбавки за Batch, Priority, Regional Processing
- Gemini: тариф `Standard`, по умолчанию текст / изображение / видео на вход; для `Gemini 3*` берется уровень `<= 200K prompt`
- xAI: если внутреннее имя маршрута не имеет публично объявленной фиксированной цены, в таблице явно указано "не выделено отдельно"
- Z.AI: берётся официальная цена `Text Models`
- MiniMax: основная таблица — цена `Pay as You Go`, подписка — отдельная цена `Token Plan`

<Note>
  Если не отмечено иначе, суммы в таблице подразумеваются в `USD / 1M tokens`.
</Note>

## Anthropic

Официальная тарификация моделей Anthropic не ограничивается двумя колонками `input / output`, а делится так:

- `Base Input Tokens`
- `5m Cache Writes`
- `1h Cache Writes`
- `Cache Hits & Refreshes`
- `Output Tokens`

Также действуют два общих правила:

- `Batch API` ввод и вывод обычно по стандартной цене `Скидка 50%`
- Для кеширования prompt применяется правило публичных коэффициентов: `Запись в кэш за 5 минут = 1.25x ввод`, `Запись в кэш за 1 час = 2x ввод`, `Чтение из кэша = 0.1x ввод`

## OpenAI

## xAI Grok

У xAI тарифная политика фокусируется не на вопросе, есть ли отдельная цена за “thinking” модель, а на разделении цены инструментов и токенов:

- `Prompt tokens`
- `Cached prompt tokens`
- `Completion tokens`
- `Reasoning tokens`

xAI отдельно подчеркивает:

- `Reasoning tokens` оплачивается по `completion token price`
- `Web Search`, `X Search`, `Code Execution`, `Collections Search` и подобные серверные инструменты оплачиваются отдельно по `Каждые 1000 вызовов`
- `Batch API` для токенов обычно применяет `Скидка 50%`

| `grok-4.1-fast` | Внутренний роутинг reasoning; по официальному смыслу соответствует конфигурации Grok 4.1 `Thinking` | По официальным данным тарифицируются четыре типа токенов `prompt / cached prompt / completion / reasoning`, плюс при необходимости отдельная цена за вызов инструментов | Сейчас xAI на публичных страницах API акцентирует внимание на SKU типа `grok-4-1-fast-reasoning`; так что тут корректнее рассматривать «расчёт по официальной структуре тарификации reasoning-моделей xAI», а не трактовать внутреннее имя как отдельный SKU |

## Выводы

Если вам просто нужно быстро понять, «за что официально взимается плата», запомните эти типы:

- Anthropic: `base input + cache write/read + output`
- OpenAI: `input + cached input + output`, инструменты оплачиваются отдельно
- Gemini: `Многопроцессорный режим + ввод/вывод + кэширование + привязка к поиску/картам`
- xAI: `prompt/cached/completion/reasoning`, серверные инструменты отдельно
- Z.AI: `input + cached input + cached storage + output`
- MiniMax: `Токены по фактическому объёму` или `Лимит подписки`, обе схемы актуальны
