# Claude OpenAI-совместимый формат

```
POST /v1/chat/completions
```

По состоянию на 23 марта 2026 года производственная среда Crazyrouter подтверждает:

- `claude-opus-4-8` Нестриминговые запросы возвращают `object: "chat.completion"`
- `message` Текущая стабильная версия включает `role`, `content`
- Стриминговые запросы возвращают `chat.completion.chunk`
- SSE всё еще завершается `data: [DONE]`

<Warning>
Эта страница описывает стандартный путь диалога Claude в совместимом с OpenAI Chat Completions формате. Если вам нужен родной `tool_use` Claude, Claude Code или сценарии агентной разработки с использованием инструментов, используйте сначала [родной формат Claude](/ru/chat/anthropic/messages) для `POST /v1/messages`. Совместимый с OpenAI формат не гарантирует равноценную поддержку родных инструментальных блоков Claude.
</Warning>

---

## Нестриминговые запросы

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {"role": "system", "content": "You are a concise assistant."},
      {"role": "user", "content": "Compare PostgreSQL and MySQL in one paragraph."}
    ],
    "max_tokens": 256,
    "temperature": 0.2
  }'
```

Ключевые формы ответа:

```json
{
  "object": "chat.completion",
  "model": "claude-opus-4-8",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "PostgreSQL and MySQL are both popular..."
      }
    }
  ]
}
```

## Стриминговые запросы

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {"role": "user", "content": "Say hello in one sentence."}
    ],
    "max_tokens": 128,
    "stream": true
  }'
```

В производственном стриминговом пробном запуске от 2026-03-23, начальный фрагмент выглядит следующим образом:

```text
data: {"object":"chat.completion.chunk","model":"claude-opus-4-8","choices":[{"delta":{"role":"assistant"}}]}
data: {"object":"chat.completion.chunk","model":"claude-opus-4-8","choices":[{"delta":{"content":"Hello! ..."}}]}
data: [DONE]
```

<Note>
  Если вам нужен родной `thinking` Claude, родные инструментальные блоки или ввод документа, используйте сначала [Claude Messages](/ru/chat/anthropic/messages).
</Note>
