# Клауд Подсчет Токенов

```
POST /v1/messages/count_tokens
```

Используется для предварительной оценки того, сколько токенов будет потрачено на входную часть перед фактическим вызовом `POST /v1/messages`. Подходит для Claude CLI, Claude Code, контроля бюджета или логики обрезки контекста.

## Аутентификация

Рекомендуется использовать стиль заголовка запроса Anthropic:

```http
x-api-key: YOUR_API_KEY
anthropic-version: 2023-06-01
```

Можно также использовать стандартную Bearer аутентификацию, но клиенты из экосистемы Anthropic обычно передают вышеуказанный заголовок.

## Тело запроса

Тело запроса оформляется в стиле Claude Messages. Обычно минимально необходимые поля:

- `model`
- `messages`

Если в запросе есть `system`, `tools`, результаты инструментов или текстовое содержимое, они также будут учитываться при оценке.

## Пример запроса

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/v1/messages/count_tokens   -H "Content-Type: application/json"   -H "x-api-key: YOUR_API_KEY"   -H "anthropic-version: 2023-06-01"   -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {"role": "user", "content": "hello"}
    ]
  }'
```

```python Python
import requests

resp = requests.post(
    "https://api.crazyrouter.com/v1/messages/count_tokens",
    headers={
        "x-api-key": "YOUR_API_KEY",
        "anthropic-version": "2023-06-01",
        "Content-Type": "application/json",
    },
    json={
        "model": "claude-opus-4-8",
        "messages": [
            {"role": "user", "content": "hello"}
        ],
    },
)

print(resp.json())
```

</CodeGroup>

## Пример ответа

```json
{
  "input_tokens": 4
}
```

## Возвращаемые поля

| Поле | Тип | Описание |
|------|------|---------|
| `input_tokens` | integer | Оценка числа входных токенов текстовой части текущего запроса |
| `warning` | string | Дополнительное предупреждение; если запрос содержит изображения или файлы, то может быть указано, что такие данные не учтены в оценке |

## Ограничения

На данный момент оценка производится главным образом для:

- `system`
- Текстового содержимого `messages`
- Текст/JSON внутри инструментария и результатов инструментов

<Warning>
Если запрос содержит изображения или файлы, данный интерфейс не учитывает токены соответствующих изображений/файлов в `input_tokens`. В этом случае в ответе может появиться `warning`, а реальная стоимость будет выше предварительно рассчитанной.
</Warning>

<Note>
Данный интерфейс возвращает только предварительную оценку, а не итоговую расчетную величину. Фактическое использование определяется результатами вызова модели.
</Note>
