# Claude распознавание изображений

На 23 марта 2026 года в производственной среде Crazyrouter подтверждены два пути визуального ввода Claude:

- Нативный `POST /v1/messages` + `type: "image"` + Base64 PNG
- Совместимый с OpenAI `POST /v1/chat/completions` + `type: "image_url"` + data URL

---

## Нативный формат: `/v1/messages`

```bash
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 128,
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "image",
            "source": {
              "type": "base64",
              "media_type": "image/png",
              "data": "iVBORw0KGgoAAA..."
            }
          },
          {
            "type": "text",
            "text": "What color is this image?"
          }
        ]
      }
    ]
  }'
```

В рамках этой проверки производственной среды были возвращены:

- `model: "claude-opus-4-8"`
- `content[0].type = "text"`

---

## Формат, совместимый с OpenAI: `/v1/chat/completions`

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {
        "role": "user",
        "content": [
          {"type": "text", "text": "What color is this image?"},
          {
            "type": "image_url",
            "image_url": {
              "url": "data:image/png;base64,iVBORw0KGgoAAA..."
            }
          }
        ]
      }
    ],
    "max_tokens": 128
  }'
```

В производственной проверке 2026-03-23 модель возвращает `message.content` в виде обычной строки, содержащей текстовое описание цвета изображения.

<Note>
  На текущей странице сохраняются только два успешных визуальных входа: Base64 PNG / data URL. В этой итерации не проводилась повторная проверка удалённых URL, других форматов изображений и более сложных сцен с несколькими изображениями.
</Note>
