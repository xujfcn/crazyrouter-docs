# Поддержка Claude PDF

```
POST /v1/messages
```

По состоянию на 23 марта 2026 года на продакшене Crazyrouter подтверждено, что `claude-opus-4-8` может считывать PDF в формате Base64 с использованием родного Messages API и возвращать текстовую сводку.

---

## Минимальный подтверждённый запрос

```bash
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 512,
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "document",
            "source": {
              "type": "base64",
              "media_type": "application/pdf",
              "data": "JVBERi0xLjQK..."
            }
          },
          {
            "type": "text",
            "text": "Summarize the document in one sentence."
          }
        ]
      }
    ]
  }'
```

Ключевая форма фактического ответа продакшена:

```json
{
  "model": "claude-opus-4-8",
  "content": [
    {
      "type": "text",
      "text": "The document is a simple Crazyrouter PDF test document..."
    }
  ]
}
```

<Note>
  На текущей странице оставлен только успешно перепроверенный путь ввода через Base64 PDF. Более сложные сценарии, такие как удалённые URL, сравнение нескольких PDF, потоковый вывод PDF и другие, в этот цикл не проходили поэлементную перепроверку.
</Note>
