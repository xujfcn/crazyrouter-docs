# Нативный формат Claude

```
POST /v1/messages
```

На этой странице описаны варианты использования Claude Messages `2026-03-22`, которые были проверены в производственной среде Crazyrouter.

Текущие основные примеры моделей:

- `claude-opus-4-8`
- `claude-opus-4-8`

## Аутентификация

На этом этапе подтверждено, что оба следующих способа могут использоваться:

```text
x-api-key: YOUR_API_KEY
```

```text
Authorization: Bearer YOUR_API_KEY
```

Также сохраняется:

```text
anthropic-version: 2023-06-01
```

---

## Базовый диалог

```bash cURL
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 128,
    "messages": [
      {
        "role": "user",
        "content": "Explain quantum computing in one sentence."
      }
    ]
  }'
```

Ключевые структуры, возвращаемые в производственной среде:

```json
{
  "type": "message",
  "content": [
    {
      "type": "text",
      "text": "..."
    }
  ]
}
```

## Function Calling

В текущей производственной среде вызов инструментов Claude стабильно возвращает `/v1/messages` и `tool_use`.

Рекомендуемое поведение при первом совместном тестировании:

- Явным образом передавать `tool_choice`
- В промпте четко указывать "необходимо вызвать инструмент, не отвечать напрямую"

```bash cURL
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 256,
    "tools": [
      {
        "name": "get_time",
        "description": "Get the current time for a timezone",
        "input_schema": {
          "type": "object",
          "properties": {
            "timezone": {
              "type": "string"
            }
          },
          "required": ["timezone"]
        }
      }
    ],
    "tool_choice": {
      "type": "any"
    },
    "messages": [
      {
        "role": "user",
        "content": "Use the get_time tool for Asia/Shanghai. Do not answer directly."
      }
    ]
  }'
```

Ключевые поля, подтвержденные в производственной среде:

```json
{
  "stop_reason": "tool_use",
  "content": [
    {
      "type": "tool_use",
      "name": "get_time",
      "input": {
        "timezone": "Asia/Shanghai"
      }
    }
  ]
}
```

## Расширенное мышление

На этом этапе проверки в производственной среде явно подтверждено возвращение комбинации блока `thinking`:

- `claude-opus-4-8`

В базовой версии `claude-opus-4-8` в этом цикле явный thinking block не был получен, поэтому здесь преимущественно описаны thinking способности.

```bash cURL
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 320,
    "thinking": {
      "type": "enabled",
      "budget_tokens": 128
    },
    "messages": [
      {
        "role": "user",
        "content": "Which is larger, 9.11 or 9.9? Explain briefly."
      }
    ]
  }'
```

Ключевые поля возращаемые при подтверждении в производственной среде:

```json
{
  "content": [
    {
      "type": "thinking",
      "thinking": "..."
    },
    {
      "type": "text",
      "text": "..."
    }
  ]
}
```

<Warning>
  При использовании `thinking`, `max_tokens` должен быть больше `budget_tokens`. Токены размышлений также учитываются в стоимости.
</Warning>
