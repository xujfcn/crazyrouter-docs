# Вызов функций Ответов

```
POST /v1/responses
```

По состоянию на 23 марта 2026 года в промышленной эксплуатации Crazyrouter подтверждено, что `gpt-5.5` в API Ответов стабильно возвращает `function_call`.

<Note>
  Claude сейчас не поддерживает `POST /v1/responses`. Если вам нужна активация инструментов Claude, используйте `POST /v1/messages` или `POST /v1/chat/completions`.
</Note>

---

## Шаг 1: Позвольте модели сгенерировать вызов функции

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "What is the weather in Beijing? Use the tool.",
    "tools": [
      {
        "type": "function",
        "name": "get_weather",
        "description": "Get weather info for a city",
        "parameters": {
          "type": "object",
          "properties": {
            "city": {"type": "string"}
          },
          "required": ["city"],
          "additionalProperties": false
        }
      }
    ]
  }'
```

Тип производственного ответа, наблюдаемый:

```json
{
  "output": [
    {
      "type": "function_call",
      "name": "get_weather",
      "arguments": "{\"city\":\"Beijing\"}"
    }
  ]
}
```

---

## Шаг 2: Вернуть результат инструмента

Как только вы получите `function_call`, отправьте фактический результат активации инструмента обратно как `function_call_output`:

```json
{
  "model": "gpt-5.5",
  "input": [
    {
      "type": "function_call",
      "call_id": "call_123",
      "name": "get_weather",
      "arguments": "{\"city\":\"Beijing\"}"
    },
    {
      "type": "function_call_output",
      "call_id": "call_123",
      "output": "{\"temperature\":22,\"condition\":\"sunny\"}"
    }
  ],
  "tools": [
    {
      "type": "function",
      "name": "get_weather",
      "description": "Get weather info for a city",
      "parameters": {
        "type": "object",
        "properties": {
          "city": {"type": "string"}
        },
        "required": ["city"],
        "additionalProperties": false
      }
    }
  ]
}
```

<Note>
  Эта страница сохраняет только путь `function_call`, который был воспроизведён на производстве. Для более сложных цепочек инструментов или потоковых изменений аргументов повторно проверьте их в тот же день перед тем, как использовать.
</Note>
