# Создать ответ

```
POST /v1/responses
```

На 23 марта 2026 года в Crazyrouter production подтверждено:

- `gpt-5.5` возвращает `object: "response"`
- простые текстовые запросы в настоящее время возвращают `output` элементов типа `message`
- потоковые запросы стабильно показывают `response.created`, `response.in_progress`, `response.output_item.added`, `response.content_part.added` и `response.output_text.delta`

<Note>
  Claude в настоящее время не поддерживает `POST /v1/responses`. Используйте `POST /v1/messages` или `POST /v1/chat/completions` для Claude вместо этого.
</Note>

---

## Простой запрос

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Explain what an API is in one sentence."
  }'
```

Наблюдаемая форма ответа в production:

```json
{
  "object": "response",
  "model": "gpt-5.5",
  "output": [
    {
      "type": "message"
    }
  ]
}
```

---

## Потоковый запрос

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Say hello in one sentence.",
    "stream": true
  }'
```

Проба потокового режима в production 23.03.2026 показала следующую последовательность открывающих событий:

```text
event: response.created
event: response.in_progress
event: response.output_item.added
event: response.content_part.added
event: response.output_text.delta
```

Таким образом, самая безопасная текущая стратегия потребителя:

1. аккумулировать текст из `response.output_text.delta`
2. рассматривать `response.completed` или завершение потока как сигнал окончания
