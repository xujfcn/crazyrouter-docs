# Поиск в вебе по ответам

```
POST /v1/responses
```

По состоянию на 23 марта 2026 года в продакшене Crazyrouter подтверждена `gpt-5.5` в API ответов с использованием:

- `tools: [{ "type": "web_search_preview" }]`
- последовательности `output` из `web_search_call`, затем `message`

<Note>
  В настоящее время Claude не поддерживает `POST /v1/responses`. Для веб-поиска Claude используйте `POST /v1/chat/completions` или нативный путь Claude.
</Note>

---

## Минимальный запрос

```bash
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Find one AI news item from March 2026.",
    "tools": [
      {
        "type": "web_search_preview"
      }
    ]
  }'
```

Фактический формат ответа в продакшене:

```json
{
  "output": [
    {
      "type": "web_search_call"
    },
    {
      "type": "message"
    }
  ]
}
```

## Текущее правило проверки

Если необходимо убедиться, что модель действительно совершила поиск в интернете, самые надежные текущие проверки:

- присутствие `web_search_call` в `output`
- получение итогового ответа в виде `message`

<Warning>
  Эта страница больше не хранит устаревшие примеры и не документирует непереосвидетельствованные параметры поиска как основной путь.
</Warning>
