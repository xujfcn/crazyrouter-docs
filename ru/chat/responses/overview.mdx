# Обзор API Responses

Responses API в настоящее время является одним из основных маршрутов для новых возможностей GPT на Crazyrouter.

На этой странице документируются только те выводы, которые были перепроверены на продакшн среде `2026-03-22`.

<Note>
  В текущем рабочем объёме с подтверждённой поддержкой, Claude поддерживает только `POST /v1/messages` и `POST /v1/chat/completions`, но не `POST /v1/responses`. Страницы с описанием Responses рассматривайте в первую очередь как рекомендации по GPT.
</Note>

## Текущий подход

- Если вам нужен выход с возможностью проверки рассуждений, выбирайте `/v1/responses`
- Если вам нужен веб-поиск в стиле OpenAI, выбирайте `/v1/responses`
- Если вам нужен только обычный чат либо необходимо сохранить текущую интеграцию, `/v1/chat/completions` по-прежнему подходит

## Responses API против Chat Completions API

| Параметр | Responses API | Chat Completions API |
|-----------|---------------|----------------------|
| Endpoint | `/v1/responses` | `/v1/chat/completions` |
| Формат входных данных | `input` | `messages` |
| Формат выходных данных | список элементов `output[]` | `choices[].message` |
| Рассуждения GPT | Проверенный элемент `reasoning` | `reasoning_effort` работает, но `reasoning_content` нестабилен |
| Веб-поиск в стиле OpenAI | Проверенный путь `web_search_preview` | Старая форма `web_search` не обеспечивала стабильного и проверяемого срабатывания в этом цикле |
| Streaming | Более насыщенные типы событий | Традиционный delta SSE |

## Минимально полезный пример

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.responses.create(
    model="gpt-5.5",
    input="Explain what a REST API is in one sentence."
)

print(response.output_text)
```

В ходе текущей перепроверки на продакшне подобный минимальный запрос вернул:

```json
{
  "object": "response",
  "output": [
    {
      "type": "message"
    }
  ]
}
```

## Когда отдать предпочтение Responses

- Вам нужны сводки рассуждений `gpt-5.5`
- Вам нужно проверить, сработала ли модель реально по `web_search_call`
- Вы хотите более насыщенные события SSE

## Когда оставить Chat Completions

- У вас уже интегрирован стабильный интерфейс Chat Completions
- Вас интересует только итоговый ответ, а не элемент `reasoning`
- Вы интегрируете Claude, Gemini или другие модели, совместимые с OpenAI

<Note>
  Оба API могут работать параллельно в одном проекте. На практике чаще оказывается полезнее не полная миграция, а перенос только тех запросов, которым требуются новые возможности, на `/v1/responses`.
</Note>
