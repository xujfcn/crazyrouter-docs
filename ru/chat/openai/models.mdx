# Перечислить модели

```
GET /v1/models
```

Возвращает список моделей, доступных для текущего API Key.

На этой странице документации описаны только действия, которые `2026-04-14` уже прошли проверку в производственной среде Crazyrouter.

## Аутентификация

```text
Authorization: Bearer YOUR_API_KEY
```

## Пример запроса

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

models = client.models.list()

for model in models.data:
    print(model.id)
```

```javascript Node.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.crazyrouter.com/v1",
});

const models = await client.models.list();

for (const model of models.data) {
  console.log(model.id);
}
```

</CodeGroup>

## Часто используемые поля

| Поле | Тип | Описание |
|------|------|------|
| `success` | boolean | Успешен ли запрос |
| `id` | string | Идентификатор модели, переданный при вызове API |
| `object` | string | Всегда равно `model` |
| `created` | integer | Метка времени |
| `owned_by` | string | Идентификатор организации или источника модели |

## Информация о ценах

Если вам нужна публичная информация о тарифах, ориентируйтесь на [страницу Pricing](https://crazyrouter.com/ru/pricing). Для программной проверки моделей, видимых текущему токену, используйте `GET /v1/models` с этой страницы.

<Note>
  `GET /v1/models` возвращает `supported_endpoint_types` только для указания поддерживаемого интерфейсного стиля конкретной модели. При этом `openai` соответствует `POST /v1/chat/completions`, `anthropic` соответствует `POST /v1/messages`, и только `openai-response` соответствует `POST /v1/responses`. На данный момент Claude поддерживает только `openai` + `anthropic`, не поддерживает `openai-response`.
</Note>
