# Модель Grok

```
POST /v1/chat/completions
```

Текстовая модель Grok вызывается в формате, совместимом с OpenAI Chat Completions. Вам просто нужно указать `base_url` на Crazyrouter и вписать ID модели Grok в `model`.

<Note>
  Доступность моделей зависит от канала, разрешений токена и настроек страницы pricing. Перед запуском рекомендуется использовать `GET /v1/models` для проверки, может ли ваш текущий API Key увидеть целевую модель.
</Note>

## Популярные модели

Ниже представлены распространённые записи для текстовых моделей Grok:

| Модель | Описание |
|------|------|
| `grok-4` | Основная модель Grok 4 |
| `grok-4-fast` | Вариант Grok 4 fast |
| `grok-4-fast-non-reasoning` | Grok 4 fast без рассуждений |
| `grok-4-fast-reasoning` | Grok 4 fast с рассуждениями |
| `grok-4.1` | Grok 4.1 |
| `grok-4.1-fast` | Grok 4.1 fast |
| `grok-4.1-fast` | Grok 4.1 thinking |
| `grok-4.1-fast` | Grok 4.2 |
| `grok-4-0709` | Версия Grok 4 с датой |

<Warning>
  Старые серии `grok-4` / `grok-4.1` могут использоваться в исторических вызовах или совместимых настройках, но актуальная публичная ценовая политика включает в основном серию `grok-4*`. При новом подключении рекомендуем выбирать `grok-4`, `grok-4.1`, `grok-4.1-fast` или варианты fast/reasoning.
</Warning>

## Минимальный запрос

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "grok-4",
    "messages": [
      {
        "role": "user",
        "content": "Reply with one short sentence: what is Grok?"
      }
    ],
    "temperature": 0.7,
    "max_tokens": 120
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.chat.completions.create(
    model="grok-4",
    messages=[
        {"role": "user", "content": "Reply with one short sentence: what is Grok?"}
    ],
    temperature=0.7,
    max_tokens=120,
)

print(response.choices[0].message.content)
```

```javascript Node.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.crazyrouter.com/v1",
});

const response = await client.chat.completions.create({
  model: "grok-4",
  messages: [
    { role: "user", content: "Reply with one short sentence: what is Grok?" },
  ],
  temperature: 0.7,
  max_tokens: 120,
});

console.log(response.choices[0].message.content);
```

</CodeGroup>

## Потоковый вывод

Для использования SSE потокового вывода, задайте `stream: true`.

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "grok-4-fast",
    "stream": true,
    "messages": [
      {
        "role": "user",
        "content": "Write a concise API migration checklist."
      }
    ]
  }'
```

## Варианты reasoning

Для моделей Grok с названиями, содержащими `reasoning` или `thinking`, рекомендуется оставлять параметры запроса простыми:

```json
{
  "model": "grok-4-fast-reasoning",
  "messages": [
    {
      "role": "user",
      "content": "Compare two implementation options and explain the tradeoffs."
    }
  ],
  "max_tokens": 800
}
```

<Note>
  Поддержка reasoning, поиска или экспериментальных параметров может отличаться для разных каналов. Для стабильного подключения через разные каналы используйте стандартные поля OpenAI Chat: `model`, `messages`, `temperature`, `top_p`, `max_tokens`, `stream`.
</Note>
