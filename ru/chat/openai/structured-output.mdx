# Структурированные выводы

```
POST /v1/chat/completions
```

По состоянию на 23 марта 2026 года, в рабочей среде Crazyrouter подтверждено, что `gpt-5.5` с `response_format.type = "json_schema"` возвращает JSON, который можно непосредственно разобрать.

---

## Рекомендуемый путь: `json_schema`

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Return the people and roles from: Alice is CTO. Bob is PM."
      }
    ],
    "response_format": {
      "type": "json_schema",
      "json_schema": {
        "name": "people_roles",
        "strict": true,
        "schema": {
          "type": "object",
          "properties": {
            "people": {
              "type": "array",
              "items": {
                "type": "object",
                "properties": {
                  "name": {"type": "string"},
                  "role": {"type": "string"}
                },
                "required": ["name", "role"],
                "additionalProperties": false
              }
            }
          },
          "required": ["people"],
          "additionalProperties": false
        }
      }
    }
  }'
```

Наблюдаемый в рабочей среде `message.content` непосредственно интерпретировался как:

```json
{
  "people": [
    {
      "name": "Alice",
      "role": "CTO"
    },
    {
      "name": "Bob",
      "role": "PM"
    }
  ]
}
```

---

## Обработка на стороне пользователя

```python
import json

content = response["choices"][0]["message"]["content"]
data = json.loads(content)
```

<Note>
  На этом продакшн-этапе повторно была подтверждена только строгая схема `json_schema`. Старый режим `json_object` отдельно не перепроверялся, поэтому больше не приводится здесь в качестве основного примера.
</Note>
