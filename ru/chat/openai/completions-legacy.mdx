# Создание завершения (Legacy)

```
POST /v1/completions
```

<Warning>
  Это совместимый endpoint, не основной рекомендованный путь. Для новых интеграций предпочитайте `/v1/chat/completions` или `/v1/responses`.
</Warning>

## Текущий статус в производстве

По состоянию на 23 марта 2026 года, в production Crazyrouter подтверждено:

- Маршрут все еще существует
- При отправке запросов с классической моделью `gpt-5-mini` возвращается `503`
- Код ошибки: `model_not_found`
- Сообщение об ошибке: «temporarily unavailable»

То есть, данный endpoint сейчас больше подходит для «проверки совместимости старого клиента по необходимости», но не для новых интеграций по умолчанию.

---

## Актуальные рекомендации

1. Для новых проектов используйте [`Chat Completions`](/ru/chat/openai/completions)
2. Для использования GPT-5 reasoning, Web Search и других новых возможностей — перейдите к [`Responses`](/ru/chat/responses/overview)
3. Используйте `/v1/completions` только если у вас есть старый клиент и legacy-модель действительно работает в текущей среде

---

## Шаблон для повторной проверки

Если нужно убедиться, что старая модель еще поддерживается этим endpoint, сначала рекомендуем проверить ID модели через [`/v1/models`](/ru/chat/openai/models), затем отправить минимальный запрос:

```bash
curl https://api.crazyrouter.com/v1/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "YOUR_LEGACY_MODEL",
    "prompt": "Say hello in three words.",
    "max_tokens": 16
  }'
```

Пример реальной ошибки в текущей production среде:

```json
{
  "error": {
    "code": "model_not_found",
    "message": "Model gpt-5-mini is temporarily unavailable",
    "type": "new_api_error"
  }
}
```
