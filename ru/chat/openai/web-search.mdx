# Веб-поиск

На этой странице документируется только поведение веб-поиска в стиле OpenAI, проверенное на Crazyrouter production для `2026-03-22`.

Текущий основной путь:

- `gpt-5.5`
- `POST /v1/responses`
- `tools: [{ "type": "web_search_preview" }]`

## Текущий вывод

В сегодняшней проверке в production:

- `gpt-5.5` через API Responses устойчиво возвращал `web_search_call`
- более старый тест Chat Completions с использованием `tools: [{ "type": "web_search" }]` возвращал `200`, но не предоставлял стабильный, проверяемый сигнал запуска поиска, поэтому он не используется как основная документированная схема

---

## Проверенный запрос

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Use web search to find one current technology headline published recently.",
    "tools": [
      {
        "type": "web_search_preview"
      }
    ]
  }'
```

Проверенные значения `output.type`:

```json
["web_search_call", "message"]
```

Это показывает, что шаг поиска и окончательный ответ возвращаются отдельно.

---

## Пример на Python

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.responses.create(
    model="gpt-5.5",
    input="Use web search to find one current technology headline published recently.",
    tools=[
        {"type": "web_search_preview"}
    ]
)

print(response.output_text)
```

---

## Как подтвердить, что поиск действительно выполнялся

Проверьте непосредственно `response.output`:

```python Python
for item in response.output:
    print(item.type)
```

Если вы видите:

```text
web_search_call
message
```

то модель сначала выполняла поиск, а затем отвечала.

---

## Старая схема, не рекомендуемая в качестве основной

В этой проверке production также был протестирован более старый формат Chat Completions:

```json
{
  "tools": [
    {
      "type": "web_search"
    }
  ]
}
```

Результат:

- запрос вернул `200`
- но не был обнаружен стабильный, проверяемый маркер запуска поиска

Поэтому для документации Crazyrouter веб-поиск в стиле OpenAI в настоящее время следует описывать через API Responses в первую очередь.
