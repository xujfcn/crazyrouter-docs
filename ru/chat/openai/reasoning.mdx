# Модели рассуждения

На этой странице документируется только такое поведение рассуждающих моделей, которое было перепроверено в продакшне Crazyrouter на `2026-03-22`.

Для интеграций, совместимых с OpenAI, актуальные рекомендации:

- Если вам нужно лишь усиленное рассуждение и требуется только итоговый ответ, используйте Chat Completions с `reasoning_effort`
- Если необходим стабильный, проверяемый результат рассуждения, предпочтительнее использовать Responses API и ознакомиться с [Режим мышления GPT-5](/ru/chat/responses/gpt5-thinking)

## Проверенные комбинации

| Маршрут | Модель | Параметр запроса | Текущее поведение в продакшне |
|---------|--------|------------------|-------------------------------|
| Chat Completions | `gpt-5.5` | `reasoning_effort` | Запрос выполняется успешно и возвращает итоговый ответ |
| Responses | `gpt-5.5` | `reasoning.effort` / `reasoning.summary` | `output` включает элементы `reasoning` и `message` |

## Chat Completions: `reasoning_effort`

Следующий формат запроса сейчас работает в продакшне:

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Which is larger, 9.11 or 9.9? Explain briefly."
      }
    ],
    "reasoning_effort": "high",
    "max_tokens": 120
  }'
```

Доступные значения `reasoning_effort`:

| Значение | Значение (описание) |
|----------|---------------------|
| `low` | Более быстрый ответ для простых задач |
| `medium` | Сбалансированная настройка по умолчанию |
| `high` | Больше рассуждения для сложных задач |

### Текущее поведение ответа

В ходе перепроверки на продакшне `2026-03-22`:

- запрос был выполнен успешно
- итоговый ответ был возвращен в `message.content`
- `message.reasoning_content` не всегда содержал пригодимый контент

Поэтому, если вам нужно только усиленное рассуждение, Chat Completions с `reasoning_effort` все еще можно использовать. Если требуется явно видимое поле с резюме рассуждения, не используйте Chat Completions в качестве основного варианта.

## Когда нужен проверяемый вывод рассуждения

Более надежный продакшен-путь — это Responses API:

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Which is larger, 9.11 or 9.9? Explain briefly.",
    "reasoning": {
      "effort": "high",
      "summary": "detailed"
    }
  }'
```

Проверенные значения `output.type`:

```json
["reasoning", "message"]
```

Для информации о конкретных форматах ответов, полях-резюме и названиях событий для стриминга см.:

- [Режим мышления GPT-5](/ru/chat/responses/gpt5-thinking)
- [Поля мыслительного AI](/ru/reference/thinking)

## Актуальная рекомендация

- Для новых сборок, где нужно вести журнал или отображать резюме рассуждений, начинайте с Responses API
- Для существующих интеграций Chat Completions, в которых важен только итоговый ответ, `reasoning_effort` все еще остается валидным выбором
- Не предполагается, что все совместимые с OpenAI модели рассуждения гарантированно будут возвращать `reasoning_content`

<Warning>
  Запросы на рассуждение обычно увеличивают задержку и расход токенов. Более высокий `reasoning_effort` обычно стоит дороже.
</Warning>
