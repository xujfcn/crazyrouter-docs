# Чат-распознавание изображений

```
POST /v1/chat/completions
```

В рабочей среде Crazyrouter подтверждена поддержка распространённых моделей с вводом в стиле OpenAI (`image_url`):

- Визуальные модели OpenAI, такие как `gpt-4o`, `gpt-4o-mini`, `gpt-5.5`, `gpt-5.5` и др.
- На входе поддерживаются 2 формата: data URL (`data:image/...;base64,...`) и публичный URL (`https://`)
- Ответ `message.content` на данный момент — обычная строка

> Рекомендуемый порядок: сначала используйте [интерфейс загрузки изображения](/ru/upload) для преобразования локальных файлов в временный URL (`media.crazyrouter.com`), затем отправляйте в `image_url`; либо отправьте сразу data URL в base64. Также допускаются удалённые публичные URL, но для них действуют ограничения, описанные ниже в разделе «Ограничения для удалённых URL».

---

## Использование base64 data URL (самый надёжный способ)

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": [
          {"type": "text", "text": "What color is this image?"},
          {
            "type": "image_url",
            "image_url": {
              "url": "data:image/png;base64,iVBORw0KGgoAAA..."
            }
          }
        ]
      }
    ],
    "max_tokens": 100
  }'
```

Пример ответа:

```json
{
  "model": "gpt-4o-mini",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "Red."
      }
    }
  ]
}
```

## Использование удалённого https URL

```bash
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": [
          {"type": "text", "text": "Describe in 5 words."},
          {
            "type": "image_url",
            "image_url": {
              "url": "https://www.gstatic.com/webp/gallery/1.jpg"
            }
          }
        ]
      }
    ],
    "max_tokens": 40
  }'
```

### Ограничения для удалённых URL

URL должен быть **доступен с серверной стороны Crazyrouter** ― возможность открыть его только в браузере недостаточна. Основные причины неудач:

| Сценарий ошибки | Причина | Решение |
|----------------|--------|---------|
| Не разрешается домен | Приватный адрес, ошибка написания | Используйте публичный https URL |
| 403 Forbidden | Часть CDN (например, wikimedia или приватные S3) ограничивает User-Agent/Referer на стороне сервера | Используйте [интерфейс загрузки изображения](/ru/upload) или base64 |
| Content-Type не `image/*` | URL возвращает HTML или перенаправляет на страницу входа | Убедитесь, что URL ведёт на прямую ссылку для скачивания |
| Размер файла больше 20MB | Ограничение на размер одиночного файла | Сожмите или обрежьте перед загрузкой |

Если вы видите сообщение об ошибке `Unable to process the image you provided. Please verify the image URL is publicly accessible, or upload it as base64.`, это означает, что URL недоступен с сервера — проверьте по таблице выше.

## Рекомендации по использованию

- Внутренние ресурсы, приватные либо сомнительные на доступность изображения: сначала вызовите [`POST /v1/files/uploads`](/ru/upload), чтобы получить временный 72-часовой URL (`media.crazyrouter.com/...`), затем передавайте в `image_url`
- Маленькие (< 1MB) или одноразовые изображения: сразу используйте base64 data URL — это избавит от лишнего запроса на загрузку
- Расширенное использование, например, работа с несколькими изображениями, параметры `detail` и пр.: сейчас такие сценарии поддерживаются OpenAI и работают по официальному протоколу OpenAI
