# Объект Chat Completion

`/v1/chat/completions` возвращает `chat.completion` для нестриминговых запросов и `chat.completion.chunk` для стриминговых запросов.

На этой странице представлен самый стабильный и широко используемый совместимый с OpenAI формат ответа Crazyrouter на сегодняшний день.

## Нестриминговый объект

Минимальный рабочий запрос:

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Explain what a REST API is in one sentence."
      }
    ],
    "max_tokens": 64
  }'
```

Типовой скелет производственного ответа:

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "created": 1774177466,
  "model": "gpt-5.5",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "...",
        "reasoning_content": null,
        "tool_calls": null
      },
      "finish_reason": "stop"
    }
  ]
}
```

### Как читать

- `message.content` — это финальный текстовый ответ
- `message.tool_calls` появляется только когда модель запрашивает выполнение инструмента
- `message.reasoning_content` может появляться у некоторых моделей или маршрутов, но пока не стоит рассматривать это как гарантированное поле

## Стриминговый объект

Для стриминговых запросов сервер возвращает события SSE `chat.completion.chunk`:

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion.chunk",
  "created": 1774177466,
  "model": "gpt-5.5",
  "choices": [
    {
      "index": 0,
      "delta": {
        "role": "assistant",
        "content": "..."
      },
      "finish_reason": null
    }
  ]
}
```

Общая форма SSE:

```text
data: {"object":"chat.completion.chunk",...}
data: {"choices":[{"delta":{"content":"..."}}],...}
data: [DONE]
```

---

## Поля, которые обычно важны

| Поле | Значение |
|-------|----------|
| `object` | `chat.completion` для нестриминговых, `chat.completion.chunk` для стриминговых |
| `model` | Используемая модель для ответа |
| `choices[].message.content` | Финальный нестриминговый текст |
| `choices[].message.tool_calls` | Нестриминговые запросы инструментов |
| `choices[].delta.content` | Дельта стримингового текста |
| `choices[].finish_reason` | Причина остановки, такая как `stop`, `length` или `tool_calls` |

<Note>
  Входные модели могут передавать дополнительные поля. Клиентский код должен ориентироваться на стабильные общие поля, а не предполагать, что каждая модель поддерживает одинаковые расширения.
</Note>
