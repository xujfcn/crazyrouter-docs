# Специальные модели (временно скрыто)

В настоящее время исторические страницы специальных моделей больше не демонстрируются как публичные примеры API. Для нового подключения используйте:

- [Примеры использования новейших моделей](/ru/latest-model-examples)
- [Список моделей](/ru/chat/openai/models)
- [Завершения чата](/ru/chat/openai/completions)

<Note>
  Перед использованием в производственной среде, пожалуйста, сначала вызовите `GET /v1/models` для подтверждения ID моделей, доступных вашему текущему токену. Модели, которые отсутствуют в публичном индексе или недоступны с текущим токеном, не следует добавлять в конфигурацию по умолчанию или в примеры.
</Note>
