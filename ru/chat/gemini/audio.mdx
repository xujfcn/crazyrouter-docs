# Gemini аудио понимание

```text
POST /v1beta/models/{model}:generateContent
```

По состоянию на `2026-04-08`, повторная проверка локальных портов Crazyrouter и `4000` показала:

- `gemini-3.1-pro` может читать `audio/wav`
- В настоящее время стабильно работает основная цепочка `inlineData`
- Для коротких аудио-файлов транскрибирование, определение языка и создание коротких аннотаций можно выполнить напрямую через текстовые подсказки

---

## Проверенный минимальный запрос

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "inlineData": {
              "mimeType": "audio/wav",
              "data": "BASE64_WAV_DATA"
            }
          },
          {
            "text": "请返回 JSON，字段为 transcript、language、summary。"
          }
        ]
      }
    ],
    "generationConfig": {
      "maxOutputTokens": 512
    }
  }'
```

Ключевые характеристики успешных ответов в производственной среде:

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "```json\n{\n  \"transcript\": \"叮\",\n  \"language\": \"zh-CN\",\n  \"summary\": \"音频中包含一个简短的提示音。\"\n}\n```"
          }
        ]
      }
    }
  ]
}
```

## Основные моменты запроса

- Для понимания аудио рекомендуется использовать `inlineData`
- `mimeType` должен совпадать с реальным аудио-форматом, например `audio/wav`, `audio/mpeg`
- В `data` вводите только содержимое Base64, без префикса Data URL
- Если вам необходим строгий JSON, можете дополнительно использовать ограничение [структурированный вывод](/ru/features/structured-outputs)

<Note>
  На текущей странице описан основной путь для успешного понимания коротких аудио. Для транскрипции более длинных аудио и генерации речи смотрите страницы существующих [STT](/ru/audio/stt) и [TTS](/ru/audio/tts); Realtime пока не представлен как открытый рекомендованный пример.
</Note>
