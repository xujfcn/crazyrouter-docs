# Генерация изображений Gemini

```
POST /v1/images/generations
```

Crazyrouter предоставляет унифицированный совместимый с OpenAI Images интерфейс для модели изображений Gemini. На стороне пользователя не требуется напрямую вызывать нативный `generateContent` Gemini, а также не требуется передавать нативный `generationConfig.imageConfig` Gemini.

| Рекомендованное публичное имя модели | Совместимое имя базовой модели |
|------|------|
| `nano-banana` | `nano-banana` |
| `nano-banana-pro` | `nano-banana-pro` |
| `nano-banana-2` | `nano-banana-2` |

<Warning>
  Генерация изображений Gemini — это длительный по времени запрос. Для продакшн-интеграций рекомендуется использовать основную линию `https://api.crazyrouter.com/v1`, полный генерирующий endpoint — `https://api.crazyrouter.com/v1/images/generations`.
</Warning>

<Note>
  Рекомендуется использовать в клиентском коде `nano-banana`, `nano-banana-pro`, `nano-banana-2`. Если ваша система уже использует напрямую `nano-banana`, `nano-banana-pro`, `nano-banana-2`, вы также можете продолжать обращаться через этот же интерфейс Images API.
</Note>

## Параметры запроса

| Параметр | Тип | Обязателен | Описание |
|------|------|------|------|
| `model` | string | Да | `nano-banana`, `nano-banana-pro`, `nano-banana-2` или соответствующее canonical-имя Gemini |
| `prompt` | string | Да | Инструкция на генерацию или редактирование |
| `image_input` | string или string[] | Нет | URL референс-изображения; если не передан, работает генерация с текстового описания |
| `resolution` | string | Нет | `1K`, `2K`, `4K` |
| `aspect_ratio` | string | Нет | Например, `1:1`, `16:9`, `9:16`, `21:9`, `auto` |
| `output_format` | string | Нет | `png`, `jpeg` / `jpg` |
| `output_compression` | integer | Нет | `0-100`, используется для настройки качества сжатия JPEG |
| `n` | integer | Нет | Количество генерируемых изображений, по умолчанию `1` |

Не передавайте эти приватные поля апстрима: `generationConfig`, `imageConfig`, `imageOutputOptions`, `image_output_options`.

## Пример запроса

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-2",
    "prompt": "A simple red square on a white background, clean vector style",
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "png"
  }'
```

Ответ соответствует формату OpenAI Images:

```json
{
  "created": 1778990000,
  "data": [
    {
      "url": "https://media.crazyrouter.com/task-artifacts/2026/05/17/sync-image/request-id-1.png"
    }
  ]
}
```

## Редактирование по референс-изображению

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-pro",
    "prompt": "把参考图改成高级电商海报，保留主体，背景更简洁",
    "image_input": [
      "https://example.com/reference.png"
    ],
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "jpeg",
    "output_compression": 85
  }'
```

<Note>
  Если вам действительно необходим оригинальный формат Gemini API, ознакомьтесь с [оригинальным форматом Gemini](/ru/chat/gemini/native). Но для генерации и редактирования изображений рекомендуется клиентской стороне использовать унифицированный Images API с этой страницы.
</Note>
