# Gemini Понимание документации

```
POST /v1beta/models/{model}:generateContent
```

На 23 марта 2026 года в производственной среде Crazyrouter подтверждена поддержка `gemini-3.1-pro`:

- Чтение PDF через `inlineData`
- Генерация разбираемого JSON с комбинацией `responseMimeType` + `responseSchema`

---

## PDF — краткое содержание

Следующий запрос успешно прочитал PDF в производственной среде и вернул краткое содержание:

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "Summarize the attached PDF in one sentence."},
          {
            "inlineData": {
              "mimeType": "application/pdf",
              "data": "JVBERi0xLjQK..."
            }
          }
        ]
      }
    ]
  }'
```

В ходе тестирования модель в производственной среде успешно вернула однострочное резюме содержимого PDF.

---

## PDF + структурированный вывод

Следующий запрос в производственной среде вернул пригодный для `json.loads()` JSON-текст:

```bash
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "Extract the key topic and whether the document mentions gamma."},
          {
            "inlineData": {
              "mimeType": "application/pdf",
              "data": "JVBERi0xLjQK..."
            }
          }
        ]
      }
    ],
    "generationConfig": {
      "responseMimeType": "application/json",
      "responseSchema": {
        "type": "object",
        "properties": {
          "topic": {"type": "string"},
          "mentions_gamma": {"type": "boolean"}
        },
        "required": ["topic", "mentions_gamma"]
      }
    }
  }'
```

Пример возврата в производственной среде:

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "{\n  \"topic\": \"Crazyrouter PDF test document\",\n  \"mentions_gamma\": false\n}"
          }
        ]
      }
    }
  ]
}
```

Соответствующий код уже позволяет непосредственный парсинг:

```python
import json

text = response["candidates"][0]["content"]["parts"][0]["text"]
data = json.loads(text)
```

<Note>
  На текущей странице подтверждена только цепочка PDF-входа и JSON-структурированного вывода. Для сложных сценариев извлечения таблиц и сравнения длинных документов рекомендуем протестировать конкретные ваши образцы в производственной среде.
</Note>

<Warning>
  Для больших PDF количество входных токенов сильно увеличивается. Перед внедрением рекомендуется начать с маленьких документов для проверки полей и подсказок, затем постепенно увеличивать объем входных данных.
</Warning>
