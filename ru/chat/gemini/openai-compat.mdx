# Gemini OpenAI совместимый формат

Вы можете вызвать Gemini в формате, совместимом с OpenAI Chat Completions.

```
POST /v1/chat/completions
```

На этой странице указано только поведение совместимого слоя `2026-03-22`, которое уже проверено в производственной среде Crazyrouter.

Текущая основная модель:

- `gemini-3.1-pro`

## Основные выводы на данный момент

Последняя производственная ревизия подтвердила:

- `gemini-3.1-pro` может нормально вести диалог через `/v1/chat/completions`
- Потоковая передача совместима со структурой SSE `chat.completion.chunk`
- Если вам нужны структурированный вывод Gemini, Google Search, thinking и другие возможности, пока рекомендуется использовать [родной формат Gemini](/ru/chat/gemini/native)

---

## Базовый диалог

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gemini-3.1-pro",
    "messages": [
      {
        "role": "system",
        "content": "You are a concise assistant."
      },
      {
        "role": "user",
        "content": "Explain quantum entanglement in one sentence."
      }
    ],
    "max_tokens": 128
  }'
```

Ключевая структура ответа, проверенная в текущей продакшн-верификации:

```json
{
  "object": "chat.completion",
  "model": "gemini-3.1-pro",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "..."
      }
    }
  ]
}
```

---

## Пример на Python

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.chat.completions.create(
    model="gemini-3.1-pro",
    messages=[
        {"role": "system", "content": "You are a concise assistant."},
        {"role": "user", "content": "Explain quantum entanglement in one sentence."}
    ],
    max_tokens=128
)

print(response.choices[0].message.content)
```

---

## Потоковая передача

В этом производственном цикле также проверена потоковая совместимая отдача:

```python Python
stream = client.chat.completions.create(
    model="gemini-3.1-pro",
    messages=[
        {"role": "user", "content": "Write one short sentence about AI."}
    ],
    max_tokens=64,
    stream=True
)

for chunk in stream:
    delta = chunk.choices[0].delta
    if delta.content is not None:
        print(delta.content, end="")
```

SSE-фрагменты, полученные в производственной среде, выглядят примерно так:

```text
data: {"object":"chat.completion.chunk","model":"gemini-3.1-pro",...}
data: {"choices":[{"delta":{"content":"..."}}],...}
data: [DONE]
```

## Когда использовать совместимый формат, а когда — родной формат

- Уже есть код с использованием SDK OpenAI и нужны только стандартные диалоги: в первую очередь используйте совместимый формат
- Если требуется структурированный вывод Gemini, Google Search, thinking или родные поля: приоритет — [родной формат Gemini](/ru/chat/gemini/native)
