# Gemini родной формат

На этой странице записаны только те случаи использования Gemini Native, которые `2026-03-22` были проверены на Crazyrouter в производственной среде.

Текущая основная модель для демонстрации:

- `gemini-3.1-pro`

Специально оформленные мультимодальные страницы по успешным запросам:

- [Gemini понимание изображений](/ru/chat/gemini/vision)
- [Gemini понимание видео](/ru/chat/gemini/video)
- [Gemini понимание аудио](/ru/chat/gemini/audio)

## Эндпоинт

```text
POST /v1beta/models/{model}:generateContent
POST /v1beta/models/{model}:streamGenerateContent
```

## Аутентификация

Передавайте API Key через параметр URL:

```text
?key=YOUR_API_KEY
```

---

## Основная генерация текста

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Explain machine learning in one sentence."
          }
        ]
      }
    ],
    "generationConfig": {
      "maxOutputTokens": 128
    }
  }'
```

Ключевые структуры, фактически возвращаемые в текущем производстве:

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "...",
            "thoughtSignature": "..."
          }
        ]
      }
    }
  ]
}
```

---

## Генерация потоком

В данной итерации подтверждено, что `streamGenerateContent` может отдавать инкрементальные данные через SSE.

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:streamGenerateContent?key=YOUR_API_KEY&alt=sse" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Write one short sentence about AI."
          }
        ]
      }
    ]
  }'
```

Получаемые в производстве SSE-фрагменты имеют форму, аналогичную:

```text
data: {"candidates":[{"content":{"parts":[{"text":"...","thoughtSignature":"..."}]}}]}
```

## Структурированный вывод

В производственной среде подтверждено, что `responseMimeType + responseSchema` применим:

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Return a JSON object with keys city and country for Tokyo."
          }
        ]
      }
    ],
    "generationConfig": {
      "responseMimeType": "application/json",
      "responseSchema": {
        "type": "object",
        "properties": {
          "city": {"type": "string"},
          "country": {"type": "string"}
        },
        "required": ["city", "country"]
      }
    }
  }'
```

Проверенный производственный ответ:

```json
{"city":"Tokyo","country":"Japan"}
```

## Google Search

В производственной среде подтверждено, что инструмент `googleSearch` работоспособен:

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Use Google Search to find one recent headline from a major technology news site."
          }
        ]
      }
    ],
    "tools": [
      {
        "googleSearch": {}
      }
    ]
  }'
```

Ключевые поля, возвращаемые в текущем производстве:

- `groundingMetadata.webSearchQueries`
- `groundingMetadata.groundingChunks`
- `groundingMetadata.groundingSupports`

## Thinking

В производственной среде подтверждено, что `thinkingConfig` применим:

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Which is larger, 9.11 or 9.9? Explain briefly."
          }
        ]
      }
    ],
    "generationConfig": {
      "thinkingConfig": {
        "thinkingBudget": 256
      },
      "maxOutputTokens": 512
    }
  }'
```

Ключевые проверочные маркеры текущей производственной среды:

```json
{
  "usageMetadata": {
    "thoughtsTokenCount": 120
  }
}
```

---

## Часто используемые поля generationConfig

| Поле | Тип | Описание |
|------|------|----------|
| `maxOutputTokens` | integer | Максимальное количество токенов вывода |
| `temperature` | number | Температура семплирования |
| `responseMimeType` | string | MIME-тип для структурированного вывода |
| `responseSchema` | object | Ограничения для структурированного вывода |
| `thinkingConfig` | object | Конфигурация режима мышления |

<Note>
  Gemini Native использует структуру `contents[].parts[]`, а не структуру OpenAI `messages`. Если вы хотите использовать стиль OpenAI, пожалуйста, перейдите к [Gemini OpenAI совместимый формат](/ru/chat/gemini/openai-compat).
</Note>
