# Список моделей Gemini, совместимых с OpenAI

```
GET /v1beta/openai/models
```

Этот эндпоинт является совместимым мостом:

- Способы аутентификации допускают стиль Gemini
- Структура ответа остаётся в стиле списка моделей OpenAI

На этой странице представлены только те действия, которые были `2026-03-23` проверены на Crazyrouter в производственной среде.

## Когда использовать

- Ваш клиент привык использовать `?key=`
- Ваш промежуточный слой уже использует `x-goog-api-key`
- Вы хотите получить структуру OpenAI-style `list + data[]`, а не нативные метаданные моделей Gemini

Если вы стандартный клиент OpenAI, сначала используйте [GET /v1/models](/ru/chat/openai/models).

## Аутентификация

На данном этапе проверены следующие три способа, все поддерживаются:

```http
Authorization: Bearer YOUR_API_KEY
```

```http
x-goog-api-key: YOUR_API_KEY
```

```text
GET /v1beta/openai/models?key=YOUR_API_KEY
```

## Пример запроса

<CodeGroup>

```bash cURL
curl "https://api.crazyrouter.com/v1beta/openai/models?key=YOUR_API_KEY"
```

```bash cURL with Header
curl https://api.crazyrouter.com/v1beta/openai/models \
  -H "x-goog-api-key: YOUR_API_KEY"
```

</CodeGroup>

## Текущий вывод производственной проверки

В производственной проверке `2026-03-23`:

- Запрос `?key=` возвращает `200`
- Запрос `x-goog-api-key` возвращает `200`
- На верхнем уровне `object` — это `list`
- На верхнем уровне `success` — это `true`
- Текущее количество возвращаемых моделей — `541`
- Общие поля элементов в `data[]` включают:
  - `id`
  - `object`
  - `created`
  - `owned_by`
  - `supported_endpoint_types`

## Описание полей

| Поле | Тип | Описание |
|------|------|------|
| `data[]` | array | Список моделей, доступных текущему токену |
| `id` | string | Идентификатор модели |
| `owned_by` | string | Источник или организация, которой принадлежит модель |
| `supported_endpoint_types` | array | Стиль API, поддерживаемый данной моделью |
| `object` | string | Всегда равно `list` |
| `success` | boolean | Запрос выполнен успешно |

<Note>
  `supported_endpoint_types` обозначает только поддерживаемый стиль API для данной модели. В настоящее время `openai` соответствует `POST /v1/chat/completions`, `anthropic` соответствует `POST /v1/messages`, а `openai-response` — только `POST /v1/responses`. На данный момент Claude официально поддерживает только `openai` + `anthropic`, не поддерживает `openai-response`.
</Note>

<Note>
  Этот эндпоинт НЕ "только для моделей Gemini". Он возвращает OpenAI-style список моделей, которые видимы через текущий токен, просто способ входа и аутентификации адаптирован для клиента в стиле Gemini.
</Note>
