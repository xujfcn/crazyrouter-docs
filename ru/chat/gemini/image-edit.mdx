# Gemini редактирование изображений

```
POST /v1/images/generations
```

Редактирование изображений Gemini / Nano Banana на Crazyrouter осуществляется через совместимый шлюз OpenAI Images. По умолчанию используется URL `image_input`; для определённых серых аккаунтов поддерживаются dataURL, raw Base64, а также `/v1/images/edits` мульти-частичная (multipart) трёхкартинная редакция.

<Warning>
  Запросы на редактирование изображений и с несколькими референсами обычно занимают больше времени. Для подключения в производстве рекомендуется использовать основную рабочую линию `https://api.crazyrouter.com/v1`, полный endpoint — `https://api.crazyrouter.com/v1/images/generations`.
</Warning>

---

## Текущие рекомендации

1. При новом подключении — сначала используйте `nano-banana-2` или `nano-banana-pro`
2. Передавайте изображение через `image_input`, укажите URL или массив URL
3. Не используйте нативные поля Gemini, например `generationConfig`, `imageConfig` и `imageOutputOptions`
4. Рекомендуется установить таймаут клиента более 180 секунд

---

## Шаблон запроса

Ниже приведен минимальный пример запроса для редактирования с референсными изображениями через универсальный Images API:

```bash
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-2",
    "prompt": "把参考图背景改成蓝色，保留主体结构和边缘细节",
    "image_input": [
      "https://example.com/reference.png"
    ],
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "png"
  }'
```
