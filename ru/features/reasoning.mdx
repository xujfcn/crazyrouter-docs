# Логическое рассуждение

В этой документации приводятся **только успешно проверенные в реальных запросах Crazyrouter** варианты использования для целей рассуждения / мышления.

Время проверки:

- `2026-03-22`

Проверенные модели:

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

---

## Проверенная матрица возможностей

| Модель | Протокол | Эндпоинт | Признак успеха |
|--------|----------|----------|----------------|
| `gpt-5.5` | OpenAI Ответы | `POST /v1/responses` | Элемент `reasoning` обнаружен в `output` |
| `claude-opus-4-8` | Anthropic Messages | `POST /v1/messages` | Возвращает блок `thinking` |
| `gemini-3.1-pro` | Gemini Native | `POST /v1beta/models/{model}:generateContent` | Элемент `thoughtsTokenCount` обнаружен в `usageMetadata` |

---

## GPT-5.4

```bash cURL
curl https://api.crazyrouter.com/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "input": "Which is larger, 9.11 or 9.9? Explain briefly.",
    "reasoning": {
      "effort": "high",
      "summary": "detailed"
    }
  }'
```

Ключевой `output.type`, возвращённый в ходе проверки в реальной среде:

```json
["reasoning", "message"]
```

Ключевые поля элемета `reasoning` включают:

```json
{
  "type": "reasoning",
  "summary": [
    {
      "type": "summary_text",
      "text": "..."
    }
  ]
}
```

Это означает, что в текущей производственной среде Crazyrouter способность рассуждения `gpt-5.5` должна определяться элементом `reasoning` из Responses API, а не зависеть от `reasoning_content` Chat Completions.

## Claude Opus 4.7 Thinking

```bash cURL
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 320,
    "thinking": {
      "type": "enabled",
      "budget_tokens": 128
    },
    "messages": [
      {
        "role": "user",
        "content": "Which is larger, 9.11 or 9.9? Explain briefly."
      }
    ]
  }'
```

Ключевые поля, возвращённые при проверке в реальной среде:

```json
{
  "content": [
    {
      "type": "thinking",
      "thinking": "..."
    },
    {
      "type": "text",
      "text": "..."
    }
  ]
}
```

Внимание:

- Базовая модель `claude-opus-4-8` в том же тесте за тот же день выдала только обычный `text`
- Только `claude-opus-4-8` дал однозначно подтверждённый thinking block

Поэтому следует отдавать приоритет `claude-opus-4-8` как примеру рассуждения Claude 4.7 в этой документации.

## Gemini 3 Pro

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Which is larger, 9.11 or 9.9? Explain briefly."
          }
        ]
      }
    ],
    "generationConfig": {
      "thinkingConfig": {
        "thinkingBudget": 256
      },
      "maxOutputTokens": 512
    }
  }'
```

Ключевые поля, возвращённые в ходе продвинутой верификации:

- `usageMetadata.thoughtsTokenCount`

Это показывает, что в текущей производственной среде режим thinking для `gemini-3.1-pro` действительно работает.

---

## Сочетания, не включённые в основное заключение

- Маршрутизация Chat Completions для `gpt-5.5` не стабильно возвращала `reasoning_content` при текущей проверке, поэтому здесь он не приводится как основной пример GPT
- Базовая модель `claude-opus-4-8` не возвращала thinking block при текущей верификации
- Модель с однозначными возможностями thinking, аналогичными указанным выше, для `claude-opus-4-8` не обнаружена
