# Вызов инструментов

В этой документации представлены только те способы вызова инструментов, которые **успешно проверены в производственной среде Crazyrouter на реальных запросах**.

Время проверки:

- `2026-03-22`

Проверенные модели:

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

---

## Проверенная матрица возможностей

| Модель | Протокол | Эндпоинт | Признак успешности |
|--------|----------|----------|--------------------|
| `gpt-5.5` | OpenAI Chat Completions | `POST /v1/chat/completions` | Ответ `tool_calls` |
| `claude-opus-4-8` | Anthropic Messages | `POST /v1/messages` | Ответ `tool_use` block |
| `gemini-3.1-pro` | Gemini Native | `POST /v1beta/models/{model}:generateContent` | Ответ `functionCall` |

<Warning>
На данный момент вызов инструментов Claude проверяется по протоколу Anthropic Messages, то есть `POST /v1/messages` возвращает `tool_use` block. Не распространяйте этот вывод на OpenAI-совместимый путь `/v1/chat/completions` для Claude; в таких сценариях, как Copilot, Continue, некоторые VS Code Agent или другие программные задачи, требующие вызова инструментов, OpenAI-совместимый эндпоинт может не запускать родной вызов инструментов Claude. Если вам нужна программная способность Agent Claude, в первую очередь используйте Claude Code или настрой Anthropic native client.
</Warning>

## GPT-5.4

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Use the get_time tool for Asia/Shanghai. Do not answer without calling the tool."
      }
    ],
    "tools": [
      {
        "type": "function",
        "function": {
          "name": "get_time",
          "description": "Get the current time for a timezone",
          "parameters": {
            "type": "object",
            "properties": {
              "timezone": {
                "type": "string"
              }
            },
            "required": ["timezone"],
            "additionalProperties": false
          }
        }
      }
    ],
    "tool_choice": "required"
  }'
```

Ключевые поля ответа в производственной проверке:

```json
{
  "tool_calls": [
    {
      "type": "function",
      "function": {
        "name": "get_time",
        "arguments": "{\"timezone\":\"Asia/Shanghai\"}"
      }
    }
  ]
}
```

## Claude Sonnet 4.6

```bash cURL
curl https://api.crazyrouter.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4-8",
    "max_tokens": 256,
    "tools": [
      {
        "name": "get_time",
        "description": "Get the current time for a timezone",
        "input_schema": {
          "type": "object",
          "properties": {
            "timezone": {
              "type": "string"
            }
          },
          "required": ["timezone"]
        }
      }
    ],
    "tool_choice": {
      "type": "any"
    },
    "messages": [
      {
        "role": "user",
        "content": "Use the get_time tool for Asia/Shanghai. Do not answer directly."
      }
    ]
  }'
```

Ключевые поля ответа в производственной проверке:

```json
{
  "stop_reason": "tool_use",
  "content": [
    {
      "type": "tool_use",
      "name": "get_time",
      "input": {
        "timezone": "Asia/Shanghai"
      }
    }
  ]
}
```

Рекомендации для первой интеграции:

- Для родного `/v1/messages` Claude, желательно явно добавить `tool_choice`
- Укажите в prompt, что "необходимо вызывать инструмент, не отвечать напрямую"
- Так легче стабильно воспроизводить `tool_use`

## Gemini 3 Pro

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Use the get_time function for Asia/Shanghai."
          }
        ]
      }
    ],
    "tools": [
      {
        "functionDeclarations": [
          {
            "name": "get_time",
            "description": "Get the current time for a timezone",
            "parameters": {
              "type": "object",
              "properties": {
                "timezone": {
                  "type": "string"
                }
              },
              "required": ["timezone"]
            }
          }
        ]
      }
    ]
  }'
```

Ключевые поля ответа в производственной проверке:

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "functionCall": {
              "name": "get_time",
              "args": {
                "timezone": "Asia/Shanghai"
              }
            }
          }
        ]
      }
    }
  ]
}
```

## Когда использовать какой протокол

- Если ваш проект уже использует OpenAI SDK, предпочтительно используйте OpenAI-совместимый способ `gpt-5.5`
- Если вы внедряете родной Claude, предпочтительно используйте `/v1/messages` и на первом цикле проверки добавьте `tool_choice`
- Если вы внедряете родные возможности Gemini, предпочтительно используйте Gemini Native API
