# Структурированные выводы

В этой документации приведены **только те способы использования Structured Outputs, которые подтверждены успешными фактическими запросами в производственной среде Crazyrouter**.

Время валидации:

- `2026-03-22`

Модели, прошедшие строгую валидацию:

- `gpt-5.5`
- `gemini-3.1-pro`

Модели, которые в настоящий момент не включены в список строго успешных примеров:

- `claude-opus-4-8`

Причина:

- В ходе проверки в производственной среде `claude-opus-4-8` в текущей совместимой с OpenAI форме запроса `response_format=json_schema` не проявил стабильного поведения «строго чистого JSON»
- В предыдущих тестах появлялась fenced code block
- В ходе повторной проверки `2026-03-22` снова обнаружился пустой `content`
- Поэтому на данный момент его не относят к категории «строго структурированных выводов, валидация успешна»

## Проверенная матрица возможностей

| Модель | Протокол | Эндпоинт | Признак успеха |
|------|------|------|----------|
| `gpt-5.5` | OpenAI Chat Completions | `POST /v1/chat/completions` | Содержимое ответа можно непосредственно `JSON.parse` |
| `gemini-3.1-pro` | Gemini Native | `POST /v1beta/models/{model}:generateContent` | Возвращает текст в стиле `application/json`, подходит для прямого парсинга |

## GPT-5.4

```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "Return a JSON object with keys city and country for Tokyo."
      }
    ],
    "response_format": {
      "type": "json_schema",
      "json_schema": {
        "name": "city_country",
        "strict": true,
        "schema": {
          "type": "object",
          "properties": {
            "city": {"type": "string"},
            "country": {"type": "string"}
          },
          "required": ["city", "country"],
          "additionalProperties": false
        }
      }
    }
  }'
```

Результат производственной проверки:

```json
{"city":"Tokyo","country":"Japan"}
```

## Gemini 3 Pro

```bash cURL
curl "https://api.crazyrouter.com/v1beta/models/gemini-3.1-pro:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Return a JSON object with keys city and country for Tokyo."
          }
        ]
      }
    ],
    "generationConfig": {
      "responseMimeType": "application/json",
      "responseSchema": {
        "type": "object",
        "properties": {
          "city": {"type": "string"},
          "country": {"type": "string"}
        },
        "required": ["city", "country"]
      }
    }
  }'
```

Результат производственной проверки:

```json
{"city":"Tokyo","country":"Japan"}
```

## Claude 4.6 — текущий вывод

В производственных тестах `2026-03-22`:

- `claude-opus-4-8` в этом формате запроса не дал стабильного, воспроизводимого вывода строго в формате JSON
- В разных циклах тестирования появлялись как fenced code block, так и пустой `content`
- Поэтому в данный момент не рекомендуется считать Claude 4.6 «строго схематичным выводом, валидация успешна»

Если впоследствии планируется добавить Claude 4.6 в данный список, рекомендуется сначала провести дополнительную, более детальную производственную валидацию и убедиться, что:

- Существует ли более подходящий вариант нативного протокола
- Необходим ли дополнительный system prompt
- Возможно ли стабильно избежать code fence
