# Псевдоним генерации видео

```
POST /v1/video/generations
```

Это совместимый псевдоним-маршрут от Crazyrouter, подходит для клиентов или промежуточных уровней, которые постоянно используют путь `/v1/video/generations`.

## Аутентификация

```http
Authorization: Bearer YOUR_API_KEY
```

## Когда его использовать

- Ваш клиент жестко запрограммирован на путь `/v1/video/generations`
- Вы переносите старый видео рабочий процесс и не хотите менять путь вызова
- Вам требуется совместимость с форматом запросов сторонних приложений
- Вы подаете заявку на создание видео через Wan, например, `wan2.5-t2v-preview` или `wan2.2-t2v-plus`

Если вы разрабатываете новое подключение, рекомендуем:

- Генерация видео Wan: используйте `POST /v1/video/generations` на этой странице
- Veo / унифицированный видео рабочий процесс: используйте `POST /v1/video/create`, отправьте `veo-3.1-fast` или `veo-3.1-quality`
- Официальный совместимый видео рабочий процесс OpenAI: используйте `POST /v1/videos`

## Минимальный пример запроса

### Wan 2.2 T2V Plus

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "wan2.2-t2v-plus",
    "prompt": "一段平静的电影感山间云海镜头",
    "seconds": "5",
    "size": "480P"
  }'
```

### Общий минимальный пример

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations   -H "Content-Type: application/json"   -H "Authorization: Bearer YOUR_API_KEY"   -d '{
    "model": "wan2.5-t2v-preview",
    "prompt": "A cinematic shot of waves hitting a cliff at sunset"
  }'
```

## Типичный успешный ответ

```json
{
  "id": "video_task_abc123",
  "task_id": "video_task_abc123",
  "status": "processing",
  "status_update_time": 1709123456
}
```

## Ошибка, обнаруженная при локальной проверке

В вашей локальной среде `http://127.0.0.1:4000` этот маршрут уже был проверен. Когда модель временно недоступна, возвращается бизнес-ошибка, а не `404`:

```json
{
  "code": "get_channel_failed",
  "message": "model wan2.2-t2v-plus is temporarily unavailable, please try again later",
  "data": null
}
```

## Важные замечания

- Поля тела запроса могут изменяться в зависимости от конкретной видеомодели и возможностей интеграции
- Доступность `model` зависит от текущего белого списка токенов и статуса вышестоящего канала
- Генерация видео Wan использует `model`, `prompt`, `seconds`, `size`; проверенные комбинации `wan2.2-t2v-plus` - это `seconds: "5"`, `size: "480P"` или `"1080P"`.
- `wan2.2-t2v-plus` не должен подаваться на `/alibailian/api/v1/services/aigc/video-generation/video-synthesis`.
- После успешного создания задачи вы можете продолжить вызов `GET /v1/video/generations/{task_id}` для проверки статуса

<Note>
Этот маршрут является совместимым псевдонимом и не гарантирует, что все видеомодели полностью идентичны по полям запроса. На данный момент для генерации видео Wan рекомендуется использовать этот маршрут; для Veo или унифицированного рабочего видеопроцесса используйте `/v1/video/create` и передайте `veo-3.1-fast` или `veo-3.1-quality`.
</Note>
