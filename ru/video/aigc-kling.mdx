# Метод вызова AIGC Kling VOD

`aigc-video-kling-*` — это видеомодель Kling, интегрированная Crazyrouter через линию Tencent VOD. Её путь отличается от `/kling/v1/videos/*`, приведённого в оригинальной документации Kling; вызовы для клиентов осуществляются через асинхронный видеоинтерфейс в стиле OpenAI:

```http
POST /v1/video/generations
GET /v1/video/generations/{task_id}
```

<Note>
  Для вызова по линии VOD обязательно используйте имя модели `aigc-video-kling-*`. Не отправляйте `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3` напрямую на интерфейс этой страницы, иначе вы можете попасть на исходную линию Kling.
</Note>

<Note>
  Если вам нужна модель изображений `aigc-image-kling-3.0`, пожалуйста, перейдите к [Генерация изображений AIGC Kling 3.0](/ru/images/aigc-kling). Эта модель использует `POST /v1/images/generations` и не поддерживает видеособинтерфейс данной страницы.
</Note>

## Создание задачи

```http
POST https://api.crazyrouter.com/v1/video/generations
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

### Общие параметры

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model` | string | Да | Имя модели `aigc-video-kling-*`, используемой на этой странице |
| `prompt` | string | Обязательно при определённых условиях | Обязательный для текст-видео; для многокадрового или некоторых сцен изображение-видео можно использовать в расширенных параметрах |
| `seconds` / `duration` | string / number | Нет | Длительность видео, обычно `5` или `10`, по умолчанию `5` секунд |
| `size` | string | Нет | Например `1280x720`, `720x1280`, определяется соотношение сторон вывода |
| `image` | string | Нет | URL первого кадра для задачи изображение-видео |
| `images` | array[string] | Нет | Первый элемент — первый кадр, второй — последний кадр или референс-изображение |
| `metadata` | object | Нет | Расширенные параметры VOD Kling, см. таблицу ниже |

### Часто используемые поля metadata

| Поле | Описание |
|------|------|
| `resolution` | Формат вывода, например `720P`, `1080P`, `2K`, `4K` |
| `aspect_ratio` | Соотношение сторон вывода, например `16:9`, `9:16`, `1:1` |
| `sound` | Генерировать звук или нет, поддерживает `true` / `false`, `on` / `off` |
| `image_urls` | Массив первого/последнего кадров, максимум 2 изображения |
| `image_tail` / `last_frame_url` | URL последнего кадра, имеет более высокий приоритет, чем `image_urls[1]` |
| `image_list` | Список референс-изображений, максимум 9 изображений |
| `multi_shots` / `multi_shot` | Переключатель многокадрового режима |
| `shot_type` | Тип раскадровки |
| `multi_prompt` | Массив промптов для многокадрового режима |
| `kling_elements` / `element_list` | Контроль Kling-элементов |
| `camera_control` | Контроль камеры (движения) |
| `motion_brush` / `dynamic_masks` | Параметры контроля движений |
| `video_list` | Видеореференс, обычно для O1 или схожих функций с видео-входом |
| `voice_list` | Аудиореференс |
| `session_id` / `face_choose` | Параметры, связанные с синхронизацией губ |

## Текст-видео

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-2.6",
    "prompt": "a red square logo slowly rotating on a clean white background",
    "size": "1280x720",
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "sound": false
    }
  }'
```

## Видео по первым и последним кадрам

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-2.6",
    "prompt": "transition naturally from the first frame to the last frame",
    "images": [
      "https://example.com/first.png",
      "https://example.com/last.png"
    ],
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "sound": false
    }
  }'
```

<Note>
  Для Kling 2.6 рекомендуется явно передавать `metadata.sound=false` при создании видео по первым и последним кадрам.
</Note>

## Контроль движений

Возможности по контролю движений используют отдельные имена моделей, такие как `aigc-video-kling-2.6-motion-control` или `aigc-video-kling-3.0-motion-control`.

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-3.0-motion-control",
    "prompt": "animate the selected subject moving from left to right",
    "image": "https://example.com/input.png",
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "dynamic_masks": [
        {
          "mask_url": "https://example.com/mask.png",
          "trajectories": [
            { "x": 220, "y": 380 },
            { "x": 620, "y": 380 }
          ]
        }
      ]
    }
  }'
```

## Видео-вход O1

`aigc-video-kling-o1` можно передать через `metadata.video_list` в качестве видеореференса. Наличие видео-входа влияет на тариф.

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-kling-o1",
    "prompt": "use the reference video motion style and generate a new cinematic shot",
    "seconds": "5",
    "metadata": {
      "resolution": "720P",
      "video_list": [
        { "url": "https://example.com/reference.mp4" }
      ]
    }
  }'
```

## Avatar и синхронизация губ

Для Avatar используйте `aigc-video-kling-avatar`:

```json
{
  "model": "aigc-video-kling-avatar",
  "prompt": "a presenter speaks naturally to the camera",
  "image": "https://example.com/avatar.png",
  "seconds": "5",
  "metadata": {
    "resolution": "720P",
    "voice_list": [
      { "url": "https://example.com/voice.wav" }
    ]
  }
}
```

Для синхронизации губ используйте `aigc-video-kling-identifyface`. Если на стороне пользователя уже определены `session_id` и `face_choose`, их можно поместить в `metadata`:

```json
{
  "model": "aigc-video-kling-identifyface",
  "prompt": "lip sync the face with the provided voice",
  "image": "https://example.com/face.png",
  "seconds": "5",
  "metadata": {
    "resolution": "720P",
    "session_id": "SESSION_ID",
    "face_choose": "FACE_ID",
    "voice_list": [
      { "url": "https://example.com/voice.wav" }
    ]
  }
}
```

<Note>
  Полный процесс синхронизации губ обычно требует сначала выполнить распознавание лица, затем отправить задачу на генерацию видео. Если нет `session_id` / `face_choose`, может возникнуть ошибка параметров на стороне сервера.
</Note>

## Запрос состояния задачи

После получения `id` или `task_id` при создании задачи используйте тот же универсальный путь для запроса статуса:

```bash cURL
curl https://api.crazyrouter.com/v1/video/generations/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

После выполнения обычно возвращается URL архивированного видео:

```json
{
  "code": "success",
  "data": {
    "status": "SUCCESS",
    "task_id": "vod_task_abc123",
    "result_url": "https://media.crazyrouter.com/task-artifacts/example.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/example.mp4"
  }
}
```

## Отличия от оригинального Kling

| Проект | AIGC Kling VOD | Оригинальный Kling |
|------|------|------|
| Имя модели | `aigc-video-kling-*` | `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3` |
| Путь для создания | `POST /v1/video/generations` | `POST /kling/v1/videos/text2video` и др. |
| Путь для запроса | `GET /v1/video/generations/{task_id}` | `GET /kling/v1/videos/{type}/{task_id}` |
| Основные поля | `model`, `prompt`, `seconds`, `image`, `images`, `metadata` | `model_name`, `prompt`, `image_urls`, `duration` и др. |
| Подходящие сценарии | Линия Tencent VOD, цены и возможности VOD | Оригинальный протокол Kling |
