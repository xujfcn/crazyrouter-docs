# Видеоинтерфейс Али Бай Лян

Crazyrouter предоставляет видеоинтерфейс, совместимый с Али Бай Лян, что облегчает прямую миграцию приложений, уже интегрированных под форматы видеоинтерфейса DashScope / Али Бай Лян.

## Что охватывает эта страница

- Здесь описаны совместимые псевдонимы Али для внешнего интерфейса Crazyrouter — они идеально подходят тем рабочим процессам, которые уже реализованы под интеграцию с DashScope / Али Бай Лян с поддержкой видеоформата `/alibailian/api/v1/*`.
- Официальный внутренний апстрим Crazyrouter унифицирован и всегда указывает на путь DashScope `/api/v1/*`
- Если вы хотите использовать универсальный видеоинтерфейс Crazyrouter, а не миграционный совместимый путь Али, перейдите на `/v1/video/generations`
- Видеомодуль Wan Wen Sheng в настоящее время использует `/v1/video/generations`. Особое внимание: `wan2.2-t2v-plus` не поддерживает отправку по адресу, указанному на этой странице (`/alibailian/...video-synthesis`).
- Возможность вызова конкретной модели всё ещё зависит от вашего белого списка токенов, тарифов на модель и текущего состояния её размещения в проде; не стоит считать, что все апстримные видеомодели Али по умолчанию открыты

## Поддерживаемые эндпойнты

- `POST /alibailian/api/v1/services/aigc/video-generation/video-synthesis`
- `GET /alibailian/api/v1/tasks/{task_id}`

## Описание внутренних апстримных путей

- Внешний путь для совместимой отправки: `POST /alibailian/api/v1/services/aigc/video-generation/video-synthesis`
- Внешний путь для совместимого запроса: `GET /alibailian/api/v1/tasks/{task_id}`
- Внутренняя отправка в апстрим Crazyrouter: `POST /api/v1/services/aigc/video-generation/video-synthesis`
- Внутренний запрос в апстрим Crazyrouter: `GET /api/v1/tasks/{task_id}`

## Аутентификация

```http
Authorization: Bearer YOUR_API_KEY
```

## POST Генерация видео

```
POST /alibailian/api/v1/services/aigc/video-generation/video-synthesis
```

### Структура тела запроса

| Поле | Тип | Обязательное | Описание |
|------|------|------|------|
| `model` | string | Да | Имя модели, например `wan2.5-i2v-preview` |
| `input` | object | Да | Базовые входные параметры |
| `input.prompt` | string | Нет | Прямой (позитивный) промпт |
| `input.negative_prompt` | string | Нет | Обратный (негативный) промпт |
| `input.img_url` | string | Нет | URL первого кадра или Base64 |
| `input.audio_url` | string | Нет | URL аудиофайла |
| `input.template` | string | Нет | Шаблон видеоэффектов |
| `parameters` | object | Нет | Параметры расширенной обработки |
| `parameters.resolution` | string | Нет | Режим разрешения, например `480P` |
| `parameters.duration` | integer | Нет | Продолжительность видео (сек) |
| `parameters.prompt_extend` | boolean | Нет | Использовать интеллектуальный рерайт |
| `parameters.watermark` | boolean | Нет | Добавить AI-водяной знак |
| `parameters.audio` | boolean | Нет | Автоматически дополнять звук |
| `parameters.seed` | integer | Нет | Случайное зерно (seed) |

<Warning>
  Запрос `wan2.2-t2v-plus` на этот путь приведёт к возврату `invalid_request`; для вывода в проде используйте `/v1/video/generations`. Для информационного видео Wan смотрите [Видео Wan](/ru/video/wan) или [Псевдонимы видеогенерации](/ru/video/openai-video-alias-create).
</Warning>

### Пример запроса

```bash cURL
curl -X POST https://api.crazyrouter.com/alibailian/api/v1/services/aigc/video-generation/video-synthesis \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "wan2.5-i2v-preview",
    "input": {
      "prompt": "改变一下光线",
      "img_url": "https://example.com/first-frame.png"
    },
    "parameters": {
      "resolution": "480P",
      "prompt_extend": true,
      "audio": true
    }
  }'
```

### Пример ответа

```json
{
  "request_id": "ccffb21f-c21e-4eba-861a-6c80e6db6e4d",
  "output": {
    "task_id": "a55bfe14-6e78-4b9d-b97d-128420399ed1",
    "task_status": "PENDING"
  }
}
```

```
GET /alibailian/api/v1/tasks/{task_id}
```

## Ошибочные ответы, выявленные локально

- Локально подтверждено: маршрут создания существует; если модель недоступна, возвращается бизнес-ошибка типа `model_not_found`, а не `404`
- Локально подтверждено: маршрут запроса существует; если задача не найдена, возвращается:

```json
{
  "code": "task_not_exist",
  "message": "task_not_exist",
  "data": null
}
```

<Note>
Этот набор маршрутов Али Бай Лян особенно подходит для «протокольно-совместимой миграции». Форматы тела запроса и ответа максимально близки к стилю оригинального DashScope / Бай Лян, а не к унифицированному формату Crazyrouter. При этом это не означает «все видеомодели Али открыты во внешнем API Crazyrouter»; детали зависят от актуальной ценовой политики, белого списка моделей и текущей доступности.
</Note>
