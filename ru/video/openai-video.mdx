# Формат видео OpenAI

Crazyrouter поддерживает официальный видеоформат API OpenAI, полностью совместим с OpenAI SDK.

## Создание видео

```
POST /v1/videos
```

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model` | string | Да | Название модели, например `veo-3.1-fast`, `veo-3.1-quality` |
| `prompt` | string | Да | Описание/промпт видео |
| `size` | string | Нет | Размер видео: `1920x1080`, `1080x1920`, `1080x1080` |
| `duration` | integer | Нет | Длительность видео (секунды) |
| `image_url` | string | Нет | URL референс-изображения |
| `storyboard` | array | Нет | Storyboard/сценарный план |
| `private` | boolean | Нет | Частный режим |

### Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/videos \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-fast",
    "prompt": "A timelapse of a city skyline from day to night, clouds moving quickly",
    "size": "1920x1080",
    "duration": 10
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/videos",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "veo-3.1-fast",
        "prompt": "A timelapse of a city skyline from day to night",
        "size": "1920x1080",
        "duration": 10
    }
)

print(response.json())
```

</CodeGroup>

### Пример ответа

```json
{
  "id": "video_abc123",
  "object": "video",
  "status": "processing",
  "created_at": 1709123456

```

## Запрос видео

```
GET /v1/videos/{id}
```

```bash cURL
curl https://api.crazyrouter.com/v1/videos/video_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Пример ответа (выполнено)

```json
{
  "code": "success",
  "message": "",
  "data": {
    "id": "video_abc123",
    "task_id": "video_abc123",
    "status": "SUCCESS",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/example.mp4",
    "result_url": "https://media.crazyrouter.com/task-artifacts/example.mp4"
  }
}
```

---

## Скачать видео

```
GET /v1/videos/{id}/content
```

Прямая загрузка видеофайла.

```bash cURL
curl -o output.mp4 https://api.crazyrouter.com/v1/videos/video_abc123/content \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Редактирование видео

Для создания видео на основе изображения передайте `image_url` в запросе на создание:

```json
{
  "model": "veo-3.1-fast",
  "prompt": "The scene comes to life with gentle movement",
  "image_url": "https://example.com/scene.jpg",
  "size": "1920x1080",
  "duration": 5
}
```

---

## Storyboard (сценарный план)

```json
{
  "model": "veo-3.1-fast",
  "storyboard": [
    {"prompt": "Wide shot of a forest at dawn", "duration": 3},
    {"prompt": "A deer walks into frame", "duration": 4},
    {"prompt": "Close-up of the deer looking at camera", "duration": 3}
  ],
  "size": "1920x1080"
}
```

---

## Частный режим

Установите `private: true`, чтобы сгенерированное видео не появилось в публичной галерее:

```json
{
  "model": "veo-3.1-fast",
  "prompt": "A confidential product demo video",
  "size": "1920x1080",
  "private": true
}
```

### Статусы задачи

| Статус | Описание |
|------|------|
| `processing` | В обработке |
| `SUCCESS` | Завершено |
| `failed` | Ошибка |
