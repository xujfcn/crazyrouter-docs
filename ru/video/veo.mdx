# Veo 3.1

Текущие публичные модели Veo 3.1 от Crazyrouter:

- `veo-3.1-fast`
- `veo-3.1-quality`

Эти два имени являются публичными псевдонимами для клиентов. Внутренние канонические имена провайдеров не раскрываются напрямую клиентам.

<Note>
  `veo-3.1` не является `model`, который может быть непосредственно отправлен клиентами. Для клиентских запросов всегда используйте `veo-3.1-fast` или `veo-3.1-quality`.
</Note>

## Вызов через Унифицированный Видео API

```
POST /v1/video/create
```

На этой странице описаны только уже доступные клиентам возможности:

- Генерация видео по тексту
- Генерация видео по одной картинке

В документации Google упомянутые `referenceImages`, style reference и более детальные provider-native режимы не входят в текущий публичный контракт.

### Доступные модели сейчас

| Модель | Описание |
|--------|----------|
| `veo-3.1-fast` | Более низкая задержка, подходит для быстрого получения первого результата |
| `veo-3.1-quality` | Приоритет качества, рекомендуется для основной демонстрации |

### Состояние возможностей

| Возможность / спецификация | Статус | Описание |
|---------------------------|--------|----------|
| Генерация видео по тексту `720P / 1080P` | `Verified` | Текущий публичный контракт утверждён |
| Генерация видео по одной картинке `720P / 1080P` | `Verified` | Текущий публичный контракт утверждён |
| Аудио включено | `Beta` | Официальная возможность есть, но публичный артефакт пока в разработке |
| `start_end` | `Beta` | На этой странице пока не обещано |
| `referenceImages` / reference assets | `Beta` | На этой странице пока не обещано |
| `4K` | `Beta` | На этой странице пока не обещано |

<Note>
  Страница Pricing и эта документация используют ту же систему статусов: `Verified` обозначает, что уже есть минимальный рабочий контур, `Beta` – официальная опция существует, но сейчас проводится доп. валидация или определяются границы.
</Note>

### Параметры запроса

| Параметр | Тип | Обязательно | Описание |
|----------|-----|-------------|----------|
| `model` | string | Да | `veo-3.1-fast` или `veo-3.1-quality` |
| `prompt` | string | Да | Описание для видео (prompt) |
| `aspect_ratio` | string | Нет | Рекомендуется использовать `16:9` или `9:16` |
| `size` | string | Нет | Рекомендуется использовать `720P` или `1080P` |
| `images` | array | Нет | Для генерации видео по картинке передайте `1` ссылок на изображения |
| `duration` | integer | Нет | Обычно: `8` |

### Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-quality",
    "prompt": "A cinematic shot of a spaceship landing on Mars, dust clouds rising, golden hour lighting",
    "aspect_ratio": "16:9"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/video/create",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "veo-3.1-quality",
        "prompt": "A cinematic shot of a spaceship landing on Mars",
        "aspect_ratio": "16:9"
    }
)

task_id = response.json()["task_id"]
print(f"任务 ID: {task_id}")
```

</CodeGroup>

### Пример ответа

```json
{
  "task_id": "veo_task_abc123",
  "status": "processing"
}
```

## Пример генерации видео по одной картинке

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-fast",
    "prompt": "The person in the image slowly turns their head and smiles",
    "images": ["https://example.com/portrait.jpg"],
    "aspect_ratio": "9:16",
    "size": "720P"
  }'
```

## Запрос статуса задачи

```
GET /v1/video/query?id={task_id}

  -H "Authorization: Bearer YOUR_API_KEY"
```
