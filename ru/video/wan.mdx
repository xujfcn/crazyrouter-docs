# Wan Видео

Серия Wan в настоящий момент использует разные клиентские протоколы в зависимости от возможностей:

- Генерация видео по тексту (`wan2.5-t2v-preview`, `wan2.2-t2v-plus`): используется `POST /v1/video/generations`, результат проверяется через `GET /v1/video/generations/{task_id}`.
- Генерация видео по изображению, генерация видео начальных и конечных кадров, генерация видео с учетом субъекта: используется совместимый путь Alibaba `POST /alibailian/api/v1/services/aigc/video-generation/video-synthesis`, результат проверяется через `GET /alibailian/api/v1/tasks/{task_id}`.

<Warning>
  Не отправляйте `wan2.2-t2v-plus` в `/alibailian/api/v1/services/aigc/video-generation/video-synthesis`. В производственной среде вернётся `invalid_request` с рекомендацией использовать `/v1/video/generations`.
</Warning>

Полный формат тела запроса и задачи для рабочего процесса формата Alibaba смотрите на [интерфейсе видео Alibaba Bailian](/ru/video/alibailian). На этой странице приведены модели `Wan`, возможности, официальные тарифы и рекомендуемый протокол, открытые для внешнего использования.

## Протокольные соглашения

### 1. Генерация видео по тексту

- Рекомендуемый путь для отправки: `POST /v1/video/generations`
- Рекомендуемый путь для проверки: `GET /v1/video/generations/{task_id}`
- Ключевые поля: `model`, `prompt`, `seconds`, `size`
- Типичные модели: `wan2.5-t2v-preview`, `wan2.2-t2v-plus`

### 2. Генерация видео по изображению

- Ключевые поля: `input.img_url`
- Типичные модели: `wan2.5-i2v-preview`, `wan2.2-i2v-plus`, `wan2.2-i2v-flash`

### 3. Генерация начальных и конечных кадров

- Ключевые поля: `input.first_frame_url`, `input.last_frame_url`
- Типичная модель: `wan2.2-kf2v-flash`

### 4. Генерация видео с учетом субъекта

- Ключевые поля: `input.image_url`
- Типичная модель: `wan2.2-s2v`

## Примеры запросов

### Генерация видео по тексту: Wan 2.2 T2V Plus

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "wan2.2-t2v-plus",
    "prompt": "一段平静的电影感山间云海镜头",
    "seconds": "5",
    "size": "480P"
  }'
```

### Генерация видео по изображению

```bash cURL
curl -X POST https://api.crazyrouter.com/alibailian/api/v1/services/aigc/video-generation/video-synthesis \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "wan2.5-i2v-preview",
    "input": {
      "prompt": "让画面中的人物转头看向镜头",
      "img_url": "https://example.com/first-frame.png"
    },
    "parameters": {
      "resolution": "720P",
      "duration": 5,
      "prompt_extend": true,
      "audio": true
    }
  }'
```

### Генерация начальных и конечных кадров

```json
{
  "model": "wan2.2-kf2v-flash",
  "input": {
    "prompt": "镜头从白天平滑过渡到夜晚",
    "first_frame_url": "https://example.com/frame-start.png",
    "last_frame_url": "https://example.com/frame-end.png"
  },
  "parameters": {
    "resolution": "720P",
    "duration": 5
  }
}
```

### Генерация видео с учетом субъекта

```json
{
  "model": "wan2.2-s2v",
  "input": {
    "prompt": "让参考人物自然说话并有轻微头部动作",
    "image_url": "https://example.com/portrait.png",
    "audio_url": "https://example.com/voice.mp3"
  },
  "parameters": {
    "resolution": "720P",
    "duration": 5
  }
}
```

## Получение задачи

Wan пока работает по модели асинхронных задач. После создания задачи клиент получает результат по протоколу отправки:

Генерация видео по тексту:

```http
GET /v1/video/generations/{task_id}
```

Совместимый с Alibaba рабочий процесс для генерации видео по изображению, начальных и конечных кадров и субъект-референс:

```http
GET /alibailian/api/v1/tasks/{task_id}
```

Когда запрос возвращает `status = SUCCESS`, окончательный видео-результат можно получить из `result_url` или `artifact_url`.

## Описание границ

- Текущий рекомендуемый клиентский протокол для Wan видео по тексту — `/v1/video/generations`, а не совместимый путь отправки Alibaba Bailian.
- Путь совместимого формата Alibaba главным образом предназначен для генерации видео по изображению, начальных и конечных кадров, генерации видео с учетом субъекта и других сценариев миграции Alibaba формата.
- Crazyrouter может использовать официальный, ApiPass, Kie или других сторонних провайдеров внутри, но эти провайдеры не определяют отдельный клиентский протокол.
- Строки Beta можно показывать клиенту; после запуска стоит использовать производственные логи задач для дополнения live evidence, а при успешном завершении процесса убрать знак Beta.
