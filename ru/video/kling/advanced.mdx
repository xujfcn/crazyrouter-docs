# Kling продвинутые функции

## Виртуальная примерка

```
POST /kling/v1/images/kolors-virtual-try-on
```

На данный момент единственной открытой продвинутой возможностью Kling является виртуальная примерка. Этот маршрут уже прошёл успешную ограниченную проверку и интегрирован в закрытый цикл `Задача выполнена -> R2 архивирование -> media.crazyrouter.com`.

### Параметры запроса

| Параметр | Тип | Обязателен | Описание |
|------|------|------|------|
| `model_name` | string | Нет | Популярные модели: `kolors-virtual-try-on-v1`, `kolors-virtual-try-on-v1-5` |
| `human_image` | string | Да | Фото человека, поддерживаются URL или Base64 |
| `cloth_image` | string | Да | Фото одежды, поддерживаются URL или Base64 |
| `callback_url` | string | Нет | Адрес для обратного вызова |
| `external_task_id` | string | Нет | Пользовательский ID задачи на стороне бизнеса |

### Пример запроса

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/images/kolors-virtual-try-on \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kolors-virtual-try-on-v1",
    "human_image": "https://example.com/person.jpg",
    "cloth_image": "https://example.com/jacket.jpg"
  }'
```

### Пример успешного ответа при отправке

```json
{
  "created_at": 1774585120,
  "id": "866361099762425934",
  "model": "kolors-virtual-try-on-v1",
  "object": "video",

  "status": "",

}
```
