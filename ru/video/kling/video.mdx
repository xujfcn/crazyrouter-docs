# Генерация видео Kling

Crazyrouter на данный момент для клиентов публично разделяет линию видео Kling на две семейства моделей по официальному протоколу:

| Маршрутизируемое семейство | Путь отправки | Путь запроса | Доступные на текущий момент модели |
|------|------|------|------|
| Стандартное Kling видео | `POST /kling/v1/videos/text2video` `POST /kling/v1/videos/image2video` `POST /kling/v1/videos/multi-image2video` | `GET /kling/v1/videos/text2video/{task_id}` `GET /kling/v1/videos/image2video/{task_id}` `GET /kling/v1/videos/multi-image2video/{task_id}` | `kling-v2-5-turbo` `kling-v2-6` `kling-v3` |
| Kling Omni видео | `POST /kling/v1/videos/omni-video` | `GET /kling/v1/videos/omni-video/{task_id}` | `kling-v3` `kling-v3` |

Все задачи выполняются асинхронно. Результаты запроса в первую очередь возвращают архивный адрес Crazyrouter, например, `https://media.crazyrouter.com/...`.

## Первые 5 моделей и их возможности

| Модель | Семейство маршрутизаторов | Текущие клиентские возможности | Статус верификации | Краткое описание тарификации |
|------|------|------|------|------|
| `kling-v2-5-turbo` | Стандартное Kling видео | Генерация видео по тексту, по изображению, по первой/первой и последней кадрам, по референсному изображению | `Beta` | `mode + duration` |
| `kling-v2-6` | Стандартное Kling видео | Генерация видео по тексту, по изображению, по первой/первой и последней кадрам, по референсному изображению, звук, голосовое управление, управление движением | `Beta` | `mode + duration + sound + voice control` |
| `kling-v3` | Стандартное Kling видео | Генерация видео по тексту, по изображению, по первой/первой и последней кадрам, по референсному изображению, управление движением, использование стандартных элементов маршрутизации | `Beta` | `mode + duration + sound`; управление движением тарифицируется отдельно |
| `kling-v3` | Kling Omni видео | Omni-видео, ссылки на изображения/элементы/видео/звук | `Beta` | `mode + duration + sound + video input` |

<Note>
  Клиентские возможности и перечень полей определяются официальным протоколом Kling; Crazyrouter рассматривает сторонние каналы только как внутренних провайдеров и не раскрывает сторонние протоколы клиентам. Цены определяются актуальной страницей Pricing.
</Note>

<Note>
  На текущий момент первые 5 моделей Kling уже синхронизированы с официальными полями и матрицей ценообразования, но статус возможностей временно помечается как `Beta`. Через некоторое время после выхода в продакшн на основании статистики и логов эксплуатации будут проводиться поэтапные изменения статуса.
</Note>

## Стандартное Kling видео

```
POST /kling/v1/videos/text2video
POST /kling/v1/videos/image2video
POST /kling/v1/videos/multi-image2video
```

### Рекомендуемые на данный момент модели

- `kling-v2-5-turbo`
- `kling-v2-6`
- `kling-v3`

### Параметры генерации видео из текста

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model_name` | string | Да | Стандартная модель Kling видео |
| `prompt` | string | Да | Текстовое описание видео |
| `image_urls` | array[string] | Нет | Официальный первый кадр / первая и последняя кадры. Рекомендуется явно передавать при использовании `@element_name` |
| `negative_prompt` | string | Нет | Негативные ключевые слова |
| `duration` | string/integer | Нет | Обычно `5` или `10` |
| `aspect_ratio` | string | Нет | Например, `16:9`, `9:16`, `1:1` |
| `mode` | string | Нет | Режим генерации, например `std`, `pro` |
| `sound` | string / boolean | Нет | Рекомендуется использовать официальные значения `on` / `off` |
| `multi_shots` | boolean | Нет | Официальное включение мультикадров; также поддерживается псевдоним `multi_shot` |
| `multi_prompt` | array | Обязателен при определённых условиях | Описание мультикадров, не более 5 сегментов в одной задаче |
| `kling_elements` | array | Нет | Ссылки на стандартные элементы маршрута `kling-v3`, используются с `@element_name` в описании |
| `cfg_scale` | number | Нет | Сила направляющего влияния |
| `camera_control` | object | Нет | Параметры управления кадром |
| `callback_url` | string | Нет | Callback-адрес |
| `external_task_id` | string | Нет | Кастомный идентификатор задачи для клиента |

### Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/videos/text2video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kling-v2-5-turbo",
    "prompt": "一只猫咪在花园里追蝴蝶，阳光明媚，电影级画质",
    "negative_prompt": "模糊, 低质量, 变形",
    "duration": "5",
    "aspect_ratio": "16:9",
    "mode": "std"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/kling/v1/videos/text2video",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model_name": "kling-v2-5-turbo",
        "prompt": "一只猫咪在花园里追蝴蝶，阳光明媚",
        "duration": "5",
        "aspect_ratio": "16:9",
        "mode": "std"
    }
)

print(response.json())
```

### Пример генерации видео по изображению

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/videos/image2video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kling-v3",
    "prompt": "图片中的人物开始微笑并缓缓转头",
    "image": "https://example.com/portrait.jpg",
    "duration": "5",
    "mode": "std"
  }'
```

Официальный приоритет поля — `image_urls`. `image + image_tail` все еще можно использовать — он будет рассматриваться как совместимый псевдоним для первого/последнего кадра. Видео задачи выполняются асинхронно, пожалуйста, используйте [запрос статуса задачи](/ru/video/kling/query) для получения конечного результата.

### Генерация видео после загрузки локального референсного изображения

Если референсное изображение локальное, сначала используйте временное хранилище изображений для получения публичного URL, а затем передайте его Kling. Временные изображения хранятся 72 часа, в течение срока хранения ежедневная тарификация не применяется.

```bash cURL
UPLOAD_RESPONSE=$(curl -sS -X POST https://api.crazyrouter.com/v1/files/uploads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@./portrait.png" \
  -F "purpose=model_input")

IMAGE_URL=$(python -c "import json,sys; print(json.load(sys.stdin)['url'])" <<< "$UPLOAD_RESPONSE")

curl -X POST https://api.crazyrouter.com/kling/v1/videos/image2video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d "{
    \"model_name\": \"kling-v3\",
    \"prompt\": \"图片中的人物缓缓转头并微笑，镜头轻微推进，电影级光影\",
    \"image_urls\": [\"$IMAGE_URL\"],
    \"duration\": \"5\",
    \"mode\": \"std\"
  }"
```

### Параметры генерации видео по референсному изображению

```
POST /kling/v1/videos/multi-image2video
```

Этот путь соответствует официальной стандартной функции Kling `Reference`. Он отличается от `image2video`, так как не использует `image` / `image_tail`, а вместо этого использует официальный `image_list` как источник референсных материалов.

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model_name` | string | Да | Стандартная модель Kling видео |
| `prompt` | string | Да | Описание соответствия референсному изображению и действий |
| `image_list` | array | Да | Официальный список референсных изображений |
| `negative_prompt` | string | Нет | Негативные ключевые слова |
| `duration` | string/integer | Нет | Обычно `5` или `10` |
| `aspect_ratio` | string | Нет | Соотношение сторон результата |
| `mode` | string | Нет | Режим генерации |
| `sound` | string / boolean | Нет | Рекомендуется использовать официальные значения `on` / `off` |
| `multi_shots` | boolean | Нет | Официальное включение мультикадров; также поддерживается псевдоним `multi_shot` |
| `multi_prompt` | array | Обязателен при определённых условиях | Описание мультикадров |
| `cfg_scale` | number | Нет | Сила направляющего влияния |
| `camera_control` | object | Нет | Параметры управления кадром |
| `callback_url` | string | Нет | Callback-адрес |
| `external_task_id` | string | Нет | Кастомный идентификатор задачи для клиента |

### Пример генерации видео по референсному изображению

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/videos/multi-image2video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kling-v3",
    "prompt": "保持同一只柴犬的形象，在草地上向前奔跑",
    "duration": "5",
    "aspect_ratio": "16:9",
    "mode": "pro",
    "image_list": [
      {
        "image_id": 1,
        "image_url": "https://example.com/reference-1.png"
      },
      {
        "image_id": 2,
        "image_url": "https://example.com/reference-2.png"
      }
    ]
  }'
```

<Note>
  `multi-image2video` является входной точкой для генерации по референсному изображению стандартной линии Kling; если ваш ввод — первый кадр или первая и последняя кадры, продолжайте использовать `image2video`. Для статуса задачи используйте `GET /kling/v1/videos/multi-image2video/{task_id}`.
</Note>

## Kling Omni видео

```
POST /kling/v1/videos/omni-video
```

### Доступные на данный момент модели

- `kling-v3`

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model_name` | string | Да | Поддерживается только `kling-v3` |
| `prompt` | string | Да | Официальные Omni-подсказки, можно ссылаться на объекты `image_list`, `element_list`, `video_list`, `voice_list` |
| `sound` | string | Нет | Официальные значения — `on` / `off` |
| `duration` | string/integer | Нет | Обычно `5`, максимальные значения определяются официальной документацией по каждой модели |
| `aspect_ratio` | string | Нет | Например, `16:9`, `9:16`, `1:1` |
| `mode` | string | Нет | Режим генерации, например `std`, `pro` |
| `multi_shots` | boolean | Нет | Официальное включение мультикадров; поддерживается псевдоним `multi_shot` |
| `multi_prompt` | array | Обязателен при определённых условиях | Описание мультикадров |
| `image_list` | array | Нет | Официальный список референсных изображений |
| `element_list` | array | Нет | Официальный список референсных элементов |
| `video_list` | array | Нет | Официальный список референсных видео |
| `voice_list` | array | Нет | Официальный список референсных звуков |
| `callback_url` | string | Нет | Callback-адрес |
| `external_task_id` | string | Нет | Кастомный идентификатор задачи для клиента |

### Пример Omni-запроса

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/videos/omni-video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model_name": "kling-v3",
    "prompt": "<<<image_1>>> 在雨夜巷子里向镜头走来",
    "sound": "on",
    "duration": "5",
    "aspect_ratio": "16:9",
    "mode": "pro",
    "image_list": [
      {
        "image_id": 1,
        "image_url": "https://example.com/reference.png"
      }
    ]
  }'
```

<Note>
  Для маршрутизации Omni рекомендуем использовать официальный `element_list`, также поддерживается псевдоним `kling_elements`. Для статуса задачи используйте путь того же семейства, что и при отправке — `GET /kling/v1/videos/omni-video/{task_id}`.
</Note>
