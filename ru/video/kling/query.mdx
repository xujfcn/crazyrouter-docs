# Проверка задач Kling

## Доступные пути для запросов задач

| Путь | Назначение |
|------|------|
| `GET /kling/v1/videos/text2video/{task_id}` | Запрос задачи по текстовой генерации видео |
| `GET /kling/v1/videos/image2video/{task_id}` | Запрос задачи по генерации видео из изображения |
| `GET /kling/v1/videos/multi-image2video/{task_id}` | Запрос задачи по генерации видео с использованием референса |
| `GET /kling/v1/videos/omni-video/{task_id}` | Запрос задачи генерации Omni-видео |
| `GET /kling/v1/images/generations/{task_id}` | Запрос задачи генерации изображения |
| `GET /kling/v1/images/kolors-virtual-try-on/{task_id}` | Запрос задачи виртуальной примерки |

## Формат ответа

Все интерфейсы запроса Kling возвращают одинаковую структуру задачи:

```json
{
  "code": "success",
  "message": "",
  "data": {
    "error": null,
    "format": "mp4",
    "metadata": null,
    "status": "SUCCESS",
    "task_id": "866168216002236456",
    "result_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/kling/866168216002236456.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/kling/866168216002236456.mp4"
  }
}
```

### В очереди

```json
{
  "code": "success",
  "message": "",
  "data": {
    "error": null,
    "format": "mp4",
    "metadata": null,
    "status": "queued",
    "task_id": "task_abc123",
    "result_url": "",
    "artifact_url": ""
  }
}
```

### В обработке

```json
{
  "code": "success",
  "message": "",
  "data": {
    "error": null,
    "format": "mp4",
    "metadata": null,
    "status": "processing",
    "task_id": "task_abc123",
    "result_url": "",
    "artifact_url": ""
  }
}
```

### Завершено

```json
{
  "code": "success",
  "message": "",
  "data": {
    "error": null,
    "format": "mp4",
    "metadata": null,
    "status": "SUCCESS",
    "task_id": "866168216002236456",
    "result_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/kling/866168216002236456.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/kling/866168216002236456.mp4"
  }
}
```

### Ошибка

```json
{
  "code": "success",
  "message": "",
  "data": {
    "error": {
      "message": "content moderation failed",
      "code": "task_failed"
    },
    "format": "mp4",
    "metadata": null,
    "status": "failed",
    "task_id": "task_abc123",
    "result_url": "",
    "artifact_url": ""
  }
}
```

## Статусы задачи

| Статус | Описание |
|------|------|
| `queued` | Отправлено или в очереди |
| `processing` | Генерируется |
| `SUCCESS` | Завершено, `result_url` или `artifact_url` доступны напрямую |
| `failed` | Неуспешно завершено (ошибка) |

## Пример полного процесса

```python Python
import requests
import time

API_KEY = "YOUR_API_KEY"
BASE_URL = "https://api.crazyrouter.com"
headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {API_KEY}"
}

# 1. 提交文生视频任务
resp = requests.post(
    f"{BASE_URL}/kling/v1/videos/text2video",
    headers=headers,
    json={
        "model_name": "kling-v2-5-turbo",
        "prompt": "一只猫咪在花园里追蝴蝶",
        "duration": "5",
        "aspect_ratio": "16:9"
    }
)
task_id = resp.json()["data"]["task_id"]

# 2. 轮询查询
while True:
    resp = requests.get(
        f"{BASE_URL}/kling/v1/videos/text2video/{task_id}",
        headers=headers
    )
    data = resp.json()["data"]

    if data["status"] == "SUCCESS":
        print(f"视频地址: {data.get('artifact_url') or data.get('result_url')}")
        break
    if data["status"] == "failed":
        print(f"失败: {data['error']}")
        break

    time.sleep(10)
```

<Note>
  Для стандартных видео, Omni-видео, изображений и задач виртуальной примерки Kling возможен возврат внутреннего архивного адреса `media.crazyrouter.com/...`. Для клиента предпочтительно использовать `artifact_url` или `result_url`, повторный разбор исходного CDN не требуется.
</Note>
