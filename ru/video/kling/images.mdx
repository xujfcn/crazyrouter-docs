# Генерация изображений Kling

```
POST /kling/v1/images/generations
```

Текущая открытая документация гарантирует только основной путь генерации изображений Kling. Не следует ошибочно считать не опубликованные поля расширения image-side стабильным контрактом для клиентов.

## Текущий подтверждённый спектр

- `kling-v2-5-turbo` Генерация изображений прошла bounded верификацию
- В успешном результате приоритетно возвращается адрес архива Crazyrouter, например `https://media.crazyrouter.com/...png`

## Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model` | string | Нет | Обычно используется пример `kling-v2-5-turbo` |
| `prompt` | string | Да | Описывающее изображение слово-подсказка |
| `negative_prompt` | string | Нет | Отрицательное слово-подсказка |
| `aspect_ratio` | string | Нет | Например `1:1`, `16:9`, `9:16` |
| `n` | integer | Нет | Количество генераций, по умолчанию `1` |
| `callback_url` | string | Нет | Адрес callback |
| `external_task_id` | string | Нет | Пользовательский ID задачи бизнес-стороны |

## Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "kling-v2-5-turbo",
    "prompt": "一只戴着墨镜的柴犬，写实摄影风格",
    "negative_prompt": "blurry, low quality",
    "aspect_ratio": "1:1",
    "n": 1
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/kling/v1/images/generations",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "kling-v2-5-turbo",
        "prompt": "一只戴着墨镜的柴犬，写实摄影风格",
        "negative_prompt": "blurry, low quality",
        "aspect_ratio": "1:1",
        "n": 1
    }
)

print(response.json())
```
