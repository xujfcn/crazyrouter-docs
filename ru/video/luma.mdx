# Luma

Luma Dream Machine предоставляет возможности высококачественной генерации видео. Официальная документация: [docs.lumalabs.ai](https://docs.lumalabs.ai/docs/video-generation)

## Создать видео

```
POST /luma/generations
```

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `user_prompt` | string | Да | Текстовый промпт для описания видео |
| `model_name` | string | Нет | Название модели: `ray-v1`, `ray-v2` |
| `duration` | string | Нет | Длительность видео (секунды) |
| `resolution` | string | Нет | Разрешение: `540p`, `720p`, `1080p` |
| `expand_prompt` | boolean | Нет | Автоматически дополнять промпт |
| `image_url` | string | Нет | URL референсного изображения для первого кадра |
| `image_end_url` | string | Нет | URL референсного изображения для последнего кадра |

### Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/luma/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "user_prompt": "A drone shot flying over a tropical island with crystal clear water",
    "model_name": "ray-v2",
    "duration": "5",
    "resolution": "720p",
    "expand_prompt": true
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/luma/generations",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "user_prompt": "A drone shot flying over a tropical island",
        "model_name": "ray-v2",
        "duration": "5",
        "resolution": "720p"
    }
)

print(response.json())
```

</CodeGroup>

### Пример ответа

```json
{
  "id": "luma_gen_abc123",
  "state": "queued",
  "created_at": "2024-03-01T12:00:00Z"
}
```

## Генерация видео по изображению

Передайте `image_url` в качестве первого кадра:

```json
{
  "user_prompt": "The person in the image starts walking forward",
  "model_name": "ray-v2",
  "image_url": "https://example.com/portrait.jpg"
}
```

Режим первого и последнего кадра:

```json
{
  "user_prompt": "Smooth transition between two scenes",
  "model_name": "ray-v2",
  "image_url": "https://example.com/start.jpg",
  "image_end_url": "https://example.com/end.jpg"
}
```

## Запрос статуса задачи

```
GET /luma/generations/{task_id}
```

```bash cURL
curl https://api.crazyrouter.com/luma/generations/luma_gen_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Пример ответа

```json
{
  "id": "luma_gen_abc123",
  "state": "completed",
  "created_at": "2024-03-01T12:00:00Z",
  "video": {
    "url": "https://storage.cdn-luma.com/...",
    "download_url": "https://storage.cdn-luma.com/..."
  }
}
```

## Продление видео

```
POST /luma/generations/{task_id}/extend
```

Продлите уже завершённое видео.

```bash cURL
curl -X POST https://api.crazyrouter.com/luma/generations/luma_gen_abc123/extend \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "user_prompt": "Continue the drone shot, camera pans to reveal a beach resort"
  }'
```

### Статусы задачи

| Статус | Описание |
|------|------|
| `queued` | В очереди |
| `dreaming` | Генерируется |
| `completed` | Завершено |
| `failed` | Неудачно |
