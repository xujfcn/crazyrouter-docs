# Единый видео API

Crazyrouter предоставляет единый интерфейс генерации видео, поддерживает вызов различных видео моделей через одинаковый формат API.

<Note>
  `Seedance` На данный момент не рекомендуется использовать единый протокол `/v1/video/*`; пожалуйста, используйте нативный `/volc/v1/contents/generations/tasks`, см. [Seedance](/ru/video/seedance).
</Note>

## Поддерживаемые модели

| Модель | Описание |
|------|------|
| `veo-3.1-fast` | Google Veo 3.1 Fast |
| `veo-3.1-quality` | Google Veo 3.1 Quality |
| `wan2.2-t2v-plus` | Wan создание видео из текста |
| `wan2.5-t2v-preview` | Wan создание видео из текста |

## Создать видео

```
POST /v1/video/create
```

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model` | string | Да | Название модели |
| `prompt` | string | Да | Описательные ключевые слова для видео |
| `aspect_ratio` | string | Нет | Соотношение сторон: `16:9`, `9:16`, `1:1` |
| `size` | string | Нет | Размер видео, например `1280x720` |
| `images` | array | Нет | Для публичной генерации видео по изображению обычно передается `1` ссылок на изображения |
| `duration` | integer | Нет | Длительность видео (секунды) |

### Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "veo-3.1-quality",
    "prompt": "一只金毛犬在海滩上奔跑，慢动作，电影级画质",
    "aspect_ratio": "16:9"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/video/create",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "veo-3.1-quality",
        "prompt": "一只金毛犬在海滩上奔跑，慢动作，电影级画质",
        "aspect_ratio": "16:9"
    }
)

data = response.json()
task_id = data["task_id"]
print(f"任务 ID: {task_id}")
```

</CodeGroup>

### Ответ при создании

```json
{
  "task_id": "video_task_abc123",
  "status": "processing"
}
```

## Генерация видео из изображения

В параметре `images` передайте изображение для референса:

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "wan-ai/wan2.1-i2v-14b-720p",
    "prompt": "图片中的人物开始微笑并挥手",
    "images": ["https://example.com/portrait.jpg"],
    "aspect_ratio": "16:9"
  }'
```

## Запрос задачи

```
GET /v1/video/query?id={task_id}
```

### Пример запроса

```bash cURL
curl "https://api.crazyrouter.com/v1/video/query?id=video_task_abc123" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Ответ на запрос (в обработке)

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "video_task_abc123",
    "status": "processing",
    "url": ""
  }
}
```

### Ответ на запрос (завершено)

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "video_task_abc123",
    "status": "SUCCESS",
    "url": "https://media.crazyrouter.com/task-artifacts/example.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/example.mp4"
  }
}
```

### Статус задачи

| Статус | Описание |
|------|------|
| `queued` | В очереди |
| `processing` | В обработке |
| `SUCCESS` | Завершено |
| `failed` | Ошибка |

## Пример полного процесса

```python Python
import requests
import time

API_KEY = "YOUR_API_KEY"
BASE_URL = "https://api.crazyrouter.com"
headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {API_KEY}"
}

# 1. 创建视频任务
resp = requests.post(f"{BASE_URL}/v1/video/create", headers=headers, json={
    "model": "veo-3.1-quality",
    "prompt": "一只金毛犬在海滩上奔跑，慢动作",
    "aspect_ratio": "16:9"
})
task_id = resp.json()["task_id"]
print(f"任务已创建: {task_id}")

# 2. 轮询查询状态
while True:
    resp = requests.get(f"{BASE_URL}/v1/video/query?id={task_id}", headers=headers)
    result = resp.json().get("data", resp.json())
    status = result["status"]
    print(f"状态: {status}")

    if status == "SUCCESS":
        print(f"视频地址: {result.get('artifact_url') or result.get('url')}")
        break
    elif status == "failed":
        print("视频生成失败")
        break

    time.sleep(10)
```

<Note>
  Генерация видео обычно занимает 1-5 минут; рекомендуется интервал опроса 10 секунд.
</Note>
