# Seedance

Seedance — это семейство моделей для генерации видео от ByteDance / Doubao. В данный момент Crazyrouter для клиентов придерживается нативного протокола `/volc/v1/*` Volcano и больше не использует старый унифицированный видеоинтерфейс `doubao-seedance-2-0-fast` как основной публичный протокол.

Если вы хотите узнать **реальную логику расчёта стоимости Seedance 2.0 / 2.0 Fast в Crazyrouter**, включая "почему токены списываются после завершения задачи" и "можно ли фиксированно пересчитывать токены в секунды", перейдите на специальную страницу: [Объяснение тарификации Seedance 2.0](/ru/video/seedance-2-billing).

## Текущие публичные модели

| Модель | Текущее публичное позиционирование |
|------|------|
| `doubao-seedance-1-0-lite-t2v` | Генерация видео по тексту |
| `doubao-seedance-1-0-lite-i2v` | Генерация видео по одной картинке |
| `doubao-seedance-1-0-pro` | Универсальная высококачественная генерация видео |
| `doubao-seedance-1-0-pro-fast` | Универсальная быстрая генерация видео |
| `doubao-seedance-1-5-pro` | Более продвинутая версия, в будущем возможно расширение официальных параметров возможностей |
| `doubao-seedance-2-0` | Seedance 2.0 Официальная мультимодальная генерация видео |
| `doubao-seedance-2-0-fast` | Seedance 2.0 Fast Официальная мультимодальная генерация видео |

## Отправка задания на создание видео

```
POST /volc/v1/contents/generations/tasks
```

### Текущие публичные параметры запроса

| Параметр | Тип | Обязателен | Описание |
|------|------|------|------|
| `model` | string | да | Имя клиентской модели, используйте каноническое имя модели из таблицы выше |
| `content` | array | да | Массив входного контента |
| `content[].type` | string | да | В данный момент поддерживаются `text`, `image_url`, `video_url`, `audio_url`, `draft_task` |
| `content[].text` | string | обязательно при условии | Заполняется подсказка при `type=text` |
| `content[].image_url.url` | string | обязательно при условии | Заполняется URL картинки при `type=image_url` |
| `content[].video_url.url` | string | обязательно при условии | Заполняется URL референсного видео при `type=video_url` |
| `content[].audio_url.url` | string | обязательно при условии | Заполняется URL референсного аудио при `type=audio_url` |
| `content[].role` | string | опционально | Seedance 2.0 поддерживает `first_frame`, `last_frame`, `reference_image`, `reference_video`, `reference_audio` |
| `generate_audio` | boolean | опционально | Указывает, нужно ли генерировать аудио в Seedance 2.0 |
| `ratio` | string | опционально | Соотношение сторон вывода, например `16:9` |
| `resolution` | string | опционально | Seedance 2.0 / 2.0 fast в данный момент поддерживают только `480p`, `720p` |
| `duration` | integer | опционально | Seedance 2.0 / 2.0 fast поддерживают `4-15` или `-1` |
| `watermark` | boolean | опционально | Нужно ли добавлять водяной знак |
| `seed` | integer | опционально | Случайное зерно |

### Официальные ограничения Seedance 2.0

- Поддерживаются четыре модальности входа: текст, изображение, видео, аудио.
- Поддерживаются мультимодальные референсы: не более `9` изображений, `3` видео, `3` аудио, общий лимит файлов — `12`.
- Поддерживаемые форматы изображений: `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`; максимальный размер изображения — `< 30MB`.
- Поддерживаемые форматы видео: `mp4`, `mov`; максимум `3` видео-референсов, рекомендуемая общая длительность — `[2, 15]s`, общий размер файлов — `< 50MB`.
- Поддерживаемые форматы аудио: `mp3`, `wav`; максимум `3` аудиореференсов, общая длительность — `<= 15s`, общий размер файлов — `< 15MB`.
- Аудио нельзя подавать отдельно: требуется предоставить как минимум `1` изображений или видео одновременно.
- Поддерживаемая длительность генерируемого видео — `4-15s`, также поддерживается вариант `-1` с использованием значения длительности по умолчанию на стороне сервиса.
- Поддерживаются `480p` и `720p`; `1080p` на данный момент не поддерживается Seedance 2.0 / 2.0 fast.
- `frames` в данный момент не поддерживается Seedance 2.0 / 2.0 fast.
- `camera_fixed` также не поддерживается Seedance 2.0 / 2.0 fast.
- В плане продукта Seedance 2.0 сейчас делится на два основных сценария входа: "начальная/конечная рамка" и "универсальный референс"; для API эти различия выражаются через `content[].role` и `content[].type`.
- Для загрузки реалистичных материалов с изображением настоящих лиц действуют ограничения соответствия: изображения и видео с чёткими лицами могут быть отклонены сервисом.

### Официальные тарифы Seedance 2.0

| Модель | Официальный метод тарификации | Официальная цена |
|------|------|------|
| `doubao-seedance-2-0` | Тариф по количеству выходных токенов | С видео на входе `28 юаней (CNY) / 1 миллион выходных токенов`; без видео на входе `46 юаней (CNY) / 1 миллион выходных токенов` |
| `doubao-seedance-2-0-fast` | Тариф по количеству выходных токенов | С видео на входе `22 юаня (CNY) / 1 миллион выходных токенов`; без видео на входе `37 юаней (CNY) / 1 миллион выходных токенов` |

<Note>
  MIME-тип, длительность и размер материалов по удалённой ссылке в итоге проверяются на стороне сервиса; Crazyrouter на этапе отправки проверяет количество, длительность, невозможность отдельной подачи аудио, а также явные ограничения (как 480p/720p / `frames` / `camera_fixed`).
</Note>

### Пример генерации видео по тексту

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/volc/v1/contents/generations/tasks \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "doubao-seedance-1-0-lite-t2v",
    "content": [
      {
        "type": "text",
        "text": "镜头缓慢推进，一只白色海鸥从海面掠过，日落金光反射在海浪上"
      }
    ]
  }'
```

## Запрос информации о задаче

```
GET /volc/v1/contents/generations/tasks/{task_id}
```

```bash cURL
curl https://api.crazyrouter.com/volc/v1/contents/generations/tasks/cgt_task_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Пример ответа (завершено)

```json
{
  "code": "success",
  "message": "",
  "data": {
    "id": "cgt_task_abc123",
    "task_id": "cgt_task_abc123",
    "model": "doubao-seedance-2-0-fast",
    "status": "SUCCESS",
    "result_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/seedance/cgt_task_abc123.mp4",
    "artifact_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/seedance/cgt_task_abc123.mp4",
    "content": {
      "video_url": "https://media.crazyrouter.com/task-artifacts/2026/06/30/seedance/cgt_task_abc123.mp4"
    }
  }
}
```

### Статусы задач

| Статус | Описание |
|------|------|
| `NOT_START` | Отправлено, ожидает обработки |
| `IN_PROGRESS` | Генерируется |
| `SUCCESS` | Завершено, результат можно получить по `result_url`, `artifact_url` или `content.video_url` |
| `FAILURE` | Ошибка (финальный статус) |

<Note>
  В текущей публичной документации гарантируется только путь native `/volc/v1/*` и каноническое имя модели. Старый `doubao-seedance-2-0-fast` сохранён только для исторических целей и не является основным протоколом для новых клиентов.
</Note>

<Note>
  Официальная стоимость Seedance поддерживается по метрике `per_output_token`, а не по секундам; если в разделе pricing в дальнейшем появится унифицированное отображение цен платформы, это следует понимать как внутреннюю маркетинговую единицу платформы, а не официальный формат тарификации сервиса.
</Note>
