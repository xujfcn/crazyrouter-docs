# MiniMax Видео

MiniMax (Hailuo) предоставляет высококачественные возможности генерации видео.

## Создать видео

```
POST /minimax/v1/video_generation
```

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model` | string | да | Имя модели, например `video-01`, `video-01-live2d` |
| `prompt` | string | да | Промпт-описание видео |
| `first_frame_image` | string | нет | URL первого кадра изображения |

### Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/minimax/v1/video_generation \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "video-01",
    "prompt": "一只小猫在阳光下打盹，微风吹动它的毛发"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/minimax/v1/video_generation",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "video-01",
        "prompt": "一只小猫在阳光下打盹，微风吹动它的毛发"
    }
)

print(response.json())
```

</CodeGroup>

### Пример ответа

```json
{
  "task_id": "minimax_video_abc123",
  "base_resp": {
    "status_code": 0,
    "status_msg": "success"
  }
}
```

## Генерация видео по картинке

```json
{
  "model": "video-01",
  "prompt": "图片中的人物开始微笑",
  "first_frame_image": "https://example.com/portrait.jpg"
}
```

---

## Проверка статуса задачи

```
GET /minimax/v1/query/video_generation?task_id={task_id}
```

```bash cURL
curl "https://api.crazyrouter.com/minimax/v1/query/video_generation?task_id=minimax_video_abc123" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Пример ответа (завершено)

```json
{
  "task_id": "minimax_video_abc123",
  "status": "Success",
  "file_id": "file_abc123",
  "base_resp": {
    "status_code": 0,
    "status_msg": "success"
  }
}
```

### Статусы задачи

| Статус | Описание |
|------|------|
| `Queueing` | В очереди |
| `Processing` | В обработке |
| `Success` | Успешно |
| `Fail` | Ошибка |
