# Jimeng

Jimeng — это сервис генерации видео от компании Bytedance. В настоящее время Crazyrouter рекомендует использовать только путь `/jimeng/*` для клиентских интеграций и не раскрывает основной протокол `Action + Version` напрямую.

## Текущий проверенный диапазон

- `POST /jimeng/submit/videos` подтвержден для отправки текста-видео `jimeng-video-3.0`
- Поддерживается ввод одного изображения и одиночный `recamera`
- В настоящее время стабильные основные положительные примеры сосредоточены на `1080P`
- `720P / recamera` по-прежнему является расширением carrier-класса для `ch119` и не входит в перечень жёстко закреплённых контрактов для расширения
- В результатах поиска приоритетно возвращаются медиассылки, уже архивированные в Crazyrouter, например, `https://media.crazyrouter.com/...`
- Для задач-кандидатов `expired` путь повторного захвата закрыт, однако примеры с истёкшим сроком всё ещё ожидают в фоне расширенное окно хранения, что не влияет на основной доступ

## Отправка видео-задачи

```
POST /jimeng/submit/videos
```

### Рекомендуемые модели

- `jimeng-video-3.0`: текущая основная рекомендованная модель для клиентов

### Параметры запроса

| Параметр | Тип | Обязателен | Описание |
|------|------|------|------|
| `model` | string | да | Имя клиентской модели, рекомендовано использовать `jimeng-video-3.0` |
| `prompt` | string | обязательно при определённых условиях | Для текст-видео рекомендуется указывать; также рекомендуется добавить описание действия для `recamera` |
| `duration` | integer | нет | Рекомендуется использовать `5` или `10` |
| `aspect_ratio` | string | нет | Пропорции, например, `16:9`, `9:16` |
| `image_url` | string | нет | Ввод по URL одного изображения |
| `binary_data_base64` | string[] | нет | Ввод одного изображения в Base64 |
| `image_urls` | string[] | нет | Совместимый массивный ввод; сейчас не следует обещать поддержку нескольких эталонных изображений |
| `template_id` | string | нет | Одиночный шаблон `recamera` изображения, например, `handheld` |
| `camera_strength` | string | нет | Одиночная интенсивность `recamera` для изображения, например: `weak`, `medium`, `strong` |
| `req_key` | string | нет | Используется для отладки или совместимых сценариев, не рекомендуется для обычной интеграции |

### Пример генерации видео по тексту

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/jimeng/submit/videos \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "jimeng-video-3.0",
    "prompt": "镜头缓慢推进，一只橘猫在窗边打哈欠，晨光柔和",
    "duration": 5,
    "aspect_ratio": "9:16"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/jimeng/submit/videos",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "model": "jimeng-video-3.0",
        "prompt": "镜头缓慢推进，一只橘猫在窗边打哈欠，晨光柔和",
        "duration": 5,
        "aspect_ratio": "9:16"
    }
)

print(response.json())
```

</CodeGroup>

## Запрос статуса задачи

```
GET /jimeng/fetch/{task_id}
```

```bash cURL
curl https://api.crazyrouter.com/jimeng/fetch/2526913314163451526 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Пример ответа (завершено)

```json
{
  "code": "success",
  "message": "",
  "data": {
    "error": null,
    "format": "mp4",
    "metadata": null,
    "status": "succeeded",
    "task_id": "2526913314163451526",
    "url": "https://media.crazyrouter.com/task-artifacts/2026/03/27/51/generate/2526913314163451526.mp4"
  }
}
```

### Статусы задачи

| Статус | Описание |
|------|------|
| `queued` | отправлено или в очереди |
| `processing` | в процессе генерации |
| `succeeded` | выполнено, `url` можно сразу получить |
| `failed` | окончательная ошибка |

<Note>
  В текущей публичной документации гарантируется только ввод одного изображения и одиночный `recamera`. Не следует ошибочно трактовать `image_urls` как контракт на множество эталонных изображений Jimeng, а также `frames` — как рекомендованный публичный параметр; неподдерживаемые значения `frames` могут вызвать отложенный отказ на этапе алгоритма upstream.
</Note>

<Note>
  Сейчас публичная документация ограничена проверенным стабильным диапазоном: `jimeng-video-3.0 + Генерация видео из текста / Ввод одного изображения / Рекамера по одному изображению`. Возможность дальнейшего расширения `720P / recamera` зависит от повторной проверки carrier-образцов, а не от того, позволит ли код репозитория продолжить сквозную передачу.
</Note>
