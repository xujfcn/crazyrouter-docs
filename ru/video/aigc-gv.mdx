# Метод вызова AIGC GV VOD

`aigc-video-gv-*` — это видео модель GV / Google Veo, интегрированная Crazyrouter через Tencent VOD. Способ вызова совпадает с AIGC Kling VOD: используется асинхронный видео-интерфейс в стиле OpenAI:

```http
POST /v1/video/generations
GET /v1/video/generations/{task_id}
```

<Note>
  `aigc-video-gv-*` использует только `/v1/video/generations` и подходящий маршрут запроса. Не отправляйте эти модели на `/v1/video/create`; несоответствие маршрута приведет к ошибке вида `model_not_found` или аналогичной ошибке вышестоящего уровня.
</Note>

## Доступные модели

| Модель | Версия upstream | Описание |
|------|------|------|
| `aigc-video-gv-3.1` | GV 3.1 | Версия высокого качества, поддерживает видео со звуком |
| `aigc-video-gv-3.1-fast` | GV 3.1 Fast | Более быстрая версия, поддерживает видео со звуком |
| `aigc-video-gv-3.1-lite` | GV 3.1 Lite | Лёгкая версия, поддерживает видео со звуком |

<Note>
  GV 3.1 из Tencent VOD — это линия Google Veo, а не Kling. Не используйте такие имена моделей, как `aigc-video-kling-3.1`.
</Note>

## Создание задачи

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-gv-3.1-fast",
    "prompt": "a cinematic product shot with natural camera movement",
    "seconds": "5",
    "metadata": {
      "resolution": "1080P",
      "sound": true
    }
  }'
```

## Генерация по изображению и мульти-референс

Для одного изображения используйте `image`; для мульти-референса рекомендуется `metadata.image_list`:

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/video/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aigc-video-gv-3.1",
    "prompt": "combine the visual style of the references into one smooth shot",
    "seconds": "5",
    "metadata": {
      "resolution": "1080P",
      "image_list": [
        {
          "url": "https://example.com/ref-1.png",
          "reference_type": "asset"
        },
        {
          "url": "https://example.com/ref-2.png",
          "reference_type": "style"
        }
      ]
    }
  }'
```

<Warning>
  Мульти-референс GV должен передаваться через `FileInfos`. Наш сайт преобразует `image_list` в `FileInfos` и не использует `LastFrameUrl` для GV мульти-запросов.
</Warning>

## Часто используемые поля metadata

| Поле | Описание |
|------|------|
| `resolution` | `720P`, `1080P`, `2K`, `4K`. Актуальные спецификации доступны на странице ценообразования |
| `sound` | Генерировать ли звук: поддерживает `true` / `false`, `on` / `off` |
| `audio_generation` | Передать прямо `Enabled` / `Disabled` |
| `image_list` | Массив мульти-референс изображений |
| `reference_type` / `ReferenceType` | Тип GV референса, обычно `asset` или `style` |

Стоимость, скидки и доступные спецификации смотрите на [странице Pricing](https://crazyrouter.com/ru/pricing).
