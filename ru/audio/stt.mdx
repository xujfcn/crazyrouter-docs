# Распознавание речи (STT)

```
POST /v1/audio/transcriptions
```

Транскрибируйте аудиофайл в текст, совместимо с форматом OpenAI Whisper API.

## Параметры запроса

| Параметр | Тип | Обязательно | Описание |
|----------|-----|-------------|----------|
| `file` | file | Да | Аудиофайл (multipart/form-data) |
| `model` | string | Да | Название модели: `whisper-1`, `whisper-1` |
| `language` | string | Нет | Язык аудио (в формате ISO-639-1), например, `zh`, `en`, `ja` |
| `response_format` | string | Нет | Формат вывода: `json` (по умолчанию), `text`, `srt`, `verbose_json`, `vtt` |
| `temperature` | number | Нет | Температура сэмплирования, 0-1 |
| `prompt` | string | Нет | Подсказка, помогающая модели понять контекст |

### Поддерживаемые форматы аудио

`mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `wav`, `webm`

## Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/audio/transcriptions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F file=@audio.mp3 \
  -F model=whisper-1 \
  -F language=zh \
  -F response_format=json
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

with open("audio.mp3", "rb") as audio_file:
    transcript = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="zh",
        response_format="json"
    )

print(transcript.text)
```

```javascript Node.js
import OpenAI from "openai";
import fs from "fs";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.crazyrouter.com/v1",
});

const transcript = await client.audio.transcriptions.create({
  model: "whisper-1",
  file: fs.createReadStream("audio.mp3"),
  language: "zh",
});

console.log(transcript.text);
```

</CodeGroup>

```json
{

```

## Перевод аудио

```
POST /v1/audio/translations
```

Переводит неанглоязычные аудио в английский текст. Параметры такие же, как в интерфейсе транскрипции.

```python Python
with open("chinese_audio.mp3", "rb") as audio_file:
    translation = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(translation.text)  # 输出英文翻译
```

<Note>
  Указание параметра `language` может повысить точность транскрипции. Максимальный размер аудиофайла — 25 МБ.
</Note>
