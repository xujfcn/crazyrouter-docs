# GPT Realtime

GPT Realtime в настоящее время не представлен в качестве публичного рекомендованного примера для Crazyrouter. Чтобы избежать копирования пользователями моделей, которые были сняты с публикации или не поддерживаются открыто, эта страница скрыта из китайской навигации, а пример запроса через WebSocket удалён.

Для публичных аудио-примеров используйте:

- [Речь в текст](/ru/audio/stt): `whisper-1`
- [Текст в речь](/ru/audio/tts): `tts-1`

<Warning>
  О повторном открытии моделей Realtime уточняйте по внутренним объявлениям `GET /v1/models`, доступным моделям в консоли и фактическим ответам производственного API.
</Warning>
