# Преобразование текста в речь (TTS)

```
POST /v1/audio/speech
```

Преобразуйте текст в естественную речь, совместим с форматом OpenAI TTS API.

## Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model` | string | Да | Название модели: `tts-1`, `tts-1`, `tts-1-hd-1106` |
| `input` | string | Да | Текст для преобразования, максимум 4096 символов |
| `voice` | string | Да | Роль голоса |
| `response_format` | string | Нет | Формат вывода: `mp3` (по умолчанию), `opus`, `aac`, `flac`, `wav`, `pcm` |
| `speed` | number | Нет | Скорость речи, 0.25-4.0, по умолчанию 1.0 |

### Доступные голоса

| Голос | Особенности |
|------|------|
| `alloy` | Нейтральный, сбалансированный |
| `echo` | Мужской, уверенный |
| `fable` | Мужской, тёплый |
| `onyx` | Мужской, глубокий |
| `nova` | Женский, живой |
| `shimmer` | Женский, мягкий |

## Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/audio/speech \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "tts-1",
    "input": "你好，欢迎使用 Crazyrouter API。今天天气真不错！",
    "voice": "nova",
    "response_format": "mp3",
    "speed": 1.0
  }' \
  --output speech.mp3
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.audio.speech.create(
    model="tts-1",
    input="你好，欢迎使用 Crazyrouter API。今天天气真不错！",
    voice="nova",
    response_format="mp3",
    speed=1.0
)

response.stream_to_file("speech.mp3")
```

```javascript Node.js
import OpenAI from "openai";
import fs from "fs";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.crazyrouter.com/v1",
});

const response = await client.audio.speech.create({
  model: "tts-1",
  input: "你好，欢迎使用 Crazyrouter API。",
  voice: "nova",
});

const buffer = Buffer.from(await response.arrayBuffer());
fs.writeFileSync("speech.mp3", buffer);
```

</CodeGroup>

Ответом является бинарный поток аудиофайла, который можно сразу сохранять.

## Сравнение моделей

| Модель | Качество | Задержка | Описание |
|------|------|------|------|
| `tts-1` | Стандартное | Низкая | Подходит для работы в реальном времени |
| `tts-1-hd-1106` | HD | Средняя | Более естественная речь |
| `tts-1` | Максимальное | Средняя | Новейшая модель, поддерживает больше языков и эмоций |

<Note>
  `tts-1` поддерживает многоязычность: язык текста определяется автоматически, и используется соответствующее произношение.
</Note>

<Warning>
  Ответ — это бинарный аудиопоток, не JSON. Используйте `--output` или осуществляйте потоковую запись в файл.
</Warning>
