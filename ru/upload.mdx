> Обновление содержания: 2026-09-28

Crazyrouter предоставляет временный публичный интерфейс для загрузки изображений, чтобы преобразовать локальные референсные изображения в публичные URL, доступные для моделей. Он подходит для таких сервисов, как Kling, Veo, Seedance, Runway, Luma, MiniMax, Nano Banana Pro, Doubao Seedream и других, которым требуются `image_url`, `image_urls`, `image_list`, `images` или `image_input`.

<Note>
  Временные изображения по умолчанию сохраняются 48 часов и автоматически очищаются по истечении срока. В течение периода хранения отдельная ежедневная оплата не требуется; на данный момент действует ограничение по квоте и скорости загрузки для предотвращения злоупотреблений.
</Note>

<Note>
  Возвращаемый `id` — это идентификатор файла на сайте, а в запросах от модели для `image_input` следует использовать возвращаемый `url`, нельзя передавать `id` напрямую. Возможность передачи `nano-banana-pro` в Base64 / multipart доступна только определённым аккаунтам.
</Note>

## Обзор интерфейса

| Сценарий | Интерфейс |
|------|------|
| Загрузка локального файла | `POST /v1/files/uploads` |
| Загрузка изображения Base64 | `POST /v1/files/uploads/base64` |
| Сохранение удалённого изображения | `POST /v1/files/uploads/url` |
| Прямое предварительно подписанное размещение R2 | `POST /v1/files/uploads/presign` |

Общие ограничения:

| Параметр | Текущие правила |
|------|------|
| Аутентификация | `Authorization: Bearer YOUR_API_KEY` |
| Поддерживаемые форматы | `image/png`, `image/jpeg`, `image/webp`, `image/gif` |
| Максимальный размер файла | 20MB |
| Квота загрузки пользователя | 200MB / скользящее окно 24 часа |
| Срок действия по умолчанию | 48 часов |
| Возвращаемый URL | `https://media.crazyrouter.com/task-artifacts/tmp-inputs/...` |

## Загрузка локального файла

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/files/uploads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@./reference.png" \
  -F "purpose=model_input"
```

Пример ответа:

```json
{
  "id": "file_e5bbce820b5941409682a9c5e9ba79f1",
  "url": "https://media.crazyrouter.com/task-artifacts/tmp-inputs/2026/05/13/user-1/file_e5bbce820b5941409682a9c5e9ba79f1.png",
  "mime_type": "image/png",
  "size": 2025,
  "expires_at": "2026-05-16T04:41:35.0131789Z"
}
```

## Загрузка Base64

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/files/uploads/base64 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "data": "data:image/png;base64,iVBORw0KGgoAAA...",
    "filename": "reference.png",
    "purpose": "model_input"
  }'
```

## Сохранение удалённого URL

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/files/uploads/url \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "url": "https://example.com/reference.png",
    "filename": "reference.png",
    "purpose": "model_input"
  }'
```

Удалённый URL должен быть адресом изображения `http` или `https`, доступным серверу Crazyrouter. Система проводит проверки размера файла, MIME-типа и защиту от SSRF.

## Прямое предварительно подписанное размещение R2

В случаях большого объёма загрузки сначала можно запросить предварительно подписанный URL, после чего клиент напрямую `PUT` отправляет изображение на конечную точку хранения. Таким образом, бинарные данные изображения не проходят через сервер приложения Crazyrouter, что удобно для рабочих процессов с ежедневной массовой загрузкой изображений.

Первый шаг: запросите URL для прямой загрузки:

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/files/uploads/presign \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "filename": "reference.jpg",
    "content_type": "image/jpeg",
    "size": 12345,
    "purpose": "model_input"
  }'
```

Пример ответа:

```json
{
  "id": "file_e5bbce820b5941409682a9c5e9ba79f1",
  "upload_url": "https://...r2.cloudflarestorage.com/...?...",
  "url": "https://media.crazyrouter.com/task-artifacts/tmp-inputs/2026/06/21/user-1/file_e5bbce820b5941409682a9c5e9ba79f1.jpg",
  "method": "PUT",
  "headers": {
    "Content-Type": "image/jpeg",
    "Content-Length": "12345"
  },
  "mime_type": "image/jpeg",
  "size": 12345,
  "expires_at": "2026-06-22T04:41:35Z",
  "upload_expires_at": "2026-06-21T04:56:35Z"
}
```

Второй шаг: клиент напрямую загружает в `upload_url`:

```bash cURL
curl -X PUT "$UPLOAD_URL" \
  -H "Content-Type: image/jpeg" \
  -H "Content-Length: 12345" \
  --data-binary @./reference.jpg
```

После завершения загрузки используйте `url` из ответа в качестве URL изображения для запроса модели.

<Warning>
  `upload_url` — это кратковременный адрес для записи, по умолчанию используемый в течение примерно 15 минут. `Content-Type` и `Content-Length` должны совпадать с данными, указанными при запросе; не передавайте `upload_url` модели, в запросах от модели используйте возвращаемый `url`.
</Warning>

## Практический пример: локальное референсное изображение для создания видео в Kling

Первый шаг: загрузите локальное референсное изображение:

```bash cURL
UPLOAD_RESPONSE=$(curl -sS -X POST https://api.crazyrouter.com/v1/files/uploads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@./portrait.png" \
  -F "purpose=model_input")

IMAGE_URL=$(python -c "import json,sys; print(json.load(sys.stdin)['url'])" <<< "$UPLOAD_RESPONSE")
echo "$IMAGE_URL"
```

Второй шаг: передайте возвращённый `IMAGE_URL` в Kling для генерации видео по изображению:

```bash cURL
curl -X POST https://api.crazyrouter.com/kling/v1/videos/image2video \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d "{
    \"model_name\": \"kling-v3\",
    \"prompt\": \"图片中的人物缓缓转头并微笑，镜头轻微推进，电影级光影\",
    \"image_urls\": [\"$IMAGE_URL\"],
    \"duration\": \"5\",
    \"mode\": \"std\"
  }"
```

После успешной отправки запроса будет возвращён идентификатор задания. Финальный результат видео можно получить с помощью [запроса статуса задания Kling](/ru/video/kling/query).

<Warning>
  Временный URL не является постоянным хранилищем материалов. Перед отправкой задания убедитесь, что URL всё ещё действителен; не используйте его в качестве долгосрочного бизнес-адреса изображения.
</Warning>
