<Note>
  Путь подключения к API: Международный основной вход — `https://api.crazyrouter.com`, для региона Восточная Азия рекомендуется использовать `https://cn.crazyrouter.com`. OpenAI-совместимые клиенты обычно добавляют `/v1` к основному домену; оригинальные клиенты Claude Code / Anthropic используют основной домен, не добавляйте `/v1`. Подробнее смотрите [API-эндпойнты](/ru/api-endpoint).
</Note>

Crazyrouter — это единый шлюз API моделей искусственного интеллекта. Вы можете использовать один API Key для вызова моделей текста, изображений, видео, аудио, Embedding, Rerank и интеграции сторонних инструментов.
