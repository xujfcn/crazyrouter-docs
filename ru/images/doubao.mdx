# Doubao Seedream

```
POST /v1/images/generations
```

На данный момент Crazyrouter предоставляет внешнее подключение к сериям моделей изображений `Seedream` на основе протокола совместимости OpenAI Images. Клиент продолжает использовать унифицированный `/v1/images/generations`; официальный и сторонние ByteDance провайдеры используются только как внутренние провайдеры и не предоставляют клиентский протокол отдельно.

## Текущие открытые модели

| Модель | Официальная версия | Текущие возможности для клиента | Статус документации |
|------|----------|--------------|----------|
| `doubao-seedream-4-0` | Seedream 4.0 | Генерация по тексту, по изображению, с несколькими референсами, батчевый вывод | Beta |
| `doubao-seedream-4-5` | Seedream 4.5 | Генерация по тексту, по изображению, с несколькими референсами, батчевый вывод | Beta |
| `doubao-seedream-5-0` | Seedream 5.0 lite | Генерация по тексту, по изображению, с несколькими референсами, батчевый вывод | Beta |
| `doubao-seedream-3-0` | Seedream 3.0 | Совместимость сохранена | Legacy |

<Note>
  Здесь "Beta" означает: клиентский протокол и определение официальных возможностей уже согласованы, но текущая производственная нагрузка и реальные artefact'ы еще дорабатываются. Официальные возможности описаны в полном объёме, незавершённые части помечены Beta.
</Note>

## Клиентский протокол

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model` | string | да | `doubao-seedream-4-0`, `doubao-seedream-4-5`, `doubao-seedream-5-0` |
| `prompt` | string | да | Промпт для генерации |
| `image_input` | string или string[] | нет | URL референс-изображения, официальная поддержка 4.0 / 4.5 / 5.0 lite ограничена `14` изображениями |
| `size` | string | нет | Размер вывода. Официально `Seedream 4.5` поддерживает `2K`, `4K` и явно заданные ширину × высоту в пределах поддерживаемого диапазона; в `Seedream 5.0 lite` требуется минимум `3,686,400` общих пикселей |
| `n` | integer | нет | Количество выдаваемых изображений, по умолчанию `1` |
| `response_format` | string | нет | `url` или `b64_json` |
| `watermark` | boolean | нет | Добавлять ли водяной знак |
| `sequential_image_generation` | string | нет | `auto` или `disabled`; для батч-вывода и генерации с связанной семантикой |
| `optimize_prompt_options` | object | нет | Официальные опции для улучшения промпта; сейчас только `Seedream 4.5` и `5.0 lite` подтверждены как `mode: "standard"` |

### Требования к размеру Seedream 5.0

Явно указанный размер `Ширина x высота` в `doubao-seedream-5-0` должен соответствовать:

```text
宽 × 高 >= 3,686,400
```

| Размер | Общее число пикселей | Соответствие минимальному порогу |
|------|--------|------------------|
| `2688x1152` | `3,096,576` | Нет; апстрим возвращает `InvalidParameter` |
| `2048x2048` | `4,194,304` | Да; при этом должен соответствовать поддерживаемым значениям ширины, высоты и соотношения сторон |

<Warning>
  Не пытайтесь повторять невалидные размеры или делать вывод о недоступности модели на их основе. Если в логах появляется "Service temporarily unavailable" или "The requested model is temporarily unavailable", сперва проверьте `size`; текущие обычные логи ошибок могут "скрывать" более точную ошибку по размеру от апстрим.
</Warning>

### Ограничения референс-изображений

- `Seedream 4.0`, `4.5`, `5.0 lite` официально поддерживают до `14` референсов
- Максимальный размер одного референса — `10MB`
- Поддерживаемые форматы файлов: `jpeg`, `png`, `webp`, `bmp`, `tiff`, `gif`
- Поддерживаемое соотношение сторон входного изображения: от `1/16` до `16`

### Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "doubao-seedream-4-5",
    "prompt": "一张高级感产品海报，主体是一只透明玻璃香水瓶，晨雾光线，简洁中文标题",
    "size": "2K",
    "n": 1,
    "response_format": "url",
    "watermark": false,
    "optimize_prompt_options": {
      "mode": "standard"
    }
  }'
```

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "doubao-seedream-4-5",
    "prompt": "基于这些参考图生成同一角色的一组商品海报，保持主体一致但镜头和布局不同",
    "image_input": [
      "https://example.com/ref-1.png",
      "https://example.com/ref-2.png"
    ],
    "size": "2K",
    "sequential_image_generation": "auto",
    "response_format": "url",
    "optimize_prompt_options": {
      "mode": "standard"
    }
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.images.generate(
    model="doubao-seedream-4-5",
    prompt="一张高级感产品海报，主体是一只透明玻璃香水瓶，晨雾光线，简洁中文标题",
    size="2K",
    n=1
)

print(response.data[0].url)
```

## Информация по синхронизации

- Клиентский протокол унифицирован в `/v1/images/generations`
- Официальные разрешения поддерживаются в `Seedream 4.5`, `2K` и `4K`; по умолчанию `2048x2048`
- В `Seedream 4.5` и `5.0 lite`, функционал `optimize_prompt_options.mode` на текущий момент синхронизируется только по `standard`; `fast` не является текущим публичным обязательством
- `Seedream 3.0` по-прежнему поддерживает совместимые алиасы, но на этой странице официальный основной приоритет — `4.0 / 4.5 / 5.0 lite`
