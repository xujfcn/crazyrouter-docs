# Нано Банан

```
POST /v1/images/generations
```

`nano-banana` — это публичный псевдоним для `nano-banana`. Пользовательская сторона использует совместимый протокол OpenAI Images; нативную передачу Gemini / Vertex, преобразование полей и выбор маршрута обрабатывает Crazyrouter на серверной стороне.

<Warning>
  Запросы на генерацию изображений, их редактирование и работу с несколькими референсами обычно требуют больше времени. Для продакшн-интеграции рекомендуется использовать основной сервисный маршрут `https://api.crazyrouter.com/v1`, полный генерирующий endpoint — `https://api.crazyrouter.com/v1/images/generations`. Для входа в аккаунт, пополнения счета и доступа к консоли используйте по-прежнему `https://crazyrouter.com`.
</Warning>

## Наименование моделей

| Рекомендуемое название модели | Эквивалентная базовая модель |
|------|------|
| `nano-banana` | `nano-banana` |

Рекомендуется использовать `nano-banana` в клиентском коде. Если ваша система уже использует `nano-banana`, можно продолжить обращаться через тот же вход `/v1/images/generations`.

## Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model` | string | да | Рекомендуется `nano-banana`; поддерживается также `nano-banana` |
| `prompt` | string | да | Инструкция генерации или редактирования |
| `image_input` | string или string[] | нет | URL эталонного изображения; если не указать — генерация по описанию |
| `resolution` | string | нет | `1K`, `2K`, `4K` |
| `aspect_ratio` | string | нет | Например `1:1`, `16:9`, `9:16`, `21:9`, `auto` |
| `output_format` | string | нет | `png`, `jpeg` / `jpg` |
| `output_compression` | integer | нет | `0-100`, используется для качества JPEG-сжатия |
| `n` | integer | нет | Количество результатов, по умолчанию `1` |

<Note>
  Не передавайте в клиентском запросе нативные поля Gemini, такие как `generationConfig`, `imageConfig`, `imageOutputOptions`, `image_output_options`. Это детали провайдера верхнего уровня, Crazyrouter автоматически преобразует из унифицированных параметров.
</Note>

## Пример генерации по описанию

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana",
    "prompt": "A clean banana icon on a white background, minimal product style",
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "png"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.generate(
    model="nano-banana",
    prompt="A clean banana icon on a white background, minimal product style",
    n=1,
    extra_body={
        "resolution": "1K",
        "aspect_ratio": "1:1",
        "output_format": "png",
    },
)

print(response.data[0].url or response.data[0].b64_json)
```

</CodeGroup>

## Пример редактирования по референсу

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana",
    "prompt": "保持主体不变，把背景改成白色电商棚拍风格",
    "image_input": [
      "https://example.com/product.png"
    ],
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "output_format": "jpeg",
    "output_compression": 85
  }'
```

## Ответ

Ответ совместим со стилем OpenAI Images. По умолчанию приоритетно читается `data[0].url`; некоторые совместимые каналы могут возвращать `data[0].b64_json`.

```json
{
  "created": 1778990000,
  "data": [
    {
      "url": "https://media.crazyrouter.com/task-artifacts/2026/05/17/sync-image/request-id-1.png"
    }
  ]
}
```

## Типичные ошибки

| Ошибочный вариант | Корректный вариант |
|------|------|
| Прямой вызов `/v1beta/models/nano-banana:generateContent` | Используйте `POST /v1/images/generations` |
| Передача в запросе `image_output_options` | Используйте унифицированные параметры `output_format`, `output_compression` |
| Только настройка base URL как `https://api.crazyrouter.com` и автодобавление OpenAI-пути через SDK | Используйте OpenAI SDK с `https://api.crazyrouter.com/v1` |
