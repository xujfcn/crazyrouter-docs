# Справка по прежнему API DALL-E

Старые примеры DALL-E 3 и дублирующая таблица размеров удалены. В публичном каталоге, проверенном 2026-10-12, нет `dall-e-3`. Исторические примеры не гарантируют доступность сейчас. Отсутствие в каталоге само по себе не означает, что все совместимые псевдонимы недоступны. Проверьте модели, доступные вашему ключу, и соответствующий API.

Для синхронной генерации выберите модель с поддержкой Images API, например `gpt-image-2`. Проверьте размеры, количество изображений и тарифы. Не переносите параметры quality/style из DALL-E в другие модели автоматически.
