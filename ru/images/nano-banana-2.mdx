# Nano Banana 2

```
POST /v1/images/generations
```

`nano-banana-2` является публичным псевдонимом `nano-banana-2`. Пользовательский интерфейс использует совместимый протокол OpenAI Images; сервер преобразует такие параметры, как `output_format`, `output_compression`, `resolution`, `aspect_ratio`, в нативные запросы Gemini / Vertex.

<Warning>
  `nano-banana-2` относится к моделям для генерации изображений с длительным временем обработки. Для промышленного внедрения рекомендуется использовать основную линию `https://api.crazyrouter.com/v1`, полный конечный пункт: `https://api.crazyrouter.com/v1/images/generations`. Вход в аккаунт, пополнение баланса и панель управления остаются на `https://crazyrouter.com`.
</Warning>

## Название модели

| Рекомендуемое имя | Эквивалентная базовая модель |
|------|------|
| `nano-banana-2` | `nano-banana-2` |

Рекомендуется использовать `nano-banana-2` в клиентском коде. Если ваша система уже напрямую использует `nano-banana-2`, можно продолжить обращаться через тот же вход `/v1/images/generations`.

## Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `model` | string | Да | Рекомендуется `nano-banana-2`; также совместим с `nano-banana-2` |
| `prompt` | string | Да | Инструкция для генерации или редактирования |
| `image_input` | string или string[] | Нет | URL референс-изображения; если не указано — генерация по тексту |
| `resolution` | string | Нет | `1K`, `2K`, `4K` |
| `aspect_ratio` | string | Нет | Как `1:1`, `16:9`, `9:16`, `21:9`, `auto` |
| `output_format` | string | Нет | `png`, `jpeg` / `jpg` |
| `output_compression` | integer | Нет | `0-100`, используется для качества JPEG сжатия |
| `n` | integer | Нет | Количество изображений для генерации, по умолчанию `1` |

<Note>
  Не указывайте нативные поля Gemini в клиентских запросах, такие как `generationConfig`, `imageConfig`, `imageOutputOptions`, `image_output_options`. Эти поля автоматически формируются Crazyrouter на сервере в соответствии с текущим протоколом upstream.
</Note>

## Пример генерации по тексту

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-2",
    "prompt": "A clean ecommerce hero shot of a red apple on a white background",
    "resolution": "1K",
    "aspect_ratio": "16:9",
    "output_format": "jpeg",
    "output_compression": 85
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.generate(
    model="nano-banana-2",
    prompt="A clean ecommerce hero shot of a red apple on a white background",
    n=1,
    extra_body={
        "resolution": "1K",
        "aspect_ratio": "16:9",
        "output_format": "jpeg",
        "output_compression": 85,
    },
)

print(response.data[0].url or response.data[0].b64_json)
```

</CodeGroup>

## Пример редактирования по референс-изображению

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "nano-banana-2",
    "prompt": "把参考图改成横幅广告图，保留主体，背景更干净",
    "image_input": [
      "https://example.com/reference.png"
    ],
    "resolution": "1K",
    "aspect_ratio": "16:9",
    "output_format": "png"
  }'
```

## Ответ

Ответ оформлен в стиле OpenAI Images. По умолчанию приоритетное чтение `data[0].url`; некоторые совместимые каналы могут возвращать `data[0].b64_json`.

```json
{
  "created": 1778990000,
  "data": [
    {
      "url": "https://media.crazyrouter.com/task-artifacts/2026/05/17/sync-image/request-id-1.png"
    }
  ]
}
```

## Инструкции по миграции

Если старый код напрямую вызывает:

```text
POST /v1beta/models/nano-banana-2:generateContent
```

Рекомендуется перейти на:

```text
POST https://api.crazyrouter.com/v1/images/generations
```

и заменить нативные параметры Gemini на унифицированные:

| Нативное понятие Gemini | Унифицированный параметр Crazyrouter |
|------|------|
| `imageConfig.aspectRatio` | `aspect_ratio` |
| `imageConfig.imageSize` | `resolution` |
| `imageOutputOptions.mimeType` | `output_format` |
| `imageOutputOptions.compressionQuality` | `output_compression` |
