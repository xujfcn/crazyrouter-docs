# Flux

<Warning>
  На текущей странице тарифов Crazyrouter отсутствует возможность напрямую вызвать Flux `model_name`. На этой странице больше не приводятся примеры запросов Flux, и устаревшие идентификаторы моделей `flux-*` не рекомендуется использовать в производственных настройках.
</Warning>

## Актуальные альтернативы

Для генерации или редактирования изображений рекомендуется выбирать модели, которые сейчас доступны на странице с тарифами:

| Сценарий использования | Рекомендуемые модели |
|-----------------------|-----------------------|
| OpenAI Images         | `gpt-image-2`       |
| Gemini Images         | `nano-banana`, `nano-banana-2`, `nano-banana-pro` |
| Grok Images           | `grok-4-image`       |
| Qwen Images           | `qwen-image-2.0`, `qwen-image-plus`, `qwen-image-max` |
| Doubao Images         | `doubao-seedream-4-5`, `doubao-seedream-5-0` |

## Как проверить

Используйте `https://crazyrouter.com/pricing` и актуальный список моделей, возвращаемый `GET /v1/models`, как достоверный источник информации. Для примеров документации и значений по умолчанию для клиентов используйте только публично видимые модели, для которых успешно проходят отправки запросов.
