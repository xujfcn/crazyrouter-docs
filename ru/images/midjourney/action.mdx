# Выполнение операций

## Action - Увеличение / Вариация

```
POST /mj/submit/action
```

Выполнение следующих действий для завершённого задания Imagine, таких как увеличение (Upscale), вариация (Variation) и др.

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `taskId` | string | Да | ID исходного задания |
| `customId` | string | Да | `customId` кнопки действия, получение из поля `buttons` задания |
| `notifyHook` | string | Нет | Адрес обратного вызова |
| `state` | string | Нет | Пользовательский статус |

### Пример запроса

```bash cURL
curl -X POST https://api.crazyrouter.com/mj/submit/action \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "taskId": "task_1234567890",
    "customId": "MJ::JOB::upsample::1::abc123"
  }'
```

### Пример ответа

```json
{
  "code": 1,
  "description": "提交成功",
  "result": "task_action_001",
  "properties": {}
}
```

## Blend - Смешивание изображений

```
POST /mj/submit/blend
```

Смешивание нескольких изображений для создания нового.

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `botType` | string | Нет | `MID_JOURNEY` (по умолчанию) либо `NIJI_JOURNEY` |
| `base64Array` | array | Да | Массив изображений в кодировке Base64, 2-5 шт. |
| `dimensions` | string | Нет | Размер вывода: `PORTRAIT`, `SQUARE`, `LANDSCAPE` |
| `notifyHook` | string | Нет | Адрес обратного вызова |
| `state` | string | Нет | Пользовательский статус |

### Пример запроса

```bash cURL
curl -X POST https://api.crazyrouter.com/mj/submit/blend \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "base64Array": [
      "data:image/png;base64,iVBORw0KGgo...",
      "data:image/png;base64,iVBORw0KGgo..."
    ],
    "dimensions": "SQUARE"
  }'
```

### Пример ответа

```json
{
  "code": 1,
  "description": "提交成功",
  "result": "task_blend_001"
}
```

```
POST /mj/submit/describe
```

Загрузка изображения для генерации соответствующего описания подсказки Midjourney.

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `botType` | string | Нет | `MID_JOURNEY` (по умолчанию) либо `NIJI_JOURNEY` |
| `base64` | string | Да | Изображение закодированное в Base64 |
| `notifyHook` | string | Нет | Адрес обратного вызова |
| `state` | string | Нет | Пользовательский статус |

### Пример запроса

```bash cURL
curl -X POST https://api.crazyrouter.com/mj/submit/describe \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "base64": "data:image/png;base64,iVBORw0KGgo..."
  }'
```

## Modal - Подтверждение в всплывающем окне

```
POST /mj/submit/modal
```

Отправка подтверждения во всплывающем окне Midjourney (для операций как Region Vary, требующих дополнительного подтверждения).

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `taskId` | string | Да | ID исходного задания |
| `prompt` | string | Нет | Подсказка во всплывающем окне |
| `maskBase64` | string | Нет | Маска изображения в кодировке Base64 |

### Пример запроса

```bash cURL
curl -X POST https://api.crazyrouter.com/mj/submit/modal \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "taskId": "task_1234567890",
    "prompt": "add a rainbow in the sky"
  }'
```

<Note>
  После отправки всех операций возвращается новый ID задания, результат можно получить через интерфейс [проверки статуса задания](/ru/images/midjourney/query).
</Note>
