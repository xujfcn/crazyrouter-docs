# Обзор Midjourney

Crazyrouter предоставляет полный прокси API Midjourney, поддерживающий все операции: Imagine, Blend, Describe, Upscale, Variation и другие. Все запросы обрабатываются в виде асинхронных задач.

## Базовый путь

```
https://api.crazyrouter.com/mj
```

## Аутентификация

Передайте API Key в заголовке запроса:

```
Authorization: Bearer YOUR_API_KEY
```

---

## Объект задачи

После отправки каждого запроса Midjourney система возвращает объект задачи. Объект задачи содержит следующие поля:

| Поле | Тип | Описание |
|------|------|------|
| `id` | string | Уникальный идентификатор задачи |
| `action` | string | Тип задачи: `IMAGINE`, `UPSCALE`, `VARIATION`, `BLEND`, `DESCRIBE` и др. |
| `status` | string | Статус задачи |
| `prompt` | string | Переданный промпт |
| `promptEn` | string | Переведённый на английский промпт |
| `description` | string | Описание задачи |
| `submitTime` | number | Время отправки (метка времени в миллисекундах) |
| `startTime` | number | Время начала обработки |
| `finishTime` | number | Время завершения |
| `progress` | string | Процент выполнения, например `"100%"` |
| `imageUrl` | string | URL сгенерированного изображения |
| `failReason` | string | Причина ошибки (указывается только при неудаче) |
| `properties` | object | Дополнительные параметры |
| `buttons` | array | Список доступных действий (кнопок) |

---

## Статусы задач

| Статус | Описание |
|------|------|
| `NOT_START` | Задача отправлена, ожидает обработки |
| `SUBMITTED` | Задача отправлена в Midjourney |
| `IN_PROGRESS` | Задача в обработке |
| `SUCCESS` | Задача выполнена |
| `FAILURE` | Ошибка выполнения задачи |

---

## Действия (кнопки)

После завершения задачи поле `buttons` будет содержать доступные последующие действия:

```json
{
  "buttons": [
    {"customId": "MJ::JOB::upsample::1::hash", "emoji": "U1", "label": "U1", "style": 2},
    {"customId": "MJ::JOB::upsample::2::hash", "emoji": "U2", "label": "U2", "style": 2},
    {"customId": "MJ::JOB::upsample::3::hash", "emoji": "U3", "label": "U3", "style": 2},
    {"customId": "MJ::JOB::upsample::4::hash", "emoji": "U4", "label": "U4", "style": 2},
    {"customId": "MJ::JOB::variation::1::hash", "emoji": "V1", "label": "V1", "style": 2},
    {"customId": "MJ::JOB::variation::2::hash", "emoji": "V2", "label": "V2", "style": 2},
    {"customId": "MJ::JOB::variation::3::hash", "emoji": "V3", "label": "V3", "style": 2},
    {"customId": "MJ::JOB::variation::4::hash", "emoji": "V4", "label": "V4", "style": 2}
  ]
}
```

Используя `customId`, можно вызвать интерфейс Action для выполнения соответствующего действия (увеличение, вариация и др.).

## Обзор API-эндпоинтов

| Метод | Эндпоинт | Описание |
|------|------|------|
| POST | `/mj/submit/imagine` | Отправить задачу Imagine |
| POST | `/mj/submit/action` | Выполнить действие (увеличение, вариация и пр.) |
| POST | `/mj/submit/blend` | Смешать изображения |
| POST | `/mj/submit/describe` | Описать изображение |
| POST | `/mj/submit/modal` | Отправить подтверждение во всплывающем окне |
| POST | `/mj/submit/shorten` | Укоротить промпт |
| GET | `/mj/task/{id}/fetch` | Получить информацию о задаче |
| POST | `/mj/task/list-by-condition` | Массово запросить задачи |
| GET | `/mj/task/{id}/image-seed` | Получить Seed изображения |

<Note>
  Задачи Midjourney обрабатываются асинхронно; после отправки заявки необходимо опрашивать статус задачи. Рекомендуется запрашивать каждые 3–5 секунд, пока статус не изменится на `SUCCESS` или `FAILURE`.
</Note>
