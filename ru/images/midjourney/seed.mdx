# Получить Seed

```
GET /mj/task/{id}/image-seed
```

Получите значение Seed изображения для завершённой задачи. Seed можно использовать для воспроизведения похожих результатов генерации.

## Пример запроса

<CodeGroup>

```bash cURL
curl https://api.crazyrouter.com/mj/task/task_1234567890/image-seed \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.crazyrouter.com/mj/task/task_1234567890/image-seed",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)

print(response.json())
```

</CodeGroup>

## Пример ответа

```json
{
  "code": 1,
  "description": "成功",
  "result": "1234567890"
}
```

| Поле | Описание |
|------|------|
| `result` | Значение Seed, можно использовать в подсказке Imagine с `--seed 1234567890` для воспроизведения |

---

## Использование Seed

Добавьте параметр `--seed` в prompt запроса Imagine:

```json
{
  "prompt": "a beautiful sunset over the ocean --ar 16:9 --v 6 --seed 1234567890"
}
```

<Note>
  Seed можно получить только после успешного завершения задачи. Одинаковый Seed + одинаковый Prompt позволяет создать очень похожие (но не полностью идентичные) изображения.
</Note>
