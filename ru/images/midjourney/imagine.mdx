# Подать задачу Imagine

```
POST /mj/submit/imagine
```

Подайте задачу Midjourney Imagine для генерации изображения по заданному промпту.

## Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `botType` | string | Нет | Тип бота: `MID_JOURNEY` (по умолчанию) или `NIJI_JOURNEY` |
| `prompt` | string | Да | Промпт, поддерживается оригинальный синтаксис Midjourney (например, `--ar 16:9 --v 6`) |
| `base64Array` | array | Нет | Массив изображений-референсов в формате Base64, используется для подсказки |
| `notifyHook` | string | Нет | Адрес для обратного вызова при изменении статуса задачи |
| `state` | string | Нет | Пользовательская информация о статусе, будет возвращена без изменений в колбэке |

---

## Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/mj/submit/imagine \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "botType": "MID_JOURNEY",
    "prompt": "a beautiful sunset over the ocean, cinematic lighting --ar 16:9 --v 6",
    "notifyHook": "",
    "state": ""
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/mj/submit/imagine",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "botType": "MID_JOURNEY",
        "prompt": "a beautiful sunset over the ocean, cinematic lighting --ar 16:9 --v 6"
    }
)

print(response.json())
```

</CodeGroup>

### Пример ответа

```json
{
  "code": 1,
  "description": "提交成功",
  "result": "task_1234567890",
  "properties": {}
}
```

| Поле | Описание |
|------|------|
| `code` | Код статуса, `1` — успех, `22` — в очереди |
| `description` | Описание статуса |
| `result` | ID задачи, используется для последующего запроса |

## Запрос с референс-изображением

Используйте `base64Array` для передачи референса:

```bash cURL
curl -X POST https://api.crazyrouter.com/mj/submit/imagine \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "botType": "MID_JOURNEY",
    "prompt": "a cat in the style of the reference image --v 6",
    "base64Array": [
      "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."
    ]
  }'
```

---

## Использование Niji Journey

Установите `botType` в `NIJI_JOURNEY`, чтобы использовать модель Niji для генерации изображений в стиле аниме:

```json
{
  "botType": "NIJI_JOURNEY",
  "prompt": "a cute anime girl with blue hair, cherry blossoms --niji 6"
}
```

<Note>
  После успешной отправки возвращается ID задачи — результат генерации нужно получить через интерфейс [запроса статуса задачи](/ru/images/midjourney/query).
</Note>

<Warning>
  Изображения из `base64Array` увеличивают размер тела запроса, рекомендуется размер одной картинки не более 4 МБ.
</Warning>
