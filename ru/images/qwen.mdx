# Qwen Image

```
POST /v1/images/generations
```

В настоящее время Crazyrouter предоставляет первую партию моделей генерации `Qwen Image` через совместимый протокол OpenAI Images. Клиенты продолжают использовать и единый `/v1/images/generations`, официальные и сторонние сервисы Alibaba выступают только как внутренние провайдеры и не раскрывают клиентский протокол отдельно.

## Текущие открытые модели

| Модель | Тип исполнения upstream | Возможности для клиента | Статус проверки |
|--------|--------------------------|------------------------|----------------|
| `qwen-image-plus` | Асинхронная генерация | Генерация изображений по тексту | Проверено |
| `qwen-image-max` | Синхронная генерация | Генерация изображений по тексту | Проверено |
| `qwen-image-2.0` | Синхронная генерация | Генерация изображений по тексту | Проверено |
| `qwen-image-2.0` | Синхронная генерация | Генерация изображений по тексту | Beta |

<Note>
  `qwen-image-2.0` протокол и код уже согласованы, но производственные доказательства ещё дополняются, поэтому временно отмечено как Beta.
</Note>

## Клиентский протокол

### Параметры запроса

| Параметр | Тип | Обязателен | Описание |
|----------|-----|------------|----------|
| `model` | string | Да | `qwen-image-plus`, `qwen-image-max`, `qwen-image-2.0`, `qwen-image-2.0` |
| `prompt` | string | Да | Подсказка для генерации изображения |
| `size` | string | Нет | Размер вывода. Рекомендуется выбрать поддержку размера на странице модели или playground |
| `n` | integer | Нет | Количество создаваемых изображений, по умолчанию `1` |
| `response_format` | string | Нет | `url` или `b64_json` |

### Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "qwen-image-max",
    "prompt": "一张具有高级感的产品海报，主体是一瓶玻璃香水，柔和棚拍光线，中文标题“晨雾”",
    "size": "1024x1024",
    "n": 1,
    "response_format": "url"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1"
)

response = client.images.generate(
    model="qwen-image-max",
    prompt="一张具有高级感的产品海报，主体是一瓶玻璃香水，柔和棚拍光线，中文标题“晨雾”",
    size="1024x1024",
    n=1
)

print(response.data[0].url)
```

</CodeGroup>

## Официальная схема тарификации

Официальное тарифицирование Qwen Image основывается на количестве успешно сгенерированных изображений, не отображает ввод/вывод по токенам.

| Модель | Официальная схема | Официальная цена за единицу | Текущий статус документа |
|--------|-------------------|-----------------------------|-------------------------|
| `qwen-image-plus` | По изображениям | `¥0.20 / изображение` | Проверено |
| `qwen-image-max` | По изображениям | `¥0.50 / изображение` | Проверено |
| `qwen-image-2.0` | По изображениям | `¥0.20 / изображение` | Проверено |
| `qwen-image-2.0` | По изображениям | `¥0.50 / изображение` | Beta |

## Пояснения по границам

- На этой странице гарантируются только клиентские возможности `Генерация изображения по тексту`; дополнительные мульти-модальные функции upstream не раскрываются на клиентский протокол.
- На стороне provider для `Qwen Image` могут быть асинхронные или синхронные различия, но клиент продолжает использовать единый формат запроса/ответа OpenAI Images.
- Редактирующая модель изображений `qwen-image-plus` не входит в охват этой партии «закрытия генеративных моделей»; при необходимости функции редактирования следует отдельно оценивать актуальное состояние открытия этой модели.
