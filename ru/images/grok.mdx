# Модель Grok для изображений

```
POST /v1/images/generations
```

Модель Grok для изображений вызывается через совместимый с OpenAI Images endpoint. В настоящее время следует различать два имени моделей:

| Модель | Описание | Рекомендация |
|--------|----------|--------------|
| `grok-4-image` | Официальное имя модели изображений xAI, тарификация по официальной цене `$0.02 / image` | Рекомендуется для новых подключений |
| `grok-4-image` | Историческое/совместимое имя в сторонних каналах | Рекомендуется только для использования с подмножеством параметров |

<Warning>
  `grok-4-image` не является официальным именем модели xAI, нельзя считать его полностью эквивалентным `grok-4-image`. Для новых интеграций отдавайте предпочтение `grok-4-image`.
</Warning>

## Параметры grok-4-image

`grok-4-image` используется в соответствии с официальным интерфейсом для изображений:

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `model` | string | да | Использовать `grok-4-image` |
| `prompt` | string | да | Текстовый промпт с описанием изображения |
| `n` | integer | нет | Количество создаваемых изображений, официальный диапазон от `1` до `10`. Для стабильного контроля затрат рекомендуем сначала использовать `1` |
| `response_format` | string | нет | `url` или `b64_json`. На практике `url` стабильно работает |
| `aspect_ratio` | string | нет | Как `1:1`, `16:9`, `9:16`, `3:2`, `auto` |
| `resolution` | string | нет | `1k` или `2k` |

<Note>
  `aspect_ratio` и `resolution` — это расширенные параметры интерфейса изображений xAI. При использовании OpenAI Python SDK передавайте через `extra_body`, при использовании cURL или Node.js SDK помещайте прямо в JSON body.
</Note>

Не следует передавать следующие параметры:

| Параметр | Причина |
|----------|---------|
| `size` | Не поддерживается официальным API xAI, при передаче вернёт `Argument not supported: size` |
| `quality` | Не поддерживается официальным API xAI |
| `style` | Не поддерживается официальным API xAI |

## Пример grok-4-image

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "grok-4-image",
    "prompt": "A tiny yellow cube on a plain white background, minimal product photo",
    "n": 1,
    "response_format": "url",
    "aspect_ratio": "1:1",
    "resolution": "1k"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.generate(
    model="grok-4-image",
    prompt="A tiny yellow cube on a plain white background, minimal product photo",
    n=1,
    response_format="url",
    extra_body={
        "aspect_ratio": "1:1",
        "resolution": "1k",
    },
)

print(response.data[0].url)
```

```javascript Node.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.crazyrouter.com/v1",
});

const response = await client.images.generate({
  model: "grok-4-image",
  prompt: "A tiny yellow cube on a plain white background, minimal product photo",
  n: 1,
  response_format: "url",
  aspect_ratio: "1:1",
  resolution: "1k",
});

console.log(response.data[0].url);
```

</CodeGroup>

## Пример ответа

Фактический ответ может содержать поля `url`, `mime_type`, `revised_prompt` и др.:

```json
{
  "created": 1776527939,
  "data": [
    {
      "url": "https://...",
      "mime_type": "image/jpeg",
      "revised_prompt": "A tiny yellow cube on a plain white background..."
    }
  ]
}
```

<Note>
  Ссылки на изображения, возвращаемые `response_format: "url"`, являются временными — пожалуйста, скачайте или сохраните сразу после генерации.
</Note>

## Отличия параметров grok-4-image

`grok-4-image` рекомендует использовать только безопасное подмножество ниже:

| Параметр | Поддержка |
|----------|-----------|
| `model` | Используйте `grok-4-image` |
| `prompt` | Поддерживается |
| `n` | Рекомендуется только `1`. На практике `n=2` часто возвращает только 1 изображение, но тарифицируется как за 2; шлюз уже ограничивает только до `1` |
| `response_format` | `url` стабильно. Запрос `b64_json` допустим, но на практике возвращается только `url` |
| `aspect_ratio` | Запрос допустим, но выполнение на сторонних каналах зависит от фактического ответа |
| `resolution` | Запрос допустим, но выполнение на сторонних каналах зависит от фактического ответа |

Не давайте гарантий по `grok-4-image` относительно:

- создание нескольких изображений `n > 1`
- обязательной выдачи base64 `b64_json`
- `size`
- `quality`
- `style`
- редактирования изображений

## Информация о тарификации

| Модель | Текущая тарификация |
|--------|--------------------|
| `grok-4-image` | `$0.02 / image`, скидки не действуют |
| `grok-4-image` | Текущий pricing: `$0.08 * 0.55 = $0.044 / image` |

<Note>
  Ориентируйтесь на актуальные страницы с тарифами и логи расходов. Модель для изображений тарифицируется за каждое изображение, не по количеству токенов на вход/выход.
</Note>

## Частые ошибки

| Ошибка | Как исправить |
|--------|--------------|
| `Argument not supported: size` | Не передавайте `size` в модель Grok для изображений, используйте `aspect_ratio` и `resolution` |
| `model_price_error` | Для целевой модели не настроена цена либо недостаточно прав у токена — сначала проверьте тарифы и список моделей |
| `model_not_found` | Имя модели, права токена или доступность канала не совпадают — используйте `GET /v1/models` для проверки |
