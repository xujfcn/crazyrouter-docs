# Ideogram старой версии

API старой версии Ideogram предоставляет базовые функции генерации изображений.

<Note>
  Рекомендуется использовать [Ideogram V3](/ru/images/ideogram/v3) для получения лучших результатов генерации.
</Note>

## Генерация изображения

```
POST /ideogram/generate
```

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `image_request` | object | Да | Объект запроса изображения |
| `image_request.prompt` | string | Да | Промпт |
| `image_request.model` | string | Нет | Версия модели: `V_2`, `V_2_TURBO` |
| `image_request.aspect_ratio` | string | Нет | Соотношение сторон |
| `image_request.magic_prompt_option` | string | Нет | Усиление промпта |
| `image_request.style_type` | string | Нет | Тип стиля |
| `image_request.negative_prompt` | string | Нет | Негативный промпт |

### Пример запроса

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "image_request": {
      "prompt": "A futuristic cityscape at night with neon lights",
      "model": "V_2",
      "aspect_ratio": "ASPECT_16_9",
      "magic_prompt_option": "AUTO"
    }
  }'
```

### Пример ответа

```json
{
  "created": 1709123456,
  "data": [
    {
      "url": "https://ideogram.ai/assets/image/...",
      "prompt": "A futuristic cityscape at night with neon lights",
      "resolution": "1344x768",
      "seed": 67890
    }
  ]
}
```

## Remix — смешивание

```
POST /ideogram/remix
```

Генерация вариаций на основе референсного изображения.

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/remix \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "image_request": {
      "prompt": "Same scene in anime style",
      "model": "V_2"
    },
    "image_file": "https://example.com/photo.jpg"
  }'
```

## Увеличение изображения

```
POST /ideogram/upscale
```

Увеличьте изображение до более высокого разрешения.

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/upscale \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "image_request": {
      "prompt": "high quality detailed image"
    },
    "image_file": "https://example.com/photo.jpg"
  }'
```

## Описание изображения

```
POST /ideogram/describe
```

Позволяет модели описать содержание изображения и сгенерировать соответствующий промпт.

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/describe \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "image_file": "https://example.com/photo.jpg"
  }'
```

### Пример ответа

```json
{
  "descriptions": [
    {
      "text": "A futuristic cityscape at night with vibrant neon lights reflecting off wet streets, tall skyscrapers with holographic advertisements"
    }
  ]
}
```
