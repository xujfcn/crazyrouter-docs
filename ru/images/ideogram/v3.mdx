# Ideogram V3

Ideogram V3 — это новейшее поколение моделей преобразования текста в изображение, обладающее значительным улучшением рендеринга текста и качества изображения.

## Генерация изображений

```
POST /ideogram/v1/ideogram-v3/generate
```

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `prompt` | string | Да | Описательные подсказки для изображения |
| `aspect_ratio` | string | Нет | Соотношение сторон, например `ASPECT_1_1`, `ASPECT_16_9`, `ASPECT_9_16` |
| `model` | string | Нет | Версия модели, по умолчанию `V_3` |
| `magic_prompt_option` | string | Нет | Усиление подсказок: `AUTO`, `ON`, `OFF` |
| `rendering_speed` | string | Нет | Скорость рендеринга: `DEFAULT`, `TURBO`, `QUALITY` |
| `style_type` | string | Нет | Тип стиля: `AUTO`, `GENERAL`, `REALISTIC`, `DESIGN` |
| `negative_prompt` | string | Нет | Негативные подсказки |

### Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/v1/ideogram-v3/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "A serene Japanese garden with cherry blossoms, text saying \"Hello World\" on a wooden sign",
    "aspect_ratio": "ASPECT_16_9",
    "rendering_speed": "DEFAULT",
    "style_type": "REALISTIC"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/ideogram/v1/ideogram-v3/generate",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "prompt": "A serene Japanese garden with cherry blossoms",
        "aspect_ratio": "ASPECT_16_9",
        "style_type": "REALISTIC"
    }
)

print(response.json())
```

</CodeGroup>

## Редактирование изображений

```
POST /ideogram/v1/ideogram-v3/edit
```

Редактирование и изменение уже существующего изображения.

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `prompt` | string | Да | Описание изменения |
| `image` | string | Да | URL исходного изображения или Base64 |
| `mask` | string | Нет | Маска изображения, отмечает область для редактирования |
| `style_type` | string | Нет | Тип стиля |

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/v1/ideogram-v3/edit \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "Replace the sky with a starry night",
    "image": "https://example.com/photo.jpg",
    "mask": "https://example.com/mask.png"
  }'
```

## Remix изображений

```
POST /ideogram/v1/ideogram-v3/remix
```

Генерация вариаций на основе эталонного изображения и новых подсказок.

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `prompt` | string | Да | Новая подсказка |
| `image` | string | Да | Эталонное изображение |
| `image_weight` | number | Нет | Вес эталонного изображения, 0-100 |

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/v1/ideogram-v3/remix \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "Same scene but in watercolor painting style",
    "image": "https://example.com/photo.jpg",
    "image_weight": 50
  }'
```

## Reframe — реконтурирование

```
POST /ideogram/v1/ideogram-v3/reframe
```

Расширение холста изображения, генерация содержания за пределами исходных границ.

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `image` | string | Да | Исходное изображение |
| `resolution` | string | Нет | Целевое разрешение |

## Замена фона

```
POST /ideogram/v1/ideogram-v3/replace-background
```

Автоматическое определение объекта и замена фона.

| Параметр | Тип | Обязательный | Описание |
|------|------|------|------|
| `prompt` | string | Да | Описание нового фона |
| `image` | string | Да | Исходное изображение |

```bash cURL
curl -X POST https://api.crazyrouter.com/ideogram/v1/ideogram-v3/replace-background \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "A tropical beach at sunset",
    "image": "https://example.com/portrait.jpg"
  }'
```

<Note>
  Ideogram V3 отличается превосходной работой с рендерингом текста, что идеально подходит для сценариев, где изображение должно содержать текст.
</Note>
