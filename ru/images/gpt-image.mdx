# GPT Image

`gpt-image-2` совместим с маршрутизацией через OpenAI Images API:

```text
POST /v1/images/generations
POST /v1/images/edits
```

<Warning>
  Для запроса генерации изображения `gpt-image-2` рекомендуется в первую очередь использовать основной канал `https://api.crazyrouter.com/v1`. Полный адрес эндпоинта для генерации: `https://api.crazyrouter.com/v1/images/generations`. Вход в аккаунт, пополнение и консоль управления остаются на `https://crazyrouter.com`.
</Warning>

## Генерация изображения

### Параметры запроса

| Параметр | Тип | Обязателен | Описание |
|------|------|------|------|
| `model` | string | Да | Всегда `gpt-image-2` |
| `prompt` | string | Да | Промпт для описания изображения |
| `n` | integer | Нет | Количество, по умолчанию `1`, диапазон `1-10` |
| `size` | string | Нет | `auto` или `Ширина x высота`. Ширина и высота должны быть кратны 16, максимальный размер стороны — 3840, всего от 655360 до 8294400 пикселей, соотношение сторон не более 3:1. Типичные значения: `1024x1024`, `1536x1024`, `1024x1536` |
| `quality` | string | Нет | `auto`, `low`, `medium`, `high`. Совместим с `hd`, сервер приведет к `high`; совместим с `standard`, сервер приведет к `auto` |
| `background` | string | Нет | `auto` или `opaque`. `gpt-image-2` не поддерживает `transparent` |
| `output_format` | string | Нет | `png`, `jpeg`, `webp` |
| `output_compression` | integer | Нет | `0-100`, применяется только если `output_format` равен `jpeg` или `webp` |
| `moderation` | string | Нет | `auto` или `low` |
| `stream` | boolean | Нет | Использовать ли SSE потоковую выдачу |
| `partial_images` | integer | Нет | `0-3`, применяется только если `stream=true` |
| `user` | string | Нет | Идентификатор конечного пользователя |

Для обратной совместимости с клиентами DALL-E / OpenAI Images, `gpt-image-2` будет принимать `response_format=url`, `response_format=b64_json`, `quality=standard` и `style=vivid/natural`. При этом `response_format` и `style` не будут переданы на сервер, а `quality=standard` приведется к `auto`.

<Warning>
  `response_format` — это только резервное поле совместимости Crazyrouter для старых клиентов, а не параметр апстрим провайдера `gpt-image-2`. Для новых интеграций предпочтительно использовать `output_format="png"`, `"jpeg"` или `"webp"` для выбора формата изображения, по умолчанию сервер возвращает в `data[0].url`. Если старый клиент присылает `response_format="b64_json"`, сервер по возможности сохранит семантику ответа через base64.
</Warning>

Пары параметров, которые все еще будут отклонены: `input_fidelity`, `background=transparent`, `output_format=png` в сочетании с `output_compression`.

### Пример запроса

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只穿着宇航服的猫咪在月球上行走，背景是地球",
    "n": 1,
    "size": "1024x1024",
    "quality": "low",
    "output_format": "png"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.generate(
    model="gpt-image-2",
    prompt="一只穿着宇航服的猫咪在月球上行走，背景是地球",
    n=1,
    size="1024x1024",
    quality="low",
    output_format="png",
)

print(response.data[0].url)
```

</CodeGroup>

### Потоковая генерация

`gpt-image-2` поддерживает `stream=true`. Если в запросе есть `partial_images`, нужно также включить `stream`, диапазон значений `0-3`.

```bash cURL
curl -N -X POST https://api.crazyrouter.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一个蓝色极简验证图标，白色背景",
    "size": "1024x1024",
    "quality": "high",
    "stream": true,
    "partial_images": 2
  }'
```

<Note>
  Синхронные запросы типа `quality=high` или совместимые, как `quality=hd`, могут выполняться долго. Для генерации изображений рекомендуется использовать `https://api.crazyrouter.com/v1`; для запросов высокого качества — `stream=true` или установить тайм-аут клиента больше 180 сек.
</Note>

## Редактирование изображений

```
POST /v1/images/edits
```

Редактирование на основе существующего изображения, поддерживается редактирование по маске, а также использование нескольких референсных изображений для сочетания, переноса стиля или комбинирования частей.

### Параметры запроса

| Параметр | Тип | Обязателен | Описание |
|------|------|------|------|
| `model` | string | Да | Всегда `gpt-image-2` |
| `image` / `image[]` | file или file[] | Да | Оригинальное изображение или референс (multipart); `gpt-image-2` поддерживает максимум `16` референсов |
| `prompt` | string | Да | Описание редактирования |
| `mask` | file | Нет | Маска для редактирования — в прозрачных зонах будет произведено изменение |
| `n` | integer | Нет | Количество, по умолчанию `1`, диапазон `1-10` |
| `size` | string | Нет | Как в интерфейсе генерации |
| `quality` | string | Нет | `auto`, `low`, `medium`, `high`; `hd` приводит к `high` |
| `background` | string | Нет | `auto` или `opaque` |
| `output_format` | string | Нет | `png`, `jpeg`, `webp` |
| `output_compression` | integer | Нет | `0-100`, только если `output_format` равен `jpeg` или `webp` |
| `stream` | boolean | Нет | Использовать ли SSE потоковую выдачу |
| `partial_images` | integer | Нет | `0-3`, только если `stream=true` |

### Пример редактирования одного изображения

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.crazyrouter.com/v1",
)

response = client.images.edit(
    model="gpt-image-2",
    image=open("original.png", "rb"),
    mask=open("mask.png", "rb"),
    prompt="在天空中添加一道彩虹",
    n=1,
    size="1024x1024",
    quality="low",
)

print(response.data[0].url)
```

### Пример редактирования с несколькими референсами

Для мультиреференсного редактирования используйте `multipart/form-data`. Рекомендуется передавать каждую референсную картинку как отдельное поле `image[]`; сервер также поддерживает повторяющийся параметр `image`.

<CodeGroup>

```bash cURL
curl -X POST https://api.crazyrouter.com/v1/images/edits \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=gpt-image-2" \
  -F "prompt=把第一张图的人物与第二张图的背景融合成一张自然的宣传图" \
  -F "size=1024x1024" \
  -F "quality=low" \
  -F "n=1" \
  -F "image[]=@person.png" \
  -F "image[]=@background.png"
```

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/images/edits",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    data={
        "model": "gpt-image-2",
        "prompt": "把第一张图的人物与第二张图的背景融合成一张自然的宣传图",
        "size": "1024x1024",
        "quality": "low",
        "n": "1",
    },
    files=[
        ("image[]", ("person.png", open("person.png", "rb"), "image/png")),
        ("image[]", ("background.png", open("background.png", "rb"), "image/png")),
    ],
    timeout=240,
)

response.raise_for_status()
print(response.json()["data"][0]["url"])
```

</CodeGroup>

<Note>
  `gpt-image-2` поддерживает до 16 референсных изображений. Такие запросы направляются на официальный OpenAI канал, поддерживающий мультиреференсы.
</Note>
