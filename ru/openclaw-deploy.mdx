> Обновление содержания: 2026-06-09

Разверните AI-шлюз [OpenClaw](https://github.com/open-claw/open-claw) на Linux или macOS с помощью однокнопочного скрипта, используя Crazyrouter как основной бэкенд. Установщик запишет исполняемый файл `~/.openclaw/openclaw.json`, зарегистрирует системную службу и по умолчанию сконфигурирует модели, подходящие для чата, программирования и задач с длинным контекстом.

## Обзор

OpenClaw помогает превратить Crazyrouter в ваш собственный локальный AI-шлюз:

- Локальный WebUI / шлюз, по умолчанию слушает `18789`
- Можно напрямую использовать модели и лимиты Crazyrouter
- Поддерживается Telegram и предварительно активированы плагины для DingTalk, WeChat Work, QQ Bot, Discord, Slack, Feishu и др.
- Подходит для персонального постоянно работающего бота, внутреннего командного помощника, домашнего сервера или легких сценариев самостоятельного размещения

## Для кого

- Для тех, кто хочет одной командой подключить Crazyrouter к локальному AI-шлюзу
- Для желающих запускать Telegram Bot на своем сервере
- Для желающих унифицировать управление чатами, WebUI и IM-шлюзами
- Для тех, кто хочет развернуть постоянно работающего помощника на рабочем или домашнем мини-компьютере

## Лицензионное соглашение

Рекомендуемое соглашение: `OpenAI-compatible API`

- Установщик по умолчанию направляет `crazyrouter` provider на `https://api.crazyrouter.com/v1`
- Также запишет `crazyrouter-claude` и `crazyrouter-minimax` provider для удобного переключения на путь совместимый с Anthropic Messages
- Сам OpenClaw предоставляет только локальный шлюз и WebUI, аутентификация зависит от токена `gateway.auth.token`, генерируемого при установке

<Note>
Если вы хотите вручную изменить адрес provider OpenClaw, сначала изучите [Описание API Endpoint](https://docs.crazyrouter.com/ru/api-endpoint) и убедитесь, должен ли клиент указывать корневой домен или `/v1`.
</Note>

## Предварительные условия

| Проект | Описание |
|-------|----------|
| Crazyrouter аккаунт | Зарегистрируйтесь на [crazyrouter.com](https://crazyrouter.com) заранее |
| Crazyrouter API Key | Рекомендуется создать отдельный token для OpenClaw, не использовать общий с Cursor или Claude Code |
| Операционная система | Linux или macOS, x64 / arm64 поддерживаются |
| Сеть | Сервер должен иметь доступ к интернету; если вы будете использовать WebUI с других устройств, откройте порт `18789` |
| Node.js | Установщик постарается автоматически установить Node.js 22+ |
| Telegram Bot Token | Необязательно, нужен только если подключаете Telegram |

<Warning>
Установщик OpenClaw по умолчанию привязывает шлюз к локальному адресу сети (`bind: lan`). Если сервер напрямую доступен из интернета, обязательно настройте ограничение доступа по firewall и храните токен для входа в шлюз в безопасности.
</Warning>

## Быстрый старт за 5 минут

<Steps>
  <Step title="Создать специальный Crazyrouter токен">
    В бек-офисе Crazyrouter создайте отдельный `sk-...` token для использования с OpenClaw. Рекомендуется разрешить только те модели, которые планируете использовать в шлюзе, например `claude-opus-4-8`, `gpt-5.5`, `gemini-3.1-pro`.
  </Step>
  <Step title="Запустить скрипт установки">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/xujfcn/crazyrouter-openclaw/main/install.sh | bash
    ```
    Если хотите пропустить выбор языка и ввод API Key, можно так:
    ```bash
    CRAZYROUTER_API_KEY=sk-xxx INSTALLER_LANG=zh \
      curl -fsSL https://raw.githubusercontent.com/xujfcn/crazyrouter-openclaw/main/install.sh | bash
    ```
  </Step>
  <Step title="Запишите 3 значения, выводимых установщиком">
    - WebUI адрес: `http://<server IP>:18789`
    - Адрес автоматического входа: `http://<server IP>:18789?token=<gateway_token>`
    - Конфиг: `~/.openclaw/openclaw.json`
  </Step>
  <Step title="Откройте WebUI для первичной проверки">
    Откройте адрес автоматического входа в браузере, убедитесь, что входите в консоль OpenClaw и отправьте тестовое сообщение стандартной моделью `claude-opus-4-8`, например "Ответь только ok".
  </Step>
  <Step title="При необходимости выполните сопряжение с Telegram">
    Установщик предложит сразу настроить Telegram. Если согласны, внесите Bot Token и отправьте любое сообщение вашему боту для первой owner-паризации.
  </Step>
</Steps>

## Рекомендованные настройки моделей

Главная модель по умолчанию — `claude-opus-4-8`. Для смены основной модели просто измените `~/.openclaw/openclaw.json`, указав `agents.defaults.model.primary`.

| Сценарий | Рекомендованная модель | Причина |
|----------|------------------------|---------|
| Стандартный чат | `claude-opus-4-8` | Текущая основная модель, подходит для качественного ежедневного общения и как главная управляющая |
| Программирование / Agent | `gpt-5.5` | Новая совместимая с OpenAI модель, хороша как основная для кодинга и Agent-задач |
| Оптимальный запасной вариант | `claude-opus-4-8` | Баланс качества, стабильности и стоимости |
| Gemini запасной путь | `gemini-3.1-pro` | Для тестирования совместимости второй ветки |
| Глубокие рассуждения | `claude-opus-4-8` | Для задач с глубокими цепочками рассуждений |

Пример: сменить модель по умолчанию на `gpt-5.5`

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "crazyrouter/gpt-5.5"
      }
    }
  }
}
```

Для явной маршрутизации через совместимый с Claude provider, используйте:

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "crazyrouter-claude/claude-opus-4-8"
      }
    }
  }
}
```

## Лучшие практики настройки токенов

| Параметр | Рекомендация | Описание |
|----------|--------------|----------|
| Отдельный токен | Обязательно | Не используйте общий токен OpenClaw и других IDE/CLI |
| Белый список моделей | Рекомендуется | Оставьте только нужные модели для снижения рисков |
| Ограничение по IP | Для серверов с фиксированным IP | Если IP неизменный, ограничьте токен этим сервером |
| Лимит бюджета | Советуем | Задайте отдельный месячный или дневной лимит для бота |
| Разделение среды | Советуем | Производственные и тестовые боты должны иметь разные токены |
| При утечке | Переключайте немедленно | Если `openclaw.json`, логи или ссылки раскрыли токен — сбросьте токены Crazyrouter и шлюза |

<Tip>
В OpenClaw есть минимум два типа credentials: `sk-...` API Key Crazyrouter для вызова модели и токен шлюза для доступа к WebUI. Не смешивайте их.
</Tip>

## Ключевые файлы и параметры

### Расположение файлов

| Путь | Назначение |
|------|------------|
| `~/.openclaw/openclaw.json` | Основной конфиг |
| `~/.openclaw/start-gateway.sh` | Скрипт запуска, вызывается системой |
| `~/.openclaw/crash-guard.cjs` | Патч на стабильность, внесенный установщиком |
| `~/.openclaw/credentials/.telegram-owner-paired` | Файл отметки завершения первой owner-паризации Telegram |
| `~/.config/systemd/user/openclaw.service` | Пользовательская systemd-служба Linux |
| `~/Library/LaunchAgents/com.crazyrouter.openclaw.plist` | launchd-служба macOS |
| `~/.openclaw/openclaw.log` | Обычные логи macOS |
| `~/.openclaw/openclaw.err` | Логи ошибок macOS |

### Самые часто изменяемые параметры

| JSON путь | Назначение | Что обычно меняют |
|-----------|------------|--------------------|
| `models.providers.crazyrouter.apiKey` | Crazyrouter OpenAI-совместимый key | Меняют API Key |
| `models.providers.crazyrouter.baseUrl` | OpenAI-совместимая база | Обычно оставляют `https://api.crazyrouter.com/v1` |
| `agents.defaults.model.primary` | Главная модель по умолчанию | Меняют на `gpt-5.5`, `claude-opus-4-8` и др. |
| `gateway.port` | Порт WebUI/шлюза | Меняют на свой порт |
| `gateway.auth.token` | Токен входа WebUI | При утечке сразу меняют |
| `gateway.bind` | Диапазон слушающих адресов | По умолчанию `lan` |
| `channels.telegram.botToken` | Telegram Bot Token | Указывают при активации Telegram |
| `plugins.entries.*.enabled` | Включение IM-плагинов | Отключают неиспользуемые |
| `env.vars.OPENAI_API_KEY` | API Key для внутренних возможностей | Обычно равен главному key |

## Интеграция IM

### Telegram

Это самая полностью поддерживаемая каналом установка, рекомендуется начать с Telegram:

1. Найдите `@BotFather` в Telegram
2. Отправьте `/newbot` для создания бота и получите Bot Token
3. На вопрос `Set up Telegram Bot now?` в установщике выберите `Y`
4. Вставьте Token, установщик сохранит его в `~/.openclaw/openclaw.json`
5. После автоматического перезапуска шлюза, отправьте боту сообщение
6. Первый отправивший сообщение автоматически станет owner
7. Если паризация не удалась — выполните:

```bash
openclaw pairing list
openclaw pairing approve <code>
```

При ручной настройке Telegram используйте структуру, которую сохраняет установщик:

```json
{
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "123456789:ABCdef...",
      "dmPolicy": "pairing",
      "groupPolicy": "allowlist",
      "streaming": "off"
    }
  },
  "plugins": {
    "entries": {
      "telegram": { "enabled": true }
    }
  }
}
```

### Другие IM-платформы

Установщик предварительно активирует следующие плагины:

- `dingtalk`
- `openclaw-wecom`
- `qqbot`
- `discord`
- `slack`
- `feishu`

Для этих каналов нужно добавить свои credentials и соответствующую `channels.<name>` настройку. Рекомендованный процесс:

1. Создайте бота или приложение на нужной платформе
2. Запишите credentials платформы в `~/.openclaw/openclaw.json`
3. Проверьте, что `plugins.entries.<name>.enabled` равен `true`
4. Перезапустите OpenClaw
5. Проверьте лог для успешной загрузки

| Платформа | Статус установщика | Ваши дальнейшие действия |
|-----------|--------------------|-------------------------|
| Telegram | Поддерживается интерактивная настройка | Добавьте Bot Token и завершите паризацию owner |
| DingTalk | Плагин будет установлен и активирован | Внесите credentials бота и настройки channel |
| WeChat Work | Плагин будет установлен и активирован | Внесите credentials корпоративного приложения и настройки channel |
| QQ Bot | Плагин будет установлен и активирован | Внесите credentials бота и настройки channel |
| Discord / Slack / Feishu | Вход плагинов активен | Внесите credentials channel по правилам этой платформы |

<Note>
Если OpenClaw интегрируется с командным IM, обязательно создайте отдельный token Crazyrouter для командного бота, а также настройте строгий белый список моделей и лимит бюджета.
</Note>

## Управление сервисом и логами

<Tabs>
  <Tab title="Linux (systemd)">
    ```bash
    systemctl --user status openclaw
    systemctl --user start openclaw
    systemctl --user restart openclaw
    systemctl --user stop openclaw
    journalctl --user -u openclaw -f
    ```

    Примечание: установщик попытается выполнить `loginctl enable-linger $(whoami)`, чтобы сервис продолжал работать даже при выходе из SSH.
  </Tab>
  <Tab title="macOS (launchd)">
    ```bash
    launchctl list | grep openclaw
    launchctl start com.crazyrouter.openclaw
    launchctl stop com.crazyrouter.openclaw
    launchctl stop com.crazyrouter.openclaw && launchctl start com.crazyrouter.openclaw
    tail -f ~/.openclaw/openclaw.log
    cat ~/.openclaw/openclaw.err
    ```

    Примечание: на macOS для просмотра логов работы используйте `openclaw.log`, для диагностики запуска лучше подходит `openclaw.err`.
  </Tab>
</Tabs>

## Рекомендации по производительности и стоимости

- Начните с `claude-opus-4-8`, убедитесь, что весь процесс работает, после этого распределяйте задачи по моделям
- Для частых QA/уведомлений бота используйте `claude-opus-4-8` или `gemini-3.1-pro` из соображений стоимости
- Для рабочих процессов программирования используйте отдельную модель `gpt-5.5`
- Для командных сценариев используйте разные токены для Telegram/корпоративного IM/WebUI для расчета стоимости и изоляции рисков
- Оставляйте только нужные плагины и модели — это снижает расходы

## Гайд по обновлению

Самый надежный способ обновления — повторно запустить установщик, так как он одновременно обновит все пакеты, патчи и сервисные скрипты OpenClaw:

<Steps>
  <Step title="Сделать резервную копию текущей конфигурации">
    ```bash
    cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.bak
    ```
  </Step>
  <Step title="Запустить скрипт установки повторно">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/xujfcn/crazyrouter-openclaw/main/install.sh | bash
    ```
  </Step>
  <Step title="Проверьте, нужно ли вернуть ваши пользовательские настройки">
    Если вы вручную добавляли каналы, помимо Telegram, или изменяли модель по умолчанию, пересравните с `openclaw.json`, чтобы убедиться, что ваши пользовательские настройки всё ещё применены.
  </Step>
  <Step title="Перезагрузите и проверьте">
    Перезапустите WebUI, чтобы убедиться, что модель, логи и все подключённые IM-каналы работают корректно.
  </Step>
</Steps>

Если вы точно знаете, что хотите только обновить npm-пакет OpenClaw, можно сначала выполнить `npm install -g openclaw@latest` и затем перезапустить сервис; однако таким образом вы не обновите патчи и скрипты из установщика автоматически.

## Руководство по удалению

<Tabs>
  <Tab title="Linux">
    ```bash
    systemctl --user disable --now openclaw
    rm -f ~/.config/systemd/user/openclaw.service
    systemctl --user daemon-reload
    rm -rf ~/.openclaw
    npm uninstall -g openclaw
    ```
  </Tab>
  <Tab title="macOS">
    ```bash
    launchctl stop com.crazyrouter.openclaw
    launchctl unload ~/Library/LaunchAgents/com.crazyrouter.openclaw.plist
    rm -f ~/Library/LaunchAgents/com.crazyrouter.openclaw.plist
    rm -rf ~/.openclaw
    npm uninstall -g openclaw
    ```
  </Tab>
</Tabs>

Если вы устанавливали Node.js исключительно ради OpenClaw, можете вручную удалить Node.js после подтверждения, что другие проекты от него не зависят.

## Частые ошибки и их исправление

| Симптом | Возможная причина | Способ решения |
|------|----------|----------|
| WebUI не открывается | Сервис не запущен, порт занят или блокируется файерволом | Проверьте сначала статус сервиса, затем порт `18789` и настройки файервола |
| Страница открывается, но постоянно требует входа | `gateway.auth.token` неверен или вы используете не адрес автологина | Заново скопируйте ссылку `?token=...` из вывода установщика, при необходимости проверьте `openclaw.json` |
| 401 unauthorized | Ключ Crazyrouter в `models.providers.*.apiKey` недействителен или истёк | Обновите API Key и перезапустите сервис |
| 403 / model not allowed | Запрашиваемая OpenClaw модель не разрешена в токене Crazyrouter | В настройках токена разрешите нужную модель |
| 429 / превышена квота | Превышен лимит токена или сработало ограничение скорости | Увеличьте квоту, используйте более дешёвую модель или разделите токен |
| После смены модели вызывает старую модель | Сервис не был перезапущен или исправлен неверный путь provider | Проверьте `agents.defaults.model.primary` и перезапустите |
| Бот Telegram не отвечает | Не прописан `botToken`, не завершено связывание owner или сервис не был перезапущен | Проверьте `channels.telegram`, перезапустите сервис, повторно отправьте сообщение для связывания |
| После установки в Linux — сообщение о неработающем сервисе | Неудачный запуск systemd user service | Выполните `journalctl --user -u openclaw -f` для просмотра ошибки |
| После установки на macOS — сообщение о неработающем сервисе | Ошибка запуска через launchd | Просмотрите `~/.openclaw/openclaw.err` |

## FAQ

### Какой адрес использовать для бэкенда Crazyrouter?

Используйте значение, установленное установщиком: для OpenAI-совместимого provider — `https://api.crazyrouter.com/v1`, для nативных провайдеров Claude / MiniMax — `https://api.crazyrouter.com`.

### Какую модель оставить по умолчанию?

В большинстве случаев оставляйте `claude-opus-4-8`. Если вы в основном используете OpenClaw как помощника по коду — переключитесь на `gpt-5.5`.

### Почему нужная мне модель не отображается в списке?

Обычно ваш токен Crazyrouter не разрешает выбранную модель, или вы выбрали неправильный префикс provider.

### Почему Telegram работает в личных сообщениях, но не в группах?

По умолчанию установщик задаёт для Telegram групп политику `allowlist`. Настройте Telegram channel в соответствии с вашими задачами.

### Как наиболее безопасно открыть OpenClaw внешнему доступу?

Минимум — ограничьте допустимые источники, защитите `gateway.auth.token` и выделите для OpenClaw отдельный токен Crazyrouter. Если делаете публично доступным — рекомендуется настроить реверс-прокси и дополнительный контроль доступа.
