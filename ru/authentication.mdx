## Аутентификация с помощью Bearer Token

Все запросы к API должны содержать API Key в Header:

```
Authorization: Bearer YOUR_API_KEY
```

## Получение API Key

1. Войдите в [Crazyrouter](https://crazyrouter.com)
2. После входа перейдите на страницу [Управление токенами](https://crazyrouter.com/console/token)
3. Нажмите «Создать токен»
4. Установите имя токена, лимит квоты, доступные модели и другие параметры
5. Скопируйте сгенерированный ключ, начинающийся с `sk-`

<Warning>
API Key отображается только один раз при создании. Пожалуйста, сохраните его в надежном месте. В случае потери потребуется создать новый ключ.
</Warning>

## Пример использования

<Note>
Для совместимого с OpenAI подключения по умолчанию используется международный адрес `https://api.crazyrouter.com/v1`. Для Восточной Азии рекомендуется использовать `https://cn.crazyrouter.com/v1`. Если вы хотите настроить адрес для Claude Code, Hermes, OpenClaw или других инструментов, сначала ознакомьтесь с [описанием конечной точки API](https://docs.crazyrouter.com/ru/api-endpoint).
</Note>

<CodeGroup>
```bash cURL
curl https://api.crazyrouter.com/v1/chat/completions \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-5.5", "messages": [{"role": "user", "content": "Hi"}]}'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",
    base_url="https://api.crazyrouter.com/v1"
)
```

```javascript Node.js
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-xxxxxxxx',
  baseURL: 'https://api.crazyrouter.com/v1'
});
```
</CodeGroup>

## Контроль прав доступа токена

При создании токена можно настроить:

- **Имя**: для удобной идентификации назначения
- **Лимит квоты**: установить максимальную доступную квоту
- **Время истечения**: настроить период действия
- **Доступные модели**: ограничить список разрешённых моделей
- **Белый список IP**: ограничить IP-адреса, с которых допускается использование
