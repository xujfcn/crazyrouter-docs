> Обновление содержания: 2026-07-20

## Описание интерфейса

Безвозвратно удаляет указанный API токен. После удаления ключ API станет недействительным немедленно.

<Note>
  Эта группа интерфейсов `/api/token/*` используется главным образом для автоматизации управления API ключами в консоли Crazyrouter. Для работы они требуют `access token` и `New-Api-User` в заголовках запросов пользователя, и не предназначены для непосредственного использования в процессах вызова моделей `sk-xxx`. В качестве базового адреса запроса обязательно используйте `https://crazyrouter.com`; `https://api.crazyrouter.com` — это специальный вход только для доступа к API моделей, обращение к управленческим путям через него вызовет `404 api_only_endpoint`.
</Note>

## Метод аутентификации

Используйте пользовательскую аутентификацию с передачей в заголовках запроса:

```text
Authorization: Bearer your_access_token
New-Api-User: 1
```

## Параметры пути

<ParamField path="id" type="integer" required>
  ID токена, который нужно удалить
</ParamField>

## Формат ответа

```json
{
  "success": true,
  "message": "令牌删除成功"
}
```

## Пример кода

<CodeGroup>

```python Python
import requests

headers = {
    "Authorization": "Bearer your_access_token",
    "New-Api-User": "1",
    "User-Agent": "Mozilla/5.0"
}

token_id = 10
response = requests.delete(
    f"https://crazyrouter.com/api/token/{token_id}",
    headers=headers
)

print(response.json())
```

```bash cURL
curl -X DELETE https://crazyrouter.com/api/token/10 \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 1"
```

</CodeGroup>

<Warning>
  Операция удаления необратима. После удаления все приложения, использующие этот ключ, немедленно потеряют возможность обращаться к API.
</Warning>
