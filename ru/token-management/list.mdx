## Описание интерфейса

Получение всех API-токенов (Token), созданных текущим пользователем, с поддержкой постраничного вывода.

<Note>
  Данный набор `/api/token/*` интерфейсов предназначен преимущественно для автоматизации управления API-ключами в консоли Crazyrouter. Для работы требуются заголовки запроса `access token` и `New-Api-User` пользователя, эти интерфейсы не предназначены для прямого использования в обычных процессах вызова `sk-xxx`-моделей. Базовый адрес запроса должен быть `https://crazyrouter.com`; `https://api.crazyrouter.com` — это специальная точка входа для model API, вызовы к управленческому пути вернут `404 api_only_endpoint`.
</Note>

## Способ аутентификации

Аутентификация с помощью Access Token пользователя, необходимо указать в заголовке запроса:

```text
Authorization: Bearer {access_token}
New-Api-User: {user_id}
```

## Параметры запроса

<ParamField query="p" type="integer" default="1">
  Номер страницы. Код совместим со старой реализацией, но рекомендуется начинать с `1`
</ParamField>

<ParamField query="size" type="integer" default="10">
  Количество элементов на странице, максимум 100
</ParamField>

## Формат ответа

```json
{
  "success": true,
  "message": "",
  "data": {
    "page": 1,
    "page_size": 10,
    "total": 1,
    "items": [
      {
        "id": 1,
        "user_id": 1,
        "key": "sk-xxxxxxxxxxxxxxxx",
        "status": 1,
        "name": "我的令牌",
        "created_time": 1706000000,
        "accessed_time": 1706100000,
        "expired_time": -1,
        "remain_quota": 500000,
        "unlimited_quota": false,
        "model_limits_enabled": true,
        "model_limits": "[\"gpt-5.5\",\"claude-opus-4-8\"]",
        "allow_ips": "203.0.113.10",
        "used_quota": 12345,
        "group": "default"
      }
    ]
  }
}
```

## Описание полей

| Поле | Тип | Описание |
|------|------|----------|
| `id` | int | ID токена |
| `key` | string | API Key (формат sk-xxx) |
| `status` | int | Статус: 1=активирован, 2=деактивирован |
| `name` | string | Название токена |
| `expired_time` | int | Временная метка истечения, `-1` означает никогда не истекает |
| `remain_quota` | int | Оставшийся лимит |
| `unlimited_quota` | bool | Неограниченный лимит |
| `used_quota` | int | Использованный лимит |
| `model_limits_enabled` | bool | Включён ли белый список моделей |
| `model_limits` | string | Строка конфигурации ограничений моделей |
| `allow_ips` | string | Строка белого списка IP |
| `group` | string | Группа |

## Пример кода

<CodeGroup>

```python Python
import requests

headers = {
    "Authorization": "Bearer your_access_token",
    "New-Api-User": "1",
    "User-Agent": "Mozilla/5.0"
}

response = requests.get(
    "https://crazyrouter.com/api/token/?p=1&size=100",
    headers=headers
)

page = response.json()["data"]
for token in page["items"]:
    print(f"[{token['name']}] {token['key'][:10]}... 额度: {token['remain_quota']}")
```

```bash cURL
curl "https://crazyrouter.com/api/token/?p=1&size=100" \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 1"
```

</CodeGroup>
