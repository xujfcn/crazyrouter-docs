## Описание интерфейса

Поиск токенов по ключевым словам, поддерживается нечеткое совпадение по названию, а также фильтрация по частям строки токена.

<Note>
  Эта группа интерфейсов `/api/token/*` в первую очередь используется для автоматизации управления API Key в консоли Crazyrouter. Для работы требуется заголовки `access token` и `New-Api-User` пользователя, интерфейс не предназначен для прямого использования стандартными процессами вызова модели `sk-xxx`. Базовый адрес запроса должен быть `https://crazyrouter.com`; `https://api.crazyrouter.com` — это специализированная точка доступа для Model API, при вызове путей управления возвращается `404 api_only_endpoint`.
</Note>

## Способ аутентификации

Используйте пользовательскую аутентификацию, передайте в заголовке запроса:

```text
Authorization: Bearer your_access_token
New-Api-User: 1
```

## Параметры запроса

<ParamField query="keyword" type="string" required>
  Ключевое слово поиска, совпадение по названию токена
</ParamField>

<ParamField query="token" type="string">
  Необязательно. Фильтрация по строковому фрагменту токена
</ParamField>

## Пример кода

<CodeGroup>

```python Python
import requests

headers = {
    "Authorization": "Bearer your_access_token",
    "New-Api-User": "1",
    "User-Agent": "Mozilla/5.0"
}

response = requests.get(
    "https://crazyrouter.com/api/token/search?keyword=生产&token=sk-",
    headers=headers
)

tokens = response.json()["data"]
for token in tokens:
    print(f"[{token['id']}] {token['name']} - 剩余额度: {token['remain_quota']}")
```

```bash cURL
curl "https://crazyrouter.com/api/token/search?keyword=生产&token=sk-" \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 1"
```
