## Описание интерфейса

Создаёт новый API токен (Token), который используется для обращения к API моделей искусственного интеллекта.

<Note>
  Эта группа интерфейсов `/api/token/*` предназначена главным образом для автоматизации управления API-ключами в консоли Crazyrouter. Для работы требуется наличие в заголовке запроса `access token` и `New-Api-User` пользователя и не предназначена для прямого использования в обычных сценариях вызова моделей `sk-xxx`. При обращении необходимо использовать базовый адрес `https://crazyrouter.com`; `https://api.crazyrouter.com` используется только как вход для доступа к моделям API, при этом при вызове управляющих путей будет возвращён `404 api_only_endpoint`.
</Note>

## Способ аутентификации

Данный интерфейс требует аутентификации пользователя:

```text
Authorization: Bearer your_access_token
New-Api-User: 1
```

## Параметры запроса

<ParamField body="name" type="string" required>
  Имя токена, для облегчения распознавания его назначения
</ParamField>

<ParamField body="remain_quota" type="integer" default="0">
  Начальный лимит (единицы: внутреннее значение лимита). Если установлено в 0, требуется совместное использование с `unlimited_quota`
</ParamField>

<ParamField body="unlimited_quota" type="boolean" default="false">
  Установить как неограниченный лимит
</ParamField>

<ParamField body="expired_time" type="integer" default="-1">
  Время истечения (Unix-метка времени), `-1` означает, что срок действия не ограничен
</ParamField>

<ParamField body="model_limits_enabled" type="boolean" default="false">
  Включить ограничение по белому списку моделей
</ParamField>

<ParamField body="model_limits" type="string">
  Конфигурация ограничений моделей; на данный момент это строка, обычно хранящаяся в виде JSON, например `["gpt-5.5","claude-opus-4-8"]`
</ParamField>

<ParamField body="allow_ips" type="string">
  Строка белого списка IP-адресов. Можно указать один IP или несколько, разделённых переводом строки
</ParamField>

<ParamField body="group" type="string">
  Группа, к которой относится токен. Можно выбрать только те группы, к которым у текущего пользователя есть доступ
</ParamField>

## Формат ответа

После успешного выполнения запроса этот интерфейс возвращает только статус успешного выполнения:

```json
{
  "success": true,
  "message": ""
}
```

## Пример кода

<CodeGroup>

```python Python
import json
import requests

headers = {
    "Authorization": "Bearer your_access_token",
    "New-Api-User": "1",
    "Content-Type": "application/json",
    "User-Agent": "Mozilla/5.0"
}

response = requests.post(
    "https://crazyrouter.com/api/token/",
    headers=headers,
    json={
        "name": "生产环境",
        "remain_quota": 100000,
        "unlimited_quota": False,
        "expired_time": -1,
        "model_limits_enabled": True,
        "model_limits": json.dumps(["gpt-5.5", "claude-opus-4-8"]),
        "allow_ips": "203.0.113.10"
    }
)

print(response.json())
```

```bash cURL
curl -X POST https://crazyrouter.com/api/token/ \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 1" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "生产环境",
    "remain_quota": 100000,
    "expired_time": -1,
    "model_limits_enabled": true,
    "model_limits": "[\"gpt-5.5\"]"
  }'
```

</CodeGroup>

<Warning>
  При создании токена данный интерфейс не возвращает полный, только что сгенерированный `key` в ответе. Если вашему процессу необходимо немедленно скопировать полный ключ, создавайте и сохраняйте его через страницу консоли.
</Warning>
