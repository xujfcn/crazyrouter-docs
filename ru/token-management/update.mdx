## Описание интерфейса

Изменяет имя, лимит, время истечения, права доступа к моделям и другие настройки существующего токена.

<Note>
  Эта группа интерфейсов `/api/token/*` предназначена в первую очередь для автоматизации управления API-ключами в консоли Crazyrouter. Для использования требуются `access token` и `New-Api-User` в заголовках запроса; интерфейсы не предназначены для прямого вызова обычными процессами вызова модели `sk-xxx`. В качестве базового адреса запроса необходимо использовать `https://crazyrouter.com`; `https://api.crazyrouter.com` предназначен как специальная точка входа для модели API, а вызовы по управленческому пути вернут `404 api_only_endpoint`.
</Note>

## Способ аутентификации

Используйте пользовательскую аутентификацию, укажите в заголовке запроса:

```text
Authorization: Bearer your_access_token
New-Api-User: 1
```

## Параметры запроса

<ParamField body="id" type="integer" required>
  Идентификатор токена
</ParamField>

<ParamField body="name" type="string">
  Имя токена
</ParamField>

<ParamField body="remain_quota" type="integer">
  Оставшийся лимит
</ParamField>

<ParamField body="unlimited_quota" type="boolean">
  Неограниченный лимит
</ParamField>

<ParamField body="expired_time" type="integer">
  Метка времени окончания действия; `-1` означает, что срок не ограничен
</ParamField>

<ParamField body="model_limits_enabled" type="boolean">
  Включить белый список моделей
</ParamField>

<ParamField body="model_limits" type="string">
  Строка конфигурации ограничений моделей, например `["gpt-5.5","claude-opus-4-8"]`
</ParamField>

<ParamField body="status" type="integer">
  Статус: 1=включён, 2=отключён
</ParamField>

<ParamField body="allow_ips" type="string">
  Строка IP-белого списка
</ParamField>

<ParamField body="group" type="string">
  Группа
</ParamField>

## Формат ответа

Данный интерфейс возвращает объект обновлённого токена:

```json
{
  "success": true,
  "message": "",
  "data": {
    "id": 10,
    "name": "生产环境-已更新",
    "status": 1,
    "remain_quota": 200000,
    "unlimited_quota": false,
    "model_limits_enabled": true,
    "model_limits": "[\"gpt-5.5\",\"claude-opus-4-8\"]",
    "allow_ips": "203.0.113.10",
    "group": "default"
  }
}
```

## Пример кода

<CodeGroup>

```python Python
import json
import requests

headers = {
    "Authorization": "Bearer your_access_token",
    "New-Api-User": "1",
    "Content-Type": "application/json",
    "User-Agent": "Mozilla/5.0"
}

response = requests.put(
    "https://crazyrouter.com/api/token/",
    headers=headers,
    json={
        "id": 10,
        "name": "生产环境-已更新",
        "remain_quota": 200000,
        "model_limits_enabled": True,
        "model_limits": json.dumps(["gpt-5.5", "claude-opus-4-8"])
    }
)

print(response.json())
```

```bash cURL
curl -X PUT https://crazyrouter.com/api/token/ \
  -H "Authorization: Bearer your_access_token" \
  -H "New-Api-User: 1" \
  -H "Content-Type: application/json" \
  -d '{
    "id": 10,
    "name": "生产环境-已更新",
    "remain_quota": 200000,
    "model_limits_enabled": true,
    "model_limits": "[\"gpt-5.5\"]"
  }'
```

</CodeGroup>

<Warning>
  Изменение токена не приводит к перегенерации API-ключа. Если требуется сменить ключ, удалите токен и создайте его заново.
</Warning>
