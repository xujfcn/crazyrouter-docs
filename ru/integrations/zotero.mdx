Zotero — это инструмент для управления научными публикациями; он не имеет встроенного интерфейса настройки Crazyrouter. Обычно подключение реализуется следующим образом: сначала устанавливается плагин Zotero, который поддерживает вызовы AI, затем в этом плагине прописываются OpenAI-совместимый адрес Crazyrouter, API Key и название модели.

Главный принцип этой страницы — не "выбрать любой AI-плагин Zotero и подключить", а сначала разделить плагины на типы:

- Можно подключать напрямую: плагин поддерживает пользовательские настройки `Base API URL` / `API URL` / `Endpoint`
- Нельзя подключать напрямую или не рекомендуется для публичной инструкции: плагин поддерживает только ввод официального OpenAI Key, не имеет поля для пользовательского upstream-адреса

## Сначала итог

Рекомендованный способ подключения Crazyrouter к Zotero:

- Выберите AI-плагин для Zotero, поддерживающий ввод пользовательского OpenAI-совместимого адреса
- Пропишите базовый адрес как `https://api.crazyrouter.com/v1`
- Пропишите API Key как `sk-xxx`
- Для первичной проверки используйте модель `gpt-5.5`

<Warning>
Не все AI-плагины для Zotero поддерживают пользовательский upstream-адрес. Если в плагине есть только поле для "OpenAI API Key" и нет ни `Base URL`, ни `API URL`, то, скорее всего, этот плагин не сможет направлять запросы к Crazyrouter. Такие плагины не подходят для публичных инструкций по настройке.
</Warning>

## Почему так

В экосистеме AI-плагинов Zotero сейчас большая разница:

- В официальной документации Zotero говорится, что плагины развивает сообщество; способ установки общий, но функциональность отличается
- Некоторые плагины явно поддерживают пользовательские настройки `base API URL`
- В других только указано, как вводить `OpenAI API Key`

Поэтому в официальной документации Crazyrouter необходимо в первую очередь учить пользователя выбирать плагины, поддерживающие ввод пользовательского OpenAI-совместимого адреса, а не предполагать, что любой плагин подходит.

## Кому подходит

- Пользователям, желающим делать аннотации, переводы, вопросы-ответы внутри Zotero
- Тем, кто хочет объединить чтение литературы и вызов моделей Crazyrouter в одну рабочую схему
- Тем, кто хочет добавить AI-помощника в процессы работы с публикациями, PDF, и заметками
- Тем, кто не хочет программировать, а предпочитает настраивать всё через графический интерфейс Zotero

## Как выбрать AI-плагин Zotero

В публичной документации рекомендуется выбирать плагины, отвечающие таким условиям:

- Есть поля для ввода `Base API URL`, `API URL` или `Endpoint`
- Есть поле для ввода `API Key`
- Можно вручную прописать название модели
- Лучше если параметры можно изменить через настройки Zotero

### Рекомендованный способ проверки

Если в документации плагина явно описаны такие возможности, он лучше подходит для подключения Crazyrouter:

- `Customize base API URL`
- `API URL`
- `Custom endpoint`
- `Model preferences`

Пример: в README плагина `zotero-chatgpt` указано, что он поддерживает пользовательские настройки `base API URL`; в README плагина `Aria` основное внимание уделено полям `OpenAI API Key` и настройке модели; но в описании не говорится о возможности пользовательского upstream-адреса. Поэтому для Crazyrouter наиболее надёжная инструкция — "выбирать плагины с поддержкой пользовательского OpenAI-совместимого адреса".

## Рекомендуемый формат настройки

Названия полей могут отличаться, но базово рекомендуется заполнить так:

| Поле плагина | Рекомендуемое значение |
|----------|--------|
| Base API URL / API URL | `https://api.crazyrouter.com/v1` |
| Full Endpoint | `https://api.crazyrouter.com/v1/chat/completions` |
| API Key | `sk-xxx` |
| Model | `gpt-5.5` |

<Tip>
Если плагин требует "базовый адрес", рекомендуем вводить `https://api.crazyrouter.com/v1`. Только если плагин явно требует "полный адрес чат-интерфейса", используйте `https://api.crazyrouter.com/v1/chat/completions`.
</Tip>

## Этапы настройки

<Steps>
  <Step title="Шаг 1: Создайте специализированный токен Crazyrouter для Zotero">
    В первый раз рекомендуется разрешить только:

    - `gpt-5.5`
    - `claude-opus-4-8`

    Не стоит сразу открывать много моделей — так проще устранять проблемы.
  </Step>

  <Step title="Шаг 2: Установите настольную версию Zotero">
    Установите Zotero для вашей ОС, убедитесь в корректном импорте или просмотре хотя бы одной публикации.
  </Step>

  <Step title="Шаг 3: Скачайте и установите AI-плагин">
    По официальной инструкции Zotero по установке плагинов, сначала скачайте файл `.xpi`, затем в Zotero:

    - Откройте `Tools`
    - Перейдите в `Plugins`
    - Перетащите файл `.xpi` в окно плагинов

    После завершения перезапустите Zotero.
  </Step>

  <Step title="Шаг 4: Перейдите в настройки плагина">
    Частые точки доступа:

    - `Edit` → `Preferences`
    - Страница настроек самого плагина
    - Боковая панель или toolbar плагина

    Расположение зависит от плагина, главное — найти область для ввода API и модели.
  </Step>

  <Step title="Шаг 5: Введите адрес Crazyrouter, ключ и модель">
    Если плагин поддерживает режим базового адреса, заполните:

    - `Base API URL`: `https://api.crazyrouter.com/v1`
    - `API Key`: `sk-xxx`
    - `Model`: `gpt-5.5`

    Если только полный адрес интерфейса — используйте:

    - `Endpoint`: `https://api.crazyrouter.com/v1/chat/completions`
  </Step>

  <Step title="Шаг 6: При необходимости, перезапустите Zotero, как требует плагин">
    В некоторых плагинах изменения API Key, модели или параметров требуют перезапуска Zotero. После первой настройки лучше перезапустить программу.
  </Step>

  <Step title="Шаг 7: Проверьте первый запуск на простейшем академическом сценарии">
    Не начинайте с сложных обзоров. Для первой проверки рекомендуется:

    - Выберите публикацию с аннотацией
    - Или откройте небольшой PDF
    - Запустите простую аннотацию / перевод / вопрос-ответ

    Для проверки используйте такой промпт:

    ```text
    Summarize this paper in 3 bullet points.
    ```
  </Step>
</Steps>

## Рекомендуемая последовательность проверок

Действуйте по этому порядку:

1. Сначала убедитесь, что Zotero и плагин запускаются корректно
2. Проверьте `gpt-5.5`
3. Сделайте аннотацию одной публикации
4. Потом перевод
5. Затем сравнение нескольких публикаций, анализ длинных текстов или пакетные задачи

| Сложная аналитика и объяснения | `claude-opus-4-8` | Лучше подходит для обзоров, сравнений методов, объяснения длинных текстов |

## Способы использования Zotero

### Аннотация одной публикации

Лучше всего для первой проверки — простой контекст, легко оценить результат.

### Перевод PDF

Сначала протестируйте на одной странице или коротком отрывке, затем расширяйте область.

### Сравнение публикаций

Не делайте это первым шагом; дождитесь стабильной аннотации и перевода, затем переходите к обзорам, извлечению пробелов в исследованиях и сложным заданиям.

### Организация заметок

Если плагин умеет записывать результат в заметки Zotero, начните с короткой аннотации, не генерируйте сразу длинные заметки.

## Типичные ошибки и способы исправления

| Симптом | Причина | Исправление |
|------|----------|----------|
| В плагине только поле для OpenAI Key, нет Base URL | Плагин не поддерживает пользовательский upstream-адрес | Поменяйте на плагин с поддержкой `Base API URL` или `Endpoint` |
| 401 unauthorized | Ошибка токена, неполный копипаст или токен не активен | Сгенерируйте новый токен и пропишите снова |
| 404 | Ошибка базового или полного адреса | Исправьте базовый адрес на `https://api.crazyrouter.com/v1`, полный — на `https://api.crazyrouter.com/v1/chat/completions` |
| 403 / model not allowed | Токен не разрешает текущую модель | В настройках токена Crazyrouter разрешите данную модель |
| `model not found` | Ошибка в названии модели | Для минимума используйте `gpt-5.5` |
| Плагин не реагирует или изменения не применяются | Нужно перезагрузить Zotero | После изменений перезапустите Zotero и повторите |
| Ошибка аннотации, но интерфейс не ругается | Нет аннотации, отсутствует PDF или плагин не получил контекст | Попробуйте публикацию с аннотацией или PDF |
| Медленная обработка длиных текстов | Слишком длинный PDF или большой объем задачи | Сократите до одного абзаца, страницы или публикации для аннотации |

## FAQ

### Можно ли настроить Crazyrouter напрямую в Zotero?

Обычно настройка идет не в основном Zotero, а через AI-плагин с поддержкой OpenAI-совместимого интерфейса.

### Какие плагины лучше всего подходят для Crazyrouter?

В первую очередь — поддерживающие пользовательские настройки `Base API URL`, `API URL` или `Endpoint`.

### Что делать, если плагин поддерживает только ввод OpenAI API Key?

Такие плагины не позволяют направлять запросы к Crazyrouter и не рекомендуются в качестве основной инструкции. Лучше выбрать другой с поддержкой пользовательского адреса.

### Какой базовый адрес вводить?

Вводите `https://api.crazyrouter.com/v1`.

### Какую первую модель настроить?

Для первой проверки используйте `gpt-5.5`.

### Когда переходить к сравнению публикаций или сложным обзорам?

Дождитесь стабильной аннотации и перевода одной публикации, затем постепенно усложняйте задачи.

<Note>
Если ваша цель — "заставить Zotero работать с Crazyrouter", главное не сразу выбирать самый мощный плагин, а убедиться, что выбранный плагин поддерживает ввод пользовательского OpenAI-совместимого адреса, и провести проверку аннотации одной публикации через `gpt-5.5`.
</Note>
