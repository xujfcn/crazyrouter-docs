NextChat (ранее ChatGPT Next Web) подходит для быстрой развертки легковесного, быстрореагирующего чата с простой самостоятельной установкой. Для интеграции с Crazyrouter рекомендуется использовать стандартный путь, совместимый с OpenAI, указав в качестве адреса службы корневой домен Crazyrouter.

## Обзор

Через опции OpenAI в NextChat вы можете направлять запросы в Crazyrouter:

- Рекомендуемый протокол: `OpenAI-compatible API`
- Рекомендуемый метод: стандартный путь OpenAI по умолчанию в NextChat
- Базовый URL: `https://api.crazyrouter.com`
- Метод аутентификации: `sk-...` token
- Рекомендуемая модель для первичной проверки: `gpt-5.5`

<Note>
В официальном README NextChat `BASE_URL` определён как базовый URL для запросов к OpenAI API, в примерах также используется корневой домен; локально открытый `http://127.0.0.1:4000/api/status` предоставляет `server_address` также как корневой адрес. Поэтому при интеграции с Crazyrouter для первичной проверки в первую очередь указывается `https://api.crazyrouter.com`; если ваша кастомная версия требует более конкретный путь, следуйте документации этой версии.
</Note>

## Кому подходит

- Тем, кто хочет быстро развернуть лёгкий фронт чата
- Тем, кто желает использовать Crazyrouter для личных или небольших командных чатов в вебе
- Тем, кто хочет задавать модель и upstream через переменные среды
- Тем, кто хочет запустить OpenAI-совместимый путь с минимальной настройкой

## Рекомендуемый протокол

Рекомендуемый протокол: `OpenAI-compatible API`

При интеграции NextChat с Crazyrouter в первую очередь указывается:

```text
https://api.crazyrouter.com
```

Не указывайте:

- `https://api.crazyrouter.com/v1/chat/completions`
- `https://api.crazyrouter.com/v1/models`

Если ваша версия NextChat в истории требует прописывать более конкретный API host вручную — следуйте документации для этой версии; для первой интеграции используйте корневой домен как базу для валидации.

<Tip>
В различных способах развертывания NextChat точка входа может меняться: при онлайн-использовании обычно вводите в настройках, а при самостоятельном размещении часто задаёте через переменные среды. Независимо от изменений UI на первом этапе придерживайтесь минимальной конфигурации: `API Key` + корневой домен `BASE_URL` + одна модель `gpt-5.5`.
</Tip>

## Предварительные условия

| Проект | Описание |
|------|------|
| Аккаунт Crazyrouter | Сначала зарегистрируйтесь на [crazyrouter.com](https://crazyrouter.com) |
| Токен Crazyrouter | Рекомендуется создать отдельный `sk-...` токен для NextChat |
| NextChat | Подойдёт онлайн или самостоятельная версия, предпочтительно последняя стабильная |
| Доступная модель | Разрешите хотя бы одну OpenAI-совместимую модель для чата, успешно протестированную сегодня, например `gpt-5.5` |

Рекомендуемый первоначальный белый список:

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

## Быстрый старт за 5 минут

<Steps>
  <Step title="Создать специализированный токен для NextChat">
    В админ-панели Crazyrouter создайте новый токен и назовите его `nextchat`. Для начала разрешите только базовые модели типа `gpt-5.5` и `claude-opus-4-8`.
  </Step>
  <Step title="Открыть настройки NextChat">
    Зайдите в NextChat, кликните на иконку `Настройки` в левом нижнем углу или на вход через `Settings`.
  </Step>
  <Step title="Ввести адрес интерфейса и ключ">
    В настройках, связанных с OpenAI, укажите:
    - `API Key`: ваш `sk-...`
    - `Адрес интерфейса / Базовый URL`: `https://api.crazyrouter.com`
  </Step>
  <Step title="Указать модель">
    В `Модель / Модель` введите или выберите `gpt-5.5` вручную. Если текущая версия поддерживает настраиваемый список моделей — добавьте нужные.
  </Step>
  <Step title="Завершить первичную проверку">
    Создайте новый диалог и отправьте `Reply only OK`. После нормального ответа постепенно подключайте новые модели.
  </Step>
</Steps>

## Быстрая настройка при самостоятельном размещении

Пример типового использования Docker:

```yaml
services:
  nextchat:
    image: yidadaa/chatgpt-next-web
    ports:
      - "3000:3000"
    environment:
      - OPENAI_API_KEY=sk-xxx
      - BASE_URL=https://api.crazyrouter.com
      - CUSTOM_MODELS=+gpt-5.5,+claude-opus-4-8,+gemini-3.1-pro
      - HIDE_USER_API_KEY=1
```

Описание популярных переменных среды:

| Переменная | Рекомендуемое значение | Описание |
|------|--------|------|
| `OPENAI_API_KEY` | `sk-xxx` | Стандартный токен Crazyrouter |
| `BASE_URL` | `https://api.crazyrouter.com` | Сначала укажите корневой домен по официальной `BASE_URL` для первичной проверки |
| `CUSTOM_MODELS` | `+gpt-5.5,+claude-opus-4-8,+gemini-3.1-pro` | Разрешить фронту использовать дополнительные модели |
| `HIDE_USER_API_KEY` | `1` | Запретить ввод других ключей конечным пользователям |

## Рекомендуемая конфигурация моделей

| Сценарий использования | Рекомендуемая модель | Причина |
|----------|----------|------|
| Основная чат-модель по умолчанию | `gpt-5.5` | Проверена и подходит как главный вариант для NextChat |
| Для длинных текстов и сложных объяснений | `claude-opus-4-8` | Лучше справляется с длинными и комплексными задачами |
| Gemini в резерве | `gemini-3.1-pro` | Для дополнительной проверки совместимости |

Рекомендация по порядку: сначала убедитесь, что работает `gpt-5.5`, затем расширяйте список через `CUSTOM_MODELS`.

## Лучшие практики по настройке токена

| Настройка | Рекомендация | Описание |
|------|------|------|
| Отдельный токен | Обязательно | Не используйте один токен для NextChat, LobeChat, Cursor, Codex |
| Белый список моделей | Настоятельно рекомендуется | Разрешите только те модели, которые реально видны фронту |
| Ограничение по IP | Можно применить для закрепленного внешнего IP | В непостоянных сетях использовать с осторожностью |
| Лимит по квоте | Строго рекомендуется | При коллективном использовании расход может резко возрасти |
| Изоляция сред | Рекомендуется | Используйте отдельные токены для демонстрации, теста, продакшена |
| Кастомный ключ пользователя | По умолчанию лучше отключить | Для единых upstream и биллинга задайте `HIDE_USER_API_KEY=1` |

## Частые ошибки и решения

| Симптом | Причина | Исправление |
|------|----------|----------|
| 401 unauthorized | Ошибка токена, просрочен или скопирован с пробелом | Заново сгенерируйте токен и замените |
| 403 / модель запрещена | Модель не в белом списке | В настройках токена Crazyrouter разрешите нужную модель |
| 404 | Указан полный путь API или ошибка в имени переменной версии | Вернитесь к `https://api.crazyrouter.com` и проверьте, используется ли переменная `BASE_URL` или другая |
| Не видно пунктов настройки на фронте после самостоятельной установки | Конфигурация задана только через environment, а не во фронте | Проверьте настройки `OPENAI_API_KEY`, `BASE_URL`, `CUSTOM_MODELS` в задеплоенной среде |
| Не отображаются модели в вебе | Не задан `CUSTOM_MODELS` или используется устаревшая конфигурация | Проверьте вручную с `gpt-5.5` и обновите/проверьте переменные среды |
| Запрос отправляется, но модель работает с ошибкой | Ошибочно прописана дефолтная модель или она недоступна сейчас | Вернитесь к `gpt-5.5` как к базовой |
| Пользователь всё ещё может менять свой ключ | Не включён `HIDE_USER_API_KEY=1` | Пропишите нужную переменную в среде |
| Быстрый рост расходов | Один токен с широкими правами используется многими | Разделите токены, ограничьте белый список, установите ограничения |

## Советы по производительности и стоимости

- По умолчанию откройте только `gpt-5.5`
- Уберите дорогие модели из списка по умолчанию, добавляйте по необходимости
- При публичном или полупубличном размещении по возможности скройте ввод ключа пользователем
- Для тестовых и основных инстансов используйте раздельный биллинг, чтобы тестовая активность не влияла на продакшн-квоту
- Если наблюдается аномальный расход, сначала проверьте логи Crazyrouter — возможно, причина в длинных сессиях или коллективном использовании

## FAQ

### Какой адрес указать в NextChat?

В первую очередь укажите `https://api.crazyrouter.com`.

### Почему не рекомендуется сразу писать `/v1`?

Потому что в официальной документации NextChat для `BASE_URL` пример приведён именно в виде корневого домена; также возвращаемый локально `4000` для `server_address` изначально указывает на корень. Для базовой проверки достаточно использовать корневой домен.

### Какую модель указать первой?

Сначала используйте `gpt-5.5`.

### Нужно ли обязательно настраивать `CUSTOM_MODELS`?

Не обязательно. Сначала вручную проверьте `gpt-5.5`, а убедившись в работоспособности, добавьте остальные модели.

### Почему в некоторых установках можно редактировать только переменные среды, а не через веб-интерфейс?

Потому что точка настройки зависит от типа установки NextChat. В некоторых самостоятельных версиях upstream, модель и Key жёстко прописываются в переменных среды, а фронт только использует их без редактирования.

### Следует ли скрывать пользовательский ввод ключа при самостоятельной установке?

Если хотите централизованно контролировать upstream и расходы — да, рекомендуется скрыть.

<Note>
Если вам нужен максимально бюджетный, лёгкий фронт для чата — NextChat очень хорошо подойдёт; если в приоритете командная работа и расширенные функции — наращивать стоит через LobeChat или Dify.
</Note>
