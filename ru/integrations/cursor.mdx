Cursor подходит для интеграции Crazyrouter в ежедневный рабочий процесс программирования: для чата, объяснения кода, советов по рефакторингу и обычной помощи при редактировании.

## Обзор

Благодаря функции BYOK (Bring Your Own Key — используйте свой ключ) в Cursor вы можете перенаправить некоторые запросы чат-моделей на Crazyrouter и оплачивать их по своему токену.

- Рекомендуемый способ подключения: режим совместимости с OpenAI
- Базовый URL Crazyrouter: `https://api.crazyrouter.com/v1`
- Метод аутентификации: `sk-...` токен
- Лучшая первая интеграция: Chat, Ask, обычные диалоги для редактирования

<Warning>
Согласно официальной документации Cursor, `Custom API keys only work with standard chat models`, такие функции, как Tab Completion, которые зависят от специализированных моделей, продолжат использовать встроенные модели Cursor. Это ограничение связано с самим Cursor, а не с Crazyrouter.
</Warning>

## Для кого подходит

- Разработчики, которые хотят использовать единый Crazyrouter токен в Cursor
- Те, кто хочет контролировать выбор моделей, расходы и лимиты
- Команды, желающие интегрировать чат-функции Cursor с Crazyrouter
- Те, кто хочет разделить оплату и лимиты для разных IDE / CLI

## Используемый протокол

Рекомендуемый протокол: `OpenAI-compatible API`

В Cursor при интеграции Crazyrouter используйте базу, совместимую с OpenAI:

```text
https://api.crazyrouter.com/v1
```

Не используйте:

- `https://api.crazyrouter.com`
- `https://api.crazyrouter.com/v1/chat/completions`

## Предварительные требования

| Проект | Описание |
|------|------|
| Аккаунт Crazyrouter | Сначала зарегистрируйтесь на [crazyrouter.com](https://crazyrouter.com) |
| Токен Crazyrouter | Рекомендуется создать отдельный `sk-...` токен для использования в Cursor |
| Десктопная версия Cursor | Рекомендуется обновить до последней стабильной версии перед настройкой |
| Доступные модели | Минимум один-два совместимых с OpenAI чат-модели должны быть разрешены для токена |

Рекомендуется сначала разрешить одну из этих моделей:

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

<Tip>
Если вы также будете настраивать Claude Code, Codex, Cline, не используйте один токен для Cursor и этих моделей. Лучше создать отдельные токены — это облегчает диагностику и контроль расходов.
</Tip>

## Быстрый старт за 5 минут

<Steps>
  <Step title="Создать специальный токен для Cursor">
    В панели управления Crazyrouter создайте новый токен, желательно назвать его `cursor`. Сначала включите небольшой белый список моделей, например, `gpt-5.5` и `claude-opus-4-8`.
  </Step>
  <Step title="Открыть настройки Cursor">
    Откройте Cursor, зайдите в `Cursor Settings` → `Models`.
  </Step>
  <Step title="Ввести данные подключения OpenAI">
    В разделе настройки, посвященном OpenAI, заполните:
    - `OpenAI API Key`: ваш `sk-...`
    - `Override OpenAI Base URL`: `https://api.crazyrouter.com/v1`

    Если в вашей версии Cursor нет `Override OpenAI Base URL`, значит, поддержка пользовательских совместимых с OpenAI endpoint'ов в текущей версии неполная. Обновите Cursor или дождитесь улучшения функционала.
  </Step>
  <Step title="Проверить ключ и выбрать модель">
    Кликните `Verify`. После этого выберите одну модель для первой проверки, рекомендуем `gpt-5.5`.
  </Step>
  <Step title="Завершить первое тестирование">
    Откройте чат-панель Cursor и отправьте простой запрос, например: `Reply with only OK`. Если ответ успешно получен — интеграция Crazyrouter работает.
  </Step>
</Steps>

## Рекомендуемая настройка моделей

| Сценарий | Рекомендуемая модель | Причина |
|----------|----------|------|
| Основная рабочая | `gpt-5.5` | Проверено в продакшене 23 марта 2026 года, отличная основа для режима совместимости с OpenAI в Cursor |
| Качественный код и длинные тексты | `claude-opus-4-8` | Лучше подходит для сложных объяснений, суммирования и помощи с кодом |
| Запасной Gemini | `gemini-3.1-pro` | Хорош для второй линии проверки совместимости |

Рекомендуемый порядок: сначала настройте `gpt-5.5`, затем последовательно добавляйте `claude-opus-4-8` и `gemini-3.1-pro`.

## Лучшие практики настройки токена

| Настройка | Рекомендация | Описание |
|------|------|------|
| Отдельный токен | Обязательно | Для Cursor должен быть отдельный токен, не используйте с другими инструментами |
| Белый список моделей | Рекомендуется включить | Разрешайте только те модели, которые реально используются в Cursor |
| Ограничение IP | По ситуации | Обычно не рекомендуется для нестабильных IP, для офисной сети можно включить |
| Лимит квоты | Очень рекомендуется | Для Cursor установите отдельный бюджет, чтобы не расходовать всю квоту |
| Разделение на разработку/продакшен | Рекомендуется | Для персональных, командных и CI машин используйте разные токены |
| Регулярная смена | Рекомендуется периодически обновлять | Для предотвращения утечек токена при скриншотах, записях или синхронизации — сразу меняйте |

## Чек-лист проверки

- [ ] `Cursor Settings` → `Models`: ключ работает через `Verify`
- [ ] `Override OpenAI Base URL` установлен правильно как `https://api.crazyrouter.com/v1`
- [ ] Успешно выбрана хотя бы одна модель от Crazyrouter
- [ ] Первый запрос в чат-панели получен успешно
- [ ] В логах Crazyrouter видны соответствующие запросы
- [ ] Квота токена и белый список моделей соответствуют ожиданиям
- [ ] Вы знаете, что Tab Completion и другие специализированные функции могут не работать через Crazyrouter

## Частые ошибки и решения

| Симптом | Причина | Способ исправления |
|------|----------|----------|
| `Verify` не удаётся | Неверный API Key или базовый URL | Проверьте `sk-...` и `https://api.crazyrouter.com/v1` |
| 401 unauthorized | Токен недействителен, истёк или скопирован с лишним пробелом | Сгенерируйте новый токен и вставьте чистое значение |
| 403 / model not allowed | Модель не включена в белый список токена | Разрешите нужную модель в настройках Crazyrouter токена |
| 404 | Base URL введён как корневой домен или специфический путь | Используйте `https://api.crazyrouter.com/v1` |
| Некорректный список моделей или отсутствие моделей | BYOK Cursor не обновился или несовместима версия | Перезапустите Cursor, повторите Verify, при необходимости обновите до последней версии |
| Чат работает, Tab Completion не через Crazyrouter | Ограничение Cursor: специализированные функции используют встроенные модели | Это ожидаемое поведение, не ошибка Crazyrouter |
| Не удаётся использовать пользовательские модели | Нестабильная поддержка пользовательских endpoint'ов совместимых с OpenAI в Cursor | Сначала проверьте работу с `gpt-5.5`, затем переходите к другим моделям |
| Неожиданно высокие расходы | Множество функций используют один токен или слишком широкий белый список | Ограничьте набор моделей, установите отдельный лимит для Cursor |

## Советы по производительности и стоимости

- На первом этапе включите только `gpt-5.5`
- Для объяснения сложного кода, суммирования и рефакторинга используйте `gpt-5.5`
- Для мультивендорной проверки добавьте `claude-opus-4-8` и `gemini-3.1-pro`
- Если одновременно используете Claude Code / Codex, обязательно разделяйте токены для учёта расходов
- При подозрениях на высокое потребление, проверьте логи Crazyrouter — возможно причиной является многотуровый контекст Cursor

## FAQ

### Какой Base URL нужно указывать в Cursor?

Укажите: `https://api.crazyrouter.com/v1`

### Почему после ввода Key некоторые функции всё равно не работают через Crazyrouter?

Потому что по официальной информации Cursor, пользовательский API key покрывает только стандартные чат-модели. Например, Tab Completion и специализированные функции используют внутренние модели Cursor.

### С какой моделью лучше начать?

Используйте `gpt-5.5` — это самая актуальная проверенная база совместимости с OpenAI.

### Можно ли напрямую пользоваться Claude или другими моделями?

Можно попробовать, но желательно сначала пройти базовую проверку совместимости OpenAI. Возможность использовать некоторые пользовательские модели зависит от реализации Cursor.

### Чат работает нормально, а выбор моделей сбивается — что делать?

Перезапустите Cursor, повторите Verify. Если сохранится проблема — приоритетно откатитесь к `gpt-5.5` как к проверенной базовой модели.

<Note>
Если ваша основная задача — стабильная интеграция Crazyrouter в рабочий процесс программирования, то Claude Code, Codex, Cline зачастую более контролируемы чем пользовательские endpoint'ы Cursor. Cursor лучше всего подходит для чата и обычной вспомогательной редакторской работы.
</Note>
