## Обзор

Gemini CLI — это AI помощник от Google, работающий в командной строке. Настроив нативный вход Gemini от Crazyrouter, вы сможете использовать модели Gemini, которые были проверены реальными запросами в производственной среде нашего сайта, прямо из командной строки.

## Способы настройки

### Переменные окружения

В текущей версии Gemini CLI, для режима API Key, необходимо явно задать `GEMINI_API_KEY`. Если вы хотите подключить нативный вход Gemini от Crazyrouter, рекомендуется одновременно задать эти 3 переменные окружения:

```bash
export GEMINI_API_KEY=sk-xxx
export GEMINI_MODEL=gemini-3.1-pro
export GOOGLE_GEMINI_BASE_URL=https://api.crazyrouter.com
```

Windows PowerShell:

```powershell
$env:GEMINI_API_KEY="sk-xxx"
$env:GEMINI_MODEL="gemini-3.1-pro"
$env:GOOGLE_GEMINI_BASE_URL="https://api.crazyrouter.com"
```

Чтобы настройки автоматически применялись при каждом открытии терминала, можно добавить их в `~/.gemini/.env` или профиль PowerShell.

### Файл конфигурации

Отредактируйте `~/.gemini/settings.json`:

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  },
  "apiKey": "sk-xxx",
  "baseUrl": "https://api.crazyrouter.com",
  "model": {
    "name": "gemini-3.1-pro"
  }
}
```

Внимание:

- Не оставляйте способ аутентификации как `oauth-personal`, иначе CLI будет выполнять вход через Google.
- Не записывайте `model` как строку, в текущей версии следует использовать `model.name`.
- В некоторых случаях только `settings.json` недостаточно — в режиме командной строки может потребоваться переменная окружения `GEMINI_API_KEY`.

### Пример `.gemini/.env`

Вы также можете добавить непосредственно в `~/.gemini/.env`:

```bash
GEMINI_API_KEY=sk-xxx
GEMINI_MODEL=gemini-3.1-pro
GOOGLE_GEMINI_BASE_URL=https://api.crazyrouter.com
```

### Запуск

```bash
gemini
```
