Immersive Translate — это очень удобное расширение для браузера для повседневного перевода веб-страниц, двуязычного чтения, перевода выделенного текста и документов. Для интеграции с Crazyrouter наиболее надёжный способ — использовать официально поддерживаемую `OpenAI`-конфигурацию сервиса и вписать свой кастомный API-адрес в `Больше настроек`.

## Обзор

Через настройку OpenAI-сервиса Immersive Translate вы можете отправлять запросы на Crazyrouter:

- Рекомендованный протокол: `OpenAI-compatible API`
- Тип сервиса: `OpenAI`
- API Key: ваш `sk-...`
- Кастомный API-адрес: `https://api.crazyrouter.com/v1/chat/completions`
- Рекомендуемая первая модель для проверки: `gpt-5.5`

<Tip>
Главное отличие Immersive Translate от ChatBox: здесь обычно нужно указывать полный путь к API, а не просто корневой домен.
</Tip>

## Почему нужен полный путь

Согласно официальной документации OpenAI-сервисов Immersive Translate, в `Больше настроек` можно задать свой OpenAI API-адрес. Поэтому в Crazyrouter обычно безопаснее указывать полный адрес:

```text
https://api.crazyrouter.com/v1/chat/completions
```

<Warning>
Не указывайте здесь только корневой домен `https://api.crazyrouter.com` и не пишите только до `/v1`. Для Immersive Translate при первой проверке предпочтительнее полный путь `/v1/chat/completions`.
</Warning>

## Установка и путь настройки

### Вариант для Chrome / Edge

1. Установите Immersive Translate из магазина расширений
2. Откройте настройки расширения
3. Зайдите в `Служба перевода`
4. Выберите `OpenAI`
5. Откройте `Больше настроек`
6. Введите ключ Crazyrouter и полный кастомный адрес

### Вариант для Firefox

1. Установите Immersive Translate из каталога дополнений Firefox
2. Откройте страницу настроек
3. Зайдите в `Служба перевода`
4. Выберите `OpenAI`
5. Перейдите в `Больше настроек`
6. Заполните параметры Crazyrouter

## Полная настройка с нуля

<Steps>
  <Step title="Шаг 1: Установите расширение">
    Установите официальный "Immersive Translate" из магазина расширений.
  </Step>

  <Step title="Шаг 2: Создайте специальный токен в Crazyrouter">
    При первой настройке рекомендуется разрешить:

    - `gpt-5.5`
    - `claude-opus-4-8`

    Не добавляйте сразу слишком много моделей в переводимые сценарии.
  </Step>

  <Step title="Шаг 3: Откройте конфигурацию сервиса OpenAI">
    После клика по иконке расширения перейдите:

    - `Настройки`
    - `Служба перевода`
    - Выберите `OpenAI`
  </Step>

  <Step title="Шаг 4: Заполните API Key и пользовательский адрес">
    Заполните:

    - `API Key`: ваш `sk-...`
    - `Пользовательский адрес API интерфейса`: `https://api.crazyrouter.com/v1/chat/completions`
    - `Модель`: сначала заполните `gpt-5.5`

    Если некоторые параметры по умолчанию свернуты, обязательно разверните `Больше настроек`, чтобы увидеть все поля.
  </Step>

  <Step title="Шаг 5: Сначала уменьшите частоту запросов">
    В официальной документации Immersive Translate по интеграции OpenAI отдельно отмечен вопрос лимитов по частоте запросов. При первом подключении Crazyrouter советуем снизить частоту — особенно для длинных текстов или электронных книг.

    Первая проба — осторожные параметры, например:

    - Не ставьте большие значения запросов в секунду
    - Проверьте сначала на маленькой странице или по выделенному тексту
    - После успешной настройки постепенно увеличивайте лимиты
  </Step>

  <Step title="Шаг 6: Завершите первую минимальную проверку">
    Рекомендуемый порядок:

    1. Сначала переведите небольшой выделенный фрагмент
    2. Затем попробуйте короткую веб-страницу
    3. После этого протестируйте перевод целой страницы или более длинных документов

    Так будет проще всего определить: ошибка в настройках API или просто слишком большая нагрузка.
  </Step>
</Steps>

| Параметр | Рекомендация | Описание |

| Утечка | Сразу менять | После утечки на видео, скрине или через браузерную синхронизацию немедленно заменяйте ключ |

## Типичные ошибки и их решение

| Симптом | Распространённая причина | Как исправить |
|----------|-----------------------|--------------|
| 404 | В API-адресе не хватает `/chat/completions` или адрес — только домен | Исправьте на полный адрес `https://api.crazyrouter.com/v1/chat/completions` |
| 401 unauthorized | Неправильный, устаревший или не полностью скопированный API Key | Пересоздайте токен и введите заново |
| 403 / model not allowed | Модель не добавлена к токену | В настройках токена Crazyrouter разрешите данную модель |
| 429 / нестабильно | Слишком высокая частота запросов | Уменьшите лимиты, сначала тестируйте на малых текстах |
| Сбои при переводе длинных текстов | Слишком высокая частота или параллелизм | Сначала уменьшите объём перевода, потом повышайте |
| Растёт стоимость | Сразу переводят полные страницы/сайты/книги | Сначала проверьте частичным переводом `gpt-5.5` и ограничьте масштабы |

## Советы по экономии

- По умолчанию используйте `gpt-5.5`
- В первую очередь переводите выделенную область, а не сразу всю страницу
- Для длинных текстов сперва проверьте качество выборочно, потом полностью
- Если расширение стоит в нескольких браузерах — заводите отдельные токены для учёта стоимости

## FAQ

### Какой API-адрес нужно указывать в Immersive Translate?

Указывайте полный путь: `https://api.crazyrouter.com/v1/chat/completions`.

### Почему здесь, в отличие от ChatBox, не рекомендуют только домен?

Потому что в Immersive Translate для OpenAI кастомный адрес предпочтительнее вписывать целиком — так первая проверка получится стабильнее.

### Какая первая рекомендуемая модель?

Сначала используйте `gpt-5.5`.

### Почему не стоит сразу переводить целую страницу или книжку?

Потому что это одновременно усилит проблемы с конфигурацией, лимиты по частоте и вопрос стоимости. Проще начать с маленького фрагмента — проще отлавливать неполадки.

<Note>
Если цель — "управлять затратами на AI-перевод страниц через Crazyrouter", Immersive Translate — отличный пример расширения, для которого важно оформить подробную инструкцию.
</Note>
