> Обновление содержания: 2026-06-09

Aider — очень удобный терминальный инструмент для парного программирования, идеально подходит для быстрого внесения изменений в код внутри Git-репозитория: чтение кода, изменение нескольких мест, просмотр diff, добавление файлов контекста и поэтапное исправление. При интеграции с Crazyrouter самый надежный способ — использовать официально поддержанную OpenAI-совместимую конфигурацию Aider.

## Обзор

Через переменные среды или `~/.aider.conf.yml`, Aider может отправлять запросы на Crazyrouter:

- Рекомендуемый протокол: `OpenAI-compatible API`
- Base URL: `https://api.crazyrouter.com/v1`
- Переменная для аутентификации: `OPENAI_API_KEY`
- Рекомендуемое выражение для модели по умолчанию: `gpt-5.5`

<Tip>
Если ваш стиль работы — «читать код -> изменить несколько мест -> посмотреть diff -> снова исправить», Aider часто является самым легким и стабильно работающим инструментом для программирования в терминале.
</Tip>

## Для кого подходит

- Для тех, кто хочет в терминале делать покоммитные изменения кода
- Для тех, кто хочет точно контролировать файлы контекста, diff и ритм коммитов
- Для тех, кто хочет разделить оплату между Aider, Codex и Claude Code
- Для тех, кто хочет интегрировать Crazyrouter самым прямым — OpenAI-совместимым способом

## Используемый протокол

Рекомендуемый протокол: `OpenAI-compatible API`

Aider официально поддерживает следующие параметры:

- `OPENAI_API_KEY`
- `OPENAI_API_BASE`
- `openai-api-key`
- `openai-api-base`

Соответствующая запись для Crazyrouter:

```text
OPENAI_API_BASE=https://api.crazyrouter.com/v1
```

Обратите внимание: имя модели Crazyrouter — это оригинальный ID, который показан в списке моделей и на странице pricing, например `gpt-5.5`, `claude-opus-4-8`. В Aider также следует указывать этот ID модели напрямую:

```text
gpt-5.5
```

<Warning>
Не добавляйте к имени модели Crazyrouter дополнительный префикс `openai/`. `openai/gpt-5.5` не является именем модели на этом сайте и приведет к ошибке `model not found` или к отсутствию доступных каналов.
</Warning>

| Доступные модели       | Нужно разрешить хотя бы одну используемую кодовую модель |

Рекомендуемый стартовый whitelist:

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

## Полный путь установки для разных ОС

### Рекомендуемый путь для Windows

На Windows самый надежный путь для Aider: `Git` + `Python` + `PowerShell установка Aider` + `PowerShell настройка переменных среды`.

Рекомендуемая последовательность:

1. Установить Git
2. Установить Python
3. Запустить официальный скрипт установки Aider через PowerShell или сначала установить `aider-install`
4. Записать временные переменные через PowerShell
5. Создать постоянные переменные пользователя через PowerShell
6. Открыть новый терминал и убедиться, что команда `aider` и переменные работают

Рекомендуемая команда для проверки:

```powershell
git --version
python --version
pip --version
aider --version
where.exe git
where.exe python
where.exe aider
```

Если `aider --version` не находит команду, закройте и вновь откройте PowerShell, затем повторите попытку.

### Рекомендуемый путь для macOS

На macOS наиболее удобно: `Xcode Command Line Tools` + `Homebrew` + `Git` + `Python` + `Официальный скрипт установки Aider` + `~/.zshrc` для постоянных переменных среды.

Рекомендуемая последовательность:

1. Установить Xcode Command Line Tools
2. Установить Homebrew (если еще не установлен)
3. Установить Git и Python
4. Запустить официальный скрипт установки Aider или установить через `aider-install` / `uv`
5. Записать `~/.zshrc`
6. Открыть новый терминал и убедиться в корректности команд и путей `aider`

Рекомендуемая команда для проверки:

```bash
git --version
python3 --version
pip3 --version
aider --version
which git
which python3
which aider
```

### Примечания для Linux

В Linux можно ориентироваться на macOS-путь работы в терминале, только постоянные переменные среды обычно пишутся в `~/.bashrc`. Если это первая интеграция на локальной машине или облачном сервере, сначала протестируйте временные переменные в текущем shell, а затем решайте, писать ли их в постоянные.

## Полная установка с нуля

<Steps>
  <Step title="Шаг 1: Установите Git">
    Если на вашем компьютере ещё не установлен Git, установите его.

    <Tabs>
      <Tab title="Windows PowerShell">
        ```powershell
        winget install --id Git.Git -e --source winget
        git --version
        where.exe git
        ```
      </Tab>
      <Tab title="macOS">
        ```bash
        xcode-select --install
        git --version
        ```
        Или:
        ```bash
        brew install git
        git --version
        which git
        ```
      </Tab>
      <Tab title="Ubuntu / Debian">
        ```bash
        sudo apt update
        sudo apt install -y git
        git --version
        which git
        ```
      </Tab>
    </Tabs>

    Рекомендуется дополнить:

    ```bash
    git config --global user.name "Your Name"
    git config --global user.email "you@example.com"
    git config --global init.defaultBranch main
    ```
  </Step>

  <Step title="Шаг 2: Установите Python и pip">
    Официальный инсталлятор Aider использует Python или автоматически создает своё окружение с Python. Для удобства диагностики рекомендуется предварительно убедиться, что Python установлен на машине.

    <Tabs>
      <Tab title="Windows PowerShell">
        ```powershell
        winget install Python.Python.3.12
        python --version
        pip --version
        where.exe python
        ```
      </Tab>
      <Tab title="macOS">
        ```bash
        brew install python
        python3 --version
        pip3 --version
        which python3
        ```
      </Tab>
      <Tab title="Ubuntu / Debian">
        ```bash
        sudo apt update
        sudo apt install -y python3 python3-pip python3-venv
        python3 --version
        pip3 --version
        which python3
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Шаг 3: Установите Aider">
    На данный момент Aider рекомендует следующий однокнопочный скрипт установки.

    <Tabs>
      <Tab title="Windows PowerShell">
        ```powershell
        powershell -ExecutionPolicy ByPass -c "irm https://aider.chat/install.ps1 | iex"
        aider --version
        where.exe aider
        ```
      </Tab>
      <Tab title="macOS / Linux">
        ```bash
        curl -LsSf https://aider.chat/install.sh | sh
        aider --version
        which aider
        ```
      </Tab>
    </Tabs>

    Если вы хотите просматривать весь процесс установки, можно воспользоваться официальным маршрутом `aider-install`:

    <Tabs>
      <Tab title="Windows PowerShell">
        ```powershell
        python -m pip install aider-install
        aider-install
        aider --version
        ```
      </Tab>
      <Tab title="macOS / Linux">
        ```bash
        python3 -m pip install aider-install
        aider-install
        aider --version
        ```
      </Tab>
    </Tabs>

    Если ваша команда уже использует `uv`, следуйте официальной документации:

    ```bash
    python -m pip install uv
    uv tool install --force --python python3.12 --with pip aider-chat@latest
    aider --version
    ```

    <Warning>
    На первом этапе не рекомендуется сразу вручную добавлять `pip install aider-chat` в системные переменные. Официальный скрипт, `aider-install` или `uv` обеспечивают лучший изоляционный режим зависимостей.
    </Warning>
  </Step>

  <Step title="Шаг 4: Создайте специальный токен Aider в Crazyrouter">
    В Crazyrouter создайте token с именем `aider` и сначала разрешите:

    - `gpt-5.5`
    - `claude-opus-4-8`
    - `gemini-3.1-pro`

    <Note>
    В whitelist вписываются оригинальные имена моделей Crazyrouter, без префикса `openai/`.
    </Note>
  </Step>

  <Step title="Шаг 5: Сначала установите временные переменные среды в текущем терминале">
    Сначала настройте временную конфигурацию, после успеха запишите в постоянную.

    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        export OPENAI_API_KEY=sk-xxx
        export OPENAI_API_BASE=https://api.crazyrouter.com/v1
        echo $OPENAI_API_KEY
        echo $OPENAI_API_BASE
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        $env:OPENAI_API_KEY = "sk-xxx"
        $env:OPENAI_API_BASE = "https://api.crazyrouter.com/v1"
        echo $env:OPENAI_API_KEY
        echo $env:OPENAI_API_BASE
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Шаг 6: Запишите переменные среды в постоянную конфигурацию">
    <Tabs>
      <Tab title="Linux Bash">
        ```bash
        echo 'export OPENAI_API_KEY=sk-xxx' >> ~/.bashrc
        echo 'export OPENAI_API_BASE=https://api.crazyrouter.com/v1' >> ~/.bashrc
        source ~/.bashrc
        echo $OPENAI_API_BASE
        ```
      </Tab>
      <Tab title="macOS / Zsh">
        ```bash
        echo 'export OPENAI_API_KEY=sk-xxx' >> ~/.zshrc
        echo 'export OPENAI_API_BASE=https://api.crazyrouter.com/v1' >> ~/.zshrc
        source ~/.zshrc
        echo $OPENAI_API_BASE
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        [System.Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-xxx", "User")
        [System.Environment]::SetEnvironmentVariable("OPENAI_API_BASE", "https://api.crazyrouter.com/v1", "User")

        $env:OPENAI_API_KEY = "sk-xxx"
        $env:OPENAI_API_BASE = "https://api.crazyrouter.com/v1"

        echo $env:OPENAI_API_BASE
        ```
      </Tab>
    </Tabs>

    После сохранения постоянной конфигурации откройте новый терминал и выполните:

    <Tabs>
      <Tab title="Windows PowerShell">
        ```powershell
        aider --version
        echo $env:OPENAI_API_BASE
        ```
      </Tab>
      <Tab title="macOS / Linux">
        ```bash
        aider --version
        echo $OPENAI_API_BASE
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Шаг 7: Необязательно записать конфигурацию в ~/.aider.conf.yml">
    Если не хотите каждый раз вводить параметры вручную, создайте конфигурационный файл.

    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        cat > ~/.aider.conf.yml <<'EOF'
        model: gpt-5.5
        openai-api-base: https://api.crazyrouter.com/v1
        EOF
        cat ~/.aider.conf.yml
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        @'
        model: gpt-5.5
        openai-api-base: https://api.crazyrouter.com/v1
        '@ | Set-Content -Path "$HOME/.aider.conf.yml"

        Get-Content $HOME/.aider.conf.yml
        ```
      </Tab>
    </Tabs>

    Для большей безопасности можно хранить ключ только в переменных среды, а в конфиге оставить только `model` и `openai-api-base`.
  </Step>

  <Step title="Шаг 8: Подготовьте Git репозиторий и сделайте первый снимок">
    Aider работает лучше всего внутри Git-репозитория. Если текущий каталог ещё не репозиторий:

    ```bash
    git init
    git add .
    git commit -m "chore: initial snapshot before Aider"
    ```

    Если это уже существующий репозиторий, проверьте его:

    ```bash
    git status
    ```
  </Step>

  <Step title="Шаг 9: Запустите Aider и завершите первую проверку">
    Перейдите в директорию проекта и выполните:

    ```bash
    cd /path/to/your/project
    aider --model gpt-5.5
    ```

    Для первой проверки придерживайтесь такого порядка:

    1. `Пожалуйста, только суммируйте текущую структуру репозитория, не изменяйте файлы`
    2. `Пожалуйста, прочитайте README и предложите минимальные изменения, сначала не изменяйте напрямую`
    3. После успешного отображения diff — сделайте небольшое изменение

    <Tip>
    Если хотите проверить другую модель, используйте похожую запись, например `aider --model claude-opus-4-8`.
    </Tip>
  </Step>
</Steps>

## Рекомендованные настройки модели

| Сценарий использования  | Рекомендуемая запись в Aider  | Причина                                  |
|------------------------|-------------------------------|------------------------------------------|
| Основное кодирование   | `gpt-5.5`              | Используйте оригинальный ID модели Crazyrouter, базовое OpenAI-совместимое решение для Aider |
| Альтернатива Claude    | `claude-opus-4-8`              | Хорошо подходит для длинного контекста и стабильных многократных итераций |
| Вариант Gemini         | `gemini-3.1-pro`              | Лучший второй путь проверки совместимости |

Сначала используйте `gpt-5.5`, после успешной интеграции можно добавить `claude-opus-4-8` или `gemini-3.1-pro` в зависимости от ситуации.

## Лучшие практики настройки Token

| Настройка          | Рекомендация   | Описание                                               |
|--------------------|----------------|--------------------------------------------------------|
| Специализированный token   | Обязательно      | Не используйте один token для Aider и других IDE/CLI   |
| Whitelist моделей  | Очень рекомендуется | Держите минимальный набор моделей, исключайте дорогие случайные |
| Ограничение IP     | По необходимости  | В серверной среде — да, на мобильном — с осторожностью |
| Лимит по квоте     | Очень рекомендуется | Длинные сессии и много этапов могут расходовать быстро |
| Изоляция среды     | Рекомендуется    | Создайте отдельные token для локальной, удалённой и CI  |
| Обработка утечек   | Менять немедленно | После утечки `.aider.conf.yml`, истории shell или экрана — срочно смените ключ |

## Частые ошибки и способы их устранения

| Проявление | Частая причина | Способ устранения |
|------|----------|----------|
| `aider: command not found` | Aider не был установлен, или установщик не добавил исполняемый файл в PATH | Запустите официальный установщик заново и попробуйте в новом терминале |
| Путаница версий Python | Системный Python конфликтует со средой Aider | Предпочитайте скрипт установки, `aider-install` или `uv`, не устанавливайте зависимости вручную |
| 401 unauthorized | Неправильный, просроченный или неполный API Key | Сгенерируйте токен заново и выставьте его повторно |
| 403 / model not allowed | Токен не разрешён для данной модели | В настройках токена Crazyrouter разрешите модель |
| 404 | Неправильный Base URL или пропущен `/v1` | Измените на `https://api.crazyrouter.com/v1` |
| `model not found` | Неправильно указано имя модели, использован несуществующий префикс `openai/` или данная модель временно недоступна на сайте | Верните оригинальный ID модели, указанный на странице pricing или в списке моделей, напр. `gpt-5.5`, `claude-opus-4-8` |
| Различие между файлами конфигурации и переменными среды | Конфликт настроек | Оставьте только один основной источник конфигурации, перезапустите Aider |
| Слишком быстро растёт стоимость | Длинные сессии, слишком много контекстных файлов | Своевременно очищайте контекст и ограничивайте квоту токенов |

## Рекомендации по производительности и стоимости

- При первой интеграции тестируйте на небольшом репозитории
- По умолчанию используйте `gpt-5.5`, для перекрёстной проверки добавьте `claude-opus-4-8`
- Для разных типов проектов используйте разные токены для удобства подсчёта стоимости
- При слишком длинных сессиях своевременно очищайте контекст, чтобы не пересылать ненужные файлы
- После крупных изменений просматривайте diff, сгенерированный Aider, и логи Crazyrouter

## FAQ

### Какой Base URL указывать в Aider?

Укажите `https://api.crazyrouter.com/v1`.

### Почему не стоит указывать имя модели как `openai/gpt-5.5`?

Потому что в Crazyrouter имена моделей не содержат префикс поставщика, а реально используется оригинальный ID модели типа `gpt-5.5`. `openai/gpt-5.5` будет трактоваться как отдельная модель, которой нет на сайте.

### Что лучше — переменные окружения или файл конфигурации?

Возможны оба варианта. Для быстроты сначала используйте переменные окружения; для долговременного применения стоит дополнить `~/.aider.conf.yml`.

### Почему при первом запуске советуют сделать снимок Git?

Потому что Aider изменяет файлы, создаёт diff, автоматически коммитит или предлагает коммитить. Предварительный снимок упростит диагностику и откат.

### Какая модель рекомендуется первой?

Используйте сначала `gpt-5.5`.

### Обязателен ли запуск Aider в Git-репозитории?

Не абсолютно обязательно, но так работать и контролировать изменения удобнее всего.

<Note>
Если вы ищете очень лёгкий, подходящий для повседневных мелких изменений кода терминальный инструмент, Aider по-прежнему стоит ставить в приоритет в гайде по Crazyrouter.
</Note>
