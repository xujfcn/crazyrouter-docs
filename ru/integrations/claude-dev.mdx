## Обзор

Claude Dev — это расширение для ИИ-кодинга в VS Code, предназначенное для объяснения кода в стиле Claude, предложений по рефакторингу и многоходового сотрудничества через Crazyrouter. Для публичной документации рекомендуется сначала использовать совместимый с OpenAI маршрут, потому что он более согласован с остальной частью интеграционного стека Crazyrouter и проще для устранения неполадок.

<Warning>
URL `https://api.crazyrouter.com/v1` на этой странице применим только к провайдеру `OpenAI Compatible` Claude Dev. Не копируйте его в `ANTHROPIC_BASE_URL` Claude Code; Claude Code должен использовать корневой домен `https://api.crazyrouter.com`.
</Warning>

## Рекомендуемая конфигурация

<Steps>
  <Step title="Установить расширение">
    Найдите `Claude Dev` в маркетплейсе расширений VS Code и установите его.
  </Step>
  <Step title="Открыть настройки">
    Нажмите на иконку Claude Dev на боковой панели, чтобы перейти к настройкам.
  </Step>
  <Step title="Выберите поставщика">
    Отдавайте предпочтение `OpenAI Compatible` как поставщику API.
  </Step>
  <Step title="Введите конфигурацию">
    - **Базовый URL**: `https://api.crazyrouter.com/v1`
    - **Ключ API**: `sk-xxx`
    - **Модель**: `claude-opus-4-8`
  </Step>
</Steps>

Для основной международной точки доступа API установите Base URL `OpenAI Compatible` в Claude Dev на `https://api.crazyrouter.com/v1`.

## Рекомендуемые модели

| Сценарий | Модель |
|----------|-------|
| Ежедневное программирование | `claude-opus-4-8` |
| Более сложные рассуждения и планирование | `claude-opus-4-8` |

<Note>
  `claude-opus-4-8` и `claude-opus-4-8` соответствуют последним проверенным рекомендациям по моделям Claude в этом наборе документации. Для самого простого первого этапа проверки в VS Code начните с `claude-opus-4-8`.
</Note>
