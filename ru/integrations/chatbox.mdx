ChatBox — это распространённый кроссплатформенный AI-клиент, поддерживающий Windows, macOS, Linux и веб-версию. Для интеграции с Crazyrouter рекомендуется в первую очередь настроить ChatBox способом `OpenAI API Compatible` или `OpenAI API`, а не искать предустановки от конкретного производителя.

Преимущества такого подхода:

- Простая настройка, подходит обычным пользователям для быстрой интеграции
- Можно напрямую переключать модели, разрешённые в Crazyrouter
- Подходит для настольных диалогов, ответов на вопросы из базы знаний, помощи в чтении файлов и других сценариев

## Сразу к выводам

Рекомендуется использовать следующий набор настроек:

- Provider / API Mode: `OpenAI API Compatible` или `OpenAI API`
- API Host: `https://api.crazyrouter.com`
- API Path: оставить по умолчанию или пустым
- API Key: `sk-xxx`
- Первая проверяемая модель: `gpt-5.5`

<Note>
Согласно официальной документации ChatBox, обычно нет необходимости вручную вводить `API Path`; по умолчанию используется совместимый с OpenAI путь для чата. Поэтому в документации Crazyrouter советуется прописывать `API Host` как корневой домен `https://api.crazyrouter.com`, не вводить заранее `/v1/chat/completions`.
</Note>

## Для кого предназначено

- Для пользователей, которые хотят быстро использовать Crazyrouter на десктопе
- Для тех, кто хочет вести повседневные диалоги, переводить, суммировать, получать помощь в письме с несколькими моделями
- Для желающих объединить локальную базу знаний или ответы на вопросы по файлам с Crazyrouter
- Для тех, кто не хочет писать код и предпочитает сделать всё в GUI

## Установка ChatBox

### Windows

1. Откройте [официальный сайт ChatBox](https://chatboxai.app/)
2. Скачайте установочный пакет для Windows
3. Дважды нажмите для установки
4. После установки запустите ChatBox

### macOS

1. Откройте [официальный сайт ChatBox](https://chatboxai.app/)
2. Скачайте установочный пакет для macOS
3. Перетащите в `Applications`
4. При первом запуске, если появится система безопасности, следуйте инструкциям для разрешения запуска

### Linux

1. Откройте [официальный сайт ChatBox](https://chatboxai.app/)
2. Скачайте установочный файл или десктопную версию для вашей дистрибуции
3. После установки запустите ChatBox

<Tip>
Если вы просто хотите проверить, работает ли Crazyrouter в ChatBox, сначала используйте десктопный клиент. Не стоит сразу пытаться синхронизировать несколько платформ, базу знаний и сложный список моделей одновременно.
</Tip>

## Рекомендуемый способ настройки

Названия элементов интерфейса ChatBox могут немного отличаться в разных версиях. Обычно вход через:

- `Settings`
- `Model Provider`
- `AI Provider`
- `Add`

Если поставщик `OpenAI API` уже встроен в вашей версии, просто выберите его; если нет, добавьте нового поставщика `OpenAI API Compatible`.

## Шаги настройки

<Steps>
  <Step title="Шаг 1: Создайте специальный токен для ChatBox в Crazyrouter">
    Первое тестирование рекомендуется разрешить только 1-2 модели, например:

    - `gpt-5.5`
    - `claude-opus-4-8`

    Так проще найти проблему и избежать расширения области устранения неисправностей из-за большого количества моделей.
  </Step>

  <Step title="Шаг 2: Откройте настройки ChatBox">
    Запустите ChatBox и нажмите на иконку настроек в левом нижнем углу, затем перейдите:

    - `Model Provider`
    - или `AI Provider`
  </Step>

  <Step title="Шаг 3: Выберите или добавьте совместимого поставщика OpenAI">
    Рекомендуется два варианта:

    - Если уже есть `OpenAI API`, просто выберите
    - Если нет, нажмите `Add`, чтобы добавить нового поставщика `OpenAI API Compatible`
  </Step>

  <Step title="Шаг 4: Введите информацию для подключения к Crazyrouter">
    Рекомендуется заполнить:

    - `API Host`: `https://api.crazyrouter.com`
    - `API Path`: оставить по умолчанию или пустым
    - `API Key`: `sk-xxx`

    Если требуется указать имя поставщика, можете написать `Crazyrouter`.
  </Step>

  <Step title="Шаг 5: Добавьте первую модель">
    В первый раз лучше добавить только одну модель:

    - `gpt-5.5`

    После подтверждения минимальной цепочки постепенно добавьте:

    - `claude-opus-4-8`
    - `gemini-3.1-pro`
  </Step>

  <Step title="Шаг 6: Используйте Check или Save для предварительного тестирования соединения">
    Если в вашей версии ChatBox есть кнопка `Check`, нажмите сначала `Check`.

    Если есть только `Save`, сохраните, затем вернитесь на главный экран и создайте новый диалог для тестирования.
  </Step>

  <Step title="Шаг 7: Проведите минимальную верификацию на главном экране">
    Создайте новый чат и убедитесь, что текущее модель — `gpt-5.5`, введите:

    ```text
    Reply only OK
    ```

    Если вы стабильно получаете `OK` или близкий результат, значит основной канал ChatBox к Crazyrouter работает.
  </Step>
</Steps>

## Рекомендуемый порядок проверки

Рекомендуем следовать по такому порядку и не включать сразу много моделей и функций:

1. Сначала добавьте только 1 токен
2. Сначала добавьте только одну модель `gpt-5.5`
3. Сначала проверьте чистый текстовый чат
4. Затем добавьте вторую модель
5. Затем включайте базу знаний, ответы по файлам или сложные параметры диалога

## Рекомендуемые модели

| Сценарий | Рекомендуемая модель | Причина |
|----------|----------------------|---------|
| Первая проверка соединения | `gpt-5.5` | В этот день успешно протестировано, подходит для проверки OpenAI-совместимости |
| Высококачественные тексты и объяснения | `claude-opus-4-8` | Лучше подходит для сложных пояснений, редактирования, суммирования |
| Gemini альтернативный вариант | `gemini-3.1-pro` | Удобно добавить для перекрёстной проверки не-OpenAI моделей |

## Как совмещать возможности ChatBox с Crazyrouter

### Обычный чат

Самый простой вариант, используется для проверки правильности настройки.

### База знаний / ответы на вопросы по файлам

Рекомендуется включать после успешной проверки обычного чата. При первом тесте:

- Файл должен быть как можно меньше
- Содержимое максимально понятно
- Сначала проверьте ответы по одному файлу

Не используйте сложные тесты с большим количеством файлов, если не уверены в правильности API-настройки.

### Переключение между моделями

Используется для разделения задач внутри ChatBox, например:

- Основной чат по умолчанию: `gpt-5.5`
- Важное суммирование и написание: `claude-opus-4-8`
- Стандартная первая проверка: `gpt-5.5`

## Рекомендации по параметрам

Если ваша версия ChatBox поддерживает стандартные sampling-параметры, в первый раз лучше использовать осторожные значения:

| Параметр | Рекомендуемое значение | Описание |
|----------|-----------------------|----------|
| Temperature | `0.2` до `0.7` | В первой проверке не завышайте |
| Max Tokens | По умолчанию или умеренно | Не допускайте слишком длинного вывода для упрощения устранения неисправностей |
| Context Messages | По умолчанию | Сначала проверьте базовый чат |

## Частые ошибки и их исправление

| Симптом | Причина | Исправление |
|---------|---------|-------------|
| 401 unauthorized | Некорректный или устаревший токен / неполная копия | Сгенерируйте новый токен и вставьте заново|
| 404 | Неправильно указаны Host или Path | Host измените на `https://api.crazyrouter.com`, Path держите по умолчанию|
| 403 / model not allowed | Токен не разрешил текущую модель | Разрешите данную модель в настройках токена Crazyrouter|
| `model not found` | Ошибка в названии модели | Сначала верните название `gpt-5.5` и проверьте минимальное подключение |
| Успешное сохранение, но чат не работает | Неверно выбран provider или модель не добавлена | Перепроверьте тип provider и список моделей|
| Медленные или неудачные ответы на вопросы из базы знаний | Слишком большой файл или слишком сложная задача | Сначала попробуйте меньший файл и обычный текст|
| Не знаете, нужно ли вводить `/v1` | Обычно текущая версия не требует ручного указания полного пути | Используйте корневой Host, Path — пустой или по умолчанию |

## FAQ

### Какого поставщика выбрать в ChatBox?

Лучше всего `OpenAI API` или `OpenAI API Compatible`.

### Что вводить в API Host?

Вводите `https://api.crazyrouter.com`.

### Нужно ли вручную вводить `/v1/chat/completions`?

Обычно не нужно. По документации ChatBox, у `API Path` есть стандартное значение, сначала оставьте по умолчанию или пустым.

### Какую первую модель указать?

Сначала указывайте `gpt-5.5`.

### Когда добавить больше моделей и базу знаний?

Постепенно расширяйте после минимальной проверки чата.

<Note>
Если ваша задача — «сначала убедиться, что ChatBox работает», лучший подход — не подключать сразу много моделей и функций, а использовать `gpt-5.5` для минимальной проверки.
</Note>
