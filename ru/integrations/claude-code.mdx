Claude Code — один из самых приоритетных терминальных инструментов программирования для подключения к Crazyrouter. Он напрямую использует Anthropic Messages API, подходит для чтения кода, изменения, рефакторинга, выполнения команд, вызова инструментов и анализа больших репозиториев с длинным контекстом.

## Обзор

С помощью переменных окружения Claude Code может напрямую направлять запросы Anthropic в Crazyrouter:

- Рекомендуемый протокол: `Anthropic Messages API`
- Base URL: `https://api.crazyrouter.com`
- Основной международный API Base URL: `https://api.crazyrouter.com`
- Переменная аутентификации: `ANTHROPIC_API_KEY`
- Рекомендуемая модель по умолчанию: `claude-opus-4-8`

<Tip>
Claude Code самостоятельно добавляет полный путь для запросов Anthropic, поэтому Base URL должен быть только корневым доменом `https://api.crazyrouter.com` или `https://api.crazyrouter.com`, не указывайте вручную `/v1` или `/v1/messages`.
</Tip>

## Рекомендуемый протокол

Рекомендуемый протокол: `Anthropic Messages API`

Для интеграции Claude Code с Crazyrouter используйте:

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

Base URL для международного API также только корень адреса:

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

Не указывайте в таком виде:

- `https://api.crazyrouter.com/v1`
- `https://api.crazyrouter.com/v1/messages`
- `https://api.crazyrouter.com/v1/complete`
- `https://api.crazyrouter.com/v1`
- `https://api.crazyrouter.com/v1/messages`

## Полный порядок установки по ОС

### Рекомендуемый путь для Windows

Для Windows устойчивее всего выполнять: `Git` + `Node.js` + `Глобальная установка Claude Code через npm` + `PowerShell` — прописывать переменные окружения.

Рекомендованный порядок:

1. Установить Git
2. Установить Node.js LTS
3. Установить Claude Code через npm
4. Задать временные переменные через PowerShell
5. Записать постоянные переменные на уровень пользователя через PowerShell

Рекомендованная команда для проверки:

```powershell
git --version
node -v
npm -v
claude --version
where.exe git
where.exe node
where.exe claude
```

Если `claude --version` не видит команду, сначала закройте и заново откройте PowerShell, повторите попытку.

### Рекомендуемый путь для macOS

На macOS наиболее удобная последовательность: `Xcode Command Line Tools` + `Homebrew` + `Git` + `Node.js` + `Глобальная установка Claude Code через npm` + `~/.zshrc` — для постоянных переменных среды.

Рекомендованный порядок:

1. Установите Xcode Command Line Tools
2. Установите Homebrew (если ещё не установлен)
3. Установите Git и Node.js
4. Установите Claude Code через npm
5. Пропишите `~/.zshrc`
6. Проверьте команду в новом терминале

Рекомендованная команда для проверки:

```bash
git --version
node -v
npm -v
claude --version
which git
which node
which claude
```

### Почему не стоит вручную писать путь к API

Claude Code работает по нативному протоколу Anthropic. Нужно просто прописать корневой адрес сайта:

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

Base URL международного API также указывать только корнем:

```text
ANTHROPIC_BASE_URL=https://api.crazyrouter.com
```

Не добавляйте самодельно `/v1`, `/v1/messages` или конкретные пути к API, как для клиентов с совместимостью OpenAI.

Для автоустановки Claude Code со всеми переменными среды Crazyrouter можете использовать [crazyrouter-claude-code](https://github.com/xujfcn/crazyrouter-claude-code). В этом репозитории есть одношаговые скрипты для Windows, macOS и Linux; в этом документе также сохранён ручной порядок, чтобы вы могли перепроверить каждую настройку.

## Использование не-Claude моделей в Claude Code

Помимо моделей Claude, Crazyrouter также предоставляет встроенный доступ к ряду китайских моделей по протоколу Anthropic Messages. В следующем списке отражены только **модели, подтверждённые реальным клиентским тестом 2026-05-15**, без неактуальных версий.

### Список реально работающих моделей

| Модель ID | Провайдер | `Reply only OK` | Чтение `agent.md` | Текущее заключение | Примечание |
|-----------|----------|------------------|---------------------|---------------------|-----------|
| `deepseek-v4-pro` | DeepSeek | Пройдено | Пройдено | Claude Code P0 доступен | Подходит для общего кодирования; В настоящее время для Codex не рекомендуется использовать Responses |
| `MiniMax-M2.7` | MiniMax | Пройдено, но содержит `<think>` | Пройдено, но содержит `<think>` | Протокол доступен | Отрицательный опыт при строгих задачах вывода |
| `kimi-k2.5` | Moonshot Kimi | Пройдено | Пройдено | Claude Code P0 доступен | В данный момент один из самых стабильных отечественных моделей-кандидатов |
| `kimi-k2.6` | Moonshot Kimi | Пройдено | Пройдено | Claude Code P0 доступен | На одном уровне с `kimi-k2.5` |
| `glm-5.1` | GLM | Пройдено | Пройдено | Claude Code P0 доступен | Только для Claude Code; Родные Responses Codex в данный момент не проходят |

> Вышеуказанные тесты основаны на реальном клиенте Claude Code и подтверждены через цепочку нативного `POST /v1/messages` для домена верхнего уровня `https://api.crazyrouter.com`.

<Note>
В этой таблице отражены “модели, которые актуально повторно проверены и доступны”, а не “все теоретически совместимые с протоколом Anthropic сторонние модели”. Если какая-то модель здесь не указана — значит, в текущей русскоязычной документации она не включена в подтвержденные и рекомендуемые к использованию с Claude Code.

### Как переключать модель

В Claude Code можно выбрать модель через переменную окружения `ANTHROPIC_MODEL` или команду в сессии `/model`. Просто замените имя модели на любую из приведённых в таблице выше.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    export ANTHROPIC_BASE_URL=https://api.crazyrouter.com
    export ANTHROPIC_API_KEY=sk-xxx

    # 临时切到 Kimi K2.5
    export ANTHROPIC_MODEL=kimi-k2.5
    claude

    # 或临时切到 MiniMax
    ANTHROPIC_MODEL=MiniMax-M2.7 claude
    ```
  </Tab>
  <Tab title="Windows PowerShell">
    ```powershell
    $env:ANTHROPIC_BASE_URL = "https://api.crazyrouter.com"
    $env:ANTHROPIC_API_KEY  = "sk-xxx"

    $env:ANTHROPIC_MODEL = "kimi-k2.5"
    claude

    # 或临时切换
    $env:ANTHROPIC_MODEL = "MiniMax-M2.7"; claude
    ```
  </Tab>
</Tabs>

Также можно менять модель командой в сессии после запуска Claude Code:

```text
/model kimi-k2.5
/model MiniMax-M2.7
```

### Рекомендации по использованию и известные различия

- **Приоритет моделей**: Если хотите в Claude Code в первую очередь использовать отечественные модели — сейчас рекомендуется начинать с `kimi-k2.5` и `kimi-k2.6`, затем уже рассматривать `deepseek-v4-pro`. Для серии Qwen сперва проверьте доступный ID модели через `/v1/models`, затем проверьте отдельно.
- **Известные различия MiniMax**: `MiniMax-M2.7` хоть и поддерживает протокол, но выводит весь ход рассуждений как обычный текст, помечая его тегами `<think>...</think>` в начале и конце. Для задач, где требуется “вывести только одну фразу”, MiniMax не рекомендуется.
- **Границы применения DeepSeek/GLM**: То, что `deepseek-v4-pro` и `glm-5.1` работают в Claude Code — не означает, что их стоит сразу использовать для родных Responses Codex. Это разные цепочки протоколов, их совместимость не универсальна — не путайте.
- **Белый список токенов**: Если для токена Claude Code включён белый список моделей, нужно добавить туда и нужные отечественные модели, иначе будет возвращено `403 model not allowed`.
- **Рекомендуем сначала проверить в реальном клиенте**: Для приближённого к реальности теста — сначала запуск задачи на `Reply only OK`, затем — задание “прочитать файл и вернуть только заголовок”. Это даст более реалистичное представление сценария, чем голый API-запрос.

### Быстрая команда для проверки доступности модели

```bash
curl -sS https://api.crazyrouter.com/v1/messages \
  -H "Authorization: Bearer $ANTHROPIC_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k2.5",
    "max_tokens": 32,
    "messages": [{"role":"user","content":"reply OK"}]
  }'
```

Ответ 200 и непустой `content[].text` означают, что модель можно полноценно использовать через Claude Code.

## Лучшие практики настройки токена

| Настройка | Рекомендация | Пояснение |
|-----------|--------------|-----------|
| Персональный токен | Обязательно | Не используйте совместно с Cursor, Codex, OpenClaw |
| Белый список моделей | Настоятельно рекомендуется | Добавлять только реально используемые Claude или отечественные модели, чтобы упростить управление ограничениями и снижением расходов |
| Ограничения по IP | Рекомендуется для фиксированной среды | Если ноутбук часто меняет IP, настройте осторожно |
| Лимит квоты | Настоятельно рекомендуется | Длинные сессии и вызовы инструментов быстро расходуют бюджет |
| Разделять для разработки/команды | Рекомендуется | Для каждого разработчика и машины использовать отдельный токен |
| Ротация при утечке | Необходимо | Если токен попал в историю shell, запись экрана или в общий терминал — нужно немедленно заменить |

## Частые ошибки и их решения

| Проявление | Причина | Способ исправления |
|------------|---------|--------------------|
| `claude: command not found` | Claude Code не установлен, либо глобальный путь npm не прописан в PATH | Переустановить, убедиться, что каталог `npm bin -g` есть в PATH |
| Версия `node` слишком старая | Локальная версия Node устарела | Обновить до Node.js 18+ и переустановить Claude Code |
| 401 unauthorized | `ANTHROPIC_API_KEY` недействителен, протух или некорректно скопирован | Сгенерировать новый токен и заново прописать его в переменных окружения |
| 403 / model not allowed | В токене не разрешена используемая Claude-модель | В настройках токенов Crazyrouter добавить нужную модель |
| 404 | Base URL указан как `/v1`, `/v1/messages` или другой неверный путь | Вернуть на `https://api.crazyrouter.com` или `https://api.crazyrouter.com` |
| В логах встречается `/v1/v1/messages`, `/v1/v1/models` или `/v1/messages/v1/messages` | В Base URL для Claude Code по ошибке добавлен `/v1` либо полный endpoint, и клиент автоматически ещё раз дописывает путь | Заменить `ANTHROPIC_BASE_URL` на домен без дополнительного пути |
| Claude Code продолжает использовать старую конфигурацию после запуска | Новые переменные окружения не подхватились | Откройте новый терминал или заново выполните `source ~/.bashrc` / `source ~/.zshrc` |
| Слишком хаотичные изменения в Git | Не сделан снапшот репозитория перед применением AI для изменения кода | Сделайте коммит с исходным состоянием, а затем изменяйте постепенно |
| Превышены расходы | Длинный контекст + много инструментов в сессии + долгое время сессии | Сократить длину сессий, разбить задачи, для Claude Code установить отдельный бюджет |

## FAQ

### Какой Base URL указывать для Claude Code?

Указывается только домен: `https://api.crazyrouter.com`

Для интернационального API по умолчанию также пишется только домен: `https://api.crazyrouter.com`

### Почему здесь нельзя указывать `/v1`?

Потому что Claude Code сам добавит путь до Anthropic Messages API. Вы должны указать только адрес сайта, без путей.

### Как правильно запускать на Windows?

Если вы работаете в командной строке — используйте PowerShell или WSL2. В любом случае заранее убедитесь, что установлены Git, Node.js и сам Claude Code.

### PowerShell или Git Bash на Windows?

Первоначальную настройку удобнее проводить через PowerShell — проще прописывать переменные окружения, проверять `where.exe` и сохранять их на уровне пользователя.

### Зачем сначала делать коммит (снимок) в Git?

Claude Code может менять файлы и запускать команды. Сначала сохраните состояние, чтобы потом было проще откатываться и анализировать изменения.

### Какой первый рекомендованный модель?

Начинайте с `claude-opus-4-8` — она наиболее стабильна для базовых задач.
