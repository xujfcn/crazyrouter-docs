## Обзор

GPT Academic (Академическая версия GPT) предназначен для задач по доработке научных работ, переводу, объяснению кода и других подобных сценариев. При интеграции с Crazyrouter рекомендуется продолжить использовать его редирект URL OpenAI, однако модель по умолчанию следует переключить на актуальную, недавно прошедшую верификацию на продуктиве.

## Способ настройки

### Изменить файл конфигурации

Отредактируйте `config.py` или `config_private.py`:

```python
API_KEY = "sk-xxx"
API_URL_REDIRECT = {
    "https://api.openai.com/v1/chat/completions": "https://api.crazyrouter.com/v1/chat/completions"
}

# 或者直接设置
LLM_MODEL = "gpt-5.5"
AVAIL_LLM_MODELS = [
    "gpt-5.5",
    "claude-opus-4-8",
    "gemini-3.1-pro"
]
```

### Через переменные окружения

```bash
export API_KEY=sk-xxx
export API_URL_REDIRECT='{"https://api.openai.com/v1/chat/completions": "https://api.crazyrouter.com/v1/chat/completions"}'
export LLM_MODEL=gpt-5.5
```

### Docker-деплой

```yaml
services:
  gpt-academic:
    image: ghcr.io/binary-husky/gpt_academic
    ports:
      - "22303:22303"
    environment:
      - API_KEY=sk-xxx
      - LLM_MODEL=gpt-5.5
      - API_URL_REDIRECT={"https://api.openai.com/v1/chat/completions": "https://api.crazyrouter.com/v1/chat/completions"}
```

## Рекомендуемые модели

| Сценарий | Модель | Описание |
|------|------|------|
| Первая верификация академического ассистента | `gpt-5.5` | Проверена на практике в продуктивной среде 23 марта 2026 г., оптимальный baseline OpenAI-совместимости |
| Качественное саммари длинных текстов | `claude-opus-4-8` | Лучше подходит для сложных объяснений, переформулировки и резюмирования больших текстов |
| Gemini как резерв | `gemini-3.1-pro` | Для дополнительной проверки совместимости у другого провайдера |

<Note>
  Возможность URL-редиректа в GPT Academic позволяет перенаправлять запросы OpenAI напрямую на Crazyrouter. Рекомендуется сперва использовать только `gpt-5.5` для минимального диалога, а затем постепенно расширять список моделей и добавлять сложные плагины.
</Note>
