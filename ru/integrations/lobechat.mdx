LobeChat подходит в качестве точки входа для корпоративного чата, персональной мульти-модельной рабочей панели и фронта для AI-диалогов при самостоятельном размещении. Для интеграции с Crazyrouter наиболее надежным способом является использование пути LobeChat `OpenAI` и указание адреса прокси на базовый адрес OpenAI-совместимого интерфейса Crazyrouter.

## Обзор

В настройках OpenAI LobeChat вы можете направить запросы для диалога в Crazyrouter:

- Рекомендуемый протокол: `OpenAI-compatible API`
- Рекомендуемый способ подключения: поставщик LobeChat `OpenAI`
- Base URL: `https://api.crazyrouter.com/v1`
- Способ аутентификации: токен `sk-...`
- Рекомендуемая модель для первой проверки: `gpt-5.5`

Если вы самостоятельно размещаете LobeChat, можно через переменные среды заранее задать путь по умолчанию для OpenAI на Crazyrouter.

## Для кого подойдёт

- Тем, кто хочет развернуть стабильный чат-фронт
- Тем, кто хочет использовать Crazyrouter в персональной или командной чат-панели
- Тем, кто хочет централизованно управлять несколькими моделями и сохранять историю диалогов
- Тем, кто хочет выдавать фиксированную модель и настройки для внутренних пользователей

## Используемый протокол

Рекомендуемый протокол: `OpenAI-compatible API`

В LobeChat при подключении к Crazyrouter следует использовать OpenAI-совместимый базовый адрес:

```text
https://api.crazyrouter.com/v1
```

Не используйте:

- `https://api.crazyrouter.com`
- `https://api.crazyrouter.com/v1/chat/completions`

<Note>
Документация LobeChat описывает `OPENAI_PROXY_URL` как "адрес запроса к OpenAI API", а типичные значения по умолчанию и примеры имеют стиль `/v1`; кроме того, локальная `http://127.0.0.1:4000/api/status` приводит официальный пример ссылки, тоже в стиле `{address}/v1`. Поэтому при подключении к Crazyrouter приоритетно заполняйте как `https://api.crazyrouter.com/v1`. Если ваш обратный прокси дополнительно добавил слой `/v1`, скорректируйте адрес, чтобы избежать дублирующихся суффиксов.
</Note>

## Предварительные условия

| Проект | Описание |
|------|------|
| Аккаунт Crazyrouter | Сначала зарегистрируйтесь на [crazyrouter.com](https://crazyrouter.com) |
| Токен Crazyrouter | Для LobeChat рекомендуется создать отдельный токен `sk-...` |
| LobeChat | Подходит онлайн-версия или самостоятельная установка, рекомендована актуальная стабильная версия |
| Доступная модель | Минимум одна чат-модель OpenAI, успешно протестированная сегодня, например `gpt-5.5` |

Рекомендуемый первый белый список моделей:

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

<Tip>
Если вы также хотите подключить Cursor, Codex, Claude Code через Crazyrouter, для LobeChat лучше выделить отдельный токен – так легче отслеживать расход на чат-клиент.
</Tip>

## Быстрый старт за 5 минут

<Steps>
  <Step title="Создать специальный токен для LobeChat">
    В панели Crazyrouter создайте токен с именем `lobechat`, на первый раз пропустите только `gpt-5.5`, `claude-opus-4-8` и другие успешно протестированные сегодня модели.
  </Step>
  <Step title="Открыть настройки языковой модели">
    Войдите в LobeChat, нажмите на аватарку или кнопку настроек в левом нижнем углу, откройте `Настройки` → `Языковая модель`.
  </Step>
  <Step title="Настроить путь OpenAI">
    В настройках `OpenAI` заполните:
    - `API Key`: ваш `sk-...`
    - `API-адрес прокси / API Proxy URL`: `https://api.crazyrouter.com/v1`

    Также включите `Использовать пользовательский API-адрес прокси` или аналогичную опцию.
  </Step>
  <Step title="Выберите базовую модель">
    После сохранения сначала выберите `gpt-5.5` как основную модель, не подключайте много моделей сразу.
  </Step>
  <Step title="Выполнить первичную проверку">
    Создайте новый диалог, отправьте: `Reply only OK`. Если ответ получен и в панели Crazyrouter виден лог, интеграция успешна.
  </Step>
</Steps>

## Быстрая конфигурация самостоятельного размещения

Если вы развернули LobeChat через Docker, можно предварительно прописать настройки OpenAI в переменные среды:

```yaml
services:
  lobechat:
    image: lobehub/lobe-chat
    ports:
      - "3210:3210"
    environment:
      - OPENAI_API_KEY=sk-xxx
      - OPENAI_PROXY_URL=https://api.crazyrouter.com/v1
      - OPENAI_MODEL_LIST=gpt-5.5,claude-opus-4-8,gemini-3.1-pro
```

Если не хотите предоставлять пользователям возможность менять Key, закрепите его в переменной среды на сервере, используя актуальные возможности скрытия или размещения конфигурации.

## Рекомендуемые настройки моделей

| Сценарий использования | Рекомендуемая модель | Причина |
|----------|----------|------|
| Основная чат-модель | `gpt-5.5` | Проверена сегодня, подходит для главной модели LobeChat |
| Качественная работа с текстом / кодом | `claude-opus-4-8` | Лучший опыт с длинным текстом, писательством и кодом |
| Gemini в запасе | `gemini-3.1-pro` | Хороший вариант для дополнительного теста совместимости |

Рекомендуем последовательность: сначала используйте `gpt-5.5`, затем расширяйтесь до `claude-opus-4-8` и `gemini-3.1-pro`.

## Лучшие практики настройки токенов

| Настройка | Рекомендация | Описание |
|------|------|------|
| Специальный токен | Обязательно | Не делайте общий токен для LobeChat и IDE / CLI |
| Белый список моделей | Очень рекомендуется | Откройте только те модели, которые используются в чате |
| Ограничение по IP | Если фиксированный выход при самостоятельном размещении — включить; при частых изменениях – быть осторожным |
| Лимит квоты | Очень рекомендуется | В командном чате один токен часто используют многие |
| Изоляция сред | Рекомендуется | Используйте разные токены для тестовой и рабочей среды |
| Контроль модели по умолчанию | Рекомендуется | Уберите дорогие модели из списка по умолчанию — включайте по необходимости |

## Частые ошибки и их исправление

| Явление | Частые причины | Способ исправления |
|------|----------|----------|
| Не удаётся сохранить или проверка не проходит | Неправильный API Key или ошибочный адрес прокси | Проверьте `sk-...` и `https://api.crazyrouter.com/v1` |
| 401 unauthorized | Токен не действителен, истёк или удалён | Сгенерируйте новый токен и замените |
| 403 / model not allowed | Модель не добавлена в белый список токена | Разрешите модель в панели Crazyrouter |
| 404 | Адрес прокси - корневой домен или конкретный путь | Измените на `https://api.crazyrouter.com/v1` |
| Настройки правильные, но всё равно 404 | Ваш шлюз или обратный прокси уже автоматически добавил `/v1` | Проверьте, не появились ли двойные суффиксы; если верхний уровень уже добавил `/v1`, не дублируйте |
| Модель видна, но выдаёт ошибку | Фронт LobeChat сохранил старые модели или несуществующую по умолчанию | Вернитесь к `gpt-5.5`, обновите страницу и выберите заново |
| Диалог отправляется, но выдаёт ошибку потока | Версия клиента или несоответствие модели | Сначала используйте `gpt-5.5` для теста и обновите LobeChat |
| Быстро расходуется лимит при командном использовании | Несколько пользователей используют один токен без лимита | Задайте лимит для командного чата; при необходимости разделите на несколько токенов |
| Пользователи могут подключать других провайдеров после самостоятельного размещения | Просто задано значение по умолчанию, не ограничена пользовательская настройка | Закрепите в настройке или отключите возможность изменения пользователями |

## Рекомендации по производительности и затратам

- На первом этапе оставьте только `gpt-5.5`
- Для командного чата по умолчанию выбирайте недорогие модели, дорогие модели пусть используют продвинутые пользователи или под особые задачи
- Если используете базы знаний, плагины или длинные диалоги, обязательно настройте квоту LobeChat отдельно
- При самостоятельном размещении разделите токены для рабочей и тестовой среды, чтобы внутренние тесты не расходовали официальный лимит
- При необычно высоком расходе сначала проверьте логи Crazyrouter — часто причиной служит многопользовательский длинный диалог

## ЧАВО

### Какой Base URL следует указать в LobeChat?

Укажите `https://api.crazyrouter.com/v1`.

### Почему нельзя просто указать корневой домен?

Потому что конфигурация OpenAI-прокси LobeChat лучше работает при указании OpenAI-совместимого базового адреса, а не только корневого домена.

### Что делать, если мой обратный прокси уже автоматически проставляет `/v1`?

Не дублируйте `/v1` в конечном адресе для LobeChat. Проверьте цепочку прокси — избегайте двойных суффиксов.

### Какая первая модель рекомендуется?

Сначала используйте `gpt-5.5`.

### Можно ли подключить несколько моделей одновременно к LobeChat?

Можно, но сперва протестируйте одну модель, затем расширяйте список.

### Нужно ли фиксировать токен в переменной среды при самостоятельном размещении?

Если хотите централизовано управлять расходом и верхним провайдером — рекомендуется; если планируете, чтобы каждый пользователь задавал свой Key — тогда разрешите пользовательское редактирование.

<Note>
Если вы хотите стабильный чат-фронт и командную рабочую панель — LobeChat отличный выбор; если важна прокси для кода и автоматизация, приоритет отдайте инструментам типа Cursor, Claude Code, Codex, Cline.
</Note>
