Cherry Studio — это AI-клиент для настольного мульти-модельного чата, организации знаний и интеграции инструментов MCP. При подключении к Crazyrouter рекомендуется использовать в Cherry Studio режим `OpenAI` пользовательского провайдера, так легче всего обеспечить совместимость списка моделей, потоковый вывод и стандартные функции чата.

## Общий обзор

С помощью пользовательского режима Cherry Studio вы можете подключить Crazyrouter в качестве совместимого с OpenAI upstream:

- Рекомендуемый протокол: `OpenAI-compatible API`
- Рекомендуемый тип провайдера: `OpenAI`
- API-адрес: `https://api.crazyrouter.com`
- Способ авторизации: `sk-...` token
- Рекомендуемая модель для первой проверки: `gpt-5.5`

<Note>
Официальная документация Cherry Studio: если API upstream имеет формат `https://xxx.com/v1/chat/completions`, обычно в `Адрес API` нужно вводить только корневой адрес. То есть, при подключении Crazyrouter первоначально заполняйте `https://api.crazyrouter.com`, а не `https://api.crazyrouter.com/v1`.
</Note>

<Tip>
Cherry Studio автоматически добавит стандартный остаточный путь; только если ваш upstream не использует обычный `.../v1/chat/completions` роутинг, требуется вручную указать полный адрес с окончанием на `#` в `Адрес API`. Для стандартного чата Crazyrouter этого делать не нужно.
</Tip>

## Кому подходит

- Тем, кто хочет централизованно управлять несколькими моделями на десктопе
- Тем, кто хочет использовать Crazyrouter для ежедневного чата, письма, перевода и работы с материалами
- Тем, кто хочет интегрировать инструменты MCP в локальный чат-клиент
- Тем, кто хочет быстро переключать экономичные и высокопроизводительные модели из одного интерфейса

## Используемый протокол

Рекомендуемый протокол: `OpenAI-compatible API`

Рекомендуется добавить новый пользовательский провайдер типа `OpenAI` и указать корневой домен Crazyrouter в `Адрес API`:

```text
https://api.crazyrouter.com
```

Не заполняйте сразу:

- `https://api.crazyrouter.com/v1/chat/completions`
- `https://api.crazyrouter.com/v1/models`

Если вы используете нестандартный роутинг, то в Cherry Studio требуется вручную прописать полный адрес с окончанием на `#`; для стандартного чата Crazyrouter этого не надо.

## Предварительные условия

| Элемент | Описание |
|------|------|
| Аккаунт Crazyrouter | Зарегистрируйтесь на [crazyrouter.com](https://crazyrouter.com) |
| Crazyrouter token | Рекомендуется создать отдельный токен `sk-...` специально для Cherry Studio |
| Cherry Studio | Используйте актуальную стабильную версию десктопного клиента |
| Доступная модель | Разрешите хотя бы одну модель для чата, которую успешно протестировали сегодня, например `gpt-5.5` |

Рекомендуемый whitelist моделей:

- `gpt-5.5`
- `claude-opus-4-8`
- `gemini-3.1-pro`

## Быстрый старт за 5 минут

<Steps>
  <Step title="Создать специальный токен для Cherry Studio">
    В админке Crazyrouter создайте новый токен, рекомендуем назвать его `cherry-studio`. Сначала разрешите 2–4 нужные модели, не открывайте все сразу.
  </Step>
  <Step title="Добавить пользовательского провайдера">
    Откройте Cherry Studio, перейдите в `Настройки` → `Служба моделей`, нажмите внизу `Добавить` или `+ Add`. Тип провайдера выберите `OpenAI`, имя рекомендуем `Crazyrouter`.
  </Step>
  <Step title="Введите информацию для подключения">
    На странице настройки провайдера заполните:
    - `API Key`: ваш `sk-...`
    - `Адрес API`: `https://api.crazyrouter.com`

    После заполнения нажмите `Проверить` для проверки токена и адреса.
  </Step>
  <Step title="Импортировать и добавить модель">
    Нажмите `Управление` или `Manage` для загрузки списка моделей, затем вручную добавьте нужные модели в провайдер. Важно: появление модели во всплывающем окне не значит, что она добавлена в доступный список — обычно надо еще раз нажать `+`. В первый раз добавьте только одну базовую модель: `gpt-5.5`.
  </Step>
  <Step title="Включить провайдера и начать первый диалог">
    Включите переключатель в правом верхнем углу, вернитесь в чат и выберите `gpt-5.5`, отправьте простой запрос, например: `Reply only OK`. После получения ответа добавляйте остальные модели.
  </Step>
</Steps>

## Рекомендации по настройке моделей

| Сценарий | Рекомендуемая модель | Причина |
|----------|----------|------|
| Основной чат по умолчанию | `gpt-5.5` | Успешно протестирована сегодня, подходит как основная модель совместимая с OpenAI |
| Качественный код / длинные тексты | `claude-opus-4-8` | Подходит для сложных задач, письма и интерпретации кода |
| Резерв Gemini | `gemini-3.1-pro` | Используется для дополнительной проверки совместимости второго провайдера |

Рекомендуемый порядок: сначала запуск `gpt-5.5`, затем поочередно добавление `claude-opus-4-8` и `gemini-3.1-pro`.

## Лучшие практики настройки токена

| Опция | Рекомендация | Описание |
|------|------|------|
| Специализированный токен | Обязательно | Не используйте общий токен для Cherry Studio и Cursor, Claude Code, Codex |
| Белый список моделей | Очень рекомендуется | Разрешайте только те модели, которые будет использовать Cherry Studio |
| Ограничение IP | По необходимости | Для стационарной сети включайте; при частой смене сетей будьте осторожны |
| Лимит квоты | Очень рекомендуется | Десктопный чат часто вызывает много запросов, выделите отдельно лимит |
| Разделение dev/prod | Рекомендуется | Создавайте отдельные токены для личных, общих и демонстрационных машин |
| Многоключевой polling | Используйте осторожно | Cherry Studio поддерживает polling по нескольким ключам, но диагностика сложнее — сначала настройте работу с одним ключом |

## Рекомендации по использованию MCP

Cherry Studio поддерживает MCP, но рекомендуем делать это поэтапно:

1. Сначала проверьте устойчивую работу чат-модели Crazyrouter
2. Затем добавьте MCP-сервис и протестируйте инструменты по отдельности

Так проще разделить вопросы моделей и инструментария MCP.

Если MCP включен:

- Выберите стабильную модель с поддержкой инструментов
- Сначала добавьте один MCP-сервис для проверки
- При первом вызове инструмента протестируйте самые простые операции чтения или поиска

## Частые ошибки и решения

| Симптом | Причина | Решение |
|------|----------|----------|
| `Проверить` — ошибка | Ошибка `API Key` или копирование с пробелами | Создайте новый токен и вставьте чистый `sk-...` |
| 401 unauthorized | Токен неактивен, истек или удален | Создайте и замените токен в Crazyrouter |
| 403 / model not allowed | Модель не разрешена токеном | Разрешите соответствующую модель в настройках токена |
| 404 | `Адрес API` указан полный путь к API или неверный тип провайдера | Измените на тип `OpenAI` и пропишите адрес как `https://api.crazyrouter.com` |
| `Проверить` — ошибка, но адрес и ключ верны | Cherry Studio проверяет работоспособность через последнюю модель списке, а она может быть невалидной | Оставьте только `gpt-5.5`, удалите сомнительные модели и перезапустите `Проверить` |
| Список моделей не загружается | Ошибка адреса, проблемы с сетью или провайдер не активирован | Сначала нажмите `Проверить`, проверьте включенный переключатель и интернет |
| Подключение есть, но чат ошибка | Добавлена несовместимая или нерабочая модель | Оставьте только `gpt-5.5` и проверьте базовую работу |
| Ошибки потокового вывода | Проблемы совместимости модели или клиента | Переключитесь на `gpt-5.5` и обновите Cherry Studio |
| MCP-инструменты не вызываются | Причина в настройках MCP, не в модели | Отключите MCP и проверьте модели; отдельно настройте MCP |

## Рекомендации по производительности и стоимости

- Для первого подключения включайте только 1–2 модели, чтобы не запутаться в выборе
- Используйте сначала `gpt-5.5`; для длинных текстов и кода переходите на `claude-opus-4-8`
- Часто ведёте длинные диалоги — выделите отдельную квоту для Cherry Studio
- Cherry Studio поддерживает переключение моделей — дорогие оставляйте только для сложных задач
- При обнаружении необычного расхода проверьте логи Crazyrouter на предмет повторных попыток, длинных диалогов

## Частые вопросы

### Какой адрес в Cherry Studio нужно указать?

Заполняйте сначала `https://api.crazyrouter.com`.

### Почему не советуют сразу вводить `/v1`?

Cherry Studio рекомендует — для большинства upstream, совместимых с OpenAI, достаточно корневого адреса, клиент допишет путь автоматически. Для Crazyrouter тоже действует такой подход.

### Когда указывать полный адрес с окончанием на `#`?

Только если upstream не стандартный роутинг OpenAI. Для стандартного подключения Crazyrouter используйте корневой домен.

### Какой первый рекомендуемый модель?

Используйте сначала `gpt-5.5`.

### Можно ли сразу добавить много моделей?

Можно, но не советуем так делать сразу. Сначала настройте одну — постепенно добавляйте остальные.

### Cherry Studio совместим с MCP при работе с Crazyrouter?

Да, но сначала проверьте работу чат-модели, затем активируйте MCP, так легче выявить проблемы.

<Note>
Если вам нужен десктопный мульти-модельный чат и лёгкая совместная работа с MCP, то Cherry Studio отлично подойдёт для старта; если важнее опыт кодового агента в IDE, рекомендуем отдать предпочтение Cursor, Claude Code, Codex, Cline и другим подобным инструментам.
</Note>
