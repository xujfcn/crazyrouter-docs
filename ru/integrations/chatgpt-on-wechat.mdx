## Обзор

ChatGPT on WeChat — это типичный проект чат-бота для WeChat, который позволяет использовать возможности моделей Crazyrouter как в личных сообщениях, так и в групповых чатах. Рекомендуется продолжать использовать его стандартную настройку совместимости с OpenAI и сначала запускать минимальную цепочку ответов на проверенной рабочей модели.

## Рекомендуемая первичная настройка

- `open_ai_api_base`: `https://api.crazyrouter.com/v1`
- Первая проверочная модель: `gpt-5.5`
- На первом этапе открывать только ограниченное число моделей, чтобы не расширять диапазон устранения неполадок

## Метод настройки

### Редактирование файла конфигурации

Редактируйте `config.json`:

```json
{
  "open_ai_api_key": "sk-xxx",
  "open_ai_api_base": "https://api.crazyrouter.com/v1",
  "model": "gpt-5.5",
  "proxy": "",
  "single_chat_prefix": [""],
  "single_chat_reply_prefix": "",
  "group_chat_prefix": ["@bot"],
  "group_name_white_list": ["AI交流群"]
}
```

### Метод с переменными среды

```bash
export OPEN_AI_API_KEY=sk-xxx
export OPEN_AI_API_BASE=https://api.crazyrouter.com/v1
export MODEL=gpt-5.5
```

### Развертывание через Docker

```yaml
services:
  chatgpt-on-wechat:
    image: zhayujie/chatgpt-on-wechat
    environment:
      - OPEN_AI_API_KEY=sk-xxx
      - OPEN_AI_API_BASE=https://api.crazyrouter.com/v1
      - MODEL=gpt-5.5
    volumes:
      - ./config.json:/app/config.json
```

## Рекомендуемые модели

| Сценарий | Модель | Описание |
|------|------|------|
| Первичная проверка цепочки | `gpt-5.5` | Успешно проверена в производственной среде 23 марта 2026 года, оптимально для начального подтверждения совместимости с OpenAI |
| Длинные ответы высокого качества | `claude-opus-4-8` | Лучше подходит для сложных объяснений, резюме и длинных текстов |
| Gemini альтернативный вариант | `gemini-3.1-pro` | Подходит для дополнительной проверки совместимости поставщика (по второму пути) |

## Рекомендуемая последовательность проверки

1. Сначала настройте только один токен
2. Сначала настройте только одну модель `gpt-5.5`
3. В личном чате отправьте `Reply only OK`
4. Убедитесь, что в логах Crazyrouter появился соответствующий запрос
5. Затем постепенно расширяйте доступ к группам, правилам префикса и другим моделям

<Warning>
  Проект чат-бота должен соответствовать правилам использования WeChat, чтобы избежать блокировки аккаунта из-за частых отправок сообщений.
</Warning>
