# Передайте документацию ИИ-инструментам

Если вы пишете код с помощью ChatGPT, Claude, Cursor, Cline, Aider, Codex или другого ИИ-инструмента, передайте ему эту ссылку на документацию:

```text
https://docs.crazyrouter.com/llms.txt
```

Этот индекс помогает ИИ найти инструкции по быстрому запуску, аутентификации, адресам API, списку моделей, API для изображений, видео и аудио, а также интеграции с инструментами разработки.

## Готовый запрос для ИИ

Скопируйте следующий текст в свой ИИ-инструмент:

```text
Сначала прочитай https://docs.crazyrouter.com/llms.txt, затем ответь на мой вопрос на основе официальной документации Crazyrouter.

Моя задача: [опишите задачу, например: сгенерировать пятисекундное видео через Sora 2 с помощью Python]

Учитывай следующее:
- Для SDK, совместимых с OpenAI, обычно нужно использовать base_url: https://api.crazyrouter.com/v1.
- Названия моделей, цены и правила оплаты проверяй на https://crazyrouter.com/pricing.
- Если доступность модели неясна, предложи проверить её на странице Pricing или через /v1/models.
- Приведи примеры кода, которые можно запустить.
```

## Примеры использования

| Задача для ИИ | Пример запроса |
| --- | --- |
| Создать код интеграции | «Прочитай llms.txt и напиши пример обращения к Crazyrouter API на Python или Node.js». |
| Подключить конкретную модель | «Прочитай llms.txt и проверь, какой эндпоинт Crazyrouter нужен для этой модели». |
| Настроить IDE или агента | «Прочитай llms.txt и объясни, как настроить Crazyrouter в Cursor, Cline или Claude Code». |
| Разобраться с ошибкой | «Прочитай llms.txt и документацию по обработке ошибок, затем помоги разобраться с этой ошибкой Crazyrouter API». |
| Создать видео или изображение | «Прочитай llms.txt и покажи пример запроса для генерации видео или изображения». |

## Когда использовать llms-full.txt

`llms.txt` — это краткий индекс. Он помогает ИИ определить, какие страницы следует прочитать в первую очередь.

Если ваш ИИ-инструмент умеет обрабатывать длинные тексты или вы хотите передать ему всю документацию сразу, дополнительно укажите:

```text
https://docs.crazyrouter.com/llms-full.txt
```

## Где проверять модели и цены

Доступность моделей зависит от каналов, разрешений и настроек платформы. Примеры в документации объясняют формат запросов и не являются полным каталогом моделей.

Актуальные публичные модели, цены и правила оплаты доступны по адресу:

```text
https://crazyrouter.com/pricing
```

Если у вас уже есть API-ключ, список доступных для него моделей можно получить следующим запросом:

```bash cURL
curl https://api.crazyrouter.com/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

<Warning>
Не вставляйте настоящий API-ключ в недоверенные ИИ-инструменты или публичные обсуждения. Когда просите ИИ написать код, используйте заглушку, например `YOUR_API_KEY`.
</Warning>

## Отдельные страницы в формате Markdown

Многие страницы документации доступны и в формате Markdown. Добавьте `.md` в конец адреса страницы:

```text
https://docs.crazyrouter.com/ru/quickstart.md
https://docs.crazyrouter.com/ru/api-endpoint.md
https://docs.crazyrouter.com/ru/video/sora.md
```

Если ИИ-инструмент плохо читает весь сайт, сначала передайте ему `llms.txt`, а затем — ссылки на нужные страницы с расширением `.md`.
