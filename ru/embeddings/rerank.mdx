## Описание интерфейса

Выполняет повторную сортировку группы документов по семантической релевантности к запросу, обычно используется как второй этап при улучшенном поиске с генерацией (RAG).

<Note>
  Реализовано по формату [SiliconFlow Rerank API](https://docs.siliconflow.cn/cn/api-reference/rerank/create-rerank).
</Note>

## Поддерживаемые модели

| Модель | Описание |
|------|------|
| `gte-rerank-v2` | Многоязычная модель для переранжирования, рекомендуется |
| `gte-rerank-v2` | В основном для английского языка |

## Параметры запроса

<ParamField body="model" type="string" required>
  Название модели переранжирования, например `gte-rerank-v2`
</ParamField>

<ParamField body="query" type="string" required>
  Текст запроса
</ParamField>

<ParamField body="documents" type="string[]" required>
  Список документов для ранжирования
</ParamField>

<ParamField body="top_n" type="integer">
  Вернуть первые N результатов, по умолчанию возвращаются все
</ParamField>

<ParamField body="return_documents" type="boolean" default="true">
  Возвращать ли оригинальный текст документов в ответе
</ParamField>

## Формат ответа

```json
{
  "model": "gte-rerank-v2",
  "results": [
    {
      "index": 2,
      "relevance_score": 0.9875,
      "document": { "text": "最相关的文档内容" }
    },
    {
      "index": 0,
      "relevance_score": 0.7432,
      "document": { "text": "次相关的文档内容" }
    },
    {
      "index": 1,
      "relevance_score": 0.1205,
      "document": { "text": "不太相关的文档内容" }
    }
  ],
  "usage": {
    "total_tokens": 128
  }
}
```

## Пример кода

<CodeGroup>

```python Python
import requests

response = requests.post(
    "https://api.crazyrouter.com/v1/rerank",
    headers={
        "Authorization": "Bearer sk-xxx",
        "Content-Type": "application/json"
    },
    json={
        "model": "gte-rerank-v2",
        "query": "什么是向量数据库",
        "documents": [
            "向量数据库是专门存储和检索高维向量的数据库系统",
            "关系型数据库使用表格存储结构化数据",
            "向量数据库支持近似最近邻搜索，适合语义检索场景",
            "Redis 是一个内存键值存储系统"
        ],
        "top_n": 2,
        "return_documents": True
    }
)

data = response.json()
for result in data["results"]:
    print(f"[{result['relevance_score']:.4f}] {result['document']['text']}")
```

## Типичный процесс RAG

```
用户查询 → Embedding 检索 Top-K → Rerank 精排 → LLM 生成回答
```

<Warning>
  Рекомендуется, чтобы количество входных документов для переранжирования не превышало 100. Слишком большое количество документов увеличивает задержку и стоимость.
</Warning>
